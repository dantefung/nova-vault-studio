# 扩展配置

## 特定行业术语规范

### 技术领域
- `React` 首字母大写
- `JavaScript`、`TypeScript` 驼峰命名
- `API`、`SDK`、`CLI` 全大写
- `GitHub`、`GitLab` 首字母大写

### 品牌名称
- `iPhone`、`iPad`、`MacBook` 保持官方写法
- `WeChat` 微信（英文场景）
- `Alipay` 支付宝（英文场景）

## 特殊格式处理

### 代码块
遇到以下标记的代码块，完全保持原样：
```
```javascript
```python
```bash
```

### 表格
保持 Markdown 表格格式，但优化表格内文字：
- 表头使用粗体
- 单元格内容应用标点规范
- 对齐方式保持不变

### 列表
- 有序列表：统一使用 `1.` `2.` `3.` 格式
- 无序列表：统一使用 `-` 或 `*` 符号
- 列表项结尾统一不加标点或统一加分号

## 自定义排版风格

### 标题层级
- H1: 文章主标题
- H2: 章节标题
- H3: 小节标题
- H4: 段落小标题

### 强调方式
- **重要内容** 使用粗体
- *次要强调* 使用斜体
- `专业术语` 使用行内代码标记

### 引用格式
```markdown
> 这是引用内容
> 引用内容保持原样，只优化引用标记格式
```

## 数字与单位规范

### 数字表示
- 小于 10 的数字：根据语境决定使用中文或阿拉伯数字
- 大于 10 的数字：使用阿拉伯数字
- 百分比：使用 `%` 符号，如 `50%`
- 日期：使用 `YYYY-MM-DD` 格式，如 `2026-07-27`

### 单位间隔
- 数字与单位之间加空格：`100 MB`、`50 kg`、`3 个`
- 货币符号紧贴数字：`$100`、`¥200`
- 温度单位紧贴数字：`25°C`

## 链接处理

### URL 链接
- 保持 URL 完整性
- 链接文本使用中文描述
- 示例：`[查看详情](https://example.com)`

### 内部引用
- 使用相对路径
- 保持文件扩展名
- 示例：`[参考文档](./reference.md)`

## 脚注与引用

### 脚注格式
```markdown
这是正文内容[^1]

[^1]: 这是脚注说明
```

### 参考文献
```markdown
## 参考文献

1. 书名，作者，出版社，年份
2. 文章标题，作者，网站名称，日期
```

## 特殊符号处理

### 常用符号映射
- `...` → `…`（省略号）
- `--` → `—`（破折号）
- `<<` `>>` → `《》`（书名号）
- `(c)` → `©`（版权符号）

### 数学符号
保持 LaTeX 格式不变：
```latex
$E = mc^2$
$$\sum_{i=1}^{n} x_i$$
```

## 禁止修改的内容

1. **HTML 标签** - 保持原样
2. **正则表达式** - 保持原样
3. **Shell 命令** - 保持原样
4. **配置文件内容** - 保持原样
5. **Base64 编码** - 保持原样
6. **哈希值** - 保持原样

## 语言混排规则

### 中英文混排
- 中文与英文之间加空格
- 中文与数字之间加空格
- 英文与标点符号按英文规则处理

示例：
```
错误：我使用React开发了一个应用
正确：我使用 React 开发了一个应用

错误：共有100个用户
正确：共有 100 个用户
```

### 中文与特殊符号
- 中文与 `@` `#` `$` 等符号之间不加空格
- 中文与括号之间不加空格

示例：
```
正确：联系方式@example.com
正确：价格¥99.99
正确：备注（重要）
```
