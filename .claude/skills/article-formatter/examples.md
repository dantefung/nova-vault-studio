# Article Formatter - 使用示例

## 场景 1: 网页文章复制优化

### 输入文本
```
AI技术发展迅速,特别是在2023年,ChatGPT的出现改变了整个行业.现在越来越多的公司开始使用AI技术来提升效率.
根据统计,有超过70%的企业表示他们计划在未来12个月内增加AI投入.
AI不仅仅是一个工具,更是一种全新的生产力...它将彻底改变我们的工作方式!!!
```

### 优化后输出
```
AI 技术发展迅速，特别是在 2023 年，ChatGPT 的出现改变了整个行业。现在越来越多的公司开始使用 AI 技术来提升效率。

根据统计，有超过 70% 的企业表示他们计划在未来 12 个月内增加 AI 投入。

AI 不仅仅是一个工具，更是一种全新的生产力。它将彻底改变我们的工作方式。
```

### 优化说明
- 中英文之间添加空格
- 统一使用中文标点符号
- 数字与文字之间添加空格
- 删除多余的感叹号
- 优化段落结构，增加段落间空行

## 场景 5: 代码注释优化

### 输入文本
````
```javascript
// 这个函数用来计算两个数的和,很简单的
function add(a,b){
  return a+b;
}

//注意:参数必须是数字类型!!!
//如果传入字符串会出错
```
````

### 优化后输出
````
```javascript
/**
 * 计算两个数的和
 * @param {number} a - 第一个加数
 * @param {number} b - 第二个加数
 * @returns {number} 两数之和
 * @note 参数必须是数字类型，如果传入字符串会导致类型错误
 */
function add(a, b) {
  return a + b;
}
```
````

### 优化说明
- 转换为 JSDoc 标准注释格式
- 添加参数和返回值说明
- 删除口语化表达
- 规范代码缩进和空格

## 场景 8: 错误混排文本修复

### 输入文本
```
使用React开发时,常见的问题包括:
1.useState的值没有及时更新
2.useEffect依赖数组配置错误导致无限循环
3.key属性使用index会导致性能问题

解决方案:
对于问题1,记住state更新是异步的
对于问题2,仔细检查依赖数组
对于问题3,使用唯一标识符作为key
```

### 优化后输出
```
使用 React 开发时，常见的问题包括：

1. `useState` 的值没有及时更新
2. `useEffect` 依赖数组配置错误导致无限循环
3. `key` 属性使用 `index` 会导致性能问题

**解决方案**

- 对于问题 1，记住 state 更新是异步的
- 对于问题 2，仔细检查依赖数组
- 对于问题 3，使用唯一标识符作为 `key`
```

### 优化说明
- API 名称使用代码标记
- 中英文之间添加空格
- 数字与文字之间添加空格
- 添加小标题强调
- 统一列表编号格式

## 使用技巧

### 1. 批量处理
可以一次性处理多段文本，每段之间用 `---` 分隔：

```
段落 1 的内容...

---

段落 2 的内容...

---

段落 3 的内容...
```

### 2. 保留特定格式
如果某些内容不希望被优化，可以用代码块包裹：

````
正常文本会被优化

```preserve
这段内容保持原样
```

继续优化的内容
````

### 3. 指定优化程度
- **轻度优化**：只修正标点和空格
- **标准优化**：标点、空格、段落结构
- **深度优化**：包含内容精简和重写

### 4. 特定领域处理
告知文本类型以获得更好的优化效果：
- 技术文档
- 学术论文
- 商务邮件
- 社交媒体
- 产品说明
