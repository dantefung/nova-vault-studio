# 50 个知识管理 Skill，帮你打造 AI 生产力系统

上半年我做 AI 生产力培训课，我也一直在实践这套东西。

关注我久的话，应该能感觉到：我的文章更新频率高了，配图质量高了，视频的制作也多了。

其实就是这些 Agent 在帮我干活。

对于一个新手，拿到一个桌面 Agent，要怎么用它来解放生产力？

首先，我们要搭建一个文件夹系统，也就是把你的数据都整理成文件夹。

下面是我的文件夹目录结构：

![image](./images/indie-hub-article-3/001.png)

数据就是 Agent 的生产力

我们要把自己读过的内容，写过的内容组织起来给 Agent 看，给 Agent 提供工具和使用规则。

工具一方面是你的电脑环境里的浏览器、CLI等，还有一部分就是 Skill 。

大量的制作 skill：

从你数据入手：你可以让 Agent 基于你的内容制作一个你的写作风格 Skill，让 Agent 每次产出内容都模仿你的风格。

从你日常执行入手：假如你每天都有重复要分析的数据、计算的表格，这些就可以让它根据你工作流程制作成 Skill。

不做 skill 也没关系。

可以先用我创作的关于阅读、设计、创作三方面的 Skill 来帮你输出文字.图片.视频 ppt 等各种内容。

我自己花了点时间把做的近 200 个 Skill 里挑选来 50 个和知识管理 Skill，整理成了三个仓库，全部开源：

Read Buddy ，阅读和整理

共 19 个 skill， 把网页、RSS、YouTube、播客、X/Twitter、飞书文档、图片 OCR、微信读书划线，全部转成可读、可检索、可继续写作的结构化内容。信息不管在什么格式里，先拿回来。

![image](./images/indie-hub-article-3/002.png)

地址：github.com/SpaceZephyr/read-buddy

Design Buddy ，设计和配图

也是 19 个 skill， 把文章内容转成封面、配图、逻辑图、架构图、Logo、故事板、幻灯片、公众号排版。从初稿到可发布，不用打开设计软件。

![image](./images/indie-hub-article-3/003.png)

地址：github.com/SpaceZephyr/design-buddy

Creator Buddy ，创作和分析

![image](./images/indie-hub-article-3/004.png)

共 5 个 skill， 从抖音、小红书、公众号、B站搜热点、挖爆款、看评论、查竞品。把"今天写什么"变成一套可复用的数据工作流。

阅读、设计、创作，正好是知识工作从输入到输出的完整链路。

地址：github.com/SpaceZephyr/creator-buddy

这些 Skill 背后，是一套系统理念

这些 Skill 不是散装的工具，它们依赖我的 AI 生产力系统理念。

传统知识管理经历的 阅读——整理——输出 的每个环节都是人参与的。

AI 生产力系统的每个模块都是给 Agent 准备的，可以包含五个模块：

文件夹就是上下文边界。每个目录下放一个规则说明，也可以用 hook 来触发 Agent 讲文件存放到指定目录，告诉 Agent 这里存什么、怎么读、写入要遵守什么规范。

你在做什么业务线、这个季度要达成什么、本周优先级是什么。

Agent 在执行任务的时候可以关联到你的目标，帮你搜的热点哪些相关、写的文章往哪个方向使劲。

今天开源的这些 Skill 就是一部分，另外还有 Agent 自身具备的电脑使用、浏览器预览等能力。

它们是系统的 SOP，一个 Skill 只做一件事：转 Markdown、生成封面、搜爆款。原子化设计，串联起来完成复杂任务。

Agent 每天干了什么、你反馈了什么、哪篇文章数据好、哪个选题扑了，重要的都要留痕。

可以让 Agent.md里说明每天记下重点做了什么。

没有记忆的 Agent 每次从零开始，有记忆的 Agent 越用越懂你。

你的写作风格、金句库、历史文章、读者画像。

这是让 Agent 的产出"像你"而不是"像 AI"的关键。

文件夹是骨架，上下文是血肉，Skill 是能力，Agent 是执行者。

我每天在跑的效果：

早上起来，24 小时内的 AI 热点、公众号爆款、小红书趋势已经躺在日报里，附带爆款原因分析

读我的历史文章和风格文档生成初稿，再按段落批量配图，我只需要审一遍

竞品在发什么、哪类标题在涨、我的内容数据如何，定期生成分析报告

写作时它会提醒我："这个观点《系统之美》里讲过，你划过线，原话是……"

上面提供的 50 个 Skill，并非独立存在的，可以结合起来一起用，很多 Skill 也是有一个总控的 Skill 来互相调用的。

Creator Buddy 找到选题 → Read Buddy 抓回素材 → 写成文章 → Design Buddy 配图排版。

也可以单独用：

用微信读书的 Skill，一键导出全部划线笔记，生成 10 维度的阅读分析报告；还能让 AI 当读书教练，想搞懂一个领域给你阶梯书单，写作时从你读过的书里找可引用的原话。

用播客获取的 Skill，丢一个 YouTube 或小宇宙链接，自动提取字幕、转成文字稿，再消化成摘要或口播脚本。

用爆款搜索的 Skill，输入一个赛道关键词，返回近 7 天小红书、公众号的高互动内容，附标题范式和爆款原因，下一篇写什么一目了然。

工具是死的，系统是活的。这些 Skill 你可以今天就单独用，但我更希望你把它们种进自己的文件夹体系里，长出你自己的系统。

数据就是你的 Agent 生产力，数据越多 Agent 越懂你。
