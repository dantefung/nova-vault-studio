# Journal / Diary Skill

日记记录技能。用于记录用户的随思、感悟、语录等非结构化内容。

## 触发词

"记录日记"、"记一下"、"写个日记"、"随手记"、"先记下来"

## 规则

### 文件位置

- 目录：`docs/md/wiki/journal/`
- 文件名：`YYYY-MM-DD.md`（按日期分文件）

### 内容组织

- 按**内容主题**划分章节/条目，追加到当天的文件里
- 同一日期的多条记录放在同一个文件的不同章节

### 格式

```markdown
## HH:MM 主题标签

内容...

*—— 来源*
```

### index.md 索引维护

`index.md` 是日记索引，**只登记不写内容**。

每次新建或更新日记文件后，在 `index.md` 顶部追加索引条目：

```markdown
## YYYY-MM-DD

- [HH:MM] 主题标签 — 一句话摘要
- [HH:MM] 主题标签 — 一句话摘要
```

index.md 保持按日期倒序排列（最新日期在前）。

## 操作流程

1. 用户说"记录日记" → 询问日记内容
2. 确定内容主题 → 创建/追加到 `docs/md/wiki/journal/YYYY-MM-DD.md`
3. 更新 `index.md` 的索引

## 示例

用户说："记录一下，今天看到一句话很触动我——创业不是冒险，而是控制风险。"

操作：
1. 创建/追加到 `docs/md/wiki/journal/2026-06-21.md`
2. 更新 `index.md`

**日记文件 `2026-06-21.md`：**

```markdown
## 2026-06-21

## HH:MM 创业风险观

创业不是冒险，而是控制风险。

*—— 某创业者*
```

**索引 `index.md` 新增：**

```markdown
## 2026-06-21

- [HH:MM] 创业风险观 — 创业不是冒险，而是控制风险
```
