## 内容概览

- **核心命题**：提示词是一次性的，流水线是复利的
- **系统规模**：67 个命令外壳、88 个工作流剧本、33 个子代理、48 份按需参考
- **三层架构**：外壳（只做路由）→ 工作流（负责决策）→ 执行者（动手写代码）
- **状态存储**：`.planning/` 就是数据库，状态在磁盘不在上下文
- **编排铁律**：编排者不动手，写代码的永远是子代理
- **单命令推进**：`/gsd:next` 的三道启动安全闸与五大出口
- **防御机制**：四类闸门（Pre-flight / Revision / Escalation / Abort）
- **产物驱动**：计划即文件、断点即文件、验证即门禁
- **硬核规则**：不猜上游、不盲重试、不跳门禁、不超预算
- **预算系统**：4 级上下文降级与 90/9/1 检查点体系
- **落地对照**：有 GSD 与没有 GSD 的真实开发命运对比
