# chrome 5

创建标记

## 一些快捷键

- `m<letter>`: 创建一个标记，例如 `mm`
- ` + \<letter\>: 切换到标记
- `gu`: 访问当前 URL 的上一层级
- `gU`: 访问当前 URL 的 root 级
- `i`: 暂停 VimiumC 在当前页面
- `<a-f>`: 重复点击
- `f2`: 取消聚焦和重新聚焦当前文本框
