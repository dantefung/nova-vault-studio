# vscode 2

掌握多窗口管理

## 打开新的窗口

- `shift + command + n`: mac
- `shift + ctrl + n`: windows

## 选择工作区

- `ctrl + r`

## 多个窗口切换

- `command + ` `: mac

## 关闭窗口

- `shift + command + w`: mac
- `shift + ctrl + w`: windows
