# Vim 教程

本章节包含 Vim 的完整学习路径，从基础到进阶。

## 学习路径

按照顺序学习以下内容：

1. 认识 vim
2. vim 的基础指令  
3. 掌握 vim 的语法
4. 处理单字符以及 undo/redo
5. 掌握可视化模式
6. 掌握文本对象
7. 如何在文件中移动的更快
8. 掌握搜索
9. 掌握高效移动的方法
10. 通过数字与点可以重复指令
11. 掌握多文件之间的跳转
12. 处理包裹字符的符号
13. 替换字符串
14. 掌握悬浮显示/大小写/注释
15. 掌握窗口的管理
16. 如何删除一个函数
17. 掌握宏
18. vim 调用 vscode 的命令
