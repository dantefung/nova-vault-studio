# 1.1 Codex 简介与环境配置

## 什么是 Codex

Codex 是 OpenAI 推出的 AI 编程工具，基于 GPT-4o 架构，专为代码生成和软件开发优化。与通用对话模型不同，Codex 深度理解编程概念、代码结构和软件工程实践。

## 核心能力

| 能力 | 说明 |
|------|------|
| 代码生成 | 根据自然语言描述生成代码 |
| 代码补全 | 智能补全当前代码 |
| 代码解释 | 解释代码逻辑和意图 |
| 调试修复 | 识别并修复 bug |
| 重构优化 | 提出改进建议并实施 |
| 生图能力 | 支持 image-2 生成图片 |

## 环境配置

### 安装方式

Codex 可通过多种方式访问：

1. **Web 端**：bewild.ai/subscribe
2. **CLI 工具**：通过命令行直接调用
3. **API 集成**：通过 API 接入自己的工作流

### 基本配置

```bash
# CLI 方式（示例）
codex login <api-key>
codex --model codex-4o codex-4o-max
```

## 订阅选择

推荐通过 bewild.ai/subscribe 订阅，支持更快的响应速度和更高的使用限制。
