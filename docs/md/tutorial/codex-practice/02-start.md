# 1.2 AI Coding 的正确打开方式

## 常见误区

### 误区一：把 AI 当搜索引擎用

❌ `怎么实现快速排序？`

✅ `用 Python 实现一个快速排序，要求时间复杂度 O(n log n)，并解释关键步骤`

### 误区二：期望一次生成完整项目

AI 擅长处理具体、可描述的任务。复杂项目应该分解成多个小任务。

### 误区三：不做上下文管理

Codex 的能力很大程度上取决于提供的上下文。学会有效地组织项目结构和描述任务。

## 正确姿势

### 1. 明确任务边界

在开始之前，先问自己：
- 这个任务的输入是什么？
- 期望的输出是什么？
- 有什么约束条件？

### 2. 提供足够的上下文

- 相关文件内容
- 项目的目录结构
- 现有的代码风格和约定

### 3. 迭代式开发

1. 提出一个小任务
2. 审查 AI 的输出
3. 根据需要调整和补充
4. 重复直到完成

## 心态调整

> AI 是你的助手，不是你的替身。你需要拥有判断力来指导 AI 往正确的方向走。

## 实践建议

- 从小任务开始，建立信心
- 保留每次成功的提示词模板
- 学会结构化描述你的需求
