# LazyVim 一键安装脚本

> **核心结论**：社区维护的 **binggan23/one-click-install-LazyVim** 脚本可以一键装好 Neovim + LazyVim 环境。**注意**：用第三方脚本前先看代码确认安全。

## 使用步骤

### 1. 下载脚本并运行

```bash
curl -O https://raw.githubusercontent.com/binggan23/one-click-install-LazyVim/main/lazyvim.sh
chmod +x lazyvim.sh
./lazyvim.sh
```

### 2. 按需选择

脚本执行时，可以根据需要选择安装 **Neovim** 和配置 **LazyVim**。

## ⚠️ 安全提示

> 使用第三方脚本前，最好先看一眼它的代码，确认安全再继续。
