# 青简 Qingjian

> 用 Rust 写的拼音输入法，候选词旁多一条正在学的语言的译词

**188 Stars** · GPL-3.0 · Rust

## 核心特性

- 用 Rust 编写，高性能、跨平台（macOS / Windows）
- 拼音输入法，候选词旁显示外语（日语/英语）译词，助力语言学习
- 支持双拼
- 离线可用，无网络依赖
