> **摘要** — 利用 Claude AI 将文档（Stripe 年度总结等英文长文）转化为美观易读的可视化网页。Claude 自动提取信息层级和分类，生成支持夜间模式和移动端响应式的可视化页面。核心技巧来自提示词工程 + Linear App 设计语言。

```mermaid
graph TD
    A[Claude可视化网页] --> B[输入文档]
    A --> C[自动提取]
    A --> D[生成网页]
    B --> B1[英文文档]
    C --> C1[信息层级]
    C --> C2[分类]
    D --> D1[夜间模式]
    D --> D2[响应式]
```

