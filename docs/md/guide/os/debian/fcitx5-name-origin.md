# Fcitx5 的名称由来与演变

## 最初：一个拼写错误造就的名字

Fcitx 最初的项目名为 **gWubi**，是一个仅支持五笔输入法的工具。开发者 Yuking 后来希望给它取一个更酷的名字，原本计划使用 **Fcit**，即 **F**ree **C**hinese **I**nput **T**ool（自由中文输入工具）的缩写。然而，在提交代码时，他"手滑"多打了一个字母 `x`，变成了 **Fcitx**。由于当时项目没有使用版本控制系统（如 Git），修改起来颇为麻烦，开发者便决定"将错就错"，保留了这个名字。

## 官方解释：旧的全称

在早期，Fcitx 的官方全称被解释为 **"Free Chinese Input Tool of X"** 的缩写，意指"X 环境下的自由中文输入工具"。这个命名方式在 Linux 社区中很常见，例如 SCIM 也是类似的首字母缩写组合。

## 演变：从"中文工具"到"输入法框架"

随着 Fcitx 的发展，它不再仅仅是一个中文输入工具，而是演变成了一个支持多种语言的**输入法框架**。因此，原先的"Free Chinese Input Tool of X"这一全称被认为不再合适，甚至可能带来误解。于是，社区发起了一次重命名讨论，最终决定**保留 Fcitx 这个名称，但不再赋予它一个单一的官方全称**。

现在，你可以用以下任何一个"回文缩写"来解释 Fcitx，它们都从不同侧面反映了它的特性：

* **Flexible Context-aware Input Tool with eXtension**（灵活的、上下文感知的、支持扩展的输入工具）
* **FanCY Input Tool for *niX**（为 *nix 系统设计的炫酷输入工具）
* **Forthcoming CJK Input Toy Xtreme**（未来的中日韩输入玩具，极限版）
* **Free Character Input Toy of *niX**（*nix 下的自由字符输入玩具）
* **Fcitx Can Input Text in *niX**（Fcitx 能在 *nix 中输入文本）

## 中文名与发音

Fcitx 的官方中文名是 **"小企鹅输入法"**。这个名字与英文全称的含义并无直接关系，它仅仅来源于项目的**企鹅图标**。同时，为了回应社区关于"Fcitx 无法发音"的抱怨，官方将发音定为 **[ˈfaɪtɪks]**（读作 "fight-iks"）。

至于 **Fcitx5**，它只是这个框架的第五个主要版本，名字本身并没有额外的含义。
