# 图解10种经典芯片，分清各类芯片都是干什么的

现代电子产品里面各种各样芯片各司其职，从通用处理器到专用芯片，看懂它们的定位，就能快速理解一套电子系统。🔹十种芯片简单解读1、CPU中央处理器：电脑的大脑，擅长通用计算，任务灵活多变，处理各类复杂程序逻辑。2、GPU图形处理器：大规模并行运算，核心优势是图形渲染，现在大量用于AI算力加速。3、MCU微控制器（单片机）：CPU、内存、定时器、ADC全部单片集成，多用于家电、汽车、物联网嵌入式控制。4、FPGA现场可编程门阵列：硬件可以反复重构修改，不用流片，适合产品原型验证、实现灵活高速算法。5、ASIC专用集成电路：为单一业务任务专门定制开发，性能强、功耗低，量产之后成本优势明显。6、存储器芯片 DRAM / Flash：负责存放数据。DRAM作为运行内存；Flash用于硬盘，断电之后数据不会丢失。7、ADC / DAC模数‑数模转换器：模拟信号和数字世界之间的桥梁，完成模拟电压与数字信号互相转换。8、PMIC电源管理芯片：电压升降转换、电池充放电管理，一颗芯片输出多路不同电压，给整套系统分配供电。9、RFIC射频芯片：专门处理无线信号，手机、蓝牙、WiFi的无线通信都依靠射频芯片完成。10、传感器芯片MEMS/光电：感知真实物理世界，采集温度、压力、图像、运动等外界物理信息，再转为电信号送给主控。💡小结CPU、MCU负责运算控制；GPU、FPGA偏向高速并行算法；ASIC面向大规模量产；存储器负责存数据；ADC‑PMIC‑射频‑传感器负责信号、电源、无线和外界感知。不同芯片互相搭配，共同组成现代电子设备。
