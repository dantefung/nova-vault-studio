## 六、常见面试题精析



Q1：为什么空结构体 sizeof(struct{}) 不是 0？



C++ 中空结构体大小为 1，因为每个对象都必须有唯一地址，若大小为 0，两个相邻对象的地址就相同了。C 语言中结果是未定义行为，不同编译器不同。



Q2：位域（bit field）怎么影响 sizeof？



位域按底层存储单元（这里是 unsigned int，4 字节）打包，全部塞进一个 int 里，sizeof(struct E) = 4。



Q3：offsetof 宏有什么用？



在不知道结构体具体布局时，用 offsetof 获取某成员相对结构体起始地址的字节偏移，常用于序列化/反序列化。



Q4：结构体成员顺序在工程中该怎么排列？



按大小从大到小排列（先放 8 字节的 double/指针，再放 int，最后放 char），这样几乎不会产生中间 padding，内存最省。
