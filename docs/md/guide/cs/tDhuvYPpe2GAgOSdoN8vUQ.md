# 想让 AI 帮我看网站数据，Google Cloud 的权限把我绕晕了

这两天打算把独立站的搜索词、流量和询盘数据接给 AI，让 AI 能直接调数据帮我挑词、看哪个页面带来了真实询盘。本以为给个权限就像点个微信扫码一样简单，结果在 Google Cloud 的权限配置上被绕晕了半天，顺带把 Bing 站长平台也接了进来。折腾完搞明白了整个链路，把跑通的配置和踩掉的坑顺手记下来。1. Google 必须开的三个 API进 Google Cloud Console，确认选对项目，在“API 和服务”的库里搜索并启用这三个：Google Search Console API：查关键词、展现量、点击和平均排名。Google Analytics Data API：查访客、浏览量这些流量报表。Google Analytics Admin API：读取 GA4 账号和媒体资源的配置。第三个很容易漏掉。很多 AI 插件在拉数据前会先核对你的 GA4 媒体资源状态，没开 Admin API 会直接卡住报权限不足。💡 提示：Google 的 API 点了启用后，后端通常有一两分钟的生效延迟。刚点完开通立刻让 AI 去连如果报错，先别急着改配置，等两分钟再试。2. OAuth 同意屏幕，必须加上“测试用户”给本地的 AI 工具授权读你的个人数据，需要配一个 OAuth 同意屏幕。在“OAuth 同意屏幕”页面，用户类型选“外部”，应用名称和联系邮箱随便填。这里最容易卡住的一步是“测试用户”：因为自己建的这个应用没有走 Google 的官方审核，默认处于“测试模式”。你必须在页面下方的“测试用户”列表里，手动点击添加用户，把你登录 GA4 和 GSC 的那个个人 Gmail 邮箱填进去。如果漏了这一步，后边 AI 调起浏览器让你登录授权时，Google 就会直接弹一整页红字报错拦截，提示“应用处于测试模式，只能让登记过的测试用户使用”。3. 下载带 secret 的凭据，放项目根目录在“凭据”页面点“创建凭据”：类型选“OAuth 客户端 ID”，应用类型选“桌面应用”。建好后点进详情，把“已授权的重定向 URI”填上本地端口（一般根据 AI 工具的要求填 http://localhost:8080/ 这一类本地地址）。保存后下载凭据，浏览器会下载一个叫 client_secret_xxxx.json 的文件。这个文件直接放在你本地项目的根目录（通常按工具提示重命名为 client_secret.json）。本地的 AI 工具在调起浏览器让你登录时，读取的就是这个文件。注意随手在 .gitignore 里加上这个文件名，别不小心推到 GitHub 上把密钥公开了。4. GSC：必须选域名资源进 Google Search Console，在左上角的资源选择器里确认：选中的必须是域名资源（也就是不带 https:// 的纯域名，比如 mysite.com），不要选带 URL 前缀的那种。域名资源才能把 http、https、带 www 和不带 www 的全部搜索词都抓全。接着拉到左下角点“设置”，进“用户和权限”，点右上角添加用户：填入授权邮箱，权限给“受限”（Restricted）就够了。受限代表只读，AI 只要能读取曝光、点击和词排名就行，不需要给修改站点的权限。5. GA4 加权限，角色选 Viewer 还是 Marketing？进 Google Analytics，点左下角的齿轮进“管理”：第一，加权限去左边的“账号访问权限管理”加。账号级加一次就能覆盖名下所有资源。第二，角色选哪个？如果只想让 AI 每天拉拉报表、看哪些文章有流量，选查看者（Viewer）就够了。如果你是做外贸站或独立站，希望 AI 进一步帮你分析询盘转化、圈出高意向人群，建议选营销者（Marketing）。给到这个权限，AI 才能在后台帮你标记转化事件和受众群体。6. 别漏了核心转化：标记 rfq_submit光看访客数和跳出率，对做业务来说意义有限，更关键的是看有多少人发了询盘。在 GA4 管理页里，找到当前媒体资源下的数据显示（Data display）→ 事件（Events）。找到网站提交询价的事件（比如 rfq_submit），把右边的开关打开，标记为关键事件（Key event）。这一步加上之后，AI 查数据才真正有用。它不再只是告诉你“今天来了多少人”，而是能直接帮你把 GSC 的搜索词和 GA4 联动起来：到底哪个国家来的访客提了 RFQ 询盘、哪几个搜索词带来的询盘转化率最高。7. 别给 AI 喂错 IDAI 连上 GA4 后，需要知道查哪一个网站。GA4 里有两串容易搞混的代码：一串是 G- 开头的衡量 ID，那个是放在网页前端用来收集访问数据的。另一串是纯数字，比如 123456789，叫媒体资源 ID（Property ID）。在 GA4 的“管理” → “媒体资源设置”第一项能看到这串纯数字。AI 调 API 查报表时，需要的是这串数字。填成 G- 开头那串，AI 会提示找不到该资源。8. 为什么还要接 Bing 站长平台？除了 Google，我还把 Bing 站长平台（Bing Webmaster Tools）也接给了 AI。打开 bing.com/webmasters 用微软账号登录（免费）。第一步先添加并验证网站，如果你的域名托管在 Cloudflare，按提示加一条 CNAME 或者 DNS TXT 记录，两分钟就能验证通过。不验证站点用不了后面的工具。Bing 后台左侧的“SEO”里有个“关键词研究”，输入词并选择目标国家，能拿到 Bing 网络的搜索量级区间和相关词扩展。为什么做 B2B 独立站很值得用 Bing？这里有个关键逻辑：Bing 是 ChatGPT Search 的搜索数据源。很多 B2B 的工业品词、长尾型号词，在 Google 关键词规划师里往往显示搜索量很小甚至为 0，根本没法判断。但这些词在 Bing 上如果有搜索轨迹，大概率在 ChatGPT 搜索里也会呈现。在 AI 搜索逐渐普及的时候，拿 Bing 的数据来找长尾词，比单看 Google 更有参考价值。9.
