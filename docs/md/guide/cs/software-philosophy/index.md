## 核心理念

### 道（哲学层）

- 凡是 AI 能做的，就不要人工做
- 目的主导：开发过程中的一切动作围绕"目的"展开
- 上下文是 Vibe Coding 的第一性要素
- 先结构，后代码
- 奥卡姆剃刀：如无必要，勿增代码

### 法（原则层）

- 一句话目标 + 非目标
- 能抄不写，不重复造轮子
- 按职责拆模块
- 接口先行，实现后补
- 文档即上下文

### 术（技巧层）

- 明确写清：能改什么，不能改什么
- Debug 只给：预期 vs 实际 + 最小复现
- 测试可交给 AI，断言人审
- 代码一多就切会话
