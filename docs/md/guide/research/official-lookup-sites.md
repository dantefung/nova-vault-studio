# 一生必用的 21 个官方查询网站：查证别信二手信息

## 为什么值得存

这批网站的共同点：**它们是原始信息的产生方**，不是搬运方。

- 查学历去学信网，不是搜索引擎摘要
- 查企业去公示系统，不是天眼查二次加工
- 查发票去税务局平台，不是财税代理的截图
- 查行情去统计局，不是公众号的统计图

很多纠纷、信息差、乃至求职与尽调里的坑，都源于**信了二手信息**。把这 21 个入口记牢，等于给自己装了一个「一键去伪」的工具栏。

## 使用建议

1. **先判断数据源是不是原始出处。** 判决书看法院、学历看学信网、发票看税务局、行情看交易所或统计局
2. **注意口径。** 房价是挂牌价不是成交价；农产品是批发价不是零售价；统计年鉴常按可比口径调整
3. **查不到 ≠ 不存在。** 裁判文书网公开范围有限；很多公示信息有延迟
4. **优先用政务平台小程序/APP**，比网页版更少验证码、更少拦截

## 访问情况核验（2026-10-26）

21 个域名均已验证 DNS 正常解析、站点真实存在。部分政务站点对程序化请求有反爬策略（返回 412/521），且沙箱网络对若干 `.gov.cn` 域名走代理拦截段，属环境限制而非站点失效；**浏览器正常访问不受影响**。
