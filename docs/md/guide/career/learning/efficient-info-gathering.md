# 【精读】高效的信息搜集与整理术（曹宇/Heidixie）

> **核心结论**：信息搜集与整理是一个**3 阶段闭环**——**搜索（找信息） → 集成（存信息） → 整理（理信息）→ 应用（用信息）→ 回到搜索**。原 2012 年发表于《程序员》杂志，曹宇 10 年实战总结出一套「个人资料库」方法论，**核心是建立主题关键词 + 用对工具 + 持续整理循环**。

> **关键洞察**：
> - **3 阶段闭环**：搜索 → 集成 → 整理，单纯集成而不整理 = 硬盘资料库塞满但找不到
> - **主题关键词**：建立 5-10 个核心关键词（含中英双语），像 RSS 一样让信息主动找你
> - **搜索语言**：换语言 = 换世界（中文「收纳」vs 日文「収納」结果是两套知识体系）
> - **搜索类型**：网页搜不到时改**文件搜索**（inurl:pdf / filetype:all）
> - **整理核心**：用 evernote 这类工具**自动集成** + **文件夹序号命名法**保持顺序稳定

## 一、信息搜集及整理循环图

```
        ┌─────────────────────────┐
        │       应用（用信息）       │ ← 调用
        └─────────────┬───────────┘
                      ↑
        ┌─────────────┴───────────┐
        │      整理（理信息）       │ ← 标签、归类、定期清理
        └─────────────┬───────────┘
                      ↑
        ┌─────────────┴───────────┐
        │      集成（存信息）       │ ← evernote 等工具
        └─────────────┬───────────┘
                      ↑
        ┌─────────────┴───────────┐
        │      搜索（找信息）       │ ← 搜索引擎 + 主题关键词
        └─────────────────────────┘
        ←─── 返回应用 ───→
```

**关键洞见**：单纯集成而不整理 = 硬盘塞满但找不到。这就是为什么需要定期「整理」。

## 二、高效搜索术

### 2.1 建立你的主题关键词

**核心**：建立 5-10 个核心关键词（含中英双语）。

**3 个好处**：
1. **建立方向提醒**——时刻明白对自己真正有价值的是什么
2. **主动获取信息**——用关键词订阅，让信息**主动找你**
3. **减少无聊时间**——找不着事情干时，搜一下关键词

> 主题关键词要**定期评估并更新**——比如曹宇"近一年对商务智能很感兴趣，但去年此刻几乎不了解"。

### 2.2 用好你的搜索引擎

**TIPS 01：找准关键词，事半功倍**

例子：要找两类「图片」——「可视化思考」类 vs 「信息图」类。

- 中文「插图/图表/手绘图」搜索失败
- 改英文「visual thinking」/「infographic」成功
- **从头脑风暴第一个关键词开始，根据搜索结果的线索**追踪 → 直至拿到结果

**TIPS 02：更换语言，别有洞天**

中文「收纳」搜出来是社区网站零碎技巧；**日语「収納」搜出来是日本专业网站**（如 http://www.iris-interior.com/mainichi/ 每日收纳教程）。

> 每多一种语言 = 多打开一扇窗。

**TIPS 03：更换搜索类型，殊途同归**

网页搜不到时改**文件搜索**：
- Google：`inurl:pdf 关键词`
- 百度：`filetype:all 关键词` 或 `filetype:PDF 关键词`

文件 = 系统化组织 = 比网页更高的信息密度。

### 2.3 图片搜索

> 巧用「图片搜索」+ 通过图片链接到有价值网站。

## 三、信息集成：evernote 工作流

### 3.1 自动化集成工具

| 工具 | 用途 |
|------|------|
| evernote | 跨设备同步、云端存储、全文检索、OCR 图片 |
| outlook 插件 | 邮件中直接保存到 evernote |
| 浏览器剪藏 | 一键存网页 |
| 花瓣网 | 视觉图片管理 |
| 知乎收藏 | UGC 知识片段 |

> 核心：**集成应自动化**——手动复制粘贴的低效不可持续。

### 3.2 文件全文检索

evernote 的「**全文检索**」是真全文检索（OCR 后图片内的字也能搜到）。

## 四、信息整理术

### 4.1 文件夹 vs 标签（tag）

**evernote 用文件夹 + tag 双维度**：
- **文件夹**：分类（一条文档只能放一个文件夹）
- **tag**：多维度的内容属性（一条文档可多个 tag）

### 4.2 复杂内容协作的文件夹体系

**作者的项目文件夹示例**：

```
04 搜索术迭代/
   ├── 2012-10-15 搜索调研/
   ├── 2012-11-20 用户访谈记录/
   └── 2013-01-10 复盘分析/
```

**关键点**：**序号命名法**——保持文件夹的排序稳定（不是字母序或随机）。

### 4.3 Heidi 的文件夹体系

> 「简单的事情不要搞复杂，复杂的事情不要搞简单」

**文件夹不宜太多** —— 不需要为每条记录单独建文件夹，过度分类成本 > 收益。

## 五、应用：让信息真的为你工作

| 应用场景 | 技巧 |
|----------|------|
| 写报告 | 在 evernote 直接搜关键词调出旧记录 |
| 会议准备 | 提前检索项目相关历史记录 |
| 跨团队协作 | 把记录里有用的部分抄到邮件或共享 |
| 个人思考 | 写博客时直接调出素材 |
