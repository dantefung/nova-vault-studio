## 一、核心哲学与底层逻辑

### 1. 为什么是 Grok？
- **最前哨的信号源在 X (Twitter)**：海外科技圈、开源社区、AI 模型开发者（xAI、OpenAI、Anthropic、Google、开源独立开发者）的第一手爆料、新产品首发全部在 X 平台，比传统搜索引擎收录早 **24~72 小时**。
- **独占级别实时数据访问**：Grok 深度直连 X 平台底层推文数据，具备全网最强的推特实时检索与热点脉冲识别能力。
- **零基础设施负担**：利用 Grok 网页端的定时任务（Task），站长不需要搭建爬虫、维护代理服务器或购买昂贵的社交媒体 API，开箱即用。

### 2. 什么是“新词”？
- **时间窗口**：过去 12 个月（甚至过去 7~30 天）内搜索量从 0 突发激增的新概念、新功能、新项目。
- **竞争真空**：大厂与高 DR 老站尚未反应过来，无专门独立站承接，Google 首页前排全为推特原帖或 GitHub 仓库。
- **战略价值**：新词意味着**上线即排名、零外链拿流量**。

## 二、Grok 定时监测任务配置 SOP（四步走）

```text
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│ 1. 登录与入口定位 │  ──>  │ 2. 创建定时任务  │  ──>  │ 3. 填入专项Prompt│  ──>  │ 4. 测试与自动交付│
│ grok.com 账号设置 │       │ 选择 Tasks 菜单 │       │ 明确过滤排除规则│       │ 每日早晨静待奏折 │
└─────────────────┘       └─────────────────┘       └─────────────────┘       └─────────────────┘
```

1. **入口定位**：
   - 打开并登录 [grok.com](https://grok.com)（或 X 网页端的 Grok 界面）。
   - 在左下角个人信息/菜单栏中找到 **Task（任务 / 定时任务）**。
2. **任务初始化**：
   - 点击 **Create Task（新建任务）**。
   - **执行周期（Frequency）**：选择 **Every day（每天一次）**。
   - **触发时间（Trigger Time）**：推荐设为 **08:00 (本地时间)**，作为早晨开工的“热点早报”。
3. **注入结构化指令**：
   - 填入经过打磨的高效 Prompt（参见第三章），严格限定排除项与输出格式。
4. **测试与落盘**：
   - 点击右侧 **Test Run（测试运行）** 验证一次，检查输出质量。
   - 确认输出符合预期后保存任务，等待 Grok 每天准时推送。

## 三、生产级提示词库（Prompt Templates）

### 模板 A：通用 AI / 科技出海新词雷达（推荐）
```text
你是一个资深的海外独立站增长专家与 SEO 关键词挖掘工程师。
请检索过去 24 小时内 X (Twitter) 平台上全球讨论热度、转发量、互动量最高的新兴事件与技术热点：

【硬性过滤规则】：
1. 绝对排除已有海量知名度的存量通用老词（如 ChatGPT, Claude, Midjourney, Stable Diffusion, DeepSeek, Cursor 等常见概念）。
2. 只聚焦过去 7 天内新发布的模型名称、开源工具、黑客松爆款 Demo、新协议、突发功能词或开发者自制小工具。

【输出要求】：
请提炼 5-8 个最具独立站工具化或内容攻略化潜力的新词，每个词包含以下结构：
- [新词名称]：标准英文原词/名称（用于评估域名与关键词）
- [核心痛点/背景]：一句话说明它是什么、解决了什么问题
- [热度佐证]：主要提及的推特博主或原始热帖概要
- [产品形态建议]：适合做成纯前端单页小工具、在线转换器、API 套壳还是使用教程
```

### 模板 B：游戏赛道 / Roblox & Steam 爆发新词雷达
```text
请检索过去 24 小时内 X (Twitter) 上欧美游戏圈、Roblox 社区、Steam 新品节讨论最火热的新游戏概念与流行梗词：

【硬性过滤规则】：
排除 GTA、Minecraft、Fortnite 等超大型常青游戏；专盯刚进入公测、发布新版本或主播正在带火的黑马小游戏。

【输出要求】：
提供 5 个突增游戏词汇：
- [游戏/词根名称]
- [玩法类型]（如 Tower Defense, Clicker, Roguelike, Obby）
- [用户搜索意图推测]（如 Codes, Tier List, Script, Unblocked, Wiki）
```

## 四、从“奏折”到“上线”的四步验证闭环

Grok 给出的候选词只完成了**信号捕捉**，进入开发前必须经过以下四步严苛验证：

```text
Grok 奏折信号 ──> Google Trends 趋势验证 ──> Google SERP 竞争透视 ──> 纯端侧秒级上站
```

1. **Google Trends 陡峭度检验**：
   - 将词汇放入 Google Trends（地区选择 Worldwide 或 United States，时间选 Past 7 days / Past 30 days）。
   - **合格特征**：前期几乎为 0，近期呈 45°~90° 陡峭上升。
2. **Google SERP（搜索结果页）竞争度透视**：
   - 在无痕模式下 Google 搜索目标词。
   - **合格特征**：前 3 名全为推特原推、GitHub 首页、YouTube 视频或 Reddit 帖子，**没有任何一个垂直域名独立站**。
3. **域名精准匹配 (EMD) 或二级目录决策**：
   - 若词汇潜力巨大，优先查询 `[keyword].org` / `[keyword].io` / `[keyword].cc` 等精准匹配域名。
   - 若只是单一轻量功能，直接挂在已有权威主域的子域名或二级目录下。
4. **快速上线抢占收录**：
   - **拒绝过度开发**：采用 Astro / VitePress / 纯静态 HTML，顶部一句话说明，核心功能（端侧/iframe），底部 FAQ 与按键说明。
   - **即时提交索引**：上线后立刻在 Google Search Console 手动请求编入索引，并借助 IndexNow 推送 Bing。

## 五、避坑准则与好品味原则

1. **不要盲信 AI 臆测，以搜索数据为准绳**：
   - Grok 擅长捕获“推特正在讨论什么”，但推特热点不等于“有人去 Google 搜索”。必须用 Google Trends 或 Google Suggest 交叉印证。
2. **严防“虚假新词”与“侵权词”**：
   - 过滤带有知名大厂商标注册风险的品牌词，聚焦于工具类型词（如 `xxx prompt generator`、`xxx online viewer`）。
3. **天下武功，唯快不破**：
   - 新词的黄金收割期通常只有 **14~45 天**。如果一个新词你需要打磨两周才上线，这个词就已经变成红海老词了。
4. **保持简洁，消除特殊分支**：
   - 找词不是目的，跑通“发现新词 → 模板上线 → 挂载变现”的端到端数据闭环才是真正的核心壁垒。
