# 分享一个无限外链的方法：Google 语法挖掘博客/资源页/客座投稿

> **作者**：Columbus ([@jinlv11](https://x.com/jinlv11))  
> **原文链接**：https://x.com/jinlv11/status/2115790132230111394  
> **发布时间**：2026-10-29 12:57:31 UTC  

---

## 核心推文内容

分享一个无限外链的方法，打开 Google 直接搜索：

### 1. 挖博客评论外链
```text
inurl:blog + "leave a reply" + [关键词]
```
> **示例**：`inurl:blog + "leave a reply" + ai image generator`  
> **逻辑**：搜索到的外链页面带有评论框，必定是可以发表评论并带网站链接的。

### 2. 挖资源推荐页
```text
[关键词] + inurl:resources
[关键词] + inurl:links "submit"
```
> **示例**：`ai tools + inurl:resources` 或 `ai tools + inurl:links "submit"`  
> **逻辑**：这种页面天生就是为了收录工具而建的，提供 Submit 入口。

### 3. 挖客座投稿页（Guest Post）
```text
[关键词] + "write for us"
[关键词] + "guest post guidelines"
```
> **示例**：`ai + "write for us"` 或 `ai + "guest post guidelines"`  
> **逻辑**：直接定位接受外部作者投稿的博客。

## 补充说明与讨论

- **主题替换**：指令中的 `ai image generator` / `ai tools` 均可替换为你自己网站相关的核心业务词汇。
- **自动化联动**：圈友评论提及可直接将此类搜索指令配置给 **Grok bot** 进行每日自动化抓取与外链清单生成。
