# 0 基础学做网站与 SEO 复盘：从 0 用户到单站爆发经历


![封面图](https://pbs.twimg.com/media/HWBeRxIWIAASbPw.jpg)

0 基础入群一个月，我在哥飞社群国庆比赛拿了征文第一，这个社群到底值不值得加？

我觉得我在这个问题上有一定的发言权。

关于新手做站、学 SEO 以及真实经历，很多小伙伴都在摸索寻找方向。
这篇把我的真实做站感受、数据爆发过程和踩坑经验完整讲清楚。
方法与经验摆在前面，大家可以根据自己的情况客观参考。

---

我是谁

我没有任何编程基础。创业6年失败结束，负债几十万，后来变卖资产，从0开始。今年 5 月才开始学建站，做的第一个产品花了 3 个月，上线后 0 用户。在结束创业一年的期间，我的收入为0。

在自己研究做站期间，7 月我就听说了哥飞社群，当时还碰上一次优惠，但我很纠结：2000 块让我很肉疼，我不停劝自己，有必要花这个钱去知识付费吗？AI 现在这么强，跟着 AI 做不就完了吗？

真正的导火索，是 8 月产品上线的那一周。上线之后，0 用户。我学 X 上的大 V，把产品公开放出来，到处介绍功能，折腾来折腾去，还是 0 用户。邮箱里倒是多了不少推销邮件：付钱给他们，帮我解决冷启动。 

这不扯淡吗？我真的非常难受，开始反思自己的问题。这时又想起哥飞社群，结果之前的优惠已经过期了。那一刻我觉得自己特别狼狈，以前创业时有多风光，现在就有多惨。

后来又碰到一个折扣，虽然还是比之前贵，但我不想再纠结了。咬咬牙，付了钱。

于是我9月加入了“哥飞的朋友们”，开始正经学 SEO。

后来的事是这样的：

1.九月上了3个站，纯练手，没啥正反馈

2.十月突然开始爆发，第4个站收入破了3000刀

3.后面又做了8个站，每个站都开单了，最差的10刀，中位数400刀

期间我把第4个站这段经历写成复盘，参加社群的国庆征文悬赏，拿了第一名。

**它不适合谁**

说实话，这个社群不适合所有人：

AI 能帮你写代码，但它不会告诉你今天该做哪个词、哪个词已经有人在做、别人踩过哪些坑。社群给我的，是 AI 给不了的那部分：新鲜的数据、真实的经验，和一起往前走的人。

· 想找一个现成的项目、照做就能躺赚的，不适合。这里教的是方法，站要你自己上。

· 不愿意花时间动手的，不适合。资料再多，不上站就没有结果。

说白了，赚钱这个东西，是自己的课题，和他人没有任何关系。

你付费拿的不是赚钱保证，你拿的东西本质上是你的时间和效率。
