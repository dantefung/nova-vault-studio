# GStack Skills Installation Summary

**Date:** 2026-04-08
**Source:** [https://github.com/garrytan/gstack](https://github.com/garrytan/gstack)
**Scope:** User (~/.gemini/skills)

## Installation Overview
The GStack skill suite was successfully installed. This suite provides a comprehensive set of specialized tools for browser-based QA, design reviews, engineering strategy, and project workflow management.

## Installed Skills & Capabilities

### 1. Browser & QA Automation
*   **gstack / browse:** Fast headless browser for QA testing and site dogfooding.
*   **qa / qa-only:** Systematic web application testing with optional automatic bug fixing.
*   **canary:** Post-deploy monitoring for console errors and visual regressions.
*   **benchmark:** Performance regression detection and Core Web Vitals tracking.
*   **open-gstack-browser / connect-chrome:** Launches an AI-controlled Chromium browser with a live activity sidebar.
*   **setup-browser-cookies:** Import cookies from your real browser for authenticated testing.

### 2. Design & Frontend Polish
*   **design-review:** Visual QA for identifying and fixing spacing, hierarchy, and consistency issues.
*   **design-html:** Generates production-quality, dependency-free HTML/CSS.
*   **design-shotgun:** Explores multiple AI design variants for visual brainstorming.
*   **design-consultation:** Researches and proposes complete design systems (DESIGN.md).

### 3. Engineering Strategy & Review
*   **plan-ceo-review:** Founder-mode strategy review (scope expansion/reduction).
*   **plan-eng-review:** Architecture, data flow, and test coverage review.
*   **plan-design-review:** Interactive design critique for implementation plans.
*   **plan-devex-review:** Developer experience audit for APIs and SDKs.
*   **autoplan:** Automated execution of the full review pipeline.

### 4. Workflow & Deployment
*   **ship:** Complete ship workflow (merge, test, version bump, PR creation).
*   **land-and-deploy:** Handles merging and verifying production deployments.
*   **setup-deploy:** Configures deployment settings for various platforms (Vercel, Fly.io, etc.).
*   **document-release:** Automatically updates project documentation (README, CHANGELOG) post-ship.

### 5. Debugging & Maintenance
*   **investigate:** Systematic root cause analysis and debugging.
*   **health:** Composite code quality dashboard (linting, testing, type checking).
*   **learn:** Manages persistent project learnings across sessions.
*   **gstack-upgrade:** Upgrades the GStack toolset to the latest version.

### 6. Safety & Security
*   **guard / careful:** Destructive command warnings and safety guardrails.
*   **freeze / unfreeze:** Scopes file edits to specific directories to prevent accidental changes.
*   **cso:** Chief Security Officer mode for infrastructure and dependency audits.

### 7. Utilities
*   **checkpoint:** Save and resume working state across sessions.
*   **pair-agent:** Connect remote AI agents to your browser session.
*   **office-hours:** YC-style brainstorming and product discovery forcing questions.
*   **codex:** Adversarial code review and second-opinion consultation.
*   **retro:** Weekly engineering retrospective and contribution tracking.
