# 耗时 7 天，我们开源了腾讯 WorkBuddy 实战蓝皮书（建议收藏）

大家好，我是满血归来的苍何。

最近 OpenAI 把 Codex 和 ChatGPT 合并了，Codex 或将是 OpenAI 通往 AGI 之路中的一个过渡产品。

![](images/canghe-workbuddy-bluebook/001.png)

Agent Coding 需求还是太小了，真正的大需求是办公类 Work，这一点，腾讯也许想的比 OpenAI 更清晰，从 WorkBuddy 的名字也能看出。

也越来越多的人使用 WorkBuddy，但现在确实还没有比较详细的实战教程，当然了，官方文档除外，但也很少有人会直接对着官网看教程吧。

前段时间，我和刘聪、甲木、袋鼠帝、摸鱼小李一起在北京参加活动，一起聊到了这个事，就打算几个人一起联合搞一个 WorkBuddy 实战蓝皮书。

经过 7 天的爆肝，今天，我们正式把 WorkBuddy 实战蓝皮书开源了。

![](images/canghe-workbuddy-bluebook/002.png)

我们还搞了个域名，在 Cloudflare 上部署了网站，你现在也能在全球任何地方打开我们的网站。

![](images/canghe-workbuddy-bluebook/003.png)

GitHub 开源地址：

> github.com/AlephAITech/WorkBuddyGuide

在线阅读：

> workbuddy.homes

这几天，我们几个为了搞这个，像是个被榨干的小毛驴，连着通了好几晚的电话，看似简单，但要做的细节还是挺多的。

![](images/canghe-workbuddy-bluebook/004.png)

> 哈哈哈，也弱弱的求一波 star，就是对我们最大的支持啦。

之前，我做了 CodexGuide，在 GitHub 上已经获得了 2.6 k 的 star。

![](images/canghe-workbuddy-bluebook/005.png)

现在也已经 5 个满人用户群了，其中也有不少人希望出个 WorkBuddy 的教程，这不就来了吗？

整个实战蓝皮书一共分为 4 个篇幅，分为：使用手册、实战案例、进阶系统、岗位与行业。

![](images/canghe-workbuddy-bluebook/006.png)

平心而论，我们投入精力最大的一部分是实战案例，这个也是我们认为最有价值的部分。

其中不少的案例是我们几个人自己的一些实践案例，比如用 WorkBuddy 来做知识管理就是我的一些实践。

![](images/canghe-workbuddy-bluebook/007.png)

在 WorkBuddy 中苍何一共入职了 2 个专家团，分别是 AI 视频创作团队、视频解析专家团。

![](images/canghe-workbuddy-bluebook/008.png)

其中 AI 视频创作团队也已经 2.79 万次使用了。

![](images/canghe-workbuddy-bluebook/009.png)

那在 WorkBuddy 实战蓝皮书中也已经把这个专家团如何使用的案例加进来了，大家也能更方便的使用了。

![](images/canghe-workbuddy-bluebook/010.png)

前段时间，苍何的 GEO 专家也上架了 WorkBuddy，现在也已经 1.65 万次使用了。

![](images/canghe-workbuddy-bluebook/011.png)

现在 WorkBuddy 实战蓝皮书中，你也能看到这个 GEO 专家如何使用，而且网站有个好处，就是有新的更新能第一时间放上更新。

![](images/canghe-workbuddy-bluebook/012.png)

前些天，我们武汉 AI 圈和腾讯云联合举办了 WorkBuddy Demo Day，我发现不少人已经在用 WorkBuddy 偷偷帮助他们办公提效了，比如有律师用 WorkBuddy 进行诉讼案件的整理。

![](images/canghe-workbuddy-bluebook/013.png)

那对不同岗位，我们也做了 WorkBuddy 岗位路线图，方便了解不同岗位如何把 WorkBuddy 用深。

![](images/canghe-workbuddy-bluebook/014.png)

> PS：当然了，如果你有更多的行业落地经验，也欢迎给我们提 PR，补充优秀案例库。

在附录部分，我们还补充了一些常用的指令模板，这部分主要照顾小白用户，当你下载 WorkBuddy，不知道咋用的时候，不妨看下这节，主打一个有手就行。

![](images/canghe-workbuddy-bluebook/015.png)

现在 WorkBuddy 内的专家和技能越来越多了，滑半天也滑不完。

![](images/canghe-workbuddy-bluebook/016.png)

有时候为了对应的场景找对应技能，也不是很方便，所以，最后，我们在附录上加了场景速查表，方便对不同场景使用不同能力进行速查。

![](images/canghe-workbuddy-bluebook/017.png)

说个邪修办法，你甚至可以直接把我们的网站或者 GitHub 丢给 WorkBuddy，让它记住这份速查表，在合适的时机给你推荐合适的技能。

最后，如果你有不错的 WorkBuddy 案例也欢迎给我们提 PR，一起把这个开源项目维护好。

最后的最后，一定要记得 star 哈哈哈。
