# vibecoding核心避坑指南

## 1. 从开设项目开始，就做好git管理

## 2. 项目开发文档，架构文档，路线图，开发规范

全部必须在一开始定好。否则后面窗口根本就是 freestyle。

## 3. vibecoding做项目最重要的不是UI，不是用户体验，而是架构

你每个功能之间的关系，整体的架构是否能处于一种**低耦合，职责层级划分是否明显**。

这才能够后期出了问题知道找哪个模块的原因，否则一出问题，永远找不到到底是谁起作用。因为所有模块都交织在一起。

## 4. 不要一直埋头做，当发现有问题时，一定要马上跳出来

让窗口告诉你你想做的产品行业**最佳实践**是怎么做的。否则容易陷入到，自己和AI定好的方向里自嗨，逐渐产品走偏。

## 核心总结

> 最重要的还是架构思维。一个有架构的系统应该是：**每一层都有边界，每一个模块都有职责，每一次调用都是"可预期的"**。

---

选边，比努力重要一万倍。有架构的系统才能让AI真正成为你的效率杠杆，而不是失控的根源。
