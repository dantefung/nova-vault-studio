# 安卓开源 Agent 深度对比：Mika 与 DSH Go 的架构选型与实践

> 深入剖析两款高星安卓开源 Agent 项目 —— Mika 与 DSH Go 的实现原理、虚拟屏幕方案及在真实移动端场景中的定位取舍。

---

## 项目概览

| 项目 | GitHub Stars | 定位重心 | 核心亮点 |
| :--- | :--- | :--- | :--- |
| **Mika** | ~2.9K | 日常手机自动化与数字代理 | 虚拟屏幕后台运行、无感免 Root、批量操作与经验复用 |
| **DSH Go** | ~3.7K | 移动端本地编程与开发助手 | 内嵌 PRoot Ubuntu/Node 环境、前后端环境直连、严谨风控校验 |

---

## 核心设计与特性对比

### 1. Mika：为手机日常自动化而生

- **独立后台虚拟屏**：给 Agent 单独开辟一块虚拟屏幕。在后台执行整理微信消息、刷小红书总结、BOSS 直聘招聘沟通等任务，前台用户正常使用手机，互不干扰；不需要 Root，也不需要时刻连接电脑。
- **批量操作降低开销**：单次支持批量下发最多 20 个动作，大幅减少模型来回推理与网络 round-trip 消耗。
- **操作经验记忆**：成功执行过的任务模式会自动持久化为操作经验，下次处理同类业务流程直接复用。
- **生态扩展能力**：支持定时任务、条件触发与 MCP 协议集成，甚至支持电脑端 Codex 跨端调度控制手机。
- **确认策略**：放宽普通只读与交互操作以保证流畅度，在涉及支付资金等高风险环节才弹窗要求人工确认。

### 2. DSH Go：将完整 Coding Agent 搬上移动设备

- **移动端 Linux 原生环境**：在 Android 系统中通过 PRoot 完整运行 Ubuntu、Node.js 与 DeepSeek Harness，直接把本地开发工作台部署在手机端。
- **会话无缝延续**：既可在手机本地执行终端命令、编辑代码，也可通过 SSH 或 DSH Remote 直连电脑继续推进未完成的开发分支。
- **双重控制模式**：支持直接控制 Android 应用，Android 14+ 下通过 Shizuku 或 ADB 实现后台虚拟屏幕操作。
- **防漂移与谨慎风控**：在执行界面点击前强制二次比对目标元素状态，避免界面刷新导致坐标漂移；对发消息、删除数据、转账等敏感行为默认严格阻断并请求用户显式确认。

---

## 选型与总结思考

- **日常手机自动化首选 Mika**：设计重心围绕“让 AI 代替人类操作手机日常交互”构建，轻量流畅、后台静默运行体验极佳。
- **移动端持续开发选 DSH Go**：适合工程师随时拿出手机无缝接力电脑上的 Coding 任务、查日志或修复急诊 Issue。
- **行业趋势**：安卓端智能体已经从早期的“单纯模拟点击录屏”逐步演进到解决**后台隔离、权限治理、任务状态恢复与风控熔断**等工业级现实挑战。
