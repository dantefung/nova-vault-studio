# 负债是什么？

债务的本质是信任关系，而非具体的"东西"。

## 债务三角循环

三个人 A、B、C：
- A 欠 B 100元
- B 欠 C 100元
- C 欠 A 100元

银行给 A 100元 → A 还给 B → B 给 C → C 给 A → A 还银行

100元转一圈，300元债务同时消失。**没有任何财富被创造或消灭，只是流动了一圈。**

## 债务的本质

债务没有具体形状——摸不到、看不见、闻不到。它不是"东西"，而是一种**关系**：

> "我欠你500，是我承诺未来要还你500块，而你相信未来能收到这500块。"

债务的背后是**信任**。能不能兑现，完全取决于借款人愿不愿意还。

## 资产负债表

借500万时，债主会问：有房吗？有车吗？有固定收入吗？负债多少？

借款人甩出资产负债表：

- **左栏**：拥有的一切 = 1000万
- **右栏**：净资产 = 820万

信任建立后，债务才能成立。
