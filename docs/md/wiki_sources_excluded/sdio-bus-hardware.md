# 小白也能懂——SDIO总线：硬件原理篇

> SDIO 是 SD 卡接口的超级进化版，不只能存数据，还能接外设。手机里的 Wi-Fi 模组、SD 存储卡、GPS 芯片，有相当一部分都在用 SDIO 和主控芯片"对话"。

<!-- more -->

## 一、SDIO 是什么？能接哪些设备？

SDIO，全称 Secure Digital Input Output（安全数字输入输出），是在 SD 卡标准基础上扩展出来的接口协议，除了能插存储卡，还能连接各种外设模组。

常见的 SDIO 设备：

| 设备类型 | 常见芯片/模组 | 用途说明 |
|---------|-------------|---------|
| Wi-Fi 模组 | RTL8189、AP6212、ESP8089 | 无线网络连接，最常见的 SDIO 应用 |
| 蓝牙模组 | AP6255、BCM4345 | 蓝牙通信，常与 Wi-Fi 集成在同一模组 |
| SD 存储卡 | SD/SDHC/SDXC 卡 | 最原始的应用，文件系统存储 |
| GPS 模块 | 部分 u-blox 系列 | 位置定位数据传输 |
| NFC 模块 | 部分 NXP 系列 | 近场通信 |
| 相机模块 | EyeFi 等 WiFi SD 卡 | 无线图像传输 |

> ⚠️ 并不是所有 Wi-Fi/蓝牙模组都用 SDIO，部分用 USB 或 UART，选型时要确认接口类型。

## 二、SD 家族大扫盲：SD / SDHC / SDXC / SDIO 怎么区分？

| 名称 | 全称 | 最大容量 | 文件系统 | 最高速率 |
|------|------|---------|---------|---------|
| SD | Secure Digital | 2 GB | FAT12/16 | 25 MB/s |
| SDHC | Secure Digital High Capacity | 32 GB | FAT32 | 104 MB/s |
| SDXC | Secure Digital eXtended Capacity | 2 TB | exFAT | 312 MB/s |
| SDIO | Secure Digital Input Output | — | —（非存储） | 视设备而定 |

SDIO 本身不是存储卡规范，而是**外设扩展接口规范**。它复用了 SD 的物理接口，但用途完全不同。

**速度等级**（影响能否流畅录 4K 视频）：

| 速度等级 | 标识 | 最低写入速率 | 典型应用场景 |
|---------|------|------------|------------|
| Class 2 | C2 | 2 MB/s | 普通拍照 |
| Class 4 | C4 | 4 MB/s | 标清视频录制 |
| Class 10 | C10 | 10 MB/s | 全高清视频、一般嵌入式应用 |
| UHS-I U1 | U1 | 10 MB/s | 4K 视频入门 |
| UHS-I U3 | U3 | 30 MB/s | 4K 视频、连拍 |
| V90 | V90 | 90 MB/s | 8K 视频专业级 |

> 嵌入式项目选 SD 卡，Class 10 / UHS-I U1 以上基本够用，稳定性比速度更重要。

## 三、引脚全解析

SDIO 接口一共有 9 根信号线：

| 引脚名 | 引脚编号 | 方向 | 功能说明 |
|-------|---------|------|---------|
| VDD | Pin 4 | 电源 | 供电，通常 3.3V（部分支持 1.8V） |
| VSS | Pin 3/6 | 地 | 信号地 |
| CLK | Pin 5 | 主→从 | 时钟信号，由 Host 提供，所有数据传输同步于此 |
| CMD | Pin 2 | 双向 | 命令通道：主机发命令、卡回响应 |
| DAT0 | Pin 7 | 双向 | 数据线 0，1-bit 模式唯一数据线 |
| DAT1 | Pin 8 | 双向 | 数据线 1（4-bit 模式）；SDIO 中断线（1-bit 模式） |
| DAT2 | Pin 9 | 双向 | 数据线 2（4-bit 模式使用） |
| DAT3 | Pin 1 | 双向 | 数据线 3（4-bit 模式）；卡检测 |

![SDIO 引脚连接示意图](images/sdio-bus-hardware/001.png)

> CLK 始终由 Host 主动产生，Card 永远不会自己产生时钟，这是主从架构的核心特征。
> DAT1 在 SDIO 模式下兼作中断线（SDIO IRQ），当设备有数据上报时，会通过 DAT1 通知主机。

## 四、1-bit vs 4-bit 模式

| 模式 | 使用数据线 | 典型时钟频率 | 理论峰值速率 | 适用场景 |
|------|-----------|------------|------------|---------|
| 1-bit 模式 | DAT0 × 1 | 25 MHz | ~3.1 MB/s | 资源受限、简单外设、调试 |
| 4-bit 模式 | DAT0~DAT3 × 4 | 50 MHz | ~25 MB/s | Wi-Fi 模组、高速 SD 卡 |
| 4-bit SDR104 | DAT0~DAT3 × 4 | 208 MHz | ~104 MB/s | UHS-I 高速应用 |

4-bit 模式相比 1-bit，速率提升约 8 倍（4 条数据线 × 时钟频率翻倍），是绝大多数嵌入式产品的首选。

> 初始化阶段必须用 1-bit 模式，等卡识别完成后再协商切换到 4-bit。

## 五、命令帧格式与响应类型

SDIO 的"对话"靠命令帧完成，每一帧共 48 bit：

![命令帧格式](images/sdio-bus-hardware/002.png)

每条命令发出后，Card 会回一个响应，常见响应类型：

| 响应类型 | 长度 | 典型用途 | 包含内容 |
|---------|------|---------|---------|
| R1 | 48 bit | 大多数命令的标准响应 | 卡状态寄存器 |
| R2 | 136 bit | CMD2（读CID）、CMD9（读CSD） | 128bit 完整寄存器内容 |
| R3 | 48 bit | ACMD41（OCR 查询） | OCR 寄存器（操作条件） |
| R4 | 48 bit | CMD5（SDIO 专用） | I/O OCR + Function 数量 |
| R5 | 48 bit | CMD52/CMD53（SDIO 读写） | SDIO 状态 + 读取数据 |
| R6 | 48 bit | CMD3（获取 RCA） | 相对卡地址（RCA） |
| R7 | 48 bit | CMD8（电压检测） | 电压范围确认 |

> 对于 SDIO 设备开发者，最常打交道的是 R1、R4、R5，覆盖了 90% 以上的日常操作。

## 六、上电初始化时序

上电后，Host 要经过一系列命令"握手"才能让设备进入数据传输状态：

![SDIO 初始化流程](images/sdio-bus-hardware/003.png)

1. **CMD0** — GO_IDLE_STATE，复位卡到空闲状态
2. **CMD8** — SEND_IF_COND，检测电压范围
3. **CMD5** — SDIO 独有命令，查询 I/O 功能（SD 存储卡没有此步，是区分 SDIO 与纯 SD 卡的关键）
4. **CMD2** — ALL_SEND_CID，获取卡识别号
5. **CMD3** — SET_RELATIVE_ADDR，分配相对地址（RCA）
6. **CMD7** — SELECT_CARD，选中卡进入传输模式
7. 配置 4-bit 模式（CMD52 写入总线宽度寄存器）
8. 激活功能（CMD52 使能 Function）

> 初始化期间时钟频率不能太高，通常控制在 **400 kHz** 以内，等初始化完成后再提速到 25 MHz / 50 MHz。

## 七、硬件设计关键点与踩坑合集

### 电源与电压
- 标准 SDIO 工作电压 3.3V，部分高速设备（UHS-I）支持 1.8V 信号电平
- VDD 上加 100nF + 10μF 滤波电容，靠近设备引脚放置
- 若主控 IO 电平为 1.8V 但设备需要 3.3V，必须加电平转换芯片

### 上拉电阻
| 信号线 | 是否需要上拉 | 推荐阻值 | 说明 |
|-------|------------|---------|------|
| CLK | ❌ 不需要 | — | 时钟线，推挽驱动 |
| CMD | ✅ 需要 | 10kΩ ~ 47kΩ | 空闲时保持高电平 |
| DAT0~DAT3 | ✅ 需要 | 10kΩ ~ 47kΩ | DAT1 作为 SDIO IRQ 必须上拉 |

### 走线与信号完整性
- CLK 走线尽量短，避免过孔，保持 50Ω 阻抗连续
- DAT0~DAT3 和 CMD 要与 CLK 等长走线，差异控制在 ±5mm 以内
- 远离高频干扰源（开关电源、晶振等），必要时加屏蔽地铺铜
- SDIO 卡座加 ESD 保护器件（如 PRTR5V0U2X），防止热插拔损坏芯片

### 常见踩坑

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 设备识别失败/CMD5 无响应 | 时钟频率过高或没有上拉电阻 | 初始化时钟降到 400kHz，检查上拉 |
| CRC 错误频繁 | 走线过长/阻抗不匹配/接触不良 | 检查 PCB 走线，加端接电阻 |
| 速率低，跑不到 4-bit 速度 | 驱动没切换总线宽度或硬件只接 DAT0 | 软件 CMD52 配置，检查 DAT1~3 |
| SDIO 中断不触发 | DAT1 没上拉或驱动未注册中断 | 检查 DAT1 上拉，sdio_claim_irq 注册 |
| 热插拔后设备不识别 | 无卡检测电路或无 ESD 保护 | 加 CD 引脚检测，添加 ESD 器件 |

> 硬件调试优先用逻辑分析仪抓 CLK / CMD / DAT0 三根线，90% 的问题都能找到答案。

## 总结

- SDIO 是 SD 接口的扩展版，能接 Wi-Fi、蓝牙、GPS 等多种外设
- SD 家族：SD ≤ 2GB → SDHC ≤ 32GB → SDXC ≤ 2TB，SDIO 是功能扩展接口
- 核心引脚：CLK（时钟）+ CMD（命令）+ DAT0~DAT3（数据）+ 电源地
- 4-bit 模式速率是 1-bit 的约 8 倍，是正式产品的标配
- 命令帧 48bit：起始 + 方向 + CMD 索引 + 参数 + CRC + 结束
- 初始化流程：CMD0 → CMD8 → CMD5 → CMD2 → CMD3 → CMD7 → 配置 4-bit → 激活功能
- 硬件重点：上拉电阻 + 等长走线 + ESD 保护

> 记忆口诀：CLK 打节拍，CMD 传命令，DAT 搬数据，上拉保稳定，初始化靠 CMD0 起步。
