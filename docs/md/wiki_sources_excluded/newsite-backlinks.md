# 新站外链做不起来，可能因为第一步就找错了地方

> 大家好，我是哥飞。新站上线以后，很多人很快会卡在外链这一步。问题可能出在第一步：入口选错了。"很多网站出现了我的网址"和"这些链接被收录、有人点击"，其实是两回事。

![新站外链](images/newsite-backlinks/001.png)

## 背景

2025 年 7 月，成都年中分享交流会。第三位嘉宾 Ada，之前是 EaseUS 推广负责人，在公司做了 8 年，从一线执行一路做到负责 SEO 和社媒推广。她当天讲了两条路：

1. **Press Release** 建立品牌曝光和第一批链接
2. **从目标关键词的搜索结果里找合作对象**，再通过 Digital PR、测评或内容合作争取链接

两条路不必固定按顺序做。有明确发布节点、也有分发预算时，可以用 PR 让新品牌先出现在公开页面里；产品已经能体验，也锁定了目标关键词时，可以直接从 SERP 找作者和合作页面。

![Ada在成都活动现场分享](images/newsite-backlinks/002.jpeg)

## 第一条路，先用一篇新闻稿建立信号

**Press Release**，也就是新闻通稿。品牌有新产品、新功能或重要进展时，把信息发到新闻稿平台，再由平台分发给媒体。

对刚上线的新站来说，这条路容易启动。它不要求团队已经认识很多编辑，稿件通过审核后，通常会在平台的媒体网络里完成发布和转载，留下第一批品牌提及和链接页面。

![Ada解释新闻通稿的作用](images/newsite-backlinks/003.png)

Ada 分享过一个新产品的做法：这个产品对应的关键词竞争很高，短期很难直接靠非品牌词拿到排名。团队先定义一个几乎没有搜索结果的新品牌词，用新闻稿让名字进入一批媒体页面，再通过 YouTube 内容和少量广告带来真实搜索。**一个月后，Google 已经能把这个名称与网站对应起来。**

新站安排 PR，最好选在产品已经能正常使用、定位和名称已经确定之后。页面还在频繁改名、功能也没跑通时就发稿，媒体和用户打开产品只会看到半成品，第一轮曝光很容易浪费。

![Ada现场讲解PR对品牌曝光和外链的作用](images/newsite-backlinks/004.jpeg)

### 200 家媒体转发，不等于 200 条有效外链

PR 最容易出现的误解，是把转发数量直接当成外链数量。

Ada 那次投放后，一篇稿件被 200—300 家媒体转发。再去搜索标题和品牌词，真正还能在搜索结果中看到的页面少了很多；**GSC 后来识别到的外链页面约有 20—30 个**。

> 销售页上的媒体总数、搜索结果中能看到的页面、GSC 发现的外链页面，是三个不同的数字。

![媒体转发数量不等于实际收录外链](images/newsite-backlinks/005.png)

选择服务时，别只看销售页上写了多少家媒体，还要问清：
- 链接形式
- 分发地区
- 历史收录情况

拿到发布报告后，随机打开几家媒体页面，检查：
- 稿件是否完整
- 官网链接能不能点
- 品牌名有没有写错

### 判断一轮 PR 有没有完成任务，分开看四件事

1. 搜索品牌名时，有没有出现正常可访问的媒体页面
2. GSC 或外链工具里，有没有逐步看到新的引用域名
3. 稿件发布以后，品牌词搜索和直接访问有没有变化
4. 有没有编辑顺着稿件联系团队，产生独立报道

前两项是基础信号，后两项取决于产品本身。同样发一篇稿，产品没有亮点时，稿件往往停在转载网络里；产品有清楚的差异、数据或故事，才可能被编辑单独拿出来写。

**记者、编辑和行业从业者才是 PR 的主要受众**，普通用户往往在搜索某个品牌是否可靠时，才会顺着结果看到这些媒体页面。

### PR 不用写得很长，先把亮点写清楚

Ada 建议英文新闻通稿**控制在约 400 个单词**。

![Ada分享新闻通稿的写法](images/newsite-backlinks/006.png)

- **标题**先放最重要的信息：产品解决什么问题，刚发布了什么能力，或者拿到了什么能被核验的结果
- **开头两段**回答基本事实：谁发布了什么，给哪类用户使用，为什么选择现在发布
- **H2** 集中写产品与同类工具的差别
- **最后**补使用方式、团队背景、官网入口和联系方式

AI 可以帮助整理结构和润色英文，但**选题不能交给 AI 猜**。产品亮点必须来自真实功能、用户反馈、数据或发布节点。

写之前可以做个小测试：把标题、第一段和产品亮点单独发给一个没参与项目的人，问他能不能说出产品做什么、服务谁、哪里不同。说不出来，就先改信息，不急着补更多文字。

## 第二条路，从 SERP 里找能合作的页面

很多人想给新站做外链，会先打开外链工具看 DR，筛一批域名，再给这些网站群发邮件。Ada 提供了另一个起点：

> **先搜自己的目标关键词，看看 Google 已经把哪些页面排进前十。**

Ada 在现场展示了一个 AI 视频生成词的真实结果页。前排有品牌官网，也有 YouTube 视频、论坛讨论、UGC 页面和内容文章。竞品官网通常不会给你链接，剩下这些页面却可能找到真实作者。

![从SERP里的视频结果寻找合作机会](images/newsite-backlinks/007.png)

这些页面已经在目标关键词下获得排名。页面本身可能持续有用户访问，主题与产品相关，也更容易找到具体作者和联系方式。

**视频结果**先看三个信息：
- 它现在是否仍有排名
- 评论区有没有真实用户询问工具
- 创作者是否持续更新同类内容

**UGC 和论坛页面**先看社区允许什么，再找原作者或管理员沟通。能参与讨论时，就直接回答已有问题；适合联系作者时，就说明自己能补充哪些资料。

**内容文章**则看它是否与自己的产品解决同一个问题，作者是否还在更新。联系时不要只说"请加一下我的链接"，而要指出哪一段信息已经过时，自己的产品或数据能补充什么。

![已经有排名的页面更接近目标搜索用户](images/newsite-backlinks/008.png)

> 自然链接成立的前提，是作者确实认为这个产品值得出现在原来的内容里。

### 筛选页面时，别只盯着 DR

候选页面先从 **SERP、主题相关性和作者活跃度** 里筛出来，再用 DR、链接属性和价格做第二轮核对。

先打开链接将要出现的那一页，检查：
- 有没有进入搜索结果
- 最近有没有更新
- 正文是否在回答用户的问题
- 页面里已经放了多少个产品链接

> 一篇文章两年没人维护，正文又塞着几十个不相关推荐，域名指标再好也未必能带来用户。

再看链接出现的位置。正文解释某个使用场景时自然提到产品，与文章末尾单独堆一排网址，效果完全不同。

**Ada 给了一个很现实的成功率预期**：联系 100 位相关编辑，能有 1 位愿意进一步了解，已经值得继续。这里的 100 位应该经过筛选，不能拿一封模板机械群发。

> 先找十个真正相关的对象，检查邮件是否正常进入收件箱、产品亮点是否说清楚、截图和演示账号是否好用。前十封主要用来测试材料，不用急着看回复率。

## 两条路怎么选，也可以怎样组合

| 场景 | 推荐路径 |
|------|---------|
| 产品名称、定位、核心功能还在频繁变化 | 先把产品跑通 |
| 有正式上线、核心功能升级或可核验结果，也愿意为分发付费 | 先写 Press Release |
| 已锁定目标关键词，也有可供作者体验的产品 | 直接搜索前两页找合作 |

两条路一起做时，**PR 先补品牌公开信息**，SERP 合作再把产品带到更接近目标用户的页面。

> 无论选哪条路，产品本身都要有值得写、值得试的东西。
