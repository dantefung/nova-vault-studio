### 2. 白屏 bug 修复（`614e9ec`）

**问题**：用户切到 `easton-clone` 主题后首页白屏。

**根因**：VitePress 1.6.4 SSR 阶段无法读 `localStorage` / `<html>.dataset`，`HomeLayout.vue` 的 `v-if="currentLandingTheme === 'easton-clone'"` 在 SSR 永远 false，hydration 后 Vue 3 patch 模式不重评估 v-if。

**方案**：去掉 `easton-clone` 整体首页特性，landingTheme 从三档（quiet / easton / easton-clone）改为两档（quiet / easton）。

**影响**：
- ✅ 白屏消失
- ✅ easton 主题下文档内页 Easton 化正常（`easton-doc.css` 靠 `html[data-landing-theme="easton"]` 触发）
- ✅ 博客 4 个页面（list / archive / series / category）正常
- ⚠️ Easton Clone 整体首页（hero / series / featured / latest / categories）已移除

### 3. 菜单失效修复（`1c7859d`）

**问题**：顶部导航菜单（文档 / 书籍 / 教程 / AGI / Wiki...）点击没反应。

**根因**：`fix-navigation.js` 的 click handler 对所有 `.VPNavBarMenuGroup button` 都 `e.preventDefault()` + `e.stopPropagation()`，导致 click 只 toggle 子菜单显示，不跳转。

**修复**：click 时找 `.items a[href]` 第一个，调 `firstLink.click()` 让 VitePress SPA router 处理跳转。

## 已知限制

1. **VitePress 1.6.4 SSR 无法读 localStorage**：landingTheme 切换后首次访问 SSR 渲染 quiet fallback，SPA 切换后正常。
2. **Vue 3 hydration patch 模式**：SSR 渲染的 v-if 节点在 hydration 后不会重新评估，需要 `:key` 强制重建。
3. **VitePress 1.6.4 不支持 `rewrites`**：博客路由必须用真实占位 md 文件。
