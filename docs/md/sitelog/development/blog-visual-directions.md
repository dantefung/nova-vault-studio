# 博客视觉升级方向对比稿

> `/md/blog/` 去 AI 味改造的三方向视觉对比。最终采用 A「克制出版」的信息结构，并吸收 B「图像随笔」的 5 篇精选配图。

<HtmlViewer src="/blog-visual-directions/index.html" title="博客视觉升级方向对比稿" />

## 最终决策

- 首页以观点与文章为主角，不做作者简历式首屏。
- 全站采用克制编辑感：低饱和纸面、细线、强排版，不使用大圆角卡片、胶囊标签和悬浮阴影。
- 首页仅为 5 篇精选文章生成主题配图，其余文章保持纯文字索引。
- 改造范围覆盖博客首页、分类、系列、归档、公共页头和页脚；文章正文保持现状。

## 实施结果

- 首页采用 5 篇精选加 581 篇纯文字目录，精选优先读取 `featured`，不足时由最新文章补齐。
- 分类、系列和归档统一为编辑式文字索引，不再使用伪封面、大圆角卡片、胶囊标签、阴影和上移动画。
- 精选插画由 5 套低饱和纯 CSS 线条构成，不引入批量生成图片或渐变背景。
- `ArticleCard` 改为语义化 `article`，文章标题是唯一主链接，元信息不再形成嵌套链接。
- light、dark、sepia 三种主题以及 390px 移动端均完成浏览器验收。
