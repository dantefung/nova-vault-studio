# 2026-08-21 开发日记

## cubxxw.com 主题复刻部署成功 ✅

### 背景
复刻 cubxxw.com 编辑风格到 Nova Vault，跳出 VitePress 限制，使用 Next.js 完整重建。

### 技术决策
| 项目 | 选择 | 原因 |
|------|------|------|
| 框架 | Next.js 16.3.1 | 跳出 VitePress，技术栈不限 |
| 样式 | Tailwind CSS v4 | 原子化 CSS，设计令牌管理方便 |
| 部署 | Cloudflare Pages | 免费额度充足，全球 CDN |
| 字体 | Space Grotesk + Noto Serif SC | 与 cubxxw 同款 |

### 设计令牌还原

```css
/* cubxxw 核心配色 */
--color-paper:        #fbf9f4  /* 暖纸张背景 */
--color-ink:          #350003  /* 深墨红黑 */
--color-accent:       #862122  /* 深红强调 */
--color-primary:      #0e7490  /* 青色操作 */
--content-width:      720px    /* 窄栏阅读 */
```

|------|-----|

| 分支 | feat/cubxxw-theme-clone |

| 构建时间 | ~3s |

### 解决的问题

1. **符号链接死循环** — `docs/md/wiki/images/images` 指向 `../images`，导致 Vite 文件监听无限递归。已删除。
2. **静态导出动态路由** — `/articles/[slug]` 需要 `generateStaticParams()` 才能静态生成。
3. **next-on-pages 版本冲突** — Next.js 16 与 @cloudflare/next-on-pages 不兼容，改用标准静态导出。
4. **Articles 页面 searchParams** — 移除 `await searchParams` 改为客户端过滤。
