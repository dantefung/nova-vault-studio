## 关键洞察

### Skill 系统正在分化

AI Coding Agent 的 Skill 生态已细分出多个方向：
- **防丑/设计方向**：taste-skill、web-designer-plugin、emil-kowalski-skill、guizang-social-card-skill
- **内容/演示方向**：magic-slide、guizang-social-card-skill（图文）、AiToEarn（视频+图文）
- **方法论方向**：geju（格局打开）、skillshare（跨平台同步）、yao-open-skills（行业学习）
- **逆向工程方向**：ky-design-to-html-skill、ai-website-cloner-template

### 工具层 vs 平台层分化

- **工具层**：单一功能精深（weread-exporter、go-stock、ai-website-cloner）
- **平台层**：聚合多功能（AiToEarn、skillshare、hai-stack）

### 内容生产 AI 爆发

AiToEarn（18.2k Stars）+ guizang-social-card-skill（3k Stars）+ magic-slide（147 Stars）形成完整内容生产链路：视频→图文→多平台分发→变现。

### geju/goudi 成对出现

Codex 用 geju 治过怂，Claude Code 用 goudi 治过飘——不同 AI 助手的典型偏差需要不同方向的反制 Skill。
