## Codex 新功能

Codex 最近更新的几个重要功能：

1. **远程控制 Mac**：手机 App 远程操控锁定的 Mac，即使屏幕黑屏也可操作任何应用
2. **Appshots 屏幕上下文**：按空格键两侧 Command 截屏传送给 Codex，比截图更清晰
3. **Goal Mode 目标模式**：设定目标后自主工作几小时甚至几天，完成后自动迭代
4. **高级注释模式**：网页上直接拖动调整外观、改颜色，Codex 实时理解并生成新版本
