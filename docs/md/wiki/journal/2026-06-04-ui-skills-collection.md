# 5 个 UI 开源 Skill — 让 AI 写出来的东西更像人设计过

## 一句话总结

| Skill | Stars | 功效 | 适合场景 |
|-------|-------|------|----------|
| Taste-Skill | 34.1k | 让页面不丑 |官网、产品页、落地页、作品集 |
| Web Designer Plugin | 43 | 让页面有设计方向 | 想做更有设计感的网页，不想只堆卡片 |
| Emil Kowalski Skill | 2.1k | 让细节更精致 | 把页面从能看打磨到舒服 |
| Magic Slide | 147 | 让演示稿更专业 | 产品介绍、项目路演、方案展示 |
| Awesome DESIGN.md | 87.8k | 让风格更统一 | 粘贴 DESIGN.md，AI 按指定风格生成界面 |

## 定位分层

```
防丑层：Taste-Skill
  ↓
设计方向层：Web Designer Plugin
  ↓
精致化层：Emil Kowalski Skill
  ↓
风格护栏层：Awesome DESIGN.md
  ↓
输出层：Magic Slide（演示稿）
```

## Taste-Skill 三档旋钮

- **DESIGN_VARIANCE**：布局实验度（低=居中干净，高=不对称现代）
- **MOTION_INTENSITY**：动效深度（低=hover，高=scroll/magnetic）
- **VISUAL_DENSITY**：信息密度（低=留白，高=密集仪表盘）

## Web Designer Plugin 决策框架

```
MOOD（情感调性）
  ↓
PALETTE（配色）
  ↓
TYPE（字体策略）
  ↓
LAYOUT（节奏）
  ↓
MOTION（动效）
  ↓
SIGNATURE（让设计被记住的那一件事）
```
