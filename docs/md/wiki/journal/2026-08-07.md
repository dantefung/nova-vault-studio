# 2026-08-07

## 精力才是真正的稀缺品

一个人真正稀缺的，从来不只是时间，而是精力。

很多人每天看起来什么都没做，却已经很累了。因为仅仅是对抗焦虑、委屈、愤怒和自我怀疑，就消耗掉了大半能量。剩下的精力，勉强够应付工作，更别说沉下心来，把一件事情真正做好。

反过来看，那些最后能把事情做成的人，未必是能力最强的，但往往都有一个共同点：要么情绪稳定，不会因为一点波动就停下脚步；要么内核足够强，有清晰的边界，不轻易被别人的评价和情绪牵着走。

不内耗，才能把精力放在事情上；持续推进，才有机会把事情做成。

很多时候，真正拉开人与人差距的，不是智商，而是一个人管理情绪、保护精力的能力。
