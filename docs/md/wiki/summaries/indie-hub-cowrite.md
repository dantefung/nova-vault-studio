## 核心内容

Cowrite 是内置于 Codex 的可视化创作工作台，将零散 Skill 封装成 GUI 界面，实现一键配图、排版、发送社媒和生成 PPT。

## 关键要点

1. **零散 Skill → GUI 工作台**：把多个写作 Skill（配图、排版、PPT、发布）封装成可视化界面
2. **选中即创作**：选中文字后可优化、配图、转 HTML，结果自动回写到文章
3. **四大功能**：全文配图、全文排版（公众号/小红书）、生成 Slide（PPTX/HTML）、发送到飞书
4. **基于 MCP**：使用 MCP 拆了 10+ 编辑器功能点，ChatCut 启发，结合 Codex 生态
5. **项目地址**：SpaceZephyr/cowrite，支持 Claude Code、Workbuddy 等任意 Agent
