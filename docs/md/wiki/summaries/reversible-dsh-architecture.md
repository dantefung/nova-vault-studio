# 可逆不是逆向运行：DeepSeek Harness 架构的数学本质 — 精读摘要

## 核心结论

DSH（DeepSeek Harness）的"可逆"不是逆向运行，而是**逆转对运行时结构空间的变更**。Cordis 论文将其形式化为数学定理：一切皆插件 = 一切皆差量（Delta 可正可负），插件的每次注册都配对一个撤销函数，运行时保证撤销函数被保存、被执行、不会被执行两次。

本文作者"可逆计算"从可逆计算理论（GRC）角度分析 DSH 架构，核心论点：Cordis 是可逆计算理论在运行时结构空间的具体应用，但要完整实现可逆性还需补上编译期结构空间的差量代数。

## 关键洞察

### 1. "一切皆插件" = "一切皆差量"

- DSH 的公式：App = Base + Plugin1 + Plugin2 + ...
- 对应可逆计算：Structure = Base + Δ1 + Δ2 + ...
- 关键区别：DSH 不是启发式描述，而是将插件运算形式化为数学空间中的精确运算

### 2. 可逆 ≠ 逆向运行

- 可逆的对象始终是**结构**（谁注册了什么、谁监听了什么），不是**状态**（业务数据、外部副作用）
- 两个软件"相空间"：编译期结构空间（Nop 的主战场）vs 运行时结构空间（DSH 的主战场）
- Nop 的可逆发生在编译期，DSH 的可逆发生在运行时——互补路径

### 3. DSH 的运行时结构空间

由三部分构成：
- **服务表**（ReflectService）：唯一共享，由"服务名+隔离标签"定位
- **fiber 树**：每次 ctx.plugin() 产生一个独立 fiber，承载生命周期
- **ctx 链**：原型链决定可见性，fiber 决定归属账本

### 4. DSH vs Pi Agent 的本质区别

| 维度 | Pi Agent | DSH |
|------|----------|-----|
| 扩展空间 | Ext(AgentLoop)：核心预定义槽位 | Compose(Plugin...)：插件可生成新坐标 |
| 拓扑 | 放射状（围绕 Agent Loop） | 依赖图（ServiceA → Plugin2 → ServiceB） |
| 生命周期 | session_start/session_shutdown 分离 | fiber 统一治理，LIFO 逆序卸载 |
| 依赖管理 | 无建模，全靠约定 | reconciliation 自动协调 |

### 5. 单写者 + 累加 + 无删除

- **单写者**：每个坐标由一个 fiber 提供一次，同层同名直接报错
- **累加**：注册操作只做插入，运行时结构单调增长
- **无删除**：只能执行自己的逆，不能删除别人的贡献——"你能减掉的，只有你自己加上的"

### 6. 插件是结构还是代码，决定定制能力的上限

- Nop 的 Delta 包本身就是结构 → 可定制到字段级
- DSH 的插件是命令式 TypeScript 代码 → 只能替换，不能差量化内部
- 未来方向：插件内部声明式化（DSL 结构）或在运行时定义差量代数

### 7. 可逆性的哲学：控制熵增

- 热力学第二定律：系统自发演化时熵永不减少
- 软件同理：增加功能越来越难，最终推倒重建
- 可逆计算的态度：控制不了熵增，但可以选择熵增发生的地方
- 可逆 = 信息可追溯 + 信息可分离
- 分离得好不好，看它能不能被完整拿走

## 理论对照：DSH vs Nop

| 维度 | DSH | Nop |
|------|-----|-----|
| 可逆空间 | 运行时结构空间 | 编译期结构空间 |
| 逆的形式 | 闭包函数（不透明） | 结构差量 x-diff（声明式） |
| 坐标 | 服务名+隔离标签（平铺映射） | 路径坐标（tree 结构） |
| 负元素 | 无（单写者+累加） | 有（Delta 可正可负） |
| 响应式 | 有（reconciliation 主动触发） | 无（被动式缓存检查） |
| 时间静止 | epoch 检查 + inertia 机制 | 编译期天然时间静止 |

## 值得深读的细节

1. **fiber 独立生命周期**：插件代码可实例化多次，每次 ctx.plugin() 产生独立 fiber，自己派生的 ctx 链、自己的 disposables、自己的生命周期
2. **ctx.isolate vs ctx.plugin**：isolate 只换服务存储槽位，不产生新 fiber；plugin 产生新 fiber
3. **事件派发模式的代数差异**：emit=可交换，waterfall=不可交换（洋葱链）
4. **可逆性（能力）与响应式（治理）正交**：可逆保证"撤得回来"，响应式保证"不会跑到无效状态"
5. **观测等价性**：逆操作后的"回到原始状态"是观测等价（Definition 33），不是物理状态完全恢复
