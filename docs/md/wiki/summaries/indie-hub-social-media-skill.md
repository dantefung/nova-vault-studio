## 核心内容

空格丶用 Agent Skill 搭建社媒监控系统，基于 X MCP 和 Agent-reach 思路，打通小红书/公众号/抖音/B站数据。

## 四个核心Skill

| Skill | 功能 |
|-------|------|
| 小红书账号分析 | 拉取账号最近内容，按互动数据排序分析，输出收藏率/标题/发布时间规律 |
| 爆款笔记搜索 | 关键词搜索，提炼标题规律/封面规律/开头钩子/用户关注点 |
| 爆款公众号搜索 | 监控最近30天爆款，分析切入角度/标题类型（观点文vs教程文） |
| 监控日报Skill | 固定抓取+日报生成，定时监控领域关键词 |

## 监控维度

- 领域关键词日报（AI Agent/Claude Code/MCP等）
- 博主风格分析（选题/标题/开头/收藏率）
- 自身账号分析（点赞/收藏/评论/发布时间/标题表达）

## 关键洞察

Skill本身不难，难的是数据源。平台没开放Agent接口，需要后端服务调度账号权限+IP网络模拟正常访问。期待平台官方开放数据能力。
