# GA4探索报告完整指南

> 标准报告告诉你"发生了什么"，探索报告回答"为什么发生"和"接下来怎么办"。先明确问题，再选分析方法。

## 核心洞察

### 1. 探索报告的本质

GA4 探索报告是一个高度可自定义的分析工作区，可以自行组合维度、指标、细分、筛选条件和可视化方式。核心原则是**先明确问题，再选择分析方法**。

### 2. 7 种探索类型及适用场景

| 探索类型 | 核心问题 | 典型场景 |
|----------|----------|----------|
| 自由形式 | 哪些维度表现最好/最差？ | 横向比较渠道、设备、页面 |
| 漏斗探索 | 哪一步流失最严重？ | 转化流程拆解 |
| 路径探索 | 用户实际走了什么路径？ | 不预设流程，观察真实行为 |
| 细分重叠 | 不同用户群是否重合？ | 判断人群重叠度 |
| 用户分层图表 | 某类用户具体做了什么？ | 查看匿名用户事件序列 |
| 同类群组探索 | 某批用户后续表现如何？ | 对比不同时期用户留存 |
| 用户生命周期 | 哪类用户长期价值更高？ | 按渠道追踪用户价值 |

### 3. 三个易混淆概念

| 概念 | 作用范围 | 可复用性 |
|------|----------|----------|
| 细分（Segment） | 定义用户子集 | ✅ 可保存复用 |
| 对比项（Comparison） | 当前视图拆分对比 | ❌ 当前视图专用 |
| 筛选条件（Filter） | 过滤数据范围 | ❌ 仅当前页签生效 |

### 4. 数据保留设置

探索使用用户级和事件级明细数据，受数据保留设置限制。建议尽早设置为最长可用期限。
