# 刘佳怡：iPhone 快捷指令自动转发短信验证码到邮箱

## 核心结论

一台常年放在别人手里的备用机收验证码，不必每次都麻烦对方代看。用 iPhone 自带的「快捷指令」做两条个人自动化——**一条被动转发、一条主动查询**——就能把短信验证码自动送进自己邮箱。零第三方服务、零越狱、零常驻成本，两种方案选一种就够用。

## 使用场景

二手手机放在国外亲戚家 + 一张月租 $5 的手机卡专用于收短信。原本每收一条短信就得联系对方开机查看再转发，反复麻烦人。改成自动转发后彻底无需人工介入。

## 方案一 · 自动转发（推荐）

被动触发，短信到达即转发。

1. 新建「个人自动化」，触发条件选**信息**。
2. 条件选**信息包含**，填入关键词（如「验证码」）——只有含该词的短信才会触发。
3. 可在一个快捷指令里挂多个自动化、设多组关键词。怕漏短信就把 `a-z`、`0-9` 全设进去（匹配不区分大小写）。
4. 末尾加「发送邮箱」指令，收件人填自己邮箱，内容选**短信变量**（多组时任选其一）。
5. 测试：发一条含关键词的短信，确认邮件抵达。

**关键坑点**：默认取到的短信数据是一种**信息附件**，不是纯文本。选完变量后必须**再点一下该变量**，在弹出菜单里选**「内容」**，发出去的才会是正文文本而非附件。漏了这步会收到打不开的附件。

## 方案二 · 主动查询

按需拉取，适合不想让每条短信都触发通知的场景。

1. 新建「个人自动化」，触发条件选**电子邮件**。
2. 条件设为邮件标题包含「查询验证码」。
3. 需要查证时，往这台手机发一封标题含该词的邮件即可触发。
4. 快捷指令执行：查询**未读**短信 → 合并正文 → 发送到自己邮箱 → 将这批短信**标记为已读**。

标记已读这步是防重复查询的关键，否则同一批短信会被反复合并重发。

## 适用边界

- 依赖 iPhone 自带快捷指令，无需安装任何 App。
- 两台设备都需能正常收短信 / 收邮件。
- 备用机若长期关机或断网则失效——本质是把「人工代看」换成「自动转发」，不解决设备在线问题。
