## 核心内容

空格丶开源50个知识管理Skill（Read Buddy + Design Buddy + Creator Buddy），覆盖阅读→整理→创作全链路。

## 三大仓库

| 仓库 | 数量 | 功能 |
|------|------|------|
| Read Buddy | 19个 | 网页/RSS/YouTube/播客/X/飞书文档/微信读书/图片OCR→结构化内容 |
| Design Buddy | 19个 | 封面/配图/逻辑图/架构图/Logo/故事板/幻灯片/公众号排版 |
| Creator Buddy | 5个 | 抖音/小红书/公众号/B站搜热点/挖爆款/看评论/查竞品 |

地址：github.com/SpaceZephyr/read-buddy + design-buddy + creator-buddy

## AI生产力系统五模块

1. **文件夹**：上下文边界，放规则说明和hook触发
2. **目标**：业务线/季度目标/本周优先级
3. **Skill**：原子化设计，一个Skill只做一件事
4. **记忆**：Agent每天干什么、反馈、数据都要留痕
5. **风格**：写作风格/金句库/历史文章/读者画像

## 链路组合

Creator Buddy找选题 → Read Buddy抓素材 → 写成文章 → Design Buddy配图排版
