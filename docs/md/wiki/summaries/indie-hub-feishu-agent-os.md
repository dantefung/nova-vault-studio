## 核心洞察

飞书不只是承载内容的终端，它是 Agent 的操作系统。操作系统四核心能力对应：进程调度（触发方式）、文件系统（存储沉淀）、消息总线（Agent间协作）、权限管理。

## AAMP协议

Agent时代的IPC（进程间通信）。每个Agent有地址+信箱+调度器，多维表格是任务队列，工作流是定时器，仪表盘是控制面板。

## 飞书作为Agent OS的优势

- CLI让Agent像用户一样操作飞书
- AAMP让Agent之间直接通信
- 多维表格+工作流让Agent可被事件触发
- 妙记和文档让Agent有充足上下文
- 文档和HTML报告呈现是系统级能力
