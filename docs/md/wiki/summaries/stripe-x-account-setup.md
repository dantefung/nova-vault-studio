# nemo 的 Stripe 香港个人账户注册指南

## 核心结论

对于没有公司账户的独立开发者，注册 Stripe 香港个人账户是实现全球收款最简单、成本最低的合规路径。关键在于：选择香港地区、使用港卡作为结算账户、保持三者姓名完全一致。

## 关键洞察

1. **香港个人账户是最佳起点**：地区必须选 Hong Kong，商户类型选 Individual。同区结算规则决定香港账号只能结算到香港本地银行。
2. **护照比身份证更顺**：作者使用护照完成 KYC，港澳通行证理论上也可以。
3. **X 主页可作为业务载体**：没有出海网站时，X 主页本身就能满足"公司详情"的填写要求。
4. **美元结算账户可降低汇损**：默认港币账户在美元业务时会损失 2% 换汇费用，手动添加美元结算账户后提现虽有约 1% 手续费，但仍比 2% 换汇损失更划算。
5. **Google Authenticator 必装**：Stripe 安全等级极高，必须绑定 2FA，备份代码务必物理抄写保留。

## 准备工作清单

- 身份证明：护照（首选）、港澳通行证（理论上可）
- 收款账户：个人名下香港银行账户（中银香港、汇丰、众安银行等）
- 业务载体：出海网站或 X 主页
- 安全工具：Google Authenticator 或同类 2FA 应用

## 流程要点

注册 → 选择香港 + Individual → 填写个人/公司详情 → 添加港卡 → 绑定 2FA → 提交审核 → 护照拍照验证 → 激活成功

审核通常几小时到 1 个工作日完成。通过后即可开始全球收款。
