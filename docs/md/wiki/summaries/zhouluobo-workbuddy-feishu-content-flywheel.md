# 用 WorkBuddy+飞书搭一条公众号内容自动飞轮

## 核心结论

**公众号创作的真正时间黑洞不是写稿，是「搬运 + 排版 + 推送」这些窗口切换。** 萝卜哥实测：原来从选题到进草稿箱要切 10 几次窗口，搬运环节就占掉 1 个多小时。WorkBuddy（腾讯自研 AI 智能体桌面工作台）连接飞书后，把这条链路压缩成三环——**飞轮第一环**：多维表格当选题库，让 WorkBuddy 把外部选题自动写入；**飞轮第二环**：状态从"待定"改为"选中"触发 WorkBuddy 读选题 + 历史文风 → 生成初稿；**飞轮第三环**：排版 skill 把稿子排好 + 公众号 API 推送到草稿箱。最后一键人工点发送。这不是无人值守，但中间所有搬运数据、格式化排版的活儿可以全部交给 AI。

## 关键洞察

1. **飞书多维表格是飞轮的「事件源」**：选题库 = 一张多维表格；状态字段「待定/选中/已完成」是 WorkBuddy 触发动作的开关。状态从"待定"→"选中"就是一个事件，WorkBuddy 看到后自动启动后续所有动作。这套「数据库字段当事件源」的玩法，是把 AI Agent 嵌入日常工作流的最自然方式。
2. **AI 选题不是直接用，要筛选再迭代**：用一句 prompt 让 WorkBuddy 分析赛道热门选题并自动写入飞书，AI 给的 10 个选题留 3–4 个、改标题、删其余。如果觉得 AI 搜索选题质量不够，可叠加卡神的「AI HOT skill」让数据源升级——同一个流程、不同质量的数据源，立竿见影。
3. **多维表格的「备注栏」才是 prompt 决定质量的真正抓手**：AI 初稿质量完全取决于「备注」里写了什么。萝卜哥做法：每条选题花 2 分钟写「这篇给小白看、只讲怎么上手、不讲原理」——上下文越丰富，稿子越贴。这是把"prompt engineering"嵌入日常工作流的最自然方式。
4. **AI 写稿你必须改三件事**：开头换成自己真实经历、中间配实际操作截图、观点立场部分重写。骨架和基本内容不用从零搭了——一篇 2000 字稿子从半天缩到 1 个多小时。
5. **排版网站也能变成 skill**：萝卜哥自己做的排版网站逻辑，打包成 WorkBuddy skill 上架 skillhub，于是「写稿 → 排版」一步到位。这是把「个人工具 → 公共资产」的低成本路径。
6. **公众号草稿箱推送的关键 4 个动作**：① 微信公众平台扫码登录 ②「我的业务」→ 公众号 ③ 拿 AppID + AppSecret ④ 设置 API IP 白名单（百度查 IP 填进去）。然后告诉 WorkBuddy 推送到草稿箱，AI 自动生成封面贴心地省掉最后一步。
7. **WorkBuddy 不抢判断的活**：选题值不值得做你判断，稿子质量你把关，发布前最后一眼你点。AI 只干搬运数据、格式化排版这些「机械劳动」。
8. **WorkBuddy 的隐藏能力**：支持多模型切换，可接入自定义模型。Hy4 preview 免费、Hy3 免费到 9 月底——薅羊毛窗口期。
9. **场景边界：偏理论内容 AI 可自动写，偏教程 AI 写不了**（教程需要真实截图视频与个人体验）；情感、时事类可用 AI 打底但仍需个人特色。

## 三环飞轮架构

| 环节 | 工具 | 触发方式 | AI 干的事 | 你做的事 |
|------|------|---------|----------|----------|
| 第一环：选题自动入库 | 飞书多维表格 | 一句 prompt | 分析赛道 → 写 10 个选题到表格 | 筛 3–4 个、改标题、状态置「待定」 |
| 第二环：选题变文章 | 飞书文档（历史文风）+ WorkBuddy | 状态改「选中」 | 读选题 + 历史文风 → 出初稿 | 改开头、换真实截图、重写观点 |
| 第三环：排版+推送 | WorkBuddy skill + 公众号 API | 一句 prompt | 排版 + 推草稿箱 + 生成封面 | 打开后台过一遍 + 点发送 |

## 操作清单（按这篇复现）

1. **接飞书**：WorkBuddy 侧栏 → 连接器 → 搜「飞书」→ 点 + → 授权（2–3 分钟）
2. **建选题库**：飞书多维表格，字段：选题标题 / 关键词 / 内容方向 / 流量预估 / 状态 / 备注
3. **采集选题**：对 WorkBuddy 说「分析赛道、给 10 个选题、写入飞书多维表格【选题库】、状态=待定」
4. **优化选题源**（可选）：装「AI HOT skill」（认准卡神官方版）→ 用新 prompt 采集
5. **写稿**：状态改「选中」→ 对 WorkBuddy 说「读选中记录、根据历史文风写 2000 字口语化文章」
6. **排版**：装「文章排版 skill」（萝卜哥上架）→ 让 WorkBuddy 排版
7. **推草稿箱**：拿到公众号 AppID + AppSecret + 设置白名单 → 让 WorkBuddy 推送到草稿箱 + 生成封面
8. **人工发布**：打开后台过一遍 → 点发送（不甩手这一步）
