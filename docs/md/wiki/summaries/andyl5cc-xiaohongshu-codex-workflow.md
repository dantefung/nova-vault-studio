# Andy L：用 Codex 把小红书账号做到 2 天涨 1000 粉

## 核心结论

AI 时代做内容不再从 0 构思，而是**先找到一个已经被市场验证的内容模型 → 拆解成可复制的逻辑 → 用 AI 当执行器批量复制**。Andy L 凭这套方法在小红书 2 天涨了 1000 粉、累计 105 万曝光、18 万观看，封面点击率 17.9%——本人全程只做「定方向 + 审核」，从选题到排版全丢给 Codex。

## 关键洞察

1. **不要从 0 构思，先找已被验证的内容模型**：作者的核心方法论是「发现 → 拆解 → 模仿 → 迭代」。这次起号的起点，是看到 X 上一个专门讲「生活中常见物的英文名」的小红书账号。他没有搬运内容，而是把它的「选题模型 + 流量模型 + 视觉模型」拆下来，让 Codex 批量复刻同一套路。
2. **选题有硬标准 = 必须有「信息差」**：用一条问题筛所有想法——「这个东西是不是大家都见过，但大多数人不知道它英语叫什么？」答案太明显的不做；看到答案后没有「原来这东西还有名字」感觉的不做。这条标准让选题流水线不会产废。
3. **封面视觉有套路可复制**：内容形式天然适合做小红书封面——「熟悉的东西 + 一个圈/箭头 + 一句『这个叫什么？』」用户 0.5 秒就能看懂。这是 17.9% 起步的视觉模型。
4. **起号阶段只做一件事：强化已验证的模型**：不要天天创新。哪个内容结构有效，就继续做类似内容，不断强化同一个被验证的内容模型。
5. **AI 真正降的是「从看到机会到做出来」的时间**：以前看到一个项目，研究一周还没开始；现在当天拆、当天发、市场直接给答案。

## 四步流水线

1. **发现**：在 X / 小红书 / 抖音上找一个已跑出来的账号。
2. **拆解**：把它的内容拆成三层——选题模型（什么能火）、流量模型（封面/标题/前几秒）、视觉模型（画面/排版）。
3. **模仿**：用 AI（这次是 Codex）按拆解出的逻辑批量生产同模型的新选题，原账号的素材不搬，只搬底层套路。
4. **迭代**：看数据反馈，强化被验证的那条主线，不轻易换玩法。

## 选题与生产的可执行清单

| 环节 | Andy L 的做法 |
|------|------|
| 选题方向 | 「生活中常见物的英文名」——披萨盒塑料架、订书机铁片、鸡蛋里的白色绳子 |
| 选题标准 | 必须有信息差：答案是显而易见的就不做 |
| 标题套路 | 反问句式（"X 英文叫什么？"）让用户 0.5 秒看懂封面 |
| 视觉模板 | 统一风格图片 + 圈 / 箭头 + 英文词 |
| 执行分工 | 人：定方向 + 审核；Codex：选题 → 查英文 → 核对资料 → 写标题 → 做图 → 排版 |
| 数据基线 | 曝光 105.1 万 / 观看 18.4 万 / 封面点击 17.9% / 2 天涨粉 1000 |

## 可照抄的三类场景

| 对象 | 做法 |
|------|------|
| 想在小红书起号的个人 | 找一个 1 万粉左右的「内容纯靠选题取胜」账号，拆它的选题/封面套路，用 Codex/Claude/任何 Agent 批量产同模型内容 |
| 内容团队 / MCN | 把「发现 → 拆解 → 模仿 → 迭代」沉淀成 SOP：每周固定时间刷对标账号、产出 5-10 个新选题、过审后批量执行 |
| 跨境卖家（英语/日语/西班牙语等） | 把「本地生活常见物的外语名」这条模型平移到任意小语种市场，复制同样的「熟悉 + 陌生」反差 |
