# 月订阅费 8000 块，一台手机管 9 台电脑、6 个 Agent

## 核心结论

**重度 Vibe Coding 之后，一台电脑不够用、离开工位就干不了活，会让人活成「焊在工位上的打工仔」。** 作者的解法是把远程问题拆成两层：**Vibe42 管「人控机」**（手机随时连任意主机），**Tailscale 管「机连机」**（跨地域 9 台电脑组私有局域网、机器之间直接互访）。工具选型不靠嘴炮争论，按真实场景实测：出门稳定性、会话续接、Agent 状态可见性、非终端操作能力，哪一项不过关就换。

## 关键洞察

1. **规模是问题本身**：月 AI 订阅约 8000 元，主力同时跑 6 个 Agent（GPT / Claude / Google / OpenCode / DeepSeek / Grok）——每个模型各有长板（写后端、做游戏、写文案）；同时开发 App、做游戏、跑 4K 渲染、在美国云主机隔离环境防封号，不知不觉攒了 9 台电脑（Mac + Windows）。**前一个月桌前摆五块屏幕，一离开工位就干不了活。**
2. **最轻量的验证场景是发公众号**：手机开远程终端 → 连家里 Antigravity CLI → 底层调比较说人话的 Gemini 4 Neon，配写作 Skill → Agent 自动清洗口水话、出封面、配图 → 调蚁小二 CLI 推到公众号草稿箱 → 手机「订阅号助手」瞄一眼排版定时发。**散步时口述就把文章发了，不需刻意坚持。**
3. **UU 远程**：免费、国内直连极稳，偶尔使用强烈建议先试；但按传统远程桌面设计，9 台机切终端费劲，**最致命的是看不到哪个 Agent 还在跑、哪个已经干完**。
4. **Paseo（开源）**：局域网实测很顺，桌前终于不用五个显示器；出门就卡壳——国内移动网络不稳、得自建中继，且 9 台电脑 + 多台手机要两两手动配对十几次。
5. **T3 Code**：交互体验短期上乘，界面赏心悦目，同会话切不同 Agent 非常顺手；遥测争议作者认为「没收集什么隐私内容」，介意可加两个环境变量关掉（`T3CODE_TELEMETRY_ENABLED=false`、`T3CODE_OTEL_SDK_DISABLED=true`）。**短板是没有自带远程桌面**，看 App 模拟器、点网页等非终端操作还得切别的软件。
6. **Vibe42（付费主力）**：补齐前面几款短板——出门移动网络极稳、端到端加密、统一账号让 iPhone / 安卓 / 电脑无缝续接，刚在书桌前聊一半出门掏手机接着聊；自带远程桌面和文件浏览，看完终端输出顺手查产物。Pro 25 美元已支持连 10 台电脑；设备不多可选 8 美元（2 台）搭配免费 UU 远程。当前仍以终端为主，**下周上线 Chat UI** 会降低门槛。
7. **选型不站队**：作者的态度是「老黄出轨也不影响我用英伟达 GPU」——不看嘴炮争论只看产品；最后也明说，没有重度多 Agent 需求的人，开源 T3 Code 或免费 UU 远程就够用。
8. **两层网络的具体形态**：Vibe42 全球加密直连负责「人控机」，不依赖 Tailscale；Tailscale 私有局域网负责「机连机」——美国云主机专跑 Claude（隔离防封号）、本地 Mac 跑多 Agent、Windows 显卡机做渲染。组完内网后 Mac 可直接调 Win 显卡渲染视频、本地可调云端 Claude，**甚至让 Agent 自己挑一台空闲机器承接并发任务**。
9. **真正的收益不是「随时加班」**：而是不被周一到周五绑死——不用纠结哪天必须守在电脑前，**坐在洱海边只要有网，手头的事就不会断档**。

## 三款工具形态对照

| | T3 Code | Vibe42 | Paseo |
|---|---|---|---|
| 形态 | 原生 Chat UI + 手机审批 | 全功能终端 + 远程桌面 | 开源多主机轻量面板 |
| 交互 | 结构化对话流 + Diff/PR 面板，手机直接点同意/拒绝 | 左侧切主机与远程桌面，右侧产物预览 + 手机快捷栏 | 局域网统一管多主机 |
| 出门稳定性 | 作者未重点评价 | 极稳、端到端加密 | 移动网络不稳、需中继 |
| 门槛 | 低 | 终端形态，对普通用户偏高（将上 Chat UI） | 多机多手机两两配对繁琐 |
