# braindump

## 功能

将脑中模糊的想法快速倾倒为结构化文本，不要求完美，只要求"出来"。

## 使用方式

```
/braindump
```

## 核心思想

- **先倾倒，后整理**：不要一边写一边组织，直接把脑子里的一切倒出来
- **格式自由**：要点、句子、碎片都可以
- **LLM 帮你结构化**：第一轮输出后，让 LLM 帮你梳理逻辑、归类、提炼主题
