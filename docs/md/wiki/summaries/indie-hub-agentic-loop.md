## 核心洞察

Agent 系统不是单循环，而是**三个循环嵌套**：
- 推理循环：调用 LLM API，持久化聊天历史
- 工具循环：执行模型发起的工具调用
- 人类循环：审批或拒绝工具调用（最难点）

## 关键要点

1. **推理循环**：负责调用聊天补全 API + 把工具调用转交工具循环 + 持久化聊天历史。API 无状态，每次请求需带完整对话。

2. **工具循环**：模型生成的工具名和参数可能是编的（hallucination），需要防假调用；API 返回 tool_call_id 用于对应调用和结果。

3. **人类循环**：不是代码里的循环，而是审批者的决策过程。最难实现——代码无法真正阻塞，Temporal 等持久化框架解决此问题。

4. **三者关系**：推理→工具→人类，审批结果作为工具结果返回。三循环之上才能搭建 RAG、渐进式发现、工具自动审批等能力。
