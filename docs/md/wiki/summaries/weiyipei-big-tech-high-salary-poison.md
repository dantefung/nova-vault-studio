# 生姜Iris：大厂高薪毒药——为什么职级越高反而越不自由

> 一位前字节 3 开头职级员工的离职观察：大厂之所以是「高薪毒药」，不在于钱少，而在于高薪同时买走了「眼里有光」与对单块业务的 ownership——一年被迫换三次业务线、data-driven 的季度 OKR、缺少 blueprint 权限，最终让所有高职级的人退化成漂亮的白金螺丝钉，只有战略部门还保有全局视角。

<!-- more -->

## 核心结论

**「高薪毒药」不是抱怨薪水，是描述高薪的隐性成本结构。** 作者放弃了「很多很多钱」离开字节，理由不是待遇不好，而是**大厂的高薪是买断注意力与 ownership 的对价**：钱由组织出，代价是把自己变成分工极细、随时可替换、且无权思考全局的一颗螺丝钉。

更反直觉的一点是：**这不是新人/低职级的处境问题，而是职级越高越严重**。作者庆幸自己是 3 开头——这个位置恰好能同时观察到 2 开头与 4 开头的同事在做什么、精神状态如何；看完之后他的判断是「没觉得谁更自由」。

## 关键洞察

1. **「眼里没有光」是可观测的离职信号，不是主观感受**：作者在大厂聊过很多人，几乎每一个都很优秀，但眼里没有光。这与「很多人眼里明明没有光，却依然在大厂坚持」互为因果——高薪本身是让人留在无光状态里的原因。

2. **ownership 缺失的根因是业务线轮换频率**：如果一个人一年要被迫换三次业务线，就很难对任何一桩业务具备 ownership。频繁换赛道的人永远在重新开始，无法积累出「这块地是我 responsibility」的位置感。

3. **data-driven OKR + 无 blueprint 权限 = 战略层与执行层的断裂**：每季度 OKR 基本都是 data-driven、自上而下拆解的；关键在于——**自上而下的人其实都不具备对单个业务场景的 blueprint 权限**。没有「这件事该长什么样」的定义权，只有被分配的指标。

4. **沟通成本高到让人失去全局视角**：因为分工被切得太细，上通下达的沟通细节太多，**很多人也就没意识去思考全局了——或者说，本来也没有权限去思考**。这句是全文最狠的一句：不是想不到，是没资格想。

5. **只有战略部门保有全局视角**：结果是每天迷失在大量细节里，所以**大厂的战略部门是真的很关键**，而其他所有人——哪怕职级再高——基本也都是执行方。

6. **「白金螺丝钉」是对大厂资深员工最精确的描述**：做的工作都非常有意义，但自由和发挥空间有限；想执行一项策略，需要花更长的时间、更大的心力去布局，而且内部竞争是真的大。注意这里的反讽——「工作有意义」恰恰是让人继续留下的理由，也是不能离开的原因。

7. **大厂的自由是相对的幻觉**：3 开头能同时看见 2 开头和 4 开头的处境，结论是「没觉得谁更自由」。这说明在金字塔里向上找「更自由的层级」是无效策略——层级不改变组织机器的结构。

8. **作者的诚实收尾**：2025 年 2 月他就开始认真思考属于自己的 passion 是什么，并写下另一篇推文；**「此刻的当下，我依然有点迷茫」**。逃离不是终点，找到 passion 才是——但作者没有假装自己已经找到了。

## 结构性解释

```
高薪
 │
 ├─→ 吸引优秀人 → 竞争加剧 → 内部分工极细
 │                        │
 │                        ├─→ 一年换三次业务线 → ownership 缺失
 │                        ├─→ 上通下达沟通成本高 → 无全局视角
 │                        └─→ OKR 自上而下 data-driven → 无 blueprint 权限
 │                                                 │
 │                                                 ↓
 │                                    除战略部门外全是「执行方」
 │                                                 │
 └─→ 离开成本高  ← 钱与期权 + 履历 + 同辈比较          ↓
                                             漂亮的白金螺丝钉
                                              （工作有意义，但没自由）
```

## 适用边界与存疑

- **样本极小**：作者的结论来自个人在大厂的社交观察与自身经历，不是统计意义上的组织研究。「大厂就是高薪毒药」是修辞，不是定律。
- **高薪毒药有结构性前提**：作者所在的是分工程序化、极致分工的头部大厂（字节 3 开头职级）。小团队、创业公司、早期业务线的「大厂病」程度完全不同。
- **不构成离职建议**：作者本人并未说「所以你应该走」——他承认自己虽然走了却仍迷茫。真正的主张是「你得知道自己要什么」。
- **「战略部门关键」是组织现象描述**：从「只有战略部门有全局视角」可以推出「战略部门承受了全部的认知成本但收益归于系统」，但作者没有展开这一层。
