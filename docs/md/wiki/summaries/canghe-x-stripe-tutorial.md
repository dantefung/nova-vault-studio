# 苍何：X 认证 + Stripe 绑定实操教程

## 核心结论

将港卡开通、Stripe 账户创建、X 认证、X 绑定 Stripe 四步串成完整闭环。关键技巧：香港地址可用地址生成器填写，香港身份证件填护照号，产品或服务选「软件」类型，公开详情与商家网站名称保持一致。

## 关键洞察

1. **众安银行比汇丰更实用**：作者同时开了众安和汇丰，但为了不影响汇丰其他用途，先用众安绑定 Stripe。Wise 虽然方便但审核慢。
2. **W-8/W-9 证书必须补**：X 绑定 Stripe 后会提示缺少 W-8/W-9 证书，需在 Stripe 后台更新，Non-U.S. Taxpayer ID 填护照号。
3. **创作者工作室是入口**：X 内点「创作者工作室」→ 设置付款 → 连接 Stripe 账户。
4. **流程顺序**：先注册 Stripe → 再认证 X → 最后绑定两者。
5. **审核速度**：Stripe 审核通常 2-3 小时，快的十几分钟通过。

## 四步闭环

1. Stripe 账户创建（谷歌邮箱 + 香港 + Individual）
2. 港卡开通（众安银行便捷，汇丰备用）
3. X 身份认证（按苍何此前文章流程）
4. X 绑定 Stripe（创作者工作室 → 设置付款 → 输入邮箱连接）
