# AYi：2026 X 创作者收益开通完整教程

## 核心结论

X 创作者收益（接马斯克工资）的核心铁律是**名字一致性**：X 认证英文名、Stripe Legal Name、Wise/港卡持卡人姓名必须完全一致（全拼音、全大写）。90% 失败案例都死在这里。

## 关键洞察

1. **资格门槛**：需要 X Premium 蓝 V + 过去 3 个月有机曝光量 500 万 + 500 个 Premium 粉丝。账号需干净无违规。
2. **环境伪装是灵魂**：90% 卡在第一步的人都是环境问题——必须用美国住宅 IP（非数据中心）、手机语言改 English US、X 网页端语言改纯英文、全程无痕浏览器。
3. **Wise 比港卡更容易**：Wise 开户简单，推荐开港币账户费用更低。资金来源选"工资"，年收入选高档，大额到账后等 24-48 小时再提现避免风控。
4. **W-8BEN 必填**：连接 Stripe 后必须填写税务表格，美国税务居民选 No，Non-U.S. Taxpayer ID 填护照号，签名用英文全名。不填会被扣 30% 预扣税。
5. **结算规则**：累计满 10 美元开始结算，每两周一次；X → Stripe 即时，Stripe → Wise/港卡需 2-7 个工作日；Wise → 支付宝/微信几分钟。

## 七步流程

1. 准备资格（蓝 V + 500万曝光 + 500 Premium 粉丝）
2. 环境伪装（美国住宅 IP + 手机英文 + X 网页英文 + 无痕浏览器）
3. 身份验证（专用链接进入 → 拍照 → 人脸识别）
4. 收款准备（Wise 港币账户 或 港卡）
5. 连接 Stripe（创建新主体 → 香港 + Individual → 信息一致）
6. 填写 W-8BEN（降低预扣税从 30%）
7. 等待审核（几小时到两三天）→ 收益 Active

## 常见失败排查

- "地区不支持"：回去重做环境伪装，重点检查 IP 和网页语言
- "Unable to start verification"：蓝 V 没亮就去申请
- 身份证拍照失败：光线和反光问题，换白墙背景用后置摄像头
- 人脸识别不过：找窗户边光线足的地方，或换手机试试

## 残余风险

- 500 万有机曝光量门槛对大多数创作者不友好
- 住宅 IP 需稳定，廉价数据中心 IP 会被识别拒绝
- Wise 可能触发风控，需准备人工客服沟通材料
