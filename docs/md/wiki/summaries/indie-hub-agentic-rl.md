## 核心观点

长程 Agent 训练 = 执行循环（秒/分）+ 学习循环（步/时/天）+ 治理循环（更慢/更窄权限）。三者转速和权限必须不同，否则闭环会越来越容易通过。

## 关键要点

1. **长程关键**：前一步会改变后一步所面对的状态，不是轮数多就行

2. **训练环境四性**：可复现、可隔离、可重置、可回放。工具列表不等于训练环境

3. **轨迹 vs 聊天记录**：原始 Token/步骤边界/工具返回/环境版本/奖励归属/终止原因都要能对齐。避免 retokenization drift

4. **奖励拆分四本账**：结果+过程+副作用+成本，分开记录再讨论组合

5. **失败分六类**：能力失败/环境失败/基础设施失败/预算终止/安全拒绝/验证分歧。只有能力失败能直接变学习信号

6. **验证器也要对抗**：用故意破坏的实现攻击验证器，给每次评估绑定版本

7. **Horizon 渐进放长**：AgentGym-RL 发现大预算早期快后期坍缩，要先稳再晋级

8. **轨迹要带版本**：异步队列每条轨迹带策略版本/环境版本/验证器版本/生成时间

9. **Template Collapse**：RAGEN-2 发现输出流畅但推理越来越通用模板，要监控 Token 熵与输入相关性

## 五份合同

环境合同 + 轨迹合同 + 验证合同 + Rollout 合同 + 晋升合同
