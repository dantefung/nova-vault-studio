## 核心概念

外汇交易基本单元是**货币对**（Currency Pair），同时买入一种货币并卖出另一种货币。

## 关键概念速查

| 概念 | 解释 |
|------|------|
| **基础货币** | 斜杠左边，数值默认为"1" |
| **报价货币** | 斜杠右边，需多少单位换1单位基础货币 |
| **直盘** | 含美元的货币对（主要货币对） |
| **交叉盘** | 不含美元的货币对（次要货币对） |
| **点差** | Ask - Bid，经纪商的过路费 |
| **保证金** | 杠杆头寸的抵押资金，非手续费 |
| **滑点** | 成交价与预期价的差异 |

## 风险机制

- **Margin Call**：保证金不足，平台警告限制开仓
- **Stop Out**：保证金严重不足，系统强制平仓

## 滑点成因

1. 网络延迟
2. 市场波动性（重要数据/突发事件）
3. 流动性深度（大单超出挂单量）

**限价单可避免负滑点**
