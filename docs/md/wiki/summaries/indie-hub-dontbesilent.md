## 核心观点

dontbesilent 深度使用 Codex 的核心在于四层工作体系：任务层完成具体工作、工作流层让结果持续生效、方法层沉淀可复用规则、系统层用 AI 改造 AI 本身。他将每次交互转化为组织能力，构建出能自我迭代的个人 AI 系统，而非单纯依赖单次 Prompt。

## 关键数据

- 534 个会话，781 MB，9 个月
- 289 个明确用户发起的任务，1668 条用户消息
- 6797 次终端操作，703 次文件修改，88 次图片检查
- 569 条 Skill/Agent 相关消息（最高频主题）

## 四层工作体系

1. **任务层**：直接完成文件/数据/代码/视觉/内容任务
2. **工作流层**：结果进入固定目录/历史主库/下一步流程，脱离聊天窗口继续生效
3. **方法层**：沉淀成 Skill/SOP/脚本/模板/规则
4. **系统层**：用 Codex 维护知识真源、同步机制、Agent 边界和整个工作环境

## 关键设计

- **短 Prompt + 厚环境**：指令短小，完整背景由工作环境提供
- **SOURCE_OF_TRUTH.md**：解决「AI 找到冲突文件后该怎么办」，超越普通知识库
- **Skill 真源治理**：同一方法在多 Agent 中保持同步，避免版本漂移
- **递归改进**：用 Codex 改进 Codex 完成工作的方式

## 成本与治理

- Skill 太多会调用混乱，知识库太大会降低定位效率
- 持续清理无价值 Skill，压缩知识库导航，收回唯一真源
- 高风险操作建立权限、确认、备份和安全删除规则
