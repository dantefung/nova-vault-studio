# xianyu-auto-reply-fix

> 闲鱼智能客服系统，支持多账号管理、AI自动回复、自动发货确认、多渠道消息通知，提供完整的 Web 管理后台。AGPL-3.0 开源。

## 基本信息

- **Stars**: 1.4k
- **Forks**: 308
- **最新版本**: v2.0.1
- **协议**: AGPL-3.0
- **语言**: Python 63.3% / HTML 16.5% / JavaScript 16.3%

## 核心功能

| 模块 | 功能 |
|------|------|
| 多用户系统 | 邮箱注册、权限控制、数据隔离 |
| 多账号管理 | 多闲鱼账号独立运行、定时擦亮 |
| 智能回复 | 关键词匹配 + AI回复（多模型兼容） |
| 自动发货 | 卡券匹配、自动确认、延时发货 |
| 商品管理 | 自动收集、详情查看、多规格配置 |
| 运营协同 | 订单管理、消息通知、在线客服 |

## 技术架构

- **后端**: FastAPI + asyncio 异步编程
- **数据库**: SQLite 3 + 多用户数据隔离
- **自动化**: Playwright + DrissionPage 浏览器
- **部署**: Docker + Docker Compose + Nginx
- **通信**: WebSocket + SSE + RESTful API
