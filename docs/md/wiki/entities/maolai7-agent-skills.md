# maolai7/agent-skills

> 一个精心整理的 AI Agent 技能集合，帮助智能助手完成更多实用任务。MIT 协议开源。

## 基本信息

- **Stars**: 32
- **Forks**: 5
- **语言**: Python 59.9% / HTML 22.5% / Shell 8.7% / JavaScript 6.4%

## 技能列表

| 技能 | 描述 | 适用场景 |
|------|------|----------|
| scrapling-article-fetch | 智能抓取网页文章内容并转换为 Markdown，支持自动写入飞书文档 | 文章整理、内容归档、公众号文章提取 |
| md-to-wechat | 将本地 Markdown 文章渲染为微信公众号格式并一键推送到草稿箱 | 微信公众号发布、文章推送、内容同步 |
| wechat-watch | 微信公众号文章订阅与推送，定时轮询关注的公众号，检测新文章后推送到飞书 | 公众号订阅、文章监控、内容推送 |
