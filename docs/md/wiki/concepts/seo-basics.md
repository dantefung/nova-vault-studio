# SEO 基础：HTTP 协议、爬虫与外链

> 让做网站的知道：互联网怎么互联、爬虫怎么工作、为什么各平台外链数据不一样。

## 核心定义

互联网是实体（网线/光纤）和虚拟（链接）双重互联的网络。网站部署在服务器上，通过 HTTP 协议与客户端（浏览器/爬虫）通信。爬虫从已知网页出发，跟踪链接不断发现新页面。搜索引擎为每个网站分配爬虫预算，根据页面质量动态调整。

## 关键洞察

1. **互联网没有统一数据库**——所有网页分散在各服务器，爬虫是唯一发现手段。没有任何一家公司能说出全网的确切网页数量。

2. **爬虫独立运行导致数据不一致**——谷歌、Ahrefs 等各自爬虫独立运行，预算不同、抓取时间不同，导致各平台外链数据有差异。这是"Ahrefs 看到了但 GSC 看不到"的根本原因。

3. **爬虫预算决定网站可见性**——低质量页面被爬后无排名 → 谷歌调低预算 → 不再爬新页面 → 已索引页面也可能被删。这是一个负反馈循环。

4. **AI 搜索不自建爬虫的经济原因**——爬遍全网成本天价，ChatGPT 等选择用 Bing/Google 搜索接口。OpenAI 的爬虫只用于定向抓取高质量内容做训练集。

5. **后端渲染 vs 前端渲染**——后端渲染一次性返回完整 HTML（爬虫友好），前端渲染分两步（先返回骨架 + JS 再异步加载内容），爬虫可能无法执行 JS 导致内容不可见。
