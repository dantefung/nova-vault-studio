# Vibe Coding（氛围编程）

> 用自然语言和 AI 快速构建功能原型，无需深度技术背景的编程方式。

## Key Points

- 用自然语言描述需求，AI 生成代码
- 降低编程门槛，让非技术人员也能参与开发
- 快速原型验证
- 与传统编程互补，非替代关系

## Details

Vibe Coding 强调用自然语言与 AI 协作，快速将想法转化为可运行的代码。核心工具包括 Claude Code、Cursor、Codex 等 AI 编程助手。

### 相关工具和资源

- **Vibe 规则**：通用开发规则和最佳实践
- **Vibe Prompts**：常用的编程提示词模板
- **Linus Principle**：代码质量原则
- **Code Quality**：代码质量检查
- **Clean Code**：整洁代码实践
