# AgentLoop：阿里云 Agent 观测与 Skill 评估优化平台

> AgentLoop 是一套以数据驱动方式交付高质量 Agent Skill 的完整闭环平台——用可观测数据感知现状，用离线实验量化质量，用 Bad Case 驱动优化，用评分趋势验证效果。

## 核心定义

**AgentLoop** 是阿里云的 Agent 观测与优化平台，提供从 Skill 创建、可观测接入、离线评估、Bad Case 分析到迭代优化的全生命周期工具链。核心价值在于让 Skill 的质量提升变得可量化、可追溯、可验证。

## 关键洞察

1. **Skill 优化的本质是闭环迭代**：创建 → 观测 → 评估 → 优化 → 验证 → 发布，形成持续的评分提升循环。每次修改有评分验证，每次迭代朝达标迈进。

2. **对比实验量化增量价值**：始终运行"有 Skill vs 无 Skill"对照，量化 Skill 的真实效果，判断普适性和模型升级后的有效性。

3. **Skill + Harness 双线并行**：Skill 解决"Agent 应该做什么"，Harness 解决"Agent 不能做什么"——输出过滤、错误处理、行为约束在 Agent 外层包装。优化效果依赖 Harness 工程与模型能力。

4. **AI 辅助优化加速安全约束**：将 Bad Case 交给 AI 分析根因并提建议，人工审核后生成新版本，对安全约束类优化效率极高。

## 六步闭环流程

| 步骤 | 核心任务 | 输出 |
|------|---------|------|
| ① 创建 Skill | 定义 Prompt 指令、工具规范、输出约束、安全边界 | 草稿 Skill |
| ② 可观测接入 | 探针自动采集执行数据，Trace Span 记录 | 执行大盘 |
| ③ 离线实验 | 数据集 + 评估器 + 对比实验 | 多维度评分报告 |
| ④ Bad Case 优化 | 筛选低分 Case → 根因分析 → AI 辅助优化 | 新版本 Skill |
| ⑤ 迭代验证 | 版本对比 + 评分趋势 + 回归检测 | 评分持续提升 |
| ⑥ 发布上线 | 达标后发布，持续观测触发新一轮迭代 | 正式 Skill |

## 评估体系

8 个内置评估维度：任务完成度、回答证据支持度、工具调用成功率、工具选择合理性、执行步骤效率、安全性、幻觉检测、正确性。

数据集设计原则：覆盖真实业务场景、正反例兼顾、可验证性。初始建议 10-20 个核心场景。
