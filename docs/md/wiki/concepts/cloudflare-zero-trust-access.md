# Zero Trust Access：永不信任，始终验证

零信任（Zero Trust）是一种网络安全范式，核心原则是**永不信任，始终验证**——无论用户在内网还是外网，每次访问资源都必须验证身份和权限。

---

## 核心概念

### 传统城堡模型 vs 零信任模型

**城堡模型**：外层有防火墙（护城河），一旦用户通过认证进入内网，就被完全信任，可以访问任意资源。

**零信任模型**：每个请求都要经过身份验证 + 权限检查，用户在网络层面没有固有信任。

### 零信任三要素

| 问题 | 答案 |
|------|------|
| 你是谁？ | 身份验证（Who are you） |
| 你能干什么？ | 权限检查（What can you do） |
| 为什么我要信你？ | 持续验证，不依赖网络位置 |

### Cloudflare Access

Cloudflare 提供免费版（50 用户）的零信任访问控制方案：

- **无需自建 SSO 服务器**：配置几步即可
- **无感登录**：用户登录一次获得 token，在有效期内访问所有受保护应用无需重复登录
- **随时吊销**：管理员可实时吊销任意用户的访问权限
- **工作原理**：反向代理拦截请求 → JWT 验证 → 策略引擎决策 → 资源访问

**国内类比**：阿里云 IDaaS、腾讯云身份管家（通常需要付费或绑定企业版）

---

## 关键机制

- **JWT Token**：无状态令牌，有效期内可访问受保护资源，管理员可远程吊销
- **反向代理**：Cloudflare 边缘节点拦截所有请求，在到达源站前完成身份验证
- **策略引擎**：基于用户身份、设备状态、地理位置等条件判断是否放行
