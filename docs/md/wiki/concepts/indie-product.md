# 独立产品方法论 (Indie Product)

> 独立开发者通过「用户群体、产品形态、收费模式」三维度找到「官方不管、用户很痒、有人愿意付钱」的需求，以最小成本验证并变现。

## Key Points

- 核心框架：用户群体（选有人离不开的平台）× 产品形态（挑上架难度扛得住的）× 收费模式（刀法精准）
- 大厂只顾做大全，「官方懒得管、用户又很在意」的环节就是留给个人开发者的机会
- 产品形态从轻到重：浏览器插件 → 网站 → 安卓 → 小程序 → 苹果商店
- 定价策略：有竞品就扒竞品价格锚，没竞品就从功能点切，基础免费进阶付费
- 收款系统可以后补，用最笨的方式（加微信转账）先验证需求

## Details

### 用户群体：选有人离不开的平台

围绕一个正在起飞的平台「卖铲子」是经典策略。以 Codex 生态为例，5 种切入商机：
1. **补能力**：Codex 不擅长的写作、设计、出图、排版、发布，做成 Skill 补上
2. **做配套插件**：剪辑视频、长文写作、图片制作插件
3. **卖现成品**：装好就能跑的 Skill 包、工作流、模板
4. **做认知差**：新平台教程、拆解、陪跑变现
5. **蹭分发**：GitHub、skill 商店等开源渠道自然分发

### 产品形态：挑上架难度扛得住的

| 形态 | 上架难度 | 特点 |
|------|----------|------|
| 浏览器插件 | 最轻 | 审核松、上线快、可内置收费 |
| 网站 | 自由 | 流量从零自己搞 |
| 安卓 | 中等 | 国内商店多且杂，可脱离商店内置收费 |
| 小程序 | 偏重 | 微信审核严、规则多、平台抽成 |
| 苹果商店 | 最重 | $99/年、审核严、内购抽三成 |

### 收费模式：刀法要精准

定价两条笨办法：有竞品扒竞品，没竞品从功能点切。结构上分三档：免费（兜底）、月度、年度（折扣锁长期）。收款方式可以后补，先验证需求。
