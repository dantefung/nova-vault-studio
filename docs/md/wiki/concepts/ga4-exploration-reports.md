# GA4 探索报告

> GA4 探索报告是一个高度可自定义的分析工作区，提供 7 种核心分析方法，帮助回答标准报告无法直接回答的问题。

## 核心定义

GA4 探索报告允许用户自行组合维度、指标、细分、筛选条件和可视化方式，构建自定义分析逻辑。

**重要约束**：
- 探索数据存在处理延迟，不适合实时监控
- 明细数据范围受数据保留期限限制（默认较短，需手动设置）
- 适合：自定义分析逻辑、比较人群、深入拆解行为

## 7 种探索类型

| 类型 | 适合场景 | 核心问题 |
|------|----------|----------|
| 自由形式 | 横向比较渠道、设备、页面、国家 | 哪些渠道流量大但转化差？ |
| 漏斗探索 | 已有明确转化流程 | 注册流程在哪一步流失最严重？ |
| 路径探索 | 不预设完整流程，观察真实行为 | 购买前的最后一步是什么？ |
| 细分重叠 | 判断不同用户群是否重合 | 高价值用户和社媒用户是同一批人吗？ |
| 用户分层图表 | 查看匿名用户事件序列 | "加购未购"用户卡在哪里？ |
| 同类群组探索 | 比较同批用户后续表现 | 新版本上线后留存是否改善？ |
| 用户生命周期 | 比较不同渠道的长期价值 | 哪些渠道用户长期价值更高？ |

## 细分 vs 对比项 vs 筛选条件

这是探索报告中最常被混淆的三个概念：

- **细分（Segment）**：定义用户子集，可保存并在多个探索中复用
- **对比项（Comparison）**：在当前视图中拆分对比，仅当前视图生效
- **筛选条件（Filter）**：过滤数据范围，仅当前页签生效

## 数据保留设置

设置路径：管理 → 媒体资源设置 → 数据收集与修改 → 数据保留

建议尽早设置为最长可用期限。调长期限后，尚未被删除的历史数据可适用新设置；已经被删除的明细数据无法恢复。
