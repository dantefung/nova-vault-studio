# 月入 10 万美元 App 点子验证法

> 把握三个点找到赚钱的 App 点子：用户已经在搜了吗？关键词还有机会打吗？同类产品已经有人付费吗？

## 三个核心判断

1. **用户已经在搜了吗** — 有真实搜索需求，不是凭空想象
2. **关键词还有机会打吗** — 热度够高、竞争够低，新 App 有入口
3. **同类产品已经有人付费吗** — 搜索兴趣不等于付费意愿，同行已验证收入

## 六步操作流程

### 第一步：Google Trends 找正在变火的需求

看趋势方向，绝对搜索量放到后面判断。一个词如果快速往上走且未明显见顶，就值得继续挖。

第一轮看两件事：
- 需求是否持续上升（不是短期新闻/梗/节日热点）
- 上升是否与真实用户行为有关

要找的是**可以做成产品的需求**，不只是可以写一条内容的热点。

### 第二步：Rising Queries 找更窄的入口

大词显示方向变热，小词（用户具体搜什么）才告诉你从哪里切进去。新 App 更适合小词切入。

优先看三类：
- **带人群的词**：women、beginners、over 40、students
- **带目标的词**：abs、weight loss、posture、meal prep
- **带场景的词**：at home、no equipment、after pregnancy、for busy people

切入点越具体，越容易写清 App Store 标、截图、onboarding 和 paywall。

### 第三步：ASO 看关键词能不能打

- 热度 > 20：说明有人搜
- 难度 < 60：说明还没被大 App 占死

**更好的组合**：中高热度 + 中低难度——用户已在找，但供给还不够强。

### 第四步：Sensor Tower 看有没有真实收入

搜索兴趣不等于付费需求。同类 App 没收入 → 可能是伪需求；同类 App 赚钱 → 才可能是产品机会。

判断信号：
- 同类 App 是否稳定有收入
- 头部 App 收入是否明显增长
- 收入是否集中在少数老产品手里
- 用户到底在抱怨什么
- 现有产品有没有明显做得差的地方

### 第五步：三个信号都过，做第一版

趋势在涨 + 关键词能打 + 同类产品已赚钱 = 需求窗口出现。

**通用做法**：
1. 下载头部竞品
2. 把 onboarding 每屏截图
3. 丢给 Claude 分析
4. 让 Claude 设计更好的流程
5. 按一屏一屏拆出新版 onboarding
6. 用熟悉的工具做第一版

分析提示词：

> 我想做一个面向「具体人群」的「具体目标」App，下面是 3 个竞品的新手流程截图，请你帮我做 4 件事：第一，拆出每个竞品的新手流程顺序；第二，指出每一步在解决什么用户心理；第三，找出哪里可能导致用户流失；第四，重新设计一个更短、更适合转化付费用户的 onboarding，按屏幕输出。输出时按 Screen 1、Screen 2、Screen 3 写，每一屏包含标题、正文、按钮和用户看到这一屏后的心理预期。

### 第六步：第一版要快

需求窗口刚开始涨时，不要花 6 个月打磨。第一版只需要：

- 一个能解决核心需求的功能
- 一个能承接搜索词的 App Store 页面
- 一个能解释结果的 onboarding
- 一个能测试付费意愿的 paywall
- 基础埋点和订阅

**七天冲刺**：
| 天 | 任务 |
|----|------|
| 1 | 列 20 个熟悉领域里的增长词 |
| 2 | Google Trends 看哪些词在上升 |
| 3 | Rising Queries 找 5 个更窄切口 |
| 4 | ASO 工具看热度和难度 |
| 5 | Sensor Tower 看同类 App 收入 |
| 6 | 选一个三项都过的方向，拆 3 个竞品 onboarding |
| 7 | Claude 生成新版流程，开始做第一版 |

## 适用方向

小型消费 App、工具 App、健身/效率/外貌/习惯类 App。
