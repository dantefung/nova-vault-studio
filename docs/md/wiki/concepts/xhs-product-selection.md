# 选品七看（小红书虚拟商品）

> 冬青提炼的小红书虚拟商品选品方法论：七个观察维度 + 两个量化指标，帮助判断一个商品值不值得做。

## 七个观察维度

1. **看做了多久**：更关注短时间内起来、最近还在出单的品，而非累计销量高但近期静止的
2. **看笔记效率**：100篇笔记卖1000单 > 1000篇笔记卖1000单——前者为什么用更少内容拿到同样成交？
3. **看爆品值**：爆品值 = 累计已售 ÷ 今日销量增量，越小越值得先看（近期动量占比高）
4. **看商品价值**：商品价值 = 客单价 × 今日销量增量 × (今日销量增量 ÷ 累计已售)，同类里越大越优先
5. **跟着时间走**：假期安全教育PPT→开学；毕业、节日、年终汇报都是时机窗口
6. **搜竞争密度**：一家卖得好 ≠ 市场上只有他，要看价格/内容/动销差异
7. **别把没人做当蓝海**：高中教师资料就是反例——老师有自己的课件和题库，通用资料未必需要

## 两个量化指标

### 爆品值（越小越好）

```
爆品值 = 累计已售 ÷ 今日销量增量
```

累计卖10000今日增100 → 爆品值100（近期动量弱）
累计卖2000今日增100 → 爆品值20（近期动量强，优先看）

### 商品价值（越大越好）

```
商品价值 = 客单价 × 今日销量增量 × (今日销量增量 ÷ 累计已售)
```

综合了价格、当天增量、近期增量占比三个维度。

## 配套监控软件

冬青开源了"红薯雷达"开发提示词：[github.com/dong-liudong/hongshuleida](https://github.com/dong-liudong/hongshuleida/blob/main/dq.md)

原理：每隔一小时读指定商品的累计销量，两次差值即增量。关键坑点：只显示"1万+"的商品不能硬算精确日销量；采集失败不能当成零，否则下次成功会凭空算出大量销量。
