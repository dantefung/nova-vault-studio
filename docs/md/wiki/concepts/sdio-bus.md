# SDIO 总线：硬件原理

> SDIO 是 SD 接口的超级进化版，不只能存数据，还能接外设。嵌入式世界里"低调的实力派"。

## 核心定义

SDIO（Secure Digital Input Output）是在 SD 卡标准基础上扩展出的外设接口协议，复用 SD 的物理接口，但用途从存储扩展到连接 Wi-Fi、蓝牙、GPS、NFC 等各种外设模组。

## 关键洞察

1. **SDIO 是 SD 的"功能扩展"，不是新的存储规范**——它复用 SD 物理接口，但连接的是外设而非纯存储卡。这是理解整个协议的关键起点。

2. **主从架构，CLK 永远由 Host 产生**——Card 永远不会自己产生时钟，这是设计所有时序逻辑的基础。

3. **1-bit vs 4-bit 速率差 8 倍**——4 条数据线 × 时钟频率翻倍。初始化阶段必须用 1-bit，识别完成后再协商切换到 4-bit。

4. **CMD5 是区分 SDIO 与纯 SD 卡的关键**——SDIO 独有命令，用于查询 I/O 功能，SD 存储卡没有这一步。

5. **初始化时序必须低速起步**——初始化期间时钟控制在 400kHz 以内，完成后再提速到 25/50 MHz。这是硬件调试最常见的坑。

## 硬件设计要点

- **上拉电阻**：CMD 和 DAT0~DAT3 接 10kΩ~47kΩ 上拉到 VDD；CLK 不需要
- **走线**：DAT 和 CMD 与 CLK 等长（±5mm），CLK 保持 50Ω 阻抗连续
- **ESD 保护**：热插拔场景必须加
- **调试**：逻辑分析仪抓 CLK / CMD / DAT0 三根线
