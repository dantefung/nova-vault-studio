# 哥飞 SEO 教程：关键词优先的网站结构规划

> 先收关键词，再看搜索量和搜索意图，最后规划网站结构——而不是先做首页再想关键词。

## 核心定义

一种**关键词驱动**的网站结构规划方法：先通过多入口收集关键词，用谷歌 Ads 和趋势补搜索量，按意图分组，再分配页面类型生成 URL 清单。网站结构背后是对用户需求的理解，而非导航栏的美观。

## 八步流程

| 步骤 | 任务 | 关键点 |
|------|------|--------|
| 1 | 多入口收集关键词 | 谷歌下拉/趋势/Similarweb/Semrush/Ahrefs/Ads 工具 |
| 2 | 补搜索量 | 用谷歌 Ads 关键词规划工具，同义词用趋势对比 |
| 3 | 清理词表 | 删不相关词，合并同义表达，标记优先级 |
| 4 | 按意图分组 | 生成类/修复类/风格转换类/具体场景类 |
| 5 | 分配页面类型 | 首页/工具页/栏目页/文章页 |
| 6 | 生成 URL 清单 | 给 AI 关键词表+意图分组+产品能力 |
| 7 | 人工删减 | 删重复页面和薄页面 |
| 8 | 先做 5-10 页 | 选最有把握的页面先做 |

## 四个常见坑

| 坑 | 说明 |
|----|------|
| 只追搜索量 | 大词看竞争、页面类型、自身能力 |
| 同义词拆太多页 | 需求一样放一页，避免薄页面 |
| 只做文章页 | 工具站核心是工具，不是文章 |
| 不做内链 | 页面之间要有关系，便于用户和谷歌理解 |
