# AI 小应用模板化创建（占位符 prompt 框架）

> **创建 AI 小应用就像后台添加一篇文章一样简单**。

## 一句话定义

把 AI 应用开发**降维成"写 prompt 模板"**：用 `[input1] [input2]` 等占位符把 prompt 抽象成可复用模板，后台填 5 个字段（应用名/简介/角色/输入提示/字段数），**几分钟上线一个独立站**。把"多写爆款"的自媒体逻辑应用在 AI 应用上——**批量测试、爆一个就值回所有成本**。

## 4 个核心机制

### 1. 占位符模板化 prompt

**核心机制**：prompt 里需要的变量用 `[inputN]` 占位符，前端收集用户输入替换占位符。

**经典案例（鲁迅体写作）**：

```plaintext
结合 [input1] 的风格写 [input2]
```

用户输入：
- input1 = "鲁迅"
- input2 = "姜萍事件"
- → 输出"鲁迅体姜萍事件分析"

### 2. 5 个关键字段（最少配置）

| 字段 | 作用 |
|------|------|
| **应用名称** | 标题，如"鲁迅体写作" |
| **简介** | 描述 |
| **角色设定**（system prompt） | 大模型扮演的角色 |
| **用户输入提示** | input placeholder |
| **输入字段数** | 1/2/3 个 input 字段 |

> 这样：一个 AI 应用 = 5 字段 + 1 个 prompt 模板。

### 3. 后台内置"SEO 专员"AI

> 后台配备了一个"SEO 专员"角色的 AI——它可以根据创建应用时填写的相关信息，给出 SEO 最佳方案并直接覆盖对应字段。

**自动 SEO + 多语种 → 一键上线全球版**。

### 4. 单交互 vs 多轮对话

| 形态 | 复杂度 | 适用范围 |
|------|--------|---------|
| **单交互** | 1 个 [input1] | 90% 场景（写作助手/图像生成/单一任务）|
| **多轮对话** | 多个 input 或 chat 模式 | 心理咨询/多步流程 |

**优先做单交互**：最简单、最快上线、最易传播。

## 5 类应用模板速查

| 类型 | 占位符形式 | 案例 |
|------|----------|------|
| **文本类** | 风格 + 主题 | 鲁迅/史铁生/海明威 体写作 |
| **图文类** | 主体 + 风格 | 动物 × 超级英雄 |
| **翻译类** | 源文 + 风格 | 翻译 + 目标风格 |
| **代码类** | 需求 + 语言 | 自然语言转 SQL/Python |
| **视频类** | 主题 + 风格 | 文字转风格化视频 |

## 4 个核心优势

### 1. 多写爆款的复利逻辑

> 这种感觉，就有种自媒体写爆款文章一样，**多写，爆一个就有很高的回报率**。

**优势量化**：

- 单应用成本 ≈ 一篇公众号（30 分钟）
- 10 个应用 = 5 小时
- 1 个爆款 = 可能 6 位数回报

### 2. 「灵活到极致」的标准

| 标准 | 含义 |
|------|------|
| 创建简单 | 像写文章一样 |
| SEO 自带 | 后台 AI 自动 SEO 优化 |
| 多语种标配 | 自动生成 N 语种版本 |
| 失败无成本 | 没人用也无事 |

### 3. "复制各平台智能体"的快速冷启动

> 各平台上每一个有意思的智能体，你都可以"复制"一份快速上一个小应用。

**好处**：

- **Coze / 豆包 / 智谱** 等平台有现成的爆款智能体
- 看到哪个火 → 复制 prompt → 5 分钟上线独立版
- 自然传播数据已证明有效

### 4. 流量 + 付费一目了然

> **只要你能调教出效果合适的 prompt，好处是易于传播，只要有意思，用的人多，无论从流量还是付费都能马上看到结果**。

**变现路径**：

```
独立应用 = 独立 URL = 独立流量
    ↓
调用量 = 流量指标（直接看数据）
    ↓
付费路径短（订阅/单次/打赏）
    ↓
ROI 立刻可见
```

## 4 步上手流程

```
第 1 步：搭迷你后台（5 字段 + SEO AI + 多语种引擎）
        ↓
第 2 步：设计 prompt 模板（[input1] [input2] 占位符）
        ↓
第 3 步：前端做 1 个 input 表单（最简）
        ↓
第 4 步：自部署到独立站 → 批量复制 N 个
```

## 占位符设计 3 条铁律

1. **简单优先**：1 个 [input1] 能解决，就别用 [input1][input2]
2. **主变量在前**：[input1] 是核心变量，[input2] 是修饰
3. **嵌套谨慎**：避免 `[input1.title]` 这种深层嵌套

## 适用场景矩阵

| 场景 | 适合吗 | 原因 |
|------|--------|------|
| **垂直写作助手**（鲁迅体）| ✅ 完美 | 单交互、强传播、强付费 |
| **角色扮演聊天** | 🟡 中 | 需要多轮，更适合 ChatGPT 类平台 |
| **复杂调研报告** | ❌ 不适合 | 需要持久上下文，超出占位符能力 |
| **图像/视频生成** | ✅ 完美 | 一个 prompt 搞定，input 即 prompt 子串 |
| **代码生成** | ✅ 完美 | input 即规范说明，AI 输出代码 |
| **教育/练习** | ✅ 完美 | input 是练习题/主题 |

| 方向 | 占位符形态 | 爆款逻辑 |

| **儿童故事** | 主角 + 主题 | 给小朋友讲睡前故事 |

## 与 Prompt 工程的进阶关系

| 范式 | 表达 | 适合 |
|------|------|------|
| **Prompt** | 自然语言 | 个人使用 |
| **Multi-shot Prompt** | 多个例子 | 个人使用 |
| **Chain** | 多个 prompt 串联 | 自动化 |
| **占位符模板**（本篇）| [input1] [input2] | **应用化、规模化** |
| **Agent** | 自主动作 | 复杂任务 |

**占位符模板的位置**：是从「写 prompt」到「规模化分发 prompt」的**关键中间层**。
