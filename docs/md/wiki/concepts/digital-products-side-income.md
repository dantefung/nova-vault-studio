# 数字产品副业模式

> 数字产品（Digital Products）副业：一次制作、多次售卖、跨境套利，边际成本趋近于零的轻资产模式。

## 定义

数字产品指 PDF、AI Prompt 模板、工作流、表格、教程、资料包等可复制的电子文件。核心特点是"一产多销"——制作一次，无限复制，国内外市场同时变现。

## 核心洞察

1. **跨境价差套利**：同一份内容国内卖 19.9 元，英文版国外卖 9 美元（约 65 元），3x+ 价差源于汇率 + 购买力差异
2. **平台分层**：
   - 新手起步 → Gumroad（有平台流量，手续费高）
   - 独立站 SEO → Payhip（费用低，无流量，适合内容站）
   - 品牌化 → Sellfy（月费制，更像商城）
   - 社媒引流 → Stan Store / Beacons（移动端优先）
3. **最轻结构**：网站做内容 + SEO 导流 → Payhip 处理收款/自动发货/税务，无需自己搭建支付系统
4. **国内替代方案**：小红书限制虚拟资料，可用链动小铺（pay.ldxp.cn）开店，开通个人支付宝/微信收款

## 适用场景

- 开发者：卖 Prompt 包、代码模板、Workflow 配置
- 创作者：卖 PDF 教程、电子书、模板
- 跨境卖家：内容翻译 → 海外平台双倍变现
