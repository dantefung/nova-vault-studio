# 七条准验的识人技巧

结合古籍名言、社会观察与心理学知识的识人技巧。

## 1. 利他话术背后的利己动机

嘴上说"我这都是为了你好"的人，往往是打着利他的旗号完成利己动作。

清代陈洪谋《养正遗规》："财不足则多谋，食不足则多虑，威不足则多怒，性不足则多言，名不足则多长，礼不足则多变。"

**核心：一个人越急于表现什么，就说明他内心越缺乏什么。**

## 2. 看透真话要看行动不要听说话

看清一个人，永远不要看他怎么说，而要看他怎么做。

网上劝年轻人躺平的大V，自己一天更新3条视频、连做2场直播——**屁股决定脑袋，利益在哪里立场就在哪里**。

## 3. 重复话术往往伴随着谎言

反复、高频强调某句话，大概率是谎言。重复说话是潜意识强化可信度，越是刻意强调可信度，恰恰说明内心越心虚。

## 4. 即时礼尚往来的人：适合合作但不宜深交

今天请喝奶茶，明天一定要还咖啡——不贪便宜、有原则、讲规矩。

但内心建有防御墙，很难真正走进成为知心朋友。**适合做生意合作伙伴，不适合做闺蜜兄弟。**

## 5. 凡事自己解决的人：内心极度强大

遇到困难第一反应是自己想办法解决，从不麻烦别人。

真正享受独处、在孤独中感到舒服的人，内心极度强大。
