# SEO + AdSense 优化：从 800 到 2000 美元/月

## 一句话洞察

网站收入提升三板斧是**技术性能 + 站内 SEO + 广告位布局**，三者协同发力。技术优化解决流量承接（让用户打开快），SEO 解决流量获取（让搜索引擎多收录），广告位解决流量变现（让每个 PV 产生更多收入）。

## 改版前后对比

| 维度 | 改版前 | 改版后 |
|------|--------|--------|
| 技术框架 | PHP 直接渲染 + 循环查库 | CodeIgniter MVC |
| 加载速度 | 慢 | 快 |
| 页面类型 | 首页/分类/详情 | + 标签页/作者页/搜索页 |
| 每页广告位 | 1 个 | 3 个（Google 推荐上限） |
| 月收入 | 874 美元 | 2100 美元 |

## 核心方法论

### 1. 技术性能优化

- 使用 MVC 框架，避免渲染时循环查询数据库
- 分离下载服务器和网站服务器
- 改版时必须保持 URL 一致（已被搜索引擎收录）

### 2. 站内 SEO

每个页面类型有独立的 title/description 格式：

| 页面类型 | 标题格式 | 描述格式 |
|---------|---------|---------|
| 首页 | 网站名称 + slogan | 网站描述 |
| 分类页 | {分类名称}-网站名称-slogan | {分类名称}类…… |
| 详情页 | {书籍名称}-网站名称-通用关键字 | {书籍名称}是{作者}的作品…… |
| 标签页 | 标签:{标签名称}-网站名称-slogan | — |
| 作者页 | 作者名称聚合 | 作者描述 |

每个页面 h1 标签明确标识页面核心内容。

### 3. AdSense 广告位优化

- 每页放满 3 个广告位（Google 推荐上限）
- 新增页面类型（标签页、作者页、搜索页）增加总 PV
- 广告展示 = 浏览量 × 广告位数量

## 增长飞轮

```
技术优化 → 承接所有流量 → UV 涨
+ 新增页面类型 → PV/UV 比例涨
+ 广告位增加 → 广告展示涨
+ SEO 优化 → 搜索排名上升 → 更多流量
= 收入暴涨
```
