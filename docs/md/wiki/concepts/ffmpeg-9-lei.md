# FFmpeg 9.0 代号 Lei

> FFmpeg 9.0 以中国开发者雷霄骅（Lei）命名，新增 ONNX Runtime DNN 后端和 GPU Execution Provider 支持，强化了作为 AI 时代多媒体基础设施的地位。

## Key Points

- FFmpeg 9.0 代号「Lei」纪念 2016 年离世的中国音视频开发者雷霄骅（26 岁）
- 新增 ONNX Runtime DNN 后端 + GPU Execution Provider，让图像处理模型更直接进入滤镜链
- 创始人 Fabrice Bellard 是传奇程序员（QEMU、QuickJS、圆周率世界纪录）
- 26 年历史，从 0.x 到 9.0，从 CPU 到 NVIDIA/AMD/Intel/Apple/Vulkan/VideoToolbox
- AI 时代核心基础设施：大模型不认识 MP4，FFmpeg 负责解码→张量

## Details

### 版本代号谱系

FFmpeg 近几代版本号以科学家/工程师命名：3.0 Einstein → 4.0 Wu（吴健雄）→ 5.0 Lorentz → 6.0 Von Neumann → 7.0 Dijkstra → 8.0 Huffman → 9.0 Lei

### 雷霄骅的贡献

CSDN 博客 900+ 篇 FFmpeg 中文教程，GitHub 30 个公开仓库（播放器、推流器、VideoEye 码流分析工具），被中国音视频开发者称为「雷神」。他留下的内容已成为中文 FFmpeg 学习路径的一部分。

### AI 基础设施

FFmpeg 在 AI 流水线中承担数据预处理角色：视频模型训练的解码/抽帧、语音模型训练的音频提取/重采样、AI 视频生成的拼片/编码、数字人配音的时长对齐/混音。Whisper 直接依赖 FFmpeg 做音频解码。
