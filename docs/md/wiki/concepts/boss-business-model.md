# 招聘信息分析：用 BOSS 直聘做商业模式研究

> BOSS 直聘不是招聘软件，而是一个免费的商业模式数据库。一家公司招什么人，说明它现在最缺什么环节。

## 核心定义

通过分析招聘岗位的类别、数量、薪资和任职要求，反向推断公司的商业模式、发展阶段和核心痛点——招聘信息是公司最诚实的"体检报告"。

## 关键洞察

1. **招聘信息是"实时带价"的行业数据**——比行业报告更新快，而且带具体的薪资范围，反映市场真实供需。

2. **岗位类型暴露商业模式**：
   - 大量招私域运营 → 靠流量和转化吃饭
   - 大量招课程顾问/销售 → 增长靠销售体系驱动
   - 大量招交付老师/客服 → 前端获客已跑通，急补后端服务

3. **横向对比 20+ 家公司即可拼出行业地图**——获客方式、成交路径、交付模式一览无余。

4. **局限性**：长年招聘可能是留不住人而非扩张；高薪资可能对应高强度。需结合官网、产品动态、员工评价交叉验证。
