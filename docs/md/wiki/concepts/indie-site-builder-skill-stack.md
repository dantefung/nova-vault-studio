# 独立网站出海创业能力栈（Indie Site Builder Skill Stack）

独立网站出海 = 用 12 个能力模块（需求/SEO/开发/数据分析/支付/流量/外链/ads/产品设计/工具/部署/复盘）组装出一台月入万美元的"个人商业机器"。**SEO 模块文章密度最高（约 35 篇）**，反映独立站流量高度依赖搜索引擎的本质。

## 关键洞察

### 1. SEO 是最大战场 = 独立站的命门

约 35 篇 SEO 文章 + AI 时代新变量（GEO = Generative Engine Optimization）。

GEO 三件套：
- **让网站被 AI 引用**（ChatGPT/Perplexity/Claude 引用的概率）
- **结构化内容**（Wiki 风格的事实卡片）
- **做 "AI 答案供给者"** 而非 "传统搜索结果"

### 2. AI 工具是基础设施，不是单点

droidHZ 的文章里 AI 渗透到了每一个模块：
- 需求挖掘：grok 监测新词、AI 找需求导航站
- SEO：AITDK 内容生成、爬虫参考 SEO、GEO 监测
- 开发：Claude Code 命令/技能封装、AI 编程
- 数据分析：AI 看录屏、AI 帮你查数据
- 产品设计：claude design 站、Stitch

**哲学：AI 是新基建，要嵌入到每一环。**

### 3. 跨境合规闭环 = 基础门槛

完整路径：**香港银行 → 香港 Stripe → 水星银行 → 美国 LLC → PayPal → Stripe → Creem**。

任何做独立站的个人都必须打通这条线，**否则再好的流量也无法变现**。

### 4. 心态 = "种树故事"

> "网站出海就是一个种树的故事，浇水施肥，静待开花结果。"

1 年稳定万刀不是异常速度，是正常节奏。但前提是**不停浇水，不问何时开花**。

### 5. 复盘模块的隐藏价值

复盘 > 14 篇专门文章，包含：
- levelsio 月入 21 万美元的方法分析
- 哥飞/彪哥/壹树三人的出海创业直播
- "5 篇很有价值的复盘贴" —— 业内高手复盘精选

**这些是其他模块文章的"上下文锚点"，告诉你这条路能走多远。**

## 适用人群

- 第一次做跨境独立站的新人（先读：需求 + SEO + 部署）
- 已起步想突破的独立开发者（重点读：流量 + GEO + 外链）
- 已经在做的独立站老兵（重点读：复盘 + levelsio 案例）
