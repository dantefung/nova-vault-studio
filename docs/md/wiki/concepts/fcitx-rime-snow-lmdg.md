# Fcitx + RIME + 雾凇 + LMDG：开源 AI 输入法

> 效果真的超级好的开源 AI 输入法组合——Fcitx + RIME + 雾凇 + LMDG，互联网从业者专属。

## 组件说明

| 组件 | 作用 |
|------|------|
| **Fcitx 5** | Linux 输入法框架，负责输入法切换、UI 展示 |
| **RIME（中州韵）** | 开源输入法引擎，高可定制，支持挂接词库和 Lua 脚本 |
| **雾凇拼音** | 基于 RIME 的现代中文输入方案，维护活跃，词库丰富 |
| **LMDG** | Language Model Drop-in Google - 用本地语言模型增强输入法的候选词排序，实现 AI 级别的智能候选 |

## 优势

- 完全开源，无隐私泄露风险（本地运行）
- 雾凇词库覆盖互联网从业者常用词汇
- LMDG 让候选词排序更智能，接近云端输入法体验
- 高度可定制，可自建词库和快捷键
