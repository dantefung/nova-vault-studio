# AdSense Pin 码与实名认证

## 一句话洞察

Pin 码是 AdSense 的**实人实地验证**环节，从美国邮寄平信，丢失率高。核心策略是：满 3 次未收到后，人工提交身份证 + 地址地标照片，一次通过率很高。

## Pin 码触发条件

网站审核通过 → 广告费满 10 美元 → 谷歌从美国邮寄平信 Pin 码

## 丢失处理流程

1. 每次信件寄出后等两周
2. 点击"再次发送 Pin"（最多 3 次）
3. 3 次后进入人工审核：support.google.com/adsense/workflow/11033519
4. 上传身份证 + 地址旁地标合影（人和地标名称同时入镜）

## 关键要点

- 平信非挂号信，跨国丢失率高
- 必须凑满 3 次后才能进入人工审核
- 人工审核上传足够证据，一次通过率很高
