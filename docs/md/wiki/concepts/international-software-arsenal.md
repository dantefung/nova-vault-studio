# 境外势力软件盘点：常用国际服务清单

> 手机已被境外势力侵蚀——盘点一直在用的国际软件，各有不可替代的用途。

## 网络与工具

| 软件 | 用途 | 说明 |
|------|------|------|
| **Shadowrocket** | iOS 翻墙 | 别名小火箭，支持多种协议，链接世界的入口 |
| **Chrome / Brave** | 浏览器 | Chrome 用户基数大，Brave 加强隐私保护 |
| **Proton Mail** | 加密邮箱 | 黑客都在用的加密邮箱服务，注册重要服务用 |
| **Gmail** | 常用邮箱 | 常用但不重要的服务用 |
| **PayPal** | 支付 | 支付宝借鉴的对象，简洁不臃肿，纯支付功能 |

## AI 与搜索

| 软件 | 用途 | 说明 |
|------|------|------|
| **ChatGPT** | AI 对话 | 用过都说好 |
| **Perplexity** | AI 搜索引擎 | 与 ChatGPT 互补，提供即时最新答案，不存在信息滞后性 |

## 内容与学习

| 软件 | 用途 | 说明 |
|------|------|------|
| **Netflix** | 流媒体 | 娱乐式学外语，大量片源支持多语种配音和字幕，还有精品手游资源 |
| **Spotify** | 音乐/播客 | 听歌和有声书，外语播客资源远超国内对应软件 |
| **YouTube** | 视频 | 大量优质最新的学习资源，养活一半童厕 up 主 |
| **Twitch** | 直播 | 类似于斗鱼，数据更真实，主要用来娱乐化学习英语 |
| **Wikipedia** | 百科 | 外国版百度，无莆田系特色 |

## 社交与社区

| 软件 | 用途 | 说明 |
|------|------|------|
| **Reddit / X** | 社区 | 内容庞大但质量参差不齐，用好事半功倍，用不好只是娱乐化产物 |
| **Discord** | 聊天/社区 | 文字语音视频聊天，可创建服务器和频道，集成机器人，常用来 Midjourney 作图 |
| **Telegram** | 加密聊天 | 开源聊天软件，端到端加密，"学习资源"丰富 |
| **Instagram** | 图片社交 | 外国版小红书，分享照片和短视频，笔记做得精良 |

## 效率与自律

| 软件 | 用途 | 说明 |
|------|------|------|
| **Notion** | 知识管理 | 笔记软件龙头老大，全世界都在抄，记琐事写草稿都用它 |
| **Habitica** | 自律 | 通过游戏化方式帮你自律的软件 |
