# 解决问题的"道-法-术-器"

道法术器的概念源自中国传统文化，其起源可以追溯到古代道家、儒家、墨家、法家等学派的思想和智慧。

这四个概念代表了古代中国对于世界万物本质和运行规律的深刻思考和总结。

**道**：道的观念最早见于《道德经》，由道家学派提出。道家强调宇宙万物的根本，认为道是宇宙间存在的根源，是一切事物形成和发展的来源和规律。

**法**：法家学派则主张以法治国，强调事物的规则和秩序。在法家看来，法是统治的重要手段，是一种行为准则和规范。法家的思想对中国封建政治和法制的发展有着深远的影响。

**术**：术在古代则是指各种技艺和技术。各种学派都非常重视术，不同学派以其独特的视角和取向阐释了术的内涵。

**器**：儒家学派以器为标志，器解释为一种符合价值观念的礼法制度、性格观和沟通技巧，追求维护和发展人的性与情。

道法术器的思想传承至今。日常工作中，我们分析和解决问题无时不在运用"道法术器"的思想。

**道**：即思考问题的思路、框架和格局。主要体现在能够精准定位问题、构建解决问题的框架，保证问题的分析严谨、透彻、全面、方向正确、视角高远、框架清晰。

**法**：即解决问题的流程、步骤、规则和制度。主要体现在能把问题拆解为可以落地的流程和步骤，以及制定每个流程的规则。流程和步骤能够保证问题被持续解决，规则和制度能够规则风险和漏洞，保证方向不跑偏。

**术**：即实际操作和落地执行，凭借专业技能在流程和规则的指引下落地执行，解决问题。

**器**：即思考和解决问题的工具、武器和技巧，即通过什么工具能落地解决问题。
