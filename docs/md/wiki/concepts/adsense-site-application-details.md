# AdSense 网站提交审核最佳实践

## 一句话洞察

AdSense 网站审核的关键在于**验证顺序**：必须先验证 ads.txt 文件，再验证 JS 代码段，最后提交申请。顺序错了会导致 ads.txt 状态始终为"未找到"。

## 核心流程

### 验证方式的优先级

| 验证方式 | 是否必须 | 说明 |
|---------|---------|------|
| ads.txt 文件 | 是（先验证） | 放网站根目录，浏览器可访问 `域名/ads.txt` |
| Adsense JS 代码段 | 是（后验证） | 放每个页面 HTML 的 `<head>` 中 |
| Meta 标记 | 可选 | 可放可不放 |

### 正确的提交顺序

1. 放置 ads.txt 文件 → 验证通过
2. 展开验证方式 → 切换到 Adsense 代码段
3. 获取 JS 代码放置到网站所有页面
4. 点击"申请审核"提交

### 错误顺序的后果

如果先验证 JS 代码段再验证 ads.txt，ads.txt 的验证选项会消失，提交后显示"ads.txt 未找到"。

## 关键洞察

- **有流量优先审核**：审核期间放 JS 代码，谷歌能监测到流量，优先审核
- **审核通过即变现**：提前放好 JS 代码，审核通过后立刻开启自动广告
- **细节决定成败**：SEO 和 Adsense 审核都是细节活，处处做好才有综合优势
