# GA4 指标体系

> GA4 的核心指标分为事件级、用户级、会话级三类，理解它们的层级关系是正确配置探索报告的前提。

## 核心指标分类

### 事件级指标（Event-level）
- 事件计数：每个用户触发事件的次数
- 事件参数：事件的附加属性（如 page_location, purchase_value）

### 用户级指标（User-level）
- 活跃用户数（Active Users）
- 新用户数（New Users）
- 用户参与率（Engagement Rate）

### 会话级指标（Session-level）
- 会话数（Sessions）
- 平均会话时长
- 每次会话页数

## 关键转化指标

| 指标 | 定义 | 用途 |
|------|------|------|
| 转化率（Conversion Rate） | 完成转化事件的用户数 / 总用户数 | 评估渠道质量 |
| 平均订单价值（AOV） | 总收入 / 订单数 | 评估用户消费能力 |
| 用户生命周期价值（LTV） | 用户在生命周期内产生的总收入 | 评估渠道长期价值 |
| 留存率（Retention Rate） | N天后仍活跃的用户占比 | 评估产品粘性 |
