# 虚拟内存的发明历程

> 虚拟内存通过分页、MMU、缺页中断和 TLB 等机制，给每个程序提供独立的虚拟地址空间，实现隔离保护、空间放大和碎片化分配三大目标。

## Key Points

- 虚拟内存的诞生是被多程序并发执行的需求逼出来的，经历了物理寻址→重定位→覆盖→分页的演进
- 核心思想：给每个程序一套假地址（虚拟地址），MMU 硬件翻译成物理地址
- 分页（Paging）以 4KB 为单位管理映射，页表记录虚拟→物理的对应关系
- 缺页中断（Page Fault）实现磁盘当内存用的魔法，对程序完全透明
- TLB（快表）是 CPU 内的高速页表缓存，解决分页带来的性能损耗

## Details

### 演进历程

1. **物理寻址**：程序直接操作物理地址，单程序 OK，多程序崩溃
2. **地址重定位**：加载时加偏移量，仍有碎片和隔离问题
3. **覆盖技术**：手动切块，麻烦但可扩展可用内存
4. **虚拟内存**：地址彻底与物理分离，自动化换页

### 三大价值

- **隔离保护**：每个进程有独立页表，bug 不影响其他进程
- **空间放大**：32 位系统认为有 4GB，64 位更大，实际物理内存小得多
- **碎片化分配**：虚拟页可映射到散落的物理页，无需连续

### 内存三层知识体系

指针（地址操作）→ malloc（动态分配）→ 虚拟内存（地址来源与隔离），三者合在一起才是 C/C++ 内存管理的全貌。
