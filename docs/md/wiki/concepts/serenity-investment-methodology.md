# Serenity 投资方法论（AI供应链卡脖子分析）

> 不要买最显眼的铲子（NVDA）——沿着供应链向上游追踪，找到那个小市场市值、但下游无法绕开的单点卡脖子，光学/CPO、复合半导体衬底、存储、电力——在那里，最小的市值对应着最大的定价权错配。

## Key Points

- **核心思想**：反推整条 AI 供应链，找最不可替代的卡脖子节点，提前布局小盘标的
- **适用领域**：AI半导体 / 光模块（CPO·硅光·InP）/ 半导体 / 内存 / NeoCloud / 电力液冷 / 机器人
- **代表人物**：Serenity（@aleabitoreddit），前 Reddit WSB 散户，现专注 AI 半导体供应链分析，39 万粉丝

## 霍尔木兹海峡类比

> "霍尔木兹海峡是全球石油的咽喉。一旦封锁，所有人受影响。但如果你在霍尔木兹海峡拥有股份，你就拥有了定价权。"

**翻译到 A 股**：哪个环节是某个大赛道的"霍尔木兹"？哪个 A 股公司控制它？

## 三步核心逻辑

```
① AI大爆发 / 政策驱动 / 技术跃迁
    ↓
② 上游硬件/原材料需求暴增，供应链某些环节产能跟不上
    ↓
③ 瓶颈环节掌握定价权 → 其中小盘股弹性最大
```
