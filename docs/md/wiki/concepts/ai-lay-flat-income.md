# AI 躺赚多语种站（6 个 AI 打工人 + 全球流量 + 被动收入）

> 选一个有流量的细分主题 → 招 6 个 AI 打工人 → 写主题自动跑 → 5 语种同时铺 → 全球流量 → Google AdSense 被动收入。

## 一句话定义

「**AI 躺赚多语种站**」是一种把内容生产、SEO 多语种、被动广告变现三件事用 AI 全自动化的实操模式。本质是把**普通 CMS 程序** + **N 个分工明确的 AI Agent（写主题/出图/标题/标签/description/正文）** + **定时任务** 串成完整流水线，**一个人就能运营一个覆盖全球多语种的被动内容站**。

## 核心架构

```
                定时任务（每 5 分钟触发）
                        ↓
                ┌───────┴───────┐
                ↓               ↓
        写主题（AI 打工人 1）   主题池
                ↓
        ┌───────┴───────────┐
        ↓       ↓       ↓       ↓       ↓
    出图   标题党   分词   desc   正文
     (2)    (3)    (4)    (5)    (6)
        ↓       ↓       ↓       ↓       ↓
        └───────┴───────┴───────┴───────┘
                        ↓
              组合成完整内容页（5 语种）
                        ↓
                  CMS 上线 + URL 多语种适配
                        ↓
                  Google AdSense 被动收入
```

## 6 个 AI 打工人分工

| # | 角色 | 输入 | 输出 | 关键 |
|---|------|------|------|------|
| 1 | **写主题** | prompt | 主题描述（角色 + 服饰单品）| 定时跑，不需要人输入 |
| 2 | **画图提示词** | 主题 | 英文 prompt JSON | 简洁精准，调图 API |
| 3 | **标题党** | 主题 | 5 语种标题 JSON（es/zh/jp/kr/en）| 100 字节内、覆盖"谁穿什么" |
| 4 | **分词高手** | 主题 | 5 语种标签 keywords JSON | 逗号分隔、核心词组、纯英文键 |
| 5 | **description 高手** | 主题 | 5 语种 meta description | SEO 合规 + 核心内容 |
| 6 | **文本创作大师** | 主题 | 5 语种正文 JSON（HTML `<p>` 分段）| 500 字内、动漫+时尚杂志双视角 |

**输出格式铁律**：

```json
{"es": "...", "zh": "...", "jp": "...", "kr": "...", "en": "..."}
```

## 5 个 URL SEO 设计铁律

| 页面 | 规则 |
|------|------|
| **首页** | 每个语种一个子路径：`/en /jp /kr /zh /es` |
| **首页 301** | 默认首页对应的子路径（如 `/jp`）→ 301 重定向到 `/`，避免重复内容惩罚 |
| **内容页** | `/<lang>/page/<角色>-<风格>` —— friendly URL |
| **内容页 URL 部分** | 统一英文，不翻译成多语种（避免翻译噩梦）|
| **标签页** | `/<lang>/tag/<本地化标签>` —— 标签要翻译 |
| **搜索页** | `/?search=<本地化关键词>` |

**这条铁律集合是 SEO 多语种的精髓**——很多站死在内容重复、URL 翻译错误、301 配置不对。

## 4 步启动流程

```
第 1 步：选一个有流量的主题
第 2 步：搭一个普通 CMS（WP/Strapi/自研）配多语种路由
第 3 步：写 6 个 AI 打工人（每个只擅长一件事）
第 4 步：写定时任务调度 → 上线 → 流量 + 广告收入
```

## 流量主题选择（决定生死）

**好的主题特征**：

- ✅ 角色/产品本身有热度（动漫 / 名人 / 宠物 / 古风）
- ✅ 视觉冲击力强（生成图吸引点击）
- ✅ 关键词长尾量大（穿搭 × 角色 × 场合 = 三维搜索空间）
- ✅ 不需要深文化背景（全球可共鸣）

**作者选择：动漫角色 OOTD（每日穿搭）**——兼具视觉冲击 + 角色 IP + 全球粉丝群体。

## 4 个你也能学的关键判断

### 1. AI 加成 > AI 应用

作者反复强调：**这是普通 CMS 程序，AI 是「打工人」**。不是要做"AI 应用"，而是用 AI 加成现有结构。

### 2. 多语种覆盖 = 流量指数级

一个人 AI 加持 = 中文 + 英文 + 日文 + 韩文 + 西文 + ... = 流量指数级。

> **理论上一个人可以覆盖全世界所有语言**（这是 zlbigger 反复强调的）。

### 3. 定时任务 = 真·自动化

定时任务不只是"触发"，而是要把整个流水线自己跑起来——**写主题的 AI 自己跑**，不是等人为输入。

### 4. "躺着赚钱"的本质

> 让 AI 打工 = 让 N 个 AI 各司其职 = 流水线 SOP = 边际成本递减到接近 0。

**躺** = 人不需要在线。
**赚** = 持续积累的内容资产产生广告收入。

| 维度 | 传统站群 | AI 躺赚多语种站 |
|------|---------|---------------|

| 多语种 | 需人工翻译 | 一次 prompt 多语输出 |
| 24h 自动生产 | ❌ | ✅（定时任务）|

## 4 个实践建议

### 1. CMS 字段要结构化

- title / description / keywords / image_url / content 多语种存储
- 提前做好 i18n schema（不要做完再加）

### 2. AI 工人 prompt 持续迭代

- 早期输出质量不稳定没关系，跑一段数据后批量调 prompt
- 不要 1 个 prompt 兼顾所有事

### 3. SEO 监测 + 自动化调整

- 用 Google Search Console 看哪些页被索引
- 哪些标题/关键词带流量 → 反哺 prompt 优化

### 4. 不要怕"套壳"

> **「成为一个拥有十万用户的套壳产品显然比拥有自有模型却没有用户更有价值。」**

> 用户和分发 > 模型本身。这是 zlbigger 反复强调的。

## 风险与边界

⚠️ **必须警惕**：

- **Google AdSense 审核**：网站要有一定内容后才容易过
- **AI 内容降权**：纯 AI 内容可能被 Google 标记低质量
- **图 API 成本**：高，必须想办法降低
- **版权**：网站显示"AI 生成"声明，避免法律风险
- **多语种质量**：翻译质量直接影响 SEO，用户体验

## 适用人群

✅ **适合做**：

- 能写代码 + 懂 SEO 的人
- 愿意 3-6 月延迟满足
- 有"内容选品"能力（能看出哪些主题有流量）
- 不怕"套壳"标签

❌ **不适合**：

- 没法写代码又找不到帮手
- 不能 3-6 月持续输出
- 想立刻爆发的
- 抵触"低质量 AI 内容"
