# 任务拆解与思维循环系统

核心是把任务拆解成自己能执行的线性流程。

## 1. 问题导向（自上而下）

从目标问题出发，不断拆解，直到拆成自己能力范围内能处理的小部分，拆解的过程本身就规划出了解决路径。

链条是：**自我状态 → 解决方法 → 目标问题**

适用于"结构良好"的问题。

## 2. 知识地图（自下而上）

把学习理解为"获取概念之间的联系"。将目标按四种关系展开：**上级、下级、并列、相关**

- 上级/下级：对应问题导向里的拆解
- 并列/相关：当问题拆不下去时，转移目标、换个角度继续推进

## 3. 思维循环（系统视角）

人的思维不是线性的，需要把思维路径可视化。

流程：**先综合考虑重要性、自身能力、学习材料等因素，定一条初步路径 → 一轮轮循环（每轮提高预期、深入一层、再循环）→ 逐步深入**

## 贯穿始终：元认知监控

用思维流程图把抽象的思考过程显性化、可见化，方便自己监控和调整学习方向。
