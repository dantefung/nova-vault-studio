# 奥地利经济学派（奥派经济学）

> 创立于19世纪70年代的维也纳，强调方法论个人主义和人的行动（Praxeology），反对数学模型预测经济，主张完全自由市场。

## 概述

奥派经济学（奥地利经济学派）创立于19世纪70年代的维也纳。该学派强调方法论个人主义和人的行动（Praxeology），反对使用复杂的数学模型预测经济，主张完全自由的市场，并认为价格和货币来源于个体的心理价值判断。

## 核心观点

- **人的行动学**：经济规律从人类有目的的行动逻辑中演绎得出，不依赖统计数据。
- **主观价值论**：物品的价值不是由成本决定，而是由个人对它满足自己欲望的紧迫程度主观决定。
- **反对政府干预**：市场能通过价格机制自动调节，政府对货币供应和价格的干预往往会扭曲信号、导致危机。
- **商业周期理论**：认为经济衰退和泡沫是中央银行人为压低利率、引发过度信贷扩张造成的。

## 主要代表人物

- **卡尔·门格尔**：学派创始人，1871年发表《国民经济学原理》奠定基础。
- **路德维希·冯·米塞斯**：提出社会主义经济计算不可能实现，捍卫古典自由主义。
- **弗里德里希·哈耶克**：因价格作为知识传达工具的研究获得诺贝尔奖，强调自由市场秩序。
