# AdSense 账号注册与审核全流程

## 一句话洞察

AdSense 审核的本质是**谷歌对你的网站流量和内容的信任评估**。有流量的网站（即使新域名）也能快速通过，内容少流量小的网站才需要靠域名年龄和内容积累来弥补。

## 核心概念

### Adsense 赚钱模型

- AdSense 是谷歌网站广告联盟，网站放广告代码赚广告费
- **离钱越近的内容**广告单价越高（电商、金融类 > 工具类）
- **发达国家流量**广告单价更高（英文站 ecpm 可达 10 美元，中文站仅 0.54 美元）

### 审核流程

```
爬虫检查 ads.txt + 代码 → 统计流量 → 抓取内容 → 人工审核
```

## 关键决策

### 养号

新注册 Gmail 不要立即注册 Adsense，先正常使用半个月一个月养号。

### 网站准备

- 已有网站在顶级域名提交，不填 https 和路径
- 无网站先部署 Wordpress 写原创博客，每天 1-2 篇，坚持半个月到一个月
- **国家地区选真实的中国**（后续需要验证真实地址）

### 双验证缺一不可

关联网站时，广告代码和 ads.txt 文件**两个验证都要做**，不是二选一。

## 反常识洞察

> 域名注册需满 3 个月才能申请 Adsense —— 这是针对**内容少流量小**的网站。有足够流量的新站（1 个月内）也能通过审核，因为谷歌知道它有流量。

## 变现链路

```
审核通过 → 显示广告 → 赚满 100 美元 → 填真实地址 → 收 Pin 码信件 → 输入 Pin 码实名 → 收到付款
```

- 收不到信可重发（最多 3 次）
- 3 次都收不到可申请线上实名：上传身份证 + 站在地址旁标志性建筑拍摄的照片
