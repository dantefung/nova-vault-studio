# 经济机器与债务周期模型

> 一套以交易为基本单元、以信贷改变支出时序、以生产率增长和长短债务周期解释宏观波动的资产负债表模型。

## Core Equations

```text
经济 = 所有市场中的全部交易
支出 = 货币 + 信贷
价格 = 支出 / 销量
一方的支出 = 另一方的收入
债务负担 = 债务 / 收入
```

这些等式不是完整的计量模型，而是帮助定位反馈回路的认知骨架。

## Three Forces

| 动力 | 时间尺度 | 主要作用 |
|------|----------|----------|
| 生产率增长 | 长期 | 决定真实产出和生活水平的趋势 |
| 短期债务周期 | 数年 | 信贷、支出、通胀和利率调节形成扩张与衰退 |
| 长期债务周期 | 数十年 | 债务负担跨周期累积，最终触发去杠杆化 |

## Feedback Loops

### 扩张回路

```text
信贷增加 -> 支出增加 -> 收入增加
-> 信用度提高 -> 信贷进一步增加
```

### 资产泡沫回路

```text
借贷购买资产 -> 资产价格上涨 -> 抵押物价值提高
-> 可借额度增加 -> 更多资产购买
```

### 去杠杆恶性回路

```text
削减支出 -> 他人收入下降 -> 信用恶化
-> 信贷收缩 -> 资产抛售 -> 抵押物缩水
-> 更难借贷 -> 进一步削减支出
```

## Policy Levers

| 工具 | 直接效果 | 主要风险 |
|------|----------|----------|
| 削减支出 | 降低新增债务 | 收入下降可能让债务收入比反而上升 |
| 债务重组 | 减少名义债务或偿债压力 | 债权人资产损失、金融机构承压 |
| 财富再分配 | 将购买力转向高消费倾向群体 | 政治冲突、激励与执行问题 |
| 创造货币 | 补充消失的信用与支出 | 资产价格失真、分配效应与通胀 |

“和谐去杠杆化”要求组合这些工具，使名义收入增长超过债务利息增长，同时避免严重通缩或高通胀。

## How to Use the Model

1. 先区分真实生产率趋势与信贷驱动的名义支出增长。
2. 观察债务收入比、偿债成本、信贷条件和资产抵押价值。
3. 判断衰退是否仍可通过利率工具缓解，还是已进入资产负债表修复。
4. 分析政策组合是在转移损失、推迟确认，还是实质降低债务负担。
5. 用其他框架检验供给、制度、国际资本流动和分配效应，避免单模型解释一切。

## Tensions With Other Schools

该模型强调总支出、信用扩张、央行和财政协调，与 [[concepts/austrian-economics]] 对信用周期、政府干预和数学化宏观建模的立场存在明显差异。两者都重视信贷导致的周期，却对成因、政策作用和“可管理性”给出不同判断。

## Limitations

- 周期长度是经验描述，不能机械用于择时。
- 将“一个人的支出是另一个人的收入”用于总量分析时，仍需考虑储蓄、进口、税收和金融资产交易等部门流量。
- 货币创造是否通胀，取决于信用收缩、产能、流通速度、财政传导和预期，而非单一数量抵消关系。
- 历史类比应控制制度、货币体系和国际环境差异。
