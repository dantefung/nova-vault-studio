# 关于睡觉的技术

> 你不是睡眠时间很长，你只是在床上呆的时间长而已。

---

## 睡眠的本质功能

1. **身体恢复**——更重要的是大脑恢复：睡觉时大脑排出残留废物（工业废水），只有排出去，白天才能继续输入干净的水
2. **增强记忆的唯一方法**——不睡觉，无论学多少都无法进入长期记忆仓；睡不好，学习不会好

---

## 三个实操技巧

### 第一条：主动调整——睡前别做刺激的事

| 刺激源 | 后果 |
|--------|------|
| 玩游戏 | 大脑亢奋，难入睡 |
| 深度聊天引发思考 | 同上 |
| 恐怖片 | 吓得不敢睡 |
| 刷小视频 | 15-30 秒一次刺激，根本没法产生睡意 |

**建议**：睡前看无聊的书（哲学、宇宙诞生类），看一会就犯困。

### 第二条：被动调整——温度是入睡关键

> 温度越高，越难入睡；温度越低，越快入睡。

- 作者每晚 25 度空调 + 空调被
- 洗完热水澡后体温迅速降低，特别想睡
- 不要穿太厚睡衣，容易热醒

### 第三条：快速入睡法——细节想象

1. 躺下，全身刻意放松，头部四肢都放松到使不上力的感觉
2. 闭眼，想象桌面苹果，拿起观察细节
3. 想象用刀削皮，持续构建细节
4. 这些细节慢慢变成梦境 → 入睡
