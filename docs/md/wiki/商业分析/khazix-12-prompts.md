# 12 个最常用 Prompt 合集

> 都 Agent 时代了，我还是想分享给你这 12 个我最常用的 Prompt。过去几年零散写过，重新整理，删了一些，优化了一些，补充了一些。全部可以单独复制使用，不需要安装任何 Skill，适配所有 AI。

---

## 五个场景

| 场景 | 说明 |
|------|------|
| **一、问清问题** | 苏格拉底提问法，帮你找到「究竟想问的本质问题是什么」 |
| **二、学习** | 深度学习、知识吸收类 Prompt |
| **三、解决问题** | 专家级问题拆解与解决（20 年经验的专家框架） |
| **四、决策** | 深度思考 Prompt，帮你挖出最本质的答案（含钢人论证） |
| **五、认识你自己** | 深度天赋挖掘机 + 人生设计师，两个 Role 型 Prompt |

---

## 核心原则

- 把 `【】` 里的内容换成你自己的信息
- 有原始材料（文档等）就尽量扔上去，**这年头不怕上下文多**
- 苏格拉底提问法比无限拷问更实用——问清楚问题，模型才知道该做什么
- 决策类 Prompt 的核心是双向钢人论证（先把双方论点强化到最强再判断）
