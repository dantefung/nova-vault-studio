# 普通人如何「上牌桌」？

> 风口是风口，牌桌是牌桌。很多人追了十年风口，最后才发现自己连一张能坐稳的桌子都没有。

---

## 核心隐喻

小兔子发现森林深处一张又脏又破的小桌子——狮子嫌太脏、老虎嫌太矮、狗熊嫌太偏，没人要。小兔子坐下来收拾烂果子，从果核里挖出金渣渣，积少成多，成了森林里最爽的动物。

## 核心观点

| 概念 | 内容 |
|------|------|
| **风口 ≠ 牌桌** | 风口是风口，牌桌是牌桌，两回事 |
| **生态位分化** | 达尔文雀：嘴形和食物错开，谁也不抢谁，大家都活得很好 |
| **根据地战略** | 老一辈革命在农村求发展，秦国在偏远大蓄家底 |

## 四个实操案例

1. **冷门自媒体**：专做职业资格考试内容，不露脸不追热点，流量少但粉丝精准，个个真买主
2. **老人数字助手**：上门教老人挂号、缴费、刷医保，服务附近几个小区，按次收费有转介绍
3. **接地气英语**：穿睡衣带娃拍简单单词，把单词打印成卡片讲，销量比培训机构账号还高
4. **本地维修大叔**：电动车走街串巷做小修小补，主攻老旧小区，二三线城市月入过万

## 四条执行原则

1. **先看谁不愿意干，再看自己能不能干**——"别人不愿干，你去干"本身就是一种壁垒
2. **把降级感当入场券**——零散、渺小、无标准、无大品牌的行业，新人能浑水摸鱼
3. **别用大桌规则打小桌**——不和同行拼同一套规则，在小牌桌上重新定义自己的规则
4. **把被嫌弃翻译成被需要**——适老化改造就是把别人不愿处理的麻烦转化为付费理由

## 自检工具

- 行业特征：零散？非标准化？无人愿意做？
- 个人匹配：能干吗？有时间吗？有资源吗？
- 竞争格局：大玩家愿意来吗？进来了能留下吗？
