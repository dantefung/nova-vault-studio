# Transformer 训练中的七个关键公式

> 训练运行可能发散、loss 无缘无故飙升、一个坏的 batch 就能毁掉一周的工作。这篇文章用七个简短的公式解释是什么让训练保持稳定——大多数人从配置文件中复制这些公式，却从未看过它们。

<!-- more -->

## 背景

人们通常把训练想象成一个干净的循环：计算 loss，沿着梯度下山一步，然后重复。但在实践中，训练运行可能发散，loss 会无缘无故飙升，一个坏的 batch 就能毁掉一周的工作。

这篇文章解释保持训练稳定的七个关键公式。每一个都来自「没有它就会出问题」的实际经验。

## 七个公式

### 1. 权重初始化

这是训练开始前就会出现的第一个问题。如果权重太大，信号会在每一层放大直到爆炸；如果太小，信号会衰减到零。

修复方法是有目的地选择方差。对于有 n_in 个输入的层和 ReLU 激活，He 初始化使用：

```
σ = √(2 / n_in)
```

**示例**：512 个输入时，标准差是 √(2/512) = 0.0625。如果用标准差为 1 的权重，方差会在每一层乘以约 512。十层之后，数值已经天文数字。

### 2. Adam 优化器

普通梯度下降给每个参数相同的步长。Adam 给每个参数自己的步长，使用梯度的两个移动平均值 g：

- m 是方向
- v 跟踪梯度通常有多大

除以 √v 意味着：梯度巨大且嘈杂的参数走小心的一步，梯度微小的参数走更大胆的一步。

### 3. 偏差修正

m 和 v 都从零开始，所以早期它们被拉向零，低估了真实值。Adam 通过除法修复这个问题：

```
m̂ = m / (1 - β₁^t)
v̂ = v / (1 - β₂^t)
```

**示例**：尝试 step 1，g = 0.5，β₁ = 0.9，β₂ = 0.999。则 m = 0.05，只有真实梯度的十分之一。除以 (1 - 0.9) 后恢复为 0.5。同样的技巧把 v = 0.00025 变成 0.25。

第一次更新变成 lr · 0.5 / √0.25 = lr。第一步的大小就是学习率，无论梯度多大或多小。

### 4. 权重衰减（AdamW）

权重衰减每一步都缩小一点权重，防止它们无限制增长。明显的方法是在梯度上加 λθ，但在 Adam 内部，这一项会和其他项一起被 √v 除。最需要缩小的权重反而缩小得最少。

AdamW 把衰减分离出来直接应用：

```
θ = θ - lr · (m̂ / (√v̂ + ε)) - lr · weight_decay · θ
```

这是一个单项变更，但意味着衰减强度不再依赖梯度历史。

### 5. 学习率 Warmup

在前几步，v̂ 只从少数几个梯度构建，所以它是一个嘈杂的猜测。在错误的猜测上使用全尺寸学习率，就是训练早期死亡的原因。

所以从小开始，线性上升：

```
lr_t = lr_max · min(1, t / warmup_steps)
```

**示例**：W = 1000，step 100 使用 10% 的目标率。当学习率达到全速时，Adam 的估计已经有时间稳定下来。

### 6. 余弦衰减

Warmup 之后，你想要早期大步、后期 Gentle 步。余弦衰减平滑地做到这一点：

```
lr_t = lr_min + 0.5 · (lr_max - lr_min) · (1 + cos(π · t / T))
```

在 t = 0 时余弦是 1，所以得到 lr_max。在 t = T 时是 -1，所以得到 lr_min。 halfway 时恰好是两者的平均值。曲线两端平坦、中间最陡，所以训练在调度开始或结束时不会突然跳动。

### 7. 梯度裁剪

有时一个 batch 产生的梯度比平时大得多。在上面走一步可能把模型推到很远的地方。裁剪在不改变方向的情况下限制总大小：

```
if ‖g‖ > c: g = g · (c / ‖g‖)
```

**示例**：如果 ‖g‖ = 50 且 c = 1，每个分量乘以 0.02。梯度现在指向相同方向但范数为 1。如果 ‖g‖ 已经低于 c，什么也不发生，所以在正常步骤上裁剪完全不作用。

## 核心洞察

> 没有一个公式是长的，每一个都存在是因为没有它就会出现故障。Warmup 存在是因为早期 Adam 不可靠。偏差修正存在是因为零初始化会欺骗你。裁剪存在是因为一个 batch 可能是一场灾难。
