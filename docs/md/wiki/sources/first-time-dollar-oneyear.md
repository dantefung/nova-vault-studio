# 【精读】第一次赚美元！纯新手深度复盘网站出海，一文掌握全流程

> **核心结论**：一位纯新手（无网站开发背景）借助 AI 编程和交学费式的课程投入，在 1 年内完成 5 个海外网站 + 2 个微信小程序的 MVP 上线并首次实现美元收入——**这是中文独立站出海圈不可多得的"新手视角"全景式复盘**。

> **关键洞察**：
> - 2025 年做网站出海仍然可行：AI 重做老网站的机会大量存在
> - 验证需求优先于打磨产品——MVP 不是半成品
> - 海外广告变现效率远高于国内（同样流量单价高数倍）
> - 边际成本几乎为零的软件生意 = 养站防老的睡后收入
> - "多上站"哲学——种十几种"果树"才能避免看天吃饭

## 文章概览

**原作者**：droidHZ（赫兹，公众号 droidHZ），自述"探索网站出海的纯新手"，之前无网站开发背景（安卓开发出身）。

**文章背景**：发布于 2025 年 7 月 8 日，是他出海探索一年时交出的"全程复盘"。文章采用高度个人化的"自上而下"叙事：先用一张表格暴露他踩过的坑和交过的学费，再展开方法论。

**文章定位**：是中文独立站出海圈少见的新手第一人称复盘，**不是教程，是经验地图**。

> 原作者：先承认自己"被割韭菜"是加速学习的方式，文中明确列出他交过的所有课程和订阅费用。

## 精读正文

### 一、起步的"账本"：交过的学费和投入的工具

作者坦然公布了自己的"投资明细"——课程和社群是主要开支，工具订阅相对便宜。

**课程与社群**（合计约 7798 元/年）
- 刘小排的《Idea to Business》（4999 元）：2 个月深度学习 + 1 年社群
- 哥飞的 SEO 社群（2600 元/年）
- 向阳乔木的 AI 领导力课程（199 元）

**AI 员工"月薪"**（约 40 刀/月）
- ChatGPT Pro（20 刀）
- Claude Code（20 刀）
- Lenny's Newsletter 大礼包（170 刀/年，内含 Cursor、v0、Lovable、Bolt）
- Dia 浏览器（教育邮箱白嫖）

> 关键判断：把"学费"看作加速器，不是浪费——作者明确说"感觉很值，能快速了解这个生意"。

### 二、当前成绩单：5 个站 + 2 个小程序

作者用数字展示真实战绩：

- 海外网站：5 个（3 个练手未推广），累计 1 千多用户
- **makememe.net**：订阅收入 5 刀 + 国内 20 元转账（国内用户用海外支付门槛高）
- **Google AdSense**：刚申请，按访问量估算有几美元收入
- 微信小程序"九宫格极简拼"：累计 1.19 万用户，广告收入 286 元

> 一个反直觉的发现：微信小程序"吭哧吭哧"做了很久，广告单价低没挣到什么钱；同样的流量在海外广告平台能多挣几倍。

### 三、什么是网站出海生意

> 顾名思义就是开发网站，挣海外用户的钱。

作者给了更具体的五步漏斗：
1. 发现用户需求
2. 找出解决方案
3. 用 AI 编程做产品
4. 宣传产品
5. 通过广告或订阅赚钱

### 四、为什么 2025 年还能做网站出海

作者列出 5 个支撑理由：

- **用户习惯仍在**：海外用户在 Google 生态下有强网站使用习惯（需适配移动端）
- **AI 带来重做老网站的机会**：很多旧站都值得用 AI 重新做一遍
- **零审核、零门槛上线**：除支付和广告外几乎无审核，提交即上线
- **AI 缩短开发周期到极致**：作者亲述发现飙升热词 → 5 小时就完成 MVP 上线
- **海外消费力强 + 订阅制成熟**：变现天花板和单价都明显高于国内

> 终极理由："软件的边际成本几乎为零，天花板比较高……可以做到养'站'防老，睡后收入。"

### 五、需求挖掘：5 个方法论入口

作者明确说"不要从供给侧出发，先找用户再找产品"，给出 5 个挖掘需求的方法：

#### 1. 痛点法
- 自有痛点、身边人痛点、社媒用户痛点（Reddit、小红书）
- 筛选标准：**高频 + 愿意付费 + 价格高**
- 刘小排老师公式：**什么人 + 什么场景 + 愿花多少钱 + 解决什么问题**

#### 2. 找关键词法
- 思考用户为什么搜索这个词
- 关键词本身可直接注册域名（推广事半功倍）
- 工具组合：Google Trends、社媒趋势、新闻找新词
- **Semrush 工作流**：种子词 → 过滤搜索量大 + KD 小 + 竞争低 + 有一定 CPC

#### 3. 现有产品复刻
- 找已验证的产品，做差异化：做最简版 / UI 更完美 / 付费模式创新 / 增加新特性 / 解决差评问题
- 通过榜单找优秀产品

#### 4. 线上服务/工作
- 逛 Fiverr、Upwork、闲鱼，看大家**愿意付费做的产品**
- 思考能否用工具去降本增效

#### 5. 关注新技术
- 逛 GitHub、Hugging Face
- 发现新 AI 能力或有趣开源项目
- 用新能力**倒推解决已有问题**

> 隐含的心法：5 个方法不是并列选项，是按"信号强度"从高到低排序——痛点最直接，新技术最前沿。

### 六、产品开发上线：设计 → 开发 → 部署 → 域名

#### 设计阶段：需求讨论 + 原型设计

- **需求讨论**：和 AI 大量对话（ChatGPT 支持视频/语音聊）。目标产出 MVP——**不是半成品，而是"够用"的最小可行产品**。
- **MVP 的真正目的**：快速验证假设 + 收集付费意愿反馈 + 避免沉没成本
- **原型设计**：用 v0、Lovable、Bolt（Lenny 大礼包）。**同时抽卡**，也能用免费的 Google Stitch（仅 UI）

#### 开发阶段：AI 模型 + 工具 + 技术栈

**AI 模型选择**：
- OpenRouter（文本模型）、Replicate（图片模型）、硅基流动（国内平替）
- 性价比选择：isunque（ChatGPT-4o 便宜）
- **积木思维**：把多个 API 串联，刻意练习复刻榜单上的 AI 网站

**开发工具**：
- Cursor + context7 MCP（保证用最新平台知识库）
  - ⚠️ 不要让 Cursor 一次性做太多事（会偷懒/乱做）
  - ✅ 做法：先和 AI 对齐颗粒度再开发
- Claude Code：能做更复杂任务（多语言一把梭），配合 Playwright MCP 可自动浏览网页/抓数据/集梦生图

**技术栈选择**：

| 组件 | 选型 | 理由 |
|------|------|------|
| 框架 | Next.js + Tailwind CSS | 前后端统一、AI 熟悉、生态完备 |
| 数据库 | Supabase | 免费 2 项目、内置登录、MCP 可让 Cursor 直接操作 |
| 支付 | Creem | 支持支付宝绑定（无海外公司/银行卡的退路） |
| 部署 | Vercel | 1 分钟自动发布、零运维 |
| CDN/防刷 | Cloudflare | 免费套餐够用 |

**支付备注**：
- 优先 Stripe（有海外银行卡）
- 其次 PayPal（国内公司）
- Creem 兜底（个人也能用，一晚通过审核）

**Creem 审核注意事项**（作者实操）：
- 网站功能完整、不能过于简单
- 必须有隐私政策 + 服务协议
- 不能有虚假内容（如虚假用户证言）
- 需有联系邮箱（作者用 Zoho 绑定自己域名）

#### Starter Kit 加速开发

> 速度 = 上站数 = 赚钱可能性

**免费选项**：
- shadcn-landing-page（GitHub）
- zippystarter.com/tools/shadcn-ui-theme-generator（定制颜色）
  - 作者的 makememe.net 就是用这个生成的

**付费选项**（建议先找优惠码）：MKSaaS、ShipAny、MakeKit、SupaStarter、Shipfast、SaasyKit

#### 部署 + 域名

- **Vercel**：GitHub 登录 → 提交代码 → 1 分钟自动发布，5 个站零费用
- **Cloudflare**：CDN + 安全校验防刷
- **域名**：
  - 不要囤域名，**上站前才买**
  - 工具：instantdomainsearch.com、query.domains（一键查后缀）
  - 黑历史查询：virustotal.com
  - 购买：namecheap、spaceship（找优惠码）
  - ⚠️ 海外站不要在国内厂商买（备案麻烦）

### 七、运营推广：收录、SEO、宣传、迭代

#### 收录与分析工具组合

| 工具 | 用途 |
|------|------|
| GSC（Google Search Console） | **必做**，网站被收录才能获得搜索流量 |
| Google Analytics | 免费访客数据 |
| Plausible | 三方数据检测（前一个月免费，更详细） |
| Microsoft Clarity | 热力图 + 用户操作回放 |

#### 站内 SEO：6 个核心标签

> Google 通过这些标签判断网站是做什么的

- Title（页面标题）
- Description（页面描述）
- Heading（H1-H6）
- 图片 alt 属性
- 链接 Nofollow 属性
- robots 元标签
- canonical 标签

> 推荐工具：AITDK 浏览器插件，一键看到所有标签问题

#### 宣传推广：5 大平台 + 3 个垂直渠道

**发布平台**：
- **Product Hunt**：很多成功产品起点，导航站会从这抓取（被动外链）
- **Hacker News**：技术用户集中地
- **Indie Hackers**：独立开发者社区
- **Betalist**：发布测试版，收集早期反馈
- **Faizer**：小型 Product Hunt（作者的 makememe 在这里莫名拿到日榜第一）

**垂直社区**：
- V2EX（需要邀请码 + 提前一个月注册）
- 即刻（网站出海/AI 领域大佬集中）
- Discord 社区、垂直群聊、导航网站

**自媒体**：找垂直领域 KOL（如阮一峰的周刊投稿）

> 推广心法：**质量 > 数量**，多测试不同平台、记录转化数据、沉淀"产品发布清单"。

#### 持续优化

- **多交流**：种子用户 → Discord 群聊 → 收集改进点
- **持续发外链**：不只开始时发，用 Semrush 看竞品外链，反向补充

### 八、哥飞老师寄语（与共勉）

> 1. **时间是魔法**：坚持上站、发外链，慢慢就会有收获
> 2. **多上站哲学**：果树比喻——种十几种"果树"才能避免看天吃饭，桃子不行苹果来凑

## 核心方法论提炼

### 1. "新手视角"独特价值
作者没有任何网站开发背景（安卓开发出身），正因为是新手，他的复盘反而不预设"这有什么难的"，更贴近中文独立站出海圈新人的真实学习路径。

### 2. AI 时代的新杠杆
- **5 小时上站**：传统上需要数周的工作，AI 编程把它压缩到一晚
- **多上站**从空想变成可执行：以前是建议，现在是现实
- **MVP 验证**的时间成本降到 1 天以内

### 3. 边际成本为零的"养站"模型
软件生意相对实体生意的本质优势是：**没有库存、没有物流、没有客服规模化**。一旦做出"持续被搜索到"的内容站或工具站，可以形成长期睡后收入。

### 4. 海外 vs 国内的两个关键差异
- **广告单价**：海外 Adsense 单价是国内的几倍
- **支付门槛**：国内需要公司、海外个人可选 Creem（支付宝也能用）
- **审核松紧**：海外网站几乎零审核，提交即上线

### 5. "果园比喻"的实操推论
哥飞老师的"多上站=多种果树"哲学是独立站出海圈最被低估的心法之一——**绝大多数新手失败不是因为某个站做得不好，而是只做了一个站就放弃**。
