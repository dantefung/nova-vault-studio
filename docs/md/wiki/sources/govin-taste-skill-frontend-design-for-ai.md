简直神药啊！15.7 万 star！微软开源的文档神器，token 最多能省 90%！

经常用 Codex 的兄弟，这个工具一定要用起来！【此贴包含完整安装使用教程】

MarkItDown：微软出品，专门把各种文档转换成 AI 最容易理解的 Markdown

支持 PDF、Word、PPT、Excel、HTML、图片等多种格式。

为什么值得装？

1. 网页 / HTML：减少 60%～90% 冗余 token

去掉大量 HTML 标签、CSS 和脚本，只保留真正有用的内容

2. Word / PPT / Excel：减少解析折腾

提前转换，省掉 Codex 自己写解析脚本、安装依赖、反复试错的过程

3. PDF：结构更清晰

保留标题、列表和表格结构，让 AI 更容易理解，减少返工

4. 最狠的玩法：一次转换，多次复用！

一份行业报告，先转成 Markdown

后面写方案、做 PPT、提炼数据、生成文章，直接读取，不用每次重新解析

怎么安装？

直接把下面这段提示词复制给 Codex：

请帮我在本机安装并配置微软开源项目 MarkItDown，先阅读官方文档，检查 Python 环境，按照官方推荐方式完成安装。安装后实际测试转换功能是否正常，不要覆盖现有环境或配置，最后告诉我安装结果和使用方法

安装后怎么用？

1. PDF 转 Markdown

用 MarkItDown 将指定 PDF 转换为 Markdown，保存为同名 .md 文件

2. Word 转 Markdown

用 MarkItDown 将指定 Word 文档转换为 Markdown，保存为同名 .md 文件

3. PPT 转 Markdown
   用 MarkItDown 将指定 PPT 转换为 Markdown，保存为同名 .md 文件

4. Excel 转 Markdown

用 MarkItDown 将指定 Excel 文件转换为 Markdown，保存为同名 .md 文件
