# Marvin：文章没少写，流量就是不涨？先改这批旧页面

> GSC 旧内容改造 5 步：筛出平均排名 3–20 的查询 → 挑有持续曝光、贴近业务、页面缺答案的词 → URL 归集确认改哪页 → 按缺口改（标题描述具体化 / 核心答案前置 / 意图匹配）→ 2–4 周复盘对比。附最小记录表。

<!-- more -->

下一篇开写前，先去 Google Search Console（GSC）找出平均排名在 3–20 的查询。已有排名和曝光的旧内容，值得优先检查哪里还能补好。

![](../images/growaiskills-gsc-old-page-refresh/002.jpg)

## 1｜先把机会筛出来

进入「效果 → 搜索结果」，看最近 28 天；数据少就拉长到 3 个月。勾选点击、曝光、CTR（点击率）和平均排名，在查询表筛选 3≤排名≤20，不方便筛区间就导出后筛。固定目标国家和设备，再按曝光从高到低看。

## 2｜挑值得改的词

优先选：有持续曝光、贴近业务、页面确实缺答案的查询。

同样排第 8，一个只有几次曝光，一个持续被搜、还跟你的产品有关，先改后者。先挑 3 个页面试一轮，别全站同时动。

## 3｜确认到底改哪一页

点击查询 → 切到「页面」，看实际获得曝光的 URL，再检查这个页面在该词下的表现。

同一个词出现多个 URL，先判断哪页最符合需求，别给每页都塞一遍相同关键词。

## 4｜按缺口改，别只加字数

• 有曝光、点击少：先看搜索结果页，再把标题和描述写具体，让人知道点进来能解决什么。

• 内容没答全：把核心答案放到开头，补缺失的步骤、案例或限制条件，关键词自然放进相关标题和正文。

• 搜索意图不匹配：先判断页面类型。用户要立即使用工具，一篇长文章未必能满足。

举个假设：查询是「批量压缩图片」，旧文主要讲图片格式。

可以补上批量操作步骤、支持格式和大小限制；如果搜索结果主要是在线工具，就先评估工具入口，只扩写概念帮助有限。

![](../images/growaiskills-gsc-old-page-refresh/003.jpg)

## 5｜改完要能看出有没有用

记下修改日期和具体改动。建议 2 到 4 周做首轮复盘，数据少就多观察一段时间；这是复盘节奏，不是见效承诺。

用相同时长、相同国家和设备，对比同一页面/查询的曝光、点击、CTR，排名只作辅助。注册、询盘等业务结果，要去站点分析工具看。

![](../images/growaiskills-gsc-old-page-refresh/004.jpg)

注意：GSC 排名是平均值，3–20 只是筛选机会的范围，不代表能轻松进前三；季节变化和竞争对手也会影响结果。

URL｜目标查询｜改动日期｜改了什么｜前后曝光/点击/CTR｜业务结果
