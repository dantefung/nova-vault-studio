# 对话杨涛：知识付费防坑指南

前两天跟涛哥线下直播聊天，这是他有史以来第一次跟人坐在一起直播，以前都是连麦的小鹅:很多大学生问我,快毕业了是不是要等毕业了再开始?还有些宝妈觉得自己年纪大了来不来得及?你怎么看?涛哥:分几个场景讲。大学生在校创业的比例不到2%,100个人里只有一个会想着去搞点副业。但恰恰是这1%的人,走路都带风,会拥有更多资源倾斜,人生就像滚雪球一样提前积累优势。人这一辈子从降生开始,就开启了资源掠夺的一生,这一点很残酷。你多一点别人就少一点,仅此而已。至于打工人做副业,实际上是开启人生的第二曲线。一个人的收入结构如果只有工资,抗风险能力非常弱。假设月薪8000,为祖国健康工作30年,不吃不喝到手300万,这辈子就这么多了,能干什么呢?什么都干不了。所以收入结构要健康。副业给自己的人生开了一个新的可能性,也许有一天副业收入是主业的五倍,你就可以真正为自己服务了。再说宝妈,你在婆家、在老公面前的家庭地位,经济来源是非常重要的一点。如果能搞点钱,每个月搞个几千块,会让生活变得更丝滑。送男生一句话:钱是英雄胆,赚钱是最大的修行。除了搞钱就不讲其他的了。1关于项目选择:要选择能长期积累的事小鹅:互联网上有这么多项目,这么多信息,我们该怎么判断哪些适合普通人上手?涛哥:我讲的这段话非常重要,大家注意听。搞项目就三个东西:流量、产品、运营。你每天都问自己,现在做的这件事情,在流量、产品、运营三个方向能不能给你提供锻炼。整体来看有四个确定性: 第一,技能上每年有没有提高 第二,每年有没有多赚更多的钱 第三,人脉——客户、私域、协作团队、供应商、社群朋友有没有变多 第四,在全网、在行业里的影响力有没有增加只要判断一件事情值不值得做,就看这四个东西。举个例子,如果去做无人直播、切片、混剪、搬运、店群这种只能做一次的事,我个人认为是没有沉淀的。我们要选择能够长期做、能在那三个方面的能力有锻炼、在那四个方面能有沉淀的,这样对自己的人生是一种负责。2关于AI:不要学,要用小鹅:现在很多人说要把AI渗透到生活里,你能讲讲自己是怎么用AI的吗?涛哥:我现在测试一下大家。在座的各位,同时在用ChatGPT、Gemini和Claude,且每天使用AI时间超过3个小时的,扣个1。我跟你说,只要这么做,你的上限会非常高。能安全地用到这些原生大模型,真的很厉害。我身边只要从2022年10月开始到现在坚持这么做的,基本都实现了十倍增长。AI不要学,要用。为什么?一个月内它就有大变化,每个月都有新东西出来。你现在只要保持好奇心、保持敏锐,去把这些新出的AI用起来,你积累的是手感、一线的手感,对你的网感和未来对工具使用的体感非常有帮助。一句话告诉大家:不是遇事不决问AI,而是万事问AI。怎么问?把AI当实习生。实习生你给他下了命令,他听不懂会反过来问你。你如果把它当实习生,这个行为做久了,你就会领悟到人机交互的最顶级境界——不要问AI能帮你做什么、能为你提供什么价值,要问你能为AI提供什么价值。你让AI做图做视频,可能做很多个才会出一个完成度很高的,这是抽卡,是概率。你提供的不断测试,是在帮AI收集样本。你想尽一切办法把事情交代清楚,这就是你对AI的价值。总结一句话:把AI当实习生用,用久了你就知道它真的太好用了,绝对比你聪明。如果你发现它降智了、弱智了,那是你没把它用好。3关于流量:流量结构和流量法则小鹅:我们学会了怎么用AI产出内容,还要有客户才能完成商业闭环。能分享一些获客的干货方法吗?涛哥:这又是一个大话题。流量、产品、运营,现在讲流量。实际上现在有个词叫流量结构。大家不是去小红书、闲鱼搞流量吗?公众号你们搜过吗?抖音图文搜过吗?拼多多、淘宝搜过吗?有大量的客户分布在全网不同的平台。而且小红书的逻辑和做其他平台的逻辑基本都是一样的。客户通过搜索相关关键词,一个搜索流量等于30个推荐流量。搜索流量,尤其是长尾的搜索流量、精准词的搜索流量,可以给你带来超多精准客户。首先要把不同平台做满。接下来要混不同的群,左手需要写手,右手需要客户。整个闭环来讲,AI代写是一个模式级的变革。它属于派单逻辑,大家理解一下派单逻辑有多牛逼:快递是派单、滴滴是派单、骑手是派单、家政阿姨是派单、维修师傅是派单,美甲美睫都是派单。这个模式可以让你变得很大。创业到最后就是一场大型套利游戏,你有流量,就可以不停派单出去。流量在全网能铺出的地方都去铺出,用的是一套逻辑,就是占据不同搜索词的搜索入口。如果只在小红书获客,那是不对的,因为你只占了整个圆的一点点,平台做一点改动,流量就断崖式下跌。一个成熟的创业者,应该提前布局到不同平台,让流量来源非常丰富,让流量结构非常健康。小鹅:所以我们要做的是全网布局,而不是只盯着一个平台4关于贵人运:如何向上社交小鹅:年轻人该如何提升自己的贵人运,能够得到一些机会和扶持,快速成长?涛哥:我先说个现实的东西。年轻人释放善意非常重要,我在评论区看到很多优秀年轻人在帮小鹅发微信号、地球号,这就是释放善意。给大家讲两个词,第一个叫工具人。人和人是分层的,由于年龄阶段、社会阶段分成三六九等。比我们高层的人就是所谓的贵人,但他们不一定能成为我们贵人。这些人时间不多了,所以他们的时间注定值钱。他们愿意花钱花资源去找人帮处理事,这就是必然。当他要找人的时候,机会出现在哪?不是向上,是出现在同层。每个大佬想做私域、搞AI、搞电商、搞直播,会在周边问有没有小伙子、小伙伴会搞这个。他的直属小弟就会想那个谁挺不错,就把人往上推了一下。把事情办漂亮了,就穿透圈层了,贵人运不就来了。所以第一个法则:在你的同一年龄阶段社会阶段的圈层里,但行好事,莫问前程,要去利他。第二点叫结构洞。人的社交是一张网,网有一个个节点。你要有意识地记住你圈子中每个领域最强的三个人,不断迭代你心中最强的三个人。两三年后你会发现人生彻底变化,你会活在一张信任之网中。5关于信息获取:如何找到优质信息源小鹅:你总会冒出一些奇怪的词,像结构洞、信任之网,我们该怎么持续获取优质信息?涛哥:优质信息来自优质的信息源,优质的信息源是迭代的。首先让你最喜欢的几个博主给你推荐一波,或者让你最信任的几个朋友推荐一波。然后看这些博主日常推荐什么书、什么号。做通讯录管理,每天蹲马桶的时候删掉三个人,不开心就屏蔽几个人,慢慢你的朋友圈就变干净了。朋友圈经常会发一些公众号、优质账号、优质内容出来,你就去关注,看优秀的朋友都在看哪些东西。这就是朋友圈升级。当然这种方法我有100条,直播间讲不完。小鹅:优质的信息它是不流通的,只会在一些密闭的小圈子里流通。所以一定要给自己找一个环境、找一个圈子。6关于知识付费:如何避免被割韭菜小鹅:市面上有很多知识付品,我们该怎么取舍,才能更快拿到想要的结果?涛哥:四个字:望闻问切。望——公开的信息里有魔鬼。看这个人的公众号、视频号、朋友圈,把朋友圈往前翻两三百条,你还看不出他有没有料,那你就活该被割了。如果一个人三年前卖奶粉做代购,三年后还在卖奶粉做代购,当你需要找代购时一定会找他,因为他靠谱。闻——闻味道。看他的内容,讲的东西对不对你的味道。有些人很厉害但你生理性不爽,看他不顺眼,味道不对,他再强也不行。问——现在马上加他,当场问,看他耐不耐心。有些人在直播间说得一本正经,但你加了微信、转了定金后一对话他就不耐烦,说明知行不合一,赶紧让他滚蛋。切——具体问题给到他。说清楚你是什么样的人,每天可支配时间怎样,最在意的东西是什么,跟他聊透。经历这四步之后,再决定给谁付费。小鹅:还有一点,有些人说知识付费是智商税。涛哥:说智商税的人主要是穷,有一种心态叫众人皆醉我独醒,实际上是众人皆醉赌你没钱买酒。钱是用来换什么的?钱是用来换加速度的,钱是用来解决问题的。举个例子,你们打网游,每天花2小时做任务,一个月60小时。买个月卡128块钱就解决了。天天做任务的人在嘲笑花128买月卡的人,你60小时做任务不值128块钱吗?谁的智商才低?钱是用来换加速度的,钱是用来解决问题的。7关于离职:什么时候可以离职创业小鹅:很多人问本职工作没盼头,什么时候可以离职?涛哥:我跟大家说清楚,副业收入是主业的五倍,且连续三个月保持增长,且收入增长的瓶颈是由于时间导致的,这时候再考虑离职。我再重复一遍:副业收入是主业的五倍,且持续三个月稳定增长,而且收入增长的瓶颈是由于时间不够带来的,这时候你再考虑离职。不要轻易离职,本职工作起码能维持最低生活保障。如果每天可支配时间有3到4小时,就先做副业,等收入稳定了再考虑离职。那种随便脑子一热就离职的,我觉得太冲动了,往往会后悔。小鹅:我很多学员都是做写作做到主业收入五倍以上才真正裸辞的【往期推荐】【最适合互联网新手的小项目——AI写作】【大学上课，纯粹的浪费生命】【被选择的理由】
