我代课问我需不需要很多启动资金,这个问题就很典型她看到的是我现在的样子,觉得创业肯定要很多钱、很多资源但她没看到的是,我最开始也是从零开始,一点点摸索出来的这就是信息不对称制造的幻觉门槛局外人看到的永远是结果的光鲜,看不到过程的朴素看到别人月入五位数,就觉得人家肯定投入了很多钱;看到别人做得很好,就觉得人家肯定有特殊资源其实互联网创业,真没那么高的门槛，小红书开个虚拟资料店，或者做个博主接点商单，每个月领点小四位数的低保是很容易的包括我们做AI写作，说白了，一个手机，开几个号，你的线上摊位就支起来了，几乎每一分都是纯利润



我代课问我需不需要很多启动资金,这个问题就很典型



她看到的是我现在的样子,觉得创业肯定要很多钱、很多资源



但她没看到的是,我最开始也是从零开始,一点点摸索出来的



这就是信息不对称制造的幻觉门槛



局外人看到的永远是结果的光鲜,看不到过程的朴素



看到别人月入五位数,就觉得人家肯定投入了很多钱;看到别人做得很好,就觉得人家肯定有特殊资源



其实互联网创业,真没那么高的门槛，小红书开个虚拟资料店，或者做个博主接点商单，每个月领点小四位数的低保是很容易的



包括我们做AI写作，说白了，一个手机，开几个号，你的线上摊位就支起来了，几乎每一分都是纯利润
