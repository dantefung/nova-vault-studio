# 独立开发者必收藏：带 Prompt 的 AI 图库，省掉创意难题

> AI 工具普及之后，做一个能上线的网站，技术门槛已经低了很多。但产品被做出来，只是第一步。接下来更难的是：怎么让别人愿意停下来，看一眼，用一下。Landing page 上的图，就是第一关。

## 做图的难点

**难的不是技术，是创意。** 比如你做的是一个给中小电商卖家用的生图工具，Landing page 需要一张让人有购买欲的产品图。桌上摆一瓶汽水，这没什么稀奇。但如果是挂着冰凉水珠的瓶身、背后是模糊的夏日热浪，光是看一眼就让人觉得口渴。

**版权问题也不能忽略。** 很多人随手从网上扒图，没有认真看 License，直接上到产品中，结果不被允许商用，网站会被投诉下线。

## 每张图的关键信息

真正有价值的地方，不只是图好看，而是每张图点进去能看到几个关键信息：

![图片详情](images/ai-image-prompt-libraries/003.jpeg)

1. **Prompt**：生成这张图用的完整提示词，可以复制，也可以拆开学习
2. **出处**：不少图片会标注来源（如 Twitter 账号），可以顺着来源继续找
3. **模型信息**：告诉你这张图大概是用哪个模型生成的
4. **License 说明**：能不能商用（最重要）

![CC BY 4.0 License](images/ai-image-prompt-libraries/004.png)

**CC BY 4.0 协议**：可以复制、分发、修改、用于商业目的，唯一条件是必须注明原作者/来源。

另外，meigen.ai 还有一个特别喜欢的功能：**Prompt 可以一键翻译成中文**。先看中文，再对照英文，更容易理解怎么描述主体、构图、光线和氛围。

## 三步使用方法

**第一步：找创意。** 先按分类浏览，找那些第一眼感觉对的图。不用纠结图里的主体是不是和你的产品一样，要看的不是它拍了什么，而是它怎么构图、怎么用颜色、怎么制造氛围。

**第二步：拿 Prompt 微调。** 把这张图的 Prompt 复制下来，做两件事：一是换主体（如把汽水换成你的产品），二是加上你的品牌关键词、颜色、材质或风格描述。

**第三步：生成，然后放到页面里试。** 用你熟悉的生图工具跑几轮，挑出符合品牌调性的图。

> 你不是搬运别人的图，而是借用别人的创意思路，生成自己的素材。既省掉从零想画面的时间，也能避开直接用图带来的版权风险。

## 让 AI 帮你挑图

把候选图全部放到一个预览 HTML 页面里：把网站截图丢给 Coding Agent（如 Codex），告诉它按这个配色和风格来排版，然后把候选图全部放进去，做成一个瀑布流预览页。

![预览页面](images/ai-image-prompt-libraries/005.jpeg)

这样做的好处：能在上线之前先看整批图放在一起的气质对不对。一张图单独看很漂亮，放到网站里可能就很别扭（如深色系网站放了糖果色图）。把候选图统一放在接近网站真实风格的背景下预览，一眼就能筛掉那些单独好看、放进去不对的图。

## 总结

> AI 时代做出一个产品已经没那么难了，难的是做出来之后，怎么让别人知道，怎么让别人愿意用。Landing page 是产品的第一张脸。图片够不够吸引人，直接决定访客会不会继续往下看。找到合适的工具、图库和 Prompt 参考，可以让这件事轻很多。独立开发者的时间是有限的。技术问题，AI 已经帮你解决了大半。接下来更该花心思的，是销售、宣传，以及让产品真正被看见。
