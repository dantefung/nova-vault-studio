# 【精读】是时候让 Agent 上线你的个人网站了

> **核心结论**：每个人都需要一个"实时对外的坐标"——个人网站不再是技术活，而是 Vibe Coding + Agent 的**口喷**工程。**技术栈只有两个 CLI（GitHub CLI + Wrangler），授权一次后靠嘴就能部署**。空格丶用这套流程上线了 kongge.space，工具 / SKII / 产品 / 摄影 / 关于我 / 合作 6 个模块完全靠嘴构建。

> **关键洞察**：
> - **为什么是现在**：Notion 创始人 Ivan Zhao 当年做 Notion 是因为艺术生卡在技术上；今天 Vibe Coding 让"不会写代码"的问题彻底消失
> - **个人网站 ≠ 博客**：是**实时对外的窗口**——承载作品、连接搜索引擎、让大模型索引你的内容
> - **4 模块收敛**：我是谁 / 我做过什么 / 我想过什么 / 我能提供什么
> - **零命令行教程**：6 步走（买域名→加 Cloudflare→改 DNS→装 CLI→授权→部署），全程一句话指挥 Agent
> - **部署一句话**：「帮我创建 GitHub 仓库，提交代码，连接到 Cloudflare 用 Pages 部署到 xx 站点」

## 第一部分：为什么是现在？

### 1. Notion 的起点故事

Notion 创始人 Ivan Zhao 在大学时学艺术+计算机。
- 艺术专业同学毕业要找作品集网站
- 人人都不会做、都做不出来
- 只能找有计算机基础的人帮忙
- **痛点**：有作品、有审美，**卡在了技术上**
- Ivan 想做"不用写代码也能建网站的东西"

这是 Notion 的萌芽。

### 2. 十多年后答案变了

**不再需要 Notion / WordPress / 买主题模板**：
- Vibe Coding 直接实现
- **不写代码、不花时间、不花钱**
- 制作流程：收集资料 + 指挥 Agent 构建

**收集资料最费时间**：
- 自己简历、社媒动态
- 做过的工具、写过的 Skill、上线过的产品
- 拍过的照片、原创内容
- 知识库

**信息架构**：工具、SKII、产品、摄影、关于我、合作 6 大模块。

### 3. 网站 ≠ 博客

**4 模块收敛**（作者最终方案）：

| 模块 | 内容 |
|------|------|
| 我是谁 | 首页自我介绍 |
| 我做过什么 | 职业经历、产品、工具、Skill |
| 我想过什么 | 沉思笔记、原创内容 |
| 我能提供什么 | 寻找商机或合作伙伴 |

> 一个实时对外展示自己的窗口，比社交媒体更能体现自己是谁。

## 第二部分：网站能给你带来什么？

1. **持续记录成长和思考**——夜深时翻阅过去写的东西，比翻朋友圈更认识自己
2. **搜索引擎找到你**——一个域名 = 实时对外连接的窗口
3. **大模型索引你的内容**——AI 搜索时代，被 LLM 引用比 SEO 还重要
4. **字体、颜色、留白、结构**——完全由你说了算，体现审美品味
5. **承载作品**——每个 demo 不再是 localhost，每个人看得到、用得到，才叫产品

## 第三部分：完整部署教程（6 步）

### 技术栈

**只有两个 CLI**：
- `gh` — GitHub CLI
- `wrangler` — Cloudflare CLI

**授权一次后，再也不用碰命令行**。

### 步骤 1：买域名

- 阿里云 / 腾讯云都行
- **别纠结**——.com > .cn > .net
- 很多人的建站热情耗死在选域名上
- **先买能接受的，网站是活的，域名以后可以换**

### 步骤 2：把域名添加到 Cloudflare

1. 注册 Cloudflare，登录控制台
2. 左侧菜单 → 域名 → 添加域名
3. 输入域名地址，点击下一步
4. **选择免费套餐**
5. 一直往下点，会给到**两条 DNS 服务器地址**

### 步骤 3：拿到 DNS 地址后回域名服务商改

1. 复制 Cloudflare 给的两个地址
2. 去购买域名的云厂商
3. 域名解析 → 修改 DNS 服务器
4. 选择"使用非腾讯云 DNS"（或对应厂商），输入两个地址
5. 提交

> **作用**：把域名的 DNS 解析交给 Cloudflare 处理。

### 步骤 4：装 CLI，各做一次授权

```bash
gh auth login
wrangler login
```

**授权是一次性的**：
- Agent 浏览器打开你的账号 → 点击授权
- 之后 Agent 就有直接操作 GitHub + Cloudflare 的能力
- **从这一刻起，你只需要说话**

### 步骤 5：配解析记录

在 Cloudflare 的 DNS 记录配置域名：
- 类型：**CNAME**
- 名称：域名本身 + `www.域名`

### 步骤 6：部署

**两种部署方式选择**：

| 选项 | 适用 |
|------|------|
| **Pages** | 纯前端 → 个人网站、作品集 |
| **Workers** | 需要后端 → 工具、调模型 API、转发请求、存数据 |

**部署指令**（一句）：
> 「帮我创建一个 GitHub 仓库，把本地代码提交推上去，并连接到 cloudflare，用 Pages 部署到 Cloudflare 的 xx 站点。」

**更新部署**（一句）：
> 「帮我推送仓库并部署网站。」

你说完，Agent 执行，线上就变了。

## 第四部分：写在最后

> 如果你也用 AI 做过一些东西，也有一堆散在各处、自己都快忘了的内容。

## 核心方法论提炼

### 1. 网站是"对外的实时坐标"

**不是博客，是窗口**。承载作品、被搜索引擎/大模型索引、表达审美——这是社交媒体替代不了的。

### 2. Vibe Coding 让"不会写代码"消失

十年前 Notion 用"模块化拖拽"解决；十多年后 AI 直接帮你写、帮你部署。**门槛从"会技术"变成了"会说话"**。

### 3. 工具栈极简 = 部署极简

只有 `gh` + `wrangler` 两个 CLI，授权一次后**全部靠嘴**。比学 Vue/React/Next.js 部署文档快得多。

### 4. 整理自己的过程 = 认识自己

> **真正的收获可能不在网站上线的那一刻，而在你整理它的过程里。**
