# 外汇交易基础概念：货币对、点差、汇率、直盘、交叉盘、外汇保证金等

## 1 直盘、交叉盘以及货币对、点差

### 货币对基础

外汇交易不是孤立地买卖单一资产，而是同时买入一种货币并卖出另一种货币，这两种货币的组合构成货币对。

**基础货币**（Base Currency）：排在斜杠左边的货币，数值始终默认为"1"。

**报价货币**（Quote Currency）：排在斜杠右边的货币，代表需要多少单位才能兑换1单位基础货币。

例如 EUR/USD = 1.1200：买入1欧元需支付1.1200美元。

核心关键点：**所有交易动作（买或卖）都是针对基础货币而言的。**

### 货币对三大分类

| 类型 | 举例 | 特征 |
|------|------|------|
| 主要货币对 | EUR/USD, USD/JPY, GBP/USD | 含美元，流动性最高 |
| 次要货币对 | EUR/GBP, GBP/JPY, EUR/JPY | 不含美元 |
| 奇异货币对 | USD/TRY, USD/MXN, USD/ZAR | 流动性低，波动大 |

### 直盘 vs 交叉盘

- **直盘**：含有美元的货币对（如 EUR/USD）
- **交叉盘**：不含有美元的货币对（如 EUR/GBP）。交易交叉盘本质上是绕过美元，直接交易两种货币的相对强弱

### 汇率

汇率是一种货币相对于另一种货币的价格。两种类型：

- **浮动汇率**：随市场供需实时波动（大多数主流货币）
- **固定汇率**：政府强力干预（如香港联系汇率 7.75-7.85）

### 点差

在外汇交易中，经纪商提供双向报价：

- **Bid（卖出价）**：你卖出基础货币的价格
- **Ask（买入价）**：你买入基础货币的价格

**点差** = Ask - Bid，是经纪商的"过路费"。

例如 EUR/USD 报价 1.10000 / 1.10012，点差 = 1.2 点。一键买入的瞬间就以较高 Ask 价成交，立刻平仓只能以较低 Bid 价成交，所以一开仓就显示小额浮亏。

## 2 外汇保证金、滑点

### 外汇保证金（Margin）

外汇保证金是开立杠杆头寸时被经纪商占用的抵押资金，不是手续费，平仓时会释放。

1标准手 = 100,000 基础货币单位。保证金制度允许用极小比例资金控制数十倍仓位。

**风险控制机制**：
- **追加保证金（Margin Call）**：保证金水平跌至特定比例（如100%），平台警告，限制开仓
- **强制平仓（Stop Out）**：保证金进一步下跌至强制平仓线（如50%/20%），系统自动平掉最大亏损头寸

### 滑点（Slippage）

成交价与预期价的差异，源于：

1. **网络延迟（Latency）**：订单传输时间内价格变动
2. **市场波动性（Volatility）**：重要数据公布或突发事件时价格爆发式跳动
3. **流动性深度（Liquidity Depth）**：大单超出当前最优报价处的挂单量

滑点分两种：
- **负滑点**：买贵了或卖便宜了
- **正滑点**：买便宜了或卖贵了

使用**限价单**可避免负滑点。
