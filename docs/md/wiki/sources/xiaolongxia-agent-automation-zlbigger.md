# 我借助小龙虾把『做个网站养老吧』升级了！

> zlbigger 系列第三篇——上次写的「AI 躺赚」**全面升级**到「小龙虾 Agent + Codex 本地执行 + 飞书/微信远程触发」。原文 123 行 19 张截图，**展示了 8 个真实在跑的自动化流水线**。

## 一句话核心

> **设计、代码、部署、运维——AI 自己搞定**。
> 剩下的就是你**的创意、策略、业务、执行**。

**核心转折**：从「手动跑 6 个 AI 打工人」升级到 **「Agent 自主跑」**——Agent 自己发现需求、自己写产品、自己部署。

## 3 个关键能力升级

| 之前 | 现在 |
|------|------|
| 手动触发 6 个 AI 打工人 | Agent **全自主** 调度 |
| 单一站点 linggan.io | 多个站点 × 多种内容形式 |
| 人在电脑前启动 | **手机远程**（微信/飞书）触发 |
| 6 个 prompt 都中文 | 中英混合 prompt |

## 8 个真实在跑的自动化流水线

### 1. 壁纸站升级（凌晨自动化）

```
凌晨 4 点：AI 生词（提示词）
凌晨 5 点：自动投稿
     ↓
GPT-image-2 自动画图
     ↓
自动发到网站
```

### 2. 穿搭题材站（找图+处理+发布）

```
指定时间 → 自动下载相关图片到指定目录
     ↓
指定时间 → 读取目录图片信息
     ↓
AI 看图写标题 + 看图写内容
     ↓
自动发布 → 删除素材
```

### 3. AI 资讯站（每天自动逛科技圈）

```
每天自动逛科技圈
     ↓
挑有价值的 AI 新消息
     ↓
用自己的话写成文章
     ↓
发到对应栏目
     ↓
没货就不发
```

### 4. 报告解读（一鱼多吃）

```
读取 PDF 报告
     ↓
AI 通俗易懂解读
     ↓
发布到对应栏目
     ↓
同步公众号分发
```

### 5. 🚀 商机→产品→开发 三阶段流水线（核心新观点）

```
商机挖掘 Agent：全网搜需求（关注某源/某数据）
     ↓
产品提炼 Agent：筛选可落地的点子（看数据）
     ↓
开发 Agent：自动写代码 + 部署到自己服务器
     ↓
一旦发现数据不错的 → 人工介入
```

**这是 zlbigger 整套方法论的「AI 版本升级」**——从「找到一个需求，自己做工具」升级到「**Agent 自己找需求、自己做、自己部署**」。

### 6. AI 工具返佣引流

**做法**：在自家网站上挂 AI 工具平台返佣链接（不打积分，要返现，打到微信/支付宝）。

### 7. 网盘拉新

**做法**：根据网站内容打包，在网盘里提供"配套资料"。

### 8. 电商联盟返佣（Agent 一条龙）

```
AI 自动上商品（商品信息）
+ 高质量商品图（GPT-image-2）
     ↓
自动拼出有吸引力的商品内容
     ↓
自动挂上带返佣 ID 的商品链接
     ↓
一个 Agent 从头忙到尾
```

## 小龙虾 Agent + Codex 的特殊价值

### 为什么用小龙虾？

| 功能 | 价值 |
|------|------|
| **本地自动跑** | 电脑开机就跑任务，不需要云服务 |
| **远程触发** | 微信/飞书 → Agent → 执行任务 |
| **权限可控** | 哪些能改、哪些不能改，全局可配 |
| **Codex 集成** | 复杂开发任务授权 Codex 执行 |
| **截图/录屏** | 任务执行过程可视化 |

### 关键的远程触发场景

> **手机刷到突发新闻 → 打开微信或飞书 → 输入网址 + "帮我把这个内容更新到某某网站" → 几分钟后人家就干完了**。

这就是所谓 **"Agent-as-a-Employee"** —— 你的 Agent 24 小时待命，你随时「喊一声」就来干活。

## 几个值得借鉴的细节

### "试错成本足够低"

> 一年几十块甚至十几块的域名 + 一年 20 美金的服务器 + 免费的 cloudflare 资源。

**单站成本 = ¥200-300/年**。失败 10 次也才 ¥3000。

### "不挑模型"也行

> 重要的活儿也用不到最好的大模型来干活儿，包月订阅的很多国产模型做起来也绰绰有余了。

**国产订阅大模型 vs GPT-4/Claude Opus**：

| 任务类型 | 推荐模型档位 |
|----------|------------|
| 内容生成 / 标签 / 标题 | 国产 + 基础能力即可 |
| 写提示词 / 写代码 | Codex + Sonnet 级 |
| 复杂决策 / 投资分析 | Opus 级 |

### "数据可观察后才介入"

> **一旦发现一个数据不错的，就开始人工介入**就好了。

**数字引导 + 人工放大**——Agent 跑数据，人聚焦高潜力需求。

## AI 三阶段流水线（核心心法）

```
      商机               产品            开发
       ↓                  ↓              ↓
      全网搜          筛选可落地        自动写代码
       |                  |               |
       v                  v               v
   关注某源/       看哪些点子        自动部署到
   某指标         数据不错           自己服务器
                   │
                   ↓
              人工介入放大
```

**核心洞察**：商机来源是动态可学习的，Agent 可以 7×24 学习。
