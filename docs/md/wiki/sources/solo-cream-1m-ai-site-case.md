# 一个人靠 AI 做到百万美元营收：哥飞社群案例复盘

> 越是大市场、竞争者越多的领域越有搞头——找到切入口，挖下一小块就能吃饱。

<!-- more -->

某位不愿具名的低调哥飞群友发了照片，展示了自己在 Creem 账号开号近一年达成的成就：最近 Creem 从海外寄过来的三块成就奖牌，分别对应总收入达到 $100K、$500K 与 $1M。1M 即 100 万美元。

## 案例要点

**基本盘**：这是一位奶爸，一边带娃一边上站，主要借助 AI 写代码，一年时间达成 100 万美元营收成就。

**口径**：这只是 Creem 一个平台的收入，PayPal、Stripe 等其他收款平台尚未计入。

**成本结构**：100 万美元是营收不是纯利，还需扣除 API 成本、流量成本与其他杂项。但因为只有一个人，也就不用扣除人力成本——而这部分成本在正规团队里不低。

**收入模式**：主要靠用户付费订阅，做的是竞争者众多的 AI 图片、视频生成领域。

## 三条可迁移的判断

### 一、大市场里切小块，比小市场里做全量更现实

越是竞争者多、蛋糕大的领域，越有搞头。原因是这类领域已被验证有付费需求，你只需要找到切入口，挖下一小块就能吃饱。不需要和头部玩家争整个盘子。

### 二、营收不等于利润，先把成本项列全

这个案例之所以值得复盘，恰恰因为作者自己把口径讲清楚了：营收需扣 API 成本、流量成本和杂项；个人项目的优势是省掉人力成本，但省掉的部分会由更长的单人工时补上——一个人做，成本不是零，是从别处挪过来的。

### 三、获客渠道不止 SEO

原文提到，用 SEO 搞流量只是获取流量的其中一种渠道，其他还可以用红人在社媒推广、花钱投放广告等；社群近期在研究的 GEO（生成式引擎优化）也已有不少群友的网站从 ChatGPT 拿到能直接变现的流量。

**所以社群虽然以 SEO 出名，但并不局限于 SEO。**

## 社群的方法论路径

原文同时解释了为什么社群内流传的案例多是「新词新站」：

> 大家能看到新词新站模式，是因为我估计新人先去做更容易拿到正反馈的新词来提升信心、积累经验，并不代表我们群里大家就只做新词新站。

完整路径是：**用新词新站练手 → 瞄准中大需求（真的会有人付费的需求）做产品 → 搞流量 → 流量变现。**

新词站是低门槛的练手段，拿到正反馈、建立信心之后要转向真正有付费体量的中大需求。

## 边界与提示

- 案例为匿名转述，数字来自当事人自述与平台奖牌，未经独立核验
- 收入高度依赖单一平台（Creem）与单一细分（AI 图片/视频生成），未说明是否已过增长窗口
- 奖牌是累计口径，不代表任一单月或单一产品的盈利能力
- 本文不构成收益预期，AI 内容赛道竞争与政策变化快
