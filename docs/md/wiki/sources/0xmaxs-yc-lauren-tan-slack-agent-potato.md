# 九江月.hl：土豆姐 Lauren Tan 的 YC 访谈——新功能从想法到上线全流程在一个 Slack 里解决

> YC 最新访谈：土豆姐（Lauren Tan，xAI Grok Bot 负责人）演示新功能全流程在 Slack 里跑通——她把一段 X 视频发给机器人 Potato，Potato 询问能否在 Grok Bot 里做类似功能，随即启动 Cursor 云端智能体做出原型，同事据返回效果提出意见，反复打磨后上线；她现场画流程图解释：让智能体像真实用户一样操作应用，记录性能、发现问题，再回去改代码，全自动跑通，工程师因此能花更多时间思考「哪些功能值得上线，以及用户最需要什么」。附：她在新加坡长大、用电饭煲做海南鸡饭（米、鸡汤、鸡肉 + 姜葱白胡椒）的生活片段。

有时候，我想找点生活的感觉，就会自己开车。不久就会后悔了。”👩‍🍳

土豆姐 Lauren Tan 在新加坡长大，平时经常用辅助驾驶。直播里聊到偶尔自己开车，她还顺手给大家科普了一个新加坡冷知识：在那儿买车，得先竞标一张拥车证（COE）。有时候，光这张证就比车本身还贵。

同一场直播，她还忍不住吐槽了 Matt 的晚饭。开播前，Matt 把鸡汤直接倒进海南鸡饭里。她看得直皱眉，说这跟在牛排上挤番茄酱差不多。

在新加坡长大的她，自己就用电饭煲做过海南鸡饭。米、鸡汤、鸡肉，再加姜、葱和白胡椒。讲到最后，她笑着说，鸡肉特别嫩，真的很好吃。

YC 最新访谈上线，土豆姐聊的又全是干货🙋‍♀️

将一个新功能从想法做到上线，全流程都在一个 Slack 里里解决。

她把一段 X 视频发给机器人 Potato，询问能不能在 Grok Bot 里做出类似的功能。

随即，Potato 启动 Cursor 云端智能体，成功做出原型，同事根据返回的效果提出意见，反复打磨后成功上线。

土豆姐还在现场画了一张流程图，解释这套机制的运行原理：让智能体像真实用户一样操作应用，记录性能、发现问题，再回去改代码，全自动跑通。

这样，工程师就有更多时间去思考，哪些功能值得上线，以及用户最需要什么。
