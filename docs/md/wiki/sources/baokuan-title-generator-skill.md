## 一、公众号写作与传统写作的根本不同

### 传统写作流程

```
阅读 → 学习 → 反思 → 输出
```

读很多，想明白，再写。

### 公众号写作流程

```
找热点/选题 → 标题 → 构思 → 输出
```

> 在公众号这套流程里，**热点对应的关键词要在标题里体现**，能带来较好的 SEO 和推荐流量。
>
> 最好在**写作前定好标题方向**——给这篇要打的点、要给的价值、要勾的情绪，都锁死了。

**关键洞察**：标题一旦定好，写内容时就有**一根准绳**，不容易跑偏。等写完再回头拟标题，思路已经被内容框死了。

## 二、什么是好标题？

> 标题的任务是**让人看见就想读**。

作者从**几百篇爆款**里归纳出**16 种反复出现的套路**。

### 新规则下"震惊体"已死

> 公众号自五月改推荐规则以来。对「最」「彻底」「震惊」「首个」这类**极致词**、**搞标题党**、**题文不符**，会被判定为**夸大误导**，直接限流。

**最近容易火的标题是**：
- 口语化的
- 观点类的
- 接地气的
- 有情绪化的

### 6 种典型标题套路

| 类型 | 特征 | 例子 |
|------|------|------|
| **数字反差型** | 两个悬殊的数字制造张力 | 「一个月，从 8 万赚到 300 万」<br>「花 68 元，我们让豆包干完了一个小团队的活」|
| **生活痛点型** | 把大家抱怨的原话说出来 | 「广东奶奶微信里 77 万条未读，孙女崩溃」<br>「PPT 又被打回来了，这是第 8 版」|
| **揭秘型** | 暗示有被藏起来的真相 | 「Anthropic 偷偷在 Claude 中植入了代码，只为识别中国用户」<br>「独家：阿里内部全面禁用 Claude」|
| **对话剧本型** | 一段有反转的对话 | 「你用了半年 Claude Code，懂 Skills 吗？」<br>「Claude、Codex、Agent、Skills 你都学了？」|
| **悬念留白型** | 告诉你「发生了」，不说「是什么」 | 「记一个我被 Claude Fable 5 震撼的瞬间」<br>「别睡了，Anthropic 今天凌晨又又发东西了」|
| **极值型** | 把最 xx 摆到明面上 | 「千问 AI 眼镜，全国销量第一」<br>「Claude Code 史诗级更新，把整个终端搬进了浏览器」|

> 标题里始终有一个「**人**」在场，是「**我**」在跟读者说话。

## 三、Title-Generator Skill 怎么用

### Skill 仓库

```
https://github.com/SpaceZephyr/creator-buddy/blob/main/skills/baokuan-title-generator
```

### 两种用法

**用法 1：先写大纲，让大纲来生成标题（推荐）**

```
输入：文章大纲
输出：候选标题列表 + 评分 + 风险
```

- **你挑一个定下来**
- 照着这个标题写正文
- 全程不跑偏

**用法 2：给已经写好的文章换标题**

```
输入：完整文章
输出：10 个候选标题 + 评分 + 风险
```

每个候选还有**评分和风险**说明。

> 哪个标题最贴合你这篇的调性，**最后还得你自己拍板**。

### 重要认知

> 阅读量是**账号体量、选题、发布时间、内容质量**一起决定的，**标题只是其中你能攥在手里的那一环**。

## 六、关键洞察提炼

### 1. 「震惊体」已死

公众号改推荐规则后：
- 极致词（最/彻底/震惊/首个）= 限流
- 标题党 = 限流
- 题文不符 = 限流

### 2. 「我」是核心

**标题里始终有一个「人」在场**，是「我」在跟读者说话。

### 3. 16 种套路选择

- **数字反差型**：2 个悬殊数字
- **生活痛点型**：抱怨原话
- **揭秘型**：暗示真相
- **对话剧本型**：有反转对话
- **悬念留白型**：只说"发生了"
- **极值型**：最 xx
- **认知反转型**
- **隐藏机制型**
- **场景画面型**
- ... 共 16 种

### 4. 先定标题再写内容

公众号写作流程与传统写作**根本不同**——先锁标题方向，再按方向写。

### 5. 双模型协同

> fable5（精准）+ GPT-5.6（全面）= 锋利方法 + 完整框架。
