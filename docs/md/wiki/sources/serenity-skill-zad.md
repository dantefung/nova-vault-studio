# ZadAnthony/serenity-skill — Serenity 供应链卡点逆向投资方法论 Claude Code Skill（15 Stars）

> 把 Serenity（@aleabitoreddit）的"供应链卡点逆向"投资逻辑操作化为 Claude Code Skill，用她**怎么提问、怎么排除、怎么把热闹拆成可验证环节**的方式帮你分析一只票/一个板块/一个 thesis。

<!-- more -->

## 核心定位

不是模仿她说话，而是提取**认知操作系统**：怎么框定问题、怎么 disqualify 一个 idea、怎么把模糊的"AI 受益"拆成可验证的环节。

适用：美股 / AI 供应链 / 光模块（CPO·硅光·InP）/ 半导体 / 内存 / NeoCloud / 电力液冷 / 机器人等投资分析。

## 分析流水线

1. **建 thesis** — 先立论再谈标的
2. **沿供应链逆向找"卡点中的卡点"** — 不是找受益者，是找不可绕开的节点
3. **数字分级标注** — 一手源 / 推断 / 推测，标注置信度
4. **独立 reviewer 复核** — 防确认偏误与取数失真
