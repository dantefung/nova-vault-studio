# 何笠聊 AI（@HeLi8866）：GitHub 上早就有了现成的 Grok Bot 团队——15 个开源项目清单

> 15 个现成的 Grok Bot / Agent 团队开源项目清单，覆盖写代码、做研究、做营销、做交易与打理个人生活：Agent Org Chart（现成团队架构，工程/营销/客服/销售齐备）、Grok Factory（总协调+分派）、multiBot（自动生成专职队友）、Grok Bot Second Brain（5 个 Agent 分管协调/记忆/研究/日常运营）、Foreman（盯进度并核验交付结果）、grokbot-x（X 选题调研到改文案一条龙）、PhoneZero（打电话订餐厅，关键步骤需人工点头）、BOTROSTER（可自部署的 AI 队友，共享文件、用浏览器、跑定时任务）、Grok Bot Profiles（4 个专职角色：写需求/复现 Bug/提 PR/验 PR）、HyperGrok Trading Desk（7 个 Agent 分管行情/研究/策略/风控/下单），以及交易基础设施 Cryptofeed、CCXT、Freqtrade、VectorBT、QuantStats。核心建议：先挑一个团队给它一个明确的活，用 API/MCP/脚本把专职 Agent 串起来，提前定清每个 Agent 管什么、哪些操作需你批准。

我的天！这也太狠了！！

很多人还在花几周时间从零搭 AI Agent 团队，GitHub 上早就有现成的 Grok Bot 团队了。

写代码、做研究、做营销、做交易，连打理个人生活的都有。

这 15 个项目建议先打开看看：

01 / Agent Org Chart：现成的团队架构，工程、营销、客服、销售都有

https://t.co/n3KaxY9ZY7

02 / Grok Factory：一个总协调，把写代码、做研究这些活分给专门的 Agent

https://t.co/i11D5CeiYq

03 / multiBot：自动生成专职队友，重活直接甩给编程 CLI

https://t.co/1D48A9PeUx

04 / Grok Bot Second Brain：5 个 Agent 分工管协调、记忆、研究和日常运营

https://t.co/SEqAwYGgmH

05 / Foreman：盯着 Agent 团队干活，发现卡住的任务，还会核验交付结果

https://t.co/vO1HqOO6YV

06 / grokbot-x：X 选题调研、写草稿、发帖、改文案一条龙

https://t.co/bkF609Dv7J

07 / PhoneZero：让 Grok Bot 能打电话、订餐厅，关键步骤要你点头才执行

https://t.co/TvtqkwqOoa

08 / BOTROSTER：可自己部署的 AI 队友，共享文件、能用浏览器、能跑定时任务

https://t.co/t4CwYyuLpL

09 / Grok Bot Profiles：4 个专职角色，写需求、复现 Bug、提 PR、验 PR

https://t.co/vykgMHE5nG

10 / HyperGrok Trading Desk：7 个 Agent 分管行情、研究、策略、风控和下单

https://t.co/bvEIjGqgqd

11 / Cryptofeed：实时推送加密货币成交、价格和订单簿

https://t.co/wtrrBUCU4s

12 / CCXT：一套 API 接上 100 多家交易所

https://t.co/saKMtqXadP

13 / Freqtrade：回测和跑交易策略，支持模拟盘和仓位跟踪

https://t.co/uSXYVWNxVM

14 / VectorBT：用历史数据一口气测几千种策略组合

https://t.co/3WhV6siMCa

15 / QuantStats：一键出报告，收益、回撤、波动率全都有

https://t.co/qmr4IHh7TY

建议先挑一个团队，给它一个明确的活。

用 API、MCP 或脚本把各个专职 Agent 串起来，每个 Agent 管什么、哪些操作要你批准，提前定清楚。

别再什么都从零开始搭了。
