# 苏茶：Agent 记忆系统设计——只回答三个问题，外加工程约束

> Agent 记忆系统只回答三个问题：记什么、怎么存、怎么用；工程约束 9 点：何时记（触发时机/延迟/背压/同步异步）、记什么（写入门槛/消息过滤/来源）、存哪里（介质/数据模型/索引/版本）、冲突与一致性（语义冲突/检测/崩溃恢复）、生命周期（时效/淘汰/合并/遗忘）、何时读（召回时机/前缀缓存/注入策略）、检索（召回策略）、怎么注入（位置/预算/防注入/权限边界）、安全隐私与权限（认证边界/记忆投毒/用户攻击）。

<!-- more -->

做 Agent 开发的看过来了，有朋友经常问 Agent 记忆系统怎么设计。

其实记忆系统只回答三个问题：记什么、怎么存、怎么用。其余的都是围绕这三点的工程约束。

1. 何时记，你应该考虑的问题有，触发时机、触发延迟、背压、同步异步等。

2. 记什么，需要考虑写入门槛、消息识别与过滤、记忆来源等

3. 存哪里，存储介质、数据模型、索引策略、数据版本等等

4. 冲突与一致性，需要考虑的问题有语义冲突策略、冲突检测、崩溃恢复等等

5. 生命周期，记忆时效管理、淘汰策略、合并策略、遗忘策略等等

6. 何时读，召回时机与粒度、前缀缓存问题、注入策略

7. 检索，主要是召回策略

8. 怎么注入，注入位置和形态、预算分配策略、防注入策略、权限边界等。

9. 安全隐私与权限，认证边界、记忆投毒、用户攻击等安全问题。

解决的上面的问题，一个完整的记忆系统就完成了，至于每一步怎么实现，用什么框架，这个因人而异。
