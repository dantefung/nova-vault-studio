# Hytidel（@HytidelLegend）：2027 上海小升初「神秘考 SMK」全攻略——梯队代码、时间线、证书门槛与黑话

> 全面拆解上海小升初「神秘考」（SMK/密考）的底层逻辑与全景图谱：超一线/一线/二线学校暗号代码对照表、三至五年级长线备考与全年节点时间线、数学小奥高端班（MCB/新舟 S/蘑菇/GY）与证书门槛（AMC8/思维 100）、英语小托福 850 分基线，以及四大获取渠道与圈内黑话速查表。

<!-- more -->

上海小升初的正规路径只有三条：公办对口、民办摇号、三公（上实/上外附中/浦外）专项选拔。

「神秘考」（SMK）是部分优质初中（含公办特色班、头部民办）在官方招生流程之外，私下组织或委托第三方开展的隐蔽选拔考试。它不属于市教委认可的正式招生环节，存在政策变动风险，不能作为保底升学方案。

本文仅作信息梳理与科普，帮助家长看懂这条“水下赛道”的玩法、门槛与词汇，方便理性判断孩子是否适配。

## 目录

## 一、什么是「神秘考」

- SMK = “神秘考” 拼音缩写；圈内也叫 MK / 密考（秘密考试）。
- 本质：头部初中为提前锁定顶尖生源（“牛娃”），绕开摇号而进行的非公开掐尖。
- “神秘”体现在三点：
1. 时间不定——考前一晚甚至提前几小时才通知，错过电话=错过考试；
2. 地点隐蔽——考点常考前数小时才公布，多设在校外机构或酒店；
3. 结果不公开——只私下通知通过者，没通过的孩子收不到任何反馈，只能被动等电话。
   - 覆盖学校：沪上 30 余所顶尖初中，分梯队参与（详见第三节）。
   - 考试科目：语数英三科为主。数学权重最高（拉分关键），英语是门槛线，语文看长期积累；偏理科的学校（交附系、华二系）会加试物理，国际路线学校（包玉刚、平和）则侧重英语。

## 为什么会存在？政策背景

2019 年《关于深化教育教学改革全面提高义务教育质量的意见》明确：严禁以各类考试、竞赛、培训成绩或证书作为招生依据，不得以面试、评测等名义选拔学生。此后“公民同招 + 电脑摇号”落地，学校失去公开选拔权，但维持升学率、争夺优质生源的需求仍在——SMK 便成为政策缝隙下的产物。

## 三、备考时间线（两条时间轴）

## 1）按年级的“长线规划”

| 阶段 | 重点动作 |
|------|---------|
| **三年级及之前** | 培养数学思维，简单接触奥数基础；英语启蒙，积累词汇与阅读（KET 打底）；养成阅读习惯 |
| **三~四年级（黄金准备期）** | 系统搭建奥数体系（数论、几何、行程、组合四大模块过一遍）；英语完成 KET/PET，扩充词汇 |
| **四升五暑假（衔接期）** | 完成小学奥数体系，提前预习初中数学（因式分解、一次函数）；冲小托福实考分；AMC8 进入专项刷题；整理简历素材 |
| **五年级上学期（9–12 月，冲刺期）** | 向目标校投递简历（“投情书”）；每周限时模考适应机考节奏；校内期中期末不能松 |
| **五年级下学期（1–4 月，收官期）** | 1–2 月一线名校笔试/面谈集中爆发（全年高峰）；二线民办&公办好班补录；3 月政策发布；4 月三公网申+考试 |
| **五升六（5–6 月）** | 5 月民办摇号、公办对口出结果；6 月分班考（FBK） |

## 2）以 2027 届为例的“全年节点”（往年规律推测，非官方日程）

- 8–11 月：五年级上学期，头部学校启动校内测评、简历收集，一线名校开第一场选拔
- 12 月：二线梯队集中启动测评
- 次年 1 月：一线名校笔试/面谈集中爆发，全年 SMK 高峰期
- 2–3 月：头部发放意向，二线补录
- 4 月：简历投递收尾；三公报名与评估启动
- 5 月：公办对口、民办摇号，官方招生落地

关键提醒：所有证书最好在五年级上学期结束前拿到（三公网申通常 4 月开放，简历投递 3 月就开始），五年级下学期再考什么都来不及。

## 四、要准备哪些证书（重点：数学 / 英语）

简历筛选的核心逻辑是：校内底盘（全优）> 数学硬实力 > 英语门槛 > 科创/语文差异化。下面分科拆。

## 数学：小奥全部学完 + 掌握扎实（核心门槛）

SMK 的数学是拉分关键，几乎所有头部民办都“以小奥为主”。业内共识是：小奥全部学完并掌握扎实，超一线场次还需提前预习初中（初联甚至高联一试）内容。

上海家长圈判断一个孩子的小奥是否“学完且扎实”，一个常用参照就是他读的是哪类高端班。以下几类班型是这一水平的典型代表——它们的共同特征是“小奥全部学完、且能跨级超前”：

| 班型 | 机构/背景 | 说明 |
|------|----------|------|
| **学而思 MCB 跨级** | 学而思创新/集训队体系（MC） | 上海公认最具竞争力的小升初奥数高端班，进度极快（3 年级完成小奥，4–5 年级初联，6 年级高中），“跨级”即超前学习 |
| **新舟领航 S 跨级** | 新舟教育 领航 S 班 | 精准对标 SMK 二梯队（SBL/ LS），“五夏学完小奥全部新知+六上”，跨级超前 |
| **蘑菇卓越跨级** | 蘑菇培优 卓越班 | 蘑菇最高班型，进度全市最快（连七年级内容都涉及），口碑以“题难、进度快”著称 |
| **GY 精品班跨级** | 龚老师（龚班）小奥 | 上海本土小奥名师工作室，低幼年级起家，精品班选拔制，适合早期打底后转高端班 |

读这些班 ≠ 保证录取，它们更多是能力证明 + 潜在“占坑”渠道。机构鱼龙混杂，部分以“内推/保录”为名收取高额费用，需重点甄别（详见第六节）。

数学证书（简历“硬通货”）：

- AMC8（美国数学竞赛）：三公最热门。20 分+（全球前 5%）有竞争力，23 分+（前 1%）优势明显；上外附中建议 21+，上实建议 21+。
- 思维 100 挑战赛：上海本土老牌，决赛二等奖以上含金量突出——家长反馈，决赛二等奖及以上“至少会被二线以上初中邀请参加神秘考”。业内有“以思维 100 为标准准备”的说法。
- 华罗庚杯 / 迎春杯 / 数学花园探秘：复赛二等奖以上含金量高。
- 低龄铺垫：袋鼠数学、澳洲 AMC（1–3 年级试水，不适合作为 5 年级主力证书）。

## 英语：小托福约 850（欧标 B1~B2）

英语是 SMK/三公的“门槛线”。小托福（TOEFL Junior，ETS 主办，满分 900，听力/语形/阅读各 200–300）是当前最被认可的英语能力标尺。

- 850 分 = 三公简历“硬通货”：对应 CEFR B1~B2（词汇量约 3500–4000，对标高考/部分四级词汇），普遍被视为三公面单入场基础。
- 各校参考线：上外附中 850+、上实 830+、浦外 800+；华育/兰生 800+ 为底线，850+ 简历优势明显；平和/世外/包玉刚等头部国际校也把 830–850+ 作重要参考。
- PET 优秀/卓越（B1，词汇约 2800）：体制内认可度高，证书终身有效（小托福仅 2 年有效期），PET 卓越在小升初简历中“含金量接近小托福 850+”。
- FCE：更高阶，但实用性相对小；KET：仅基础门槛，单有 KET 缺竞争力。
- 小托福偏学术英语，文本贴近初中/国际课堂，更贴合三公面谈的听力、阅读方向。

四年级考取小托福、五年级网申直接用，是最顺的节奏；若四年级未达标，需在 4–5 年级上完成考试并预留申请时间。

## 语文（加分项，非刚需）

- 上海本土最高含金量语文赛事：上海市古诗文大会（市级三等奖以上在网申很占优）。
- 补充：美丽汉字、市级作文大赛（适合补齐全科均衡短板）。
- SMK 语文通常考：古诗文、现代文阅读、写作、病句修改，难度接近中考。单靠语文证书很难拉开差距，是“锦上添花”。

## 科创 / 信奥（差异化一维，上实尤为偏爱）

- 雏鹰杯（红领巾科创小能手）：小学首选，上海白名单，3 年级可参与，门槛友好。
- 上海市青少年科技创新大赛（青创赛）：市级天花板，4–5 年级深度项目。
- 宋庆龄少年儿童发明奖、蓝桥杯、CSP-J 信息学入门、机器人竞赛：上实（信奥班）、上外附中（科创班）重点看。
- 作用：数学英语都强的娃，用市级科创奖丰富简历、平衡“偏理科”印象；对文科不占优的理科娃尤其有用。

## 校内底盘（重中之重，先于一切证书）

- 四、五年级《成长记录手册》语数英全优：出现“良”会大幅降低初审通过率，权重高于所有竞赛证书。
- 校内荣誉：市/区/校三好、优秀少先队员、红领巾二星/三星章、大队长/中队长任职；浦外网申硬性要求至少校级荣誉。
- 简历排序建议：数学证书 → 英语 → 科创 → 校内全优紧跟其后，获奖经历如实填写、不要夸大。

## 五、SMK 考什么、难度如何

| 梯队 | 数学 | 英语 | 语文 |
|------|------|------|------|
| **超一线**（华二丘班、华育、上宝、兰生） | 高思 4–5 星奥数 + 七年级代数；数论/组合/几何高频；触及初联甚至高联一试 | 对标小托福 850+，长篇阅读、首字母填空高频，部分加英文面谈思辨 | 各校自选是否加试 |
| **一线**（闵华二、进才系等区头部特色班） | 3–4 星奥数 + 少量初中基础；中档题为主，1–2 道高难压轴，看正确率与速度 | 中考一模标准，阅读完形重点 | 同上 |
| **二线**（各区优质公办重点班、普通民办强校） | 1–3 星浅奥 + 校内拔高，重计算准确度，少量小初衔接 | 难度偏低，重基础词汇语法 | 同上 |

一句话：数学是拉分关键，英语是门槛线，语文看积累。数学拔尖但英语严重跛脚，反而会被质疑学习均衡性。

## 六、怎么拿到考试机会（渠道 + 黑话）

## 四大获取渠道

1. 简历投递（投 QS / 裸投）：把成绩单、小托福、AMC8、科创等奖项材料投递至目标校邮箱。反馈概率中等，难点在获取有效官方邮箱；普通家庭最可控的第一步。
2. 家长圈消息：大部分通知靠“小道消息”，需提前进群留意（信息真假混杂，需甄别）。
3. 机构推荐（高端班内推）：部分机构声称有推优渠道，但真正有资源的极少，且常伴“内推/保录”高额收费——谨慎选择，避免被割韭菜。
4. 校内推优 / 学科营：优质小学向合作初中推荐尖子生；华师大、交大等高校数学营表现突出者有机会获推荐。

## 七、理性提醒（务必看）

1. 政策风险：上海市义务教育实行免试入学，严禁以测评、竞赛成绩选拔生源。SMK 属民间非官方渠道，随时可能受政策影响变动，绝不能作为唯一/保底升学方案。
2. 受众面窄、录取率低：SMK 面向极少数学科特长牛娃，头部场次难度对标初中竞赛，大部分孩子不适合，盲目备考只会加重负担。
3. 双线准备：优先吃透官方对口、摇号、三公路径，再结合孩子真实水平判断要不要走这条拔尖赛道。“匹配孩子能力的路线，才是最好的路线。”
4. 信息甄别：网上考试时间、场次消息多为家长圈流传，真假混杂；对任何“内定”“保录”承诺保持警惕。
