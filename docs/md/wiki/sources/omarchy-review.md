# Omarchy 评测 — 精读摘要

作者：冯若航（老冯，Pigsty/PostgreSQL 发行版作者），公众号，2026-08-24 发布

## 核心判断

Omarchy（DHH 的 Linux 桌面发行版 4.0）：品味在线，但两头不靠——桌面体验替代不了 macOS，服务器便利取代不了 Ubuntu 26。举双手支持生态多出这样一个玩家。

## Omarchy 好在哪

- **盘活老旧 Intel MacBook**：T2 Linux 安装时的键盘/USB/Wi-Fi 驱动问题全部解决，安装流程丝滑
- **桌面体验比 Ubuntu 好**：虽然仍不及 macOS，但已是 Linux 发行版中的品味巅峰
- **Linux 生态里唯一一个有精气神追平 macOS 体验的项目**

## 对吹捧的反驳

- 「DHH 的 dotfiles 大合集」：太贬低，里面有定制的匠心
- 「为 AI 而生的 Agent 原生操作系统」：太离谱，Codex/Claude Code 打包老冯年前就干了

## Linux 发行版观点

| 发行版 | 评价 |
|--------|------|
| Ubuntu | 海外压倒性主导，桌面+服务端都还不错，AWS/Azure/WSL 默认，AI 场景 NVIDIA 驱动首选 |
| Debian | 开源原教旨，纯纯粹粹，Proxmox 首选，基础镜像优先选它，稳如老狗 |
| EL（CentOS 等） | 国内用得多，接触多但不优先选 |
| Arch | 懒得打 pacman 包 |
| 其他 | Fedora、NixOS、Mint、Kali、麒麟、统信、欧拉——基本都试过，最终回归 Debian+Ubuntu |

## 选购建议

- **桌面**：macOS 一把梭。极致的桌面体验 + BSD-style 终端 + 开发者优先支持
- **折腾**：用 Linux 服务器（云服务器或 mini PC），别折腾桌面
- **肌肉记忆**：macOS 的改键方案（CapsLock→Hyper 键）不可迁移，换系统效率大幅下降

## Omarchy 与 Ubuntu 的类比

- DHH ≈ Mark Shuttleworth（Ubuntu 创始人，南非富翁）
- 都是大富翁 + 真心热爱 Linux + 把 Debian 底子打磨成普通人可用的桌面系统
- 区别：Ubuntu 已有 Canonical 商业化，强推 Snap；Omarchy 还纯粹
