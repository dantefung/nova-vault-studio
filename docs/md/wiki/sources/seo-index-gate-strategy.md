# AI 说「新词全铺完」，我把建议砍成索引闸门

> 真正省页数的不是让 AI 多吐词，是先规定什么叫「值得进站」的词。AI 负责扩候选；闸门负责定义什么叫「可以占一个 URL」。

> 周四固定写真实使用·判断向。在维护几个已上线的游戏攻略站（2026 年 6 月模板化上线）。日常除了加页，还有一件事反复做：词向与索引方向怎么收。

不是从 0 发明词库。是复盘：哪些方向还值得加，哪些标题在自嗨，哪些该并进索引页。

用 AI 做过几轮之后，冲突点越来越清楚：AI 很会给「看起来覆盖更全」的方案；我要的是「索引还能读、人还能维护」的方案。

## 先说结论

| AI 常建议 | 我通常怎么判 | 谁拍板 |
|-----------|------------|--------|
| 把相关词一次铺满，站显得「厚」 | 有没有承接页模板 + 维护节奏 | 我 |
| 每个变体各建一页，长尾全吃 | 意图重复 → 合并进枢纽页/索引，不堆壳页 | 我 |
| 标题越带数字越狠越好 | 狠可以，但不能写没证据的精确数据 | 我 |
| 真实性趋势掉了也先留着，「万一回来」 | 无点击意图、无更新计划 → 标记观察或停更 | 我 |

> **AI 负责扩候选；闸门负责定义什么叫「可以占一个 URL」。** 我把 AI 吐的整表直接进发布队列——过不了四问就不进队列。

## 操作路径

### 步骤 1：先钉边界，别一上来「帮我生成 200 个词」

打开对话时，我先写死四件事：

1. **站点类型**：游戏攻略 / wiki 向，模板页可复制
2. **本轮目标**：复盘词向，不是冲量发版
3. **禁止项**：编造精确搜索量、把未核验站当「我的站」、无证据的「稳排首页」
4. **输出形态**：候选表 + 风险列 + 建议动作（做/并/停），不要直接成稿站内文

提示词骨架：

> 这是游戏攻略站词向复盘。只扩候选，不替我定义「必须做」。每条标：意图类型 / 是否可套模板 / 和现有页是否重复。不确定的搜索量写「未知」，不要编数字。

不先钉边界，AI 默认走「词表越长越专业」。那是训练里的高频解，不一定是你的维护预算。

### 步骤 2：要「方案对比」，不要只要一张大表

我通常要三份东西：

1. **候选词 15-30 条**（够用就停，不追求上百）
2. **意图归类**（怎么玩 / 位置 / 材料 / 版本更新 / 对比）
3. **冲突清单**（哪些和已有标题撞车、哪些只是同义词）

第三项它特别爱偷懒。所以我会反问：

> 「如果我只允许本周新增 3 个 URL，你删哪 27 条？理由一句话。」

答成「都挺重要」的，多半是在回避优先级。砍。

### 步骤 3：人工四问（这步不能省）

每个「建议做页」的词，只过四问。**四问里有两问卡死，就不做新 URL。**

1. **读者搜完要的是答案，还是目录？** 答案 → 单页；目录 → 索引/枢纽，别拆十个空壳
2. **现有模板能不能直接套？** 套不了 = 先估改造成本，不默认「先上了再说」
3. **和站内已有页是不是同一意图？** 是 → 改旧页或内链，不新建抢自己
4. **三个月后谁更新？** 没人 → 标记观察，不进发布队列

## 两次典型交锋

### 交锋一：AI 要「版本号全铺」

- **AI 常见说法**：每个小版本各做一页，长尾都接到
- **我的判断**：版本词往往季节性强。全铺的结果是半站过期标题、内链混乱、你自己都不敢点开维护
- **落地动作**：
  - 主版本留一个常青枢纽（规则/机制讲清楚）
  - 小版本差异用同一页内锚点或简短更新块
  - 确定死透的旧版本 → 合并或 301，不留僵尸入口
- **拍板句**：覆盖宽度服从维护半径

### 交锋二：AI 要「近义词各建一页」

- **AI 常见说法**：用户有时搜 A、有时搜 B，两页都做更稳
- **我的判断**：意图相同就一个 URL 说清楚，标题用主搜法，次要说法放首段与 H2。两页互抢，Google 也烦，你更烦
- **落地动作**：
  - 主词定 1 个
  - 次要说法进正文，不进新 slug
  - 若数据以后证明意图真分裂，再拆——**先并后拆，别先拆后悔**
- **拍板句**：先防自我竞争，再谈覆盖

## 五格判断表

| 格子 | 问什么 | 绿灯 | 红灯 |
|------|--------|------|------|
| 意图 | 搜完要带走什么 | 单一清晰任务 | 「什么都沾一点」 |
| 模板 | 能否套 | 现成结构改标题+关键块即可 | 要重做信息架构 |
| 重复 | 站内是否已有 | 无同意图页 | 已有页只是写得烂 |
| 保鲜 | 谁、多久更新一次 | 有节奏或常青 | 靠运气 |
| 证据 | 词从哪来 | 搜索建议/公开趋势/已有查询形态 | 「我觉得有人搜」 |

**用法**：五格里 ≥2 红 → 不进本周队列。AI 可以帮你填表，打分的人必须是你。

## 一页纸

1. 让 AI 出候选，先要删词理由，不要只夸「覆盖全」
2. 四问：答案还是目录 / 能否套模板 / 是否撞车 / 谁更新
3. 版本词优先枢纽 + 更新块，不默认一版本一页
4. 近义词先并后拆，防自我竞争优先于覆盖

## 回扣

> 这个 URL 三个月后还站得住吗？

站得住，再铺。站不住，再全的词表也只是给未来的自己挖坑。驾驶位不是反对 AI。是反对把「候选」偷换成「决定」。
