# fiapp：Opus 按我的工作流推荐土豆姐的四个 skill

> 四个 skill：① `/create-verification-skill`（连同 `/maintain-verification-skill`）——把验收步骤固定成项目自己的检查流程，减少亲自抓低级错误，**最先装**；② `/correct`——同一错误被纠正两次就从根上修，不再靠多加提示词；③ `/statechart`（连同 `/create-formal-verification-skill`）——检查计费、额度、后台任务等状态机漏洞；④ `/ketchup`——任务多时快速看清改了什么、还有哪些等你拍板。另有 `/reframe`：把模糊点子讲清楚——给出行业术语与相近领域现成做法、核实引用来源。

<!-- more -->

opus 根据我的工作流推荐土豆姐的四个 skill：

1. /create-verification-skill（连同 /maintain-verification-skill）：把验收步骤固定成项目自己的检查流程，减少你亲自抓低级错误。最先装。

2. /correct：同一个错误被纠正过两次，就从根上修掉，不再靠多加一句提示词。

3. /statechart（连同 /create-formal-verification-skill）：检查计费、额度、后台任务这些状态机有没有漏洞。

4. /ketchup：任务多时，帮你快速看清改了什么、还有哪些等你拍板。

还有个是产品相关的，

- /reframe 推荐装。
   - 适用场景： 你有一个模糊的点子，但叫不出名字，比如之前想做某个功能，却不知道业内怎么称呼它。
   它会给出行业术语和相近领域的现成做法，并核实引用来源，再用这些说法帮你把点子重新讲清楚。
