# Yihui（@yihui_indie）：一天不快乐，大概率是这 4 件事没做

> 极简的情绪自检清单：一天不快乐大概率来自四件事——前一晚没有充足睡眠、没有做中高心率运动、没有晒半小时太阳、没有听音乐；反过来说，人的快乐可以简单到由这四件基础生理与感官行为兜底。

<!-- more -->

我发现我一天如果不快乐，大概率是因为这 4 件事情：

1. 前一晚没有充足的睡眠
2. 没有做中高心率的运动
3. 没有晒半小时太阳
4. 没有听音乐

原来，人的快乐这么简单~
