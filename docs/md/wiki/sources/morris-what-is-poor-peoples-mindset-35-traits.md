# Morris（@Morris_LT）：什么是穷人思维？——五类共 35 条认知错位自查清单

> 把「穷人思维」拆成五组共 35 条可自查的认知错位：① 价值与金钱（只看价格不看价值、只看成本不看机会成本、把收入当财富、害怕花钱不害怕浪费时间）② 机会与风险（把不确定性等同危险、追求绝对安全、只看投入不看杠杆、等条件成熟才行动、把一次失败当永久失败）③ 认知与成长（把自己经验当世界边界、用过去解释未来、只消费不投资自己、用情绪代替分析）④ 商业与社会关系（只关注产品不关注表达、只卖时间不创造系统、只看竞争不看创造、把人脉当资源把价值当负担、把财富展示当财富创造）⑤ 人生与选择（用消费证明成功、把辛苦等同于价值、把忙碌当成进步、把选择权交给环境、只考虑自己能不能做到而不考虑如何让别人帮助自己做到）。

## 一、价值与金钱

1. 只看价格，不看价值： 总在计算一件事要花多少钱，却很少思考它能够创造多少价值。
2. 只看成本，不看机会成本： 认为不花钱就是省钱，却忽略了因为不投入而失去的收益。
3. 只看眼前，不看长期： 为了节省眼前的一点成本，放弃能够长期产生回报的机会。
4. 把便宜当成划算： 认为买得便宜就是赚到，却不考虑产品是否真正解决问题。
5. 把收入当成财富： 关注每个月赚多少钱，却忽略资产积累、现金流和财富增长能力。
6. 害怕花钱，不害怕浪费时间： 为了省下一点钱，愿意付出大量不可再生的时间。
7. 只计算得到什么，不计算失去什么： 只看一笔交易的直接收益，却不考虑拒绝机会的潜在代价。

## 二、机会与风险

1. 只看失败的可能，不看成功的空间： 还没有研究机会，就先列举一大堆不行动的理由。
2. 把不确定性等同于危险： 因为无法确定结果，就拒绝尝试任何尚未验证的新事物。
3. 追求绝对安全： 希望在没有风险、没有成本、没有不确定性的情况下获得高回报。
4. 只看投入，不看杠杆： 习惯用自己的时间和体力换钱，却很少考虑资本、技术、系统和团队的放大作用。
5. 害怕失去已有的东西： 因为担心失去眼前的小利益，而放弃可能改变长期处境的机会。
6. 等条件成熟才行动： 总想等到资金、经验、资源和环境都准备好，却迟迟不开始积累。
7. 把一次失败当成永久失败： 因为一次尝试没有成功，就否定整个方向，而不是从中提取经验。

## 三、认知与成长

1. 把自己的经验当成世界的边界： 因为自己没有见过、做过或理解过，就认为这件事不可能。
2. 用过去解释未来： 习惯根据过去的收入、环境和经历判断未来，而不是观察正在发生的变化。
3. 只消费，不投资自己： 愿意为即时娱乐付费，却不愿为知识、能力和认知升级投入。
4. 追求确定的答案，不培养判断能力： 总希望别人告诉自己该怎么做，却不愿建立独立分析和决策的能力。
5. 用情绪代替分析： 遇到新机会时，先产生喜欢、讨厌、嫉妒或恐惧，再寻找理由证明自己的情绪正确。
6. 只看结果，不研究过程： 看到别人成功就羡慕，看到别人失败就嘲笑，却不研究背后的结构和因果关系。

## 四、商业与社会关系

1. 只关注产品，不关注表达： 认为只要产品好就自然有人购买，却忽略市场传播、定位和价值传递。
2. 只卖时间，不创造系统： 习惯依靠个人劳动获得收入，却没有建立能够脱离个人持续运转的业务。
3. 只关注竞争，不关注创造： 总想着从竞争对手那里抢走客户，而不是创造新的需求和市场。
4. 把人脉当成资源，把价值当成负担： 总想认识有资源的人，却很少思考自己能够为别人创造什么。
5. 只看眼前利益，不经营长期信用： 为了一次交易的收益，牺牲未来更大的合作机会。
6. 把免费的东西看得更重要： 过度追逐免费资源，却忽略真正有价值的服务往往需要付费。
7. 把财富展示当成财富创造： 更关心别人如何看待自己的生活，而不是自己的资产和能力是否真正增长。

## 五、人生与选择

1. 追求稳定，却忽略结构性风险： 认为维持现状就是安全，却没有意识到环境变化可能让现有优势逐渐失效。
2. 用消费证明成功： 通过购买奢侈品和展示生活来获得身份认同，而不是通过创造资产建立真正的自由。
3. 把辛苦等同于价值： 认为付出越多就越值得回报，却忽略努力的方向、效率和杠杆。
4. 把忙碌当成进步： 每天安排大量工作，却不检查这些工作是否真正推动了目标。
5. 把选择权交给环境： 总是抱怨出身、市场和时代，却很少主动寻找能够改变自身处境的变量。
6. 只考虑自己能不能做到，不考虑如何让别人帮助自己做到： 习惯单打独斗，却不懂得通过合作、组织和资源整合扩大能力边界。

穷人思维最核心的问题，不是缺少金钱，而是缺少对价值、时间、机会、风险和杠杆的整体理解。
