# 创业不要合伙！！！

接到过很多付费咨询，大家的问题都挺同质化的



比如一个经典问题：我该怎么找到合适的合伙人？



每次我一追问，咱们先不说怎么做，先说为什么，你为什么需要一个合伙人呢？



到这里大部分人其实就讲不清了，原因不超出以下三点：



1.分摊恐惧和孤独



创业这事儿说白了就是跳悬崖,一个人跳太吓人了



找个合伙人,心理上就觉得”至少有人陪我一起死”，有一种玄幻的安全感



2.能力焦虑



我只会xx，我不擅长xx，我需要找个人弥补我的短板



3.资源幻觉



想找一个有资源，有人脉，有渠道的大腿，跟着大腿屁股后面混



以上，我觉得都是不成立的



首先，在内地的劳动力在全世界范围内都极其的优质和廉价的大前提下，几乎没有任何能力是不能靠钱采买到的



采买不到的唯一可能性就是出价太低



因此，绝大多数事情是没有必要通过找合伙人的方式去解决的



以此为基础，我认为绝大多数想找合伙人的本质心态都是贪便宜



你不想付薪水，你想找一个不拿薪水也无怨无悔的人跟你一起拼，然后画个股权的饼



以此为基础，会出现巨大的bug



业务不好就算了，最大的bug是绝大多数人都只能共患难不能同富贵



比如：



每个人都认为自己付出的更多，都会美化自己的奉献和努力，认为自己应该比别人拿的更多



这是人性使然



没有清晰的退出机制，有时候都不是谁做错了什么



有可能就是你的合伙人的成长速度跟不上你的成长速度



或者你们之前的某种问题在那个阶段是小问题，过了一个阶段是大问题了



所以，如果真的非要合伙不可，要清晰地认识到，本质上人都是阶段性的



初中最好的朋友可能过了几年就断联了，你们谁也没做错，只是你们没有了共同的场景和话题



定期分钱就好了，不要分股权，哪有那么大的生意需要分饼



合伙人分手是比离婚还要痛苦和深刻的情感



与此同时我又见证了身边了很多人是情侣分手+合伙人分家



简直是孕妇分娩时被蚊子叮了——第19级的痛



包括我觉得很扯淡的一点是，很多人不清不楚的开始合伙，核心的原因是对方是你的朋友/亲人/同学/舍友



加上一层情感因素，更难讲了，每个人都得考虑对方情绪，还有一些低头不见抬头见不敢撕破脸的情愫在，责任是不明不白的，钱也是稀里糊涂的



业务没见做很大，气是都生着了



那么怎么避免出现以上所有种种种种问题？



你要自己牛逼



你要自己始终掌握着真正的稀缺资源，例如获客能力，招商能力



你要自己拥有独立判断的能力



你有对任何人说爱干不干，不干给我滚的底气



毕竟，所有人都只是生命的玻璃窗外缓缓划过的雨滴
