# 被裁了，用Code X做了个赚钱工具

> 被裁程序员用 AI 工具（Code X）9 分钟完成全栈项目，LOF 基金溢价率监控工具实战案例，揭示 AI 对初级开发者的替代威胁。

<!-- more -->

## 核心洞察

1. **AI 工具已能接管完整开发流程** — 从需求分析到代码生成，Code X 在 9 分钟内完成全栈 Web 工具
2. **金融量化场景是 AI 工具的天然试验场** — LOF 基金溢价率计算、数据抓取、自动化监控，适合 AI 处理
3. **AI 替代初级程序员已成现实** — 之前需要 3 人协作的工作，现在 1 个熟练使用 AI 工具的人即可完成
4. **AI 失业问题需要社会层面的解决方案** — AI 税、算力税、AI 公共财富基金等机制可能成为趋势

## 案例背景

作者阿豪是一名被裁员的程序员，在失业期间决定利用 AI 工具完成一个一直想做的项目：**LOF 基金"真实"溢价率监控工具**。

**核心痛点**：LOF 基金套利需要实时监控溢价率，但传统数据源（如集思录）存在以下问题：
- 爬虫抓取容易被封
- 数据滞后（T-2 估值）
- 手动计算容易出错

## Code X 实战流程

### 工具介绍

**Code X** 是 OpenAI 推出的 AI 编码工具（可能是 Codex CLI 或类似产品），核心特点是：
- 不是复制粘贴代码，而是**接管电脑**
- 能自主操作浏览器、执行任务
- 支持插件扩展（改 PPT、P 图、操控浏览器等）

### 四步完成配置

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 安装 Code X | 从 ChatGPT 左侧入口安装 |
| 2 | 创建项目 | 指向策略文件夹 |
| 3 | 喂入知识 | 将溢价计算公式整理成 PDF 导入 |
| 4 | 配置数据源 | 给 Code X 集思录账号，让它自己登录 |

### 关键公式

作者之前与 GPT 反复讨论出的**最优溢价计算公式**：
- 剔除 QDII 净值滞后
- 考虑 T+2 到账成本

### 自动化效果

```
用户语音指令："把能申购的放上面，不能申购的放下面。
能申购的里面，再把限额的和不限额的分开。"

→ Code X 自动执行
→ 输出分类后的表格
```

## 进阶：9 分钟完成全栈项目

在完成溢价率工具后，作者进一步要求 Code X **开发一个 Web 网站**：

**需求描述**：
- 前端简洁
- 后端稳定
- 抓取时间卡在每天下午 2 点半

**执行过程**：
1. Code X 输出十几页开发计划书
2. 作者挑刺 → Code X 修改 → 反复迭代
3. 确认后开始编码

**结果**：从零到一，**9 分钟**完成一个能跑的 Web 工具。

## AI 对就业的冲击

### 直接观察

> "之前需要三个人分工协作，现在留一个能熟练使用AI工具的足矣。更重要的是，它不摸鱼，不抱怨，也不交社保。"

### 核心观点

> "以前我们总说，要多学技能，要努力提升认知。现在看来，如果这种'提升'仅仅是把自己训练成一个更精密的'零件'，那结局早已注定。因为当机器学会思考，最先被替代的，就是那些只会执行命令的脑袋。"

### 社会层面思考

作者提出**AI 失业基金会**概念：
- 资金由利润高的龙头企业提供
- 维持社会稳定是大企业的责任

**国际参考**：
- 韩国劳动部长呼吁：三星、SK 海力士由 AI 芯片带来的超额利润应更多分给供应商、员工和社区

**未来趋势预测**：
- AI 税
- 算力税
- 数据中心电力税
- AI 公共财富基金

> "政府不可能眼看着 AI 把财富集中到极少数公司手里，却让失业、医保、养老、财政压力都由社会承担。"
