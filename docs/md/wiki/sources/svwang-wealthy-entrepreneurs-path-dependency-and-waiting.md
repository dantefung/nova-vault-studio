# 硅谷王川（@Svwang1）：富商发家史随想——路径依赖、缺乏抽象思考与「什么都不做耐心等待」的缺失

> 硅谷王川剖析许多第一代与第二代实业家的四层认知局限：把时代与特殊约束下的运气当成自身能力导致跨环境迁移遭遇重大损失；身体习惯守旧产业而不愿耗费脑力探索低风险高回报新产业；缺乏「什么都不做，耐心等待」的克制而陷入盲动内卷与高杠杆疲态；富二代因缺乏底层失败体验而极易照葫芦画瓢败光家产。

<!-- more -->

最近了解了一些富商的发家史，有个感触是：

很多人发家是时代和特殊环境下的产物，但是严重路径依赖，缺乏抽象出问题本质的思考能力。

而且在单一环境，单一产业内工作时间越长，抽象出真正底层规律的能力就越差。

因此他从事某个产业发家，就误以为把这个产业迁移到新的环境，可以重复原来的模式。但是旧的环境有一些特定的约束条件，新的环境没有，因此模式无法复制，换了新的环境可能遭遇重大损失。

第二，当他的身体习惯已经适应了某个产业后，虽然这个产业有各种结构性的风险和缺点，他还是不愿意放弃。情愿守着旧的产业，不愿意耗费脑力做些抽象思考，去探索一些唾手可得的，风险更小，回报更高的新产业。

第三，他无法实践‘’什么都不做，耐心等待‘’的工作方式。实业家的习惯是每天需要做点什么，每天需要有些正反馈，这样才感到充实。但很多机会是等出来的，需要好机会浮现之前极度的克制，这对于每天都想做点什么的人，完全无法忍受。这样必然因为盲动而事倍功半，跌入大坑。而且实业家大多是高负债高杠杆的经营模式，每天必须要动。看似富有风光，实际上缺乏时间自由，常常被各种突发事件牵着鼻子走，累得半死。

第四，如果上面几点对于白手起家的第一代创业者很难的话，对于第二代就几乎不可能。因为富二代缺乏第一代的各种丰富的失败体验，问题都是父母罩着。因此做事时会对风险完全缺乏敬畏，觉得父母以前就是这么做的，理所当然的照葫芦画瓢。所有他没学过的失败体验，一定会被迫亲自全部学一遍。这个过程中可能就把家给败光了。
