# Morris（@Morris_LT）：财富来自陌生人，麻烦来自身边人

> 关系与财富的底层结构：财富的本质是价值交换，而麻烦往往来自关系越界——陌生人更在意你能提供什么价值，按价值与规则与你交易；身边人却容易因感情、利益与期待产生比较、依赖、干涉甚至控制，并要求你按感情和关系让步。推论是一体两面：想获得更多财富就要向外建立更广泛的价值连接，想减少生活中的麻烦就要在亲密关系中建立清晰边界。

<!-- more -->

为什么说，你绝大多数的财富来自陌生人，而大多数麻烦却来自身边人？因为财富的本质是价值交换，而麻烦往往来自关系越界。陌生人更在意你能提供什么价值，身边人却容易因为感情、利益和期待，产生比较、依赖、干涉甚至控制。陌生人通常按照价值和规则与你交易，熟人却可能要求你按照感情和关系让步。一个人想要获得更多财富，就需要向外建立更广泛的价值连接；想要减少生活中的麻烦，就需要在亲密关系中建立清晰的边界。
