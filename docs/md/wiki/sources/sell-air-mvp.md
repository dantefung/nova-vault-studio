# 【精读】网站出海每日分享：卖空气验证需求

> **核心结论**："卖空气"是独立开发圈对"预售验证"最接地气的叫法——产品还没做出来就敢挂出来卖。**用 Pieter Levels《MAKE》预售的成功案例说明：先验证需求再开发产品，是降低独立开发沉没成本的最高优先级动作**。

> **关键洞察**：
> - MVP 的极致是"卖空气"：连 MVP 都不用做，直接挂个落地页 + Stripe 收款
> - **价格是测试工具**：太便宜 → 熟人支持；太贵 → 真需求；合适 → 真付费
> - Landing Page 4 步 SOP：文案 → AI 生成 → Stripe → 投广告，1 天就能跑通完整闭环
> - 小红书也能卖空气：国内社媒是低成本验证场，找到足够用户再生产
> - 时间最值钱，验证需求要趁早——别等产品开发完才发现没人要

## 精读正文

### 一、什么是"卖空气"？

> 卖空气 = 预售

具体含义：
- 告诉用户"这是一个什么产品"
- 说明"它解决什么问题"
- **看有多少用户愿意付费**
- 在产品真正做出来之前完成

### 二、案例：Pieter Levels 的《MAKE》预售

Pieter Levels（独立开发之神）写书没有等书完稿，而是：

1. **只写了部分内容和大纲**
2. **搭建了一个简单的落地页**
3. **挂上标语**："我正在写这本书，现在可以购买预售版"

**结果**：
- 预售期就赚到了大笔收入
- 同时验证了市场需求
- 等书真正写完出版时，《MAKE》已经有了稳定的读者群和口碑
- 成为独立开发者社区的**必读书籍**

### 三、复用方法：直接做预售

> 验证你即将开发的软件是否有需求的最快方式。

#### 朋友圈/社群路线
直接在朋友圈或社群里宣传：
- "我要做一个付费产品"
- 定价多少（**不能太便宜**——熟人可能是出于鼓励支持你）
- 看能找到多少**实际愿意付费的用户**

#### Landing Page 路线（4 步 SOP）

**Step 1：写产品预售营销文案**
- 列出你要解决的问题
- 突出 3 个核心卖点

**Step 2：用 AI 生成 Landing Page**
- v0 / Lovable / Bolt 都可以

**Step 3：接入 Stripe 支付**
- 完整的支付链路（不只是挂着好看）

**Step 4：投放 + 监测**
- 购买 Google 关键词搜索广告
- 或其他宣传渠道
- 重点关注**转化率数据**

> 关键指标：不是流量大小，是**付费转化率**——这才是验证需求的金标准。

### 四、扩展案例：小红书卖空气

> 小红书上也有用户这样卖空气（预售），如果收集到足够多的用户，就可以去生产了。

**启示**：
- 国内社媒也能做预售验证
- 关键不是"先有产品"，是"先有付费意愿"

### 五、避坑原则

> 千万别等产品开发完再去验证需求，那样只会浪费宝贵时间。

**最有效的方式**：
1. 敢于"卖空气"——产品没成型就直接抛想法
2. **定一个真实的价格**——测试真实付费意愿
3. 没人愿意买 → 果断止损，把时间精力投入更有前景的项目
4. 记住：**时间最值钱，验证需求要趁早**

## 核心方法论提炼

### 1. 验证 > 打磨
独立开发失败的最大原因是"做出来没人要"。**卖空气**把验证提前到产品成型之前，把沉没成本压到接近零。

### 2. 价格是最好的需求测试
- 太便宜 → 测不出真需求
- 没人买 → 真没需求
- 有人买 → 真有需求，且需求可货币化

### 3. Landing Page 4 步 SOP 是可复用的最小验证单元
任何产品创意都可以在 1 天内完成"卖空气"验证：文案 → AI 生页 → Stripe → 投广告。**这是把 Pieter Levels 的成功经验工程化的产物**。

### 4. 验证成本和开发成本是杠杆关系
开发成本越高，越要前置验证。AI 编程时代开发成本下降 → 验证可以更激进，但**卖空气仍然比开发更便宜**。

### 5. 时间是终极成本
不是"我能不能做出来"的问题，是"做出来之前我浪费了多少时间"的问题。**卖空气的本质是缩短反馈环**。
