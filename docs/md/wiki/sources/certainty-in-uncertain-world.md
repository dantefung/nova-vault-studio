# 在自己心中藏一块高地

刘守英 2018 年 6 月在人大经济学院毕业典礼上的致辞《以个人的确定性应对世界的不确定性》节选。

## 以个人的确定性应对世界的不确定性

世界的不确定性在加剧，但个人的确定性是不会被时代剥夺的财富。与其焦虑于无法掌控的外部世界，不如在自己心中藏一块高地——那里有你的信念、你的专业、你的判断，它们是你应对一切不确定性的根据地。

### 以机会而非成本给自己定价

不要用你付出的成本去衡量自己的价值，而要用你创造的机会与可能性来给自己定价。机会是面向未来的，成本是面向过去的。一个人真正的价位，取决于他能为世界提供什么，而不是他曾经投入了多少。

### 对认定了的事情一定要较真

人生可以柔性，但认定了的事情必须较真。较真不是固执，而是对自己的承诺负责。只有在真正重要的事情上较真，你才能把一件事做到别人做不到的程度，才能形成自己的立身之本。

### 靠伎俩或计谋走不了太远

技巧可以让你赢一时，靠伎俩或计谋走不了太远。长期来看，人与人之间比拼的是底色与诚意。诚实、踏实、坦诚，这些看似笨拙的品质，才是穿越周期的护身符。

### 扩大眼界是一辈子的事情

眼界决定一个人的边界。读书、旅行、与人交流、跨领域学习，都是在扩大眼界。不要以为出了校门学习就结束了——扩大眼界是一辈子的事情，它决定了你能看见多大的世界，也决定了你能走多远。
