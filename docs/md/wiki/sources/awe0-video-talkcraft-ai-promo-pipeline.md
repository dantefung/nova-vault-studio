# awe0：两个神级 GitHub 项目——video-talkcraft 与 video-shotcraft 组合出 AI 宣传片 Agent

> 把口播稿与配音交给 video-talkcraft 生成动态解说视频，把产品截图与网页界面交给 video-shotcraft 做成有运镜、有节奏、有音效的宣传片，两者组合可搭出自动生成产品宣传片的 AI 视频 Agent。

<!-- more -->

发现两个神级 GitHub 项目，AI 宣传片神了！

最近发现两个特别适合做产品解说、知识科普、企业营销视频的开源项目。

我甚至觉得，把它们组合起来，就能做出一个自动生成产品宣传片的 AI 视频 Agent！

不用自己写脚本、录音、找素材、做分镜、剪辑，甚至连动效和音效都能交给 AI。

1. video-talkcraft：让 AI 把东西讲明白

GitHub：https://github.com/Vincentwei1021/video-talkcraft

把口播稿 + 配音，生成动态解说视频。

适合：

- 产品测评、知识讲解
- AI 工具介绍
- 企业宣传、课程视频

2. video-shotcraft：让 AI 把产品拍得很帅

GitHub：https://github.com/Vincentwei1021/video-shotcraft

把产品截图、网页、软件界面，做成有运镜、有节奏、有音效的产品宣传片。

不再是简单地把截图一张张拼起来，而是让软件界面真正成为视频的主角。
