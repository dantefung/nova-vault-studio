更新：shipwords v0.3.0 从 Cloudflare Workers 搬到了 VPS。

视频站离不开 ffmpeg，CF Workers 跑不了，只能上 CF Containers，但它有个官方一直没修的空转计费问题，稍不注意就可能上千元账单。

网站规模上来 D1 也有事务和并发问题。

CF Workers 省心，但不省钱。

现在 AI 把运维门槛拉低了，决定换成更省钱、更长期的 VPS 方案。

我做了一个 新词站群 框架：shipwords。

一个新词，一个站，一个下午上线，上线当天就能收钱。

核心哲学是：起量的站继续迭代，没起来的放着不管。

不变的东西共享，变的东西独立。

免费，MIT 协议。
