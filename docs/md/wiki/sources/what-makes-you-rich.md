# 什么人可以赚大钱？

这两次回老家，老爸都反复提及他的一个朋友的儿子，名牌大学毕业，目前在搞新能源汽车的一项什么技术，国内称得上名号的水平，年薪基本上8位数。噢，说明一下，他不是为了鞭策我，而是他喜欢以这些为自豪，例如今年村里有个考上哈工大学，他也电话给我提了2次。



今天聊一下，你的工作在未来，能不能赚得到大钱，或者你应该如何赚大钱。



很早我就聊过关于这个知识变现的逻辑。



《为什么你读了15年书却挣不到钱？》



大部分人赚得到很强的溢价，就是因为用了自己知道别人不知道的那部分知识去变现，因为只有对方不知道，才是你的价值点。



有没有价值，有多大的价值，看你从事的这个工作，是否存在迫切性，另一个就是稀缺性。



牙医稀缺吗？其实也不算十分稀缺，但是它承载的需求是有迫切性的，牙疼起来你恨不得下一分钟就解决，钱在这个时候就不是那么重要了。



律师稀缺吗？也不算十分稀缺，但是你都要找律师了，必然是非常重要和紧急的事情，他真帮你解决了，你觉得钱多少也不是那么要紧。



还有很多这样的职业，例如开锁的，例如抢修水管电路的，还有一个非常痛苦的需求，就是数据紧急恢复，这个我用过，还不算十分紧急的，但是恢复硬盘数据的价格高于硬盘本身，而且还不保证100%的恢复，能恢复一部分也得收费不菲。



而稀缺性就更好理解了。



就是除了他 /她，别人干不了，或者没有干出这效果来。



最简单就是大概10年前，演员的薪酬，天价。



那时候的确有个演员有超强的号召力，票房或者收视率只要有他在，那就有保证，换别人真没这效果，所以一部剧几千万的片酬很常见。



90年代末期的周星驰，一部片收费1500万，表面上死贵，但是他出现可以保证投资方一定赚钱。



成龙2000万一部，全球发行，也是百分百赚钱。李连杰最鼎盛的时候，报价1亿片酬，也有投资人买单，因为真的可以赚得到钱。他们的确是有全国甚至全球的票房号召力，太稀缺了。



而10年前，开始流行电视台+网络平台一起发新剧，一些真的可以带动用户充会员的红人，也是真的实打实报价上千万一部片，市场买单了。



但是今天他们的稀缺性似乎被打破了，一来新人多，二来新剧多，市场无法和从前比，以前多集中，几乎全国同时在看某一部新剧，而现在各有各平台，各有各的剧，根本看不过来，收视率自然就摊薄了，那么片酬也不可能支棱得起来了。



以后会不会好？以后更惨，因为AI长剧是必然会出现的，包括电影，僧多粥少，以前和同行竞争已经很惨了，现在和AI竞争，更惨。



回想你的工作如果不挣钱，是不是稀缺性不够？你能做的事，大把人可以做，而且是随时替代你。是不是迫切性不够？今天你这个项目没有完成，也无法左右这个项目接下来的目标。



回想2011年，我从公司离职自己干，在自身条件和选择上，都是踩中了2个点。



稀缺性，那时候电商平台的设计真不咋滴，商家大部分都是糊弄一下，因为最好的那一拨设计师，要么在4A公司，要么在大厂内部，我那时候介绍店铺设计给同事，他都懒得接，觉得LOW。



所以我离开公司，自己对接几个商家的长期需求，在市场上是有一定的稀缺性的，做得好的嫌弃LOW，做得差的干不过我。



迫切性呢？这个才是我做的最正确的选择，在2007年-2008年，我还在做企业站设计，这东西完全没有迫切性，说好什么时候上线，最终耽误了一头半个月，几乎没啥压力，所以需求方没有催着我必须什么时候完成，这样也容易被拖款。



但是电商店铺设计，这可太好了，所有营销活动，都定死了时间，情人节的活动，你不能过了1天再给他设计图吧，商家报名平台的促销活动，那就100%必须前一天准备好设计素材，时间绝对不容晚一小时，不过。。。设计质量可以商量，就是你设计得还不是那么完美，不要紧的，先上架再说，这东西影响不了太多销量。



那时候一个商家一个月平均大几千的包月需求，其实对我来说好简单，没有多大难度的工作但是比我上班收入多几倍，后来网络建站的需求要么我就拒绝，要么就转包，自己只做电商的需求，真心感受就是迫切性真的超级值钱！



噢，送快递也有迫切性，但是人人都可以干，那就没有了稀缺性，也不值钱，但是，我的老同学在老家开了个快递站，也可以赚一些钱的，因为有品牌保护，我们镇里他这个品牌的，只有他一家，有稀缺性，迫切性就不用说了，必须是有的。



在去电商部门之前 ，我还应聘了一次游戏部门，最终没有过，但是有得必有失，有失必有得，我到了视觉要求相对没有那么高的电商部门，让我摸清了电商设计的底层逻辑，也积累了客户，到后来我看设计的角度从视觉走向了转化结果，大大提升了自己的商业思维，这个大概率在游戏部门是无法触达的，因为游戏对酷炫画面的追求和电商的信息传达效率是很不同的。



和大家聊这些，是希望大家也可以思考一下自己正在做的事情，是不是没有卡到这些条件里，那么如何可以调整自己的工作重心或者方向，让自己变得更稀缺，或者更迫切需要你。
