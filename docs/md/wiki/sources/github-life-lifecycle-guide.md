# 给人生装一套「赛博外挂」，这份 GitHub 指南先收藏

> 把学习、人际、职业、健康与家庭的资料按人生阶段整理成一份 GitHub 指南，按眼前的问题查，不必一次读完。

<!-- more -->

会解方程，会背单词，却不知道第一次租房该问什么，简历怎么写，跟人闹了矛盾怎么收场。

从读书到工作，从独居到成家，每个阶段都会遇到新问题。换一份工作、照顾家人，或者经历一段低谷，都可能需要重新找资料、学方法。

GitHub 上有不少人，把自己踩过的坑、查过的资料和做出的工具公开了。从自学到求职，从做饭到维护自己的权益，遇到具体事情时，可以先有个查资料的地方。

我愿意把它们叫作人生的"赛博外挂"。先看看别人怎样处理，再结合自己的处境做决定。

## 第一次用 GitHub，怎样打开这些资料？

点进仓库后，往下看 README。先找"在线阅读""从这里开始"或目录，文字手册通常可以直接阅读。遇到软件或 Skill，再看安装条件；不要把整个仓库的 ZIP 都当成应用安装包。

这份清单核对了公开说明，没有安装实测全部工具，也没有验证房源、录用效果或收益。旧经验和个人观点各有适用范围，重要决定要继续查原始依据。

还在读书，可以先挑一份学习指南。准备换工作，就从简历和求职开始；最近更在意健康或家庭，也可以直接跳到相关资料。已经独居，可以今晚照着菜谱做一顿饭。
