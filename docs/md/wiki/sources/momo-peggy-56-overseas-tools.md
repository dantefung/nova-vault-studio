# 夏林果：出海必备的56个实战工具清单

> 把出海流程拆成7大核心方向，每个工具附上简介和具体用法。工具是手段，变现才是目标。

## 一、市场机会与竞品调研

1. **沉浸式翻译** — 双语同步显示，不覆盖原文，出海插件中使用最多的一个
2. **AITDK** — 浏览器SEO/网站分析插件，看域名年龄、TDK、关键词密度、页面结构
3. **SiteData** — AITDK升级版，看流量趋势、关键词、广告投放、相似网站
4. **Similarweb** — 流量来源分析，Direct/Search/Social/Referral/Paid 比例
5. **Wayback Machine** — 竞品历史快照，看目标用户和价格如何变化
6. **Wappalyzer** — 识别网站技术栈（CMS/分析工具/支付系统/客服营销工具）
7. **Google Trends** — 搜索趋势和季节性，提前一个月上线站点赶上搜索高峰
8. **Exploding Topics** — 发现上升趋势，不能替代用户和付费验证

## 二、SEO 与内容资产

9. **Screaming Frog** — SEO检查扫描，免费版500 URL限制，重点看404/重定向/重复标题
10. **SEO Minion** — 比AITDK更细节，检查标题/H1/内部链接/图片Alt
11. **Semrush** — 竞品Organic Research/Keyword/Backlink Analytics
12. **Moz Link Explorer** — 外链和域名权重查询
13. **Ahrefs** — SEO和竞品关键词分析，与Semrush选一个即可
14. **Linkhouse** — 外链采购平台
15. **Collaborator** — 内容发布和外链合作平台
16. **Fiverr** — 自由职业者服务市场，找外链发布/SEO审核/内容撰写
17. **Adsy** — 外链采购平台，筛选维度多但需人工确认页面质量

## 三、产品设计、AI能力与演示

18. **Figma** — UI/交互原型，先画5个关键页面暴露用户理解问题
19. **Framer** — 可视化建站，小型SaaS/垂直需求可用
20. **IconPark** — 图标素材库
21. **OpenRouter** — 统一调用多家大模型接口
22. **Dify** — 可视化搭建AI应用和工作流
23. **Replicate** — 试用和调用开源模型
24. **n8n** — 连接不同工具的自动化工作流
25. **Midjourney** — 生图工具，统一品牌视觉方向
26. **Ideogram** — 带文字海报/社媒图片生图
27. **Loom** — 快速录屏和异步讲解
28. **Screen Studio** — 公开展示录屏，缩放+高亮+字幕

## 四、建站、本地化与基础设施

29. **Cloudflare** — 域名/DNS/CDN/安全管理，海外访问慢先从这里排查
30. **Vercel** — 前端部署，GitHub连接后自动重新部署
31. **DeepL** — 偏自然表达的翻译，完成第一版英文仍需人工润色
32. **Weglot** — 给现有网站增加多语言版本
33. **Lokalise** — 多语言文本协作平台

## 五、支付、跨境资金与合规

34. **Stripe** — 全球支付和订阅管理，测试所有异常路径
35. **Paddle** — SaaS/数字产品支付，自动处理税务
36. **Lemon Squeezy** — 独立开发者收款，Checkout Link最快验证付费意愿
37. **Starryblu** — 跨境团队全球账户和资金管理
38. **Termly** — 隐私政策/服务条款/退款政策生成

## 六、增长获客与渠道分发

39. **Product Hunt** — 海外产品发布和早期反馈，冲榜+定位测试
40. **Uneed** — 产品导航站
41. **Microlaunch** — 独立开发者发布社区
42. **BetaList** — 早期创业项目发现平台
43. **Discord + Disboard** — 海外社群获客，先参与再提产品
44. **Toolify** — AI工具导航分类
45. **There's An AI For That** — 按任务查找AI工具目录
46. **Typefully** — X长推文写作/排版/排期
47. **Beehiiv** — Newsletter和邮件订阅，沉淀平台流量
48. **Customer** — 按用户行为触发邮件的营销自动化
49. **Loops** — SaaS事务邮件和生命周期邮件

## 七、数据分析与用户反馈

50. **Google Search Console** — 真实搜索词/展示次数/点击率/平均排名
51. **Google Analytics 4** — 事件追踪(sign_up/generate_lead/purchase)
52. **PostHog** — 产品事件分析，注册到付费漏斗
53. **Microsoft Clarity** — 热图和用户录屏
54. **Feedlog** — 用户反馈和产品问题集中整理（作者自有产品）
55. **Crisp** — 网站在线客服
56. **Cursorful** — 产品操作录制和演示视频
