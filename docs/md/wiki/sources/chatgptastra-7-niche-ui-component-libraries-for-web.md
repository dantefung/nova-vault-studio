# 摸鱼巨匠🔨（@ChatGptAstra）：网页 UI 做不好不是水平低——7 个特色组件库

> 7 个小众但有辨识度的 UI 组件库推荐：Looseleaf（纸张纹理 + 手绘钢笔线条 + 胶带贴纸风格，像画在笔记本上的完整界面）、Rare UI（专门做稀有动画组件，每组件一个文件，支持 shadcn CLI/MCP 安装）、ExpoKit（带液态玻璃、3D 效果、图表的移动端高端组件库）、goopUI（会滴落、拉伸、融合的液体物理效果）、beUI（动画丰富，覆盖 Web 与 React Native）、Sketchbook UI（手绘笔记本风 React 组件库）、AffectUI（专注 AI 产品的 React 组件库，Agent 可观测性做得非常深）。

<!-- more -->

你的网页 UI 做得烂，不是你水平低，而是你没用好这些组件库！

1. Looseleaf
   纸张纹理 + 手绘钢笔线条 + 胶带贴纸风格，像画在笔记本上的完整界面。
   https://t.co/jmT6gR50oP

2. Rare UI
   专门做稀有的动画组件，每个组件一个文件，支持 shadcn CLI/MCP 安装
   https://t.co/FSLcLVIsus

3. ExpoKit
   带液态玻璃、3D 效果、图表等的移动端高端组件库
   https://t.co/gw4oR8olFa

4. goopUI
   帮你做出会滴落、拉伸、融合的液体物理效果。
   https://t.co/PQbLsUyP0k

5. beUI
   动画丰富的组件库，覆盖 Web 和 React Native。
   https://t.co/MQeCLl2nEo

6. Sketchbook UI
   手绘笔记本风 React 组件库
   https://t.co/SIHd9hIf0a

7. AffectUI
   专注 AI 产品的 React 组件库，Agent 可观测性做得非常深
   https://t.co/pHMq3xTSOm
