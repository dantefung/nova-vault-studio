# 用 AI 从 0 到 1 做个海外工具站赚美元

之前介绍过，PDF 转 markdown、markdown 转 word、word 转 PPT……很多这样不起眼的工具站收入颇丰，这也是绝大多数 AI 出海的主营业务。

这个模式的好处显而易见：**0 成本创业，成了盆满钵满，不成，除了 token 毫无损失。** 不用投资，不用负债，堪称无风险创业的典范。

今天我一篇文章，不收一分钱，把里面的运转逻辑写给你听。

## 为什么要出海

首先，为什么不做国内市场，要出海？

这里面原因非常多，有些原因不便讲透，大家意会即可。

首先，海外市场相对不那么卷，发达国家的付费意愿相对更高，并且有不小的汇率差。比如针对美国市场，假设美国用户的转化率是国内用户 3 倍，再乘上 7 倍的汇率差，理论上能达到 21 倍的营收期望的差距，这是非常可观的。

另外一个很重要的原因是：海外的移动互联网相对没有那么发达，很多人还停留在使用网页应用的习惯上。我们可以不用开发成本更高的 app，而是相对成本更低的网页，能够快速上线，快速测试。

最后是合规，国内上架网站需要层层审核，经营性网站必须要公司实体，还有很多业务范围会受到限制。出海的政策限制更少，并且当前受到国家以及各地政策鼓励。

## 前期准备

### 收款账号

想要顺利出海赚钱，最重要的一点就是收钱。

用户得能够把他们的美元支付到你的账户里，所以首先得有一个账户。

海外收款账户，比较常规的选择是 Stripe。

![Stripe 收款界面](images/overseas-tool-site/001.png)

Stripe 目前官方不对中国大陆居民开放，但却经常在上海开展各类商户活动（懂得都懂）。一般来说需要借助境外公司实体，也就是首先得在境外开一家公司。

可能很多人不知道，中国公民是可以在境外开公司，而且门槛并不高。

常规的选择有香港、新加坡、英国和美国。

各地公司政策运营需求各有所不同，自己开的话流程比较繁琐，图快省事可以借助中介，花费在几千块不等。

我因为有新加坡 PR，所以开的是新加坡公司，其余地区不甚了解。

据说也有假装成 HK 人用港卡开通 Stripe 的邪修路子，我没研究过，一切只是道听途说。但公司开通的 Stripe 账户要比个人抗风险能力高得多，我个人不是很推荐。

除了 Stripe 之外，还有 Lemon Squeezy 和 Waffo Pancake 等选择，我也没有折腾过，有需要可以自行研究。

### 境外电话卡

一般来说，还会涉及到各类境外账户的注册，有时会用到境外电话。

我个人推荐的是澳门卡，某宝就能买到，外贸人员专用。需要绑定国内身份证，正常的使用没有任何问题，但不要拿它做奇怪的事情。

除此之外 Google Voice 也是一个选择，注册难度会比较高，当然，如果你善于浏览海鲜市场的话，一定可以找到方法解决的。

如果有机会去新加坡旅游的话，也可以考虑办个新加坡的 prepaid 电话卡。只要一直充钱，它就不会注销能一直用，月租 15 新币，80 RMB 左右，不算太贵。这个卡只有去新加坡才能办，别的地方花再多钱都办不了。

## 开发过程

现在应该没有人会古法编程手搓代码了吧，都是用 coding agent 来 vibe-coding。

vibe-coding 离不开大模型，这块的资源我也替大家搜集过了，国内外叫得出名的大模型渠道都有，比官方便宜。

**相比于大模型，其实更关键的是代码模板。**

为什么很多独立开发者大佬可以小时级上站？

除了他们经验丰富以外，更重要的是他们有一套专属的代码模板，天然集成了 70% 以上的功能。像是登录、支付、会员体系等，每个项目的逻辑都是大同小异的，有现成的代码就可以速成了，没必要从头开始。

真正要做的核心逻辑只有很小一部分，vibe-coding 就能做到非常快。我曾经开发我的博客时就试过一次，先用 Codex 找模板，然后再基于模板开发，从开工到上线，一小时搞定。

代码模板的重要性可见一斑，也有大佬专门出售代码模板，收入颇丰。

## 流量获取

网站开发容易，上线之后赚钱很难。

因为没有流量。

那怎么样才能获取流量呢？大概分成三个流派。

### SEO、AEO 派

SEO 是搜索引擎优化，顾名思义就是通过优化网站布局、内容等方式，来迎合搜索引擎的喜好获取流量的方式。

也不只是网站本身的优化，很多站点在设计之初就是围绕 SEO 设计的，甚至还没有开发就已经选好了目标搜索词。

AEO 类似，只不过把搜索引擎换成了 AI。

这一派也是最讲究技术含量的，最卷的。搜索引擎的免费流量大家都想要，为了赢得流量就得卷。

除了要卷网站本身的质量、内容排版，还要卷搜索词、卷外链、卷权重。

尤其是卷外链，真的非常卷，要不停地做手工活，很多外链还得花钱。我个人不太喜欢卷，所以只是浅尝辄止。

### 广告投放派

顾名思义，这一派的做法是广告投放，俗称买广告。

和谁买？一般是谷歌。

既然是买广告，那显然得花钱，而且得花不少钱。在卖流量这件事情上，谷歌并不比某度良心多少。

然而买广告并不只是花钱这么简单，里面的门道也不少。比如买什么词，选什么人群，用什么投放策略。经常有大佬折腾了很久，结果不小心选错了投放国家（比如印度），导致最后打水漂的。

新手买广告几乎就是给谷歌送钱，基本上 ROI 都是负的。

但研究明白了会比较逆天，因为花钱就行了，能省事很多，运气好能直接引爆站点，短时间内盆满钵满。

属于是学成了就会比较牛 X，但是学费不菲的技能。

很遗憾，我不够有钱，没有攒到足够的学费，所以也没有过多经验。

### 自媒体派

这一派讲究的是通过做自媒体自带流量。

好处很明显，长期来看价值很高，并且不花钱，而且流量能形成闭环。靠宣传自己的产品吸引粉丝，自媒体的内容是自己的产品介绍，赚钱的主要来源是自己做的产品。相当于自己给自己打广告，绝对是最符合长期主义的。

然而缺点也很明显，做自媒体太难了，门槛也非常高，尤其是境外的自媒体。

像是 X、Reddit、Product Hunt 等，很多平台注册时间过短甚至直接不让你发帖……

我的 X 折腾了一个月也才 75 个关注……相对来说 X 是比较容易做的平台，对中文使用者也比较友好。

很明显，这三条路子都不是很好走。

有没有别的办法？
