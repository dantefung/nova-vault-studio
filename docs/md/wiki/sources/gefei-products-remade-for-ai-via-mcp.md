# 哥飞（@gefei55）：很多产品都可以重做一遍——不是给人用，而是提供 MCP 给 AI 调用的自闭环

> 产品重构的新范式：不要只考虑面向人类的 GUI，而是提供 MCP 让 AI Agent 能够直接读写数据。哥飞分享实战经验：网站管理后台所有配置、数据读取与总结分析全由 Claude Code 自主接管，再由 CC 根据数据反馈修改代码更新迭代，形成 AI 自己赚回订阅费与实现自盈利的闭环飞轮。

<!-- more -->

很多产品，都可以再做一遍。

不是给人用，而是给 AI 用，让 AI 更方便用。

提供 MCP 让 AI 可以读写数据，会特别特别方便。

最近我自己上的几个网站，虽然有一个网站管理后台，但我自己已经不亲自动手去做任何设置了，只是偶尔上去看看某些数据。

所有的设置，我都让 CC 帮我去，包括读取数据总结分析也是让 CC 自己去。

有了这些数据之后，CC 又可以修改代码，更新迭代。

再继续下去，是不是就可以让 AI 自己赚回他的订阅费，甚至赚到很多钱呢？

答案是完全可能。
