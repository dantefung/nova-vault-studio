# 再谈信任

昨天做了一期开放日，原本想收集下素材，结果不太如人意，大家可能更喜欢看我聊，后边尽量还是多写一些内容。有人问如何加入团队，回复说写一年复盘，如果你不太熟悉我的话觉得这件事非常扯淡，但近几年加入团队的人都是这样进来的，所以也没有例外。



不过这也不是无条件的，不是写完立马就加入，因为写的过程中，我们也会不断聊天，碰撞出来一些东西，加上一些抗压测试，再赚点小钱，这段期间会积累不少的信任。这个过程也算是一个双向选择，不需要什么仪式感，最好也别带有任何预期，如果觉得ok就发。



下边引用24年8月小记的一个素材，如何去把信任这件事量化。拿两个奥运会的入选资格来举例子（这是去年的例子，时效性差了一些）。



一个是比较冷门的三人篮球。



众所周知，中国足球和篮球都不太行，那为什么能进奥运会八国名单里边？这八个队伍入选规则是：世界排名前三名+奥运资格赛前三+两次普遍性资格赛第一。中国男篮队刚好卡在世界第三名，保送到奥运会。张宁个人积分也到了亚洲第一，并不是打得绝对的第一好，而是参加的比赛足够多。他在去年有个外号叫“流浪地球”，因为永远都在赚积分的路上。



三人篮球有一套成熟复杂的计算公式，比如要计算赛事权重和个人贡献因子，这里不再延展，只需要知道一件事就是——这个排名是可以刷的。只要参与的次数足够多，就可以弥补实力的差距，当然前提是付出非凡的努力。



再找个简单的例子，就是乒乓球积分系统。



女单冠军陈梦在五月沙特WTT之前是没有锁定奥运会资格的。王曼昱比陈梦多1555积分，此时只剩下一场积分赛。陈梦只有赢下冠军才确保拿到奥运会资格，因为这场冠军会拿到2000+3000个积分，亚军则是1400+1500积分。



那这一场竞争对手王曼昱拿到多少分呢？止步32强，拿到了90积分。没错，只有90分。如果连32强都没打进的话，会给个安慰奖20个赛事积分。



（2025最新世界女乒乓选手积分榜）



废话有点多了，铺垫了这么久，想参考这样的一个设定：信任值是有衡量标准的。



举几个例子：



约定了回复时间，及时回复，完成一次闭环，+10分



完成一次业务上的专业解答，+20分



线下见面，+50分



微信群里发1分钱红包，-100分



完成一个周期的合伙合作项目，+1000分



面对诱惑，并且超预期完成一个项目，+5000分



……如果你想积累到不错的信任度，有两种方式可以完成：



1. 完成级别较高的任务（陈梦拿到WTT大满贯冠军）；



2. 不断刷低等级任务（张宁“流浪地球”般参加积分赛）。



有个基本常识是：信任是不难获得的。如果难获得，那么电诈公司就不会轻而易举地骗钱。而且信任大概率直接等于钱（划重点）。



有人考古过我的公众号，最早期这个系统用途是自己在17年做了一个早起学院的东西，拉了个群每个人交10快钱，没完成早起任务几次淘汰，最后瓜分这个奖池，每个月有个千八百块。那时候遇到最多的问题是什么呢，很多人会来质疑，你会不会拿着这10块钱跑路。那时候我的信任值10块，这就是具象化的一个体现。



到了现在通过不断的打怪升级，在公众号里边看到日更了两年（目前是三年），即使我们毫无交集，大概率也不会有人认我为了10块钱或者更多的钱，就不爱惜翅膀了 。



所以正确的做法应该是：创造积累信任点的机会-执行闭环-完成更高级别的任务，随着任务的分数越来越高，舍弃掉一些低等级的任务，完成自己的爆发式增长。



回顾完去年的小记素材，我发现自己非常擅长把一件很抽象的事情去量化，或者用通俗的语言讲清楚。我践行的价值观或者招人策略也都是如此。



简单说，必要的一定要积累信任，积累信任这件事很难，但是失去信任非常简单，比如有人直接加好友或者留言说，我要赚钱，那可能连加好友的门槛都过不了。很多人会在还没建立信任值时，就开口要结果，这几乎等于要别人直接把冠军积分让给你。这件事除了kk园区，全世界任何一个地方都没办法满足你这么粗暴的一个要求。



加入团队角度也是如此。大部分人起点几乎没有信任基础，靠简历、面试来推进一桩强信任关系的合作，本身就很草率。所以在正式合作之前，有一段磨合期就是方案。不必担心是不是链接太晚，我坦诚讲，身边绝大多数人合作哪怕五六年，也就是T1–T2的信任强度，少数人能到T0。



并不建议来问“在我心中你的信任度是多少？”因为信任度和是否信任一个人没一毛钱关系，我也不想回答这么伤感情的问题。团队里信任度决定了分工和资源分配。信任强度T0的人一定在任何方面都是连吃带拿的，整个社会的运行规则也是如此，但很少有人能一蹴而就。这里还有一个反常识的规律：一般来说，靠近资源越近，反而越不容易珍惜机会；机会不多人，反而能迸发出更强的关系。



所以一定要尽早的去各处抢占信任的资源，我写公众号也是，拍视频也是，这是我未来所有事情的下限和底气。



信任是有极强的复利的，无论创业、投资还是关系，本质都在于信任。钱只是信任的映射，机会只是信任的衍生。理解这一点，很多事情就会变得简单。
