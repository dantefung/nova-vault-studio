# Roland（@ChainEpic）：另一个例子——Time.is 放弃 whattimeisitnow.com，用冰岛 .is 凑出完整句子

> Time.is 团队放弃 whattimeisitnow.com，直接用冰岛 .is 后缀凑成完整句子。若按传统 SEO 思路得注册 exacttime 相关词组，而创始人用 .is 凑出 time.is（时间是……），既是完整英语句子、又只有 6 个字符，垄断了全球「对时搜索词」，月流量破五百万。
