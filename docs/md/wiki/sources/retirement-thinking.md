# 退休么

日更写了几天，灵感有些枯竭。今天完成了一次转念：不如从之前的小记里挑些选题，把当时的素材再拿出来聊聊。好处有两个：



一是避免没灵感时硬写流水账，况且很多内容我自己都没印象了，更别说大家；二是随着时间推移，想法会发生变化，再聊也能有新的体会。



比如，我曾有个特别土的想法，想住别墅，现在完全不想了。原因很简单，别墅没那么舒服、要打理的东西太多、楼上楼下动线复杂，本来家里就够乱了，想想都觉得头疼。那时只觉得大房子=舒服，是典型的单线程思维，没往后想，能稍微想一想的就是那大房子我可以雇保姆啊，但是缺少的思考是保姆带来的不仅是开销，还有隐形的管理成本。带过团队的人都懂，很多时候管理最大的麻烦就是“还不如自己上”。更别提万一做大做强了还要管理一个保姆团队，换个更全景的视角，就有了完全不同的答案。也许过几年又会变，但至少当下是这样。



看到有人提别人的公众号，说紫菜要退休了。虽然纯属谣言，但我认真想了下：自己是不是要退休了？



按照我当初立的flag，18、19年时就时不时提到，35岁退休。时间一晃，这个年纪真的快到了。但随着年龄增长，我对退休的理解早已不同。



就像住别墅一样，都是没经过深思熟虑的念头。我们从小就被一种固定句式诅咒：等你考上大学就好了，等你毕业就好了，等你结婚就好了，等你买房就好了……我是每个阶段的亲历者，但事实证明，活到现在都不知道哪里变好了。所以大概率，退休也不会像想象中那样简单。



这些想法，都是单线程思维的结果，经不起推敲，拿退休来说退休不只是离开工作岗位。字面上看，它太魔幻、太模糊，经不起推敲。叔本华说过，人生就像钟摆，在痛苦与无聊之间摇摆。如果一个人是靠奋斗获得乐趣的，那停止奋斗，也等于失去了乐趣。那样的退休，才是真的走向无聊。



对我来说，做团队是一件很有意思的事，也很珍惜其中的友谊。从这个角度看，我不会退休，因为会一直做下去。至于未来会不会出现更有意思的事？可能会，但这并不意味着要停下追求和奋斗。



我想起一个视频：新加坡一位70岁的老人还在开出租车。他抱怨说，新加坡人七十岁了还得工作，要是在大陆，可能早就能安稳享福了。在发达国家，出租车司机很多都是老人。拍摄者问他为什么还要赚钱？老人说：要攒钱去旅游啊。那一刻我很确定，就算让他重新选择一百次，在享清福和继续赚钱之间，他还是会选择后者。



无论是当初想住别墅，还是立下35岁退休的flag，都是一种单线程的想象，真正的生活远比想象复杂，也比想象有趣。
