## 核心洞察

### 广州的优势三角

```
货源（番禺农机/花都工程材料/白云小型机械）
    ↓
物流（环城高速+广清高速，重货到全国成本可控）
    ↓
圈层（白云/番禺电商园同行，互相分享哪个工厂配合好）
```

三人互相强化，构成广州特有的工业品电商生态。

## 商业模式：店群 + 采集 + 代发

**操作流**：
1. **采集**：用软件一键复制工厂链接和图片
2. **优化**：主图加"工厂直发"/"厂家直供"水印，标题用工厂原版
3. **上架**：淘宝店群（20 个店）
4. **发货**：代发模式，工厂直发，不用囤货

**关键公式**：好货不愁询盘。

## 核心方法论

> "广州周边工厂多得是，就看你会不会用。"

这句话是整个商业模式的锚点。不是选赛道，是**选地理**——广州本身就是供应链超级节点，就看你能不能把它用起来。

**从那之后**：去工业区跑、拍实拍图、用采集软件复制。这套流程的精髓是**工厂真实场景 = 最强信任背书**。焊接火花四溅的过程拍下来，比精修图更有转化力。

## 一个人管 20 个店的杠杆

店群 + 采集软件 + 代发 = 极低边际成本的放大结构。核心杠杆不是资金，是**信息路由**：知道哪个工厂配合好、哪个品类售后少、哪个品类的物流成本最优。

这些信息靠跑出来，不靠想出来。
