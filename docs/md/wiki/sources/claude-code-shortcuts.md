# 用了一个月 Claude Code，这几个快捷键我每天都在按

今天想分享我最常用的 Claude Code 快捷键。

之前我用过 Antigravity、Codex、Cursor，唯独没用过那个大家都说是全世界最好的 Claude Code。

一个多月前抱着想尝试一下的心情开了 Pro 订阅会员。

结果从这里：

dont-touch-vibe-coding

变成了这里：

do-not-touch-cc

正好我也一直觉得，不能老换工具，得专心用好一个。

于是就铁了心，一直好好用 Claude Code。

大伙儿也都知道，Claude Code 是在终端里用的（终端就是那个黑乎乎、全靠打字的命令行窗口）。

所以有件挺不方便的事：操作基本全靠键盘，能用鼠标的地方少之又少，除了关窗口，我想不出鼠标还能干啥。

说到键盘操作，我可就有的说了。

上学的时候我爱打游戏，网游、射击、还有《星际争霸》这类。

打星际的时候你要是不会快捷键、全靠鼠标点，基本连电脑都打不赢。

可能就是因为这个，我到现在用电脑都爱用快捷键，能不碰鼠标就不碰。

单次也就省一两秒，但天天用，省下的时间真不少。

我也不追求什么快捷键都知道，光知道没用，记不住。

真正留得下的，就是那些天天用的，用着用着自然就记住了，其实也就那么几个。

我也常看博主分享快捷键，但说实话，他们列的我大半用不上。

这一个月我自己攒下的就这些，都不是什么秘密、网上也搜得到，但应该挺适合跟我一样的小白。

Claude Code 自带的：







快捷键

功能









Esc

打断 Claude（停下当前回复，已经做完的部分会保留）





Esc Esc

清空你刚打、还没发出去的内容





Shift + Tab

切换权限模式（控制 Claude 动手前要不要先问你一句）





Ctrl + G

把输入跳到外部编辑器里写（写长提示词时顺手）





Option + P

切换模型（不用清空已经输入的内容）





Option + T

开关扩展思考（让它回答前多想一会儿）





Ctrl + V

粘贴剪贴板里的图片





Ctrl + J

换行，但不发送





↑ / ↓

翻你之前输入过的内容





/、!、@ 开头

分别是调命令、直接跑终端命令、补全文件路径







终端通用的（不只 Claude Code，在终端里到处都好使）：







快捷键

功能









Ctrl + A

光标跳到行首





Ctrl + E

光标跳到行尾





Ctrl + U

删掉光标前面到行首的内容





Ctrl + K

删掉光标后面到行尾的内容





Alt + 左 / 右箭头

光标按“词”左右跳（这个可能要在你终端的设置里开一下，不一定默认就有）







上面这些，就是我的常用清单了。

但我就怕大伙儿看完，要么收藏吃灰，要么记不住，最后也没用上。

所以再说说我自己是怎么做的。

前面我说了，我也常看博主分享快捷键。

可别人列的，我照样记不住，也对不上自己的用法。

这让我想起那句老话，授人以鱼不如授人以渔。

与其死记别人给的快捷键，不如找到一个自己随时能查的方法。

顺着这个想法，我问了一下 Claude Code（万事问 Claude Code），找到方法了。

你把这句提示词存下来，下次想不起快捷键，直接在终端里问 Claude Code：

请给我看 app 和 chat 的快捷键和说明

快捷键除了 app 和 chat 还有很多，那我为什么这里只提 app 和 chat？

因为我用下来觉得，除了这两类，其他的小白基本用不上。

当然你要是好奇，把提示词里的「app 和 chat」去掉，直接说 请给我看快捷键和说明，Claude Code 就会把全部快捷键列给你看。

最后再分享这篇其实最干的一个货：Claude Code 的官方文档，有中文版。

学什么都不如学官方文档，它最权威、最真实、也最完整。

而且我发现它有个特别好的点：它内置了一个免费的 AI 询问助手，不用登录就能问。

围绕 Claude Code 的使用，你有什么问题都可以直接问它。
