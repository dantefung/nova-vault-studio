# 无需公司！手把手教你注册 Stripe 个人账户，轻松搞定全球收款

> 出海过程中最大的门槛之一是收款。Stripe 是全球最成熟的线上收款方案之一，即使没有公司账户，也可以通过注册 Stripe 香港个人账户，利用已有香港银行卡实现合规结汇。这是目前最简单直接、损耗较低的方案。

<!-- more -->

## 前置条件

在开始之前，需要准备以下资料：

- **身份证明**：护照（港澳通行证理论上也可以）
- **收款账户**：个人名下的香港银行账户（中银香港、汇丰、众安银行等）
- **业务载体**：自己的出海网站或 X 主页（作者用的是 X 主页）
- **安全工具**：手机端已安装 Google Authenticator 或其他 2FA 工具

## 一、注册

访问 Stripe 官网开始注册。**最关键的一步**：账户地区必须选择**中国香港特别行政区**。

原因：使用港卡作为提现账户，必须选择香港。Stripe 的规则是「同区结算」——香港账号只能结算至香港本地银行。

同时需确保填写的姓名、银行卡持有人姓名、证件姓名三者拼写完全一致，否则 KYC 认证不通过会很麻烦。

### 1.1 基础设置

初始配置中有「商家设置」和「使用方式」选择，为了快速搭建收款链路，可以先点击「跳过」或默认选择。

点击继续后前往管理平台，系统默认进入沙盒页面。此时账号还未激活，需要点击顶部的「切换到真实账户」正式开始激活流程。

### 2.1 验证业务信息

Stripe 对个人账户非常友好，但填写时需保持信息真实有效：

| 字段 | 填写建议 |
|------|---------|
| 商家类型 | Individual |
| 个人详情 | 如实填写，香港身份证号填写护照号即可 |
| 公司详情 | 填写自己的网站地址（作者填的是 X 主页地址） |
| 产品或服务 | 如实填写，需与网站一致 |

**注意事项**：
- 单个业务最好使用单个账号，以防某个业务被风控导致其他业务收款受影响
- 需要添加公开详情（账单和收据上展示的信息）

### 2.2 添加银行账户

- 输入香港银行代码、分支代码及账号
- 确保账户状态正常，能接收小额转账校验
- Stripe 安全等级极高，推荐使用 Google Authenticator 绑定
- 绑定后会生成一组备份代码，**务必截图留存 + 物理抄写保留**——一旦丢失密码又不记得备份代码，找回账号会非常麻烦

### 2.3 审核信息并提交

检查一遍填写的信息，核对无误后提交。

完成后 Stripe 会提示进行 Identity Verification，按系统提示用手机拍摄护照上传即可。审核通常在几小时到 1 个工作日内完成。

通过后，账户正式具备收款权限，可以开始全球收款。

## 二、优化汇损

用个人港卡做的 KYC，Stripe 默认会有一个港币账户。

如果业务平时收的是美元，它会从美元转换成港币，中间有约 **2% 的换汇损失**。解决方案：

1. 进入「商家 → 银行账户与货币 → 结算货币和银行账户」
2. 新加自己的美元账户，并将其设置为默认货币

虽然美元提现通常会有约 1% 的提现费用，但相比 2% 的换汇损失，依然能节省近一半的中间手续费。

## 三、总结

Stripe 的个人账户为小成本试错的出海者提供了一个方便的途径。比起动辄几千元的公司注册费用，非常划算。

注册过程在身份验证和银行绑定上存在一定门槛，但其极高的自动化程度和强大的 API 支持，能省下大量处理财务杂务的时间，让注意力更专注于业务本身。

## 边界与判断

- **适用范围**：需要已有香港银行账户，非香港居民不适用此方案
- **风险点**：
  - 姓名一致性要求严格，拼写不一致会导致 KYC 不通过
  - 备份代码必须物理留存，丢失后找回困难
  - 单业务单账号原则，避免风控牵连
- **汇损优化**：设置美元为默认货币可节省约 1% 成本（从 2% 换汇损失降至 1% 提现费）
- **发布时间**：2026-01-26，部分规则可能有更新，请以 Stripe 官方最新说明为准
