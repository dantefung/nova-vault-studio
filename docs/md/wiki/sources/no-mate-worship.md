# 不要乱拜码头

今天想聊一个严肃的话题。



以前卖手机的时候，正常流程是要找不同供应商拿报价单对比价格，因为每家擅长的项目不一样，价格也会有差距。理论上，比价肯定能拿到更好的条件。但那几年，我从头到尾只合作过一个商户，不是懒，也不是没资源，而是自己太清楚——信任的建立太难了。偶尔可能少赚一点钱，但省下的时间、精力和摩擦成本，让我能在极短时间把这个生意做的还不错。



昨天遇到一个类似的事，有个不错的项目可以通过合作放大，一个人说他有两个账户，问能不能一起做，我说可以。过了一会儿，另一个朋友又问我这人是不是靠谱？他说那人也找他聊过，说有账户想合作。这才反应过来，他可能有多个账户，想找多个人进行合作。其实目的也很简单，通过合作的方式跟不同人建立信任，广撒网。



太阳底下无新事，圈子太小了，很容易互相知道。这是一个非常糟糕的体验，我内心对他的信用评级大概到此为止。



我说这些的目的是什么？



是想提醒一句：不要乱拜码头。



很多人刚入行就东一下西一下，见谁都想聊两句，觉得人脉越多越好。但人脉不是越多越值钱，而是越深越值钱。你要有克制，才能让真正的关系发挥最大效用。



### 克制能让人脉发挥最大作用



人脉的关键在“稀缺”，而不是“数量”。



我倒不是希望别人把所有账户都压在我身上，而是觉得无论给谁，全力信任一次，才是真正的开始。那种每个人都浅尝辄止的合作，只会让自己永远停留在表面。



现在我在行业里常合作的也不超过五个人，算上临时的加起来不到十个，大家节奏一致、配合高效、信任牢固，沟通成本极低，反而比那种“广撒网”的关系网更有力量。



克制是一种能力，当你能拒绝无效连接，就能沉淀出真正的信任与实力，到最后，人脉会反向来找你。



### 人脉也是“10倍比2倍更容易”



想起一本书《10倍比2倍更容易》。当你以“10x”的视角要求自己，就会自然聚焦，只做有可能让你十倍增长的事。这个逻辑对人也一样，真正能带来十倍回报的关系，往往不在数量，而在质量。我们对“深度人脉”的挖掘实在太少，能把一段关系经营好，已经很难得。一段高质量的关系，能带来的能量与信任，是十段浅层关系都换不来的。



到了今天，大家赚钱的方式早已各显神通。这里没有对错，但选择了A，大概率就得放弃B，这是必然的。赚钱的流派有很多，这个世界不允许既要又要。你必须清楚自己要学哪一种模式去赚钱，或者要跟谁学习赚钱。



这种时候，更应该把有限的注码all in在自己最容易拿到回报的人身上。因为资源永远有限，把能量集中在对的人身上，才能持续放大。



赚钱比的不是更会社交，而是更知道谁值得花时间深交。
