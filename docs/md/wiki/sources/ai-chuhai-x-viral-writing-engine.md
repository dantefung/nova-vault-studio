# X 爆款写作引擎 v1.0：没有自己的数据，就用同赛道的爆款

> @GeekCatX 分享了一套很硬的 X 写作方法：把过去 7000 多条推文喂给 AI，清洗成「原子化知识库」，再炼出选题与写作两个 Skill。但这套方法有个前提——你得自己真刀真枪发过大量推文。新手恰恰卡在第一步。工程书的解法是：**没有历史就让 Agent 自己去拉同赛道的高互动原创帖。**

## 一、猫哥的绝活，和新手卡住的地方

@GeekCatX 的做法：

```text
7000+ 条历史推文
  → 喂给 AI
  → 清洗成「原子化知识库」
  → 提炼出两个专属 Skill
      ① 选题 Skill
      ② 写作 Skill
  → 看到热点：先用选题 Skill 定角度，再用写作 Skill 出稿
```

> 「写出来**连老粉都分不清是不是 AI 写的**。」

### 评论区点破的痛点

@willzero 一句话：

> 「这是基于有大量原创数据的情况，问题是**很多人没有这么多的原创数据**。」

**新手恰恰卡在第一步。**

---

## 二、工程书的解法：没有自己的数据，就用同赛道的爆款

**数据源换一下，整套方法就对所有人都能用了：**

| 你的情况 | Agent 的数据来源 |
|---|---|
| **有历史** | 读你的推文或数据存档，学你的口吻 |
| **没历史** | Agent 自己去拉 **10 到 30 个同赛道账号的高互动原创帖**，作为学习材料 |

> 「你只需要**一句话说清楚你的赛道**，比如『AI 出海、面向中文用户』；有账号就附上 @你的账号。剩下的 Agent 全部自己做完。」

---

## 三、怎么用

- **最简单**：打开聊天，选你的 Grok Bot，把这篇文章整篇投喂给它，说「**按这本工程书做**」。Grok Bot 自带免费读取 X 公开数据的能力，不用申请 API；
- **其他 Agent**（Muse、WorkBuddy、Claude、ChatGPT、Cursor 等）：把文末「给 AI 看」那段整段复制进去。没有 X 数据权限的 Agent 会改用网页搜索，或者让你贴 20 到 50 条帖子给它。

---

## 四、Agent 会自己做完的事

| # | 动作 | 要点 |
|---|---|---|
| 1 | **拉数据** | 有账号就读你的原创帖；同时搜出同赛道账号，拉它们的高互动原创 |
| 2 | **清洗排序** | 按互动率排序——**（点赞 + 收藏 + 转发）÷ 曝光**；去掉回复、转推、广告和水帖 |
| 3 | **原子化** | 每条拆成**主题、角度、钩子、结构、长度、形式、数据、原帖链接**，存成 JSON 语料库 |
| 4 | **炼出两个 Skill** | 选题 Skill 记录什么角度容易爆、怎么接热点、什么该避开；写作 Skill 记录钩子类型、结构、节奏、排版、长度，**有你的历史就加上你的口吻特征** |
| 5 | **写出本周 7 篇成稿** | 都是原创主帖，紧扣你的赛道。有 Premium 给长文版，没有就给 280 字符以内的短版 |
| 6 | **逐篇查重** | 每篇成稿都和语料库里的来源帖比对，**连续 12 个字以上相同或者词组重合太多，就重写**，直到通过 |
| 7 | **排好发帖时间** | 按你的目标读者所在时区，挑他们醒着的时候发，并附上发帖后 2 小时的互动清单 |

### 只学结构，不抄句子

> 「拉别人的爆款，学的是**选题角度、钩子、节奏和排版**，不是原句。Agent 不会照搬任何一句话，也不冒充任何博主，**每条学习材料都保留原帖链接作为出处**。」

## 五、新手要知道的 X 算法

> 原文声明：「以下只写开源代码 `xai-org/x-algorithm` 里看得到的规则，以及 @situking 手册里核对过的参数。**公开代码的默认值不等于线上每个账号的实际参数，所以不保证效果。**」

### 推荐是按每个读者预测互动

同一条帖子，面对不同读者排序不同。**内容越贴近你粉丝关心的话题，越容易被推。**

### 互动权重（公开参数）

**正向**：

| 行为 | 权重 |
|---|---|
| 复制链接分享 | **20** |
| 回复 | 5 |
| 引用 | 5 |
| 私信分享 | 5 |
| 关注作者 | 4 |
| 转帖 | 1 |
| **点赞** | **0.66** |

**负向**：

| 行为 | 权重 |
|---|---|
| 举报 | **-234** |
| 静音 | -58.8 |
| 不感兴趣 | -52.272 |
| 屏蔽 | -31.2 |

> 「**写让人想转给朋友、想回一句的内容，比求赞更有用。**」—— 点赞权重只有 0.66，而复制链接分享是 20，两者差 30 倍。

### 其他四条规则

- **发原创主帖**：非关注者的回复和转推，会从 For You 里过滤掉；
- **小号有冷启动加推**：5 万粉以下的作者，发出 **2 小时内、曝光不到 200** 的主帖（不含回复）有一次加推。所以挑读者醒着的时候发，**发完守在评论区回复**；
- **外链不用放评论区**：X 产品负责人 Nikita Bier 说过**外链从未被刻意降权**；
- **@ 的位置有讲究**：
  - 帖子开头就写 @用户名，会限制它在粉丝首页的分发；
  - 长帖只有**前 280 个字符内**的 @ 会通知对方；
  - 长文 Articles 正文里的 @ 不一定通知，**发布后在回复里单独 @ 一次**。

## 六、iLang 判断层管什么

这本工程书用 iLang 写成。**iLang 是一个 AI 判断层协议，管的是 AI 什么时候自己做、什么时候必须先问你：**

- 不抄袭、不冒充任何博主；
- 算法只写代码里看得到的，不编规则、不编数据；
- **绝不替你发帖、回复、点赞、关注或发私信**，成稿交给你自己发；
- 不承诺涨粉和曝光。
