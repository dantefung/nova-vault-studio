# 【哥飞SEO教程】先收集关键词，再规划网站结构

> 很多人做第一个网站顺序就反了——先买域名、搭首页、想导航栏，再问要优化哪些词。更稳的顺序：先收关键词，再看搜索量和搜索意图，最后规划网站结构。

## 核心思路

网站结构不能只看导航栏好不好看，背后是你对用户需求的理解。**关键词表整理得越清楚，后面写页面、做工具、建内链、看 GSC 数据都会更顺。**

## 先别急着做首页

以 AI 图片工具站为例，需求分生成图片、照片转动漫、职业头像、老照片修复、图片放大等方向。如果只用一个首页接所有需求，页面泛泛，用户找不到对应功能，谷歌也难判断你最擅长什么。

## 多入口收关键词

不要只靠一个工具：

| 入口 | 用途 |
|------|------|
| 谷歌下拉 + 相关搜索 | 真实用户经常接着搜什么 |
| 谷歌趋势 | 趋势走向和地区差异 |
| Similarweb / Semrush / Ahrefs | 从竞品页面反查关键词 |
| 谷歌 Ads 关键词规划工具 | 搜索量和点击价格参考 |
| YouTube / TikTok / Pinterest 搜索下拉 | 不同平台的角度 |

第一步只是收集，先尽量把词拿全。注意同义表达（photo/image/picture/pic/img）都要收。

![关键词收集](images/gefei-seo-keywords/001.png)

## 搜索量不能只看一个工具

第三方工具用来发现机会，最终排序时回到谷歌自己的数据。谷歌 Ads 关键词规划工具的两个功能：

1. **发现新关键词**：输入主词，基于语义给更多相关词
2. **获取搜索量和预测数据**：批量输入关键词，看搜索量、竞争情况和点击价格区间

两个细节：
- 同义词可能被归到一起显示同一搜索量，用谷歌趋势对比（加双引号）看哪种更常用
- **点击价格低 ≠ 没价值**：可通过广告、联盟、工具订阅、线索转化变现

![谷歌 Ads 关键词工具](images/gefei-seo-keywords/004.png)

## 清理词表

拿到搜索量后先清理，不要马上让 AI 规划网站。词表结构：

| 字段 | 用途 |
|------|------|
| 关键词 | 用户实际搜索的词 |
| 搜索量 | 大致需求规模 |
| 意图 | 用户到底想完成什么 |
| 页面类型 | 首页、工具页、栏目页、文章页 |
| 优先级 | 先做、后做、暂不做 |
| 备注 | 竞争、风险、是否需要功能 |

## 按搜索意图分组

以 AI 图片工具为例：

- **生成类**：文本生成图片、图片生成图片、批量生成
- **修复类**：老照片修复、图片放大、去模糊、色彩增强
- **风格转换类**：照片转动漫、转卡通、转艺术画
- **具体场景类**：领英头像、简历照片、电商商品图、社媒头像

首页负责解释总需求和引导；工具中心负责分门别类；具体工具页负责满足一个明确需求。

## 关键词表 → URL 清单

把清理后的关键词表、搜索量、意图分组和产品能力一起给 AI。提示词要详细，不要只问"帮我做一个网站结构"。

得到结果后人工判断：删掉没有真实差异的页面（如 `ai image generator` 和 `ai images generator` 可能不需要两个页面），保留需求确实不同的（如 `ai image generator` 和 `old photo restoration ai` 应拆开）。

## 新人最容易踩的坑

1. **只追搜索量** — 大词未必适合第一批做，还要看竞争、页面类型、自身能力
2. **同义词拆太多页面** — 需求一样只是表达不同，放同一页覆盖即可，强行拆开做出一堆薄页面
3. **只做文章页不做功能页** — 工具站核心是工具，用户搜"生成/转换/修复/下载/计算/检查"时希望打开页面就能操作
4. **不做内链** — 首页、栏目页、工具页、文章页之间要有关系，用户看完一个页面能继续找到相关工具

## 总结流程

1. 多入口收集关键词
2. 谷歌 Ads + 趋势补搜索量
3. 删除不相关词，合并同义表达
4. 按搜索意图分组
5. 给每组词分配页面类型
6. 生成第一批 URL 清单
7. 人工删掉重复页面和薄页面
8. 先做最有把握的 5-10 个页面
