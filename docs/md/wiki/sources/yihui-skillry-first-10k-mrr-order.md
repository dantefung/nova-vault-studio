# Skillry 上线一月破万刀复盘：写代码前先想明白商业模式与营销打法

> 写代码的速度变快了 10 倍，做出「0 付费 0 用户」产品的速度也快了 10 倍。绝大多数独立开发者亏钱不是代码写得不好，而是**顺序做反了**——先把产品写出来，上线后才发现没人买。Yihui 分享自己新产品上线 1 个月的完整账本与前置决策方法。

<!-- more -->

## 一、结果与核心判断

新产品 **Skillry** 上线 1 个月：**400+ 活跃付费订阅，近 30 天收入 $12,037，MRR $3,918**。

> 「Vibe Coding 真的太爽了。以前要写一个月的 SaaS，现在打开 Codex 或 Claude Code，接上 Stripe 或者 Waffo，一个周末就能上线收款。」

**但残酷的真相是**：

> 「写代码的速度变快了 10 倍，做出『0 付费 0 用户』产品的速度也快了 10 倍。」

> 「绝大多数独立开发者亏钱，不是因为代码写得不好，而是**顺序做反了**——大家总是先把产品写出来，上线后发现没人买，才开始头疼怎么营销，最后才发现这个商业模式根本赚不到钱。」

---

## 二、写第一行代码之前的两个必答题

Yihui 现在的固定流程是**先扒同赛道已经赚钱的产品**，逼自己想明白两件事：

1. **商业模式怎么转**——卖什么？怎么定价？怎么持续盈利？
2. **营销打法怎么抄**——第一批付费客户从哪来？怎么营销增长？

> 「想通了这两件事，最后才决定这个产品做不做，才去 Vibe Coding。」

---

## 三、第一件事：先想明白商业模式

### 3.1 反面样本：Skill 集合站为什么不赚钱

今年年初「小龙虾」（Claude Code 类工具）火的时候，一窝蜂出现大量 Skill 集合站——抓几千个开源 Skill 往站上一放，看起来内容很丰富。

> 「**绝大部分 Skill 集合站根本不赚钱。** 原因很简单：普通的规则脚本和通用提示词，大家去 GitHub 免费复制就行，或者让 AI 自己写只要 10 秒钟，**根本没有人会为『信息搬运和汇总』掏钱**。」

### 3.2 核心原则：不要发明没人验证过的商业模式

> 「**不要自己去发明一个没人验证过的商业模式，去找一门早就被证明能赚大钱的老生意，换上 AI + Agent 时代的新载体。**」

Skillry 看着在卖 Skill，**底层其实就是「卖有审美的模板」**——和传统卖 PPT 模板、卖网页模板是完全同一种生意。

> 「程序员和 Vibe Coder 最大的短板从来不是写逻辑，而是**缺审美**。AI 默认生成的网页、PPT 和视频有一股浓浓的『塑料味』，谁能帮开发者把审美调好、做成现成的模板，谁就能赚钱。」

### 3.3 模板赛道三个标杆

| 产品 | 做法 | 结果 |
|---|---|---|
| **Tailwind UI** | 卖顶级排版的官方组件模板（$299 买断） | 上线 5 个月卖破 $200 万 |
| **Magic UI / Aceternity UI** | 卖 Linear 风格和 3D 炫酷动效组件模板 | 一个靠开源引流卖 $199 终身版（5000+ 付费开发者），一个连代码都不开源，光靠 X 上的动效演示就做到**月入 $6 万–$10 万** |
| **21st.dev** | 把高审美组件和付费模板（$29–$69）通过 MCP 直接塞进 Codex / Claude Code | 迅速成为 AI 编程圈最火的组件市场之一 |

### 3.4 用竞品真实流水校准三个真相

Yihui 在动手前用竞品收入数据工具拉出同赛道 7 个产品的真实收入做对比，看完立刻看懂三件事：

**真相 1：纯一次性买断的老模板正在衰退**

| 产品 | 累计 | 近 30 天真实流水 |
|---|---|---|
| ShipFast（$199 Next.js 代码样板） | $127 万 | **$1,694** |
| God of Prompt（Prompt 模板） | $55.8 万 | MRR 也在掉，**已挂牌出售** |

> 「如果只看历史总榜去抄一个买断制老模板，**你一进场就是夕阳期**。」

**真相 2：当下持续赚钱的，都在走「订阅制 + 给 AI 工具直接用」**

| 产品 | 近 30 天收入 | MRR |
|---|---|---|
| Sleek（AI 生成 App 界面） | $16,684 | $19,110 |
| TypeUI（给 AI 编程工具喂设计风格和组件） | $3,429 | $3,519（在增长） |
| **Skillry** | **$12,037** | $3,918 |

**真相 3：越聚焦具体场景的结果交付，付费转化率越高**

> TypeUI 偏底层通用 UI 组件与图标，近 30 天收入 $3,429；Skillry 直接聚焦「**有审美的完整网页、演示文稿与宣传片动效**」这类拿来就能交付的成品，近 30 天收入 $12,037——**超过前者的 3.5 倍**。

还有一个极端例子：**Low Content AI**（专卖亚马逊 KDP 低内容图书模板）几乎不做泛流量 SEO，单靠切准亚马逊卖家这一类刚需人群做垂直订阅，**近 30 天收入 $14,900**（累计 $64.6 万）。

> 「在写代码之前把这些数字看明白，你就知道自己的产品该定什么价、该卖订阅还是买断、该切哪类痛点才最容易收到钱。」

## 四、第二件事：再想明白怎么营销

> 「如果产品明天上线，我的第一批付费客户去哪找？**最稳的办法从来不是自己闷头瞎猜，而是去拆那几个正在赚钱的同行**，看它们的客户到底是从哪来的，看我自己能不能抄作业。」

### 拆 Sleek 的三个点

Sleek：累计收入 $18.4 万、近 30 天收入 $16,684。

**① 看它的免费自然流量是怎么搞来的**

Google 自然搜索占全站流量的 **39.8%**。但最聪明的不是硬磕高难度大词，而是做了一个**「免费绿幕去除小工具（Green Screen Remover）」**——

> 「单这一个解决相邻小痛点的免费工具页，就吃下了它**美区自然搜索流量的 55.5%**，源源不断地把潜在用户导进核心产品里。」

**② 看它的第一批种子用户是怎么冷启动的**

典型的「创始人单骑闯关 + 外部创作者多点开花」：

- 联合创始人 Mattia 在 X 上发了一条**只有 23 秒的实机演示视频**——直接展示输入想法后不到 2 分钟生成多张统一风格移动页面、并可导出到 Figma 或代码，文末留一句「评论 sleek 领内测」喂饱算法；
- **就这一条视频，打出 89 万浏览、2,871 条评论**；
- 第二天顺势放开免绑卡公测，**零广告费冲破 $10k MRR**；
- 紧接着联动 @StarterStoryBuild 实操视频（24.5 万播放）与多语种创作者接力放大。

**③ 变成自己的行动清单**

- 能不能也拍一条 25 秒以内的「输入想法 → 导出成品」无剪辑实机录屏来做首发冷启动？
- 能不能在主站 `/tools/` 下做几个纯前端免费小工具去吃自然搜索流量？
- 能不能把核心能力封装成开源 Agent 技能包去各个技能市场导流？

## 五、最后一步：决定做不做，再去 Vibe Coding

每次有新点子，走完上面两步后，用三个问题做最终判定：

- [ ] **底层商业模式被验证过吗？**——同行最近 30 天是真的在赚钱，还是两年前赚过钱、现在一个月不到 $2,000？
- [ ] **定价与转化逻辑算得过来吗？**——是做一锤子买卖，还是能像 Sleek、Skillry、Low Content AI 那样做成高复购订阅？
- [ ] **它的核心获客动作，我明天上线能直接复制吗？**

> 「如果这 3 个问题全都能答上来，我才会打开 Claude Code / Codex 开始 Vibe Coding。而且因为前两步已经想透了，写第一行代码的时候，**连首页怎么写、定价定多少、第一条宣传视频拍什么都已经胸有成竹**。」
>
> 「如果答不上来，**哪怕代码 1 天就能写完，我也会直接放弃**——因为省下的是后面几个月的营销获客时间。」
