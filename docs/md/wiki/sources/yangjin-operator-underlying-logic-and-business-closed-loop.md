# 杨进（@shaozhu93314）：构建操盘手的底层逻辑「全文手打、放心食用」

> 资深操盘手的商业推演全景长文：从流量结构、用户心智、交付模型到资本效率，剖析做项目与做生意的根本分野；指出普通创业者如何突破执行层面的盲目勤奋，建立全局视角的因果闭环与杠杆意识。

IP 打造系列三篇文章已经收获了大家 3k➕收藏，今天跟大家分享另一条自媒体创业道路。它不吃背景、不吃钱、不吃表达力、不吃长相，很少吃运气、资源，拼的就是认知、执行力、人品。而且比做个人 IP 拿到结果更快，更稳。我对我讲的话负责。

导读：操盘手不是替老板拍几条视频的人。你真正要做的，是判断一门生意值不值得放大，用内容撬开增量，再用组织和利益分配把成果留下来。选错 IP，拍得越好，死得越快。这篇先讲最影响生死的选品：选什么老板、什么行业、什么合作方式，以及为什么只做代运营很难守住成果。内容和组织，后续再拆。

## 什么是自媒体操盘手？

在自媒体平台创业只围绕三件事展开，「选品、内容、组织」这里面包括的要素，几十甚至上百个。能精准地调控这些要素的人，就是自媒体操盘手。接下来我会围绕着这三点贯穿全文和后面更新的「自媒体操盘手系列」。

## 为什么要做自媒体操盘手？

年轻人翻身最高效的一条路是通过学习、使用最先进的工具去服务当下最有钱的人。去进入他们的圈子、得到一手的信息、资源、认知，研究他们是做什么业务赚的钱、研究他们业务赚钱背后的模型和模型包含的要素。然后去和他们一起赚钱。当年抖音如此、当下 AI 亦如此。

做任何生意都要尽可能避免做 0-1 的生意。要想尽办法搭便车。这个就相当于你想要一年挣 100 万，两条路：

1. 从 0 挣到 100 万，选择这条路的人就去选择做个人 IP。
2. 你帮助一个一年挣 1000 万的人，然后让他分你 10%；帮助一个一年挣一个亿的人，让他分你 1%。但是为什么挣 1000 万的人会分给你 10%？一句话回答：「做事的结果是钱，钱的结果是人情世故。做流量的结果是钱，钱的结果是人情世故。」选择这条路的人成为自媒体操盘手。
3. 没有第三条路了。

比学历，我是没有学位证的民办三本。

比路人缘，我是一眼过去就是人精脸。

比钱，说实话没有什么能拿出来装的了。

比性格、表现力，我是极度平和，没办法调动别人情绪。

       我发誓我经历过大概五年左右资产过千万的阶段了，现在还在还债 ing。说实话当时除了海鲜随便吃，烟抽贵一点没啥特别的地方。我原来以为自己是盘菜现在，如今明白了自己其实就是一坨屎。我已经认识到自己的平庸了，没必要在平庸的自己身上浪费时间了。就是「自媒体操盘手」这个职业让我对世界有了深刻的感悟、认识到了很多行业的大咖，可以养自己的家人和身边的兄弟们。我将毫无保留地陆续分享给大家我的经验、教训。

自媒体创业说到底只有三件事：选品、内容、组织。把复杂的事情简单化，越简单越高效。

## 选品

那做自媒体操盘手选品，先不说产品，只谈选 IP 。你选的这个 IP 几乎就决定了你 50%的生死。如果你这个 IP 在市场上足够具有定价权，具有差异化，具有护城河，那前端流量是一定非常好做的。比如马云出来做 IP，那任何一个团队都可以给他做爆。

选 IP 不是看你的 IP 有多强，是看你竞争对手、你的同行 IP 有多强。举个例子，三月份短期火过一个概念，叫文科生学 AI，然后拿这个身份去卖课，兄弟，这不扯吗？那我是愿意听一个文科生给我讲 AI，还是我愿意听一个腾讯 T11 给我讲？还是一个计算机博士给我讲？一样的价格，他不打死文科生吗。就算你以一个低的身份去进场，完全做不大。比如文科生的这个 AI 课卖 199，那这个博士 AI 课直接把你的利润品变成引流品，也 199，我进去打死你。再比如说，K12 教育，你这个老师是一本，那我的老师就是清北博士，那我就是比你能打。做医美，你这个医生又老又丑，我这个医生又年轻又帅，说话又好听，技术又好，学历又高。说到底是孙子兵法里的道天地将法。

不要陪男孩长大，多陪王总说说话。没见过钱、没挣过钱的人会有无数个你做梦都想不到的问题出现。如果这种没见过钱的人暴富了，因为自媒体它就是一个暴富的阶段，他们起来的第一件事儿就是要踹掉你，没有别的事。他们没有任何生意人的体面。

一定不要做小白的生意，不要面对小白。他们是真会为了几千块钱去跟你拼命。比如所有爆雷的知识付费，几乎都是碰了穷人的钱，碰了小白的钱。我们要做的就是老板的生意。因为老板他只要能走到今天，他的商业认知是不可能出现太大问题的。根本不存在什么土老板，现在活下来的老板都是人精中的人精。而且做生意的人非常在乎体面，就算最后项目没成功，大家也都秉承着买卖不成仁义在，没有人愿意去鱼死网破，谁都不是傻子。而且你只要做成了，老板之间是有圈子的，大家都会互相推资源，互相推客户。而且你做老板群体非常有看点，比如我拍马云的一天好不好？那闭着眼睛都出素材。

在自媒体创作三要素「产品、内容、组织」里，一个老板可以搞定产品、组织，那我们专注搞内容就好了。你可能见过五花八门的混乱分成，包括什么？CPS、CPA、CPS+CPA。但是你最终的归宿一定是你专注做好内容，烂的公司是什么钱都想挣。不能说到最后还需要帮他去调整他的产品结构，还要帮他去调整这个组织架构。

他会不会分钱，你可以去看他有没有控股的公司。那你必须要明白他们公司对应的组织架构。甚至你还要对他进行贿赂，还要给他返点。跟他竞争对手坐在一个桌子上喝茶，去他的圈子里打听。

一定要盯着存量市场去做增量。这里的存量市场指的是没有做「主动获客」的行业。比如说现在餐饮几乎每家餐饮老板现在都在做自媒体推广，那餐饮就不是一个好赛道。同样比如说做医生的操盘手，如果医生不通过线上渠道去做，他有其他渠道吗？没有吧。他每天就只能坐在诊室里边儿，等着患者上门儿。你就算给他拍出屎一样的流量，他也是在做增量。这种出效果就非常容易。

## 那如何让 IP 离不开操盘手？

这应该是每个操盘手最头疼的问题。这个时候还是自媒体创业三要素：「产品、内容、组织架构」。

首先，代运营就是一个屎一样的商业模式。兄弟停下来想一想，谁做拍拍剪剪的代运营发家了？我想问有人是做代运营赚到大钱了吗？反正我这四年里是没见到过。

代运营赚的是什么钱？

赚的是老板的学习成本、时间成本和人力成本。IP 本身如果想要做一个自媒体团队，一个老板他需要至少招一个拍摄、两个剪辑。这个工资就每个月都要两万，而且他还不能享受当甲方的那种爽感，还要倒逼他自己直面结果。因为他没做起来，那就是没做起来。但是他找个代运营，他可以甩锅。

当操盘手给 IP 做好内容这个板块以后，你就要去从剩下的两个方面「组织、产品」去发力。这里有个容易混淆的点：IP 需要三要素，操盘手团队一样需要三要素，这并不冲突。

市面上大部分代运营和操盘手团队走的是两条路，代运营团队最多就是一个内容剪辑，在自媒体创业三要素中只能解决「内容」问题。操盘手是要负责全案策划，解决三个要素。所以不是代运营想割韭菜，他只能在内容端发力。而且好的代运营团队，他绝对去干操盘手团队了，好的代运营团队也不会缺项目，也就不会外流了。

如果 IP 要脱离你，那他就要自己去搞定组织。如果说我就是一个医生，我上哪会懂组织架构？我就是个厨房炒菜的，我上哪懂组织架构？对不对。流量的终局是组织架构。这篇文章侧重讲选 IP，不过多阐述了。

深入去挖掘，从组织的这个角度出发，如果一个操盘手团队你同时去做 10 个各行各业的老板，假如说一个餐饮、一个母婴、一个医美、一个国学，你把这些员工召集到一起，你怎么开会啊？他每个用户的客群心理完全不一样，你怎么去剖析这个事儿？怎么针对性解决呀？解决不了啊兄弟。阿米巴模式可不是普通人能走的。

有的行业 IP 注定时间不宽裕，他们没办法 all in 线上。这种行业 IP 就不要走操盘手模式就做做代运营挺好的，然后通过赛马沉淀出一个值得 all in 的 IP 。只能通过矩阵操作先让整个团队忙起来，运转起来。

管理操盘手和 IP 的关系就是实打实的利益，可以双方共同成立一家公司，把私域放在那家公司上。私域把控在操盘手团队里。针对的是复购的一个问题。比如做医美医生 IP，咱们第一个月操盘手和 IP，我们共同积累了 1000 私域医美客户，你只要继续跟我合作，那未来每个月的复购足够医生。我们可以一起积累达到复利。但你如果跟我合作终止，医生丧失的就是未来的所有复购。我拿着这些私域的客户，我再接一个医生，我同样可以继续做这个，其实就完成了一个关系的转变，操盘手团队是 IP 的甲方。适用于各个行业，只要这个行业有复购，这个模式就可以走通。

给 IP 钱，或者收 IP 高前置费用。这个能解决你 99%的问题。只要你做过，你会发现在拍摄的过程中去引导 IP 的情绪，这是一个非常难的事情。而且，你还会遇到 IP 各种各样的奇葩问题。比如你今天拍摄团队过去，他有时候接孩子，有时候心情不好，那他一拖你就拖个没完了。但是，你这边公司还要正常去运转，员工的工资还要正常去发，不能因为他一个人的素材产出就影响整个项目。如果说你成为他的甲方，这些问题几乎都不存在。而且，后端分成你照样可以拿得多，私域一样可以把控在你的后端。你可以把它理解为一个投资，你一个技术入股去分走 10%。

说到底，把所有经验、知识这些全部内化。在选品的时候，什么是好产品？好用，好卖，好守，超预期。那选 IP 的时候就问 IP 一句话，你赚钱吗？你有多赚钱？我帮你翻十倍，分我 30%。

自媒体说到底是一个工具，他能把一块黄金扩大十倍，变成 10 块黄金。但是一坨屎扩大十倍它是十坨屎。收起圣母心，你没办法用工具把屎变成金子，跟屎在一起玩，只会招来一身臭味。保持狩猎状态，持续找到金子，持续扩大金子。AI 亦是如此。

        保持愚蠢，保持好奇。独立思考，穿透噪音。踏实做事，本分做人
