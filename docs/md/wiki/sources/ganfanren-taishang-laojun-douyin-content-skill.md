# 饭饭猛猛炫（@ganfanren_ai）：太上老君·AI 炼丹炉——去 AI 味、改爆款口播的自媒体内容 Skill

> 基于抖音头部创作者「柳爷不迷糊」内容方法论提炼的开源 Agent Skill：通过对话生成使用者档案定位、拆解对标机制、系列选题、生成带画面指令口播稿，提供去 AI 味与漏斗归因诊断，破除模板化假大空套话。

<!-- more -->

不知道拍啥、写出来的稿子一股 AI 味的，可以试试这个免费 Skill：太上老君·AI 炼丹炉。

README 写，它用的是抖音创作者「柳爷不迷糊」平时做内容的思路：先下判断，落到今天就能拍的一件事，不出换谁都能用的泛货。

它能帮你做：

· 先聊几轮，整理出一份《使用者档案》：你是谁、想吸引谁，以后贴进来不用重聊

· 拆对标爆款：它为什么爆，哪个机制到你手里还成立

· 选题、系列策划

· 写能直接念的口播稿，带画面提示

· 只改开头、标题或某一段

· 发完数据不对，沿链条找出第一个偏掉的环节

· 去 AI 味

README 里的例子：一段「营养丰富、承载乡愁」的卖土鸡蛋 AI 文案，改完变成「蹲在鸡窝边、手里拿着刚捡的蛋」开口，第一句直接说出观众心里的怀疑「网上卖土鸡蛋的那么多，哪来那么多真土鸡」，再用捡蛋画面接住；没测过的「营养丰富」直接删掉。

哪类账号直接用哪一步：

· 新号没方向：先跟它聊出使用者档案，定位清楚再拍

· 已经有稿的：只让它改第一句和标题

· 发了没量的：让它按选题、开头、内容一步步排查

· 卖货、本地店、替老板做号的：拿自己的真实场景让它改，越具体越好

安装：

npx -y skills add liuhaisi2026212-maker/taishang-laojun -g --all

支持 Claude Code、Codex、Cursor；用豆包这类聊天机器人，可以下载仓库里的 Bot 提示词版。
