# KKKK（@kkkeric_ai）：SEO 收益最高的地方，是你已经排名的那些页面

> 老站 SEO 提效的核心判断：Google 已认可的页面补内容，收益远高于从零起盘。操作路径：GSC 按点击与展示排序找出 3-5 个有排名的页面 → 用 API 把近 3 个月 GSC 数据喂给 Agent（如 Claude）→ 筛两类词（有展示但正文完全没提到的查询词；排在第 10-30 名即第 2、3 页的词，后类最值钱因为 Google 已认定相关只是页面差一点）→ 让 Agent 参考优质竞品指出每个词该补在何处（重写开头、新增 H2、新增段落、FAQ 或改一句话），只改需要改的不整篇重写。文末给出四个具体检查项：开头前两段直接回答核心问题、主关键词须出现在标题与 meta description 与第一段、补充 AI 写不出的东西（自己的截图表格数据判断，AI 不能代写后台截图）、页面之间做 3-5 条读者真会点的内链。

<!-- more -->

SEO 收益最高的地方，其实是你已经有排名的那些页面。

Google 已经认可它们了，只是内容还不够完整。把这部分补上，收益会比从零开始快得多。

一些做法如下：

1. 在 GSC 里按点击和展示次数排序，找到有排名的 3-5 个页面。

把数据交给 AI Agent，比如 claude 等等

最近 3 个月的 GSC 数据，直接用 api 喂给自己的 agent

找两类词

一类是有展示、但文章里完全没提到的查询词。

另一类是排在第 10–30 名的词，也就是第 2、3 页。

后面这类最值钱。Google 已经觉得你相关，只是页面还差一点。

然后让 Agent 参考你做的比较好的竞对，告诉你每个词和每个页面该补在哪：

重写开头、新的 H2、新的段落、FAQ，还是改一句话。

只改需要改的，不要整篇重写。

2. 几个具体需要检查的文职

（1）开头

前两段直接回答核心问题。读者几秒钟就决定要不要看下去，Google 也一样。

（2）检查关键词位置

主关键词要出现在标题、meta description 和第一段。这个很基础，但很多页面都会漏掉一处。

（3）加 AI 写不出来的东西

自己的截图、表格、数据、判断，还有排名前几的页面都没写到的角度。

这一步不要让 AI 代写。AI 可以帮你找缺口，但没法截你后台的图。

AI 一定是用来做辅助的，不能全部 AI 化

（4）这几个页面之间做内链

只放读者真的会点的链接，每篇 3–5 条就够了。

（5）重新提交索引

在 GSC 里对改过的页面请求编入索引。等 7–14 天，再拉一次数据，看哪些词上来了，然后接着补。

这个循环跑上 1–3 个月，SEO 效益会比新上页面更好。
