# 50元搭建一家属于自己的中转站，并且拥有国内外主流模型

> 用域名 + 海外服务器 + Sub2Api 中转站上游，50 元成本搭建私有 API 中转站，支持国内外主流模型。

<!-- more -->

## 一、准备工作：三样东西

### 1. 域名

- 腾讯云微信小程序可购买
- 自用选便宜即可（几块钱）
- 推广用途建议选好记的（.com / .cc / .cn，二三十块钱）

### 2. 服务器

- 建议购买国外服务器
- 初始配置：1 核 2G（十几块钱/月）
- 用户多了再升级

### 3. 中转站上游

- 需要注册一个 API 中转站账号作为上游
- 获取 API Key 和 API 端点

## 二、部署流程

### 让 AI 帮忙部署

1. 打开 GPT Codex（需 Plus/Pro 会员）
2. 在对话框里提供：
   - 购买的域名
   - 服务器信息
   - 指令："帮我把 Sub2Api 部署到我的服务器里并且绑定到我发你的域名"
3. 按 Codex 的需求提供所需信息
4. 全程指挥 Codex 执行，等待部署完成
5. 打开域名验证中转站是否上线
6. 登录管理员账号进入后台

**Sub2Api 项目地址**：`github.com/Wei-Shaw/sub2a...`（原文截断）

## 三、对接模型

### 创建 API Key

1. 在上游中转站 → API Key 首页 → 创建密钥
2. 获取：API 密码 + API 端点

### 创建分组

1. 中转站后台 → 分组管理 → 创建分组
2. 设置：名称、描述、平台（OpenAI）、费率倍数
3. 点击创建

### 添加账号

1. 账号管理 → 添加账号
2. 设置：
   - 名称
   - 平台：OpenAI
   - 账号类型：API Key
   - BaseURL：上游 API 端点
   - API Key：上游 API 密钥
   - 同步最新支持模型
   - 分组：选择刚创建的分组
3. 点击创建

## 四、测试与定价

### 测试连接

1. 账号管理 → 更多 → 测试链接
2. 选择 5.6Sol 模型
3. 点击开始测试
4. 正常返回绿色对话 = 对接成功

### 设置渠道定价

1. 渠道管理 → 渠道定价 → 创建渠道
2. 设置：名称、OpenAI 平台
3. 添加模型定价
4. 根据上游价格表逐一填写
5. 也可让 AI 根据价格表自动填写，但需人工核对

## 五、收尾

1. 给中转站加头像、名称
2. 测试扣费一致性
3. 调整到满意后推广使用

## 核心成本

| 项目 | 价格 |
|------|------|
| 域名 | 几元 - 三十几元 |
| 服务器（1核2G） | 十几元/月 |
| 上游 API Key | 按用量计费 |
| **总计（首月）** | **约 50 元** |
