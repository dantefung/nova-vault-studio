# 我想不通，原来真的会有人讨厌挣钱…

今天遇到一个我觉得很荒谬的事情



我刷小红书，刷到了一个网球+旅行的产品，我觉得我感兴趣，而且价格也挺便宜，于是顺理成章的加了他们的微信



加上微信以后都是非常正常的问询



他说满了，我就忘记了这件事，直到昨天晚上又刷到



于是想着咨询一下近期还有没有合适的产品，点进这位的头像发现对方的朋友圈已经不可见了，我就有了不好的预感



一发消息，果然，把我删了



删了我觉得也很正常，毕竟我自己也有定期清理非付费用户的习惯，而且产品我确实很感兴趣，所以想着再加一遍聊一聊



于是出现了下面让我觉得啼笑皆非的一幕：



看到的一瞬间，我突然觉得很冲击



为什么会有做生意的人，这么不尊重，这么不珍惜高意向客户？



我不太理解这位对微商的定义是什么，如果是做私域就等于做微商，那我可以是，我不觉得一个称呼的区分有多么耻辱



我平时的意向客户有很多女生会是微商，无论是找我代写还是想要跟我做副业，我是非常乐意见到客户是微商的



因为根据我长期的观察，微商＝有付费意识+付费能力强+爽快，从初高中就开始做小生意的女生，大概率是很有钱的



而且大部分做微商的女生确实很会提供情绪价值，所以一般也会好沟通一些



如果我要因为有色眼镜和偏见直接一棒子打死这个群体，我得少挣多少钱啊



更何况旅游这样的低毛利行业，我根据他们产品数测算了一遍，想要超过月利润十万是很难的，一个小企业或者小工作室，哪里来的资格对用户如此的傲慢？



归根结底，甚至我们做的事情都是一样的



他在小红书上引流，在私域成交，然后交付产品，我们的路径是完全一致的



一个依托微信作为成交场域的人，却认为别的靠微信做成交的人低人一等，是什么道理？



说到底，就是跟钱过不去



他的私域塑造的非常非常普通，全是大字海报+照片



如果是我自己去做这个产品的话，在基建上，我会从几个角度去做



1.视频号发实拍混剪/vlog



2.主理人出境讲自己设计产品和做交付的理念



3.朋友圈分为几个板块去发：



①交付细节+剧情：我是怎么去设计产品的，怎么去选址的，和用户的沟通是怎样的，用户出发前我是怎么提醒他做好准备的



②客户反馈聊天记录，客户旅行完以后的真实反馈



③穿插一些关于网球的学习思路和干货分享



在销转上，我会这样去做



首先一个人张口只问产品不问价格已经注定了这个用户是非价格敏感性用户，属于典型的优质用户，一定要拉留存



“你自己关注小红书”属于典型的大忌，我都已经进你私域了，我还要跑去盯着你的公域吗？



这个时候，哪怕你不确定下一期什么时候，也可以推送一个公众号名片：



小姐姐，我们平时组织新的活动会在朋友圈通知，如果你怕错过的话可以先关注一下公众号，有推送可能会及时一些



其次，这种地域限制的，我会给他打好标签，比如他就是只能接受江浙沪周边出行，就打好江浙沪，然后如果有活动会推送问询



哪怕是这一期满了，没有名额了，我也要让他多关注我的一些多的微信生态内的账号，例如视频号/公众号/微信群等，提高触达率



私域的触达率是公域的n倍，做好私域+社群，哪怕公域流量完全不做都这个生意都可以做很久



这一次没成交，我也可以吃到这个用户的成长红利或者终身价值



当然，也可能这位同学真的没有挣钱的打算吧

## 补充：考核与分钱问题

问题其实不是员工的，是考核体系的。逆向思维一下，是什么让老板能容忍这么差的私域销售？那大概是他不在乎转化。何以不在乎？只能是交付能力有限。固定时间内，消化不了太多流量，一期满员了就不关心后续了。私域销售拿不到更多提成，自然不珍惜眼前客户，以为是水龙头里的自来水拧开就有。所以根源上，这其实是考核与分钱的问题。
