# 图解：计算机中的数据表示与存储系统

## 一、计算机如何认识现实世界

计算机不认识字母、颜色和声音，真正识别的是电路中的高低电平、开关状态。工程师把一种状态记作0，另一种记作1。

**信息转换流程**：现实信息 → 数字编码 → 二进制数据 → 存储设备

## 二、十进制基础

### 2.1 什么是十进制

十进制使用0-9十个数字，规则：**逢十进一**。

### 2.2 十进制加法

例如 8 + 7 = 15，个位写5，向十位进一。加法进位的本质是当前位装不下了。

### 2.3 十进制减法

例如 52 - 27，个位不够减，向十位借一。高位借来的单位在个位上相当于10。

### 2.4 位权计数法

数字325 = 3×10² + 2×10¹ + 5×10⁰，同一数字在不同位置表示大小不同，每个位置对应的权重叫**位权**。

## 三、二进制基础

### 3.1 二进制基本概念

二进制只使用0和1两个数字，规则：**逢二进一**。1 + 1 = 10（这里的10等于十进制的2）。

### 3.2 二进制的位权

二进制数1011 = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 11（十进制）

### 3.3 二进制的长度

- **1 Byte（字节）** = 8 bits，能表示 0-255（2⁸）
- **1 KB** = 1024 Bytes ≈ 1千字节
- **1 MB** = 1024 KB ≈ 1百万字节
- **1 GB** = 1024 MB ≈ 10亿字节
- **1 TB** = 1024 GB

## 四、常见存储单位

| 单位 | 全称 | 大小 |
|------|------|------|
| Bit | 比特 | 0或1 |
| Byte | 字节 | 8 bits |
| KB | Kilobyte | 1024 Bytes |
| MB | Megabyte | 1024 KB |
| GB | Gigabyte | 1024 MB |
| TB | Terabyte | 1024 GB |

## 五、有符号数与无符号数

### 原码

最高位作为符号位（0正1负），其余位表示数值。例如 +5 和 -5：

- +5 原码：00000101
- -5 原码：10000101

**问题**：0 有两种表示（00000000 和 10000000），且加减运算复杂。

### 反码

- 正数的反码与原码相同
- 负数的反码：符号位不动，其余位取反

### 补码（计算机实际存储方式）

- 正数的补码与原码相同
- 负数的补码：反码 + 1

补码优势：0 只有一种表示，且加减法可以统一处理。

## 六、浮点数表示（IEEE 754标准）

浮点数 = 符号位 + 指数部分 + 尾数部分

**单精度（32位）**：1位符号 + 8位指数 + 23位尾数

**双精度（64位）**：1位符号 + 11位指数 + 52位尾数

## 七、字符编码

### ASCII码

用7位（后扩展为8位）表示128个字符，包括大小写字母、数字、标点符号和控制字符。

### Unicode

为解决全球字符统一问题而设计，UTF-8是其最流行的实现方式：

- 英文字符：1字节（与ASCII兼容）
- 中文字符：3字节
- 表情符号：4字节

## 八、数据存储层次

从快到慢、从贵到便宜：

1. **寄存器**：CPU内部，最快最贵
2. **Cache（缓存）**：SRAM，CPU与内存之间
3. **内存（RAM）**：DRAM，主内存
4. **SSD**：固态硬盘
5. **HDD**：机械硬盘
6. **网络存储**：最慢最便宜

## 九、大小端模式

- **大端模式（Big Endian）**：高字节存低位地址（数据高位存在低地址）
- **小端模式（Little Endian）**：低字节存低位地址（数据低位存在低地址）

x86架构采用小端模式，网络传输采用大端模式。

## 十、数据的计量单位

- **Bit（比特）**：最小单位，0或1
- **Byte（字节）**：通常为8 bits
- **Word（字）**：计算机一次处理的数据单位（32位/64位系统）
