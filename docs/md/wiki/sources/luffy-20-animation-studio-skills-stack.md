# 路飞（@0xluffy_eth）：20 个 Skill 搭一整套动效工作室——动画、模拟、3D、音频与导出全流程

> 盘点由 20 个顶级开源工具与 Agent Skills 构成的端到端 AI 动效工作室：从 Remotion 视频生成与 Motion UI 过渡，到 Blender MCP、Three.js、Jolt 物理引擎与 postprocessing 后期，再到 ComfyUI、CosyVoice 配音、librosa 节奏对齐、WhisperX 字幕及 FFmpeg 导出。

太牛逼了，20 个 skill 搭一整套动效工作室。

直接把全文复制给 Opus 5.5 就能用：

动画、模拟、3D、音频、导出全都有。

01 Remotion → 用 React 做视频

https://github.com/remotion-dev/remotion

02 Remotion Skills → 官方给智能体用的视频 skill

https://github.com/remotion-dev/skills

03 Anime.js → 用时间线编排动作

https://github.com/juliangarnier/anime

04 Motion → UI 动画和布局过渡

https://github.com/motiondivision/motion

05 Manim → 图表、公式和动画讲解

https://github.com/ManimCommunity/manim

06 Lottie → 体积很小的矢量动画

https://github.com/airbnb/lottie-web

07 MCP for Blender → 让 Claude 帮你搭和改 3D 场景

https://github.com/ahujasid/mcp-for-blender

08 Three.js → 3D 场景和镜头运动

https://github.com/mrdoob/three.js

09 Three GPU Pathtracer → 真实的光照和反射

https://github.com/gkjohnson/three-gpu-pathtracer

10 Jolt Physics → 碰撞、刚体和软体

https://github.com/jrouwe/JoltPhysics

11 postprocessing → 泛光、景深和调色

https://github.com/pmndrs/postprocessing

12 Three.quarks → 粒子和特效

https://github.com/Alchemist0823/three.quarks

13 Tweakpane → 实时调场景参数

https://github.com/cocopon/tweakpane

14 ComfyUI → 节点式生成工作流

https://github.com/Comfy-Org/ComfyUI

15 CosyVoice → 多语种旁白配音

https://github.com/QwenAudio/CosyVoice

16 librosa → 抓节拍，让画面跟着音乐动

https://github.com/librosa/librosa

17 WhisperX → 逐词对齐时间轴的字幕

https://github.com/m-bain/whisperX

18 OBS Studio → 录屏

https://github.com/obsproject/obs-studio

19 LosslessCut → 不重新编码的快速剪辑

https://github.com/mifi/lossless-cut

20 FFmpeg → 编码和最终导出

https://github.com/FFmpeg/FFmpeg

想法 → 场景 → 运动 → 声音 → 成片。
