# 杨进（@shaozhu93314）：构建 IP 系统的底层架构（全文手打、放心食用）

> 作者 23 年末至今高频迭代沉淀的 MCN 内培级 IP 方法论全文：贯穿三句核心——**IP 的本质是连接产品与用户的渠道、IP 最核心的作用只有一个（背书）、IP 需要做的只有一件事（讲好故事，把产品内容化）**；指出商业只有「产品卖点 × 渠道 × 用户需求」三个变量，排除用户需求后发力点只剩产品与渠道，并给出「有产品没流量 / 有流量没产品」两种起局情形的倒推顺序与跨行业对标方法。

<!-- more -->

本文是我个人 23 年末到现在高强度高频次迭代出的 IP 底层架构，适用于各个行业。本是给 MCN 内容团队进行内培使用。全文贯穿三点 IP 的本质是连接产品与用户的渠道；IP 最核心或者武断地讲有且只有一个作用——背书；ip 需要做的只有一件事 --讲好故事， 把产品内容化.

       自媒体时代 有且仅有三个变量 产品卖点、渠道 、用户需求，或者说从商业诞生之日就是这三个变量，用户需求亘古不变，“小孩怕笨、女人怕丑、男人怕穷、老人怕死”，具体细分不再过多枚举。 排除这个要素我们发力方向就只剩下产品卖点和渠道，从传统的线下门店到淘系图片电商到现在自媒体时代内容电商，反复进行迭代的只有两点无限缩短产品与用户间的成交距离，提升转化效率，IP 的存在是极大程度提高这两点优势的最终产物

1 不以个人能力模型做账号 以个人能力模型做账号会面临内容瓶颈、没有突出点因为人外有人、算法不确定 规则一直在变...

         ip 的本质是渠道 比如你是一个数学老师 ，你的产品也就是你的课程 是基于你多年沉淀下来的数学经验决定的。 那顺此逻辑 ，你出完数学课程下一个品是什么？ 不会是出一个语文课吧？ 那数学东西就那么多 ，出完就出完了。 总不能把已经上线过的课程再重新讲一遍吧！受众群体就那么多，该买的都买过了。想要更多客户只有两种办法--投流，扣话术。这两件事注定是边际效用递减。破解的方法就是在做 IP 时提炼出如何最大发挥渠道作用更好匹配产品与客户，围绕 IP 本身进行产品打造例如知识付费头部胡说老王，围绕其开发出各种生活日用品让他进行带货。卖课本质就是卖空气，空气都能卖出去，什么你不出去。

2 创作者开始一般会面临两种情况———有产品没流量，有流量没产品。

- 有产品没流量 。以产品为始点，围绕产品进行 ip 身份的匹配，倒推流量创作形式，顺序不能发生改变！你要充分意识到每条作品匹配的是你产品哪个卖点，对标同行和跨行业对标，弄清楚你的作品到底在和谁讲话，渠道类似于黑洞，要汲取百家之长。
- 有流量没产品。不必过度分析内容所吸引的人群画像，人群画像是个很虚的概念，分析人群画像约等于挖掘人群需求，可是前面提到过需求亘古不变，你只需做到拿一批具有差异化产品疯狂对受众进行测试，可以是茶叶、是白酒、是私密护理，是减肥这批不行再换一批…. 标签不是自己给自己的，永远不可能是想出来、讨论出来的，自己给自己的叫立牌坊，行业是测出来的，就和谷爱凌在成为滑雪 top1 之前他的母亲已经开始她大量报兴趣班，滑雪是测出来的最优解。

3. 精准流量和泛流量 是最大的骗局。我们可以很好的麻痹自己， 给自己一个我上我也行，世界是个草台班子的幻觉。做精准流量没大流量会说我做泛流量我也行，做泛流量没客资会说我做精准流量我也行。走到最后会发现做泛流量的不能变现，做精准流量的客户池子就那么大。解决方法说掏心窝子话，有解但很难。这是个人成长环境、经历、心理的综合结果，其暴露的本质问题是个人素材创造能力不足，将观众从路转粉的能力不足。遇到问题直面解决，但不要麻痹自己，更不要对别人抱有偏见。更不要用投流麻痹自己。付费流量和内容流量本质都是在付费 前者是直接打钱后者是优质素材但需投入大量的时间成本，付费的目的是磨平素材创造能力带来的内容鸿沟。

     人若无名专心练剑 自媒体是最快速让人知道自己是个傻 x 也是普通人最快速了解商业运行底层逻辑和顶层法则的途径。算法一变 就像 geo 一样 你所谓的任何技术全部失效但底层逻辑和顶层法则 修炼自我是永远不会变的

       没有任何一个苦难可以难住人 。往后种种困难将来都成传奇。自媒体创作就像断崖式爬山， 没有渐进的问题。 因为大家都是刚刚做自媒体， 遇到的困难都是最小白的啊，中期就是直面自我怀疑自我，顶层还是财务法务税务。眼前的一切困难让你遇到是因为你可以解决，问题贯穿你的创作生涯，是因为底层结构出了问题，加油！勇往直前！

                              治愈自己 治愈大家
