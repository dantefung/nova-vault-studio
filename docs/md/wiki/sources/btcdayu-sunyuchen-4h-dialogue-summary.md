# 大宇（@BTCdayu）：4 小时对话孙宇晨精排全文——年轻人怎么抓时代机会

> 邵艾伦与孙宇晨 4 小时深度对话完整精排：关于 AI、Web3、精力分配与时代机遇的思考。核心判断：不要被宏大叙事吓住，专注高确定性赛道，利用杠杆放大生产力，个人成长取决于在关键分叉口做出非共识决策并坚持执行。

<!-- more -->

本文为邵艾伦对孙宇晨四小时采访的全文整理，依据原始逐字稿，合并同题问答，省去时间戳、重复表述和纯附和，适度梳理语序与段落，保留原有观点、案例和实质内容。

## 一、开场：AI 怎样进入日常生活

1. 邵艾伦： 如果重新回到 20 岁，没有人脉、没有资源，您会怎么开始？

孙宇晨： 我觉得不难。认知决定命运。今天能看到我们这个节目的听众就非常兴奋，赶紧点保存的。如果你的周围人给你发这个节目，你就是要千恩万谢，我跟你讲，就是每年过年都得去他家拜年，就是说太感谢你发给我这个视频了，这改变了我的人生啊。

2. 邵艾伦： 您开始练薄肌了吗？目前的身高、体重、体脂率和训练目标是什么？

孙宇晨： 已经开始一天了，我身高 172，目前大概 75 公斤左右，体脂 29，目标是三到六个月达到一定目标。

3. 邵艾伦： 您平时一天怎么过，工作之外最喜欢做什么？AI 如何记录饮食、训练和身体数据？

孙宇晨： 我讲讲这两天开始练习薄肌之后的生活吧。

起床之后先工作，然后开始吃第一餐。吃之前先把餐桌照片丢给 Claude，吃饱之后再丢一张吃完的照片，它会告诉我这一餐吃了多少卡路里，还会告诉我怎么吃，比如先吃哪道高蛋白的菜。此外，我现在还补充 25g 蛋白粉和 5g 肌酸。

吃完之后就训练。如果是训练日，就练硬拉、深蹲这几个主要动作；如果不是训练日，就正常工作。现在训练日和非训练日刚好隔天交叉一次。

工作完吃第二餐，就直接是晚餐了，晚上继续工作，最后睡觉。

工欲善其事必先利其器。我现在还使用 Oura Ring 抓取睡眠指标，也是直接丢给 Claude Code。Claude Code 会抓一下运动消耗的卡路里，再抓一下吃饭摄入的卡路里，二者相减，卡路里赤字 600 卡以内就说是燃烧脂肪。蛋白质现在定在每天 140 到 150 克，同时增肌减脂。Claude Code 负责全程跟踪。每个动作，旁边的教练都会帮我拍视频，再发给 Claude Code，记录每组 12 个、做 3 组、多少公斤。

我专门给 Claude Code 开了一个项目，它每天会整理出一份日报，汇报今天完成得怎么样，再结合 Oura Ring 读取的睡眠数据，让 AI 帮我跟踪、分析、督促。

4. 邵艾伦： 您看过我的薄肌教程吗？开始训练前做了哪些准备，对蛋白粉的认识有什么变化？

孙宇晨： 看过。我花了一周做理论准备，包括读你的薄肌教程、理解薄肌理论，先弄清楚是怎么回事，再准备 Oura Ring，购买蛋白粉和肌酸。

这也打破了我一个陈旧的观念：以前总觉得蛋白粉是不是‘科技’，喝了会不会像打药一样。后来才明白，蛋白粉就是补充蛋白质。平常的饮食很难吃到 140 克、150 克蛋白质，所以这 25 克蛋白粉是很好的补充。我们不是全靠蛋白粉，但补充一部分，可以减轻必须吃那么多食物的压力。

5. 邵艾伦： 听起来，您生活中的很多事情都交给了 AI。AI、教练和本地文档具体怎样配合？

孙宇晨： 现在全部 AI 化了。我的训练动作都拍了视频，AI 会评估做了多少组、练到哪些肌肉、动作是否规范、建议做多少，再给我反馈。教练也会盯着，和 AI 一起检查是否练到位，最后由 Claude Code 汇总成日报。

整套流程都是可视化、数据化、可总结的。记录整理成 MD 文档，照片也全部保存在本地文件夹里，AI 已经熟悉这套资料。下一个 AI 来，直接读这些文档就能接手。如果把 Claude Code 换成 Codex，README.md 和相关记录都在，不需要重新开始。

## 二、从零开始：方向、机会与决策

6. 邵艾伦： 如果回到 20 岁，没有资源，每月可支配收入也很有限，怎样低成本使用 AI？这包括健身、上课、日程安排等生活的各个方面吗？

孙宇晨： 不难。每个时代不一样，我觉得现在是最好的时代。先从每月可支配收入不超过 1000 块人民币说起，我以前在北大时也不超过这个数。可以先注册智谱或者 Kimi，它们都有类似 Claude Code 的工具。Claude Code 一个月就要 200 刀，如果你一个月总共只能花 100 刀，当然用不起，但可以装智谱、Kimi Code 或者开源的 Code，这些应该都有免费的办法可用。

我自己也做了 B.AI，结合了所有模型。总之，找个便宜的 AI 工具，把资料读进文档。如果连电脑都买不起，用手机也可以，建个文件夹把资料放进去。无论有多少钱，都可以先把自己的流程 AI 化。我们公司和产品现在也在推行全面 AI 化、AI 整合。

孙学以前讲过，先用理论武装自己。现在最重要的是 AI 化，它不亚于当年日本崛起时通过君主立宪走向现代化。以前日本要从封建国家走向资本主义国家；今天先 AI 化，是我们要做的第一步。

把 MD 文档输入好，也可以利用不同平台和 API 的免费活动：今天智谱免费，明天 Kimi 免费，就换着用。我现在钱不是最主要的阻碍，所以包给 Claude，求个稳定；如果一分钱都不想花，就看各家的活动，也可以把整套流程 AI 化。

零基础起步，接下来就是我总结的三个理论。第一个是孙学，用理论武装自己，相当于先给大脑、给操作系统做一次升级。

7. 邵艾伦： ‘孙学、薄肌、黄毛’分别解决什么问题？我的理解是认知、身体和心态的升级，即使被嘲笑、走的不是传统道路，也敢坚持自己的判断。为什么还要加上 AI 作为掌舵者？

孙宇晨： 孙学是先升级对金钱、财富自由乃至万事万物的理解。第二是薄肌，它不只是为了泡妞，归根到底是为了身体健康。身体不健康是一票否决，肥胖带来的问题会拖慢财富自由的进度，给生活添很多麻烦。当然，泡妞也重要，不然没有后代，后代也要保证质量，但健康才是薄肌最根本的目的。

第三是黄毛理论。在今天的中国或华人社会，孙学和薄肌还是小众理论。你开始践行，绝对会被打压、被嘲笑，觉得你格格不入；你又帅又有肌肉，100%会招来嫉妒。所以需要黄毛心智：别人说什么先别管，自己认定是对的，就充分执行。

这三套具备，就可以开始了。它们首先是认知升级，不需要花钱。我认为这是中国现在的版本答案，20 岁到 40 岁的年轻男性有 2 亿，算上女性，年轻男女有 4 亿，都可以用这套理论升级自己。

现在我们又加了一个最核心的掌舵者——AI。我是百分之百相信 AI 的。前段时间的小风波，也是因为我过于坚信 AI。有人说我甩锅给 Claude，其实不是，而是它说什么我就执行，无论有多大阻力都执行。Claude 只是一个代表，不用它也没问题，OpenAI 的 Aster、智谱 GLM 都可以。

8. 邵艾伦： 接受这些理念以后，怎样具体落地？从找方向、挣钱，到执行和调整，都可以借助 AI 吗？

孙宇晨： 先把这套方法执行起来。无论在地球哪个角落，无论是自由职业者还是公务员，只要通网、有手机，都可以零成本开始。我建议先做两件事：

第一， 把现状全部数字化。健康和其他数据不用着急，先积累两到四个月，连同自己的现状分析一起交给 AI，让它帮你判断。可以在 B.AI 问三个模型，用 API 按问题付费、切换模型，不必每个都单独包月。Claude、OpenAI Aster、智谱 GLM，中美顶尖模型都有。让它们分别给出建议，形成上中下三策，再从中选择。这是第一个思路：问 AI。

第二，随时关注人类科技发展的动向。孙学是 2016 年建立的，到现在 10 年，我自己就是践行者。2016 年我什么都不是，后来践行孙学，现在开始练薄肌。以前可能也是大肚腩，可以拍照比较六个月、一年的变化，用控制变量法看结果。

更重要的是，科技不断进步，新东西一直在出现，要有一套持续抓取信息的机制。可以让 AI 抓，也可以自己关注。我会看 X 上马斯克每天在做什么，自己抓信息，加上 AI 抓信息，再结合兴趣钻研一个方向。每个人都有擅长的领域，不可能样样都是专家。

决策还有一个 tuning 的过程，像训练大模型一样。例如根据 Oura Ring 每天推来的数据不断改进，把整套系统逐渐训出来。自己的判断也要参与，但我以 AI 为主：就像开飞机，90%的时间让 AI 开，我用 10%的时间调整它。

我也会和 AI 意见不同。比如我曾觉得蛋白粉是不是‘科技’，跟它交流后，它告诉我：健身领域确实有很多科技，但蛋白粉、肌酸是唯一不算科技的，就是普通食物。它把原理讲清楚，我的想法就翻过来了。自己的观念与 AI 冲突时，通过频繁交流，也能不断更新认知。

9. 邵艾伦： 所以，先建立这些基本思维，再结合个人情况，让 AI 帮忙找方向、不断调整？不会做 MD 文件、不会调用 API，也可以问 AI 怎么做？

孙宇晨： 是的。孙学、黄毛、薄肌很有参考性，每个人的情况未必都那么复杂。升级思想、升级身体、专注于个人发展，这三件事可以立刻做；其他事情，再结合自己的情况去问 AI。

孙学也在不断升级。我之前说‘不要在微信聊天，去跟豆包聊天’，现在又升级为‘用 API 跟全球的 AI 聊天’。文件全部保存在本地，通过 API 读取，让它帮你构建整套大模型体系。只需要一点计算机常识，不会就直接问 AI。别一听 API 就觉得很难，它和使用豆包差别不大，主要是一点渠道上的变化。

10. 邵艾伦： 您看好年轻人未来几年投入哪些方向？AI 会怎样改变学术研究的机会？

孙宇晨： 我非常看好未来的年轻人。AI 时代，所有东西都会变得很便宜，唯一值钱的是寿命，年轻就是财富。年纪大了，很多事情赶不上趟，到点就得下车。AI 还没做到长生不老，但除此之外，各行各业都在被它改变，年轻人在每条赛道都有机会。

比如我设立孙宇晨奖的数学领域。过去数学很依赖家学和师承。北大、清华以及中国高中生拿了很多 IMO 金牌，为什么菲尔兹奖、顶尖数学奖拿得少？为什么未来的孙宇晨奖得主也少？关键在于解题需要思路。如果跟着哈佛、MIT、巴黎高师的导师，就能接上这些思路；在北大再聪明，如果导师不知道怎么解，进不了那个圈子，就摸不到路。

现在 AI 能把全球的解题思路抓到模型里，像 NS 方程，直接就能解。AI 本身不创造东西，无法平地起高楼。问它怎么做可控核聚变，它也不知道，因为人类还没做出来；但前人已经提出一些方向，AI 可以把这些思路收集起来分析、往前探路。

所以我设孙宇晨奖，题目摆出来就可以直接解。研究生甚至高中生，只要读得懂 AI、Aster、Claude Code 给出的思路，就能一步到位达到数学博士的水平。数学本来就常出年轻天才，陶哲轩十几二十岁解出难题，爱因斯坦提出相对论时也很年轻。有了 AI，不必等着逐级升硕、升博，高中就可以开始。以前 IMO 的天才被耽误了，现在接上 AI，两个人可能两天就做出世界级成果。

前两天 OpenAI 和纽约大学一位研究 NS 方程的数学家发生了纠纷。教授把思路告诉 OpenAI，模型学会后就内化了。你说是不是把他的 idea 偷了，我认为并不是故意去偷。我相信 OpenAI 内部有 agent，每天监控模型对千禧年难题的解题思路有没有进化。碰巧教授提供了新方向，OpenAI 调集 700 万美金的算力、几千个 agent，两天就把它攻破了。教授的思路很关键，没有他提供，OpenAI 也不知道；但他一提供，AI 两天就做了出来。

数学现在就是这样你追我赶。懂 AI 的 15 岁年轻人，很快就能超过 50 岁的老教授。生物学也是类似的机会。我平常问 AI，它也告诉我天文学会有本质性进步：哈勃望远镜积累了大量数据，处理起来枯燥，没人有时间做。加上 AI 去处理这些数据，很快就能取得决定性突破。

11. 邵艾伦： 如果对学术不太感兴趣，只想尽快实现财富自由，您建议什么商业方向？除了 Token 中转站，还能怎样做全球生意？

孙宇晨： 挣钱的路很多。我举个合法环境下的例子：AI 的 API 价格并不统一，同样的用户在阿根廷、土耳其、尼日利亚包月最便宜，在美国包月最贵。我自己也做过类似 Token 中转站的事，这个思路是慢慢跟 AI 交流形成的。

商机要在全球发现，不要只想着在家门口开个小卖部，挣楼下老奶奶的钱。结合自己的长处和兴趣，把尼日利亚人、土耳其人、阿根廷人都看成客户。人的基本需求差不多，语言也不该成为限制：做阿根廷市场不会西班牙语，AI 可以帮忙，自己也可以学一点，别先把自己限制住。

商业是我的老本行，比学术更懂一些。最基本的原则是有没有创造价值。Token 中转站所在的地方价格低，别的地方价格高，能让贵的地方用上便宜的服务，就体现了价值。所以首先要改变度量衡，不能只看本国、本地区、本市，要放到全球去看。

中国是世界级工厂，有大量过剩产能。把产能、商品和想法对接全世界，把全球的人当客户，只要能体现价值，就不用愁卖。这个华语节目虽然面向 4 亿中国年轻人，但我希望他们走向世界，而不是在内部互相消耗。

这 4 亿年轻人借助 AI、黄毛、薄肌和孙学，去服务全球 80 亿人，未来很快还有 20 亿 AI，就是 100 亿人与 AI 的需求。这个尺度足够大，总有缝隙和机会，一个行业不行还可以换另一个。AI 时代把路打开了，但不要太早下断言说‘我就想做什么’，先多学、多听、多看。

12. 邵艾伦： 买房、买车、结婚或者选择职业前，应该怎样积累信息、提高决策胜率？我的第一反应是找能升值的房、保值的车，以及合适的伴侣，避免离婚分走一半财产。您认为关键是什么？

孙宇晨： 虽然我说 30 岁之前不买房、不买车、不结婚，但如果非做不可，就先建立自己的判断。买房先看 100 套，不急着买，一手房、二手房、地段、配套都去看；买车也先看 100 辆。看得多了，对方怎么要价、大概值多少钱，你自然会形成认知框架。

数学里也有类似问题。假设只有 10 套房可看，而且不能回头买，看第一套就决定，后面 9 套还没见过；等到第 10 套，又可能错过前面的好房。我的理解是，前三套先不买，用来建立 Benchmark；第四到第六套，一旦出现比前三套都好的，就立刻买。这里既有黄金分割线 0.618 的因素，也是概率分布最成熟的区间。

择业也一样。大学生不知道选什么行业，可以让 AI 帮你看 100 个专业的就业情况，逐个推导未来 10 年的趋势，相当于一夜变身张雪峰。比如同样的高考分数，不一定要挤清华北大的冷门专业，也可以去中国海关学院、福建海关学院，听起来不如清北，但毕业进海关，前途非常好。张雪峰讲的很多类似思路，现在 AI 都可以帮助覆盖。

过去决策受限于信息太少，现在要先把地图打开。玩红警、星际时，有些人关起门来造兵，聪明的做法却是先造几个斥候：哪里有资源、哪里有黄金、对方主要造什么兵，都探清楚，再针对性地造兵。对方造战象，你造长矛兵，长矛兵打战象有 5 倍伤害，就能克制它。

先把资源标出来再决定，何况现在借助 AI 探图几乎是免费的。一直闷头造兵，等后期开图，资源可能早被别人挖光了。《王者荣耀》也是这个道理：要插眼，要知道对方什么时候开大龙、野区刷野情况如何，团队总得有人负责视野。没有信息，胜率就低。

13. 邵艾伦： AI 信息很多，大家仍然希望听一个可信的人指出方向。能否直接给年轻人讲讲您看好的五条大趋势或赛道？

孙宇晨： 先看学术界，凡是依靠数据推导的领域都有很大机会。纯数学、天文学、生物学都有大量数据等待处理，实验数据、观测数据、理论数据交给 AI，都很值得做。生物制药一旦实验通过，回报很大，我自己也在研究 AI 和生物相关内容。基因测序也是，现在能测出一个人的全部基因，再分析、预测未来的健康管理，我高度看好。

再看建立在这些基础上的商业。第一是制药、生物、基因分析、健康管理；第二是金融，比如直接与人寿相关的保险。现在不少精算算法落后，等待年轻人发明新的一套逻辑。

第三是 Crypto。它是全球性的支付体系，和 AI 天然相连，可以做微额计算，按 API 的调用读取、计费并即时结算。传统金融的最低单位可能是一分钱，做不到这种高精度微结算，而 Crypto 天然适配。

第四是 AI 本身，包括 LLM、数据清洗和数据标注。别小看标注，Scale AI 做数据标注，估值已经一百多亿美金。现在机会很多，要珍惜 20 到 40 岁最有创造力的黄金年龄。我 36 岁，还剩四年黄金时间。十年前，甚至二十年前我 17 岁刚进大学时，科技没这么大的进步，能上网、在校内网聊天，最多增进联系，没有今天这样的爆发。我认为未来只要稍微努力一点，人均都能取得诺贝尔奖级别的成果。

## 三、薄肌、健康与认知转变

14. 邵艾伦： 为什么您反复强调年轻人要练薄肌？马斯克、巴菲特、特朗普都不健身，您怎样看待这些例子？这与人在 AI 时代的工作又有什么关系？

孙宇晨： 人类正在进入科技大爆发时代。未来的成果会是人均诺奖级别，一个大学生加上 AI，研究速度很快就能超过诺贝尔奖得主。如果每人都发 100 万美金，诺贝尔基金会都要发不起、破产了。所以我很着急，要求全员 AI 化、全面进入数据清洗状态。

但回到个人，最容易上手、控制变量并看到效果的，还是薄肌。看 100 套房再做决定需要时间，练薄肌可以立竿见影。70 岁的王石也在练，但我问 AI，它说 70 岁确实有点晚，可能勉强保证不坐轮椅。人一生的肌肉总量在 30 到 40 岁到顶，40 岁后开始下降，所以我认为 20 到 40 岁练薄肌的回报最高。

马斯克、巴菲特、特朗普都是我的宾大校友，他们不练，甚至反对健身。AI 问过我一句话：你跟巴菲特吃午餐时，他是自己走进餐厅，还是坐轮椅被推进来的？当然是被推进来的。不练薄肌，到 80 岁就是被轮椅推进来；练了薄肌，80 岁就能自己走进来。这让我想明白了：自己 80 岁时，是想走进来，还是被推进来？每天练 40 分钟，对后半生的生活质量提升很大。

马斯克现在五十六七岁，比我大差不多 20 岁。如果不练肌肉，二十年后 AI 做得再好，也得被推进来，除非 Neuralink 已经实现意识上传，让人成为钢铁侠。只要肉身还在，就不能违背生物学规律。我们可以学他们的商业思路，但我认为他们反对健身是错的。我今天也转发了马斯克 Neuralink 的动态，这不妨碍我在健身问题上反对他。

年轻人不能看别人不练，自己也不练。20 到 40 岁身体最好的时候练，对 40 到 80 岁的生活质量至关重要。在我看来，人均诺奖、人均薄肌，都会成为这个时代的入门要求。如果没练出来，把 API 给我，我读一下你过去 180 天在做什么。AI 时代，工具已经准备好了。

我现在每天让几十个 agent 监控工作，自己只花少量时间微调。人是总指挥，能操控成百上千个 agent，时间反而更宝贵。主要精力应该用来维护身体。Neuralink 还不够发达，大脑只能托管在碳基肉体上；这台‘碳基服务器’垮了，硅基服务器调得再好也没用。

所以我每天主要做两件事：维护好碳基身体，再适度指挥硅基 AI。碳基是一票否决的，一旦病倒，其他事情都做不了。先保证身体，才能争取超长待机。

15. 邵艾伦： 您怎样理解薄肌、心肺和寿命的关系？我认为身体和专注力是一个杠杆，再结合 AI 应用才有更多机会；薄肌还可以提升形象和自信。

孙宇晨： 我 36 岁了，前 40 年快过完了，开始考虑 40 到 80 岁怎么生活。二三十岁的年轻人可能还没想过寿命，但我最近专门问了 AI：怎样才能活得更长？它说，寿命一共 100 分，25 分是心肺，25 分是肌肉，二者占 50 分，而练薄肌两者都能管上。

光跑步会消耗肌肉，心肺就白练了；薄肌却像《王者荣耀》里一件自带效果的‘传奇皮肤’。比如红莲斗篷有持续伤害，贴着别人就扣血，肌肉则可以被动燃脂。肌肉本身的 25 分，让人老了不会摔倒、不会瘫在床上或轮椅上；训练时调整呼吸、增加重量，也在提升心肺。所以我认为，练肌肉可以把前面这 50 分都拿到。

其余还有不抽烟、不喝酒、防癌基因，以及眼睛、牙齿等器官的保养。有些要花钱，比如看牙；有些要靠运气，比如父母给的基因。但心肺和肌肉这 50 分，可以通过薄肌拿满。

这些是我研究、和 Claude AI 讨论后的理解。我认为薄肌是唯一既不会让心血管爆表、又能被动燃脂、把这 50 分拉满的路线，还能改善形象和吸引力。提升形象的唯一解就是薄肌。这是硬核科学。我认真研究后，决定一定要走这条路。

16. 邵艾伦： 我把肌肉看作个人和国家的战略储备，有条件时应该先存起来。所以我说‘薄肌会取代美金’，并不是开玩笑，而是把它当作事实。您为什么把它比作身体里的现金？真正让您决定练薄肌的原因是什么？

孙宇晨： 对国家来说，薄肌小子是战略储备；对个人来说，有件事让我很受震动。我决定练，并不主要是因为那场风波。有人嘲笑我胖、没有‘生理性喜欢’，有人说我一米六三，但我实际是一米七二。这些都不是关键。关键有两点：一是我认为它符合科学，二是 AI 的一句话点醒了我。

AI 跟我说：你在物质上是富人，但在身体上还是穷人。练薄肌就像领工资，是在提高身体的收入。

肌肉负责支撑身体、维持机能，身体开始消耗时，先扣肌肉，再扣脂肪。有氧运动营养没跟上，会掉肌肉；生一场大病，也先消耗肌肉。所以肌肉就像最核心的银行账户，平时多吃蛋白质、多吃鸡肉，是把它存起来。美金没了还可以再赚，身体有薄肌，扛大包也能赚美金。

我认为这套理论应该全社会推行。减少肥胖，可以为医保、社保省下很多开销。90%的疾病都与心血管和肥胖有关；体脂降下来、有肌肉，生大病时恢复速度极快，因为身体能直接从肌肉中提取氨基酸修复黏膜和组织，抵抗力也强。这是我从认知上高度重视薄肌的原因。那句‘物质上是富人，身体上是穷人’，确实让我重新认识了自己。

17. 邵艾伦： 您的认知变化受到我的薄肌理论启发了吗？过去有哪些误解，网络上的批评又起了什么作用？

孙宇晨： 有启发。我年轻时对肌肉的认识很浅，错误认知耽误了自己。一个武断的想法是，练肌肉的人都是为了泡妞，觉得不正经；另一个是，凡有肌肉的人都上了‘科技’，打了什么东西。网上一些公众号也迎合这种想法，报道谁打药练肌肉、又猝死了。

受这些影响，我就觉得自己忙，不用练。有一阵想追求健康，反而把肌肉和健康对立起来，给自己建立了‘有肌肉不健康’的理论，所以一直不重视。

这次风波后，全网对我进行了一轮攻击。但不能简单说是‘被骂醒了’，我的态度是有则改之、无则加勉。我已经过了玻璃心的阶段，虽然头发还是黑的，心态已经被黄毛理论武装，不会因为别人的评价就额外想很多。

不过，我会考虑这些批评有没有道理：肌肉少、头大四肢小，是不是一个问题？身处 AI 时代，我首先去请教 AI。我和 Claude Code 进行了一番深入辩论，把陈旧理论都抛给它，它逐条反驳，最终帮我建立起一个新认识：肌肉就是身体的储蓄。

18. 邵艾伦： 我认为‘四肢发达、头脑简单’不对，应该是‘四肢发达、头脑发达’，二者相辅相成。为什么聪明人也会排斥健身？怎样改变对肌肉和有氧训练的误解，包括怕练得太大的顾虑？

孙宇晨： ‘四肢发达、头脑简单’没有坑四肢发达的人，反而骗了很多头脑发达的人。数理化、AI 很厉害的人，也可能不懂身体。特朗普、马斯克、巴菲特都是顶尖聪明人，也是我的校友，但他们说健身有害。我觉得这里存在屁股决定脑袋：自己不是薄肌，是胖子、大肚子，就要替大肚子说话。

这像一个穷人不想着怎样变富，反而说钱没用：富人会因钱发生凶杀案，钱破坏家庭幸福，所以自己是主动选择不富。越聪明，越能编出一套说辞，不仅不改变，还嘲笑去练的人。这也是为什么你练了之后，周围一定会嫉妒、指责你，而且他们有很强大的说辞来攻击你。

我为什么能跳出来？虽然现在还有大肚腩，但思维已经更新，走在薄肌的路上。这有点像改革开放。过去低买高卖被看成投机倒把，要抓起来；换个思路看，能让消费者买到更便宜的东西，是一种本事。从美国买便宜的东西到中国卖，也可以是在带来科技和新东西，而不是赚黑心钱。观念一变，这样的商人不仅不被抓，还要被评为人大代表、政协委员。

过去两周，我对肌肉也做了类似的认知升级：肌肉不但无害，还极大有益健康，应该积累，而不是刻意压制。这就像从闭关锁国转向改革开放。但听众不用因为听了节目就盲目去练，先自己问一问，想清楚道理。

我以前特意避开肌肉，很多女生也会要求教练‘一点肌肉都不要练’，既想健康，又想没有肌肉。我受过这种思路影响，多做有氧、少做器械。现在我认为这完全错了，有氧甚至可以不专门做，因为器械、抗阻训练本身也提升心肺。心肺、肌肉各 25 分，练薄肌可以拿到 50 分；只练有氧，肌肉消耗了，只剩心肺 25 分，肌肉仍是零分。这套道理让我彻底转向薄肌。

19. 邵艾伦： 您推荐大家看薄肌教程吗？除了教程，还有哪些误区需要集中澄清？为什么强调尽早开始？

孙宇晨： 非常推荐。我把那部‘薄肌圣经’的视频下载保存，还逐帧逐句给 AI 看过，觉得很有用。不过，先认可薄肌理论的人，才读得进去；不认可的人可能直接划过。所以我们可以再做一期问答，把最基础、最容易误导人的问题集中解释清楚。

马斯克在这方面起了不好的作用。他和我以前有点像，四肢细，脂肪主要集中在躯干。做 Don’t Die 的 Bryan Johnson 以前也这样，后来练肌肉，虽然不敢说是薄肌天花板，至少肌肉和身体指标都跟上了。

Bryan Johnson 把以前肥胖、不健康和现在的照片放在一起，号召大家健身，马斯克却留言‘you look better before’，说他以前更好，等于说练这么久白练了。我认为这就是屁股决定脑袋，而传播这种错误观念，最终吃亏最大的还是他自己。

AI 跟我讲，马斯克比我大 20 岁，现在五十六七岁，每晚一年练，就少一年宝贵时间，肌肉每年还在按 1%、2%的速度流失。过了 60 岁再练，就来不及了。我们现在可以两天一个训练循环，年纪大了，恢复能力下降，可能四五天才能一个循环。上器械需要恢复，健康账单会越积越大，所以一定要趁早。

## 四、未来十年：机动性、Crypto 与个人媒体

20. 邵艾伦： 我今年 30 岁，过去十年主要挣钱、投资，基本实现了财富自由。该如何规划下一个十年？您说的机动性，是指地点、事业，还是连投资也要保持灵活？

孙宇晨： 我的思路可以概括为‘逐水草而居’。我很欣赏游牧民族，羊要喝水吃草，所以匈奴、辽、金，哪里有水草就去哪里。传统历史叙事常把他们妖魔化，是因为我们站在宋朝一边看问题。但辽、金今天也是中华民族大家庭的一员，五十六个民族人人平等，不能天然认为他们比宋朝低一等。能把宋朝打得很厉害，总有他们的长处。

放到未来十年的规划上，就是没有一个固定答案，也不必在一个地方一辈子不变。哪个地方、哪个行业能发挥自己的最大价值，就去哪里。能不能赚到足够的钱，是一种客观反馈：赚到钱，不只是别人给你钱，也说明你所在行业、你做的事情创造了更大的价值。

同样一个人、一家企业，在 AI 领域工作，现在就比在西贝更赚钱。西贝做了十几年，这几天却快倒闭；梁文锋做 DeepSeek 才几年，据说估值就要突破几万亿人民币。做焖面、做西贝和做 AI 相比，全社会给 AI 的溢价大得多。所以要去能发挥最大价值的地方，不要死守原地。

这也是为什么我不建议过早买房、买车、结婚，它们都会把你定死在一个地方，有时你自己都没有意识到这种束缚。假设明天 OpenAI 录取你，要求去旧金山，你却说北京买了房，能不能留在北京工作，大概率对方不同意，这个时代级的机会就没了。有水草的地方在旧金山，就应该能去旧金山。

我见过很优秀的人才，想招来大城市，回去和妻子商量后却拒绝了 offer。妻子在老家有月薪五千的稳定工作，不愿辞职，也不让他去；即便给他四万月薪，他也只能留在原地拿两万。这样的束缚会直接影响选择。

所以我强调机动性，也很少投资机动性弱的事业。在灵活的前提下，选择适合自己、能创造最大价值和回报的方向。孙学、黄毛、薄肌的精髓都有这一点，肌肉长在身上，本身也是一种可以带走的机动性。

21. 邵艾伦： 手机里的 AI、系统更新都可以随身走。我理解，买香蕉艺术品是一笔数字资产的投资。您花 600 万美金买香蕉艺术品而不是黄金、钻石或珠宝，也是出于这种机动性的考虑吗？

孙宇晨： 是这个道理。手机里装再多东西，也能拎着就走。香蕉是概念艺术，是在网络上传播的流动 IP。只要我同意，明天任何一个博物馆都可以贴一根香蕉展出，流动性极强。黄金、珠宝却固定在某个地方，带不走，还可能被偷；这根香蕉和我的名字绑在一起，谁也偷不走。

很多人不理解，像薄肌一样，这种理念很新，今天绝大多数中国人还接受不了。但我认为它是正确的，布道者的价值也正在这里。如果大家都知道，我每天讲‘1+1=2’就没有意义。小众意味着风口，大众化以后，信息差和红利也就没有了。暂时不被接受、被骂得多，反而说明传播这些理论还有价值。

22. 邵艾伦： 对于完全不懂 Crypto 的人，您会如何介绍 TRON？它是不是在把传统货币体系升级为 AI 能够读懂、参与和结算的工具？

孙宇晨： TRON 和 Crypto 本质上都在做一件事：把货币翻译成机器和互联网能听懂的语言。这跟我设立的孙宇晨奖类似。孙宇晨奖鼓励把数学证明翻译成 Lean 的形式化证明，也就是让机器读懂数学理论和推导，为 AI 时代铺路。如果不是机器能理解的形式化语言，AI 就无法理解。

有人会问，招商银行、PayPal 不也是机器读得懂的货币吗？并不是，它们只是传统法币的数字化，本质上仍是中心化服务器管理的账本，不是机器原生可读的货币语言。只有在去中心化的分布式网络下，账本完全按照密码学和数学逻辑运行，机器才能原生理解和交互。所以波场、比特币天然能与 API、智能微支付融合，把人类几千年历史的古老货币，变成 AI 和机器能够原生调用的底层语言。

很多人不了解这些，一提区块链就说割韭菜，认为是把没价值的东西高价卖给别人。这跟把练薄肌归因为泡妞一样，都是盯着所谓动机，却忽视技术价值或健康事实。明明是为了健康，却被扭曲成自私、猥琐的想法，很多人会被这种错误归因带偏。

我们做的事情和 AI 是一回事。比如数学界前段时间在做费马大定理、庞加莱猜想的形式化：人类早已证明，但机器读不懂，全世界真正吃透证明思路的人也很少。只有通过 Lean 形式化，让计算机读懂、验证，再由全世界的计算机和 AI 吸收，这些成果才算真正沉淀下来。在这个时代，如果一样东西机器读不懂，它对硅基文明就没有价值。

人类正处于从碳基向硅基的过渡阶段，充当翻译官至关重要。把数学、货币和人类文明的发明翻译给机器，整个文明才能升级上路。我们和 SWIFT 做的是同一件事：把美元或其他资产清算、发送到世界各地。但 SWIFT 是上世纪五十年代基于二战后盟军电报系统搭建的，那个时代没有计算机，更没有 AI，不可能原生兼容现代互联网和 AI 智能体。

它是一个落后、线下且沉重的清算协议。我们把价值结算翻译成机器语言，我认为这件事绝对正确。未来如果成果不能被机器吸收，它的长期生命力就会大打折扣。

23. 邵艾伦： 为什么要把知识、文化和个人想法数字化，变成 AI 能读取的语料？就像我们的对话，如果没有录制、公开，很多想法可能就流失了。

孙宇晨： 现在任何东西都要翻译并放到互联网上，成为 AI 的语料。如果一样东西未来没有成为 AI 的语料，在硅基世界里就等于从未发生过。比如五百年前有一个五千万人口的国家，如果没有文字记录、没有语料沉淀，未来也没有被喂给 AI，那么哪怕整个国家灭亡，在地球上也像从未存在过，因为 AI 根本不知道。

所以全面上网、被 AI 读取吸收，是进入下一个人类文明的入场券。把中国的历史、文字、诗歌和图书馆里的书全部数字化，免费上传公网，这类文化工程非常有意义。我相信 DeepSeek、字节跳动这些公司已经在做。如果只在私下说，没有记录和公开，灵光一闪很可能就彻底流失了。

还是纽约大学那个教授的例子：他把解题思路告诉了 OpenAI，后来 OpenAI 用这个思路攻克了 NS 方程。从科学家个人的角度看，这可能是悲剧，但从人类整体看是件好事，因为人类锁定了 NS 方程的解。

当年费马提出费马大定理时说，自己能解出来，但空白太小写不下。他可能真有思路，却没分享给全人类，导致后人花了一百多年才证明出来。如果放在 AI 时代，他只要用语音讲两句，AI 记住并同步给全世界的数学家，可能提前一百年就证明出来了。按今天 AI 进化的速度，只要思路对，两天就能算出来。对个人可能有点委屈，但全人类的进度被大幅加快。站在人类文明的立场，甚至巴不得 AI 多吸收一点大家的 idea。

24. 邵艾伦： 把个人信息全面数字化、互联网化，自媒体是不是也是风口？我觉得很多人从 BBC 等传统媒体转向 Twitter 的讨论，也是因为去中心化的讨论更接近真实。

孙宇晨： 绝对是。以前只有传统媒体才能发声，个人有想法也无法表达。我在传统媒体工作过，结构很简单：主编定选题，记者执行，主编个人的认知基本决定了大众看什么、怎么想。但主编不是神仙，不可能每件事都对。

原则上应该允许所有人发言、充分辩论，才大概率接近真理。自媒体给了所有人发声的机会，这也是抖音、YouTube、Twitter（X）迅速崛起的原因。通过开放的市场化竞争和读者用脚投票，最终胜出的观点大概率是客观科学的；而过去中心化的报纸和媒体一旦误导，全社会都会跟着被误导。

25. 邵艾伦： Crypto 对普通人生活的杀手级应用是什么？我把波场理解为资金通行的高速公路，赚取很低的通行费；稳定币日常支付，以及人与 AI、AI Agent 之间的微支付，是不是主要应用？像网购一样，更高效的工具出现后，趋势就不可逆了。

孙宇晨： 现在已经有杀手级应用，就是全球范围内的稳定币即时转账。波场每天的交易清算量有几百亿美元，一年发送总量达到数万亿美元（Trillion 级别），规模已经赶超 SWIFT。普及当然需要循序渐进，就像 AI 已经爆发，仍有很多人没开始用，但这是不可阻挡的历史趋势。

AI 更高效，Crypto 更接近未来的终局。一百年后还会有人使用纸币吗？我认为绝对不会。纸币必然退出历史舞台，数字货币是整个社会的终局方向。Crypto 是可编程货币，本质上就是把货币翻译成 AI 能直接调用的底层逻辑。随着智能体普及，货币加密化、数字化不可阻挡，AI 之间的 API 级微支付与清算前景也极其巨大。

这是一门更先进的底层科技，就像血肉之躯抵抗工业机械没有意义，技术潮流也无法阻挡。当年马云把中国网购推起来是件大好事。技术趋势形成后，我们要拥抱，而不是挡在门外；AI 来了，就主动适应，而不是限制它发展。

年轻人更容易做到：20 到 40 岁身体代谢好、思维敏锐；到了六七十岁，很多人受制于既得利益，不愿意改变。所以年轻人更要主动吸收、主动升级，先吸收、先改变，跟练薄肌是同一个思路。

26. 邵艾伦： 您个人的资产配置和投资，也全面偏向 Crypto 这类资产吗？这是不是做自己相信的事，赚钱只是做对事情的副产品？

孙宇晨： 我是全部 Crypto 化，大概 2012 年以后就这样了。当时不是为了发横财，而是为了升级底层操作系统：第一，做自己相信的事；第二，像手机出了新系统，我一定是第一批更新的人。iPhone 刚出来我就买了，假如后来涨到 100 万美金一台，也不能说我当初是为了炒作赚钱。我买它唯一的原因，是它代表未来。

我很早就觉得买房、买车意义不大，它们是旧时代的资产，无法翻译给机器，机器听不懂砖头水泥。能够翻译给机器的是数字货币、比特币，以及后来我做的波场网络。所以我第一批完成系统更新。操作系统不能回滚，只能向前；如果扛着不更新，后面的软件生态只支持新版本，就会逐渐抛弃你。

早更新早受益。2012 年我更新成 Crypto 时，买入成本自然很低。任何领域都涉及买入成本，练薄肌也一样，70 岁再练成本太高、来不及了，越早越好。哪怕只从趋势代表未来的角度看，也应该尽早更新。

我也是第一波坚定看多存储赛道的人，因为 AI 爆发必然需要海量存储。有人以为我要做存储项目、喊单割韭菜，并不是，只是底层技术趋势往那个方向走，没必要硬抗。很多丰厚回报并不是奔着赚钱去才得到的，赚钱只是做对事情的副产品。随着时间推移，这些事物在人类社会里的角色越来越核心，社会给它的定价和评价也就越高。

27. 邵艾伦： 判断技术或理念的价值，应该看事情本身，而不是猜提出者的动机吧？就像有人说我推广薄肌是在吃黑红流量，真正该看的是内容有没有价值、符不符合科学，而不是从私德推导技术价值，或把中年人健身归因为中年危机。

孙宇晨： 市场会用脚投票。这次风波之后，很多人试图扒我的黑历史，编造我看牙医不给钱、去商店买东西赖账等从未发生的事。买东西不给钱不就是小偷吗？直接报警抓我就行。他们想证明我是坏人，再推导出我做的事也是坏的、赚的钱是不义之财，这在逻辑上没有意义。

就像一个健身博主宣扬健身，别人拼命挖他的私生活，想证明他道德败坏。哪怕他道德真有问题，能证明练肌肉有害吗？肌肉对健康的价值由底层生理规律决定，人体需要肌肉托底，肌无力就会卧床不起，这跟博主的人品没有因果关系。波场和 Crypto 的成功也脱离了我个人的道德，难道说我看牙医不给钱，全球就不使用数字货币了？这是因果错乱。

为了博眼球，很多人喜欢用动机论攻击人。前两天好莱坞有导演拍黑马斯克的纪录片，采访一堆前女友，有人说马斯克做 AI 是为了奴役全人类。山姆·奥特曼也有亲戚接受采访，说他做 AI 纯粹为个人私利。但他们做出的技术对人类有没有用，客观评价与私德是两回事。

动机论还有另一种影响：传统观念把练肌肉歪曲成想泡妞，要求大家老实念书。开玩笑地说，为了避嫌，怕别人觉得作风不正，我以前甚至不敢练肌肉，好像不练才是好学生。只要进健身房，就有人问是不是想泡妞；坊间还说中年男人健身就是想出轨，甚至跑去给别人老婆吹耳边风。两者没有因果关联，但为了抹黑你、阻止你做这件事，各种动机论就扣上来了。

28. 邵艾伦： 我很大一部分资产配置在 Crypto，但核心能力是英语内容、个人 IP 和自媒体。您说过资源有限时，能力和资源最好 All in 一个地方，那我需要把投资和主业绑定吗？面对新事物，是否也应该坚持逻辑判断，而不是为了合群放弃？

孙宇晨： 不一定要死板绑定。如果核心优势是做内容，完全可以一边做内容、一边投资 Crypto，两者不冲突。2007 年乔布斯时代，我第一次知道 iPhone，觉得产品很牛，就买了很多苹果股票，但没有去苹果上班。当然，如果本身就在手机行业，去苹果也是知行合一；买股票参与同样是一种方式。2012 年看到第一辆特斯拉，我认为这是产业革命，也买了。

核心逻辑是升级底层操作系统。无论投资还是工作，看到更先进的事物就先升级。我平时很追时髦，前沿工具都会买来用，虽然要付出时间，但值得，因为新东西大概率代表未来的方向。

当初一些观点别人觉得极端，后来事实证明是对的。比如我说日常决策都要交给 AI，很多人坚持自己拿主意。但随着 AI 越来越强，听它的决策往往最高效。拥抱新事物是我的第一原则。认定了就坚定去做，不要被别人一劝就动摇，为了所谓合群而放弃。

29. 邵艾伦： 做 Crypto 自媒体有前途吗？像 Joe Rogan，个人节目甚至能左右大选选票，而且他天天健身；Andrew Tate 也是健身大网红，您怎么看这类个人媒体？

孙宇晨： 自媒体整体都值得做，现在是做多自媒体的黄金时代。Joe Rogan 在全美的播客影响力极大，单独一个节目的影响力，就堪比哥伦比亚广播公司（CBS）整家电视台，这就是自媒体时代的威力。

Joe Rogan 天天高强度健身，也在练薄肌。包括前两天在佛罗里达被抓的 Andrew Tate，虽然他确实做了些错事，但也奉行这套理论。

## 五、认知更新：Small EGO 与财富自由

30. 邵艾伦： 如何从薄肌进一步理解主动健康管理？我理解，黄毛、薄肌、Crypto 的底层都是认知，健康这项分数也应该努力拿满。认知如何影响人生？

孙宇晨： 我把薄肌论再往上提升一层：未来在 AI 赋能下，主动健康管理会成为人类最核心的健康范式。不是生病才去医院，而是没生病时主动监测。我最近没有不舒服也去了医院，因为 AI 告诉我该查哪些指标。我之前体重偏重，开始大强度健身前，先排查高血糖、高血脂，以及高密度好胆固醇、低密度坏胆固醇等指标，摸清底，再针对性地科学健身。

检查后，医生问我是不是用 AI 开的检查单。我说是，医生说他接诊过这么多人，我是第一个没有任何不适，却主动拿着精准指标做健康监控的。绝大多数人出现明显症状才来，那时早就晚了。他认为我用 AI 做主动健康管理，是走在正确的道路上。

所以我认为，主动健康管理一定会成为主流，薄肌也会从少数人的追求，变成成功人士的标配。没有肌肉，说明根本没做主动健康管理：一是认知缺陷，二是不懂未来趋势。心肺占 25 分、肌肉占 25 分，肌肉这 25 分当然要拿满，对健康负责，自然就会去练抗阻。归根结底，还是认知决定命运。

能看到这期节目的听众，相当于提前打开地图。朋友把节目转给你，值得好好感谢，因为孙学能够让人尽早迭代认知，改变人生轨迹。很多人以为必须先有钱、有资源，成为巴菲特才能做成事，但这个时代并不是这样。

2012 年我买比特币时，一枚只要一美元，现在快十万美金。当年我苦劝巴菲特投资，他账上有上千亿美金现金，只拿出很小一部分就能买光市面上的比特币，但就是不买，这就是认知锁死。

如果当年劝他练薄肌，也已经晚了：我 29 岁与他吃饭时，他 89 岁、快 90 岁了。如果年轻时早点练，晚年的生活质量会大幅提高，根本不用坐轮椅。世界首富也会犯认知错误。随着阅历增加，我越来越觉得认知才是第一位，别迷信社会地位和当下的财富，要看底层认知水平。

31. 邵艾伦： 旧版本的成功者往往不愿接受新版本，既得利益也容易让 EGO 膨胀。为什么越成功，越需要保持 Small EGO？您向巴菲特推荐比特币时，也推荐过马斯克吗？

孙宇晨： 张一鸣讲过，字节跳动能持续打胜仗，做出抖音和各种头部 App，又敏锐推出豆包，秘诀就是 Small EGO。不管多成功，都愿意虚心听年轻人怎么说，学习前沿事物，不觉得自己天下第一、别人都是傻子。保持这种状态才能跨越周期，否则就像当年的百度，前半程不错，后半程跟不上新版本，被时代甩下。

理论上，越有钱、越成功，EGO 越应该小，才能保证下一版本继续成功。但现实往往相反：人越成功，越觉得自己的成功证明过去一直正确，别人失败就说明别人错了。

我向巴菲特极力推荐过马斯克和比特币。但站在他的视角，可能会想：马斯克要是真那么厉害，当年怎么不是他当世界首富？结果几年后，马斯克真的成了世界首富。如果在他登顶前提前布局，搭上顺风车，资产不就更上一层楼了吗？所以越成功，越要警惕大 EGO 带来的认知遮蔽。就像很多人上网狂喷薄肌理论，我的第一反应却是认真学习。

32. 邵艾伦： 您认为当年与巴菲特吃饭，是他获益更多。那今天这场薄肌对话，是不是您获益更多？我觉得肥胖率上升时，练薄肌就是这个版本的答案。

孙宇晨： 这次确实是我占了大便宜，因为我彻底吸收了薄肌理论。一看到这个理论，我就和 AI 认真推演、学习，判断正确后立刻落地，花了两周验血、排查指标，把训练日程安排起来。全面启动后，我未来四十年的健康底子就稳了，心肺 25 分、肌肉 25 分，主要靠这套理论拿下来。

控制住体重、有了薄肌，能少踩很多坑。我自己不算特别胖，但已经感受到肥胖带来的问题：三高、胆固醇高、睡眠变差、睡眠呼吸暂停、心血管供氧不足，一系列问题都会出现。

别人看孙学、薄肌、黄毛，可能只看到你更有钱、更容易泡妞，甚至因此嫉妒，但本质是你走在正确的道路上。就像我把钱换成 Crypto，赚钱是因为升级得早。我们追求的是未来和健康，赚钱、泡妞只是副产品。

当然，别人可能从这些副产品上攻击你。只看我推广 Crypto，也许还无所谓；一看福布斯把我排进前 100，就开始编看牙医不给钱的事。练出薄肌也可能受到攻击，但要坚信自己本质上是在追求健康。与其攻击别人，不如自己早点开始练。

33. 邵艾伦： 很多成功者很难跨过 EGO 这一关。您现在愿意接受薄肌理论，如果以后越来越成功，甚至成为世界首富，怎样继续保持 Small EGO？是不是只有想被帮助的人，才会接受别人的建议？

孙宇晨： 我写过“一代版本一代神”。王思聪以前嘲笑我，现在我比他父亲都有钱。在别人看来变化很大，但我觉得自己还是以前那个孙宇晨，只是社会现在更认可这套认知。没有一个认知能像算命先生那样吃 50 年，人的认知必须不断升级，而且一个领域认知正确，不代表其他领域也正确。

比如马斯克的创业认知是顶级的，但在健康和薄肌方面不如我们。他自己超重，不练薄肌，还嘲笑练的人，用替尔泊肽或司美格鲁肽降重。而这些药最大的问题是会掉肌肉：不练已经在掉，用药又掉一层，脂肪和肌肉一起减少，肌肉量更低，就可能出现肌无力、摔倒骨折、卧床后难以恢复等一系列问题。

认知转不过来，就会觉得别人的忠告是错的。Brian Johnson 推广 Don’t Die 并没惹马斯克，马斯克却坚持说他之前发胖时更好，这就是认知扭曲。良言只劝有心人，自己不愿改变，别人摆多少事实、证据都没用。

我劝巴菲特投资特斯拉、比特币也一样，不是价格的问题，而是他认为不符合自己的投资逻辑，所以不投，哪怕这笔钱对他无关紧要。当时他账上有 3000 亿美金，拿 300 亿就能买光比特币，但他不肯买。

那时波场估值才二三十亿美金。如果吃饭时他提出给我 10 亿美金、拿一半波场币，我说不定会同意，因为巴菲特成为股东，对声誉的加持太大。现在我们的市值已经到 330 亿、340 亿美金。如果他当年投 10 亿，短短七年就成了 150 亿、200 亿美金。所以还是认知决定命运，听不进去，再怎么劝也没用。

34. 邵艾伦： Small EGO 如何让您从外界嘲笑和攻击中发现问题、升级自己？即使处境不好，也能从中得到一些好处？

孙宇晨： 我过去 36 年没练薄肌，也是被大量错误信息误导。我可能是 Crypto 专家，但没学生物，不懂健身和健康。网暴反而救了我，让我第一次意识到自己身体上确实是个穷人。以前我觉得自己挺正常，把身体穷人理解成那些肥胖的人，身边也没人提醒我。

这次“小仙女们”为了挑刺，放大我的缺点进行攻击，反而让我看清了问题，觉得必须改、必须练。全网疯传两张对比图：一张是我头大、四肢细，另一张是张继科的腿比河马还粗。我立刻意识到，首先要开始练，其次要先练深蹲，因为腿部肌肉最多。

我像 AI 一样，把这张图转化成自己的行动。Small EGO 的重要性就在这里：能迅速把别人的理论和批评化为自己的思路，而不是拒绝听别人说话。

35. 邵艾伦： Alex Hormozi 提过一个观点：如果信息是分母、行为改变是分子，根据新信息扩大行为改变，就是在提升智商。您认同吗？认知是否也应该全方位提升，不能因擅长一个领域就忽视健康等其他方面？

孙宇晨： 我认为世界上不存在智商这个东西，只存在信息多少。《Attention Is All You Need》和 Transformer 模型已经讲清楚了。以前大家觉得 GPT-3、GPT-4 很蠢，到了 GPT-5、o1 Aster，就笑不出来了；未来到 GPT-10，更笑不出来。它们的核心区别，本质上是灌入的信息量。无论 pre-training 还是 reasoning，学习和训练的核心，都是灌入更多高质量信息。

一般人看这是智商差距：3.0 像人工智障，5.0 已经能尝试破解 NS 方程。但从底层看，就是信息更多了。现在模型训练数据可能是以前的上千倍，带来显著的智商提升。人也是一样，认知改变行为模式，行为模式又改变结果。

再举个例子，韦东奕数学极强，也是我们北大的校友，主攻破解 NS 方程的学者里就有他。但其他方面我不了解，只看照片，他最大的问题是不懂看牙医，年纪轻轻牙齿快掉光了。我认为肯定有牙周疾病却没有及早就医，至少口腔卫生认知不足。牙齿脱落不可逆，假牙功能也远不如原生牙，所以不能只研究数学，忽略其他维度的认知。

马斯克的肥胖也一样，不仅缩短寿命、带来健康问题，还会拖慢事业进展。磨刀不误砍柴工，不能为了砍柴连刀都不磨。很多有钱人觉得有钱就能让医生延长寿命，这是不对的。等进急救室才喊不惜一切代价抢救，已经晚了。

健康必须自己主动管理，不能指望别人替你负责。所以认知要逐步迭代升级。按我们刚才讨论的逻辑，智商是认知和信息的外在显化，认知才是最底层、最本质的东西。

36. 邵艾伦： 您认同 Crypto 会重塑世界、比特币会成为最终的价值储存吗？“版本”从软件用语进入人生观，意味着我们要怎样保持学习和更新？

孙宇晨： 我认同。比特币竞争的对手是黄金，而黄金竞争不过比特币。包括 AI 在内的新事物，我都很看好，因为它们的对手太古老了。比特币每个版本都在升级，黄金永远不升级，怎么比？所以核心是版本更新：今天差不代表明天差，版本上去，实力也会上去。

随着 software is eating the world，很多软件词汇被年轻人吸收，进入人生哲学。以前软件在后台自动更新，大家感知不深；后来《王者荣耀》普及，每次更新都调整英雄强度。今天李白玩得很好，下个版本就可能大砍李白、加强其他英雄，玩家自然会认真研究更新公告，也逐渐明白“一代版本一代神”。

很多人以为找到一个强势英雄苦练，就能一招吃遍天。听说后羿强，就一直练后羿，其实不是这么玩的。必须理解发育、经济、打野等底层机制和动态全局，再根据版本选英雄、做布局。单个英雄不可能永远强势，太强就会被削弱。

人生和地球 Online 也一样，没有哪条路径能一直吃下去。比如 2017、2018 版大更新，房地产被砍掉 50%，AI 加 100%的生产力。如果我是王健林，有这个认知，就会让万达火速跟进 AI 版本，投 DeepSeek、Kimi、智谱。之前有新闻说，碧桂园在合肥做产业开发时，机缘巧合投了长鑫存储，却赚了几倍就卖掉，因为旧认知握不住新资产。

这个版本削弱房地产、加成 AI，可能再过十年，AI 也被削弱，又有新版本。黄毛、薄肌、孙学讲的，就是先领悟全局规则，而不是只苦练后羿射箭，等刺客来了一刀就没了。

游戏没有固定答案，不是规定必须练哪个英雄、怎么拼手速，而是要看懂全局和持续迭代。区别只在于地球 Online 更新慢一些，两三年一次，游戏则几个月一次。游戏选错英雄会立刻暴毙，现实淘汰有滞后性，像你说的，版本更新后可能三年后才破产，但虽迟必到。

37. 邵艾伦： 成功者为什么难以改变已有观念？经历一场情伤会不会让人醒悟？如果到了马斯克的位置，您能不能做 180 度转向？这些成功者的弱点，又给年轻人留出了什么机会？

孙宇晨： 成功者也不例外。Elon Musk 坚持不健身，肌肉流失到不可挽回可能要十年、十五年，但不改变，恶果绝对会发生。越胖越打药、越打药越掉肌肉，基础代谢下降后又更容易胖，形成恶性循环。我 20 岁时很瘦很帅，还是杰尼亚中国区代言人，30 岁却突然发胖，就是肌肉流失、代谢暴跌，吃同样的东西也胖，甚至觉得喝水都胖。

他像是孙宇晨的加强版，但我 36 岁赶紧醒悟、打补丁修 bug。他如果坚持不修，系统就会反复受攻击，多少钱都守不住，连命都搭进去。现在尽早修复还来得及，但到了那个位置，只能自己说服自己，别人劝也听不进去。

即使经历情伤，我觉得也很难，因为 EGO 太大，很难承认自己公开反对过的东西是对的。能力极强，又能做 180 度转向，需要伟人级别的心胸。我现阶段可以做到，一是还不够成功；真到了马斯克的地位，也可能无法回头。二是克服大 EGO、彻底转向，本来就很难。

像邓小平从计划经济转向市场经济，把过去甚至要坐牢的人转为人大代表、带头搞经济，在那种权力和历史语境下做到，太难了。但成功者转不过弯，对年轻人反而是机会，因为他们的“待机时间”变短了。

年轻人零起步，更容易避免大 EGO。年轻、没钱、起点低不一定是坏事，反而是天大的好事。峰哥的“互联网学”就会说：没钱，明早睡马路，这是好事，因为没有包袱。马斯克、巴菲特瞧不上孙学、黄毛、薄肌，拒绝更新，年轻人却可以一听就安装，在健康这个维度上超越他们。

38. 邵艾伦： 《财富自由革命之路》十年过去，您对财富自由的理解有什么变化？请也为没听过的朋友解释一下。我理解，自律、健康、研究 AI 和获取财富会互相强化；反过来，新陈代谢下降、状态变差，也会形成恶性循环。

孙宇晨： 核心底色没变，但理论有重大更新。2016 年我年轻、代谢高、肌肉充足，薄肌补丁还不紧迫。现在 36 岁了，就火速更新，把它打进系统，又能保 44 年。薄肌理论延伸出了主动健康管理，再加上 2016 年还没有的 AI 工具，主动健康管理、财富自由和训练全部打通，试错成本大幅降低。

我去医院检查时，医生看我开的项目，就知道我用了 AI，因为普通人不会一进门就精准指名这些指标，只有专业医生才懂。我承认用了 AI，他连连夸赞。医生知道怎么做是对的，却无力推动，因为患者往往出了大事才来，平时说了也没人听。

我现在把财富自由定义为“先自由，后财富”：先拥有自由，财富只是自由的伴生品。不是先有钱才自由，而是先足够灵活、没有包袱，才能像逐水草而居一样，扑进风口获得红利。就像玩《王者荣耀》，只想带妹乱杀，却不理解底层机制、只练一个英雄，根本做不到。

自由没有门槛，是个主观选择，尤其对年轻人来说，认知提升后主动选择自由，就能拥有自由，财富是它的必然副产品。两者还会互相强化：越自由，越容易获取财富；财富越多，又扩大自由度，形成正向飞轮。健康也一样，身体好、睡得深、精力足，就能省出时间锻炼，继续螺旋上升。

负循环也会自我强化。比如马斯克胖了用司美格鲁肽、替尔泊肽，肌肉流失、代谢下降，又更容易胖。他可能还为体重下降高兴，却没意识到掉的是宝贵的肌肉，之后肌无力、坐轮椅、骨折、生病难恢复等问题都会出现。财富也是同一逻辑：买房后，维护房子消耗时间和现金，失去流动性与抓机会的能力；机会越少，财富越缩水。

大语言模型也有类似规律。初始模型与数据输入的一点差距，在 RSI（Recursive Self-Improvement，自我递归更新）中，会走出不同轨迹：聪明的模型越迭代越聪明，吸收更多高质量数据；方向错的模型越走越偏，差距被指数级拉大。所以年轻人的认知提升极其关键，比存款、学历、房车这些外在显化更深刻，理解了才能看透财富的底层源泉。

39. 邵艾伦： 我理解，薄肌可以是迈向财富自由的第一步，也是高认知、高智力和强自控力的外化，要先读薄肌圣经，学习营养学和渐进负荷。为什么说它不只是肌肉，而是一套主动健康管理和认知体系的表现？

孙宇晨： 学薄肌不只是练肌肉，而是先读基础理论，构筑身体健康的底层基座。理论建好后，薄肌就是主动健康管理的具象显现。建筑工人也有薄肌，但那是高强度体力劳动的副产物。一旦回乡、不再干工地，很快就会发福，因为没有主动健康管理、热量缺口、营养学和蛋白质摄入这些概念，一旦停工肌肉就没了。那只是重体力下脂肪少，肌肉被动显露出来，没有知识体系支撑，所以搬砖虽然带来了薄肌，却没能带来长寿和长远健康。

孙学、薄肌、黄毛理论是从根子上想通，先把地基打稳。虽然还要看我后续执行，但现在就能断言，六个月后我必将拥有薄肌。别人看大肚子可能还在嘲笑，我却觉得六个月前就已经“拥有”肌肉，因为心智模型已成，结果只是时间问题。

2016 年理论成型时，我的财富比现在差一千倍、一万倍，王思聪甩我一百条街，但我内心已经想通。不能只看当下的肌肉和财富，核心是认知体系；金钱和薄肌都是认知的物理显现。懂营养学、懂主动健康管理后练出的肌肉，与被动体力劳动露出的肌肉，是两回事。

再加上 progressive overload（渐进超负荷）：通过抗阻负荷微损肌纤维，靠蛋白质修复，实现超量恢复，形成正循环。肌肉储备越多，未来衰老或生病需要消耗时，就有足够“本金”。这背后是一整套科学体系，不是表面练一块肉。

很多人冲着泡妞、增肌来看节目，就像当年冲着搞钱听《财富自由革命之路》。看不懂的人觉得抽象就退出，真正学通的人会发现，这不单是肌肉或金钱的问题，而是底层全盘打通、一通百通。

40. 邵艾伦： 我理解，金钱是放大器，会放大原有的错误与恶习。即使王思聪、王健林这样的成功者，也未必想通了底层认知。为什么缺少相应认知，偶然得到的财富或身材也可能很快失去？

孙宇晨： 我们先从大众关心的现实痛点切入，吸引大家关注，再解决认知问题，让人用新认知处理生活里的事情。我们不是为了抽象而抽象。这套认知体系就像物理学最终收敛到几个核心的大一统公式，能够解释和指导各个分支。如果没有这个认知地基，即便机缘巧合获得财富或肌肉，也会不知不觉就失去了。

真实统计数据确实如此。中彩票就像上帝打个响指，突然赐你一身薄肌。但如果没有主动健康管理的认知，还是天天吃炸鸡、汉堡、麦当劳，熬夜不起床，最多六个月，肥膘就会卷土重来。缺乏孙学与财富自由的思维底盘时，暴富非但不是好事，反而会成为人生的诅咒。不懂底层规律的人拿到横财，不会用来再投资或自律提升，反而滑向各种放纵恶习。本来能活到 80 岁，有了横财 60 岁就暴毙了。原来一天只能吃得起一桶炸鸡，现在一口气吃十桶，劣势全被放大，财富反而成了催命符。

一切都是认知的显化：认知到位，步步向上；认知没到位，即便偶然获得财富或身材，最终也会在负循环中被摧毁。今天表面上聊薄肌，实际上聊的是地球 Online 最根本的运行逻辑。薄肌、孙学、黄毛听起来像调侃，背后却是极其本质的规律，连巴菲特和 Elon Musk 都未必想得通。

我们至少想通了一点：版本必须持续更新，不能被大 EGO 绑架。在健康和身体这个维度上，我们的认知走在了 Elon Musk、巴菲特和特朗普前面。就像古人分不清日心说和地心说，你只要懂日心说，在这项常识上就比孔子高明。认知存在代际更迭，不要妄自菲薄。学会薄肌理论与主动健康管理，就在这个维度上超越了他们。这不是夸张，而是他们不懂这个维度的科学。

41. 邵艾伦： 拥有巨大财富之后，您发现哪些东西是金钱彻底解决不了的？

孙宇晨： 依然是认知。认知只能靠自己下功夫、主动求索、认真吸收，光砸钱买不来。暴富或中彩票，缺乏认知最终还是会归零。最近红果短剧和 TapTap 上有类模拟游戏：假如突然中了 3000 万，人生会发生什么？如果模拟推演的结局是迅速破产，就说明你的认知还没有达到掌控 3000 万的量级。

这时横财就是催命符。我不是歧视任何人，而是在说这个客观规律。大家可以试试这种人生模拟器，如果玩到最后破产，就要反思：现实中给你 3000 万，很可能也是同样的结局。这就印证了我说的“先自由后财富”。

## 六、婚姻、家庭与情感

42. 邵艾伦： 财富、事业和投资中的很多问题可以通过战略推演解决，但婚姻、家庭往往更难掌控，人容易当局者迷。欧美、日韩也在经历类似的婚姻与情感危机。您现在如何看待这些关系？金钱能否解决感情问题？

孙宇晨： 我也在摸索。如果有标准答案，上个月就不会陷入那场风波了。面对记者时我很坦诚：很多事情确实分不清对错，也不知道该怎么妥善处理，所以才去问 Claude。很多人看到那篇文章，第一反应是孙宇晨又要蹭热度，甚至认为波场币没有实际价值，全靠我的名气吸引人购买。这纯属胡扯，谁能按着别人的头逼人买币？无论写文章还是当年拍巴菲特午餐，都是我在人生探索中，因为真实困惑而表达，最终自然引发社会共鸣。

如果真看懂了，我也不会抛出那个“世纪之问”：如果给了那 5000 万，她还会不会走？答案还是会走。很多博主推导过，给 5 个亿、50 亿、500 亿也一样。还有人做了套算法模型，测算换人接盘能坚持多久：我能坚持两百多天，巴菲特 300 天，Elon Musk 400 天，美联储也只能撑 600 天。这虽然是调侃，却说明了一个根本问题：感情跟拥有多少钱没有关系。

不要试图在爱情里用金钱解决问题。金钱只是放大器，爱与不爱在底层早有输入与输出，它改变不了最本质的情感定性。这是第一点。第二，感情极其主观，所以更难看清。很多情感大师给别人分析时头头是道，自己一旦坠入情网，也会被搞得五迷三道。清官难断家务事，再聪明的人也很难断清极度主观的情感。但主观不意味着没有规律，背后的机制仍然需要摸索和学习。

我不能在这方面装懂。我没结过婚，没成家，也没有孩子，只是在边缘摸索了一下。后来给胡锡进的回信里，我也坦诚说自己不懂。这种迷茫不是我一个人的问题，当代中国两亿未婚年轻人都面临这个困惑。这是全球性的时代命题，大家都在摸索，我也在探索。

43. 邵艾伦： 我之前做过一期“黄毛思维”的视频，可以私下发给您，看看是否有启发，再一起梳理情感关系背后的逻辑。婚姻家庭这块如果没理顺，人生始终会有缺失感。现在大家都在摸索，也可以先按各自的节奏探索，给彼此一点时间。您愿意继续交流吗？

孙宇晨： 你把那期视频发给我，我认真看一下。这确实需要继续摸索，是人生不可或缺的重要拼图。跟薄肌一样，从思想根源上悟透了，整个人的健康底盘才稳得住。目前我还在摸索。

## 七、人生体验、商业探索与参照系

44. 邵艾伦： 您现在认为人活着的意义是什么？真正支撑您不断向前的驱动力是什么？为什么主张先增加体验，不急着下结论？

孙宇晨： 我是一个玩家心态，相当于被扔进地球 Online 这个游戏，现在开始玩，还处于探索期。活着的意义太难回答，我不敢说已经想通了，只是逐步摸清了一些门道，开始知道这个游戏里什么东西比较关键。

这有点像大模型。为什么灌入更多数据、增加训练，模型的智商就会显著提升？哪怕问山姆·奥特曼、问达里奥，他们也回答不了。AI 可以给出回答，但内部的推导机制、逻辑链和思维链是怎样形成的，仍然是个黑盒。达里奥说要对齐、要刹车，也是因为没有搞清楚里面怎么运行。

AI 像个魔术师，往黑盒里灌数据，就能产出更聪明的 AI。但灌更多数据，它会不会向邪恶靠近？善恶如何定义、如何在数据中标记，又该怎样理解智商？连最强的研发人员也没搞清楚。很多东西只能靠猜和做实验，在第一线形成一些看法。这是个混沌体系，不懂就会产生恐惧。

我觉得人生目前也一样。我估计人类如果练了薄肌，90 到 100 岁打底，那么前 50 年可能只是一半。按照我之前孙学里那套有数学依据的理论，前 50%先观察，不急着下结论；后 50%如果出现比前面更好的、觉得对了的选项，就赶紧下结论。我们今天讲的薄肌、孙学，都是一线的体悟。没有发言权的我不说，真正悟通了才说。

我小时候想过很多人生意义，后来逐渐被打破。比如为人类、为地球做贡献。去了一趟太空后，我发现地球这个范围可能太窄了：也许过些年人类都离开地球，去火星或别的星球了。说为人类做贡献，也不一定。现在有了 AI，以后会不会出现其他智能生命体，人类未来还在不在，都不确定。所以知道得越多，越不敢下结论。

但游戏的一些规律仍然可以体会。我更深一层的领悟是 enjoy your life，去体验这个过程。前 50%的岁月用来增加体验，相当于灌数据；观察之后才有资格发表观点，后面出现更好的观点，再接着用。人生意义暂且不明，地图也不能说已经全开，我只领悟了一小部分。很多行为可以用不同理论解释，但究竟哪种理论更合适，要把时间拉长才能看清。

45. 邵艾伦： 所以可以先体验、获取更多信息，再慢慢推导意义？马斯克说过，人类生活在 simulation、也就是虚拟世界里的概率超过 99%，我们的意识可能就是游戏的一部分。您上太空也是出于这种体验心态吗？

孙宇晨： 别人解释我的成功，有一种“炒作论”：无论前段时间的风波、巴菲特午餐还是上太空，都是为了更大热度和流量，不断炒作、螺旋上升。照这个逻辑，假如我当了地球总统，为了在外星人那里提升知名度，可能还要发动银河系战争。哪怕死几百万人，最后也能被解释为：整个银河系都知道孙宇晨了。这是一种理论。

但我还有另一种理论。它未必能解释我的所有行为，却能解释上太空这件事，就是体验论。我上太空不是为了炒作，也不是为了荣誉，而是本着实验态度单纯去体验。没上去之前，对太空能作出什么评论？这样的评论很无力，不如先上去，获得更多信息再说。

有人指责我上得不够猛，应该去国际空间站、去月球，只上去一下太软了。我觉得有点苛责，因为我也不确定上太空就是对的。我先试一次，有了体验和想法，回来再消化。之后要不要去月球、更进一步，甚至去火星，可以以后再说。如果前期投入产出比算下来 OK，就先上。不是所有事情都要先想好、形成结论和明确目的，才开始做。

我不知道这个想法对不对，但对觉得生活没意义、甚至涉及抑郁症的人，我觉得这也是一种疗法。我不试图灌输什么有意义，只想说：可以先不急着自杀，不急着结束，再等一等。有什么事情必须立刻下结论？一个疗法或一件事，不一定非要明天早上就解决问题，也不一定保证有用，但可以试一试。

也不能说是在滑向不可知论，而是越来越觉得过早下结论未必有意义。新的认知是体验大于结论，这本身可能就是人生的意义。我们总想寻找意义、寻找结论，好像这样就能跳过体验，但人生本身的意义，会不会就是体验的集合？我不敢下定论，只觉得这是一种可能。

我推荐看 Rick and Morty。里面 Morty 是个小孩，Rick 是他爷爷。Morty 经常问人生有什么意义，爷爷笑而不语。无论 Morty 得出什么结论，Rick 都能立刻带他去宇宙的另一个地方找出反例，让他无法概括整个宇宙。从这个无所不知的宇宙之王的角度看，或许有点虚无。但 Rick 最终的结论，就是不再追求某种意义，整个人生是他体验的集合。

46. 邵艾伦： 您想在接下来的几十年增加体验，同时又在挣钱、发展波场、让 TRX 在美股上市。这些扩张商业版图的行为，怎样和人生体验重合？为什么您计划创业一百年？

孙宇晨： 两者是重合的。每个人不可能体验全世界所有东西，我在商业上的体验，就像博尔特在短跑上的体验：跑到 9 秒 80，能不能再跑 9 秒 70、9 秒 60、9 秒 50、9 秒 40？突破 9 秒 90 时，是牙买加最快的人；突破 9 秒 80 时，是整个美洲最快的人；突破 9 秒 70 时，已经是全人类最快的人。再往 9 秒 60、9 秒 58 突破，就是在代表全人类拓展极限。不是自己宣称代表谁，而是目标不断被突破。

企业家碰巧从事了一个职业寿命很长的行业。像巴菲特，只要愿意，可以做到生命最后一刻。我 22 岁开始创业，当时就定了一个计划：创业到 122 岁。因为那时已知的人类极限寿命，是一位法国女性活到 123 岁，我想自己不可能超过 123 岁，于是定下从 22 岁到 122 岁、创业 100 年的计划。我想打破创业时间最长的人类纪录，看看在这个时间跨度里，自己能代表人类探索到什么程度。

刚创业时说这些没有说服力。现在从 2012 年到今天，我已经创业 14 年，100 年的进度条走过了 14%。跟巴菲特比不算什么，但跟自己、跟很多没创过业的人相比，已经是一段不短的历程，而且行业还在增长，时间也能拉得很长。体育明星的运动周期可能只有十年，之后就不能做了，在这一点上我更幸运。

前段时间 C 罗来香港比赛，到我家做客，我们一起吃了两三次饭，也交流了很多人生观念。合影、签球衣只是表面，我觉得他也是体验论的践行者：进 100 球、200 球分别是什么感觉？一路推到现在 900 球，全世界都在等他进第 1000 球。这是人类极限和足球体验边界不断扩张的结果。足球给他一种使命，所以四十一二岁了还在踢。有人讽刺他干脆踢到 52 岁、102 岁，但他是在不断拓展边界。

我的商业追求也是这样，并非所有事情一开始都想好了。波场之外，我们现在也在做 B.AI。未来公司是不是一家纯区块链公司，很难下结论。伯克希尔·哈撒韦最初是纺织厂，后来才迭代成金融巨头、投资公司。波场和我未来可能继续做区块链，也可能做 AI，甚至宇宙殖民。但有一点不变：在体验的范围内不断拓展边界，把我最初设想的 100 年创业过程推到极致。

47. 邵艾伦： 您是在把金钱当作商业游戏的积分，不断测试边界，比如踢进 900 个球对应赚到 900 亿。这个数字有没有极限？

孙宇晨： 我和 AI 讨论过，这个数字不是无穷大，肯定有边界。我问它：世界首富埃隆·马斯克大概赚两千亿美金，为什么没有人赚到一万亿、五万亿，再继续往上？AI 给的答案是，赚多少钱不重要，金钱是在衡量可接触范围内经济活动的总值。

比如美国一年 GDP 大概十几二十万亿，中国十几万亿，全球加起来四五十万亿美金。一个人再能赚钱，最多赚全球 GDP 的 1%，不可能全地球的钱都让一个人赚走。总值如果是 50 万亿，1%就决定了最多赚 5000 亿。

科技会提升天花板。没有 AI 时，赚最多钱的是苹果，智能手机做到 4 万亿美金市值就到了极限。有了 AI，未来集中度会更高，新行业不排除能到 10 万亿，但仍然有极限，只是极限不断被推高。比如未来发现外星人、开始星际贸易，全球经济可能从 50 万亿膨胀到 1000 万亿。这些都是动态的，金钱只是衡量动态经济活动的度量衡，是一个数值，除此之外不代表什么。

48. 邵艾伦： 您希望后人记住自己做成了什么？从您身上能看到马斯克、巴菲特和特朗普三人的影子，他们分别给您什么参照？

孙宇晨： 我想成为一个参照系。比如 50 年后的企业家会说，想成为像孙宇晨这样的人，因为我在人生坐标中有某种定义的价值。没有人生来就是 Benchmark，大家都以别人为 Benchmark，我希望未来有人说想成为 Justin Sun、想成为孙宇晨。

在我之前，我也有自己的偶像和参照。2012 年我就开始关注埃隆·马斯克，觉得他是乔布斯去世后，最可能成为美国商业领袖的人。当时特斯拉市值只有二三十亿美金，远不如苹果，马斯克也刚起步，离首富还很远，但我认为他很有潜力，一直把他当作 Benchmark，也了解他很多细节。

我的三个主要参照是 Elon Musk、Warren Buffett 和 Donald Trump，碰巧都是宾大毕业的，并不是刻意找校友。他们代表不同象限：马斯克代表高精尖科技和 engineer。这个时代是工程师的时代，我的员工主力也是 software engineer。我向他学习怎样做工程、怎样成为优秀的工程师。

巴菲特代表长青、长期主义和金融。他的滚雪球雪坡理论是，前面怎么做不重要，只要雪坡足够长、雪球滚得足够久，优势就会被无限放大。所以他重视提前布局、长期坚持和超长待机。

特朗普首先代表个人 IP 运作和商业影响力的极致。他是全世界最有名的 name brand，可能也是第一个直接把姓氏当品牌运营的人。法拉利、香奈儿同样是创始人的姓氏，但大家先知道跑车、经典包包，再知道创始人。Trump 相反，大家先知道他本人，再去追他的产品。他直接运营个人，首先让人想到的不是某个产品，而是他自己。

他还代表跨界。巴菲特最专注于做生意，马斯克稍微跨了一些，而 Trump 的跨界最广：政治、经济、娱乐圈、选美、赌场、WWE、综艺《学徒》（The Apprentice），最终爆发出很强的综合能力。我的商业思想基本盘，就是从这三个人身上吸收的。巴菲特离我最近，因为我们都做金融；但我的个性和做事风格又有点像 Elon Musk 和 Trump。我也不会轻易下结论。

49. 邵艾伦： 这三个人既有共通的底层逻辑，又常常彼此看不上。在我看来，他们还有一个共同弱点：都没练薄肌。您怎样吸收他们各自的长处，而不受门派偏见和 EGO 限制？

孙宇晨： 如果只拜一位老师，他经常会告诉你别人的都是错的。比如巴菲特相当看不起特朗普，认为商人就该专注做生意，老老实实做价值投资，乱跨界既浪费时间，也会削弱商业基本盘。他为了专注，连奥马哈都不愿离开，觉得伯克希尔·哈撒韦一旦搬到纽约，每天有参加不完的晚宴和应酬，会造成 distraction。哪怕公司已是全世界最大的金融公司之一，他仍然留在奥马哈。

每个人有自己的选择，我不敢轻易判断谁对谁错。就像青城派、华山派、桃花岛都在练武功，不知道哪一门练通了就能成为武林霸主。我选择三家一起练：学马斯克的工程，学巴菲特的金融和长赛道，再学特朗普的跨界和个人 IP。

他们之间也相通。我相信马斯克也借鉴了特朗普不少，他也是个人 IP 运营者和跨界高手，做电动车、做 AI，还收购了社交平台 X。收购 X、帮助特朗普竞选究竟对不对，大家看法不同，但都可以观察、学习。作为后辈，看着他们往前走，就像航海时有北极星，前面有灯塔，不至于迷航。

我一边吸收他们的经验，一边形成自己的方法论。孙学不是凭空来的，我希望未来能为中国乃至全球的创业者提供借鉴，让他们把我也当成一个 Benchmark。我身上还有中国商业的烙印，主要来自马云，我以前在湖畔大学读过书。不要过早把自己的思维和门派定型。金庸小说里最厉害的高手，往往融合了各门派绝学，单练一门很难登峰造极。

各门派各有所长，不能轻易断言别人不靠谱。巴菲特可能觉得特朗普跨界终会垮，但特朗普在竞选总统时爆发了。这又回到 EGO：越成功，执念和包袱越大，越难吸收别人的长处。巴菲特瞧不上马斯克和特朗普，否则早就投资马斯克了，我也向他提过这个建议。马斯克同样瞧不上巴菲特，有点像应激反应：比尔·盖茨、巴菲特这些老钱看不上他，他也烦老钱，彼此鄙视。

我学的这几门武功，老师之间互相看不上，但他们的轨迹我都看在眼里，每个人都有独到之处，可以把精髓吸收过来。唯一的共性是没练薄肌。触类旁通、多吸收很重要，不要过早定型、先入为主；一开始就盲目否定，很容易错过真相。

## 八、财富自由之后：创造与消费

50. 邵艾伦： 很多人想财富自由以后躺平，但您说整天玩也会玩吐，不符合人的需求。财富自由后该怎样继续探索？您为什么反而想去上班，还喜欢各种人生模拟器？

孙宇晨： 人往往是缺什么想什么：上班的人不想上班，我这种没上过班的反而特别想去。我现在处于迷茫期，如果能入职 OpenAI 或 Anthropic，我愿意为这个 offer 给五千万美金，一分工资不要，按时完成 KPI。但他们不收我，怕我偷师，学会之后就把 B.AI 做大了。

我毕业就创业，从来没有真正上过班，不了解顶级科技公司的内部运转，也没有一手信息。面试员工、看网络资讯都能了解一些，但缺乏第一视角。我一直站在老板的位置往下看，缺少普通员工从下往上的视角，所以想亲自体验顶级大厂的管理。

一直打工的人，自下而上的视角看腻了，缺少自上而下的掌控感；我缺的却是自下而上的真实执行感。财富自由是一种迷思（myth）：以为到达彼岸就圆满了，到了之后又发现缺少另一种体验。大公司的流程和执行会建立一种肌肉记忆，亲身经历过才懂；但一直打工，又会觉得枯燥、受管制。人生是在寻找互补。

所以我很喜欢玩各种模拟器。不亲自玩，就进不去那个视角；玩过之后，很多事情会豁然开朗。即使模拟器把现实体验砍得只剩百分之二十，这百分之二十对我也很关键，因为它提供了新视角。我玩过打工模拟器，也玩过流浪汉模拟器，在城市里流浪，靠微薄救济金生活。它们让我体会到，自己平时忽视的东西，在别人眼里可能极其宝贵。

51. 邵艾伦： 财富自由像是一张探索人生的入场券。如果不追求商业扩张，是否可以不再以金钱为 Benchmark，而是自己设定支线任务，比如周游世界、坐遍火车、探索太空、跑马拉松——虽然不提倡——或练薄肌？是不是不必先想清楚意义，再出发？

孙宇晨： 每个人的体验模式不同。我有位同样上过太空、做 Crypto 的华人朋友王纯，就不走商业 IP 路线，非常低调，甚至花钱让媒体删掉名字。他的体验是字面意义上的周游世界，每个国家都要去，每趟知名火车都要坐，还去过挪威、去南极做极端徒步。这些都是我没经历过的维度。我们在 Crypto 和太空探索上有交集，其他生活面向却各有精彩。

本来就没有标准答案。成为版本答案的人，事先也不知道自己是对的。爱因斯坦没有先发誓要成为最伟大的物理学家。他最早是瑞士专利局的审查员，在那期间发现光速不变原理和相对论，后来才去大学当教授。特朗普起初做商业、办选美、开赌场、搞 WWE 和真人秀，可能只是出于爱高调、出风头的性格，后来关注政治，一路成为总统。

很多事情是柳暗花明、触类旁通，并非为了功利目标才去做。难道特朗普一定要成为总统，之前的事情才有意义？不是，另一个平行时空里，他可能走出另一条路。每个人都有自己设定的地图。

诺贝尔也是这样。他发明黄色炸药后，因为炸死了很多人，被骂黑心，报纸甚至叫他“死亡商人”（The Merchant of Death）。别人拿炸药杀戮，他也拦不住。临终时，他立遗嘱用遗产设立五个奖项。一百多年后，大家记住的是崇高、权威的诺贝尔奖，谁还在乎“死亡商人”的外号？他自己没有搞过理论学术，只是发明炸药的化学家，也不知道这份遗嘱能延续一百多年、奖励无数先驱。

人生际遇很奇妙，一开始死磕某种宏大的意义，往往意义不大。体验本身可能就是意义，先上路比先想清楚为什么上路更重要。很多事情在路上机缘巧合就碰到了，不要先入为主。

很多历史人物最终被铭记的成就，跟最初的设想也无关。南唐后主李煜亡了国，妻子被宋朝皇帝抢走，国破家亡让他极度悲痛，于是写词表达，并不是为了炒作。“问君能有几多愁？恰似一江春水向东流”，字字泣血，引起共鸣，让他成为中国历史上最有名的词人。皇帝没当好，词却名垂千古，成了宋词的代表人物。宋朝皇帝抢了江山和妻子，却没想到宋词这个巅峰被李煜统治了。

李煜受过文化教育，后来的经历给作品增添了魅力，碰巧成为千古名家。如果是文盲，他写不出词；但如果从一开始就立志做天下第一词人，天天闭门狂写，也成不了。文学是经历和文学功底共同磨砺的结果。很多事情都是随机碰撞，不是一开始规划好的。我在北大学历史，从历史角度看，人生更大程度上是个混沌系统。

52. 邵艾伦： 但从您的道路来看，您在模仿那三位商业人物，也确实向他们靠近，似乎仍是按预先设计的战略执行。这与您说的人生随机性、混沌性怎样兼容？

孙宇晨： 那是你站在现在的视角看我。也许一百年后的年轻人知道孙宇晨，只是因为孙宇晨奖表彰了很多人，早期争议已经没人在乎，就像诺贝尔一样。大家把他看作大化学家，而他自己却因炸药造成的伤亡深感负疚。不同时间，看事情的角度完全不同。

每个人心中都有北极星，它带来指引，也带来变量。比如我设立孙宇晨奖时讲过，诺贝尔奖的设置与诺贝尔本人的偏好有关。他做炸药、做化学，不相信纯理论，所以没有设数学奖，而是奖励物理、化学等能直接改变现实生活的实验科学。在他看来，纯理论不算改变世界，生产炸药才是人类改变自然最极端的方式。因此，奖项带有很深的个人色彩。

所有事都与之前的人生经历有关。李煜的词与当皇帝、亡国有关，但词和亡国又是两回事；诺贝尔和诺贝尔奖也是两回事，彼此存在共鸣共生的共轭关系。我坚信，只要人生体验的大方向是对的，就没有哪段体验是作废的。

53. 邵艾伦： 怎样定义正确的大方向？意义一定要建立在给世界创造价值之上吗，还是纯粹环球旅行、增加自己的体验也可以？

孙宇晨： 比如我以那三个人为参照，确立一个大致方向，再沿着这个方向尽情体验，不必纠结眼前是否绝对精确。也不一定要给世界创造宏大价值，因为价值的定义很主观。很多人试图定义意义，最后发现那只是个人偏好。

连诺贝尔也试图精确定义价值，认为必须改变世界。在他眼里，数学解出一道题没有影响，炸药能把五十米的山炸平一半，才算改变世界。但后来的历史证明，这种定义很狭隘，数学改变世界的威力一点不比炸药差。数学本来不需要放进炸药的坐标系比较，但即使按诺贝尔的标准，数学最终也改变了世界。加密货币就是数学加密算法的产物。

所以不要过度框定意义，有些定义本身可能就是错的。只要大方向有积极意义，就可以放心尝试。每个人有自己的方向，比如我对 AI、Crypto 感兴趣，就去做这些。大方向没问题，就尽情体验，过度定义意义往往是徒劳的。

54. 邵艾伦： 有条件自由选择以后，不能只是偷懒和消费享受，应该多创造、少消费。这里怎样区分创造与消费？像哈兰德的父亲培养后代，教育和传承也算创造吗？

孙宇晨： 单纯躺平确实没有意义。人类活动大致分为创造和消费，应该以创造为主，单纯的消费没有价值。李煜的价值在于创造了一首首好词，亡国的昏君很多，单纯亡国只是消耗，把苦难转化成诗词才是创造。

哈兰德的父亲也是球员，踢得一般，但一直热爱足球。有了儿子后悉心辅导，虽然自己不算出彩，儿子却成为世界巨星，身上带着父亲深刻的烙印。很多体验的意义未必直接显现在自己身上，你的选择很可能改变后代的命运。生养后代、传承技艺和教育都是创造。哈兰德沿用父亲的姓氏，也让这个姓氏留在了足球史上。

55. 邵艾伦： 追求百分之百的纯创造太残忍，但现代人又普遍创造不够、消费太多。两者该怎样平衡？

孙宇晨： 应该以创造为主，但创造和消费都存在边际效用递减。《财富自由之路》里讲过：单纯消费久了，会觉得没意思，需要回到创造；持续高强度工作，又会头晕脑胀，需要适当消费来回血。两者相辅相成，不是谁压制谁。完全不消费也不符合人性，缺乏充足的消费反而会压抑创造力。

56. 邵艾伦： 刚学到的新认知，分享时往往最鲜活，说出来也能巩固认知。这些内容都来自真实经历，您之前的文章是否也由 AI 帮忙润色？AI 能代替切身体验吗？

孙宇晨： 我也很受启发。你的薄肌圣经里很多接地气的理论更新了我的认知，我们相互激发，才聊出了这么多。这是相互给予的过程。我在一线不断学习、修正，这些真实的探索经验对年轻人应该也有参考价值。能够既贴近现实痛点，又把思维展开，核心在于有一线体验，不是光靠嘴说。

比如之前那场风波写的文章，大几千字、快一万字，都是生活的沉淀。苦难是文学的温床，没有经历就写不出来，很多人却以为是 AI 写的。AI 确实帮我 proofread、校阅，但整体思考框架和切身感受，如果没有人类真实体验的输入，AI 无法体验。

就像之前讲 OpenAI，必须先有纽约数学家的高质量输入。缺少输入、让 AI 硬编，它推导不出来，因为语料库里没有。有了核心输入，AI 学会之后才能触类旁通。

57. 邵艾伦： 希望您过段时间再来交流，结合反馈和新感悟继续更新认知。一年前我曾发过自荐信，希望加入您的团队，在个人 IP、传播和内容上提供帮助。现在可以再发给您吗，需要润色吗？我也把两性认知和“黄毛思维”的视频一并发给您，期待尽快看到薄肌版的孙哥。您还有什么补充？

孙宇晨： 可以，内容方面发给我看看。自荐信不用润色，直接把原来的截图发给我，相关视频也一并发来。我没有其他补充了。薄肌版应该快了，认知已经到位，只是时间问题。
