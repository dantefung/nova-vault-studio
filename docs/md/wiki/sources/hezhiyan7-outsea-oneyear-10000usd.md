## 文章概览

droidHZ (@hezhiyan7) 在出海 1 周年、3 月达到月入万刀后，把一整年的微信公众号每日分享按业务模块做了系统化整理。这是独立网站出海创业者的实战知识地图，**不是一篇教程，是 200+ 篇实战文章的分类索引**。

每篇文章链接都指向他微信公众号的具体文章，主题覆盖从需求挖掘到支付收款的全链路。

最后他还创建了配套导航站 **aichuhai.dev**（AI 出海），把所有文章做了二次分类整理，并开放话题提交入口。

## 模块详解 + 关键洞察

### 1. 需求挖掘（28 篇）

最高频模块，反应出独立网站出海的本质问题——**先有真需求，再有产品**。

核心方法集：
- **搜索语法** 找新词（Google dorks）
- **Similarweb 着陆页找词**（竞品流量结构反推）
- **词根扩展**（人群/产品/场景多维拆解）
- **外链找需求**（Referral source 反查竞品流量来源）
- **Discord/Reddit 收集抱怨**（用户原声 = 痛点金矿）
- **HeyGen 案例分享**（AI 工具找需求）
- **GSC 出词反推**（基于自己网站 Google Search Console 反向新增内页）

特别值得注意：
- **卖空气验证需求**（最低成本 MVP）
- **基于人群找细分需求**（场景化切割）
- **需求的痛点决定了转化率**（再小的痛点，只要准就值钱）

### 2. SEO（约 35 篇，最大模块）

**这是这个地图中最大的模块**，也对独立网站最关键——绝大部分独立网站收入依赖 SEO 流量。

核心方法集：
- **图片也能做 SEO**（图片搜索流量被低估）
- **sitemap 使用小技巧**（提交更精细的 URL）
- **手动请求索引**（Search Console 加速收录）
- **低竞争小词** —— 8 条外链拿下 41K 月访问量的案例
- **搜索引擎爬虫访问说明书**（理解爬虫 = SEO 心智）
- **semrush 查看主要页面**（竞品流量结构）
- **Canonical 标签**（避免重复内容惩罚）
- **typo 词的妙用**（拼写错误的低竞争长尾）
- **多语言适配**（多语种站 = 自然流量 X 倍）
- **基于 GSC 的出词数据反向新增内页**（用已有数据找新词）

AI 时代新玩法：
- **布局 AI 搜索**（让网站被 ChatGPT/Perplexity 引用）
- **如何看 AI 流量，做好 GEO**（Generative Engine Optimization）
- **AITDK SEO 内容的生成和重写**（AI 辅助内容生产）
- **使用爬虫参考 SEO 内容**（竞品内容分析）
- **推荐一个 SEO skill**（把最佳实践封装为 Claude Skill）

### 3. 开发（约 22 篇）

工具栈关键词：**Next.js + Cloudflare + Stripe + Neon + Vercel**。

核心方法集：
- **注意后端渲染**（SSR/SSG 选择）
- **Cloudflare R2 白嫖存储**（低成本对象存储）
- **白嫖 Neon 数据库**（免费 Postgres 配额）
- **一键部署上线**（Vercel/CF Pages）
- **创建 Claude Code 命令**（把常用命令变成快捷指令）
- **创建 Claude Skill**（重复操作封装）
- **跟着 AI 快速部署服务器**（AI 协作运维）
- **Cloudflare 绑定域名邮箱**
- **让 AI 了解你的项目**（CLAUDE.md + 项目记忆）

避坑指南：
- **重大 Next.js 漏洞问题，小心账单爆炸**
- **分享遇到的 3 个 Vercel 账单暴涨的问题**
- **Stripe 重复接入新网站**（多站复用一个账户）

### 4. 数据分析（约 11 篇）

工具链：**Google Analytics + Microsoft Clarity + Stripe Data + Semrush**。

核心方法：
- **常见的数据分析工具**（GA4 事件追踪）
- **网页性能分析检测**（Core Web Vitals）
- **Google Analysis 事件上报**（自定义事件埋点）
- **热力图分析用户行为**（Clarity）
- **GA 对比查看不同用户群数据表现**（分群对比）
- **Stripe API 分析数据**（付费用户行为）
- **AI 看录屏发现网站优化点**（Clarity + GPT）
- **AI 帮你查看分析网站数据**（自然语言查询数据）
- **你的用户到底值不值钱**（LTV 计算）
- **提升用户留存**（留存 = 复利）
- **网站变现效率**（单位流量的收入）
- **提升网站停留时长小技巧**
- **计算网站的获客成本**（CAC / LTV 闭环）

## 核心洞察提炼

### 1. 这是一个**创业技能树地图**

12 个模块 200+ 篇文章的覆盖密度 —— 这个地图本身就是一份**完整的 indie 创业能力清单**。

如果你是新加入 indie 创业者：
- **先读需求挖掘 + SEO + 部署上线**（上手期）
- **再做产品设计 + 数据分析**（成长期）
- **后做流量 + 外链 + ads**（放大期）
- **全程配合支付 + 工具推荐 + 复盘总结**（基础设施）

### 2. SEO 是最大模块 = 独立网站的生命线

约 35 篇 SEO 文章占 1/6 篇幅，**反映独立站流量高度依赖搜索引擎**。

AI 时代新变量：
- **G**enerative **E**ngine **O**ptimization（GEO）成为新战场
- **AI 搜索布局** = 让网站被 ChatGPT/Claude/Perplexity 引用
- **长尾 + 低竞争词** 仍然是最稳妥的流量入口

### 3. AI 工具深度嵌入全流程

AI 在每个模块都有对应文章：
- **需求挖掘**：grok 上奏折监测新词、找需求 AI 导航站
- **SEO**：AITDK 内容生成、使用爬虫参考、推荐 SEO skill、AI 流量监测
- **开发**：Claude Code 命令/技能封装、AI 编程、AI 帮你部署服务器
- **数据分析**：AI 看录屏、AI 帮你查数据
- **产品设计**：用 claude design、提升 AI 审美

**核心哲学：AI 不是单点工具，是基础设施。**

### 4. 跨境合规闭环 = 必选

**香港银行 / 香港 Stripe / 水星银行 / 美国 LLC / PayPal / Stripe / Creem** —— 这是一条完整的"个人出海商业账户"路径。

任何做独立站的个人都必须打通这条线。

### 5. 复盘模块最后说"种树故事"

> "网站出海就是一个种树的故事，浇水施肥，静待开花结果。"

这反映了 indie 创业的真正心态：**慢就是快，资产型增长**。1 年达到月入万刀不是例外，是正常节奏；但前提是**不停地浇水施肥，不问何时开花**。
