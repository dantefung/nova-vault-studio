# 注定贫穷的性格——反驳性人格

前几天我的学员群里在讨论一件事，一个黑人写手在学员A的帖子底下应聘



学员B说：我跟你打赌10块钱，这个人你用不起，他肯定价格很贵



我当时看见就很疑惑



我们英文类内容经常会用到黑人写手，不仅服务态度超级好，让修改就立马修改，



而且跑代码、做数据分析、图表样样精通，价格也比国内写手低廉非常多



我们那一单收款7000元，2000块这个写手就全包搞定了



我直接说，你这个思维很危险：



不是超出你认知范围的事情就是不存在的，为什么要这么傲慢



有时候刷一些社媒，有些人确实在认真的分享自己怎么做的小生意，但底下总有人会在3s之内0延迟开怼



哪怕帖主把数据盘的清清楚楚明明白白，也会觉得对方在扯淡，不问业务的逻辑是怎么样的，也不问用户体量和客单价



反正只要我不知道，一定是不可能的



当然，学员B后面很快就承认错误并且改正了



但是从这几件事，让我想起了心理学里有一个词，叫“反驳性人格”



当面对于自身信息相悖的事实时，有些人会习惯性的固执己见和防御性极强，一定要靠自己的那点儿少的可怜的知识体系争出是非对错



简单来说，就是一种本能式的"否定别人"。 遇到新鲜观点或陌生事实，不是先了解，而是第一反应——不可能。



这种人格有几个典型特征：



1.喜欢争论没有意义的输赢，仅仅是为了证明自己是对的



2.不愿意承认错误或者道歉，思维极度的封闭



我遇到过一些来向我咨询AI写作的意向，无论我讲什么都有办法驳斥我的观点："市场是不是已经饱和了？""为什么那么多人自己知道AI不会用？""这个真的能赚到钱吗？"



最后我实在是没招儿了，直接说："那你觉得你是对的就听你的吧，你比较懂。"



过了半年，同样时间来找我的一些不纠结不内耗的女生已经在半年内变现六位数，他又来问我："这半年我工作很不顺利，现在入局还来得及吗？市场会不会饱和了？"



我有点忍不了了：我觉得你去哪个市场，哪个市场就是饱和的市场



反驳性人格对事情的理解和判断完全不看数据，不看逻辑，抗拒一切外界信息的介入



所以这些人的成长会在自己原本的世界里打圈，不会产生新的变化



我自己也有过这样的时刻



以前的我很喜欢杠，总认为自己永远是对的，或者说话总是拿“不是”开头



有些朋友因为在我这里永远得不到肯定，所以就不爱跟我聊天



导致错过了很多增长的机会，比如有个大佬早八百年就告诉我做代写应该考虑海外市场



我当时用了800条理由解释为什么这个事做不了，现在真的只想扇自己一巴掌



如果现在再遇到和自己认知不符的事，我先问"为什么"，他是怎么思考的，我会研究和琢磨他给出这个意见背后更深层的动机



我们可以先把别人的逻辑听清楚，再决定信或不信



我时常告诫自己：无论听到什么观点，哪怕是截然相反的两种声音，我都可以先收藏起来，不急着下判断，等着未来的子弹正中眉心



我认识的绝大多数有所成就的大佬，都有一个共同特点：极其谦和和开放，永远保持着空杯心态



像亦仁这种美股一个月被动收益比我吭哧吭哧干一年都多的人，也会花一小时听我们聊乱七八糟的小生意



整个过程完全的倾听和接受，不强行教导我们什么一定是对的



所以，以后在驳斥别人的时候，可以先对自己发出灵魂三问：



我很牛吗？



我算哪块小饼干？



我知道的就是全世界吗？
