# Viking（@vikingmute）：保持专注的三种方式——真正的写作、每次一个项目、认真看老美剧

> Viking 保持专注的三件事：30 分钟真正的写作（Obsidian 全屏、进入心流、写人味的文字）、一次只做一个项目（等待时盯着 agent 的思考过程而不刷手机 / 不看网页、不并行多于一个）、看之前爱过的美剧且全程不用手机对 agent 发号施令——作者把「不刷手机」当成三件事的共同底层纪律。

<!-- more -->

我最近保持专注的三种方式，

1 写作半个小时，真正的写作，打开 Obsidian，全屏，别的啥都不看，随便写今天的见闻，感想，真实的文字，进入心流，写人味的文字应该是人类文明最后之光了吧。

2 一个小时每次只做一个项目，等待的时候不刷手机，不看网页，看看它的思考过程，实现方式，思考下一步的规划和其中的问题，不要并行做多于一个项目。

3 看之前看过的很爱的美剧，期间不玩手机，不干别的，不用手机对 agent 发号施令，认真看，感受细节，感受对话，感受美景，再发掘一些之前没注意到的点和细节。
