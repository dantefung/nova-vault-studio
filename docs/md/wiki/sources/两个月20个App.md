# 两个月做了20多个App，我是怎么用AI把开发变成流水线的

## 04 App 工厂（App Factory）

**Monorepo 架构**：所有 20+ 个 iOS App 放在一个 monorepo 里，有 Swift 写的、Flutter 写的、Expo 写的。

**代码模板**：创建了一个符合自己设计风格的代码模板，所有 App 基本上都叫 "One" 开头（OneFocus、OneMarkup、OneMusic 等），基于模板快速新建。

**Harness**：注册云服务 → 接入 MCP → 安装 skills → 把项目经验总结为 skill → 总结为大的模板。

## 05 从 idea 到上架的全自动流水线

**核心 Skill：create iOS App**

完整流程（全自动，中间不需要作者操作）：

```
调研 → 需求文档 → Imagegen 原型 → 从模板新建 → 校正测试 → 发布
```

每个阶段详解：

1. **调研**：查看竞品内容大概什么样
2. **需求文档**：写出需求
3. **Imagegen 原型图**：生成原型
4. **从代码模板创建 App**：所有坑都浓缩在 skill 里，避免重复犯错
5. **校正测试**：检查是否符合需求文档
6. **发布**：使用 ASC skill + CLI 自动操作 App Store 上架

> 我现在可以说我要开发一个相机整理 App，AI 就可以基于这套 skills 完整的从 0 到 1 去上架一个 iOS App，中间不需要我做任何操作。

**小程序同理**：提前搭建 Harness → 选技术栈 → 安装 skill/MCP → 批量产出（会员社区源码、缝纫社区、个人名片小程序等），对应 skill 包括小程序云开发、微信支付、微信 CSS、Vite 等。

> **搭建好 Harness，并且根据不断实操经验浓缩出一个又一个自动化的 Skills，是我快速烧 Token、快速能够做大量 App 的关键。**

**日常工作流**：有想法或额度重置 → 从 idea 库选一个 App → 丢给 AI → AI 运行十几二十个小时 → 最终只要在手机上打开 App 测试。

## 06 宣发做得很少

意识到宣发做得很差才录了这个视频。正在用 Grok 自动生成宣发视频（先跟 AI 讨论方向，推荐了 Hyperframe、OpenMontage 等工具）。

自媒体数据：B 站常年阅读量 1000+，偶尔两三万；抖音看情况，偶尔有爆款。

> 老实讲我现在宣发做的是比较糟糕。

## 07 内耗，以及那句话

**内耗是常态**：一天有 50% 都在内耗。经常做 AI 心理疗愈，花很多时间跟 AI 说哪些事很抗拒、怎么赚钱、对未来感到迷茫。

**核心焦虑**：

> 我做了这么多 App，但收入也不是很高，也好像也没有很多用户在用。我烧了这么多 Token 有用吗？我熬夜熬这么多次，我现在做了这么多东西，会不会 AI 迭代一个版本，我的做事已经完全没有意义了？因为 AI 完全可以取代我。

**既想要快乐又想要赚钱**："既要又要的人"——要做喜欢的事，同时想赚钱。

**自我认知**：花了一年了发现不适合社交，是 i 人。拒绝过很多外包机会，不適合做社区创业。

**支撑他的那句话**：

> **人生短短几十年，想他妈怎么干就怎么干，哪管那么多。**

"假设你只剩下一年的寿命，你会做点什么？"这个问题帮他排除了很多事情——原来那么多事情是可以不做的。可以不上班，可以放弃很多看起来重要但实际不重要的事情。

> 至少我现在在用我喜欢的方式做我喜欢的事情。我享受当下那就可以了。

## 关键洞察

1. **740 亿 Token / 月支 4000-5000 元**：一个人做 20+ App 的 Token 成本和订阅成本

3. **全自动流水线**：调研→需求→原型→新建→测试→发布，中间不需要人工操作，AI 运行 10-20 小时
4. **多机并行**：3 台 Mac + 1 台 Windows 同时跑多个 Agent，一台不够用
5. **工具矩阵**：Codex（主力）+ Claude + Grok + Kimi + Cursor + OpenCode，多模型互补
6. **核心瓶颈转向**：开发不再是瓶颈，**宣发和推向用户才是真正缺的**
7. **收入真实**：3000 下载 + 100 美元，"每天赚个拼好饭的价钱"——独立开发收入预期要务实
8. **内耗是独立开发者的常态**：50% 的时间在自我怀疑，AI 心理疗愈也是一种方式
9. **"人生短短几十年，想他妈怎么干就怎么干"**：终极决策过滤器——假设只剩一年寿命，哪些事是可以不做的？
10. **i 人独立开发的优势**：不需要社交、不需要社交、不需要管理，一个人一台流水线
