# 退学边缘的五天里，我得到了一份让我复用终身的资产

前两天我遇到了一件对我来讲的大事。



熟悉我的朋友应该知道，我自从上大学和创业以来，一直在用各种手段游走于规则边缘，而且几乎平衡的非常好。



但是这个平衡前几天被打破了，我翻车了。



这个具体的故事我不想再去讲，大概就是因为我做错了一个很小的决定，让我的学业严重偏离了我预设的轨道，发生了一系列蝴蝶效应。



在情绪起伏最严重的两天里，我产生了极端想法——实在不行退学吧，反正没有毕业证我也能创业。



事实是，我又放不下我漫长的沉没成本，我已经付出了大量的时间和金钱，这个时候放弃又太可惜。



在几天时间内，我陷入了巨大的纠结，内耗，痛苦，我用了很多方式，比如去迪士尼骗自己遗忘，比如去找一些长辈谈心，始终是治标不治本。



于是我找著名的心力教练易仁永澄老师约了一次咨询。



结果对我来讲是远超预期的。



很多朋友都会好奇，我们聊了什么？



下面我会从双视角开展，复盘这一个小时的对话

我和老师聊起了情绪困扰的根源，尽管事件的结果已摆在眼前，但我依然心神不宁了许多天。



老师给了我一个很有意思的视角，他说，这其实是上天在通过这件事情告诉你一些信息。



我说，是的。我也觉得这次的事件结果最差也能接受，但却始终没理解透这件事到底要告诉我什么。



他说，那是因为你并没有真正去想到最坏的可能。



万一这次帮我的那个人真的出了意外呢？万一她被发现替代后被退学呢？万一她无法承受事实选择了极端的方式呢？



这些超出我承受范围的可能性，其实都是有可能性存在的。



我做出错误决策的真正原因，就是我从来没有真正去想到过这些最糟糕的结果。



为什么我没有想到？因为我在做决策之前，根本没有去收集足够的信息。



其实，如果我提前去问够10个大学老师，答案就会非常清晰，甚至许多比我维度高的人，会从更细的颗粒度看到我看不到的风险，他们的建议能更好地引导我做出正确的选择。



但我却只受了和我同样视野的人影响，凭着当时的情绪草率地做出了决定。



这件事也让我发现，我之所以一直感到不舒服，是因为我总把学历和创业放在对立面。



我表面上在机械地执行着拿学历的任务，心里却全是对学校的抵触与不满。



究其根源，是我自己的短线思维。我只关注眼前三五年的图景，却没有认真思考过10年、20年后的样子。



就像很多人为了短期的收益不断熬夜做项目，忽略了健康，结果到了财富巅峰却没有一个健康的身体去享受成果。



昨天柠柠和我聊起这件事时，她说：



未来，你真的没有任何移民、落户，或者去更高维度平台上和高校甚至高阶企业合作的可能性或者打算吗？



如果你还在意这个可能性，就不应该放弃学历。



我一直觉得自己是草台班子，没学历也能继续赚钱，却从未认真想过自己完全有可能成为正规军，走上更广阔的舞台。



我总觉得拿个毕业证就是为了落户，三五年后的图景覆盖了二十年后的图景，导致我一直在短视。



也可能我隐隐看到了20年后的蓝图，但我没有像对三五年后的景象那么确定，所以会有这种强烈的拧巴和内耗。



如果我坚信这个可能性，我才会愿意去付出我的时间精力，去做必须要做的非我不可的这些事情



就像打德州一样，眼下手里的牌似乎大得没边就盲目梭哈，这不过是赌徒心理。



从长远看，绝对不可持续。



老师告诉我，上天其实一直是偏爱我的。



它没有让我遭遇最坏的结果，而是一次次用温和但严肃的方式提醒我：在做重大决定之前，多问几句，去预见那些自己根本无法承担的极端风险。
