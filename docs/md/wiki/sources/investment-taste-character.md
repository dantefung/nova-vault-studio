# 投资中的品味&人的品性

Viking投资小记（第1137期）2026年4月17日



关键词：投资中的品味



1.今天和朋友聊段永平，聊价值投资，在咖啡厅聊了蛮久。



发现这些简单的道理越品越有味，无论是人还是公司，其实最重要的就是看这个人的品质、品性怎么样。



靠不靠谱？是不是坦诚？是不是会认错？有没有耐心？能力绝对不是首位的。



就我之前犯的一些错误，比如说去跟一些人合作，可能就把能力放在第一位。但有些人虽然能力很强，但他不靠谱，最后我还是亏了很多钱。



2.其实上市公司也是一样的。要先看这家公司的企业文化怎么样，是不是诚实的、靠谱的、不做恶的？看管理层怎么样？看商业模式怎么样？



我觉得只有把这些作为前置条件，然后去筛出来那些公司，才能列入你的好公司列表。然后再从这些好公司当中去选那些更有竞争力的、更有潜力的、赔率更高的。必须通过前面这一关严格的筛选，这样你的失败率就会大大降低。



比如说我们看到一些公司，可能会觉得这家公司跌了很多了，价格很合适。但如果这家公司管理层不靠谱，你真的敢买吗？或者说你是不是在赌？



3.我觉得这些道理真的是大道至简。巴菲特在1998年佛罗里达大学的演讲，其实就是这个意思。你班上有50个同学，你必须去投资其中5个同学，把钱都交给他们。你会交给什么样的人？你会交给能力最强的人吗？还是交给靠谱负责任的人？还是交给那个阴险狡诈的人？最终你会发现你交出去的那些人的品质是你喜欢的。



4.后来我想想，其实这就是投资上的一个品味。你对你投资的标的要有这样一种品味，是不是靠谱、本分？公司是不是想长远？是不是有利润至上的追求？这些真的越思考越有味道。
