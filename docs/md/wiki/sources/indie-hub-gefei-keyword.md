# 哥飞SEO找关键词方法论

## 一、找词渠道：9个入口穷尽关键词

1. **谷歌下拉搜索** — 输入词根后追加字母/单词，获细分长尾词变体（覆盖photo/image/picture/pic/img等多种表达）
2. **谷歌相关搜索（People also search for）** — 搜索结果底部推荐
3. **Similarweb** — 关键词生成器，或输入竞品网址查流量关键词
4. **Semrush** — Keyword Magic Tool，按搜索量/KD/CPC筛选，看变种/问题/相关词
5. **Ahrefs** — Keyword Generator，输入关键词选国家拓展
6. **谷歌趋势** — 看「搜索量上升」和「热门」相关查询，最多25个，可链式拓展
7. **各平台搜索框下拉** — YouTube、TikTok等平台抓下拉推荐词
8. **谷歌 Ads 关键词规划工具** — 核心武器：基于语义给出未知关键词，搜索量直接来自谷歌最权威
9. **竞品反查** — Similarweb/Semrush/Ahrefs查竞品页面/整站流量来源关键词

工具：searchsuggest.tips、searchsug-extractor.com、keywordtool.io可批量提取。

## 二、评估筛选：7步判断流程

1. **看搜索量** — 谷歌趋势/Ads规划工具/Similarweb多渠道交叉验证
2. **看搜索结果** — 谷歌搜看前10是首页还是内页。权重：域名>子域名>子目录>内页
3. **看整站/页面流量** — Similarweb或AITDK插件查竞品流量
4. **看外链** — Ahrefs查KD和竞品外链数量。ROI = 流量 ÷ 外链数
5. **看CTR** — Google Organic SERP CTR Curve工具判断有机点击占比
6. **计算KDROI** — 公式：KDROI = Volume × CPC / KD
7. **避开陷阱** — 季节词（不稳定）、谷歌直达（被卡片吃掉）、搜索量大但KD奇低（假象）

核心逻辑：搜索量小+竞争大→放弃；有搜索量+竞争大→蛋糕够大分一小块也有价值。

## 三、跨平台对齐

**原则**：以谷歌Ads规划工具为准（Semrush/Similarweb数据也来源于谷歌）

方法：
1. 所有渠道收集的关键词去重，一行一个填入Ads规划工具
2. 清空地理位置，选全球，拿谷歌真实搜索量
3. 同义词归组后用谷歌趋势+双引号对比各说法搜索量

## 核心观点

1. 9个渠道穷尽找词，不遗漏任何入口
2. 两家数据都不信，以Ads规划工具为准
3. KDROI公式快速量化性价比
4. AI辅助打通从关键词到网站规划全链路
