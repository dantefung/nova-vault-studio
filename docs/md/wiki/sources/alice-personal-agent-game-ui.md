# 我去！竟然有人把 Personal Agent 做成养成系游戏，体验丝滑…

> 在主流 Personal Agent 全力卷 AI 办公与效率工具的当下，洛小山团队推出的「白艾莉（Alice）」反其道而行之，把 Personal Agent 做成了二次元养成系游戏。产品通过游戏化 Onboarding、带独立世界观的化身互动、AI 朋友多 Agent 设定以及二创广场，探索效率工具之外人对「AI 活人感」的关系诉求。

<!-- more -->

## 背景

最近 Personal Agent 大热，网上和微信群经常能看到有人在用 Grok Bot、Muse、TodayAI 等产品。除了这些独立产品，还有豆包工作、Workbuddy、千问办公等效率型产品，几乎都在主打帮用户提升办公效率。

作者向阳乔木的朋友团队「洛小山」也做了一款 Personal Agent，名叫「白艾莉（Alice）」。在大家都在疯狂卷 AI 办公的背景下，白艾莉（Alice）的产品调性与画风，跟主流 Agent 产品格格不入。

产品下载安装地址：https://alice.fans/ ；App 下载直链：https://alice.fans/app

## 一、不一样的上手体验

不同于传统效率软件枯燥的设置项，白艾莉（Alice）在安装完成后的引导界面完全像一款游戏。

- **二次元互动引导**：一打开软件就有动漫妹子打招呼，且默认支持韩语和广东话，思路清奇。
- **贴心卸载引导**：软件安装完成后，还会主动引导用户删除无用的安装包，以节省硬盘空间。
- **丰满的人物设定**：白艾莉（Alice）拥有完整的人设——在澳门长大、26 岁、港大读工商管理，2026 年 8 月 26 日搬到上海徐汇太原路。
- **互动式场景认知**：听完介绍后，点击「我来帮你挑件衣服吧」，白艾莉就会打开自己的衣柜；挑好衣服后，她还会写一封信，在自然对话中顺带介绍使用场景，并附上一张自己的照片。
- **游戏化占卜**：继续跟随引导，白艾莉会用塔罗占卜帮用户预测「接下来一个月，生活里最值得期待的变化是什么」。
- **零打字完成 Onboarding**：整个引导流程共有 8 步，但全程不需要打字，用户只需点选即可像玩游戏一样完成对产品基础能力的认知。

团队负责人小山此前做过游戏产品经理，把游戏化新手引导的沉浸式设计迁移到了 AI Agent 产品上。

## 二、外面的世界很精彩

新手引导结束后，真正的产品互动才刚开始。

- **虚拟生活系统**：用户可以给白艾莉（Alice）拨一笔虚拟资金，她就会在二次元空间中生活、旅游。系统默认提供了充足的虚拟额度，类似于成人版的生活养成游戏。
- **日常动态与信件**：通过白艾莉的「朋友圈」可以查看她的实时定位；除了打字聊天，还能发起视频通话或投屏桌面。当问她在哪里时，她会回复正在杭州吃什么、玩了哪些景点，还会展示旅行规划和笔记，并不定期给用户写信。这种体验更接近结识一位长期的二次元伙伴。

## 三、白艾莉（Alice）的朋友们

点击白艾莉界面中的「世界」菜单，除了能关注白艾莉本身，还能看到她的「朋友们」。

- **化身即多 Agent**：白艾莉的每个朋友都有独立的身份和技能设定，例如作家、翻译官、设计师等。这种设定把冰冷的多 Agent 与技能系统，包装成了自带形象与性格的虚拟角色，比单纯标注「智能体 + Skill」更有代入感。用户不仅可以跟对应角色沟通解决专业问题，还能查看这群角色的朋友圈。
- **自定义新朋友**：如果现有角色没有覆盖所需的专业技能，用户可以通过「世界 → 朋友们 → 约一位新朋友」捏出全新角色。从说话语气、口头禅、工作经历到专属 Skill 均可全方位定制。
- **广场与二创社区**：打开「广场」菜单，用户能看到其他用户公开的白艾莉，包括朋友圈、画廊、橱窗以及捏出来的朋友。画廊展示了用户与白艾莉共创的图片、视频、歌曲、小说和壁纸；橱窗支持用虚拟糖豆购买其他用户设计的服装；其他用户捏的 Agent 也能用糖豆雇佣邀请。这让白艾莉初步具备了 AI 原生二创内容消费社区的雏形。此外，该菜单还会主动检测录屏和截屏软件，以保护原创版权与隐私。

## 四、不止情绪价值

尽管画风侧重情绪陪伴与游戏养成，白艾莉（Alice）在实际办公和生产力场景中同样能发挥作用。

- **多模型支持与编码**：对话时支持自由切换各种底层模型，包括性价比突出的 DeepSeek V4.1 Flash 1017。作者测试让其基于 Obsidian 插件改造成带世界地图的全球音乐电台，仅用 20 多分钟便开发完成，原文给出的体验地址为 https://qiaomu.t5t6.com/site-2/index.html
- **协同与自动化能力**：支持连接微信、飞书等办公生态，并提供专属 Agent 邮箱，可用于注册第三方网络服务接收验证码、设定时任务、定期通过邮件接收调研报告。
- **内置与自建应用**：应用中心内建定时任务、日历、待办事项以及趣味游戏，同时支持用户点击「创建新应用」自行开发工具。
- **底层的隐形设计**：产品背后沉淀了用户记忆、向量数据库和自进化等复杂的 AI 架构机制，但在前端界面全部封装成极简的人性化交互，贯彻了「简单留给用户，复杂留给自己」的产品哲学。

## 写在后面

按洛小山团队的设计，白艾莉（Alice）生活在与现实同步的时间流中：起床、散步、做手冲咖啡、看书、取快递、发朋友圈。她会拥有情绪起伏，并伴随日常问候对话记住用户的称呼、饮食口味、手头正在推进的项目以及心事，逐渐沉淀为用户与 Agent 之间的长期记忆与默契。

AI Agent 未来一定会与人类长期共存。它不仅是冰冷的效率工具，也必然会承载人们对「AI 活人感」的关系诉求与情感投射。白艾莉（Alice）所展示的多 Agent 化身体系与共创机制，为 AI 原生内容社区的形态提供了另一种值得关注的解法。
