# 哥飞SEO 如果真这么赚钱，为什么他还要卖课卖社群？ 这不符合科学道理

我之前回答过这个问题，有以下几点考虑：

1. SEO 是一门通用技能，并不是只有我会，即使我不教，别人也会教，即使我不教，也会有很多人在用 SEO 来获取流量，也就是说，我教不教，都不会给我自己增加很多竞争对手；

2. 需求太多了，我一个人是做不完的，我教的是方法，大家学会方法之后，可以找到很多各种各样的需求关键词去做，大多数时候，群里大家做同一个词概率并不高，我们每个月有一次新词新站比赛，当月找机会，当月注册域名，当月上站搞流量，拿当月流量来比排名。每一次都会发现，虽然有些词的确有几个人竞争，但更多人提交参赛的网站其实是五花八门的，且都有人可以搞到流量；

3. 我们群里大家看好一个机会，的确也有一拥而上的时候，这时候就各凭本事拿排名了，最终结果就是谷歌搜索结果前20里，有好多个网站都是群友的网站；

4. 有些机会很大，即使拿不到第一名，也够我们吃的，事实上过去两三年的好多个大机会，每次都能喂饱几十人；

5. 有些行业，如在线小游戏单站（注意不是游戏盒子网站），之前基本上都是海外玩家，越南、印度、菲律宾等等都有站长在做，现在我们中国站长也能分一杯羹了，此处需要感谢 @clarencesh19272 是他发现了一个大机会后，让群里现在很多新人都学会了做小游戏站；

6. 可能的确很多人不理解，但我的确是把培养更多出海人才当做目标的，而在这个过程中，我同时也能获利，何乐而不为。

补充下第一点，虽然并不是只有我会，但我可以说，目前国内教 SEO 的，且自己还在一线做网站的，没几个了，而我刚好是其中之一。我能把新人教出来，这就是我的本事。
