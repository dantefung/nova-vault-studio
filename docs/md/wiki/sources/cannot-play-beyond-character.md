# 打不出来性格以外的球

想起一种很熟悉的感受，我之前学画画，到了后期会有一个现象，无论男女，画出来都长一个样子，甚至都和自己长一个样子。越是往后，越会把自我投射进画面，画谁都像自己。



日更给我的感觉也是如此，回来看自己写的内容，或者看别人写公众号，也会有类似的感觉。看似每天都是新的花样、新的感受、新的观察，但时间久了就会发现，背后指向的还是同一个人、同一种性格、一套惯性下来的东西。大部分日更选手，其实就是在反复写一件事，反复写一种性格。



除此之外，我发现人都会被同一个问题困扰非常久，当然也包括我。几个月，甚至几年、十几年的时间，在某些问题下面，像是进入了时间循环一样。



反思自己在日更中遇到最大的问题是，不管在什么情况下，都太追求确定性了。我非常害怕出错，所以写东西一直很累，因为我会不停地校对：这句话是不是太绝对了，会不会被人误解，会不会对什么人造成某种影响。于是直到写完，表达本身已经被打了很大折扣，所以经常性地休息一段时间，恢复了再继续写。



并非只有日更，生活里很多问题，或者说创业里很多问题，看似是困在了某个具体问题里，实际上都是困在了性格里。



和我走得近的人，很多问题我其实都已经回答过十来次了。甚至很多都是从二十多岁一直回答到三十多岁，过去五年十年没变化，未来可能也不会有太大变化。不是自己多聪明，也不是别人不聪明，而是当很多问题反复出现的时候，你会明显感觉到，答案本身并不稀缺。真正稀缺的是，听完答案之后，能不能穿过自己性格里的那道坎。



这种情况在AI时代变得更明显。如果只是追求准确答案，那问AI往往能获得更准确、更完整的答案。但其实没有AI的时候，答案就已经非常廉价了。很多事情的标准答案一直都在那里，比如创业赚钱，本身就是有一套非常标准的答案的。最后所有落到头上的具体问题，都只是性格换了一种方式出现而已。



所以我发现，自己过去一直在做一件非常对抗性格的事情。表面上是在解决一个个具体问题，实际上是在反复对抗自己身上的那套惯性。前段时间找阿姨就找得挺烦，前前后后估计面试了几十个，时间被切得很碎，心力也被严重消耗，打球也断了一阵子。刚好有一天张老师约着打球，就去了。只打了可能不到十分钟，他突然说：来来来紫菜，我跟你说下你打球的问题。



他说，你打球太紧了，你不要总想着不要出界。接下来说了一句话我都懵了，完全不相关的一句话，不要总想着把所有事情都控制在自己手里。说完还补了一句，哎呀不好意思，我又上价值了。



因为和张老师并没有熟到那种程度，更别说他知道我最近在调整方向，也不可能知道生活上正被找阿姨这件事困扰。但十来分钟的球，好像就把我过去几年甚至十几年的生活习惯给击穿了。



因为我打球的时候，确实特别害怕失误，尤其害怕出界。很多球明明可以正常挥拍，但脑子里一直想着别出界、别打飞、别失误，于是身体会下意识收着，动作反而开始变形。往往会比正确的击球点晚半拍再击球，也就是我不太愿意在那个更主动的位置里冒风险。第二个是动作会比较僵硬，因为我从准备的第一刻开始，就已经在想怎么控制球拍了。



球不是因为我不会打才出问题，而是因为自己太想把它打在界内了。张老师说，决定球走向的往往就在最后一刻拨的那一下球拍，其余时间不用握得那么紧。他句句在聊球怎么打，我却一句都没听到打球这件事。



我自己一直有一套做事的方法论，而且在过去的经验里，这套方法确实是有效的。如果一件事在我看来成功率只有四五成，就会通过更多准备、更多确认，把它尽可能推到六成。看起来只是提高了一点点胜率，但如果每一件事都这样做，长期下来，结果会和别人差很多。



所以过去很多年，自己其实很相信这一套东西。至少这套方法不会让我太轻易地把事情搞砸，也让我在很多不确定的事情里，尽量站在一个更安全的位置上。但它的副作用也很明显。它会让我经常处在一种紧绷状态里，任何事情刚开始的时候，我就能预演出更多的风险。



过去一直用自己的标准去做这件事。我觉得别人做得不够好，也发现这一点上，自己很久没有发生变化了。总觉得，这件事明明能做得更好，为什么你不做好？这是我长时间不能理解的地方。



按照张老师的说法就是：打不出来性格以外的球。



其实类似的反思，我好像也写过无数次。甚至某种程度上，整个公众号复盘反思就是为了反思这个问题而生的。写来写去，还是绕回到自己身上：为什么总想控制，为什么总怕出错，为什么总希望在行动之前先获得足够的确定性。没有新的答案，回到最初说的一成不变，我是非常讨厌这种感觉的，先接受自己的平庸和无法改变。不急着把自己写成另一个人。能把这件事正常描述出来，又是一个重新的开始，先允许自己写出来的东西，还是长得像自己。我的其他文章：AI不会让人更轻松有些学费可以不用交在深圳做了两片网球场
