# 可灵 4.0 全流程实测：AI 短剧从剧本到剪辑，以及与 Seedance 2.5 的五组对比

> 可灵 4.0 最长单次生成 30s、带对白、还能自己切镜头。但实测的价值在于它给出了边界：哪些场景能用、哪些仍然要靠剪辑救。

<!-- more -->

## 评测前提

可灵 4.0 最长单次可生成 30s、支持带对白、能自己切镜头，理论上很适合做短剧。但实际效果必须跑一遍才知道。

作者用此前用 Seedance 2.5 做过的五个案例重新测试可灵 4.0，再用一部都市短剧把剧本、人物图、视频生成到剪辑的流程完整走一遍。

对比口径：原片分别为 1080P 与 720P，合成视频统一 1080P，保留原声与原速。

## 一、五组实测

### 01 女团舞

提示词只规定三位成年成员、粉色长发／银色短发／黑色长发，以及全景、转身和表情特写，让模型自由发挥。

作者评价：可灵 4.0 在这个场景里的感觉接近他此前用 MiniMax H3 时的体验；与 Seedance 2.0 差不多，有些地方还不如。审美本就主观——人物皮肤细腻程度、面部处理、三人齐舞效果需要自己看。**作者结论：这一条没有 Seedance 2.5 好。**

### 02 武士打斗

沿用原案例人物与月下神社场景，把交锋拆成进攻、格挡、换位和终结。

作者评价：可灵 4.0 还是差点意思。极速交锋、打得特别快的感觉没出来；前后有割裂，动作逻辑接不上，打着打着人的物理位置就变了。作者认为这种问题挺伤——而且这还是在用了专门的打斗 Skill 之后的结果，可灵这条基本还得靠剪辑把不同片段重新拼一遍才能把动作逻辑弄好。Seedance 2.5 那条他基本能直接拿来用。

### 03 镇妖斗法

看点是先让镇妖师落入红丝陷阱，再用金符反过来困住蜘蛛精，重点看特效颜色、攻守关系和反转。

作者评价：整体还不错，动作是连着的，法术也基本对，人物嘴型能对上，镜头切换也还可以。明显问题在 14 秒左右，蜘蛛精把自己捆住了——又是逻辑错误，有点可惜。排除这个点，整条仍有不少能用的地方。

### 04 森林逃亡

两名互不认识的逃亡者迎面撞上，从「你跟着我？」聊到「带路」，嘴上互相提防，行动却越来越靠近，30 秒里几乎全靠人物关系推进。

作者评价：基本挑不出什么大毛病。清晰度、人物写实程度、包括细节，跟 Seedance 2.5 不相上下。可能是一些微妙的语气差那么一点感觉，烘托暧昧氛围的小细节也稍少一些，但整体能接受，这条可以用。

### 05 耳机广告

上传产品整体、侧面、网布细节各一张，沿用原案例提示词，要求简洁商业展示和结尾产品名。

作者评价：整体清晰度 OK，产品一致性也还可以；加上旁白后反而变得更 low，音乐也没那么高级。这些问题后期换掉声音还能处理，整体能用。如果是他来交片，会先去掉这段旁白，再重新找合适的音乐。

## 成本怎么算

按 10 秒、16:9、只用文字或图片参考（不带输入视频）比较：

| 方案 | 规格 | 本次实扣 / 价格 |
|------|------|----------------|
| 可灵 4.0（钻石会员积分） | 1080P | 实扣 135 灵感值；按测试时首月套餐折算约 7.86 元，续费月约 9.89 元 |
| Seedance 2.5（火山方舟官方 API） | 1080P | 约 37.42 元 |
| Seedance 2.5（火山方舟官方 API） | 720P | 约 15.12 元 |

按这两种购买方式，可灵这次的 1080P 单条预算更低。文中保留的是本次测试时的价格与扣积分口径。

## 二、短剧全流程

作者拍的短剧是：女继承人被栽赃，董事逼她交权，父亲也不相信她。保安上来拉人，西装保镖出手解围，拿出监控。最后查到的钱，却进了父亲的账户。

**这条片子从写剧本、做人物图，到生成视频、剪辑、加字幕和配乐，全程跟 AI 对话完成，中间没有打开过剪映等任何剪辑软件。**

当然也不是一句话就全对：男主不够帅、女主像贴上去的、打戏突然开打、证据文字乱码——这些都遇到了。作者的做法是看完觉得哪里不对就接着说，让它继续改。

### 1. 连接可灵

把可灵的 MCP 和 CLI 都接到 Codex 里，连好后上传参考图、提交视频、查看进度、下载原片都可以让它做。

```text
请运行以下命令安装可灵 Skill，并完成授权流程：npx skills add klingai-tech/skills
```

安装和授权照它的引导走，浏览器弹出登录页时用自己的可灵账号授权即可。不一定非要用 Codex——WorkBuddy 和豆包工作用同样的提示词也能连接。

### 2. 编写剧本

用「西羊石短剧剧本创作 GPTS」，主要按短剧节奏来写。输入很口语化，把脑子里的画面说给它听：

> 家族企业只有一个女继承人，她被董事会的人搞了，最无助的时候，保镖出来救场。要有冲突、有反转，角色别太多，一分钟到 80 秒左右，背景放在中国。

GPTS 输出完整剧本后作者自己改：女主不能一直等人救，她自己得有反驳；监控也不能只拍赵董事进了财务室，最好能看到他拿印章、盖章、刷卡，证据才接得上。

确认剧本后交给 Codex 继续做，并明确分步：

```text
这是我确认过的短剧剧本。接下来按这个版本制作，先给我角色设定和需要准备的人物、场景、道具清单，再逐项生成资产图。先别急着生成视频。
```

### 3. 准备资产

作者认为这一步最关键：故事讲董事会，人物穿着和房间风格不能各有各的。

- **女主**：希望是被富养大的女孩——自然、有气质、有一点贵气，不需要浓妆或把所有昂贵的东西都穿在身上。最终用白短外套、深色长裤和暗红胸针，放在一群深色西装里比较显眼
- **男主**：虽是保镖但毕竟是男主，一定得帅、给人安全感。最早那版戴眼镜，看着像大学生或程序员，作者说「这哪里像能打得过反派打手」；后来选中一张脸，继续换西装、调身材比例
- **反派打手**：造型可以粗粝一点、凶狠一点，别所有人都长得像精修男模
- **女主父亲**：四五十岁、已成功的商业掌权者，有一点教父式的威严；其他高管也要有年龄感，可以稍微发福，大家站在一起观众才分得清谁是什么人

**人物参考图用白底三栏**：正面脸部大特写 + 遮住脸的正面全身 + 背面全身。这个做法是作者看 Higgsfield 公开创作流程学来的——正面全身里把脸涂掉只用大特写提供脸部信息，全身图负责身材和衣服，背面负责背后结构，这样可以减少两张脸不完全一样、模型不知道该参考哪一张的干扰。

> 保持已选定的人物身份和脸型，做一张纯白背景角色参考板：左边是清晰的正面脸部大特写，中间是头顶到鞋底完整的正面全身，仅遮住脸部，右边是背面全身。人物比例修长自然，服装、鞋子前后一致，不要加文字。

但要跟视频模型说清楚，黑块只是参考图的处理方式，成片人物的脸必须完整——他们前面真的生成过遮脸画面，所以这个说明不能省。一致性也要继续看原片，不能做完三视图就完全不管了。

场景同样先固定下来：这间会议室的门、窗、长桌和主位，后面换镜头还得是同一间房。再让人物进到场景里试一张构图——人的比例、窗光的方向、手和桌子的接触都要看。前面女主像贴上去的，就是因为只顾脸好看，没让她真的站在这个空间里。

### 4. 编排视频提示词

用了一份具有视听语言专业知识的提示词模板，它会结合短剧节奏，把景别、运镜、人物表演和段落衔接编排进去。作者认为资产图和提示词是生成视频特别关键的两个东西，把它们弄好后面才能少一点盲目抽卡。

```text
按我提供的提示词模板，把这集拆成可以连续生成的几批素材。
每批写清参考图用途、开场站位、人物表演、对白、景别和运镜，结尾停在哪里也要说明。台词用已经确认的版本。打戏单独调用我们的打斗 Skill 细化。

一批素材里面可以有几个镜头，不用一句台词生成一条。也别为了凑满时长，让人物站着发呆。

尤其是表演，你得写。
```

**表演必须写细。** 作者原话：不把反应说清楚，它真的会很尴尬——一个画面里好几张脸，大家都不怎么动，也没表情，看久了甚至有点毛骨悚然。

所以女主听到父亲让她停职，不要只写「她很伤心」，可以写：

> 女主听到父亲让她停职，不要只写她很伤心。
>
> 可以写她撑桌的手指收紧，短吸一口气，抬眼看父亲；父亲听完，避开她的目光。旁边的赵董事看向门口，等着保安过来。每个人在这个时候做什么，都得有原因。

作者「停职」这一段的实际提示词组织：

> 父亲近景，放下笔，看向女儿：交印章。停职调查。镜头轻推。
> 切女主侧面肩胸近景，画面下缘看得到她撑桌的手。她手指收紧，压着委屈说：爸，你连我一句话都不肯信？
> 切父亲近景，他看她一眼，又低下眼：我只看证据。
> 切赵董事中近景，他马上向门口抬手：带走！

**景别也要换。** 先让观众知道大家在哪，再切近一点看表情或动作，别整段都用一个全景——一直远远看着既枯燥，也容易把那些不自然的小动作全露出来。

打戏另外用了专门的打斗 Skill，没装过的可以让 Codex 安装 GitHub 上的 `ZzzAloong/fight-scene-director`。作者自己对比下来更偏好用了 Skill 的那一版：同一组 5 张参考图、同一个可灵 4.0、都是 10 秒 1080P，一条用原提示词、一条用 Skill 细化提示词——他更偏向后者，但两条仍有不自然的地方，后面也继续返修了。

打戏肯定要有快有慢。

## 边界与判断

- **可灵 4.0 的 30s 单次生成是真实能力**，但五组实测里只有 2 组（森林逃亡、耳机广告）作者认为「整体能用」，打斗类仍需剪辑救
- **「可灵 4.0 vs Seedance 2.5」的胜负逐案不同**，不能整体下结论；女团舞 Seedance 胜、森林逃亡打平、武士打斗 Seedance 胜
- **成本优势是实打实的**：按本次口径，可灵 1080P 单条预算显著低于 Seedance 官方 API
- **资产图与提示词模板是质量前提**，不是可选项；作者前期「男主不够帅、女主像贴上去的」问题都出在资产环节
- **模型会犯物理逻辑错误**（蜘蛛精把自己捆住、人打斗时位置漂移），需要人工发现并要求返修
- 评测样本只有五组，且是作者自选案例，存在选择偏差
