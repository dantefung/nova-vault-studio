分享一下我个人的邮件 outreach 工作流：

1. 筛选：用 agent 批量扒取同赛道高权重网站联系方式。
2. 定制：把对方网站首页丢给 AI，生成定制化开头
3. 利益：首段直接给合作方案
4. 第 3 天、第 7 天自动发跟进邮件

本质上，outreach 是个概率游戏，我这么做就是提高分子和分母。
