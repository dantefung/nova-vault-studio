# CloudHu：面向小白的AI出海建站教程

> 因为自己淋过雨，所以想为别人撑伞。做了一套完全面向小白的AI出海建站教程，只需要：用过AI、不用懂代码、不用懂英文。

## 工具清单（约30元内搞定）

- 域名商：spaceship（几块钱域名，支持支付宝）
- 服务器部署：vercel（免费）
- SEO工具：semrush（付费，一个月几十）
- 找词工具：google trends（免费）
- 站长工具：Google Search Console（免费）、Bing Webmaster（免费）
- AI编码工具：Codex或Claude Code（有免费的Workbuddy或Trae也行）
- 代码仓库：GitHub（免费）

## 四步法

### 第一步：找需求关键词

分两种：
- **老词**：长期有人搜索的（如"word转pdf"）
- **新词**：当下流行的（如"26年世界杯"）

筛选原则（semrush）：
- KD（关键词难度）：新手适合0~30
- CPC（商业意图指数）：0.1~10，CPC为0基本无变现价值

不做：体育比赛/天气预报/政治时事/娱乐新闻（大平台垄断，时效性短）

### 第二步：做网站

全程只需要和AI交流，让它出方案写代码。给AI一段提示词确认项目边界，生成需求文档后让它直接实现。

### 第三步：部署

把代码上传GitHub，然后到Vercel导入GitHub仓库，点Deploy即可。
