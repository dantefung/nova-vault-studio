# 做网站前3个月一分钱没赚，一年后他做到了月入万刀

金果 2017 年普通本科毕业，做了 8 年程序员。2024 年 5 月加入哥飞社群后开始做英文网站。前三个月没有收入，到 2025 年 4 月 30 日，网站收入做到了月入万刀。

## 核心叙事

- **前3个月**：第一个项目选得太难，流量和收入都没有起色
- **转折点**：换小需求，找到已有人搜索但竞争不强的词，做可用页面，几天/几周内看到反馈
- **第一美元**：来自游戏站——看游戏榜单→判断新游戏热度→做能直接玩的页面→观察收录和访问
- **AI 工具站**：换赛道但方法不变，入口从游戏榜单换成模型/工具目录/YouTube/论坛
- **月入千刀→万刀**：先做几个能到月入千刀的站，或找搜索量更大的词让一个站跨到万刀

## 关键方法论

| 阶段 | 策略 |
|------|------|
| 选需求 | 两问：能否较快看到搜索反馈？能否用现有能力做出可用页面？ |
| 找词 | 固定来源入口（更新频繁的网站/YouTube 创作者/社区），非临时想关键词 |
| 页面设计 | 按用途分开（直接玩/攻略/下载），不要照首页做相似页面 |
| 推广 | 渠道单独记录：上线速度、链接类型、是否带来访问/注册/订阅 |
| 放大 | 自然流量+付费后投广告，自然搜索用户和广告用户分开看 |
| 转化优化 | 查看操作回放和每一步转化数据：等待→功能→订阅→支付页 |

## 时间线

| 时间 | 事件 |
|------|------|

| 2024-09 | 第一美元（游戏站） |
| 2025-01~02 | 月入千刀 |
| 2025-04-30 | 月入万刀 |
