# Hedy Zhang（@xiaomanhedy）：多 Agent 协作该学蚂蚁——痕迹协作（Stigmergy）而不是人类开会

> 一个通透的多 Agent 架构比喻：蚂蚁通过「环境」协作而非通过「开会」对齐——它从不会给同伴发消息说「我要去找食物了」再群发「我在那边找到了」，只做一件事：改变环境、留下痕迹，其他蚂蚁据此直接行动；这在生物学里叫痕迹协作（Stigmergy）。推论：多 Agent 协作最大误区是把人类大厂那套低效的「汇报、对齐、审批」原样搬给 AI——Agent 数量翻一倍，彼此通报量就翻四倍；真正 AI Native 的协作是取消点对点无效寒暄，共享同一个鲜活上下文环境，直接改状态、留痕迹、触发下一步。

<!-- more -->

太牛了，醍醐灌顶啊，原来多 Agent 协作居然可以借鉴蚂蚁协作的思路！

今天看到一个关于多 Agent 架构极通透的比喻：像蚂蚁一样通过“环境”协作，而不是像人类一样靠“开会”对齐。

蚂蚁从不会给另一个蚂蚁发消息说“我要去找食物了”，然后再群发一条“我在那边找到了”。

它只做一件事：改变环境，留下痕迹，然后其他蚂蚁根据留下的痕迹就能直接行动。

这个在生物学里叫痕迹协作（Stigmergy）。

多个 Agent 协作，最大的误区就是把人类大厂那套低效的“汇报、对齐、审批”完全搬给 AI。

Agent 数量翻一倍，彼此通报的沟通量就翻四倍。

真正的 AI Native 协作，是取消点对点的无效寒暄。

共享同一个鲜活的上下文环境，直接改状态、留痕迹、触发下一步。
