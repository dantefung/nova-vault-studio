# wavborn：选词三板斧——Trends 比值法、前十占位检查与 72 组词验证率

> 「扔掉的比上线的多得多。」wavborn 公开自己的选词过程与放弃原因：先看 Google 第一页是谁，被大站或免费插件占满的直接扔；判断一个词有没有量不看第三方流量估算，只用 Google Trends 和基准词比比值；12 天验了 72 组词，扔掉 64 组。

> 本文汇总 @wavborn（AI 工具站实战）连续三帖，构成一套完整的新手选词筛选法。作者公开每个放弃词和原因、上线站真实排名，不卖课。

## 第一板斧：Google 第一页是谁（2026-10-22）

> 「我做出海工具站，每个词先看谷歌第一页是谁，被大站或免费插件占满的直接扔，扔掉的比上线的多得多。」

作者的判断逻辑很直接——**看 SERP 前十里有没有「小站」**：

| 第一页被谁占住 | 处理 |
|---|---|
| 大站 / 官方免费工具 / 同名小站 | **直接扔** |
| 有小站 / 有独立站 | 值得竞争 |

## 第二板斧：Trends 比值法，不看绝对数（2026-10-15）

> 「判断一个词有没有量，我不看第三方流量估算，只用 Google Trends 把它和一个固定基准词（我用 gpts）放一起比。**看比值，不看绝对数。**」

### 关键操作

- **工具**：Google Trends
- **基准词**：作者固定用 `gpts`（因为它是稳定的全民级参照物）
- **比法**：候选词与基准词放在同一张图上对比
- **判读**：看**比值曲线**，不看绝对搜索量

### 淘汰阈值

> 「这几天我扔的词，不少只有基准词的 **0.02 到 0.1 倍**，还在下滑，竞争再弱也救不了。」

两条硬性淘汰条件：

1. **比值过低**——只有基准词的 0.02～0.1 倍；
2. **趋势还在下滑**——方向不对，再弱的竞争也救不了。

> **为什么不用第三方流量估算**：Ahrefs / Semrush 这类工具给的是绝对数值和竞品级数据，但对新手选词来说，「相对基准词有多强」比「有多少量」更有决策价值——绝对量小的词未必不能做，但比值可以横向比较所有候选词。

## 第三板斧：72 组词、64 组被扔（2026-10-19）

> 「三步里最容易被跳过的是选词。我这 **12 天验了 72 组词，扔了 64 组**，多数不是没人搜，而是**前十早被官方免费工具或同名小站占满**。」

### 关键数据

| 指标 | 数值 |
|---|---|
| 验证周期 | 12 天 |
| 验证词组 | 72 组 |
| 淘汰词组 | 64 组 |
| **上线率** | **8/72 ≈ 11%** |

### 淘汰原因排序（作者自述）

1. **前十被占满**（主因）——官方免费工具或同名小站已占位；
2. **比值不达标**——第二板斧的 0.02～0.1 倍线；
3. **趋势下滑**——需求在退潮。

原文向 @GoSailGlobal 提问：「你挑词时会先看前十有没有小站吗？」

## 三板斧的串联关系

```text
① 量的门槛（Trends 比值法）
   → 只有基准词 0.02～0.1 倍以下 / 趋势下滑 → 直接扔
        ↓ 通过
② 竞争的门槛（Google 第一页是谁）
   → 前十被大站或官方免费工具占满 → 直接扔
        ↓ 通过
③ 规模化验证（12 天 72 组词）
   → 预期上线率仅 11%，所以必须批量验证，不能只赌一两个词
```

> **反向逻辑**：被扔掉的比上线的多得多（64 : 8），所以**选词是流水线不是手工艺**——不要指望「我找到一个好词」，而是「我一天筛掉 5 组词」。
