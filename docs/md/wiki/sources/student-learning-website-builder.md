# 我做了个「一键生成学习网站」的 skill，把自己惊艳到了

> 从三天到十分钟：把课程设计→教学设计→互动网站全流程打包成一个 Skill

上篇文章用 AI 实现从教育创意到项目落地介绍了如何用 DeepSeek + Trae 生成互动自学主题网站，效果非常好。一位老师朋友找到作者，希望能帮忙做个生物学习网站——学生说看 PPT 太无聊了。

那一刻作者意识到：**为什么每次都要从零开始？** 课程设计的结构是相似的，网站的基础设施是通用的，互动组件是可复用的。重复造轮子，是对生命最大的浪费。

于是作者做了一个决定：把整个流程「打包」成一个 skill。输入主题，自动输出「课程设计 + 教学设计 + 互动学习网站」三件套。这就是 **student-learning-website-builder** 的由来。

---

## 不会做 skill？没关系，Trae 来协助

作者只需要有好的想法，剩下的交给 Trae 来完成。分两步走：

**第一步：通用课程设计模板**

先基于已有的「认识 AI」课程设计方案，让 Trae 改造成一个通用的（适用于各学科）markdown 格式的课程设计模板，提示词大致是：

> 将文件 `ai-learning-website-design.html` 改造成一个通用的 markdown 格式的课程设计模板。该模板应具备可扩展性和灵活性，能够适应不同类型不同科目课程的设计需求。完成改造后，应提供使用说明文档，指导如何基于该模板快速创建新的课程设计方案。

**第二步：基于模板生成 skill**

再让 Trae 基于这个通用模板，开发一个能自动生成学生自主学习专题网站的 skill。核心要求：

1. 根据用户提供的课程内容，严格按照模板格式生成完整课程设计方案
2. 基于课程设计文件，开发功能完善的学生自主学习主题网站
3. 大模型集成：将 AI 自然融入课程学习的各个核心模块
4. AI 学习伙伴：右下角悬浮常驻，苏格拉底式引导
5. 视觉设计：明亮活泼，新颖现代
6. 核心功能模块：学习资源展示 / 互动学习模块 / 进度追踪系统
7. 纯 HTML + 原生 JS，零框架
8. 同时输出与课程匹配的教学设计

## 从「三天一个」到「十分钟一个」

初次设计「认识 AI」主题网站时，从想法到优化到最终完成用了三天。但 skill 已经沉淀了初次开发时的各种经验和避坑经验，因此再次开发变得非常顺畅——大概十分钟就能成型。

以「奇妙的生命之旅」初中生物网站为例，告诉 skill：

> 初中生物·细胞到生态系统的自主学习

然后它自动跑三阶段：

**第 1 阶段：课程设计文档自动生成**

七章节结构，一个不落：

1. 项目概述（背景、目标、约束）
2. 设计理念（五阶学习路径）
3. 内容结构（架构图 + 8 个模块一览）
4. 课程内容详细设计（每个模块 2-5 个活动 + 分层任务）
5. 大模型交互功能设计
6. 技术实现要点
7. 学习评价体系

**第 1.5 阶段：配套教学设计**

课程设计回答「教什么」，教学设计回答「怎么教」。九章内容直接从课程设计里「长」出来：

1. 教学目标（行为动词，可观察可检测）
2. 学情分析（起点能力、认知特点、潜在困难）
3. 教学重难点
4. 教学策略与方法
5. 教学过程设计（每课时五环节表格：教师活动/学生活动/网站操作/设计意图/时间）
6. 教学评价方案
7. 教学资源清单
8. 板书设计
9. 教学反思建议

最绝的是第五章——每节课的网站操作都具体到页面和活动名称，不是写「学生打开网站」这种废话，而是「打开 m1-cell.html，完成翻牌墙活动，得分≥60」。老师拿到手就能直接用。

**第 2 阶段：网站一键生成**

纯 HTML + 原生 JS，零框架，双击 `index.html` 就能跑。8 个学习模块，个个有互动：

- 细胞翻牌墙 + SVG 结构辨认
- 光合作用 Canvas 对照实验
- 动物行为判断游戏 + AI 行为分析
- 拖拽配餐 + AI 营养顾问
- 食物网连线 + 能量流动动画
- 案例投票 + 宣言生成
- 知识闯关 + 四维素养雷达图
- 资源中心 + 术语词典

**AI 学习伙伴，全站悬浮常驻**

右下角一个按钮，点开就能聊。不是那种搜答案的工具人——是苏格拉底式引导。学生问「细胞的结构是什么？」，它不会直接给答案，而是先反问：

> 「你觉得细胞为什么需要一个控制中心呢？先想想，再告诉你～」

进度自动保存，对话跨页续接。刷新页面，你的学习伙伴还在。

**成长可视化，看得见的进步**

首页学习地图，8 个模块卡片，完成进度实时显示。四维素养雷达图，学习前 vs 当前对比一目了然。徽章墙，解锁一个亮一个。

## 亮点：为什么说它碾压 PPT？

对比项  |  传统 PPT  |  Skill 生成的网站
--------|-----------|-----------------
学生能做什么 | 看 + 听 | 动手操作、实验、对话、闯关、AI 评价
学习成果数据 | 没有 | 进度、正确率、素养画像、徽章
制作时间 | 几个小时 | 十分钟
可复用性 | 改一次重做一次 | 换个主题，一键新生成
AI 能力 | 没有 | 学习伙伴 + 各模块 AI 场景
运行方式 | 要装 Office | 双击即开，浏览器直接用

PPT 是老师讲学生听。这个网站是学生自己探索，AI 陪在旁边引导。

## 三点体会

**第一，好工具的标准是「用完即走」**

不希望老师花半天学怎么用这个 skill。说一句「我要做个 XX 主题的学习网站」，剩下的它自己搞定。简单到极致。

**第二，一致性比什么都重要**

做过课程设计的人都懂——改了模块数，一览表要改、详情要改、目录树要改、场景表要改、评价维度也要改……改到最后总有一处漏了。这个 skill 的核心价值之一，就是把所有的「对应关系」用铁律锁死。你不用再担心「是不是哪里忘改了」。

**第三，技术要为人服务，而不是反过来**

为什么坚持「纯 HTML + 原生 JS，零框架」？因为见过太多老师，拿到一个「需要 Node.js、需要 npm install、需要构建部署」的东西，直接就放弃了。双击就能打开，这是底线。

**写在最后：** 这个 skill 已经用多个实际项目跑通了全流程——从课程设计文档、教学设计文档到 8 个模块的互动网站，整个过程顺畅得不像话。无论是参赛作品、校本课程、单元设计，还是单纯想给学生做一个「比 PPT 好玩一百倍」的学习资源——这个 skill 都能帮你省掉 90% 的重复劳动。
