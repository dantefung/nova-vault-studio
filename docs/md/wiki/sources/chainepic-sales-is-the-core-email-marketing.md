# Roland（@ChainEpic）：商业的本质还是销售——用 Grok Bot 把营销性邮箱利用起来

> 调研 80% 的商业模式都依赖销售完成。邮件营销能流行几十年、电话营销即便没效果也仍有数不完的企业在用。作者建议把 Grok Bot 和营销性邮箱利用起来——不要觉得工作量大，实际需要你回复的，就只有那么一两个真实的客户。

商业的本质还是销售。

最近做调研，可以说 80% 的商业模式，都是依赖销售完成的。那种闷头做站不叫销售。

难怪邮件营销能流行几十年，电话营销就算现在这么没效果还还是有数不完的企业用这招。

我建议所有人都把 Grok bot 利用起来，把营销性邮箱利用起来。不要觉得工作量大，实际上真正需要你回复的，就只有那么一两个真实的客户。
