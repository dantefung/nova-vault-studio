# 我为什么更愿意聊冰山之下的内容

最近两篇内容写得长了一些，但数据不太好。我并不是为了取悦读者才去调整，只是会想：能不能写一个大家喜欢，同时自己也有收获的东西。目前看最好的状态，是写在1000–1500字之间，读者不觉得累，我写得也轻松，刚好是意犹未尽的状态。



我聊的更多还是冰山以下的部分，所以有人觉得内容太务虚、缺乏实操。我反而认为，聊具体项目、聊执行才是务虚。任何一个项目，都可以靠执行力、搭团队这些简单粗暴的方式完成从0到1，甚至从0到100，自己更愿意把一件事的底层逻辑讲清楚。



比如昨天苹果17开售，我开玩笑说：没下够500台的退群吧。其实这里有两个信息差：



第一，苹果官网和电商平台不同，并不是抢购模式，而是下单预付款模式，差别只在到货时间。



第二，官网支持7天无理由退款，没有利润退款即可，即使段短时间破发也可以稍微等一下。



况且今年17整体改动不错，从体感看大家还是有换新机的需求，9月到货的机器利润应该不差。如果涨不起来，官网还支持无理由退款。



同样一条信息，每个人看到都会有不同想法。他的赚钱逻辑是有人只早点拿到手使用，所以愿意加钱买，所以催生了这样的黄牛生意。但直到今天，还有很多人会把这种买卖和认知差，直接扣上刷单诈骗的帽子。



所以有人看到了，但是不信能赚钱，这就是为什么要聊认知外的钱



假如你理解这件事的赚钱逻辑，但又有人会问：没钱怎么办？我没钱的时候就用信用卡下单，而且部分苹果商店支持免息分期，找一大帮想去信用卡套现刷积分的人帮我下单，也分他们一点利润，又实现了共赢。



问题的关键并不是钱，而是：你能不能找到一群无条件信任你的人。归根结底，还是要解决信任问题，是不是在过去的生活的工作当中积累了足够多的信任额度再谈信任



这很反人性，所以常常会遭到误会：轻则漠视不理你，重则被质疑诈骗。这个时候就要想清楚，如果你真的还处在积累本金的阶段，就要记住：赚钱才是唯一重要的事。如果靠说服能解决，那就再去聊。这时候对你来说，要权衡一下道理重要，还是赚钱重要？



所以



如果你只盯着渠道，追着问怎么下单、在哪卖，最后也就赚个1000。



如果你能看见这些项目背后的逻辑，就有机会把它放大至少100倍。



这就是我为什么总是愿意去聊冰山之下的内容，因为真正决定结果的，往往都藏在那里。
