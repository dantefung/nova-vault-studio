# Koda（@wadezone）：干货没人看？用好莱坞三幕式讲故事——拉人上船、撞冰山绝路到递出木板

> 为什么精修一周的干货教程阅读量破不了百？编剧朋友一语点醒：不要写平铺直叙的产品说明书。详解三幕式爆款结构：第一幕抛出惨淡现状拉人上船、第二幕把常规办法试死堵绝退路（撞冰山）、第三幕才递出真正有效的实操解法（递木板），让读者身临其境产生情绪共鸣与高转化。

<!-- more -->

我第一回写公众号，花了整整一个星期憋了一篇干货教程。

自个儿端详半天觉得写得简直绝了。

结果发出去挂了一个星期，连 100 个人浏览都没有。

我不信邪，开始折腾各种野路子：

花钱给内容加热、学人家起震惊体标题、到处求人转发。

市面上所有教人怎么搞流量的歪招全试了一遍，结果呢？后面发的东西照样没人看。

直到后来，我撞大运认识了一个在影视圈干过编剧的朋友。

我把链接甩过去，寻思让他帮我把把脉，看看问题出在哪。

他拿过手机划了两下，眼皮都没抬就扔回来了：

“你这写得哪叫文章，这就是份产品说明书。通篇平铺直叙，谁能看得下去？”

我当时还不服气，他接着问我：

“你看过《泰坦尼克号》吗？”

“看过啊。”

“那你记不记得它到底是怎么讲故事的？”

他给我现场扒了一遍好莱坞那套流传了几十年的三幕式结构：

第一幕先铺垫。让那个穷小子赌博赢了张船票，硬生生把两个八竿子打不着的人塞进同一条船里。

中间第二幕开始上强度。各种矛盾接踵而至，最后直接撞上冰山，把所有人逼上绝路，退路全给堵死。

到第三幕生死关头，两个人只能抱同一块木板，最后露丝活下来。

朋友指着我那屏幕说：

“你再看看你写的，一上来就跟人讲怎么造木板。读者连船都没上，冰山也没见着，谁有闲心听你在这儿讲大道理？”

那一瞬间我才算彻底回过味来。

当天晚上，我把那篇没人看的教程全推翻了：

开头直接扔了我那篇挂了一周的惨淡截图（第一幕：拉人上船）；

中间写我花钱买教训、试各种野路子把流量折腾归零的惨痛过程（第二幕：撞冰山堵退路）；

最后才把真正摸通的一套排版和选题步骤贴上去（第三幕：递木板）。

同样的一批干货，换了这个顺序重发了一遍。

第二天一睁眼，阅读量直接破万。

所以说，不管你是写公众号还是发推文，别老琢磨着怎么把道理讲圆满。

先让人看你掉坑，再把常规办法全试死一次，最后才把解法亮出来。
