自动化这件事，想做好其实出奇地难，哪怕你天天都在做。我想分享一下我自己怎么做，无论是工作上还是日常生活里，以及 Grok Bot 怎样能帮你去挑战更大的目标。

## 一种思考方式

自动化其实就是一种人人都能学会的思考方式。它讲的是系统地、有逻辑地思考，在心里盯着一个目标的同时，把事情拆成一小步一小步。

它有两个部分，一个是目标，一个是过程。

日常的例子是烤一个苹果派（这是目标）。你照着食谱或流程走，步骤写得很清楚，买齐并准备好材料，把派组装好、装饰好，送进烤箱，再让它冷却，诸如此类。或者你要换瘪掉的轮胎（这也是目标），可能得先想办法把车顶起来才能碰到轮胎，找到工具把旧胎卸下来、换上新的，再把所有东西装回去。

简单说，目标是你最后想要的结果，过程是你怎么到达那里。

![](../images/maiyang-lauren-tan-grok-bot-automation/002.jpg)

自动化也是同一回事，同样是目标和过程，只不过多了某种机器，比如面包店用来一次烤很多苹果派的那种。或者是代码，软件工程师以前要亲手去写，好把电脑能做的事情自动化。关键是把事情拆成朝向目标的步骤，再把过程自动化，这样你就不必每次都亲自做一遍。

## Grok Bot 让每个人都能做自动化

就在一两年前，自动化还只属于那些懂得怎么造机器、组装机器或写代码的人。有了 Grok Bot，凡是电脑能做的事，现在即便不是技术出身、也不是软件工程师的人，也可以去自动化了！电脑能做的事情之多，也着实让人吃惊，包括你可能觉得 bot 做不了的那些。

要用 Grok Bot 开始自动化任务，你不必会写代码。你可以用平白的语言把想做的事说清楚，然后和你的 bot 一起把步骤理出来。Bot 可以替你写代码，也可以用它自己的电脑，去做几乎所有你能在自己电脑或手机上做的事。

如果你不是技术背景，我想请你先暂时放下怀疑。Bot 真的能做你在电脑上能做的任何事。它能自己移动鼠标去点击，安装或连接到你日常用的应用和软件，用它自己的浏览器上网，替你参加会议并做笔记，还有多得多的事情。

而正因为我们现在的工作和生活有很大一部分都依赖技术，也就意味着越来越多的工作可以交给 bot 去做，好让你把精力放到别的事情上。

从目标开始

为了说得更具体，我们一起来建一个新的 bot，让它替你自动化一件事。打开 Grok Bot，新建一个 bot，给它起个你喜欢的名字。如果想不出名字，就先叫它 Potato，稍后再让它给自己起名。

在开始和 bot 聊天之前，我一想到自动化，总是先从目标开始想。我们到底想做成什么？

我常常看到的一个错误，是把过程当成了目标。比如，你在工作里可能已经有一套很明确的任务流程。但目标并不是填一张表，也不是发一封邮件。那只是过程中的一步。

相反，要想的是最终的目标，这套流程是为了什么，它在业务里处在什么位置？它是帮你增加收入（比如处理一笔销售、做新功能），还是帮你降低成本（比如只订刚刚好的库存）？如果不确定，去和你的经理或同事聊聊，甚至也可以请 Bot 帮你想清楚！

把目标说清楚，是最好的起点，因为它会让你和 Grok Bot 都把注意力放在最终结果上。你可能还会发现，bot 也能想出办法让过程更有效率，所以不要太执着于某一种特定流程，毕竟流程只是达到目的的手段。

一旦目标想清楚了，先把这个目标讲给新 bot 听，如果你不想一直叫它 Potato，再请它给自己起个名字。

「嗨 Potato，这是我希望你负责的目标，<目标>。请根据这个目标，给自己选一个名字和一张图片。」

下面是一些可以告诉 bot 的起始目标想法。

- 存钱，用来买新车、买房，或给孩子准备大学基金
- 为我的小企业安排新客户预约
- 改善我小企业的客户体验，让他们给我好评
- 为我的小企业招聘新员工
- 收集产品反馈，好据此改进
- 为每周的会议准备幻灯片
- 为我的产品做新功能

如果你不太确定该怎么描述自己的目标，就请 Potato 来帮你！你可以这样对它说。

「嗨 Potato，我想请你负责一个目标，但我还不太确定怎么最好地把它说清楚。你能向我提问、采访我，直到我们得到一个我满意的目标吗？」

## 过程

把目标告诉它之后，想一想如果是你自己来做，会怎么达成这个目标，然后让 bot 看看哪里可以把事情做得更有效率。如果你更希望它严格按你的流程来做，也可以直接告诉它。

把这些信息交给 bot 最好的办法，是在 Grok Bot 里用语音输入，连续说上一段时间，把做这件事它需要知道的一切都倒出来，先不用担心意识流，也不用先整理思路。告诉它下面这些。

- 你通常会走的步骤
- 你通常会留意和盯紧的事情
- 你做这件事时用的应用和工具
- 你如何检查工作是否做对
- 你从哪里获得做这件事所需的信息（比如邮件、Slack/Teams、工单、某个应用或网站）
- 你从哪里获得这件事做得怎样的反馈（比如客户反馈/评价，同事的反馈）

「Potato，我自己通常是这样来完成这个目标的。<过程>我希望你想一想，怎样才能把这件事完全从我手里接过去。在开始之前，请用简单的话复述你理解的目标和过程，好让我反馈并确认。我还不希望你现在就开始执行，我们先把流程规划清楚。」

![](../images/maiyang-lauren-tan-grok-bot-automation/003.jpg)

不必担心第一轮就做对。看 bot 说了什么，再补上更多信息来纠正它。这样来回几次，你应该就能得到一个自己满意的版本。然后可以让 bot 继续往下做，开始连接到它把工作做对所需的应用和工具。

如果你想更大胆一点，甚至可以请它对照原来的目标审视这套流程，看看能不能想出更好或更有效率的做法。

「请对照我原来的目标审视我们的流程，如果你看到能把它做得更好或更有效率的办法，就告诉我。」

## 教你的 bot 你是怎么想的

解释一套流程时，很容易忘掉的一件事是，有多少事情是你几乎不假思索就在做的。如果你在给客户预约，你大概知道哪些服务更花时间、谁能做哪项工作、预约之间什么时候该留出额外时间。这些判断对你来说可能觉得理所当然，但你的 bot 也需要这些上下文。想一想你自己做这件事时在注意什么，以及是什么让你做出不同的处理。

告诉它这些信息你从哪里来，以及你如何检查工作是否做对。比如，如果一封邮件和你的预约系统显示的时间不一样，它该信哪一个？预约也不是发出一封邮件就算完成了。预约需要被正确保存，客户也需要收到确认。如果你还在等细节，就让 bot 把这件事记着，这样它之后可以接着处理，而不会不小心再创建一个预约。

不必担心一开始就把所有可能的情况都讲完。先从几个真实的例子开始，包括出过错、或你不得不换一种做法的例子。问 bot 它会怎么处理，然后给它反馈。你也可以请它帮你找出你还没解释到的地方！

「Potato，帮我想想这个流程里我还没告诉你的部分。请提问，我是怎么做决定的，信息从哪里来，我如何检查工作，以及什么时候你该来问我。一次只问一个问题，然后带我走几个例子，好让我在我们把这件事自动化之前先给你反馈。」

## 让你的 bot 自己改进自己

一旦你的 bot 开始执行这套工作流，重要的是给它反馈，好让它改进。最好的办法是给 bot 配备它自己获取这些反馈所需的应用和工具。我的做法是想，如果是我自己在做这件事，并且想自我改进，我会怎么做。

比如，如果你的 bot 在帮你管理新客户预约，可以让它监测你的邮件、社交媒体，或 Google/Yelp 上的评价，从中看客户反馈，好让它自己改进。它可以发现这些反馈，然后主动提出改进流程的建议。

也许有客户在 Yelp 上说，等了很久才有人来招呼他们。如果你的 bot 能自己在 Yelp 上查到这条信息，再去查你当天关于这位客户的记录，它就有可能看出哪里出了问题。

![](../images/maiyang-lauren-tan-grok-bot-automation/004.jpg)

就这一点看，你的业务越是数字化，对 bot 和自动化就越有利。正是这些数据的存在，让 bot 有能力提出更好的改进。而最妙的是，Grok Bot 可以帮你把获取这些数据的工具做出来！比如，如果你在经营汽车维修，可以请 bot 给你做一个能在电脑和手机上用的应用，用来记录客户到店的细节。

你可以记下下面这些时间。

- 他们何时到店
- 他们何时能和接待人员说话
- 你何时拿到他们的钥匙
- 服务何时开始、何时结束

你就能算出他们等了多久，也更能判断原因。这只是一个简单的例子。关键在于，你能提供给 Grok Bot 的数据越多，它就越能帮助你，也越能帮到你的业务和工作。

如果有类似 ID 的东西，bot 还可以把多个来源的数据交叉对照。所谓 ID，就是某种数字或唯一的文本，比如邮箱地址，能给那条数据一个身份。可以是客户 ID 或邮箱、订单号、零件号、条形码、员工 ID，等等。如果你在用多个应用和服务，让这些工具里的 ID 保持唯一且一致，会帮你把数据汇到一起，让 bot 能完整理解正在发生的事。

## 让 bot 自动开始干活

接下来的问题是，bot 该在什么时候开始干活？是邮件一到就开始，还是有人发来消息时开始，或按固定时间表开始？在 Grok Bot 里，这件事用 routines 来设置。

没有 routine，bot 只会在你要求的时候才做事。刚开始用 bot 时这样没问题，但如果你想把事情理顺，就得想办法让 bot 自动去做，这样你自己就不再是瓶颈。

通常，工作会由某种触发引起，比如一封邮件或一条 Slack/Teams 消息。也可能按固定时间发生，比如每周一次，或每隔一天一次。不管是哪种，只要你让 bot 去设置，它就会去设！
