# awe0（@awe0_io）：跟 AI 别说「布局好看点」——6 种标准前端布局术语让 AI 一秒对齐意图

> 如何精准指挥 Claude Code 或前端 AI 生成符合心意的高质感布局？避免「好看点」这类模糊诉求，直接使用标准前端布局术语：Hero Section（首屏招牌）、Bento Grid（便当格）、Masonry（瀑布流）、Split Screen（左右分屏）、Sidebar Layout（侧边栏）与 Full-width Section（通栏），模块化拼装出严谨 UI。

<!-- more -->

跟 AI 说「布局好看一点」

结果整页每个区块都换了个排法？

因为你没讲清楚要换哪一种布局。

其实这些布局都有名字，直接告诉 AI 就好：

1. Hero Section：首屏大横幅，一打开就是一张大图加一句话，像商店门口的大招牌，先告诉你这是干嘛的。
2. Bento Grid：便当格，大格子小格子拼在一起，像便当盒，一格装一个东西，看着满但不乱。
3. Masonry：瀑布流，卡片像水一样一列列往下流，每列长短不一样，越刷越多。
4. Split Screen：左右分屏，屏幕从中间切开，左边放图，右边放字，两边对照着看。
5. Sidebar Layout：侧边栏布局，左边一条竖菜单，右边是正文，像书旁边一直贴着目录。
6. Full-width Section：通栏，一整条颜色从左铺到右铺满屏幕，像横幅拉满，专门放最重要的一句话。

下次直接说：「首页用 Hero Section，功能区用 Bento Grid，文章列表用 Masonry。」

一句话，AI 就知道每一块该怎么排。
