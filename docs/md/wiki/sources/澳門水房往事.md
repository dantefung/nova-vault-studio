# 疫情前，我在澳門做過兩年「水房」

我在那裡幫賭客過手的錢，大概比我投胎十次賺的還要多。

很多人不知道水房在幹嘛的，說穿了，就是地下錢莊，專門幫人把錢從對岸搬到澳門。對岸有外匯管制，一年只能換五萬美金，但賭客去澳門，隨便一下就是幾十上百萬，正規管道根本不夠用。

於是我們就出現了——你把人民幣匯到指定的內地帳戶，我們在澳門直接拿港幣給你。我們賺的，就是匯差跟手續費。聽起來很簡單，但這行的水，其實深得很。

我會入行是因為我表哥。他在珠海搞水房十幾年，當時說缺人，一個月開兩萬人民幣叫我過去幫忙。還沒搞清楚是幹嘛的我就去了。

我的工作很單純：平常在澳門的賭場飯店待命，客人要錢了，打聲招呼，我們的人確認收到人民幣，我就在澳門把港幣現金或籌碼送過去。一筆交易，手續費抽1%到3%，快的話十分鐘搞定。

## 我第一次送錢

是送給一個中國老闆，在永利的貴賓廳。

他換了五十萬港幣。我提著裝滿現鈔的紙袋走進去，手心全是汗，我這輩子沒摸過這麼多現金。老闆接過錢，算都沒算，直接換成籌碼推上賭桌。

三個小時後，五十萬歸零。

他面無表情地站起來，說：「再給我拿五十萬過來。」

那天晚上，我總共送了三百萬過去。

三百萬，在他手裡就跟三百塊沒兩樣。

做水房久了，你對錢會失去概念。我每天經手少說幾十萬、動輒上千萬。有次一個客人喊了兩百萬港幣，我提著袋子走在飯店走廊，忍不住想：這兩百萬夠我在台灣中南部買幾間房了。但在賭場裡，可能就只是幾把牌的事。

## 形形色色的客人

我們見過形形色色的客人。

有開公司的老闆，輸光公司帳款回去繼續裝沒事；有不敢見光的，用人頭帳戶轉錢，輸了只能吞下去；也有年輕人借網貸湊十幾萬，輸光了在走廊上哭；還看過老太太拿養老金換籌碼，在老虎機前按一整天。

表哥說：
「做這行，不能有同情心。」
「有了你就做不下去。」

不管你是誰，錢到了我們手裡就只是數字。我們不管錢從哪來，也不管你輸光後怎麼辦，只在乎手續費入帳沒。

## 這行的三大風險

但這行風險比想像中大很多，主要有三個：

### 一、黑錢

有時客人轉來的是詐騙贓款。帳戶一收到，半小時內就被警方凍結，錢全沒了還會被查水表。我碰過一次，客人轉四十萬，結果是電信詐騙，警方順著金流查來，表哥花了一大筆錢找關係才壓下來，那四十萬全部充公。

### 二、黑吃黑

這行什麼人都有。有同行假裝客人把錢搶了，也有客人拿假的轉帳截圖騙錢。我表哥就被熟客弄過一百萬，錢放了才發現帳戶沒進帳，對方早就封鎖搞失蹤，一百萬直接咕嘰咕嘰。

### 三、被抓

水房在澳門是灰色地帶，但對岸就是非法經營。這幾年抓得很兇，我認識一個同行在深圳落網，判了五年，賺的錢全被沒收，老婆帶著小孩連生活都成問題。

## 我為什麼離開

後來，我決定洗手不幹；不是怕被抓，是因為一件事。

有天我送八十萬給一個客人。那男的三十出頭，戴副眼鏡，斯斯文文的。他拿到錢沒有馬上賭，而是坐在沙發上，給家裡打了通電話。

「老婆，我在這邊挺好的，那個案子快談成了」「談成就給妳跟孩子換間大房子。」

掛了電話，把八十萬換成籌碼，坐上賭桌。

兩小時，八十萬輸得一乾二淨。

他癱在椅子上雙手抱頭，坐了很久。然後站起來走到窗邊，看著澳門的夜景，又站了很久。

我那時候突然覺得，我們這些做水房的，就像是把刀遞給賭徒的人。他們原本可能還有退路，但我們把錢送到他們手上，讓他們連最後一點退路都沒了。

我不知道他後來怎麼了，但我很常想起他打電話時溫柔的聲音，跟在賭桌前的樣子，完全判若兩人。

隔天我跟表哥說，我不幹了。

## 離開之後

離開水房後，後來去當了疊碼仔，那是另外一段故事了。好幾年後台灣找了份正經工作，一個月四五萬。錢少很多，但我終於睡得著了。

以前每天提心吊膽，怕帳戶被凍、怕被黑吃黑、怕警察找上門，手機24小時不敢關。

現在下班打卡，手機一丟，世界就安靜了。

水房這行，表面上只是幫人轉錢，但客人越瘋我們生意越好。但我們賺的每一分手續費，都沾著別人家庭的血。

水房，就是把賭場跟賭客連起來的那條地下暗河。錢從暗河流過去，變成籌碼，變成賭局。最後變成別人的眼淚。只要還有人賭，暗河就不會停。

澳門的夜景還是那麼美，金碧輝煌的。這條暗河一直都在，只要你看過裡面的金子，你就很難再假裝它不存在。

回台灣後，我以為我上岸了；但其實沒有，其實只是換了一艘更大、更黑的船。
