# 认知外的钱

在X上边看到另维发的一段内容。她说17年自己的微博就已经有200万粉丝了，那时候国内的币圈信息铺天盖地，她却一条都没刷到，也没人带她入行，感慨自己的入行的时间太晚了。



时间拉回17年，我同样感慨一件事。自己第一次接触到一个新鲜事物，抢黄牛货。当时加了一个QQ群，里边发了抢美图手机的线报，说抢到高价回收，抱着试试看的心态抢了一部。第一部手机没卖给收货佬，而是挂到闲鱼交易，结果被秒拍，我强烈要求说对方只能见面交易，否则就不卖了，对方倒是也比较干脆叫了个顺丰，把手机转交给顺丰小哥的时刻对方把钱转给我支付宝了，就这样很顺利的赚了300块钱。



原价6000的手机转手就能卖6300让我大受震惊。第二次我组织了一些朋友一起抢，抢到四五台，分掉利润后又赚了几百块。当深入了解这个行业时才发现，前几年的生意更好做。因为黄牛、饥饿营销在2012、2013年小米刚出来时就已经火了，最早的时候，一个免费的小米激活码就能卖几百块，几乎零成本，有些大学生靠着组织同学抢购就发了财。



那时我才知道，一台利润200块的手机已经是人家不屑的边角料。更夸张的是在苹果6、6S阶段，一台手机差价能拉到大几千，至今还流传着两三万块求一部苹果手机，直接高铁送货的截图。要知道那可是15、16年，钱还很值钱的阶段。



可那时候我在干嘛？还在做校园活动，最常见的是兼职和充场。商家给120块，转手结给学生100或110，一个人头赚十到二十块。微信号没毕业就加满了好友，这些本来都是能帮我抢购的人头啊，结果全白白流失掉了。



我常常在想，怎么在大学时期没人把我引到“正道”？要是那时候去抢小米激活码，是不是早就财务自由了。



有段时间我一直觉得自己选错了行业，做校园活动太辛苦了也不赚钱。后来仔细想，也不是完全没接触过类似信息。比如经常看到有人找学生兼职去苹果门店排队，或者有线上抢购注册的信息。但那时候信息闭塞，我完全没有认知，理解不了为什么一个激活码能卖几百块钱。于是每次看到这类信息，都自动当作骗子信息给屏蔽掉了。



这和当初自己最早接触Web3很像，2020年我开始混各种圈子，加了很多人，其中有个叫张秋兴的，每天朋友圈都在发一些特别劣质的图，配上珍珠又涨了多少钱，或者一天赚几百几千美金的文字。在我看来完全不靠谱，心里想：这东西能比我拼多多下一台手机赚100更真实吗？一天下十台就是1000块钱，你拿什么和我比？



回过头来看，其实我每个阶段都遇到过进入的机会。我都站在门口，却因为认知不够而没有进去。错过是必然的，每个人都会错过一些风口，不可能全都抓住，就像无法赚到认知以外的钱。



如果我的认知不变，就算让我回去一百次，也只有一两次能侥幸抓住机会。更多的时候，我还是会把那些信号当成骗局、当成笑话。也算是给自己一个提示：面对下一个“看不懂”的机会，要不要主动停下来，先别急着下结论，哪怕只是多看一眼。
