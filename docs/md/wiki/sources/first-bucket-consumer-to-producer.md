# 第一桶金从消费者到生产者

如果你像我一样特别的野心勃勃，相信自己未来能有一番成就，但是你现在还处于一个迷茫，焦虑，徘徊，不确定要做什么的时期。

我劝你一定要看完这个视频，因为我会在里面完整的去拆解我是怎么从0~1，以及现在没毕业就能够实现年利润几百万的一个完整的路径。

## 复盘

**第一句话：任何一个人的第一桶金，大概率是从消费者到生产者的一个转变。**

什么意思呢？我迄今为止所有拿到大结果的项目，都是从我自己的一次消费开始的：

- 高中做线上家教辅导 — 因为我会经常在某鱼某书知乎上找老师，看见他们分享好，我就会买他们的产品，然后觉得这个事情我好像也能做，去试一试 — 人生第一个几万块钱的来源
- AI写作项目 — 最开始觉得自己作业懒得写，于是在某鱼上找人帮写，最后发现这个事情我自己也能做，开启了做了三年的项目
- 水晶项目 — 最开始给舍友送礼物，想送平价又好看的，在别人那里买了水晶，于是开启了现在的业务

## 核心洞察

你会发现一个人的第一桶金，很难跳脱出原本的认知框架。

你应该去盘点自己的消费行为和消费逻辑：你愿意为什么东西付费，然后去看这个事情你能不能做，你不能做的一个核心原因是什么？这个原因能不能靠你去借助外力去搜索、搜集各种信息去解决？

## 解决卡点

我这个卡点很难解决怎么办？

你一定要不择手段的去用各种各样的方式去拓宽你的人脉圈、资源圈以及信息圈。

像我自己很多学员，他们去东海已经看过了一圈的货，就会发现自己拿货实在是太贵了，一个月没有100万根本下不来，然后他们就会打听一圈，找到我，然后就发现给我交一个很低的门槛费，就可以直接去用我的货源，这就是属于他们自己去置换出来的资源。

## 承接流量的方法

我去学别人发帖子，然后发现这个流量很大，但是他来了，我承接不住，我自己解决不了，我能不能靠花钱或者说是去托关系，我能去找到别的后端，我说我把流量给你，你能不能帮我做这个事情？

或者说你自己去招聘软件上去发布信息，能不能招到一些人去帮你做这个事情？

比如说我发现客户来了，我接不住，就是我跟他聊两句，他就不跟我聊了，没有下文了，那我能不能去找同行，我去问他，然后我假装一个客户，我跟他一步步聊出来，我盘出来他每一句话背后的引导的动作和用意是什么，然后我根据他的框架，总结出来适合我自己的框架，这样我就拥有了自己谈单和销售的能力。

慢慢的你解决问题的能力就会越来越强，它就会像滚雪球一样，慢慢形成了属于你自己的一个壁垒和优势。

## 能力边界

你会发现，其实每个人的能力边界都是有限的，每个人都很难跳出自己的能力边界。

比如说有些事情对于别人来说是很难的，但可能对你来说，你会发现其实很简单呀，你很容易就能做到。

你在任何一端去形成自己的优势了以后，你的变现方式就不会再局限于说我去卖一单，挣一单的钱。这样是不断的去消耗自己的时间，再换取金钱。

一定是你要去搭建自己的团队，搭建自己的模式。

## 套利模式

比如说你非常擅长搞流量，你的后端交付能不能外包出去，你只用负责搞流量，然后去谈单，去转化就可以了。

比如说你有很强势的一个后端，就是你别人的后端交付率，他满意度只有30%，但你后端的交付满意度能做到60%，你有一个很好的产品，你能不能去找很多的前端去跟他谈合作，就是我给你提供这个交付，我给你去稳定的把控这个质量，但是你去给我怎么分成。

当你在任何一端形成优势的时候，你都可以去实现这样子的一个套利。

到这个地步，你其实都不是去赚这个米了，而是说你钱源源不断的向你滚过来。
