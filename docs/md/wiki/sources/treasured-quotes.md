# 珍藏许久的短句——50句治愈语录

高手和小白的区别，在于高手知道如何去利用各种资源，制定战略规划，并通过高效的方式达到自己的目的。而小白永远都在等着别人发号施令，然后只能干着一些粗浅的工作，成长速度极慢。

这个世界就是这么不公平，同学们会开挂，老师也可能很水，上大学的意义，只是在于给了你四年时间去思考自己该干什么，去尝试自己的每一种可能，去为将来接触社会打好基础。

有缘看到这里的朋友，希望你能知道不公平而加倍努力，不要给自己的青春留下遗憾。

别做梦，也别抱怨，把握好现在的每一个机会，但行好事，莫问前程，立德立言，无问西东。

天晴蓝，天空灰，天生万象。心灯死，性灯灭，万般归土。

今晚月色真美，风也温柔。

> "现代人的崩溃是一种默不作声的崩溃。看起来很正常，会说笑、会打闹、会社交，表面平静，实际上心里的糟心事已经积累到一定程度了。不会摔门砸东西，不会流眼泪或歇斯底里。但可能某一秒突然就积累到极致了，也不说话，也不真的崩溃，也不太想活，也不敢去死。"

你有哪些珍藏许久的短句？

1. 总之岁月漫长，然而值得等待。——村上春树
2. 凡是过去，皆为序章。——莎士比亚
3. 少年与爱永不老去，即便披荆斩棘，丢失怒马鲜衣。——莫峻
4. 没有一个冬天不可逾越，没有一个春天不会来临。——南方周末

6. 四方食事，不过一碗人间烟火。——小灯泡儿

8. 我走得很慢，但我从不后退。——林肯
9. 花看半开，酒饮微醺。——《菜根谭》

35. 人生没有白走的路，每一步都算数。——李宗盛
