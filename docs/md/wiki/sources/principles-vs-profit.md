# 道理重要，还是赚钱重要？

今天聊的内容非常重要，每次有很好的idea，我第一反应往往是先囤着，等合适的时候认真写一篇长文。但每当有这种想法，我就没法专心投入到新的素材，最后还是忍不住写出来，看到的算是有福了。



先讲一个10年前大二时的事。那时在做人人网的校园大使，给了一个虚名去管北京所有学校。正值移动互联网兴起，公司给了任务：监督每个校园大使完成100个app下载。那会哪懂什么pua，心想这么大的任务落在我头上，就说包在我身上。



每个下载还有2块钱奖励，不算太复杂。但是有些学校大使看不上这个奖励，尤其是好一点的学校死活推不动，印象最深的就是那个月我打电话花了一百多，一直在打电话摇人。最后因为这件事和第一代校园大使不少人闹掰了，很多人关系本来不错，经常聚会，但大部分早早就断了联系。



我时常很后悔这件事，因为那是自己第一批积累的人脉朋友，当时的视角很简单：这是公司给的任务，你既然是校园大使，就该完成，完不成就滚。结果就是——我赢了道理，输了感情。后来慢慢明白，这世上没那么多地方是真讲道理的。尤其为了一件无关紧要的任务，与一些人交恶，现在想想也挺莫名其妙的。



(2014年团建照片)



这十年间无数类似的事，让我的阈值慢慢提高，也让我意识到，并不是所有事都要执着于对错。



最近的一件小事，要先说我们的运营模式是把一些项目外包出去，执行团队比较多，同样的工作量，不同团队的执行成本差别很大。前几天一个项目结项后，北风跟我说卓飞的执行成本要比别人高几倍，问怎么办。



我听到后并不意外，很简单，报销费用既然报上来，大概率已经知道自己的费用是超出平均水平的，但是还是报上来，那肯定是有备而来的。去纠结具体金额没意义，掰扯赢了，输了感情。况且一个项目涉及的人多，有贵的自然有便宜的，对我来说综合成本没超预算即可。



所以我跟北风说：这种事别跟我说了，我也不是圣人，听完心里也会不舒服。这种事典型的属于抓大放小里的小，如果自己把精力都放在这上面，公司早没了。



原本我也没想解决这件事，而是在这里看到了一个很不好的点，就是卓飞在做这件事的时候，一定先把道理放在第一位了，这是一个我们行业中非常不好的开端，所以在这讲一下我的思考。



(《大明王朝1566》台词)



我做生意时，肯定不是一个大大方方的人，在非常多方面都会去计较尤其是利润相关的东西，另一方面又特别不计较，经常抹零。这里的矛盾是如果过度让利，公司一定撑不下去；但如果一点不让利，竞品又很多，别人凭什么还愿意合作？这个度，需要拿捏。



再说我们的模式：投资人给钱时，默认这笔投资是安全的，所以衍生出来一个潜规则就是，责任人一定是我。



这就会出现一个矛盾，投资人会觉得：分了不少钱给你，小紫你也赚不少了，能不能搞点优惠，我通常会答应。但实际上给执行人的钱是不会变的（ 除非性价比完全不划算）。衍生出来的问题是有些项目我成了担保商，不赚钱还要承担中间风险，也常常能让人夜里睡不着觉。



做这个动作不难，很多人都在做，难的是什么态度去做面对这件事，我常常看到一些拧巴的情况：有人会说“因为你是大哥才帮你做”，或者“这个项目我亏钱帮你做了”。事是做了，但情绪也甩出来了。



这种话术就是纯粹把别人当傻子的话术，哪个老江湖不知道是在占你了一些便宜，人心中自然有一杆秤，我占了你便宜，但你这个人还不错，那么下次回馈给你，这个回馈可能不是钱，可能是有些对我来说不值钱的人脉或机会，随便给点就够你吃几年的，但是你说出来算怎么回事。



那是不是吃了哑巴亏，被误会了？是的，就是被误会了。



很多人把“误会”觉得是一件天大的事情，我却觉得没那么严重。因为我清楚在合作关系里，关键是看谁占主导权。比如在我和投资人之间，主导权肯定在对方手里。在完全不对等的合作里，有时甚至完全看心情。所以合作最理想的状态是：事顺利，沟通也舒服；即便事不顺利，沟通舒服，也可能继续合作。但如果沟通不舒服，无论事顺不顺利，下次都会觉得难受。



当然一直处于弱势地位的话，那不就是成羔羊了么，任人宰割，我自己的动态调整是，谁处于一线谁对利润的把控会更敏感一些。小项目上，我一般不太重视这些，因为还没触及核心利益。通过小项目这些让利去积累合作中的话语权，在重要的项目上去争取自己的利益。



回到那次结算，我还是把想法沟通了一下。这笔钱放在均值里微不足道，完全可以视而不见。但我还是愿意把原理讲清楚。讲过之后后续大概率也不会再讲了，所有人只有被社会大学教育过才会知道这件事的含金量，重新理解“占便宜”这件事，在合作里，尤其是这种带有信息差的生意，几乎不可能真正占到便宜。当你想明白这一点，这些钱就变得无所谓了。



水至清则无鱼。



道理重要，还是赚钱重要？



道理重要，还是感情重要？



道理重要，还是合作能长久重要？



道理重要，还是彼此都能睡得着觉重要？



这么一比较，道理在哪都是最廉价的。
