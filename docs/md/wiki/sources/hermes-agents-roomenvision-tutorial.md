# Hermes Agents 实战：RoomEnvision 上线

作者：范范，2026-08-24 发布

## 项目

RoomEnvision：AI 房间改造工具，上传照片选风格，几秒生成改造效果图。
官网：`https://roomenvision.pages.dev/`

从代码到上线、支付全链路跑通、提交商店审核——一天。

## 三个核心概念

| 概念 | 说明 | 作者评价 |
|------|------|---------|
| Profile | 独立 Hermes 实例，各自配置/API 密钥/记忆/会话/技能互不干扰 | 管「状态」不管「工作目录」，桌面端 Project 工作区不便，需手动分目录 |
| Skill | 按需加载的知识文档，平时只带技能清单 | 技能可以自己长出来，沉淀流程后下次直接调用 |
| Agent Loop | 模型决定下一步→调用工具→执行→看结果→再决定，循环往复 | 不回答完就结束，危险操作会停下来等确认 |

## 实战一：查官方文档理清 7 项合规清单（半小时）

支付选型：Creem（个人可注册、MoR 模式税务发票全包、支付宝直提人民币）

Hermes 自行读 Creem 审核文档整理出 5 项核心 checklist：政策页面必须存在无需登录可访问、AI 产品需 AUP 禁 NSFW/有害内容、客服邮箱与商户资料一致（审核被拒最常见原因）、内容审核 API 正式环境开 production 模式、用户可自助取消订阅。

额外发现：测试环境审核 API 宽松，违规词放行，真实拦截效果必须到正式环境验证。

## 实战二：8 个产品全自动重建 + 26 个环境变量

4 套餐（Basic/Pro/Scale/Team）× 月付/年付 = 8 产品，Creem 测试/正式环境完全隔离。

Hermes 全自动迁移：读配置→正式环境重建 8 产品→配置 webhook→更新 26 环境变量→重新部署→逐项验证（违规词真拦截、checkout 指向正式域名、错误签名 401/正确签名 200）。

部署：数据库建表、生产迁移、图片存储、限流、6 个中英文政策页面，全程没碰终端。

## 技术选型

- Next.js 静态导出 + Cloudflare Pages（几乎零成本、全球边缘网络）
- D1 数据库 + R2 图片存储 + KV 限流（全家桶不用运维）
- Replicate 跑 FLUX 模型（单张约 $0.08）
- Google One Tap 登录

## 核心判断

> AI Agent 有没有用，不看它多聪明，看它能不能把体力活接走、把判断留给你。
