# 山羊赚钱笔记（@shanyanggm）：做内容营销，参考这 8 套框架

> 8 套经典内容营销文案的骨架清单及其适用场景：AIDA（吸引注意 → 引起兴趣 → 激发欲望 → 促成行动）、PAS（指出问题 → 放大痛点 → 提供解决方案）、BAB（改变前的处境 → 改变后的状态 → 改变的路径）、ACCA（知道 → 理解 → 信服 → 行动）、QUEST（筛选受众 → 理解需求 → 讲解知识 → 激发兴趣 → 引导下一步）、SLAP（停下来 → 吸引目光 → 促成行动 → 完成购买）、4C（清晰易懂、简洁直接、有吸引力、可信可靠）、5A（了解品牌 → 产生好感 → 主动询问 → 采取行动 → 推荐给别人）。

做内容营销，参考这 8 套框架：

1. AIDA：吸引注意 → 引起兴趣 → 激发欲望 → 促成行动。

2. PAS：指出问题 → 放大痛点 → 提供解决方案。

3. BAB：展示改变前的处境 → 描绘改变后的状态 → 给出实现改变的路径。

4. ACCA：让人知道 → 帮人理解 → 建立信服 → 推动行动。

5. QUEST：筛选目标受众 → 理解需求 → 讲解相关知识 → 激发兴趣 → 引导下一步。

6. SLAP：让人停下来 → 吸引目光 → 促成行动 → 完成购买。

7. 4C：清晰易懂、简洁直接、有吸引力、可信可靠。

8. 5A：了解品牌 → 产生好感 → 主动询问 → 采取行动 → 推荐给别人。
