# 做海外产品推广，可以先把这个外链表跑一遍

> 最近看到一个叫 [mkdollar.com](https://mkdollar.com) 的网站，适合做出海产品、AI 工具、SaaS 和工具站的独立开发者，名字寓意也挺好 XD

它的核心功能很简单：整理一批可以提交产品的网站，并标出 **DR、流量、价格、是否 Dofollow、是否需要账号、所属分类**。

![网站概览](images/mkdollar-backlinks/001.png)

产品上线后，很多人都会去找 Product Hunt、Hacker News、AI 工具导航站、SaaS 目录站、插件推荐站。但一个个打开看，很容易浪费时间：有的站已经不维护了，有的入口藏得很深，有的写着免费，提交到最后才发现要付费。

MkDollar 把这些判断先放进一张表里：

| 字段 | 说明 |
|------|------|
| **DR** | 网站权重的大致参考 |
| **Traffic** | 网站大概有没有访问量 |
| **Pricing** | 免费、付费，还是混合提交 |
| **Dofollow** | 外链是否更有 SEO 价值 |
| **Account** | 提交前是否需要注册 |
| **Category** | 网站类型 |

![筛选功能](images/mkdollar-backlinks/002.png)

比较实用的是筛选功能。比如早期产品预算有限，可以先筛 **Free + Dofollow**，优先提交免费、相关性高、权重还不错的网站。

## 产品管理

MkDollar 还有一个更偏管理的功能：你可以提交自己的产品，然后记录这个产品已经在哪些网站提交过外链。在 Dashboard 里输入产品域名，它会自动拉取产品名称、描述、Logo、OG Image、DR 等信息。

![Dashboard](images/mkdollar-backlinks/003.png)

后面就可以进入产品详情页，管理这个产品对应的外链提交记录。每个外链有状态：Unknown、Submitted、Approved、Rejected。

![外链状态](images/mkdollar-backlinks/004.png)

这个功能比单纯收藏一堆网站更实用，因为外链提交本来就不是一次性动作，而是一个需要跟踪的列表。

## 操作顺序

如果你刚上线一个 AI 工具、SaaS、小插件或模板站，可以按这个顺序跑一遍：

1. 先筛 **Free + Dofollow**
2. 挑 DR 较高、主题相关的网站
3. 准备英文产品介绍、Logo、截图和官网链接
4. 提交后把状态记下来
5. 一两周后回看哪些站点通过了，哪些带来了点击或收录

> 外链提交不要想得太神。它不会让产品突然爆起来，也不是每个站点都会收录。但对早期产品来说，先把免费、相关的渠道跑一遍，是一个成本很低的推广动作。

如果你正在给海外产品做第一批外链，MkDollar 可以先收藏一下。它不只是给你一张外链网站清单，还能顺手帮你把提交进度管起来。
