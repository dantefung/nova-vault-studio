# 胡二虎 Will Hu（@willlhhh）：在 Manus 负责增长的实战思考——从制造 Agent 到驾驶 Agent 的能力模型演进

> Manus 增长与商业化负责人胡二虎（Will Hu）出海思考：未来经营组织中 Agent 数量会远超人类，个人转型为 Agent 制造员与驾驶者；提出广告投放本质是信号学、SEO 是不可或缺的基础盘但需靠 Agent 极简打理、商业化必须算清真实经营账本，并推出个人知识分身 Wigent（wigent.ai）。

<!-- more -->

Hello，我是二虎🐯，也可以叫我 Will。

2021 年毕业后一直在创业公司做 SaaS 出海。做过 3 年产品经理，现在在 Manus 负责广告和 SEO，也兼职干点商业化产品经理的活。

3 年前立的 flag 还在：希望自己能在 AI 这件事上热爱 10 年。

重新介绍一下自己。先聊聊我现在最关心的 Agent、广告和 SEO，再讲这些想法是怎么一路长出来的。

01 / Agent：我的新职业，可能是制造员和驾驶者

我越来越相信：以后一个负责经营和增长的组织里，Agent 的数量会比人多。

我想象中的样子是：投放调价、SEO 维护、素材分析、数据监控、竞品追踪，每一件重复的事都有 Agent 在跑。人不多，但每个人身后都带着一队 Agent。

这几年，我已经习惯把竞品研究、公开数据收集、广告素材和 SEO 页面分析先交给自己的 Agent 跑一遍。以前只能看几个样本，现在能看更多。

按我的体感，以前做增长，花在创新上的时间大概只有 5%；现在倒过来了，95% 的时间都在创新。效果投放里的各种优化、反复改定价页这类工作，正在很快被自动化。

所以，我想象中自己的工作会变成两件事：

Agent 制造员：把一件重复的增长工作拆清楚，做成能稳定干活的 Agent。

Agent 驾驶者：决定它往哪跑，看数据判断它跑得对不对，跑偏了自己接管。

这让我想起 3 年前给自己设想的能力模型：

• 半吊子的工程师，不分前后端运维

• 出海增长专家，主要是 SEO / SEM

• 不专精的产品舵手

• 合格的数据分析师

当时写“半吊子的工程师”“不专精的产品舵手”，多少有点心虚，觉得是自己没进过大厂、不够专精。

现在回头看，什么都会一点、能自己把一件事从头做完，可能正在变成 AI 时代每个人的标配。近一年，我也是第一次开始自己往线上提交代码。

那四个能力没有过时，只是换了个用法：工程和产品用来制造 Agent，增长经验和算账能力用来驾驶 Agent。但很多过去的打法，确实要重新学。

Agent 再多，人也不会没用。数据抓回来，不等于结论就是对的。问题怎么问、结果怎么核对、最后要不要做，还是得人来定。

这套能力模型，也正在改变我做广告和 SEO 的方式。

02 / 广告投放：我越来越觉得，它本质上是信号学

我理解的广告，有两套系统要打通：

系统 1：把产品能力翻译成市场容易看懂的广告素材，让用户明白它能帮自己做什么。

系统 2：把商业化结果翻译成广告系统容易理解的信号，保证信号的密集度和准确度，让系统知道什么样的用户值得继续找。

广告不能只看前端的点击和注册，还得看这批用户进产品后有没有留下来、有没有付费、多久能回本。

最早写这篇自我介绍时，还是“最近接手了相当多的 SEM 工作”。现在已经是 Google / Meta / TikTok 几个渠道一起投了。

目前正在跟团队一起打磨这两套系统。

03 / SEO：它是基础盘，但未必是以后让你赢的理由

SEO 一直是我比较擅长的方向，尤其是 SaaS 工具类产品。

我现在的看法是：它还是得做，是增长的基础盘。但大家找信息的习惯正在被 AI 改变，它以后大概率不再是让你赢的那个理由。

所以更适合交给一个人 + 一个 Agent 稳稳维护，把人省出来去做新东西。

这个想法，是从过去做 SEO 的经历里慢慢长出来的。

之前给 3 个网站做过程序化海量页面，大多拿到了很大的流量。但我一直不觉得，页面多、流量大，就等于增长成功。

在 Monica，接手时 SEO 月流量不到 10 万。技术基础有不少问题，做页面也很依赖多人协作。

后来跟团队一起，先修技术问题，再挑真正有需求的工具和页面，最后把页面生产改成低代码系统。

大概 8 个月，月流量最高做到了约 400 万。

到了 Manus，SEO 已经是一套不需要我天天盯着的维护体系。现在 Ahrefs 上的自然流量估算约 100 万，由一个人 + 一个 Agent 打理。

这是我前面说的“每个人身后都有 Agent”的一个小例子。我们团队正在往这个方向猛冲。

这里面有很多关于地区、设备和具体需求的 insight，欢迎找我讨论。

04 / 商业化：不管从哪个渠道来，最后都要回到经营的账本

无论广告还是 SEO，找来用户都只是开始。做过商业化之后，我看增长的方式也变了。

在 Monica 的 15 个月里，除了流量，也跟团队一起做了 onboarding、定价、退款和渠道。同一阶段，日收入翻了好几倍。还做过 Affiliate 渠道，做到了整体收入的 10%–15%。

再看一个增长项目，会多问几句：找来的是什么用户？为什么愿意付费？付费后有没有继续用？获客的钱多久能收回来？

也停掉过看起来很热闹、但 ROI 算不过来的项目。

现在还是喜欢搞野路子，但最后要能回到经营的账本上。

05 / 产品：能把人找来，不等于能让人留下来

账能算过来，也不代表产品就做好了。

快速做一个满足基础需求的 MVP，再通过用户反馈慢慢把它做大，还是我比较擅长的事情。

短板也还在：没体验过花一个月只做一个功能版本，对单个需求想得不够深。

这几年一直在对用户体验要求很高的团队里，每天都在补这一块。能把人找来是一件事，让人真的用起来、持续用下去，是另一件事。还在练。

而且我觉得这块短板以后更值得补：功能会越来越容易被做出来，用户愿意留下来，更多是因为喜欢这个产品，也信得过背后的团队。

06 / 往回看：这些想法，是从野路子里长出来的

简单过一下经历：

• 大学时，在一家互联网小厂做过半年产品实习。

• 2021 年毕业后加入广大大（SocialPeta），做产品经理，从这里开始做出海。

• 2023 年底加入 Monica，继续做产品经理。

• 2024 年上半年转去负责产品自然流量增长，主要是 SEO；年中开始接触海外广告投放。

• Manus 发布后，开始负责它的广告（Google / Meta / TikTok）和 SEO，也做一些商业化产品工作。

刚进入出海时，完全是野路子玩家。不知道怎么系统性地做增长，也没搭好增长的数据体系。

但跟团队一起，依靠插件市场内的自然流量，做过超过 40 万用户的产品矩阵，没花一分钱买量，也没借助 SEO、SEM 或红人。

到现在还是很佩服当时在广大大的团队，硬生生挖出了一条行之有效的野路子。

这一路都是创业公司，做产品和找用户很难分开。我慢慢养成了一个习惯：从第一天就想用户从哪来、为什么愿意付费、这件事能不能持续经营，把自己当成产品的 CEO。

——

从这些经历走到现在，我还有一个越来越强的感受：增长正在变成一个信任问题。

Agent 能复制，打法也能复制，但用户信不信一个团队，没法直接复制。

我觉得以后，人会花更多时间在“被信任”这件事上：把真实的经历、判断，甚至踩过的坑公开讲出来。这也是我开始在社交媒体上认真写东西的原因。

我也先拿自己试：

Will + Agent = Wigent。

想把自己的经验、判断和工作方式，慢慢沉淀成一个能跟着我一起长的个人知识分身。我注册了 https://wigent.ai 这个域名，网站先搭好了，分身还在慢慢造。

会在这里慢慢写下我在出海 AI 里的实践：Agent、广告投放、SEO、商业化经营，还有产品思考。

还是喜欢跟真正动手做事的人交朋友。我超级 E 人，不用担心和我聊天会尴尬。

如果你也在做 AI / 出海 SaaS / 增长，或者也在用 Agent 做增长和经营，特别想认识你。
