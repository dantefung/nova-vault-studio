# Marvin：如何用 Claude Fable 5.2 做 SEO

> 卖产品/服务/工具站的 SEO 流程：先给模型 GSC 28 天数据（选定国家设备、同口径复盘）→ 挑有成交机会且大品牌没占满的词（已有页面优先更新）→ 让这页回答下单前问题（别编事实）→ 上线前核对结构化数据/sitemap/索引 → 每周只改 3 页（排名 5–15、有展现）；附可直接复制给 Claude 的任务单。

<!-- more -->

用 Claude Fable 5.2 做 SEO，先挑一个有成交机会的词，把一页做扎实，再决定要不要扩大产量。

这套流程适合卖产品、卖服务、做工具站的人。照着做：

## 1｜先把真实数据给它

准备 Search Console 近 28 天的查询、点击、展现、平均排名和对应页面。选定国家与设备，后面复盘保持同一口径。

再补关键词工具的搜索量、当天搜索结果、你自己的产品资料。Search Console 的展现量不能当成市场月搜索量。

不会接 MCP，就先上传导出的表格和页面资料。ChatSEO 这类集成工具可以省步骤；也可以自己组合数据源。AI 没拿到的数据，统一标“缺失”，别让它补数字。

Claude Code 使用 Fable 5.2 前，先更新，再启动：

claude update

claude --model claude-fable-5-2 --effort high

## 2｜挑一个值得做、也有机会做的词

假设你卖茶几，可以先核对“小户型橡木茶几”这类具体需求。它只是选词示例，搜索量和竞争要实际查。

看当前前三名：主要是商品页、分类页，还是教程？页面类型要跟用户的任务匹配。再看前十名有没有同量级的网站，大品牌挤满的词先放后面。

写之前，在 Search Console 按查询筛选，再看“页面”。如果已有页面承接同一需求，优先更新它，避免反复新建相似页面。

![](../images/growaiskills-fable-5-2-seo/002.jpg)

## 3｜让这一页回答用户下单前的问题

让 Claude 读前三名，列出大家都回答了什么、哪里还没讲清楚。只补跟你的用户有关、你也拿得出证据的内容。

卖茶几，就补实测尺寸、木纹细节图、适合多大空间、运费、送达时间、退换条件。别把三篇文章拼成第四篇，也别编造实测和评价。

推理预算可以这样分：清洗表格用 Low，读竞品和归类用 Medium，关键页面的推敲与核查用 High。先跑一页，再看投入值不值。

![](../images/growaiskills-fable-5-2-seo/003.jpg)

## 4｜上线前，过一遍能检查的项目

核对标题与主标题是否清楚、描述是否准确、网址是否简洁；补相关内链，压缩图片，写准确的图片说明。

商品结构化数据要与页面上的价格、库存一致，并通过验证。检查新页面是否进了 sitemap，再用 URL 检查工具看抓取与索引状态。

AI 写完后，人逐项确认事实。进了 sitemap、提交了索引，都不等于已经收录，更不等于有排名。

## 5｜每周只挑 3 页来改

从近 28 天里筛出平均排名 5～15、已有展现的查询，按页面归组，优先看展现较多且与业务相关的 3 页。

有展现、少点击：核对标题、搜索意图和结果页竞争。

有点击、少询盘：结合站内分析，看内容有没有答疑，行动入口是否清楚。

记录改了哪里、哪天改、改前数据。确认重新抓取后，再按相同口径观察。别把“等 60 天”当成固定规则，也别拿新模型发布一天就宣称 SEO 见效。

![](../images/growaiskills-fable-5-2-seo/004.jpg)

## 可直接复制给 Claude 的任务单：

“根据我提供的 GSC、搜索量、搜索结果和产品资料，选出 10 个有成交机会的候选词，注明数据来源。检查已有页面后，只选 1 页：列出竞品遗漏、我能证实的补充内容、具体修改稿和上线检查表。缺数据就标缺失，未核实事实标 [待核实]。先交草稿，等我确认再发布；附上修改记录和复盘指标。”

模型与设置：https://code.claude.com/docs/en/model-config

抓取与索引：https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl
