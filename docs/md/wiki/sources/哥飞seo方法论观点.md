# 我也简单说说我个人的观点

就推友提到的问题其实我之前也有同样的疑惑，理论上吃饭的本领肯定不轻传，如果这个模式很挣钱，那不应该大量培养竞争对手。

我与哥飞老师素未谋面，素不相识。我最近一直也在找创业的方向，但是我通过AI助手分析了哥飞老师公众号的大量免费文章，我得出来的结论大致是这样的：

## 商业逻辑

简单来说大致是：找已经有流量的东西 → 反查用户在找什么 → 找到自己能切入的需求 → 快速上线 → 用真实流量和收入验证 → 成功的继续放大。

本质上我理解是讲述了一套非"创造需求"，而是"从已有流量里发现需求，然后用小网站去接这部分需求"的方法论。

同时，提供了相对来说比较具体的落地实操步骤。我印象中有提到先打一些"小词"，先通过相对"容易"的词来练手，找商业直觉。

## 实操变数

但是这套打法整体实操下来，能否拿到比较不错的结果，还有很多"变数"。举个例子，词找的不错，当前的产品市场也有不足，但是我们做出来的产品也没比市面上的好多少，可能最后也不一定有满意的结果。这套打法的每一个环节都可能直接影响最终的效果。

## 未公开项目

还有，就我了解，哥飞老师一些项目是不公开的。我们假设哥飞有一个站是做"AI生成证件照片"的，每个月收入可观，这里就回到推友的问题了，如果告诉大家说这个站每个月的订阅/广告很赚钱，那么大家分分钟每人复刻一个，这就涉及到根本的利益冲突。

## 核心结论

所以，我理解核心哥飞老师教的是一套方法论，这套方法论适应360行，但是每个人能做出来多大的结果，就是学艺在个人了。比如我，现在就没拿到任何结果（手动狗头），还在努力～

以上仅代表我个人观点，不喜勿喷，也欢迎大家客观有效的交流
