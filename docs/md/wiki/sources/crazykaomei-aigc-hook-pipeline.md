为什么绝大多数人找达人拍视频或者自己做矩阵全赔钱？ 因为大家都在犯这 2 个致命错误：

- 从产品功能自嗨，不说人话： 他们严禁文案写任何高大上的参数，必须把几千条真实买家的评价（Review Vault）喂给 AI，用买家骂人或夸人的原话去写脚本。

## 01 / 爆款底层逻辑：26 亿播放背后的 “反直觉带货公式”

在外行眼里，做短视频带货要想爆，总觉得得请高薪策划、找热门网红合作、以及砸重金买流量投流。

但在 Lucas 这类操盘过 62 场活动、追踪 22,504 条视频的顶级老手眼里，短视频带货其实是一门极其冷酷的 “概率控制与流程把关学”。

很多人以为调度 590 位博主得养一个几十人的大团队。 

事实上，他的团队：0 项目经理、0 专职文案、0 数据分析师，整条线全靠一套自动化的 Agent 工作流在转。

他把整套搞钱逻辑浓缩成了一个极简闭环：

- 痛点素材库全部来自真实买家评价（严禁策划在办公室自嗨编词） 
- 视频前 3 秒 100% 锁死爆款钩子（绝不让博主随意发挥）
- 画面呈现真实自然、接地气、别碍事就行
- 发布前把关，Agent 逐句排查 “前 3 秒跑题”（Hook Drift）

传统卖家的做法是：品牌方写一份自嗨的方案给达人 ➜ 达人自由发挥开拍 ➜ 开头寒暄废话 5 秒 ➜ 完播率断崖式下跌 ➜ 投流赔到底掉。

而 Lucas 的做法是：收回博主在前 3 秒的自由发挥权，把 AI 当成爆款解剖刀和严格的把关人。

## 02 / 拆解 Lucas 的 5 步自动化生产流程

Lucas 在原文中公开的这套系统，核心分为 5 个环环相扣的步骤：

> Step 1：把买家的嘴，变成你的带货文案

Lucas 团队有一条铁律：绝不允许文案凭空瞎编！ 

他们从各个平台的真实评论区里爬取了 13 万多条真实买家留言。 

然后发现，一条点赞破百万的爆款短视频，第一句话往往就是买家自己的原话。 

比如买家留言里反复出现一句：“等等，这玩意儿居然真的管用？”（出现过 847 次）。

Lucas 直接把它拿来当视频第一句，单条直接跑出了 210 万播放！ 

最好的带货话术，永远不需要高级策划去憋，买家早就替你写好了。

> Step 2：把同行的爆款扒皮抽筋（逆向拆解）

让 AI 读视频不是直接硬塞 MP4。Lucas 做了一个很聪明的小工具链： 

- 自动把同赛道近期跑得最好的 50 支爆款视频下载下来；
- 重点抽出前 3 秒的画面镜头和动作；
- 提取前 3 秒的语音台词和屏幕花字； 

然后整理成一份纯文本的 “解剖清单” 给大模型，几分钟就能让 AI 同时比对 50 支爆款的开场共性。

> Step 3：按 “骨架结构” 给钩子分类

这是 Lucas 抓出 “4.2 倍播放差距” 的关键一步。 

他要求 AI：不要按视频聊什么话题分类，必须按「开场第一句的骨架套路」分类！ 比如：

- “第一人称反转型”：你以为我在做 XX，其实我是在 YY 
- “避坑警告型”：千万别碰 XX，除非你已经做好了……
- “反常识共鸣型”：真希望我在买房/考试前就刷到这个视频 

分类后他们发现：同样推广一款产品，全员统一采用同一套黄金开场结构的活动，平均单条播放 12,333 次。

而让博主各显神通的活动，平均只有 2,921 次！

> Step 4：给每个博主量个性化话术

给达人发那种又臭又长的品牌宣传册，达人根本懒得看。 

Lucas 让 AI 根据每位博主平时的讲话语速和风格，把【买家真实词汇】和【爆款前 3 秒套路】融合成一份 200 字以内的专属拍摄指导。

然后让博主用他最顺口的口癖把核心卖点说出来，达人配合度直接提升 31%。

> Step 5：视频发布前严格把关（掐死跑题）

这是最硬核的一道防线。

博主交片后，AI 会在发布前逐字逐句核对视频的前 3 秒： 

- 画面有没有在第 1 秒就抓住眼球？
- 博主有没有把那句核心痛点台词念偏？ 

一旦检测到博主开头又在说 “哈喽家人们，今天天气真好” 这种废话 🤣

系统直接自动拦截并提示：“前 3 秒跑题，预计完播率会断崖下跌，请把第一句换成 XX 重录”。

## 03 / Lucas 核心 Prompt 架构（中文重构版）

Lucas 在原文里放出的提示词很长，烤妹儿帮大家把里面的海外黑话全部洗掉。

然后整理成了 3 个最核心、复制到 DeepSeek、Codex 或者豆包里就能跑的中文模版：

模版一：买家评价挖宝与爆款逆向 Prompt

这个提示词可以帮你从买家评价里提取真正的痛点词汇，告别策划自嗨。

```
输入提示词： 你是一名顶级的短视频爆款研究员与电商投放老手。 这里是我们收集到的 100 条真实买家评价（包含好评与差评）以及同行跑得最好的 3 条爆款文案： [粘贴买家真实评价与同行爆款文案]

请帮我做三件事：
1.【提炼真实人话】：找出买家在评价中最常说的 10 个生活口语词汇（严禁出现任何生硬的广告术语，必须是普通人平时吐槽或夸人时的大白话）；
2.【挖掘核心顾虑】：买家在下单前最大的 3 个犹豫和担心是什么？针对每个担心，写出一句扎心的痛点反问句；
3.【总结开场套路】：拆解同行爆款的前 3 秒文案，提炼出它们的开场骨架结构，并结合我们买家的真实语言，写出 5 个能在第 1 秒让人停下滑动的黄金开场白。
```

模版二：博主专属短视频脚本生成 Prompt

这个提示词把买家原话，变成博主愿意念、前 3 秒绝不跑题的带货脚本

```
输入提示词： 你是一名短视频编剧导演，请为我们的产品写一份 30 秒口播带货脚本。 产品信息：[简要描述产品] 目标受众：[受众群体] 核心开篇第一句：[填入模版一生成的开场白] 买家最常提的痛点词：[填入买家评价中的原词]

请严格遵守以下要求：

1. 第 0~1 秒（生死线）：第一句话必须直接抛出核心钩子，画面必须同步给到核心动作或冲突，严禁任何寒暄打招呼的废话；
2. 第 1~5 秒（留住观众）：紧接着第一句话给出解释，用买家的大白话把痛点点透，给观众继续看下去的理由；
3. 第 520 秒（给解决方案）：用 23 个具体的生活场景展示产品怎么解决问题，不要堆砌参数；
4. 第 20~30 秒（临门一脚）：自然顺畅地引导大家去评论区或橱窗查看。 请输出分秒对照表（包含时间轴、画面动作、口播台词、屏幕文字）。
```

模版三：发布前 “前 3 秒防跑题” 把关 Prompt

这个提示词帮你在视频发出前严格把关，掐死 4.2 倍播放暴跌的元凶。

```
输入提示词： 你是一名经验老道、眼里揉不得沙子的短视频把关人。 这是我们原本要求的开场核心钩子与脚本要求：[粘贴要求] 这是博主录制提交的实际视频前 5 秒内容与逐字稿：[粘贴博主实际台词与画面描述]

请帮我把关前 3 秒的抓人程度：

1. 跑题审查：博主在前 3 秒有没有完整表达核心痛点？有没有夹带多余的废话？
2. 划走风险：如果博主的前 3 秒跑偏了，观众直接划走的风险有多大（高/中/低）？
3. 改写建议：不要讲空话套话（严禁使用“建议更有吸引力”等废话），直接写出一句让博主重新补录的【具体台词替换方案】，控制在 20 个字以内，直奔主题。
```

## 04 / 普通人 & 国内和出海卖家如何照抄作业？
