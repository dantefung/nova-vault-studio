# 普通人如何“上牌桌”？

风口是风口，牌桌是牌桌。



很多人追了十年风口，最后才发现自己连一张能坐稳的桌子都没有。



之前我们讨论了一种赚钱的方式，叫做“升维思考，降维做事”。有伙伴问：



普通人怎么找到一张属于自己的、别人不容易挤进来的牌桌？



为什么很多人穷其一生都在苦苦寻找机会，却始终两手空空呢？



假设你是一只小兔子，看你是怎么破局的。



森林里有一张巨大的、华丽的大桌子，上面摆满了各种金银珠宝美味佳肴。不幸的是，但凡是这种桌子，周围都挤满了狮子老虎狗熊大象这样的狠角色，清一色的身强力壮牙尖嘴利。



小兔子很沮丧，毕竟它也曾经试过拼尽全力的想上桌，结果不但一无所获，还搞得自己受了一身的伤。毕竟成年人都知道，努力真不一定有结果，唯有受伤是可以确定的。



终于，小兔子明白了，大桌筛选的是体型和战斗力，这是自己再怎么努力也填不平的差距。所以它断了这份念想，再也不内耗了，再也没有那种“我又落后了”的羞耻感和“为什么我总是抢不到机会”的挫败感，这不是躺平摆烂，是极度焦虑后的清醒。



后来，小兔子走到森林深处，无意中发现了一张破破烂烂的小桌子，桌子腿是歪的，桌面上脏兮兮的，堆满了没人要的烂果子。



小兔子问：这里有人坐吗？



刺猬告诉它：没有，狮子嫌它太脏，老虎嫌它太矮，狗熊嫌它太偏。但你可以找找，这些烂果子里偶尔也能挖出一些金子。



小兔子半信半疑，开始坐下来收拾这些烂果子，给它们剥皮去核。果然，这其中一些烂果子的果核里真的能挖出一丢丢金渣渣，虽然很小，但只要你肯努力，也能积少成多。于是它开始稳住心神，继续专注，慢慢的居然也攒了一小袋金子。



消息传出去，狮子老虎狗熊大象们都跑过来看，但它们都觉得：



“这也太慢了吧，金子太小了，而且太麻烦了，还得一颗一颗的用手剥。总之，这活儿又脏又累，还丢人。”



于是，它们马上又转身回去挤那张金碧辉煌的大桌子去了...



小兔子乐了：你们都看不上，这不正好没人跟我抢吗？



从此，小兔子每天都坐在那张又小又破的桌子上，踏踏实实的处理那些烂果子。关键是，还没人来抢，因为没人愿意弄脏自己的爪子。



慢慢的，小兔子发现，其实森林里最爽的就是自己了：



故事讲完，回到现实。



绝大多数人找不到属于自己的牌桌，实际上是因为他们用的是“找风口”的方法。而所谓风口，其实就是那张金光闪闪的大桌子。



但问题是：



风口是风口，牌桌是牌桌，这是两回事儿，就算某个东西是风口不假，但它跟你没关系。



如果你把它当自己的牌桌，就大错特错了，你一头扎进去，只有当行业的炮灰、趋势的NPC、时代的眼泪。 相反，最坚固的牌桌，往往不是最热闹的，而通常是在那些精英们、大玩家们、资本们不愿意来的角落里。这种地方，才恰恰是普通人能稳稳坐住的地方。这就好像，一条狭窄的、崎岖的小路，只要你愿意跟它做朋友，时间久了，它就只认你一个人，别人谁来谁摔跟头。



我记着好像是在某个海岛，经常被达尔文拿来讲《进化论》，说的就是这个道理。在这个岛上，不同的鸟类把嘴形和食物种类都错开了，它们有的吃大一点的种子，有的吃小一点的种子，有的抓鱼吃，有的捉虫子吃，谁也不抢谁的，大家都活的很好。它们并不追求比对方更强，只是不挤在同一张牌桌上。这种现象叫“生态位分化”。对于自然界的物种来说，最危险的往往不是天敌，而是去和那些强者争夺同一种资源，天敌最多只能单杀个体，但如果去和强者抢资源，就会被灭族。想长期发展，不能靠竞争内卷，而是找到强者不吃的食物、不感兴趣的领地。



老一辈的革命能在当时那种恶劣环境下逆风翻盘，靠的也不是争夺资源丰富的大城市，而是在敌人控制薄弱的农村求发展，你们不是看不上吗？那正好，我来建立根据地。



秦国能统一六国，很大程度上是因为它的地理位置很偏，别人甚至都不拿它当人，所以不会卷入激烈的中心消耗，反而能猥琐发育，后来才有条件进行一系列的内部改革，在角落里积攒家底。如果一开始就坐在最华丽的牌桌上，别说统一大业了，能自保就不错了。



市面上靠这种思维赚钱的人有很多：



1. 有的自媒体账号比较冷门，专做那种职业资格考试的内容，也不露脸，也不追热点，更不会火，播放量和粉丝数少得可怜，但每个粉丝都精准，有人买资料，有人问陪跑，个个都是真买主。小众不等于没价值，流量越泛，转化越难，话题越窄，越能直接成交。适合自己的牌桌不一定有万人关注，只要有人持续需要你，并且不容易被替代。放弃大流量，却能换来了一小群离不开你的客户。



2. 有的人专门给老人处理数字业务，比如线上挂号、缴费、做各种认证、清理手机什么的。这种业务的价值在于，老人不用再单独面对屏幕。很多老人的问题小到没人愿意管，但这些小问题是海量的，每天都在发生。事情虽小，但老人自己很难完成，子女又不在身边。也是按次收费，服务范围就附近几个小区，有的老人也会推荐给邻居，也有子女主动加联系方式的。如果你家里也有老人的话，就能明白这种需求有多要命。这种看上去很低端、很low的面向老人群体的手机教学账号，大家可以去搜一搜，你看他们那播放量和粉丝量，保准让你吃惊。你们那些资本、精英人士什么的不都喜欢研究AI吗？又是什么行业新闻，又是什么各种名词术语，我偏不，我就教老头儿老太太们怎么用手机、买东西、刷医保、调字号、查地图，我不去跟你们抢，你们也别来跟我争。前几年江苏电视台还有新闻，说是有几个年轻人开了线下培训班，去上课的老人乌央乌央的...



3. 还有那些教英语的，那些培训机构账号那叫一个高级、洋气，恨不得专门请个老外来拍视频...有的人偏不，我就穿个睡衣带着孩子一块拍摄，就拍那些简单的不能再简单的单词，而且生怕你听不懂，把每个单词都打印成卡片，每次就讲一两个，掰开了揉碎了讲。你们继续高大上，我就干这些基础的、傻瓜的，把各种少儿英语读物挂小黄车，去看销量，我甚至怀疑那些做得好的宝妈们比培训机构赚的都多。



4. 有很多大叔，中年危机了，开始骑个电动车走街串巷，专做本地千家万户的小修小补。比如各种安装问题、水电问题、水暖问题什么的。网上接单是最基础的，再加上为人热情、手艺靠谱、价格公道容易产生回购和转介绍，再加上在策略上主攻那些更容易出各种问题的老旧小区，月入过万的大有人在，而且还不是大城市，只是二三线城市。本地信任的业务复利，比网上那种泛流量更直接、更牢固，越干越有回头钱。

具体该怎么执行，总结了以下几个要点：



比如，先看谁不愿意干，再看自己能不能干。之前在咱们的图文版《案例库》中也提到过一些创业/副业/自由职业的项目攻略，比如编号A0024车位涂鸦、A0035废品回收、A0075上门洗车、A0070陪诊服务等等，这类项目，"别人不愿干，而你去干"本身就是一种行业壁垒。



比如，把降级感当入场券。编号A0060地摊经济、A0073绿植租摆等等，这类的项目，靠的就是这个行业"零散、渺小、无标准、无大品牌"，新人入场的话能够浑水摸鱼。



比如，别用大桌规则打小桌。A0016迷你小火锅、A0030狗粮OEM、A0063餐饮金融玩法等等，这类项目，它原本所在的行业并不小，竞争也很激烈，但是它们这种玩法的精髓就是：我虽然和你们那些大玩家做的是同一类产品，但我并不进入你们的既定规则之内，而是在小牌桌上重新定义我自己的规则，所以我也能在我的这一桌上做得很好。
