# 旺旺（@TiagerBao）：Obsidian 核心开发者 Kepano 开源了自己的知识库模板——自下而上的 Vault 结构

> Obsidian 官方核心开发者 Kepano 开源的个人知识库模板（kepano/kepano-obsidian）：不是几份零散 Markdown，而是一套完整 Vault 结构——Daily 日常笔记 / Notes 知识与想法 / Clippings 网页收集 / References 参考资料 / Categories 内容分类 / Templates 数十种书籍人物会议项目模板；核心思路是自下而上整理知识，不在起步时就设计复杂分类体系。

我们还在纠结怎么对 Obsidian 笔记进行分类和目录结构？看看大师是怎么搭知识库的。

Obsidian 核心开发者 Kepano 把自己使用的知识库模板开源了。

不是简单的几份 Markdown，而是一套完整的 Vault 结构：

-Daily：日常笔记

-Notes：知识和想法

-Clippings：网页内容收集

-References：参考资料

-Categories：内容分类

-Templates：书籍、人物、会议、项目等数十种模板

核心思路是自下而上整理知识，不用一开始就设计复杂的分类体系。

下载后直接用 Obsidian 打开，还能按自己的习惯修改。

项目地址：

https://t.co/ugbC7nPhuo

你们用 Obsidian，最头疼的是怎么分类，还是笔记越来越多却很少回头看？
