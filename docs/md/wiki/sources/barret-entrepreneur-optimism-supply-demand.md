# Barret：创业成功的秘诀——极乐观、快速复盘、靠观察供需找目标

> 一个创业成功朋友的秘诀：① **极其乐观、恢复极快**——普通人遇挫折要一两天甚至更久，他几小时就能走出来。低落情绪逃不过，困难与错误决策照样会不开心，但任由情绪肆虐几小时后就开始冷静复盘：哪里好、哪里不好、问题出在哪、是自己的还是别人的、哪些能改变哪些不能、这件事还要不要坚持——很快找到原因并做出下一步决策。失败是正常的，重要的是能快速走出来。② **靠观察找创业目标**：流量本质是不断发现和满足用户需求，找到真正需要什么再借势做热点；关注需求自然就会思考市场供需关系，不怕失败、愿意不断尝试。③ **对标 Top 1**：一旦找到供需机会、明确要解决的问题与方法，就研究行业第一怎么做的，然后以平起平坐或超越为目标——「只要资源和能力全部到位，就没理由干不过对方」，创业者必须有这份自信。

昨天跟一个朋友聊天，他给我分享了自己创业成功的秘诀。他是一个极其乐观的人。

一般人在遇到挫折的时候，可能需要一两天，甚至更长时间才能恢复，但他几个小时就能走出来。

他说，低落的情绪是逃不过去的。遇到困难、挫折，或者做出了错误的决策，他也会陷入不开心的状态。他会任由这种情绪肆虐几个小时，然后开始冷静分析和复盘：哪里做得好，哪里做得不好，问题出在哪里，是自己的原因还是别人的原因，哪些能改变，哪些不能改变，这件事情还要不要坚持。他会很快找到原因，做出下一步决策。

失败是正常的，重要的是能够快速从失败中走出来。

关于如何找到创业目标，他说自己主要依靠观察。他很擅长搞流量，而所谓的流量，本质上就是不断地发现和满足用户需求，找到用户真正需要什么，再借势做一些热点出来。

因为关注的是需求，所以他很自然地会去思考市场的供需关系。他不怕失败，也愿意不断尝试。一旦找到供需关系中的机会，明确了要解决的问题和方法，他就会去研究行业 Top 1 的人是怎么做的。

然后把对方当作自己奋斗的目标，要么跟他平起平坐，要么就超越他。

他觉得，只要资源和能力全部到位，就没理由干不过对方。他说，这就是来自创业者的自信，创业者必须有这份自信。
