# 游戏站 SEO 建设 FAQ

## 一、平台选择

**独立游戏 → itch.io / Newgrounds**
- 本身支持嵌入，有天然流量
- 版权方不会追究

**套壳风险**
- 如果想让外链归自己，进阶做法是自己托管游戏文件
- Scratch 游戏可以导出 HTML 自托管

## 二、版权 / 商标

群友 mason 提醒：
- 游戏名称作为域名，需要看这个游戏是否申请了商标版权
- 如果申请了商标版权，尽量别用
- 如果没有申请过，就没事
- **大厂游戏（任天堂等）不能碰**
- 大量独立小游戏和开源游戏没有问题

## 三、iframe 的外链问题

群友田七指出：
> 你们套别人的 iframe，那就是给别人做外链了

如果想让外链归自己：
- 自己托管游戏文件
- Scratch 游戏可以导出 HTML 自托管

## 四、域名策略

两种路线都可以：

**单游戏单域名**（如 gamename.com）
- 适合蹭爆款游戏词的精确流量
- 成本低（每年一个域名钱）
- 词凉了不续费就行

**聚合站**（多个游戏在一个域名下）
- 长期更有价值
- 但起步需要更多维护

**哥飞的建议**：两个都做，自己卷自己。

## 五、快速上手路线

守正在群里总结：
> 游戏站最快的是做一个页面，然后把现成的网站嵌进来。游戏中 iframe 比较快。

**实操路线**：

1. 用关键词找词方法找到一个游戏相关词（有搜索量、竞争不算太大）
2. 注册域名
3. 在 itch.io 等平台找到对应游戏，拿到 iframe src
4. 让 Cursor 生成一个落地页（游戏 iframe 居中 + 标题 + 描述 + Adsense 广告位）
5. 部署到 Cloudflare Pages

**案例**：群友华从问「嵌入码去哪找」到「可以了，谢谢」只花了不到半小时。

**学习资源**：new.web.cafe 搜索「游戏」，把几十篇文章看完就差不多了。

## 核心要点

1. **平台选择**：itch.io / Newgrounds 本身支持嵌入
2. **版权注意**：大厂游戏不能碰，独立小游戏没问题
3. **外链归己**：自己托管游戏文件，Scratch 可导出 HTML
4. **域名策略**：单游戏单域名 + 聚合站双线并行
5. **快速上手**：iframe 嵌入 + Cloudflare Pages 部署
