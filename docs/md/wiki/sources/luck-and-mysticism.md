# 运气和玄学

前几天专门去了趟深圳参加紫菜同学的年终总结



紫菜有一种魔力，就是我听他的分享之前，我并不会抱有任何听完要学会挣更多钱的预期



我的预期很简单，如何更好的拥有最优解人生



1.人生的安全感，来自于多重的支点



我很喜欢王哥，不仅是因为那种淡淡的好像东北人自带天赋的幽默感，还有极其稳定的情绪



他在用绝对的理性对抗世界的波动



活动开始前几天，他刚刚遭遇了一次黑天鹅事件，损失了一大笔钱。相对来讲，这个数字不小



他的状态依然很稳定，跟打德州一样poker face，没有任何的情绪波动



我直接问他为什么，他说，一方面他设置的仓位让自己不会一把一无所有



另一方面，他长期建立起的信任，输出的影响力，深度聚焦的人脉关系，让他永远拥有东山再起的资本



2.时间周期拉长，就没有运气成分了



大多数年纪很小就有第一桶金的人，去复盘自己所谓的成功轨迹，其实原理都是很虚浮的，运气成分很大



刚好碰上了好业务，刚好遇到了贵人，瞎猫撞上了死耗子



紫菜举了一个例子：二战时期，英国研发了一项新的军事技术，但害怕被窃取，就对外宣称他们的军人吃了大量的胡萝卜，提升了夜视能力



我们每天接触的大量信息，可能都是烟雾弹



真正有价值的信息往往藏得很深，需要你有判断力和筛选能力



他又讲了德州的例子



如果只以一两局为单位去看，运气成分很大，你辛辛苦苦打了一天的码量被别人狗屎运一把就清空了，这种事情时有发生



但如果拉到100局的单位去看，胜负率的唯一指标就是技术，运气的成分几乎接近于0了



创业也是如此，短期撞到狗屎运，一把起飞的故事比比皆是，如果拉到10年20年的维度去看，真正可持续的人就很少了



3.机会就在眼前，但我们总被诱惑带走



现场有一个圈友分享了他的困惑：



他跟着航海做B站好物，拿到了一些成绩。但最近因为一些原因有下滑，他在考虑要不要转型，做一些新业务



紫菜听完，给了一个非常直接的建议：



现在的当务之急，就两件事：



拿到现实的金钱回报



快速借助这次机会成为明星学员，积攒起自己在社群内的影响力



如果一次性不做透，很难积攒下来下次再来的资本



很多时候，我们转型的冲动，往往不是因为看到了更好的机会，而是想逃避当下的困难



新机会总是看起来更容易，旧业务总是充满问题



但是一次次"吃透"的经历，会让我们越来越强，而一次次"浅尝辄止"会让我们越来越脆弱，越来越缺乏足够的风险抵抗能力



4.不要乱拜码头



不要乱拜码头



虽然早已拜读过，但是线下听他反复强调，才会想把理论反馈到自己的实际行动上



信任是稀缺资源，不是批发商品



之前看到过一些人，原本选择跟一个大哥做业务，后面又去了别的同行那里，隔了几个月又换人



最后导致的结果就是，大家都不待见他



就很像投资，紫菜前几天在社群说的一句话我觉得很重要，不赌实际也是一种赌



完全不参与任何投资行为的人，看似躲避了很多风险，其实是在押注自己的赚钱速度能长期持续跑赢通胀



把资金分散各种完全不同种类的人，开超市，既分摊了风险，也错过了真正红利期释放出来的大机会



5.逐字稿



紫菜说，活人感的核心其实是要经过略微的设计的，比如他在跟别人打电话前是会写逐字稿的



如果一个人来拜访他，他提前准备了逐字稿和问题，他的信任值会上升



其实一开始不太适应这点，我去拜访别人会准备问题，但如果是自己做分享，从来不写逐字稿，因为我觉得自己的freestyle会比有稿子限制表现力更强



最后仔细想了想，可以试试



或许写逐字稿可以降低系统性风险的概率，无论如何有托底



6.信任值



其实这次我对锦亿的印象很深刻



我们是见了不止二十面的朋友，我一直知道他是个很好很善良的人，但是这一次信任值又🆙了



不知道有没有人要求他去组织活动，但是在冷场的时候，他一直在想办法组织起来



让我想起我们之前的一个聚会，是一个朋友喊了她不同圈子的朋友一起过生日，大家互相不认识，导致场面极其的冷和尴尬



锦亿完全可以低头装死吃饭，但是他全程在努力热场子让大家互相熟悉，主动抗这个重担



我觉得这样的人就是典型的值得推荐和深交的人



7.只玩10%的手牌



关于德州，他说只玩10%的牌，不玩90%的烂牌，其实我觉得这不是我想要的答案



理论上是GTO是最优策略，但是记忆里实际跟他玩的时候，他把把在玩脏牌，我就特别好奇这么玩的原因



回来跟朋友聊，朋友说，应该是他段位比我们高太多，我们的牌他一眼就能读出来范围，所以玩我们跟打日本人一样简单



虽然不知道真实答案，但是以后再说吧



这是和王哥第四次见面，希望第五次见面能又学到更多
