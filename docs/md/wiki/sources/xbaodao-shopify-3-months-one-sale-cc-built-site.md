# 宝刀（@xbaodao）：Shopify 3 个月只卖出一单，用 CC 搓了个站当天就收款

> 用 Claude Code 独立搓站绕开成熟平台的实战：原 Shopify 店 3 个月只卖出一单，改为用 CC 自建站后当天就完成收款；文中拆解了自建站相比平台开店的关键差异（收款链路、转化摩擦、流量入口）、踩到的坑与最小可行实现路径。

<!-- more -->

昨天发了我第一个独立站上线三周的收入，大家比较感兴趣是怎么开始做的，这几天我会慢慢的把过程都写出来，分享给大家。今天就先从建站第一天就出单说起，明天计划写关键词的选择和 seo，geo 的策略。

7 月，我在 Shopify 上开了一家店。

起因很随便：刷到一篇帖子，说在 Shopify 上卖虚拟产品比较好做，我就开了。

店铺主题是用 Claude Code 改的，完全靠口喷，觉得哪里不好看就让它改。

结果 3 个月只卖出去一单，还是我朋友买的。

Shopify 前 3 个月是 1 块钱一个月。眼看 10 月 28 号就要到期，到期后最便宜的套餐也要 50 多澳元一个月。成本比收益大太多，我打算把店关了。

后来一想，现在用 AI 编程工具做个网站这么方便，我干嘛不自己做一个？

前两年刷到过哥飞的文章，建个简单的独立站，甚至是单网页站，只要做好 SEO，GEO，会有自然流量。

说干就干。

10 月 14 号晚上 8 点多，我把需求跟 Claude Code 说好，把 Cloudflare、Stripe，还有几个 AI 工具的密钥和 API 存进一个文件，让它自己去做。

我只留了一句话：我去睡了，额度用完就停，重置了再接着做。

第二天早上起来，一个能跑的网站已经在我电脑上了：商品页、结账、登录、后台都有。

不过也只是「能跑」，真实付款一次都没测过。

半夜还出了个插曲：项目放在 Google Drive 里，一堆文件被清成了全是 0 的空文件。还好代码都提交进了 Git，能还原。当天我就把项目搬出 Google Drive，让 Codex 建了 GitHub 仓库，推上去之前先扫一遍，确认没有密钥混进去。之后只要推代码，网站就自动部署。

15 号白天，我开始同时开好几个 AI 对话：一个管商品，一个管支付，一个管页面，一个管 SEO，再开一个「总指挥」负责派活、审查和上线，这部分内容比较长下一篇单独写。

边干我自己的活边监工。半天就做的差不多了（我以为的差不多😃）

下午接完小孩回来吃完饭，把域名切换到了新独立站，打开支付，我自己先试了一单。

付款、系统确认、自动发货，大概 45 秒，邮件就到了我的邮箱。

从开工到能付款发货，不到 24 小时。

我自己没写一行代码，做的是这三件事：把需求说清楚，遇到选择时拍板，最后自己真买一单验收。

我发现建独立站完全没有门槛，代码托管在 Github，网站用 Cloudflare Pages，后端用 Worker，发邮件用 Resend。分币不花，白嫖赛博菩萨。唯一要掏钱的就是需要 Codex 和 Claude。

测试完把孩子哄睡觉后，一看邮件，竟然进来一个付款！ Shopify 上 3 个月卖了一单。新站上线当晚就出单了。我非常想给她发邮件问一下是怎么找到我的网站的😂

接下来我会把这 3 周多用 AI 建站的过程分几篇写出来。比如 SEO 和 geo 的策略，关键词的选择，怎么去找长尾词（因为我用的是一个比较老的词）。还有主要用什么工具，怎么同时指挥 Claude Code 和 Codex 干活，以及它们是怎么翻车的。大家有什么想知道的也可以随时提问，短的我就回复，长的话我就写个推文或者长文。感谢阅读🙏
