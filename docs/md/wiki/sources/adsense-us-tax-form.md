# 【精读】AdSense 美国税务信息填写指南（W-8BEN 表 + 中美税收条约）

> **核心结论**：开通 AdSense 收款前必须填「**美国税务信息**」（W-8BEN 表），照流程 10 分钟搞定。**关键三档预扣税率**：YouTube 版税 10% / AdSense 服务 0% / 电影电视版税 10%。**填错风险**：选 W-8BEN + 中国 + 中美税收条约 = 享受税率优惠。

> **关键洞察**：
> - **W-8BEN 不是美国公民用的**，中国非美国人必须用
> - **姓名写拼音**（ZHANG SAN），**不是汉字**——必须与身份证拼写一致
> - **外国纳税人识别号** 填 **身份证号**
> - **三大税率** 你只需要按图填：版权版税 10% / 服务商业收入 0% / 电影电视版税 10%
> - **3 个工作日**审核通过（非 7 天）

## 文章概览

**原作者**：阿加曦r
**发布时间**：2026 年 7 月 15 日
**文章定位**：独立开发者开通 AdSense 收款前的「**过路坑指南**」—— 国内非美国公民必须填 W-8BEN 表才能收到美元广告费。

## 一、为什么必须填？

Google AdSense 涉及美国境外的广告收入分配，根据 **IRS（美国国税局）** 规定，所有非美国收款人必须**提交税务信息表**，否则：
- 广告收入会**默认 30% 预扣税**
- 收款可能被**冻结**

## 二、完整操作流程（10 分钟）

### Step 1：进入税务信息页面

```
AdSense 后台
  → 【收款】
  → 【支付信息】
  → 【管理设置】
  → 【美国税务信息】→ 修改图标
  → 【添加税务信息】
  → 「开始填表」
```

### Step 2：基本信息（3 项必选）

| 字段 | 怎么填 | 备注 |
|------|--------|------|
| 账户类型 | **个人** | 非公司 |
| 是否美国公民 | **否** | 中国用户填"否" |
| 纳税表 | **W-8BEN** | 关键！非美国公民 |

### Step 3：受益所有人（关键字段）

| 字段 | 怎么填 | 备注 |
|------|--------|------|
| 姓名 | **拼音**（如 ZHANG SAN） | **不能写汉字**——与身份证拼写一致 |
| 国家/地区 | **中国** | |
| 外国纳税人识别号 | **身份证号码** | 关键字段，填错会被拒 |

### Step 4：地址信息

> **地址要写成英文**。不知道怎么翻 → 丢给 AI 工具帮你翻，再人工核对省市区 + 邮编。

### Step 5：税收条约优惠（关键三档税率）

> 是否依据税收条约申请降低预扣税率？ → **是** → 国家选 **中国**

**三大预扣税率**（按图中选择）：

| 收入类型 | 税率 | 适用 |
|----------|------|------|
| **其他版权版税** | **10%** | YouTube 合作伙伴计划 |
| **服务或其他商业收入** | **0%** | **AdSense（关键！）** |
| **电影和电视版税** | **10%** | 电影电视 |

> 这三个数字是 **根据中美税收条约**，AdSense 也认可，**按图选**即可。

### Step 6：无纸化 + 预览确认

- 特殊声明/豁免 → **否**
- 勾选「**无纸化**」

### Step 7：预览 + 确认

- 检查姓名、身份证号、地址、税率
- 勾选「**我确认**」

### Step 8：签名 + 提交

- 该勾都勾上
- 点「**提交**」

**审核时间**：
- Google 提示：**最多 7 个工作日**
- **实际情况**：**3 个工作日内**通过

## 四、易错点

| 错填 | 后果 |
|------|------|
| 姓名写汉字 | 审核驳回 |
| W-9 表（不是 W-8BEN） | 默认 30% 预扣税 |
| 外国纳税人识别号留空 | 审核驳回 |
| 税率全选 30%（不享受条约优惠）| 多扣税 |
| 选错国家（不是中国）| 没法享受中美条约 |

## 五、与其他变现方式对比

| 变现工具 | 是否需要 W-8BEN | 税率 |
|----------|------------------|------|
| **Google AdSense** | ✅ 必须 | 0%（AdSense）/ 10%（YouTube 版税）|
| Google Play | ✅ 必须 | 视情况 |
| Apple Developer | ✅ 必须（如果美国开发者账号）| 30% / 30%-税收协定 |
| Stripe | ✅ 必须 | 视注册国家 |
| PayPal | ⚠️ 部分情况 | 视设置 |

## 跨领域应用

- **YouTube 创作者**：同 W-8BEN 流程，版权版税选 10%
- **Amazon 联盟营销**：W-8BEN 类似流程
- **Stripe Atlas 注册美国公司**：需要 W-8BEN-E（公司版）
- **其他美国 SaaS 平台**（如 Substack、Medium Partner）：基本同流程
