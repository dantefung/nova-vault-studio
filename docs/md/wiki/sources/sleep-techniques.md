# 关于睡觉的技术。

一直以来的评论区



都有门友问我



阿门，你每天睡多久



然后我说每天6小时，白天就可以精神饱满了，



然后再问为什么ta每天睡8小时都还觉得困。



今天，我分享自己几个睡眠的小技巧，提高睡眠质量和入睡时间。



一开始我以为每个成年人都是都是睡得差不多的，7小时左右，而婴儿12小时以上，儿童9-10小时，但接触的人多了，发现真的人与人之间的差距真的太大了。



最极端的是达芬奇，每隔4小时，睡25分钟，一整天下来只需要睡2.5小时，按道理这样的破坏生物钟，严重睡眠不足的人，脑子肯定不会清醒，偏偏，他是世界上最伟大的发明家，艺术家之一，脑子不是一般的灵光。



但是这些极端的案例，我们学不来，我们都只是正常的普通人，有时候我甚至觉得他不是人类，因为太不正常了。



人类或其它生物为什么需要睡觉？



因为睡觉的时候，我们的身体得到恢复，更重要的是大脑需要回复，而睡觉的时候，大脑会把一些残留废物，排出去，是一些液体，你可以理解成工业废水吧，因为只有排出去废水，白天才可以继续输入干净的水，如果大脑不休息，持续工作，工业废水堆积满了，基本上就无法正常运作了，所以熬夜结束后，或者通宵2天，基本上这个人就和一个傻子差不多，脑子无法正常思考的了。



另一个重要功能，睡觉竟然是增强记忆的唯一方法。如果你不睡觉，无论你之前学了多少东西，都无法进入长期记忆仓，睡觉就是把今天学习的知识输入到长期记忆仓，然后锁死在里面，睡不好的话，你的学习肯定不会好的，无论你多努力都没用。



说到睡觉时长，我说2个我最羡慕的动物。



第一个是海豚，它有多强大呢？它。。不。。需。。。要。。睡。。觉！！



是的，由于它的特殊构造，大脑分了左右两边，它启动左脑的时候，右脑就在休息，右脑休息够了，换左脑休息。



你说羡慕不羡慕，如果我们的大脑也可以这些一边休息一边工作，这一辈子可以做的事就X2了。



另一个让我羡慕的是帝企鹅，因为它最高纪录可以2个月连续的不睡觉，其实就是在保护蛋的时候了，这么冷的天，我几分钟就睡着了，它居然可以2个月都瞪着眼站着，不是一般的彪悍。



好了



上面的都是无法学习无法操作的，说点实在点的吧。



但是怎么可以减少点花在睡觉上的时间而又可以休息足够，精神饱满呢？



注意了，我说的是以第二天可以精神饱满的前提下去减少睡眠时间，而不是靠一味地熬夜来达到睡眠时间减少。



第一条，主动调整。



你不是睡眠时间很长，你只是在床上呆的时间长而已。



也就是你躺床上，并没有睡着。



为什么你会在床上很久睡不着呢？



当然是因为你的大脑处于亢奋的状态，



为什么你睡前做了一些刺激的事啊。



例如，玩游戏，游戏当然是刺激的事，例如和人聊天聊得太深入，引发了思考。例如看恐怖片给吓得不敢睡，例如。。。反正就是大脑还处于非常兴奋的状态，不容易一下子进入休息的状态。



我入睡是特别快的，从来都是5分钟之内睡着，而且是叫不醒的那种。所以这个属性给我增加了特别多的工作和学习的时间。



那有什么建议呢？



睡前不要玩刺激的游戏，最好是看一些无聊的书，而且不要太亮的灯光，一下子就困意来袭，睡着了。



为什么赵本山这个小品里，让高秀敏唱一听就迷糊的歌让他入睡，她就唱了生产队开会啥的呢。。。就如学生时代开大会，校长一讲话我就瞌睡一样的道理，太无聊了。



为什么有人说睡前刷小视频很容易刷几个小时呢？



因为小视频的刺激都是15秒一次30秒一次的，不断刺激你的大脑，你根本没机会产生睡意，所以一下子可能就刷了1-2小时。



我在大学的时候，每天熬夜，就是几件事。



第一，玩游戏，那是大一的时候，终于释放和自由了，疯狂玩游戏没人管，玩到两三点是常事。



第二，玩PS，画图，大一的下学期，已经不怎么玩游戏了，因为已经疯狂地释放完了，觉得无聊了，开始专注玩PS，经常也是画图不知道时间。



第三，玩编曲，gtp啥的，从大二开始，被学音乐的同学发来的编曲软件吸引，就爱上了编曲，经常编一首曲子连续一两天不间断的，搞完输出之后，戴着巨大的耳机躺下睡，开着刚刚写完的曲子循环听。



真的就是这边变态，听着叮叮当当的midi电子音乐睡觉，而且还是开很大声的那种，因为要听腻了之后才会有新的修改灵感。



关于音乐，多聊几句，到了2008年我才真正停止了写歌，2011年为了参加腾讯的公司级音乐比赛才有写了一首新的，因为晋级了2轮，第一轮翻唱了张学友的《怎么舍得你》，第二轮唱了一首2007年写的情歌，第三轮，写了一首关于这次比赛的歌，由于时间紧迫，特意花了900块网上找了个人给我做编曲，不过也是这轮被淘汰了。

好了，说这些是干嘛呢？



就是大学期间，由于是经常睡前都是非常亢奋，导致大学期间经常出现鬼压床，压到我都完全习惯了，一开始很怕，后来经常这样，就一点都不怕了，知道鬼压床又来了，淡定得很又睡过去了。



但是这样导致睡眠质量很差。



我给大家一个非常有用的主动实操，就是睡前看那些哲学什么的，宇宙诞生什么的文章或者书本，保证你一思考就犯困。



这些书，几乎正常人看了都反馈，没有这么高的思想境界和觉悟是无法对研究宇宙什么的产生亢奋的情绪。



第二条，被动调整。



我以前在文章中说过，我刚刚毕业的时候，在广州棠东，租了一个农民房的楼顶，上面是铁皮的，7月啊，那温度，真是一个大蒸笼，半夜起来洗澡降温，一夜洗3次以上。扛了一个月实在不行，加了50块钱，搬到下面一层550的一室一厅。之后才可以正常的睡觉。



温度！是入睡的非常非常重要的因素。



温度越高，越难入睡。



温度越低，越快入睡。



只谈个人，不是标准哈，我现在每晚都是25度空调，盖个空调被睡的。



为什么冬天我们总是不想起床？因为低温会让人容易产生困意，只听过说热到睡不着，没听过冷得睡不着的，除非是室外不盖被子的低温，噢，一般室外低温不盖被子，第二天就长眠了。



人在身体散热的过程中，也就是变低温的过程中，最容易犯困。所以洗完热水澡后，体温迅速降低，你就特别想睡觉。



这些都是非常有效让你快速入睡的办法。



记得不要穿太厚的睡衣，不然容易热醒。



我的确是1点睡到7点左右自然醒了。



养成这个习惯我要感谢一款游戏，那就是2010年左右的偷菜游戏。



每天调闹钟艰难起来偷朋友的菜，实在不容易。



结果后来不需要闹钟，我也醒来了~ 擦！



最后，分享一个今年学到的一个快速入睡的方法。



今年有一段时间，我也焦虑着，失眠过2次，其中一次不是焦虑，是大腿神经疼得睡不着，后来无意中看到一个教如何快速入睡的方法，我试了一下，亲测有效。



具体操作如下



躺下，全身放松，是真的刻意放松的那种，头部放松，四肢放松，感觉使不上力的那种。



然后闭眼，开始想象一个画面，自己在桌面上拿了一个苹果，拿起来观察它的外面，包括上面的小细节，然后拿小刀削皮。。。一直去想象这个事情的细节，然后，没几分钟居然就睡着了。



因为脑子在构建这些细节的时候，这些细节慢慢变成了梦境一样。



嗯，



今天想分享的基本上说完了。



希望大家晚上可以睡个好觉。



晚安~
