# 26年的回乡文学——关于AI的思考

> 一位从业互联网 20 年的开发者在 2026 年春节回乡的冷静观察：三种对 AI 的认知差异、编程范式的根本转变（命令行 + Agent 取代编辑器）、Agent 终局判断（过渡品→平台内嵌）、以及对"AI 能否替代人类思考"的否定回答。

## 作者信息

- **作者**：Corly
- **发布**：2026-02-26

## 开篇：三种时代，一个屋檐

回乡过年，作者观察到三种对 AI 的认知态度，"几乎生活在同一个屋檐下，却像是活在三个时代"：

| 人群 | 对 AI 的态度 | 代表认知 |
|------|------------|---------|
| 老一辈 | 无感 | 刷快手段子、讲荤笑话 |
| 传统行业同学 | 震撼 | 通过媒体接触 AI，眼睛发亮 |
| IT/码农 | 悲观 | "它离不开人类，替代还早" |

> 这个认知差异，可能有 1～3 年。

## 个人经历：20 年技术浪潮 + AI 的颠覆性冲击

作者几乎完整经历过每一轮技术浪潮，但"并没啥大的收益"。

春节期间开发了 3-4 个 Web 站，并重新翻看了之前打磨了 4 个月的 App。当看到尘封的代码、反复对齐需求的聊天记录、会议纪要、通宵改 Bug 的记录……

> **AI 只用了半天，就给他全部重构了一遍。不是优化，不是参考，而是从结构到实现，完整复现。**

> 原来你引以为傲的"苦劳"，在这个时代，已经不再是壁垒了。

## 一、历史的车轮，从来不会停

**受冲击最大的岗位：程序员。**

Token 已经像毒品一样——不用它，很难进入"心流"。

**关键认知转变：**

> **编程，已经不再是文本编辑行为了。**

命令行 + Agent 的模式，正在取代编辑器本身。我们不再逐字看代码，只是粗略扫一眼对话，然后打开浏览器直接验收结果。

而在其他行业（写公众号、做视频、画漫画），AI 依然只是自媒体的狂欢和少数 Geek 的玩具。

> 所谓的 Skills，本质上只是人类 SOP 的抽象。而执行效果？差强人意。

## 二、代码是日抛的，但思想不是

（原文未展开详细论述，标题本身即为观点：代码可以被 AI 大规模复现和替代，但思想和认知框架是更持久的资产。）

## 三、Agent 的终局：不是通用超智能

> **未来的终极软件形态，一定是 Agent。只是这个 Agent，大概率不会是我们今天想象的"通用超智能"。**

## 四、现在的 Agent，本质都是过渡品

在大厂无法贸然行动之前，才会出现大量 Desktop Agent、套壳 Agent。

它们的意义不是终局，而是：试水、占位、验证路径。

**最终格局很可能还是：**

- 大厂平台内嵌 Agent 能力（而非独立 Agent 产品）
- 这个过程中，创业者的机会窗口在于"过渡期的占位"

## 五、AI 能替代人类思考吗？

> **至少现在，远远不能。**

所谓"Agent 超越人类"，本质上还是人类 SOP 的再组织。

> 你让 Agent 去真正探索未知，它很可能会在最后对你说一句：
>
> **"你说得对，我们不如 format disk，重来一遍。"**
>
> 这不是智慧，这是概率。

## 六、不要恐慌，也不要自嗨

> 我们缺少的，从来不是美，而是发现美的眼睛。
>
> AI 看到的世界，只是我们让它看到的世界。

不要因为收藏夹里多了几个 Agent Skills 就沾沾自喜，也不要对 AI 的进步视而不见。

> 真正改变命运的，从来不是工具本身，而是你是否愿意重新理解这个时代。

## 结语

> 我们应该庆幸——庆幸自己活在这样一个伟大的时代节点。
> 它残酷、快速、甚至有些不讲道理，但它至少给了普通人一次，重新站上牌桌的机会。
>
> 时代不会等任何人，但时代，也从不拒绝愿意理解它、靠近它的人。
>
> 过完这个年，路已经很清楚了。不是回到过去，而是带着清醒，继续向前。

## 关键洞察

1. **认知差异 1-3 年**：同屋檐下三种 AI 态度（无感/震撼/悲观），反映了 AI 渗透的不均匀性
2. **"苦劳"不再是壁垒**：AI 半天重构 4 个月的 App，代码层面的个人积累被大幅贬值
3. **编程范式根本转变**：编程从"文本编辑行为"变为"对话+验收"行为，命令行 + Agent 取代编辑器
4. **Agent 是过渡品**：现在大量 Agent 产品本质是大厂占位前的试水，终局是平台内嵌而非独立产品
5. **AI 不能替代人类思考**：Agent 探索未知时的输出是概率而非智慧，"format disk"式回答暴露了本质
6. **Skills = SOP 抽象**：Skills 的价值上限是"把人类操作流程结构化"，执行效果差强人意
7. **工具不是命运**：真正改变命运的是是否愿意重新理解这个时代，而非具体掌握哪个工具
8. **"不是回到过去，而是带着清醒继续向前"**：作者的核心态度——接纳变革但不盲目，保持清醒的参与
