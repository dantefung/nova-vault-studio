# Grok Bot 保姆级新手指南（上篇）：从安装、充值到上手

> 「大多数人装了 Grok Bot，聊了三天，就扔在那吃灰。其实不是工具不行，是用法错了。你把它当聊天机器人用，它就只是个聊天机器人；你把它当员工带，它就真能替你干活。」本文是上篇——装好、付好钱、摸清云电脑；下篇讲带 AI 员工干活与 25 段提示词。

<!-- more -->

> 官方文档入口：`https://x.ai/bot`、`https://docs.x.ai/overview`、价格页 `https://x.ai/pricing`。

---

## 一、它到底是什么

> 一句话：**Grok Bot 是一个自带电脑的 AI 员工。**

普通 AI 聊天是「你问一句，它答一段，然后就没了」，下次还得从头讲一遍你是谁、要干嘛。Grok Bot 不一样，它有四样东西：

| 特性 | 说明 |
|---|---|
| **有名字、有岗位** | 可以建一个「课件主笔」，再建一个「选题官」，各管各的事 |
| **有记忆** | 交代过的规矩会记着，越用越懂你 |
| **有一台自己的电脑** | 在云上一直开着，有浏览器、有文件夹。自己上网查、自己存文件 |
| **会互相派活** | 员工之间能发消息、拉群、交接文件 |

> 「还有最爽的一点：**你合上电脑去睡觉，它还在干。**」

### grok.com 和 Grok Bot 怎么区分

> 「Grok 是 xAI 做的大模型，你在 X 或 Grok App 里跟它聊天，它负责回答问题；**Grok Bot 是建立在它之上的 AI 员工，有自己的电脑和浏览器**，能记住你的资料、按你定的规则一直干活。**一个是『大脑』，一个是『带着大脑上班的员工』。**」

| 场景 | 用哪个 |
|---|---|
| 问一次就完的事（查概念、翻译一段话） | `grok.com` 聊天足够 |
| 天天重复的活（每天找选题、每周复盘、每场直播后出课件） | 交给 Grok Bot |

## 二、怎么装

### 2.1 下载与版本

**第一步**：浏览器打开 `https://x.ai/bot`，点下载。

**第二步：选对版本。**

| 系统 | 怎么选 |
|---|---|
| **Mac** | 关于本机 → 看「芯片」那一行。Apple M1/M2/M3/M4 → 下 Apple 芯片版；Intel → 下 Intel 版 |
| **Windows** | 大多数选 **x64**；少数轻薄本是 Arm 芯片才选 **Arm64** |

> **坑**：Grok Bot 是一个**单独的软件**。在 `grok.com` 网页里聊天，**不等于**在用 Grok Bot，一定要下载这个 App。

### 2.2 手机也装上

iPhone 需 iOS 18 以上，安卓需 Android 9 以上。登录同一账号，电脑和手机的员工、聊天记录都同步。

> 「**云电脑是员工上班的地方，你的手机是遥控器。** 出门在外，掏出手机给它派活、批审批、看结果。」

> **注意**：苹果需要美区 ID，谷歌需要美区谷歌账号。

### 2.3 登录

打开 App 点登录按钮（电脑版写的是 Sign in，设置里叫 Sign In with Cursor；手机版写的是 Log In or Sign Up）。它会跳到浏览器里的统一登录页，页面显示 Grok 或 xAI 的标志是正常的。

> 「**Grok Bot 没有单独的账号**，登录页上会列出几种登录方式（Cursor 账号、Sign in with X、Sign in with Grok 等，以页面实际显示为准），**选你付钱买套餐的那个账号**就行。登录只是验明身份，不会把你的几个账号合并，也不会改你的套餐。」

第一次进去会问「你平时用哪些工具」——**这一步只影响它给你推荐什么，不会自动帮你连上任何东西**，嫌麻烦可以跳过。然后等它几分钟，把云电脑准备好。

> **本文档特别标注的一条关键动作**：如果你是通过 **X App 内购**付费的，登录 Grok Bot 时**必须选 X 账号登录，别用 Cursor 账号**——用 Cursor 账号登录会显示没有额度。详见第四章。

### 2.4 认识界面：就看四块

| 位置 | 内容 |
|---|---|
| **左边** | 员工名单。点 + 号可新建员工、新建群聊 |
| **中间** | 聊天区，跟员工说话的地方 |
| **右边** | 员工档案。点聊天顶部的员工名字打开，能看到它的**电脑实时画面**、定时任务 |
| **左下角头像** | 设置。设置里没有齿轮图标就点头像，或按 `Cmd + 逗号` |

设置里常见的几页：General（常规）、Computer（电脑）、Usage & Billing（用量和账单）、Updates（更新）；有的账号还会多一页 Vault（保险箱）。**看不到其中某几页，正常。**

界面可以切成中文：设置 → General → Language。

## 三、它的云电脑能干什么

> 「很多人不知道，**Grok Bot 最值钱的不是模型，是那台电脑。**」

可以理解成：平台给你的 AI 员工配了一台**一直开着的办公电脑**，放在云上。它在上面开浏览器、存文件、装软件。

| 能力 | 说明 |
|---|---|
| **上网** | 查资料、打开网页、填表、截图。**你能实时看着它点哪里、打什么字** |
| **登录一次，一直有效** | 在它的浏览器里登录过某个网站，下次直接用，不用每次重新登录（网站自己过期才需再登） |
| **关键步骤你接管** | 遇到密码、验证码、人机验证、付款，它会停下来叫你。你打开它的电脑自己输完，再把控制权还给它。**它看不到你的密码** |
| **存文件** | 所有员工有一个**共享文件夹**。一个员工存的文件，下一个员工能接着用，团队协作靠这个 |
| **装软件** | 有命令行，能自己装工具 |
| **读 X** | 不用绑定 X 账号也能搜帖子、看账号、看趋势——**只能看，不能发** |
| **定时干活** | 设好每天几点干什么，它在云上自己跑，你的电脑关着也没关系 |

### ⚠️ 云电脑三个坑，一定要知道

| 坑 | 说明 |
|---|---|
| **① 所有员工共用一台电脑** | 建 5 个员工是 **5 个岗位，不是 5 个保险箱**。一个员工登录的账号、存的文件，其他员工都看得见、用得了。**别在里面登录你不想被所有员工碰的账号** |
| **② 平台更新会换一台新机器** | 文件和登录状态会尽量保留，但**它自己装的软件可能会没了**。重要成果记得另外备份（如同步到飞书或网盘） |
| **③ 没事干的时候会休眠** | 已经开始的活会干完，但**别指望拿它当一台 24 小时挂网站的服务器** |

### 国内平台登录小技巧

云电脑在海外，登录公众号后台、小红书这类国内平台，可能被当成异地登录。设置 → Computer 里有一个「**让云电脑走你这台电脑的网络**」的开关（Route traffic through this computer），打开后网站看到的是你自己电脑的网络。

> **代价是你的电脑得开着。你试之前先拿小号试。**

> ⚠️ **风险提示**：这条技巧在实践中已被证明有平台规则风险——作者本人在 2026-10-15（早于本文）发过紧急通知，指 Grok Bot 接管**小红书已出现大批量封号**。详见 [[sources/lzj-grok-bot-xiaohongshu-ban-warning]]。

## 四、怎么充值（中国用户重点看）

### 4.1 先看懂「四合一」订阅

10 月 12 日起，**Grok、X 会员、Cursor 合成了一张订阅**，官方叫 The X Subscription，大家叫它「四合一」。一份钱，几样东西一起开。

| 档位 | 月价 | Grok Bot 可用？ | 用量 | 适合 |
|---|---|---|---|---|
| Free | $0 | ❌ | 有限 | 只刷 X |
| Plus | $8 | **❌** | 基础 | 发发帖、聊聊天 |
| **Premium** | **$30** | ✅ | Plus 的 4× | **新手入门（官方默认推荐）** |
| Super | $100 | ✅ | Plus 的 15× | 天天用 |
| Ultra | $200 | ✅ | Plus 的 50× | 重度用户、老板 |
| Teams | 每人 $30 起 | ✅ | — | 公司多人用 |

年付有优惠：**Premium 一年 $300、Super 一年 $1000、Ultra 一年 $2000**。价格不含税，结账时可能按账单地区加税。

> ⚠️ **最大的坑：$8 的 Plus 用不了 Grok Bot。**
>
> 「网上有文章说『Plus 就够 Grok Bot 每天干活』，这和官方说法矛盾。官方写得很清楚：Grok Bot 只在 Premium、Super、Ultra 里有。**最低买 $30 的 Premium，别买错。**」

**怎么选**：新手先买 Premium $30；天天用、员工多再上 Super 或 Ultra；**拿不准就先买 $30，额度不够了再升级**。

> **相关**：[[concepts/shared-weekly-pool]] — 四合一「共用周池」机制详解（Grok / Grok Bot / Cursor 共用一个每周刷新的用量池）。

### 4.2 中国用户怎么付钱

> **先说结论：不用开美元账户。** 国内带 Visa 或万事达标的信用卡，直接在网页上付美元就行，银行会自动换成人民币记账。

#### 路线 A（首选）：网页 + 国内 Visa / 万事达信用卡

1. 准备一张带 Visa 或万事达标的国内信用卡（**招行最稳**，建行、中行也有人付成功）。付之前在银行 App 里打开「境外线上支付」（有的银行叫「境外交易」或「无卡支付」）；
2. 电脑打开 `https://x.ai/pricing`，选 Premium（$30/月，**首月半价 $15**），填卡号、有效期、安全码。**账单地址填自己的真实地址，和银行登记的一致**；
3. **被拒了别慌**：把同一张卡绑进 Apple Pay（iPhone 钱包）或 Google Pay，回到结账页选 Apple Pay 或 Google Pay 再付一次。**这是目前救回来最多的办法**；
4. 还不行：先看银行 App 里有没有这笔授权记录。**有记录但被拒** → 打信用卡客服让他们放行；**没有记录** → 是结账页拦的，停一天再试，或发邮件给 `support@x.ai`。**别连着刷**；
5. 付完，用**买套餐的那个账号**登录 Grok Bot，到设置 → Usage & Billing 看套餐有没有显示。

#### 路线 B（没有外币卡）：iPhone + 国区 Apple ID + X App 内购 + 支付宝

> 「这条路是网友实测跑通的，**不是官方写的渠道，一切以 App 里显示为准**。只适合新用户；已经有 Cursor、SuperGrok 或 X 会员的，按官方说法去网页上切换。」

1. iPhone 登录中国区 Apple ID，打开 X App，进「订阅」页，选 Premium；
2. 看到人民币价（网友截图：**首月 ¥104，之后 ¥208/月，年付 ¥2080**），用支付宝或绑定的银行卡付；
3. ★ **付完一定做这一步**：回到 Grok Bot，**用 X 账号登录**。你是在 X App 里买的，套餐挂在 X 账号上——**用 Cursor 账号登录会显示没有额度**；
4. 登录后点左下角头像 → 设置 → Usage & Billing，看「当前计划」那一行。显示不出来，发邮件给 `support@x.ai`。**取消和退款都找苹果。**

#### ⚠️ 四条红线

- **网页上没有支付宝，也没有微信**，不标人民币价（点支付宝会提示 "Alipay payments aren't supported yet"）；
- 网上「Cursor 结账选 CNY、用支付宝」的**老教程已经过时**，新订阅走不通；
- **银联单标卡**（卡面上只有银联标）目前没看到一个付成功的；
- **不要找代充，也不要买共享号。官方不认，封号、盗刷都没人管你。**

> 「U 卡、虚拟卡有人能用，但要交护照做认证，**卡说停就停，还有冻结风险，不推荐当主路线**。」

### 4.3 以前买过 SuperGrok 的，不用重买

以前买过 SuperGrok / SuperGrok Plus / SuperGrok Heavy，或 X Premium+ 的，可以直接「**绑定**」（Link）过来用 Grok Bot。

> **在 App 里**：左下角头像 → 设置 → Usage & Billing，找到 **Link** 按钮，点一下。

**绑定之前看清这四条：**

1. **绑定是永久的，绑了就解不了**，也不能换绑到别的账号；
2. **SuperGrok Lite 用不了 Grok Bot**；
3. **两份订阅额度不叠加**，只按多的那份算，**钱却两边都扣**——别重复买；
4. 官方帮助中心写 SuperGrok Heavy 和老的 Cursor Ultra 是同一档、也是绑定里额度最高的，但**没说等于四合一里的哪一档**，所以别跟人说「Heavy 就是新的 Ultra」。

### 4.4 额度怎么算

| 规则 | 说明 |
|---|---|
| **每周重置**，不是每月 | 设置 → Usage & Billing 能看到用了百分之多少、几天后重置 |
| **定时任务也扣额度** | 半夜跑的一样扣 |
| **用完了怎么办** | 等下周重置，或花钱加购。新四合一订阅叫「**充值加购**」（Top-ups）：在 `grok.com/dashboard/billing` 先充值，再设每月加购上限；老的 Cursor 套餐或绑定 SuperGrok 的老用户叫「**按量付费**」（On-demand），在设置 → Usage & Billing 里开 |
| **新用户有免费试用** | 给一笔额度，**7 天内有效** |

> **坑**：加购先别急着开。要开就**设一个低一点的每月上限，自动充值（Auto Top-up）先别打开**。加购是实打实扣钱的——额度用完以后，**员工多干的每一步都在花钱**；而且**上限不是急刹车**，正在跑的活会先跑完才停。

> 官方说：四合一订阅下 **Grok、Grok Bot、Cursor 共用一个每周额度池**，充值加购的额度也是通用的。

## 五、这篇的价值：它填的是「非技术用户能不能真的用起来」

现有的 [[sources/yaohongan-grokbot-48-use-cases]] 讲的是「**能拿 Grok Bot 做什么**」（48 个场景），本文讲的是「**还没开始用的人，第一步会不会卡住**」。两者的关系：

| 阶段 | 对应文章 |
|---|---|
| 还没装 | **本文**（版本选择、登录方式、界面四块） |
| 装完不知道能干嘛 | [[sources/yaohongan-grokbot-48-use-cases]] — 48 个玩法按场景整理 |
| 不知道给谁用 | [[sources/copperforge-orca-mastery]] — Agent 编排实战 |
| 团队场景 | [[concepts/bot-vs-codex-context]] — Bot 与 Codex 的上下文差异 |

本文最实用的三处，是泛泛的「玩法盘点」不会覆盖的：

1. **Plus $8 用不了 Grok Bot**——这是最容易买错的一步，作者说「我发现我有很多小伙伴在这里犯错」；
2. **X App 内购后必须用 X 账号登录 Grok Bot**，用 Cursor 账号登录会显示没额度；
3. **云电脑三个坑**——尤其是「所有员工共用一台电脑，不是 5 个保险箱」，这直接决定了什么账号能往里登。
