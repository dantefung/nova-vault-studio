# 生姜 Iris（@WeiYipei）：从字节离职后写下的「大厂高薪毒药」——白金螺丝钉、执行方与自由

> 一位前字节 3 开头职级员工的离职观察：大厂之所以是「高薪毒药」，不在于钱少，而在于高薪同时买走了「眼里有光」与对单块业务的 ownership——一年被迫换三次业务线、data-driven 的季度 OKR、缺少 blueprint 权限，最终让所有高职级的人退化成漂亮的白金螺丝钉，只有战略部门还保有全局视角。

<!-- more -->

从字节离职的时候，我是真的放弃了很多很多钱。大厂的待遇是真的好，给的钱也是真多。

但我还是走了。因为我在里面聊了很多人，每一个都很优秀，但几乎每一个人，眼里都没有光。

我后来和很多朋友交流，我们得出一个一致的结论：大厂就是「高薪毒药」。这也是很多人眼里明明没有光，却依然在大厂坚持的原因。

我很庆幸我的职级是 3 开头。这个位置很巧，能同时看到 2 开头和 4 开头的朋友在做什么、是什么样的精神状态。看完之后我没觉得谁更自由。

如果一个人一年要被迫换三次业务线，那真的很难对任何一桩业务具备 ownership。每个季度定的 OKR 基本都是 data-driven，自上而下的人其实都不具备对单个业务场景的 blueprint 权限。因为分得太细，上通下达的沟通成本太高，日常要沟通交流的细节太多，很多人也就没意识去思考全局了——或者说，本来也没有权限去思考。

结果就是每天迷失在大量的细节里。所以大厂的战略部门是真的很关键，而其他所有人，哪怕职级再高，基本也都是执行方。

大厂里的每个人，哪怕职级很高，也都是漂亮的白金螺丝钉。做的工作都非常有意义，但自由和发挥空间确实非常有限。想执行一项策略，需要花更长的时间、更大的心力去布局，而且内部竞争也是真的大。

2025 年 2 月，我在厂里写过另一篇推文。是那个时候开始，我开始认真思考属于我自己的 passion 是什么。说实话，此刻的当下，我依然有点迷茫。

（「高薪毒药」这四个字不是骂人。这是写实。）
