# 太好说话的人，为什么更穷？

2018年，《个性与社会心理学杂志》有篇论文叫《好人垫底》。作者用了300多万人的数据，得出结论：

随和的人储蓄更少，欠债更多，违约率更高。

是因为随和的人太好说话，太容易让步？

真实的解释是：随和的人把钱看得轻。

应了那句俗话：你不离钱，钱不理你。

论文还有一条，收入越低，这个效应越强。

2012年 Judge 等人在同一本期刊发了《好男人和好女人真的垫底吗》。论文发现：随和的男性比不随和的男性年收入少约 18%，女性的差距约为 5%。

同一项研究也发现，随和的人过得更开心，压力更小。

随和的人，未必真不需要钱。他们想的是："算了，不值得伤感情。"

更麻烦的是，老板知道你不拒绝，加班总会有你；亲戚知道你不催债，借钱先想到你。

你慢慢变为大家眼里的软柿子，当好人甚至成了义务。

流行文化对"老好人"有各种批评：

a、所谓"好人"多半是胆小鬼，痴迷于别人怎么看自己。

b、每一次为了取悦别人而扮演另一个人，你都在拒绝自己。

c、人善被人欺，马善被人骑。

亚当·格兰特发现，随和与给予几乎不相关。他研究了给予者、索取者、互惠者三种人，结果成功阶梯的底部全是给予者，顶部也全是给予者。

区别在于底部的是"门垫式给予者"，顶部的是"不随和的给予者"。随和是外在，给予是内在。

英文里有两个词，nice 和 kind，中文都翻成"好"。nice 是让人舒服，kind 是对人好。

不借钱给赌徒，他不舒服，但这是对他好。告诉合伙人方案不行，他不舒服，但这是对他好。把该你的钱要回来，对方不舒服，这是对你自己好。

门垫式给予者只做 nice，把让别人舒服当成了好的全部。不随和的给予者做的是 kind，该让人难受的时候，他让人难受。

好在这世界并非会哭的孩子有奶吃。伯克利做过一个十四年的追踪，发现：脾气坏的人并没有升得更快。所以也不是要变成混蛋才过得好。

所以，你的一个好选择是：做不随和的给予者。

动机上给予，外壳上有边界。

送给随和的人三条：

1、你要在乎钱，钱才会在乎你；

2、用规则替代面子：不借钱，不担保，不背锅，算账按市场来；

3、区分 nice 和 kind：让人舒服，不等于对人好。

对人好，首先是对自己诚实。

善良可以不求回报，但不能总由你的生活来买单。
