## 互联网的本质

互联网，顾名思义，就是一张互联连接起来的网。这里的网，既可以认为是网线，也可以认为是链接——一个是实体，一个是虚拟。

世界上所有的计算机，通过网线、光纤、光缆连接了起来，这是实体的连接。

![互联网由实体网络连接](images/seo-basics-http-crawlers-backlinks/001.png)

而互联网，正是建立在这个实体网络上的。每一个网站，都部署在某一台或某几台服务器上，通过网线连入整个互联网。一个网站，少则一个网页，多则几十个、几百个、几万个、几千万个网页。这些网页之间通过链接互相连接，正是因为有了这些链接，整个互联网才能称之为真正的互通互联。

服务器其实也是计算机，只不过是一般不关机、持久长期运行的计算机，专门用于处理网络请求。你甚至可以把你自己的电脑通过一些工具连入互联网，让别人通过网络来请求你的电脑。

## 网络请求与 HTTP 协议

什么是网络请求？

![网络请求的两种形式](images/seo-basics-http-crawlers-backlinks/002.png)

你用浏览器打开一个网页，其实就是由你的浏览器作为客户端，向这个网页所在的服务器发起一个网络请求，获取网页 HTML 源码。这是获取数据，所以是 GET 形式的请求。你打开推特网页，使用输入框发布一条推文，也是一次网络请求——这是提交数据，所以一般用 POST 形式的请求。

你在服务器里调用某个 API，也是发起一个网络请求。虽然这次是服务器到服务器，但依然分客户端和服务端：请求的发起方就是客户端，提供 API 服务的那台服务器就是服务端。

而请求的具体格式，就是由 HTTP 协议规定的。所有客户端发出的请求都遵循 HTTP 协议，所有服务端响应请求时也遵循 HTTP 协议。

HTTP 全称「超文本传输协议」，是明文纯文本协议，发出的数据和返回的数据其实都是文本格式。即使上传的是图片等二进制数据，有时也会通过 Base64 等编码方式转换为文本格式来传输。如果是 HTTPS，则客户端和服务端先进行加解密，加密后传输的是二进制数据。

## 后端渲染与前端渲染

我们只需要知道：网站是由一个一个网页构成的，而每一个网页返回给客户端的，其实都是 HTML 代码，也是纯文本的，肉眼可以读取和解析。

![HTML 文本](images/seo-basics-http-crawlers-backlinks/003.png)

浏览器去解析 HTML 文本，之后渲染为丰富多彩的、可以互动操作的网页。

![浏览器渲染网页](images/seo-basics-http-crawlers-backlinks/004.png)

我们常说的**后端渲染**，就是浏览器发起请求后，返回的网页是完整的内容，所有最终渲染出来的内容都由后端在 html 里一一返回。

而**前端渲染**通常分两步：第一步浏览器请求时，返回一个 HTML 网页基本内容外加一段 JS 代码；第二步，浏览器解析并执行 JS 代码，按需再发起新的请求，获取数据之后在 JS 里组装好 HTML 内容，由浏览器在前端插入到网页的合适位置，最后渲染出来。

## 爬虫：全网没有统一数据库

互联网并没有一个统一的数据库，所有网站和网页都分散在整个互联网上各个不同的服务器里。没有谁能够清楚地说出全世界总共有多少个网站、多少个网页。

如果有一家公司想要知道整个互联网上到底有多少网页，就需要派出爬虫，一个一个网页去爬。

![爬虫爬取网页](images/seo-basics-http-crawlers-backlinks/005.png)

这里的「爬」，其实就是发起一个网络请求，获取网页 HTML 代码，之后解析 HTML 代码，提取里边的链接，查看是否已经抓取。已经抓取过的网页，看是否需要再次抓取；没抓取过的，判断是否需要去抓取。需要抓取的，就放到待爬列表里，之后不断从待爬列表拿任务、不断爬。

爬网页需要消耗资源，资源就是钱。所以各家爬虫都有判断规则，目的都是找出值得爬的网页，尽可能减少成本。

对于谷歌的爬虫来说，分配给每个网站的爬虫预算都不一样。有些新网站爬虫预算少，有些高权重网站爬虫预算高。如果你的网站大量生成低质量页面，谷歌一开始爬了之后发现拿不到排名，之后就会调低你的预算，不再爬新网页。对于已经爬的网页也可能不索引，已经索引的网页也可能删除索引。这时候你的 GSC 里的网页索引就会看到未索引页面在不断增长。

如果你无视这些信号，还在持续不断地生成同样的低质量页面，谷歌就会对你的网站进行惩罚，不给你曝光了——目的也是提醒你，要有点自觉，别再生成垃圾页面了。

## 为什么各平台看到的外链数据不一样

刚才说了，各家的爬虫都是独立运行的。所以谷歌的爬虫爬到了的网页，Ahrefs 家的爬虫不一定爬到了；同样，Ahrefs 家爬虫爬到的网页，谷歌的爬虫不一定爬到了。

另外，谷歌 GSC 里显示的外链（反向链接）是有延迟的，并不是爬虫抓取到了就立马显示出来。而 Ahrefs 等 SEO 数据平台的反链会更实时地放出来。

![各平台数据差异](images/seo-basics-http-crawlers-backlinks/006.png)

基于以上两个原因——一、爬虫独立运行；二、数据显示时间不一致——就会导致大家在各个平台看到的数据不一致。

举例：你在 ABC 三个网站给你的 D 网站加了外链，过两天你去 Ahrefs 查，可能看到了 BC 出来了、A 还没出来；而去 GSC 查，可能一个都看不到，或者只看到了 A，或者只看到了 B，都是有可能的。

## 为什么 AI 搜索不自建爬虫

为什么现在大家做 AI 搜索，不会想着去自建一个爬虫？原因就是上面说的：如果想要建一个能把全网所有网页都爬完的爬虫系统，需要的费用会是天价的。

所以 ChatGPT 会选择用 Bing 的搜索接口，有些别的 AI 搜索可能会选择 Google 的接口，或者别的搜索引擎的接口。

但是 OpenAI 是有爬虫的，它的目的不是爬完全网所有网页，而是去爬一些指定的、有着高质量内容的网页，用于构建训练模型所需要的数据集；以及在我们提出让 GPT 去搜索总结一些网页时，实时地去抓取网页内容。
