# 出海建站，服务器选型：Vercel / Cloudflare / Railway

出海建站，服务器部署到底怎么选？

## 1. Vercel

- 小白推荐放 Vercel 托管，前端体验最好。
- 尤其是 Next.js 的最佳搭档。
- GitHub 仓库关联后，push 完自动触发部署。
- 配合 Codex、Claude 接入 MCP 操作顺畅，对开发极其友好。
- 起步阶段 Hobby 免费版足够用，真正开始商业化后再升级 Pro（$20 / 月）。

## 2. Cloudflare

- CF 最省钱，全球节点极多，访问速度快。
- Cloudflare Pages 静态页面基本免费。
- Workers 免费版每天 10 万次请求，D1 数据库免费版每天 500 万行读取。
- 起步阶段个人项目额度充足，真要付费 Workers Paid 也是 $5 / 月起，初期工具站很难消耗完免费额度。

## 3. Railway

- Go、Python、数据库、Worker、Cron 定时任务放上去非常方便，不用繁琐配置，控制台点选即可。
- 采用按资源用量计费，免费额度相对较少。

## 总结与建议

对于 MVP 阶段与出海初期探索，优先把流程跑通，服务器阶段无需过多资金投入。能善用 Vercel 与 Cloudflare 免费配额就先充分利用，产品跑出真实用户与验证商业模式后，再调整架构与成本。
