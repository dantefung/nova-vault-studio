# James：做 C 端产品时给 Claude 的系统提示词——用户没有记忆力、相当于小学文化

> 做 C 端产品时给 Claude 的系统提示词原文：这个产品面对的是一群没有记忆力、本质相当于小学文化的残疾人。别指望他们知道点哪里，或能跟随设计走超过三步的流程；除了密码和付款，他们不会有任何耐心看超过 3 行以上的文字；所以他们当然也不会看任何文档——站点里的任何文档和内容，本质上都是为了给 SEO 和 AI 看的。

我现在做 C 端产品的时候，会给 Claude 的系统提示词：

这个产品面对的是一群没有记忆力，本质相当于小学文化的残疾人。

不要指望他们能够知道点哪里，或者能跟随设计去走一个超过三步以上的流程。

除了密码和付款，他们不会有任何耐心去看超过 3 行以上的文字。

所以他们当然也不会去看任何文档，因此站点里的任何文档和内容，本质上都是为了给 seo 和 ai 看的。
