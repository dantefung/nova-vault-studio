# 利用 AI 给自己做个网站给养老吧，「躺」着把钱挣

> zlbigger 上次 AI 产品沉思录没能融到钱，没找到稳定团队。这次直接**裸晒项目**——一个 `linggan.io` 全球多语言 AI 自动运营站点，14 张截图完整手把手教程。这是目前**最具体的"AI 躺赚"实操拆解**。

## 一句话核心

> 一个普通 CMS 系统 + AI 驱动 + 全球多语言 + 自动化，让 AI 24 小时持续打工。

**本质**：**N 个 AI 打工人各司其职（写主题 / 出图 / 写标题 / 写标签 / 写 description / 写正文），定时任务调度，组合成完整内容页上线。**

## 4 步准备工作

| 步骤 | 操作 |
|------|------|
| 1 | 域名 + 空间（去国外平台买，便宜，不做国内可以免备案）|
| 2 | 成功开通 Google AdSense（前期可等网站内容丰富了再申请）|
| 3 | 常用 AI 大模型的 API（OpenAI/便宜到白嫖）|
| 4 | 基础 SEO 知识 |

## 站点结构设计（核心中的核心）

`linggan.io`：动漫角色的 OOTD（每日穿搭）站

### URL 参数（非常关键）

**首页**：每个语言一个子路径（SEO 友好）

```
https://linggan.io          # 默认（按用户 IP 智能匹配）
https://linggan.io/en       # 英文
https://linggan.io/jp       # 日文
https://linggan.io/kr       # 韩文
https://linggan.io/zh       # 中文
https://linggan.io/es       # 西文
... 任意追加语言
```

⚠️ **关键 SEO 技巧**：默认首页匹配的某语言（比如日语），要把所有 `linggan.io/jp` 301 重定向到 `https://linggan.io/`，避免重复内容惩罚。

**内容页 URL**：用 friendly URL 包含**角色名 + 风格关键词**

```
https://linggan.io/en/page/medaka-kurokami-beautiful-high-heels
https://linggan.io/kr/page/medaka-kurokami-beautiful-high-heels
https://linggan.io/zh/page/medaka-kurokami-beautiful-high-heels
```

> 后面的语义化部分不必翻译成不同语言，统一英语就好——**避免翻译噩梦**。

**标签页**：要翻译对应语言

```
https://linggan.io/en/tag/Long plush cardigan
https://linggan.io/kr/tag/롱 퍼 가디건
```

> 因为标签页打开后是个聚合列表，标题/关键词需要本地化。

**搜索页**：类似标签页

```
https://linggan.io/?search=Long plush cardigan
https://linggan.io/?search=롱 퍼 가디건
```

## 6 个 AI 打工人（核心流水线）

| # | 打工人 | 输入 | 输出 |
|---|--------|------|------|
| 1 | **写主题** | 提示词"知名动漫女性角色 + 时尚穿搭 + 随机穿搭" | 完整主题描述（含服饰单品）|
| 2 | **画图提示词** | 主题内容 | 简化成英文 prompt，JSON 格式 |
| 3 | **标题党** | 主题内容 | 5 语种标题 JSON（es/zh/jp/kr/en）|
| 4 | **分词高手** | 主题内容 | 5 语种标签 JSON，逗号分隔 |
| 5 | **description 高手** | 主题内容 | 5 语种 meta description JSON |
| 6 | **文本创作大师** | 主题内容 | 500 字内 5 语种正文，HTML `<p>` 分段 |

**输出格式强制 JSON 多语种**，例：

```json
{
  "es": "...", "zh": "...", "jp": "...", "kr": "...", "en": "..."
}
```

### 完整流水线可视化

```
定时任务（每 5 分钟提交一个主题）
        ↓
[AI 打工人 1] 写主题（角色 + 穿搭）
        ↓
[AI 打工人 2] 简化成英文画图 prompt → 调图 API
        ↓
[AI 打工人 3] 5 语种标题
        ↓
[AI 打工人 4] 5 语种标签（keywords）
        ↓
[AI 打工人 5] 5 语种 description
        ↓
[AI 打工人 6] 5 语种正文
        ↓
组合 → 上线
```

## 两种运行模式

### 手动模式

后台输入主题或批量导入上百个主题，AI 打工人按顺序执行，组合成完整页面上线。

### 全自动模式（真·躺赚）

写一个**定时任务**，让 [写主题] 打工人自己写主题，然后再交给其他打工人按顺序完成。

**建议频率**：每 5 分钟提交一个主题 → 每天 288 个内容页。

## 5 个核心方法论（提炼）

### 1. 选"有流量"的主题

> 选择一个"有流量"的主题，比如动漫角色穿牛仔短裤、吊带背心、婚纱礼服。

**流量三大来源**：
- 角色本身热度
- 关键词长尾搜索
- 视觉冲击 + 收藏分享

### 2. AI 打工人 = 流水线个体

每个 AI 各司其职，**只擅长一件事**。这和「Atomic Agent」「Prompt as Component」是同一思想。

### 3. JSON 多语种输出是降本关键

**一个主题 → 一个 prompt → 一次调用 → 5 语种结果**。

不要每语言单独写 prompt——浪费 token。

### 4. 定时任务 = 真·自动化

**写主题**的 AI 自己跑（不需要人输入主题）。这是"零边际生产内容"。

### 5. AI 加成不等于 AI 应用

> 核心不在于「一定做 AI 应用」，**在于「AI 能帮你干很多事情」**。

CMS 是普通程序，AI 是「打工人」。这是和 zlbigger 上篇一致的方法论延伸。

## 6 个核心优势

| 优势 | 说明 |
|------|------|
| **零边际内容成本** | 写主题 → AI 全自动完成 |
| **多语种覆盖全球** | 5+ 语种同时铺 |
| **被动收益** | 广告收入 24 小时持续 |
| **复利积累** | 内容越多，流量越大 |
| **跨平台可复制** | 一个模板可换 N 个主题 |
| **AI 加成降本** | 之前需要人工写作，现在 AI 直接打工 |

## 3 个你也能学的步骤

1. **选一个细分主题**（动漫角色穿搭、宠物 × 服装、古风 × 美食 etc.）
2. **搭 CMS**（WordPress / Strapi / 自研都行，关键是结构化字段）
3. **招 6 个 AI 打工人**（写主题 / 出图 / 标题 / 标签 / desc / 正文）

剩下的交给定时任务，**3-6 个月就能看到流量起来**。

## 适用人群

✅ **适合用这个方法**：

- 能写代码（或有人能帮你写）
- 选得出"有流量"的内容主题
- 接受 3-6 月的持续输出周期
- 不怕"套壳"二字（这是 zlbigger 反复强调的路径）

- 没法写代码又找不到帮手
