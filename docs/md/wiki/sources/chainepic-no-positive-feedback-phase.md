# ChainEpic：一个人能否成功，很大程度上取决于如何处理「没有正反馈」的阶段

> 出海的人基本都要经历无正反馈的阶段——不像工地搬砖，搬一天就有一天收益；出海更糟糕的是**连负面反馈都没有**。能否成功，很大程度上取决于如何处理这段没有正反馈的时期。
