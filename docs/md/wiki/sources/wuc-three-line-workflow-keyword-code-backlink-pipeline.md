# Wu（@Wuc436）：重构后的工作流——找词线、代码线、外链线三条并行流水线的极简分工

> 独立站出海三线并行工作流的极简拆解：找词线每天定时找词、挂看板并由 AI 打标签，人工只看数据；代码线买好域名即交 Claude Code 拉仓库模板写代码，基建任务派给 Grok Bot 加脚本以一句话上线 MVP；外链线每天补充新名单、老候选池每天核验 1000 个域名达标入库，上站后由 Grok Bot 从外链库选合适外链发布。作者强调这套流程需边做边迭代。

<!-- more -->

重构后的工作流改为了 3 条线：

1. 找词线
   每天定时找词， 找到的词放在看板上，AI 打一遍标签，最后我自己看数据。

2. 代码线
   买好域名后直接交给 cc 去拉仓库模板，然后写代码，同时基建任务交个 grok bot 加脚本，一句话可以上线 mvp。

3. 外链线
   每天定时补充新的外链名单，老的候选池子每天核验 1000 个域名，达标的填入外链库。上站后，交给 grok bot 去外链库选取合适的外链发。

以上 3 条线是我现在的工作流，需要边做边迭代。
