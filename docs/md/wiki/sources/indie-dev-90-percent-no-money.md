# 90% 的独立开发不挣钱

作者：梁唐，公众号 Coder梁

## 三层漏斗

1. 从 0 到能推进行动落地：10%
2. 有行动能落地成结果，能长期坚持：10%
3. 能坚持且不停尝试、优化方法：10%

10% × 10% × 10% = 1%。90% 独立开发者挣不到钱是"美化"之后的现实。

## 核心论点

**开发是确定性难题，产品/运营是不确定性难题。**

- 开发：确定性解法、确定性知识体系，只要满足智商和学习能力就能学会
- 产品/运营：问题不确定、解法不确定、反馈不确定，连试错积累经验都困难

**技术能力可能不是独立开发者的优势，反而是枷锁。**

**认知差 = 时间差**

- 上等认知：领先同行，在同行意识到机会之前下手
- 次等：趋势刚显现就果断出手
- 再次：趋势成规模后才察觉，只能分一杯羹
- 最差：事情翻篇了才后知后觉梭哈

## 行为观察

- 绝大多数人追求成功停在嘴上，不研究他人成功原因，反而把成功案例当排除选项
- 恐惧和已有的成功案例竞争
- 习惯假想困难来为自己不行动找补
- 90% 提前设想的问题根本不会发生

## 阿甘理论

世界上只有两种人能获得大成功：
1. 绝顶聪明——总能想出办法
2. 阿甘一样的"蠢人"——不会想那么多，想到了就去做

绝大多数介于两者之间的人，不够聪明也不够蠢，还没开始就被想象出来的困难吓倒了。
