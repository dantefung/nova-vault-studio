# KKKK（@kkkeric_ai）：SEO 新站起步心法——看淡 DR、死磕 GSC 与 300 条外链分界线

> 新站做 SEO 不要迷信第三方 DR 分数（易受老站重定向操纵），最核心指标是 GSC 里的真实排名与搜索点击次数；外链数量实测 300 条是一个关键分界线，即使是免费外链在 1-2 个月内平稳堆到 300 条也能产生显著权重增益。

<!-- more -->

做 SEO 其实 DR 这个东西没那么重要，很多老站导导流 DR 就快速起来了

最有价值的数据就是 GSC 的排名和搜索点击次数

然后外链数量还是很有作用的

实测 300 条外链是个分界线，哪怕免费外链你能堆 300 条也是很有价值的

大概这个时间就是 1-2 个月左右，新站不要太激进
