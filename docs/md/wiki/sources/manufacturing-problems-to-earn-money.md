# “解决问题”不赚钱，反过来才赚钱

传统方法教我们：寻找痛点，解决需求。



但，这是典型的正确而无用的废话。



赚钱难，正是因为太想“解决问题”。 而真正轻松赚钱的那一拨儿人，大部分都是：



先把水管的阀门拧松半圈，然后站在旁边卖扳手。



也就是：“制造问题”。



这是一种很厉害的赚钱方式，它可以把白热化的市场竞争变成你一个人的舞台。



所谓“制造问题”，并不是凭空变出什么幺蛾子，而是：



重新定义匮乏。



更具体一点的话，可以拆成三层：



第一层、制造一套“标准”，把“你没有”变成“你有病”。



原始社会，人只有两种状态：要么饱了，要么饿了。但现在不行，你走进任何一家商场，或者打开电视、手机、购物软件，会发现自己活在一个充满“病”的世界里：



所以，有没有一种可能：



问题不是客观存在的，是被某种“叙事”喊出来的。



高手赚钱，第一步不是研发产品，是搞来一套标准：



定义什么叫“好”，什么叫“正常”。



一旦你定义了“正常”，所有不符合的人就都成了“病人”。本来，你只是没有某样东西而已，是正常的，而现在你有病了，它就不正常了，因为既然有病，你就马上从正常人的状态，跌入了有待治疗的状态。



这只是最表面的玩法，才刚刚开始，标准一旦建立，就会像癌细胞一样疯狂进化。



后来，高手们发现，仅仅定义“你没有”是不够的，太初级了。更高阶的玩法，是把那些你已经有的，也重新定义为一种新的病。



所以，



你看，他们都不是解决一个客观问题，而是重新定义你拥有的东西，把你的某种“资产”定义某种“负债”。PPT版式、身体素质，都从优势变成了病灶。



很巧妙，但这还只是收割普罗大众的玩法。



当这套标准继续进化，它会变得越来越“高级”，开始瞄准社会上那一小撮儿精英群体。他们会用一种你无法反驳的哲学，让你心甘情愿地掏钱。



他们的玩法，从重新定义一个物件，升级到了重新定义一个人。



第二层、制造“依赖”，让你永远在换药。



刚才说的定义“正常”与“病态”，只是基本功。但这套玩法并不完美：如果你真的被"治好了"，怎么办？你没病了，就不需要治了，我还怎么赚钱？



所以更隐蔽的操作，是确保这个病永远治不好。



这个说来也好理解，就像很多木马病毒都是那些杀毒软件公司制造出来的，因为如果病毒没了，杀毒软件就得饿死，所以他们很善于养寇自重。就算没病毒，也会隔三差五提示你有什么漏洞可以“一键修复”，并且恭喜你电脑性能提升30%。你心里踏实了，但这个"漏洞"永远存在，你今天修完，明天还有。



问题是被持续制造出来的，只要定义权在别人手里，你就永远有待处理的事项。



当这套逻辑继续进化，它会变得越来越精妙，甚至让你心甘情愿地把依赖当成习惯。



刚才说杀毒软件，它属于明着告诉你问题还在，更厉害的玩法是：



它的解决方案本身，就会长出新问题。



在三瓶洗发水里加不同的色素和香精，分别宣称能够“去屑”、“柔顺”、“营养”，让你觉得必须三瓶都买。而且，去油太猛导致头皮敏感，于是你就得买护发素；护发素太营养导致毛囊堵塞，于是你就得再买头皮清洁产品。你每解决一个问题，就制造出新的问题，你从买一瓶洗发水，变成买一整套产品线。



再比如，你花上千块买个净水器，用了一年，提示灯亮了，让你更换滤芯，并且告诉你：不换的话，水就被二次污染了，甚至比没过滤还脏。你赶紧再花好几百换滤芯。但那个提示灯是谁设计的呢？它真的能检测水质吗？有没有一种可能，它只是个定时闹钟？它根本不知道你家的水干不干净，它只知道时间到了，该让你花钱了。



我家里、办公室里就供着几个这样的祖宗。他们管这叫“用户粘性”，翻译成人话就是：



让你永远带着没付完的账单活着。



更聪明的人，会把依赖从产品层面，搬到心理层面，不卖产品，卖的是一个永远不会到来的未来。



比如，有一类自媒体博主，自称什么“亏过500万的连续创业者”，天天发视频讲自己当年怎么踩坑、怎么赔钱、怎么爬起来，很励志，很正能量，见多识广，认知也高。你越看越上头，觉得这人真性情、说真话。他会经常提一嘴：“我把我亏500万总结的《避坑指南》整理成了文档，评论区扣1领取。”



你扣1了，看到第8页，他说：“完整版66页，但最核心的项目风控模型在知识星球里，年费599。”你犹豫了，但紧接着他下一条视频就来了：“我最近在研究一个新赛道，月入十万的核心就三点，星球会员优先看。”你怕错过，进去了，进去后发现，他确实每周发东西，但发的全是“观察日记”：比如今天看了什么项目、明天约了谁喝茶、后天觉得哪个行业要凉。你永远在看他“正在研究”的路上，他永远研究不完。 因为他一旦画句号，你就毕业了，就不续费了。他靠这种未完成感来吊着你，把你拴在一个永远不会完结的连续剧里。你一直续费，买的是“万一他下次真掏出了金矿呢”的虚无缥缈的可能性。这简直就实是在卖一个永远不发货的期货。



杀毒软件养着病毒，日化公司养着头皮问题，博主养着你的"错过焦虑"。他们永远不让你离开这个游戏，因为他们赚的并不是解决问题的钱，他们赚的是你一直在解决问题的路上所产生的燃料费用。



第三层、制造“身份否定”，让你为“未来可能的自己”买单。



如果说前两层都还停留在行为层面，比如你买除螨仪是为了除螨，换滤芯是为了喝水，它们都有一个明确的、可感知的目的。真正的高手，玩的不是你的行为，玩的是你的身份感。



这一层的核心，是让你讨厌“现在的自己”，类似于卖赎罪券。他们让你相信：



你的人生困境，源于你还未拥有某件物品、某个证书、某种外貌。



他们制造的问题叫“现在的你不够格”，而解决方案，当然是花钱。而且你永远在为一个"未来可能的自己"付费，而那个未来的自己，永远在下一站，你总是需要买更高阶的产品或课程。



好，三层说完。有的人肯定会想，我能不能也这么玩儿呢？
