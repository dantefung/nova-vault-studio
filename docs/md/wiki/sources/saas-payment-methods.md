# 用户更倾向于选择Creem而不是Paypal，SaaS工具网站支付方式选择

Creem和Paypal解封后，我在网站放两种支付方式让用户选择，默认帮用户选择Paypal。目前已经一个月过去了。



说个数据：80%+的用户选择 Creem（网站上显示的选项叫：借记卡和信用卡），只有不到20%用户选择Paypal支付。



所以这也证实了我之前两次切换到Paypal后收入几乎跌没，当时猜想的原因。



我其实还是比较希望用户选择Paypal的，因为我Paypal可以直接提现到公户，提现手续费也不高。



同样价格Creem帮我交了增值税，欧盟地区基本在19%～22%，高得离谱。用Paypal就不需要交这笔钱。



Creem每笔交易手续费是3.9%+$0.4。但Creem收款我要提现到Wise，Wise转账到银行卡又扣一笔手续费，这个手续费也很高，按上次转账算大概是2.1%。



Paypal交易手续费4.4%+$0.30，通过贝宝跨境人民币结算到公司公户手续费1%+$0.35。我现在提现少于3次都还是免费阶段。上传提现手续费0元。



在欧盟地区，我通过Creem收款到提现到国内银行卡的损失大概: 24.9%。而我通过Paypal收款到提现到公户的损失大概: 5.4%。



对比算一下，以这笔89.99的订阅来算：



Creem到手：$67.58



Paypal到手：$85.1



Creem 如果不扣增值税19%，其实跟Paypal差不多，就是这增值税～



一笔89.99的订阅，到我手上估计不到452人民币，算完笑容就消失了。



我在想要不要让用户自己承担，之前定价39.99的时候就是让用户自己承担的。但是让用户承担就超100美元了，不知道会不会影响订阅率～
