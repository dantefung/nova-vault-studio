# 用户更倾向于选择 Creem 而不是 Paypal，SaaS 工具网站支付方式选择

Creem 和 Paypal 解封后，我在网站放两种支付方式让用户选择，默认帮用户选择 Paypal。目前已经一个月过去了。



说个数据：80%+的用户选择 Creem（网站上显示的选项叫：借记卡和信用卡），只有不到 20%用户选择 Paypal 支付。



所以这也证实了我之前两次切换到 Paypal 后收入几乎跌没，当时猜想的原因。



我其实还是比较希望用户选择 Paypal 的，因为我 Paypal 可以直接提现到公户，提现手续费也不高。



同样价格 Creem 帮我交了增值税，欧盟地区基本在 19%～22%，高得离谱。用 Paypal 就不需要交这笔钱。



Creem 每笔交易手续费是 3.9%+$0.4。但 Creem 收款我要提现到 Wise，Wise 转账到银行卡又扣一笔手续费，这个手续费也很高，按上次转账算大概是 2.1%。



Paypal 交易手续费 4.4%+$0.30，通过贝宝跨境人民币结算到公司公户手续费1%+$0.35。我现在提现少于 3 次都还是免费阶段。上传提现手续费 0 元。



在欧盟地区，我通过 Creem 收款到提现到国内银行卡的损失大概： 24.9%。而我通过 Paypal 收款到提现到公户的损失大概：5.4%。



对比算一下，以这笔 89.99 的订阅来算：



Creem 到手：$67.58



Paypal 到手：$85.1



Creem 如果不扣增值税 19%，其实跟 Paypal 差不多，就是这增值税～



一笔 89.99 的订阅，到我手上估计不到 452 人民币，算完笑容就消失了。



我在想要不要让用户自己承担，之前定价 39.99 的时候就是让用户自己承担的。但是让用户承担就超 100 美元了，不知道会不会影响订阅率～
