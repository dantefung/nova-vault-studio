# myleaf（@myleafy1）：开源 phongent——基于 Mika 的安卓局域网多设备群控与 AI 任务调度系统

> 基于手机端常驻 Agent 框架 Mika 二次开发的开源局域网设备群控工具 phongent：支持集中下发任务或由主控 AI 自主感知分配任务给被控手机，跨设备接收屏幕操作与消息并在主控端统一汇总回复。

<!-- more -->

项目已开源https://github.com/mylea1/phongent

核心功能为

1. 群控多设备，可以指定设备下发任务或者将任务部署下去由发布任务的 ai 自行分配
2. 接收被控设备信息并在主控设备上回复

只是在自己使用时测试了大致功能，很多地方还不够完善，欢迎大家提 issues 或是直接私信我😘 https://t.co/nOZz3x5ptm

基于 mika 改了个群控软件，同时控制局域网下所有设备干活❤️，mika 太屌了❤️ https://t.co/5HgEB96z3d
