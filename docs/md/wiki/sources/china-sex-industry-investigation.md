# 中国色情行业调查进展

> 基于潘绥铭、黄盈盈等学者的田野调查（1997-2015，23 个红灯区，1132 名受访者），揭示色情行业并非悬浮于社会之外的污秽角落，而是经济转型、企业倒闭、失业等社会问题的下游承接者。东北下岗女工平均 51.5 个月、换 4.7 份工作后才流入性产业。


前段时间起了个念头，想认真查一查中国的色情行业。

这东西大家都知道存在，规模不会小，却几乎注定很难留下公开、连续、具有全国代表性的大规模统计。行业本身在地下，从业者不断流动，连“谁算性工作者”都很难划出一条整齐的线，大样本的学术研究自然更难。

但过去几十年，还是有人真钻进去做过。

潘绥铭从上世纪90年代开始进入红灯区做社区调查，1997年调查广东、广西、贵州三个地下性产业社区，后来写成《存在与荒谬——中国地下“性产业”考察》。

黄盈盈等人继续往下做，从1999年到2015年，团队先后进入东北、四川、云南、广州等地23个红灯区，累计访谈1132名女性性工作者、239名妈咪或老板和212名嫖客。规模当然还不能说大，但对于这样一个地下行业，这已经是一批极其罕见的资料。

我最近一直在翻这些旧研究。材料距今二十多年了，样本也不大，可今天重新看，还是会让人心里一沉。

最典型的是东北。

2002年，黄盈盈、潘绥铭在东北三个城市访谈了103名中低端女性性工作者。95%是城市户口，51%原来在正规单位工作，后来下岗或者完全失业；这些下岗女性中，74%原来在国企，74.5%是因为裁员、企业倒闭、改制、兼并等单位原因失去工作。

而且，她们并不是一下岗就去做了小姐。

她们下岗或待业以后，直接进入色情行业的不到9%；其余的女性又挣扎了很久，平均51.5个月，换过4.7份工作，做过各种正常工作，最后才进入性产业。

所以东北大下岗留下的，并不只有今天还能在统计年鉴里找到的失业人数、国企关闭数量——至少在这批样本里，它还有一个非常具体、很少有人再提起的后果：

一批原来的国企女工被甩出原有就业体系，在底层劳动力市场挣扎了几年以后，最终流进了色情行业。

她们不是一下子“堕落”了，而是工作没了，接下来四年多找了将近五份工作，最后终于“沉底”。

这也是我查这件事以后，对色情行业认识变化最大的地方之一：它并不是悬浮在正常社会之外的一块污秽角落。经济转型、企业倒闭、失业、人口迁移，最后都会有人来承担，而色情行业恰恰会吸收其中的一部分人。

还有一个变化，是我自己以前也把这个行业想简单了。

如你我这样的普通人，说起色情行业，脑子里最容易出现的就是两个角色：小姐和嫖客。

真正的田野不是这样。

早期研究资料中，已经调查过性产业中的妈咪、老板和各种组织形式；黄盈盈后来总结长期田野时，看到的则是一张更大的关系网：性工作者、妈咪、嫖客在中心，外面还有场所经营者、老乡、男朋友、社区居民、小诊所、草根组织、警察、疾控人员等。早期研究甚至专门分析过妈咪、鸡头与老板、小姐之间怎样组织生意和分配利益。

色情行业并不是“几个小姐偷偷接客”，而是一套嵌在正常社会里的地下产业生态。

这件事也会改变我们怎么看“扫黄”。

色情行业当然涉及违法，很多人也对它不齿。但怎样治理它，并不只是一个简单的治安问题。那不是孤零零的一次性交易，而是一整张由就业、场所、客流、熟人网络、医疗和基层治理组成的关系网。

打击力度怎么变，人会去哪里，交易会转入什么地方，疾病防治还能不能接触到这些人，原来靠这个生态吃饭的人又会去做什么——这些最后都会落到底层人的身上。

换句话说，色情行业本身也许在地下，但它产生的后果一直在正常社会里。

目前我查到的，还只是这个行业露出水面的一部分。地域来源、人员流动、收入分配、场所组织、嫖客结构、扫黄之后的迁移，以及互联网怎样重新改造这个行业，还有很多资料正在往下挖。

今天先出一份阶段感想。

而我自己，会把这个调查继续做一做。
