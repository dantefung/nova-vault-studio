# Barret 李靖（@Barret_China）：把 Pi、DSH、Super-Agent 组装成主动服务的超级智能——一段提示词里的自主分级、Inbox/Outbox 与 HITL 机制

> 一份可直接投喂给高能力编码 Agent 的系统级构建提示词：探索并复用本地 CLI/MCP/Skills/浏览器自动化生态，搭建主动感知巡检机制与统一任务中心 Inbox，建立 L1-L5 自主执行等级（信息整理 → 建议方案 → 中间成果 → 人工确认 → 端到端自主验证交付），设计 HITL Outbox 决策推送、并行子 Agent 任务拆解、监控看板与个人上下文持续演进机制，最终目标是可长期运行、真正主动交付成果的超级智能。

<!-- more -->

昨晚发给 AI 的一段提示词，早上起床有惊喜：

在我的电脑上，配置好 Pi、DSH、Super-Agent 等开源项目，将它们组合成一个能够主动提供服务的超级智能。

首先，充分探索当前系统已经具备的能力，包括各种 CLI、MCP、Skills、浏览器自动化工具，以及本地和云端的 Agent 执行环境。尽可能利用现有的工具生态，把研发、信息检索、文档处理、项目管理、日程管理、沟通协作等能力都集成进来。

整个过程中，需要主动调研 GitHub 上最优秀的开源项目，优先复用成熟的技术成果。将调研内容、架构设计、配置方案、依赖资源、工具使用经验等整理保存，做好版本管理，确保整个系统能够持续迭代、方便迁移。

接下来，构建一套主动感知机制，定时巡检我的消息、邮件、日历、文档、代码仓库、项目任务等信息源，结合我的个人工作上下文，理解我正在做什么、关注什么、有哪些尚未完成的事情，以及哪些事情值得主动推进。

去互联网寻找类似 Multica 的开源项目或成熟方案，在本地构建一个统一的任务中心，将发现的待办事项、潜在问题、项目机会和需要决策的内容梳理出来，统一放进 Inbox。

任务中心需要对所有事项进行分类，并建立 L1 到 L5 的自主执行等级。Level 越高，意味着这件事情越容易被 AI 独立推进。

- L1：理解和整理信息，提取待办、总结背景。
- L2：分析问题，提供建议和执行方案。
- L3：能够完成部分工作，生成可交付的中间成果。
- L4：能够自主完成大部分工作，关键环节需要人工确认。
- L5：能够端到端完成任务，自主验证结果并交付成果。

系统需要能够根据任务类型、上下文、工具能力和权限，自动判断哪些事情可以由 AI 推进，哪些事情需要我参与。

对于能够自主完成的任务，要主动制定计划、调用工具、执行操作、验证结果，并持续跟进。对于复杂任务，需要自动拆解成多个子任务，交给不同的 Agent 并行处理，同时管理任务之间的依赖关系。

另外，设计好 HITL（Human-in-the-loop）机制。涉及重要决策、对外沟通、内容发布、敏感操作等事项，需要先进入 Outbox，等待我的确认。通过消息通知等方式，将需要我决策的内容主动推送给我，并提供必要的背景、建议和可执行选项。获得授权后，再继续推进后续工作。

这个系统的建设存在一定的复杂度。你需要充分利用 Codex 等高能力编码 Agent，让它们对整个工程进行系统性的设计和任务拆分，再将具体任务交给独立的子 Agent 处理。能够并行的任务尽可能并行，能够复用的能力尽可能复用。

要求整个执行过程不能偷懒，不能只停留在架构设计、生成代码或者 Demo 阶段。要真正把生态能力用起来，必要时自己编写代码，完成真实环境下的集成、测试和验证，确保每个核心模块都能正常工作。

整个系统的架构要清晰、简洁、可移植，稳定性要足够强。需要考虑任务持久化、异常恢复、失败重试、权限隔离、数据安全、执行成本和资源管理，保证 Agent 能够长期稳定运行。

同时，为整个执行过程建设一套监控看板，能够直观查看 Inbox、Outbox、任务状态、Agent 执行进度、工具调用记录、执行日志、异常信息和最终交付成果。支持调试、任务重试、人工干预和历史回溯。

你还需要持续理解和更新我的个人上下文，包括我的工作职责、正在推进的项目、长期目标、技术兴趣、日常习惯和个人偏好。让 Agent 能够基于这些信息主动判断事情的优先级，并发现潜在的工作机会。

整个建设过程需要自主完成调研、架构设计、任务拆分、并行开发、集成测试和部署运行。遇到问题主动寻找解决方案，只有真正需要我决策或者授权的事情才来找我。

系统建设完成后，还需要通过真实任务进行端到端自测，验证从信息发现、任务识别、自动规划、自主执行、人工确认到成果交付的完整闭环。确保它能够在后台持续运行，真正主动替我完成工作。

最终，我希望得到一个能够长期运行、主动感知信息、理解个人上下文、自主发现任务、持续推进工作、交付真实成果的超级智能。

我只需要关注目标和关键决策，剩下的事情，尽可能交给 AI 自己完成。
