# 良竹（@liangzhu_AI）：会写代码不会卖？基于 Agent Skills 的独立开发者营销转化体系

> 独立开发者最常陷入「只管写代码、不懂怎么卖」的困境。本文推荐基于 Corey Haines 开源的 marketingskills 套件，解析其协同工作流：先跑 product-marketing 固化定位与目标用户画像作为唯一事实源，再依次调用 cro 转化率审计定位漏洞、copywriting 润色文案与 SEO 优化。

<!-- more -->

会写代码，不会卖？

有人把落地页转化、文案、SEO、数据分析做成了一套 Agent Skills，也就是给 AI 代理复用的技能说明。

开源：https://github.com/coreyhaines31/marketingskills

先跑 product-marketing：把“卖给谁、解决什么问题、怎么定位”写清楚，存成一份背景资料。后面的技能都会先读它，给建议时不用每次从零解释你的产品。

实操例子：SaaS 首页没人注册，先用 cro（转化率优化）检查价值主张、按钮和表单，再用 copywriting（文案）改表达。顺序别反，先找漏点，再润色。
