# DeepSeek Harness，Agent 自己「组装」

DeepSeek 今天开源了 Harness v0.1 开发者预览版，一个基于 Cordis 元框架构建的 AI Agent 框架。

我看下来，最核心的哲学其实就一句话：

一切皆插件。

模型是插件，今天用 DeepSeek，明天换 Claude，直接替换；

工具是插件，需要什么能力就插什么；

Skill 是插件，特定任务可以封装成可复用模块；

会话、沙箱、文件系统是插件；

甚至连循环、编排逻辑、UI 界面，也都可以是插件。

也就是说，它不是想再给你做一个「什么都有的超级 Agent」，而是给你一套 Agent 的底盘。

然后我看到玉伯发了个 X：

「看完 DeepSeek Harness，让我想起了 foobar2000。」

我觉得这个比喻绝了。

以前用过 foobar2000 的人应该懂（都是互联网老登了），它默认看起来甚至有点「简陋」。但它真正厉害的地方，从来不是自带多少功能，而是：

核心极简，能力外置，一切都可以自己装。

解码器、歌词、音效、媒体库、界面……全靠插件扩展。

所以最后，每个人电脑里的 foobar2000，可能都不是同一个 foobar2000。

Harness 也是一样。

它真正想解决的，不是「怎么做一个功能更多的 Agent」，而是把 Agent 拆成一堆标准化、可替换、可组合的模块。

以后你可能根本不需要纠结：

「我到底该用哪个 Agent？」

而是变成：

「我想要什么模型、什么工具、什么 Skill、什么工作流，把它们拼起来就行。」

这其实挺像这两年整个 Agent 的演化方向：

以前大家都在造 Agent，现在越来越多人开始造 Agent 的操作系统。

模型会换，Agent 产品也会换。

但真正能沉淀下来的，可能是你自己的插件、Skills、Workflow、数据和业务逻辑。

所以我越来越觉得：

未来真正值钱的，未必是哪一个 Agent，而是你围绕 Agent 积累出来的那套「组件库」。

再暴论一点：

foobar2000 是播放器的 Harness，Harness 则有点像 Agent 世界的 foobar2000。
