# YC 2026 夏季批次：Agent 浪潮向基础设施与实体产业下沉

> 作者对 YC 2026 夏季 235 家公司的观察是：创业热点正从通用 Agent 应用下沉到身份、支付、记忆、评测、调试和推理成本等基础设施，同时向 AI 原生服务公司、机器人、国防和工业硬件扩散。

## 批次结构变化

文章称 YC 2026 夏季批次共有 235 家公司，高于春季批次的 196 家。作者引用 New Economies 的赛道整理，认为相较春季：

- B2B 比重下降。
- 工业类占比接近翻倍，成为第二大赛道。
- 金融科技和消费类收缩。
- 美国总部公司的比例略有下降。

原始抓取文本丢失了部分分类标签，只保留了百分比，因此归档不重建无法确认的分类对应关系。文章也明确指出，没有可靠的“AI 公司占比”或“Agent 公司占比”数据；当几乎所有公司都使用 AI 时，这个标签本身的信息量有限。

## Agent 的基础设施层

作者将一组公司概括为 Agent 的“水电煤”：

- **身份与通信**：为 Agent 提供邮箱、电话号码、消息账号和两步验证保管。
- **支付与资金权限**：管理 Agent 如何花钱。
- **记忆**：提供 Agent 的长期状态和上下文基础设施。
- **评测与纠错**：检查 Agent 是否完成任务，失败后自动创建修复请求。
- **运行时调试**：观察和定位 Agent 执行过程中的问题。
- **模型经济性**：基于真实流量微调较小模型，以自动评测把关，再将日常请求路由到低成本模型。
- **推理与算力**：GPU 市场、推理路由和专用芯片。

背后的判断是：当 Agent 从演示进入真实工作，身份、支付、记忆、调试、评测和成本都会成为独立预算项。

## AI 原生服务公司

另一类公司不把工具卖给传统服务机构，而是直接经营会计、法律或市场研究等服务，用 Agent 完成大部分交付。

这种模式从按席位收费转向按结果收费，潜在客单价和价值捕获更高，但经营者必须承担错误成本。核心竞争力不只是模型，而是领域流程、质量控制、异常处理、责任边界和人工兜底。

对小团队而言，可迁移的方向不是简单复制某个 Agent 产品，而是选择熟悉的垂直行业，把 Agent 嵌入完整交付链路，并对最终结果负责。

## 硬件与实体产业回归

文章还观察到机器人、国防、能源和工业硬件升温，并列举家用机器人、反无人机、自主搬运机器人、机器人控制代码和海上数据中心等项目。

这组案例支持一种趋势判断：软件生成成本降低后，受物理制造、部署、渠道和交付约束的产品反而更稀缺。AI 的价值也从纯软件界面延伸到现实世界执行。

## 三个可迁移信号

1. **通用 Agent 应用趋于拥挤**：机会向基础设施、治理和成本层移动。
2. **垂直服务值得关注**：不只卖工具，而是用 Agent 直接交付有明确结果的服务。
3. **实体世界重新变重要**：机器人和工业产品将软件智能转化为高门槛的物理交付。
