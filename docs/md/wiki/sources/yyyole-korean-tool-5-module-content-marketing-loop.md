# 沐阳（@yyyole）：一个韩国工具把内容营销做成 5 个 AI 模块的完整闭环

> 拆解一个把整个内容营销工作流塞进单一工具的方案（五个 AI 模块）：① Collector 从 X、Threads、YouTube、TikTok、Reddit、GitHub 等 10 个渠道持续抓取信息建立素材库；② Picker 分析素材价值、筛选选题并监控竞品；③ Creator 把同一选题自动转成 X 帖子、Threads 内容、Instagram 卡片、短视频等全平台形态并匹配品牌风格；④ Scheduler 连接 Instagram、TikTok、YouTube、X、LinkedIn、Threads、Facebook 统一排期发布；⑤ Reviewer 跟踪表现、生成分析报告并把跑得好的内容重新加工利用——即「发现热点 → 筛选选题 → 生成内容 → 多平台发布 → 分析效果 → 反哺下轮创作」的完整闭环。

看着挺高级，但感觉就是一个内容分发工具！！

不过，整个工作流还是值得借鉴的！

一个韩国老哥，搞了个工具，把整个内容营销工作流塞进一个工具里。

从找选题、写内容、做图、剪视频，到多平台发布、分析数据，还有竞品监控也都一起搞定了！

看了一下整个工作流，可以分享一下，也许会给一些朋友一些启发！整个流程被拆成了 5 个 AI 模块：

Collector：自动收集素材

从 X、Threads、YouTube、TikTok、Reddit、GitHub 等 10 个渠道持续抓取信息，建立自己的内容素材库。

Picker：AI 筛选选题

自动分析素材价值，筛选值得做的内容，还能监控竞争对手，寻找高潜力选题。

Creator：一次生成全平台内容

同一个选题和素材，自动转换成 X 帖子、Threads 内容、Instagram 卡片、短视频等不同形式，还能匹配品牌风格。

Scheduler：全平台分发

连接 Instagram、TikTok、YouTube、X、LinkedIn、Threads、Facebook 等平台，统一安排发布。

Reviewer：数据分析与内容复用

自动跟踪内容表现，生成分析报告，再把表现好的内容重新加工利用！

这其实就是做自媒体，以及内容营销的一整个闭环！

发现热点 → 筛选选题 → 生成内容 → 多平台发布 → 分析效果 → 反哺下轮创作。

学习这个思路，我觉得每个人都可以搭建一个自己专属的内容 AI 生产系统！

结合自己的一些内容沉淀和知识资产，让这一套工作流稳定跑起来，一个人运营多平台、多账号，可能真的会轻松很多。
