# 花 1 万积分、熬一个通宵，我整理了教育场景下所有 AI Skills

> AI 再聪明，也得先有一双能干活的手——而 Skills，就是给智能体装上的那双手。

## 一、Skills 到底是什么

没有 Skills 的 Agent = 只会聊天的书呆子。一个刚出厂、没装任何 Skills 的 Agent，就像一个刚毕业的大学生：脑子很聪明（大模型底座），懂天文地理，能陪你聊天、写诗、翻译。但是，如果你让他「帮我订张机票」或「查一下公司今天的考勤数据」，他就傻眼了——因为他虽然聪明，手却被绑住了，没法跟现实世界打交道。

**Skills = 给书呆子装上「手」和「专业证」。** 可以从两个角度理解它：

1. **Skill 就像手机里的 App**：Agent 本身是手机系统，Skills 就是微信、高德地图、美团。装了微信才能发消息，装了高德才能导航；Agent 有了「天气查询 Skill」才能报天气，有了「数据库查询 Skill」才能看报表。

2. **Skill 也像标准化的 SOP**：你不用教 Agent 怎么思考，只需给它一张「操作说明书」。比如「报销 Skill」里写着：第一步识别发票金额，第二步核对预算，第三步提交审批。Agent 照着做就行，不会瞎编。

## 二、生活中的例子

你对 Agent 说：「帮我总结一下上周的销售情况并发到钉钉群。」

**没有 Skills**：「好的，但我无法访问您的销售系统和钉钉，请您提供数据。」——典型的有脑无手。

**装了 Skills**：它会把几项能力自动串起来，一路干到底：

1. 触发「销售数据查询 Skill」，连上 CRM 系统拉取数据
2. 触发「数据分析 Skill」，自动生成总结报告
3. 触发「钉钉消息 Skill」，把报告发到指定群组

## 四、实战案例一：生成课程设计

用 **Course-designer**，只给它一句话：

> Course-designer：人教版 A 版高中数学必修第一册 2.3 二次函数与一元二次方程、不等式，word 格式。

产出：结构完整、可直接落地的课程设计文档，教学目标、重难点、教学过程一应俱全。
