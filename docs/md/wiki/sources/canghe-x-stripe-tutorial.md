# 2026年最新最全X认证+ Stripe绑定教程

终于完成了X认证+港卡办理+Stripe绑定的一整套流程，现在可以领马斯克工资了。

整体流程需要涉及的东西还蛮多的，我也学习了很多大佬的经验，特别是wise老师的教程帖子，结合自己的实践，也给大家带来最新的2026年X认证+ Stripe绑定教程。

主要会涉及港卡开通、Stripe 账户创建、X认证、X绑定Stripe。

花了不少时间整理，如果有帮助可以点赞分享给有需要的朋友。顺祝大家元旦快乐呀。

#  一、Stripe 账户创建

1、邮箱建议选择谷歌邮箱, 运营国家选择香港。

接着就会进入一个沙盒模式，这个不用管，点击上方的提示「填写资料」去填对应的资料。

![](../images/canghe-x-stripe-tutorial/001.jpg)

2、填写商家信息

接下来会收到一个激活邮件，点击后就会进入到这样的界面，开始填写具体的信息

![](../images/canghe-x-stripe-tutorial/002.jpg)

业务所在地选择香港，商家的类型我们就选择 individual，代表个人的账户。

![](../images/canghe-x-stripe-tutorial/003.jpg)

3、个人详情

然后点击继续，会进入个人详情信息填写。填写一个香港地址（这里可以选择地址生成器随便填写一个好了），电话号码可以选择国内手机号，香港身份证件号码就填写护照号码即可（可以去移民局微信小程序查询，按理论上港澳通行证也可）。

![](../images/canghe-x-stripe-tutorial/004.jpg)

4、公司详情

公司网站这里可以选择自己官网或者 X 主页，这里我填写的 X 主页链接

5、产品或服务

类型选择「软件」，然后服务描述就自己写下。

![](../images/canghe-x-stripe-tutorial/005.jpg)

6、公开详情

这里对账单需要和刚才提供的商家网站一致名称，这里我填的就是自己的名字了。然后客户支持就填写自己的手机号。

![](../images/canghe-x-stripe-tutorial/006.jpg)

7、添加银行账户

这里比较重要，就是绑定我们之前开通的港卡，如果你还没开通港卡，可以看下我之前的教程：https://x.com/canghe/status/2005558647070634051?s=20

我开通了众安和汇丰，但汇丰比较重要，还有其他用处，防止受到影响，就先绑定众安吧。但其实我一开始申请了Wise，结果审核了好久好久，等我去香港办完了才给通过。（Wise还是方便的不用人去香港）

银行输入ZA BANK 后，分行地址就自动弹出来了，输入银行账号，提现的话就选择手动提现吧。

![](../images/canghe-x-stripe-tutorial/007.jpg)

8、税务计算

就选择默认的「一般以电子方式提供的服务」即可。

![](../images/canghe-x-stripe-tutorial/008.jpg)

9、捐款

个人可以自己选择是否捐款。

![](../images/canghe-x-stripe-tutorial/009.jpg)

10、提交审核

一切准备完毕，直接提交审核就好了。

![](../images/canghe-x-stripe-tutorial/010.jpg)

11、验证账户状态

点击右上角设置，选择商家——账户状态，需要激活下。

![](../images/canghe-x-stripe-tutorial/011.jpg)

这里需要到手机上拍照护照：

![](../images/canghe-x-stripe-tutorial/012.jpg)

然后等待审核就好了，通常需要 2-3 个小时，快的十几分钟也就会通过了。

![](../images/canghe-x-stripe-tutorial/013.png)

# 2、X 绑定Stripe

点「创作者工作室」：

![](../images/canghe-x-stripe-tutorial/014.jpg)

这里先是要进行认证，具体可以查看苍何之前的文章：

1、https://x.com/canghe/status/2004216665819828231?s=20

2、https://x.com/canghe/status/1997549334070530237?s=20

![](../images/canghe-x-stripe-tutorial/015.jpg)

点击设置付款，连接 Stripe 账户：

![](../images/canghe-x-stripe-tutorial/016.jpg)

输入刚才注册的 Stripe 邮箱，然后选择刚刚注册的账户：

![](../images/canghe-x-stripe-tutorial/017.jpg)

这个时候会看到提示说缺少 W-8/W-9 证书：

![](../images/canghe-x-stripe-tutorial/018.jpg)

点击更新，然后在非美国纳税人识别码这里填写护照号：

![](../images/canghe-x-stripe-tutorial/019.jpg)

这样就大功告成了：

![](../images/canghe-x-stripe-tutorial/020.jpg)

点击继续，就能看到这个界面代表已经完成了。

![](../images/canghe-x-stripe-tutorial/021.jpg)
