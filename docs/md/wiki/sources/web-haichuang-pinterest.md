## 运营一下 Pinterest 也能带来用户

这个是建站大佬蓝星空在浅水虾群里推荐的方式：

> 【pinterest.com 这个站也值得好好运营一下，他还只在 pinterest.com 发了一张图片，现在每天就有好几个不同国家的人点进来了。】

虽然出海 Web 主要的流量获取方式是 SEO，但是其他地方也多多益善。毕竟 Pinterest 是一个用户精准的网站，从这里进来的流量，不是太泛流量。

大家快去养号吧。
