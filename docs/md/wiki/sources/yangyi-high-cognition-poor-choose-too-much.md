# Yangyi：为什么看起来聪明的人反而赚不到钱——选择太多、看不上朴实机会

> 高认知穷人之所以穷，是因为**选择多**：很多明确赚钱的机会看不上——当号贩子能赚钱（朴实无华）、卖 API 做中转也能赚钱，但偏要硬着头皮创业做什么 personal agent，然后被大厂卷。反观失业后的人很明确自己没有别的路，只能做自媒体……选择少反而更聚焦。
