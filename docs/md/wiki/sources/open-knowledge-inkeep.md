## 项目定位

OpenKnowledge 由 **Inkeep** 开源。Inkeep 是一家专注 AI 驱动的企业知识管理公司（产品包括 AI-powered search、AI chat 等企业知识平台）。

项目定位是 **"AI 原生 Markdown IDE 和 LLM Wiki"** —— 将个人知识管理（PKM）、第二大脑（Second Brain）、知识图谱与 LLM 驱动的 AI 能力结合到一个工具中。

## 与 LLM Wiki 概念的关系

Topic 中的 `llm-wiki-karpathy` 表明该项目直接关联 Karpathy 提出的 **LLM Wiki** 概念——将 LLM 从"回答问题"转变为"维护一个可迭代的知识库"。

OpenKnowledge 的"AI 原生"方向意味着：知识不是静态地写在那里，而是由 Agent 帮助维护、关联和演化。这与本站（Nova Vault Studio）的 LLM Wiki 实践方向一致——知识库不是最终产品，而是持续运行的知识基础设施。

## 与本站的关系

本站已在使用 LLM Wiki 模式（`docs/md/wiki/` 四层架构：sources → summaries → concepts → artifacts），OpenKnowledge 提供了一个开源工具化的参考实现——将这一模式封装为一个可安装的 AI 原生 Markdown IDE。
