# 在深圳做了两片网球场

年前我们自己做了两片网球场，昨天是开工的第一天。



为什么会选择做一个自己的网球场，动机也很简单：身边的几个人都在打网球，平时一是场地难约，二是这么多人经常上课、约场也是一笔不小的费用，所以我们干脆就决定，自己做一片网球场。



这种偏重资产的生意有几个难点。因为我们一窍不通，从场地到装修再到运营，价格已经被层层加码，相比专业玩家，可能要多支付30%的冤枉钱。不过算了下这个钱也还能接受，就没再纠结。最坏的情况就是没什么生意，自己多上课来填坑，也算锻炼身体。



从有这个想法到落地，用了一个多月。找场地大概一个月，施工差不多半个月，效率算是挺快的，也比较符合我做事的逻辑：在纠结干不干这件事上不会浪费太多时间，一旦确定做，就赶紧推进，没必要前摇太久。



今天开业还挺顺利。说是开业也没那么正式，因为没有做任何曝光：没有开美团、没有开小红书，甚至也没几个人知道我去做了个网球场。第一天就赚了第一桶金。原本估计怎么也要三月开始才能正式运营，磨合一段时间，没想到第一天就赚了还不少。体验课和场地费赚了350，更惊喜的是第一单体验课转化了30节私教课，利润应该有5000–6000。



关于第一桶金跟大家分享下怎么来的，因为它不是靠运气中彩票，更像是这个世界总是在奖励努力做事的人的一种反馈，有个前提：我去年年底才搬来深圳，在这边基本没什么资源。就上了十来节网球课，认识了一个当时比较熟的教练。当有了自建网球场的想法的时候，我就跟团队商量，能不能把这个教练挖过来。把意向跟他说了之后，他一直有些推辞，说课排满了没有时间聊。



我们都已经算是“三顾茅庐”了，还没见上面。团队小伙伴说，这个人太不上道了，要不别找了。我说别跟钱过不去，我们一点资源都没有，开局亏损和开局赚钱的心气肯定不一样。



如果能把这个教练拉过来，再带一些客户资源，压力完全不一样。后来想了个办法：假装去上课，实际上是想借这个机会聊能不能过来。果然这样才终于见上面，聊了一轮，该画的饼也画了，最后还是因为稳定性的问题，把我们拒绝了。



本来我们也死心了。年前最后一个工作日，他说可以推荐一个朋友过来当教练，大概聊了下，不过第二天就回家过年了。我们也没抱太大希望，毕竟都是口头沟通，像在开盲盒：先别说能不能带客户，连这个人什么水平、能不能来球场、甚至回不回深圳，都不知道。



结果初七他回深圳主动联我们，说初八可以上班，当天邀约一下老客户。开业第一天他就约了两个试听课，其中第一单试听课直接卖了1万多。



这件事体验给大家都非常好，就像这个世界一直在奖励积极主动的人，奖励在做事情的人。



还有一个小插曲，也值得一聊，同一天还入职了一位运营同学。晚上因为有学员上课，我们也在现场，运营也跟着忙，就顺便一起打了几盘。然后发现一个很离谱的点：他居然不会打球。但之前面试的时候，他说自己是3.0水平，这里要解释下因为他上一家也在网球机构任职，所以我们默认他是清楚3.0是什么水平的。就算有水分，也不应该差到几乎是初学者。



上完课之后一起吃饭聊到这个运营。我当时就说，这个人肯定要不了，倒也不是运营必须会打网球，而是一开始就掺了水分，我会默认后面所有表达都有水分。



无论目的是什么，这一层信任已经打破了，后面很难修复。他们希望再给三天时间适应。我问，三天之后你会用吗？对方说可能也不会用，只是心里舒服一点。我说既然都确定不会用，那就别浪费彼此时间了，直接叫他打车过来，把事情当场交割清楚，如果让他继续干三天，中规中矩，加上岗位又没人替代，很可能再拖到七天。



随着工作的交接越来越多，会多出很多潜在风险，而且越往后越难收。最后还是要回到同一个决定，那不如早点做完。面对一个错误，当下改正就是最小成本。



聊得还算顺利，打车回来十来分钟就交割好了。今天聊的这些碎片和我的做事风格一致，所有环节都是比较干脆明朗的，都是可以验证的反馈。



一件是场地：从想法到落地，一个多月，球场真的在那儿，你能站在上面打球。



一件是业务：没有宣传、没有仪式，第一天就有人上课，第一单就能卖到一万多。



一件是人：合作初期就有不好的体验，没有心存幻想，当天就把合作关系收掉。



这三件事放在一起，就会更清楚什么是关键：有些事你只要往前推，它就会给你结果；但有些关系一旦出现裂缝，它会拖着你，把你往后拽。



这里顺便发一个广告，招聘全职网球教练：地址在深圳南山区科技园，薪资每个月15000-20000，有感兴趣的可以后台联系。
