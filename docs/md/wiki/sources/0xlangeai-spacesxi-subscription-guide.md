# SpaceXSI订阅大一统详解：Grok、Cursor、X合并套餐全解读

> One subscription. Access to everything. 但这到底是真省事，还是换皮涨价？

## 大一统是什么

以前你可能一边付Cursor，一边付SuperGrok，再一边付X Premium。现在官方给一条新路：一份订阅，打通三产品。

**共用周池**：Grok和Cursor共用同一个一周刷新的用量池，Chat/Imagine/Voice/Bot/API都从这口池子里喝。一天造猛了不会直接吃光整月，但见底了要么top-up，要么等刷新。

## 各档定价（月付）

| 档位 | 月价 | 年付月均 | 核心权益 |
|------|------|---------|---------|
| Free | $0 | - | 尝鲜，限额度 |
| Plus | $8 | ~$7 | 共享用量池入门，Grok API，X蓝标，少广告 |
| Premium | $30 | ~$25 | 用量约Plus 4倍，Grok Bot，最新模型，AI图/视频，代码托管 |
| Super | $100 | ~$84 | 用量约15倍，高峰期优先访问 |
| Ultra | $200 | ~$167 | 用量约50倍，power user |

Plus不含Grok Bot（从Premium开始才有）。Cursor里用Claude/GPT等第三方模型另算。

## 新用户怎么选

- **X创作+偶尔用AI** → Plus
- **认真用Grok+Cursor+Bot** → Premium（官方推荐）
- **每天跟agent干活，池子老见底** → Super
- **用量夸张或团队协作** → Ultra / Teams

## 老用户切换注意

**切完永久不可撤销**，Support也不能帮你撤。

- 有付费Cursor：从 [cursor.com/unify](https://cursor.com/unify) 起步
- Grok侧：从 [accounts.x.ai/unify](https://accounts.x.ai/unify)
- X侧：产品内banner/订阅设置（注意：从X起步不含Cursor）

**App Store坑**：
- Cursor走Apple内购：官方不能取消、不能退，需自己向Apple申请
- Grok/X Premium走App Store：官方会取消并申请退款，退多少由Apple定
- Google Play：切完自己去订阅里看一眼
