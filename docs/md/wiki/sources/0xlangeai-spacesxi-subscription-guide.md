# SpaceXSI 订阅大一统详解：Grok、Cursor、X 合并套餐全解读

> One subscription. Access to everything. 但这到底是真省事，还是换皮涨价？

## 大一统是什么

以前你可能一边付 Cursor，一边付 SuperGrok，再一边付 X Premium。现在官方给一条新路：一份订阅，打通三产品。

**共用周池**：Grok 和 Cursor 共用同一个一周刷新的用量池，Chat/Imagine/Voice/Bot/API 都从这口池子里喝。一天造猛了不会直接吃光整月，但见底了要么 top-up，要么等刷新。

## 各档定价（月付）

| 档位 | 月价 | 年付月均 | 核心权益 |
|------|------|---------|---------|
| Free | $0 | - | 尝鲜，限额度 |
| Plus | $8 | ~$7 | 共享用量池入门，Grok API，X 蓝标，少广告 |
| Premium | $30 | ~$25 | 用量约 Plus 4 倍，Grok Bot，最新模型，AI 图/视频，代码托管 |
| Super | $100 | ~$84 | 用量约 15 倍，高峰期优先访问 |
| Ultra | $200 | ~$167 | 用量约 50 倍，power user |

Plus 不含 Grok Bot（从 Premium 开始才有）。Cursor 里用 Claude/GPT 等第三方模型另算。

## 新用户怎么选

- **X 创作+偶尔用 AI** → Plus
- **认真用 Grok+Cursor+Bot** → Premium（官方推荐）
- **每天跟 agent 干活，池子老见底** → Super
- **用量夸张或团队协作** → Ultra / Teams

## 老用户切换注意

**切完永久不可撤销**，Support 也不能帮你撤。

- 有付费 Cursor：从 [cursor.com/unify](https://cursor.com/unify) 起步
- Grok 侧：从 [accounts.x.ai/unify](https://accounts.x.ai/unify)
- X 侧：产品内 banner/订阅设置（注意：从 X 起步不含 Cursor）

**App Store 坑**：
- Cursor 走 Apple 内购：官方不能取消、不能退，需自己向 Apple 申请
- Grok/X Premium 走 App Store：官方会取消并申请退款，退多少由 Apple 定
- Google Play：切完自己去订阅里看一眼
