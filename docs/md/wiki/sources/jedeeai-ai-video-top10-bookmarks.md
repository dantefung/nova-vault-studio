## 榜单里的三条技术路线

10 篇实操帖大致落在三条路线上：

| 路线 | 代表条目 | 核心手段 |
|------|----------|----------|
| **代码做视频** | #3 xilo、#5 观默、#9 宝玉 | Opus 5.5 / Codex 写代码渲染，不走 GUI 剪辑 |
| **Prompt + Skill 模板化** | #1 卡尔（463 个视频转成 Skill）、#6 Simon（Excalidraw 白板风） | 把一次成片经验沉淀成可复用 Skill |
| **工作流编排** | #2 Miles（零剪辑爆款）、#4 雪踏乌云（Codex + Hypit 复刻） | 用 Agent 编排既有工具链，产出可发布成片 |

**共同点**：全部强调「不露脸、不剪辑」或「零剪辑」——把传统剪辑工时压到最低。
