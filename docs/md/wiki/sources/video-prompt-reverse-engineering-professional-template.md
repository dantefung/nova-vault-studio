# 视频反推提示词：快速版与 18 维专业模板

> 一套面向短视频、广告、Vlog、MV 和教程视频的反推模板，分为快速七要素版与逐镜头十八维专业版，并附成品 Prompt、负面提示词、类型专项要求和固定输出格式。

<!-- more -->

## 使用边界

这套模板用于提取参考视频的镜头逻辑和视觉方法，不用于照抄人物、品牌、台词或具体故事。反推结果是对视觉语法的近似描述，不是对原始生成 Prompt 的恢复。

使用前应指定目标视频模型，例如 Sora、Kling、Runway、Vidu 或 Pika。不同模型支持的镜头数量、时长、负面提示词和参数不同，输出后仍需按目标模型调整。

## 快速通用版

适合短视频、产品展示、Vlog 片段，以及需要快速获得可执行 Prompt 的场景。

```text
请根据上传视频，反推一套完整、可直接使用的 AI 视频生成提示词。

要求：表达无歧义、高度可执行，避免模糊抽象表述。每一项都必须具体、可视化、可落地。

提示词必须覆盖以下七项核心要素：

1. 主体

明确视频核心对象的关键细节。

人物：年龄段、性别、体态与比例、面部特征、肤质、发型、妆容、服装款式与面料、颜色与图案、合身度、配饰、情绪状态和整体气质。仅在画面证据充分且任务确有必要时描述敏感人口属性，不确定时标记为不确定，不要猜测。

物品：尺寸比例、材质、颜色与饱和度、表面反光特性、结构细节和使用状态。

场景作为主体时：建筑类型、空间尺度、关键地标或标志性元素。

2. 动作

描述起始姿态 -> 运动过程 -> 结束姿态。说明速度、节奏、力度、手部动作、重心转移、身体朝向、微表情、视线方向，以及主体入镜、停留、移动和出镜的方式。

3. 场景

描述环境与空间结构，包括：
- 室内房间类型、建筑风格、空间布局、家具陈设和墙面材质。
- 室外地形、植被、天际线、街道或自然环境。
- 前景、中景和背景的层次与纵深。
- 时间、季节、天气和整体氛围。

4. 光影

说明自然光、人工光或混合光，硬光、柔光或漫射光，光源方向、强度、阴影边缘、面部明暗分割、轮廓光、眼神光、投影、反射、折射、整体色温及色温变化。

5. 运镜

说明景别、焦段感受、构图、机位、镜头运动轨迹和速度、景深与焦点转移、屏幕比例，以及多镜头之间的切换方式和时序关系。

6. 风格

定义影像类型、色彩体系、调色方向和画面质感，并确保人物、场景与光影风格一致。

7. 画质

说明目标分辨率、帧率和质量要求。避免把“8K”“无噪点”等标签当作万能质量词，应优先描述目标模型真正支持的输出规格，以及高细节、自然动作、稳定时序、正确比例和受控景深等可检查结果。
```

## 完整专业版

适合多镜头长视频、广告、短剧、MV，以及需要精确复刻镜头语言的场景。

```text
请作为 AI 视频提示词架构师、电影镜头语言分析师和多模态视频逆向工程师分析上传视频。

不要只总结内容。请严格按照时间顺序逐镜头完成以下任务。对无法从视频确认的信息标记“不确定”，不要自行补全事实。

第一步：逐镜头时间轴拆解

每个镜头必须包含以下十八个维度：

01. 镜头编号与时间码
使用 Shot 01 [00:00-00:03] 格式。

02. 主体身份与外观锚点
描述人物可观察的年龄段、体态、发型、妆容、服装、配饰与情绪，或物品的尺寸、材质、颜色、结构和使用状态。敏感属性仅在证据充分且任务必要时描述。

03. 动作轨迹
起始姿态 -> 运动过程 -> 结束姿态，包括手部细节、重心变化、速度和力度。

04. 微表情与视线
记录眉毛、眼睛和嘴角的变化节点，以及视线方向和变化。

05. 场景空间
记录室内外类型、建筑风格、空间布局和关键陈设。

06. 前中后景关系
记录前景元素、中景主体、背景环境的层次和纵深。

07. 景别
大远景、远景、全景、中景、中近景、近景、特写或大特写。

08. 机位高度与角度
平视、俯拍、仰拍、荷兰角、鸟瞰或低机位，并估计机位与主体的相对距离。

09. 焦段感受
广角空间延伸或畸变、标准透视、长焦压缩或背景虚化。

10. 构图
三分法、中心、对称、黄金比例、引导线、框架或对角线构图。

11. 景深
浅景深、深景深、虚化范围和焦点转移方向。

12. 运镜方式与速度
推、拉、摇、移、跟拍、环绕、升降、手持或稳定器，并说明匀速、加速、减速或骤停。

13. 光线方向与类型
记录光源方向、自然光或人工光、硬光或柔光，以及可判断的光比。

14. 色温与调色
记录冷暖倾向，以及暗部、高光和中间调的颜色方向。

15. 材质与质感
记录金属、织物、皮肤、玻璃、液体等关键材质的视觉表现。

16. 节奏
记录镜头时长、动作速度、剪辑节奏、停顿和呼吸感。

17. 转场
记录硬切、叠化、闪白、遮罩、运动匹配、声音桥接或其他衔接方式。

18. 环境声音与音效
记录环境底噪、关键音效、音乐节奏及其与画面的配合。无法从输入中听见声音时明确说明。

第二步：输出成品生成提示词

基于上述拆解，输出适用于 <TARGET_MODEL> 的成品生成提示词。每个镜头分别包含：

1. 起始画面：第一帧的完整视觉描述。
2. 主体动作：镜头内完整的动态过程。
3. 摄影机运动：运动轨迹、速度和焦点变化。
4. 结束画面：最后一帧的完整视觉描述。
5. 镜头衔接：与下一镜头的视觉、动作、声音或情绪连接。

第三步：输出负面提示词或禁止项

根据目标模型是否支持负面提示词，输出可用的负面提示词，或转换为正向质量约束。覆盖人物一致性、肢体动作、面部表情、场景物理、画面质量、运镜和时间连续性。

第四步：声明提取原则

只学习镜头逻辑和视觉方法，不照抄人物、品牌、台词和具体故事。输出是对视觉语法的提取，不是对原视频内容或原始 Prompt 的复制。
```

## 负面提示词与质量约束

并非所有视频模型都支持独立的负面提示词字段。支持时可以使用下列禁止项；不支持时，应改写为正向约束，例如把“禁止人物变脸”改为“所有镜头保持相同面部锚点”。

### 人物一致性

- 避免面部特征、肤色、发型、服装和配饰在镜头间漂移。
- 保持角色身份、年龄感、体态比例和妆容连续。
- 避免配饰消失、变形或位置跳变。

### 肢体与动作

- 避免多指、缺指、手指融合、穿模和关节反向弯曲。
- 避免头身比、手臂或腿部比例异常。
- 保持动作连续，避免帧间跳跃、肢体穿透和非预期悬浮。
- 保持脚部与地面、手部与物体之间合理接触。

### 面部与表情

- 避免面部扭曲、五官位移、牙齿融合或异常排列。
- 避免双眼大小、瞳孔方向和眼白比例异常。
- 保持表情与情境一致；有语音时保持口型同步。

### 场景与物理

- 避免背景闪烁、建筑和家具漂移。
- 保持重力、阴影、反射、折射和接触关系合理。
- 保持透视和人物与环境比例一致。
- 避免同一物体的材质在帧间突变。

### 画面质量

- 避免非预期模糊、局部失焦、色带、撕裂和帧间闪烁。
- 避免水印、乱码、伪文字和局部清晰度异常。
- 保持画幅、分辨率感和锐度一致。

### 运镜与时间

- 避免非预期的镜头跳变、卡顿、回放和时间流速突变。
- 保持相邻镜头的光线方向和色温连续，除非变化是明确的叙事设计。

## 类型专项补充

### 人物与剧情

- 标注情绪起点、变化节点和情绪终点。
- 多人场景标注站位、距离、朝向和互动方式。
- 对话场景记录正反打、视线匹配和轴线关系。
- 记录台词密度、停顿、沉默和表演节奏。

### 产品与商业广告

- 每次产品出现时记录展示角度、光线、材质高光和品牌标识可见度。
- 记录产品与手或环境的交互方式。
- 区分快节奏的情绪驱动与慢节奏的细节展示。
- 记录字幕、标题和价格等文字元素的时间与动效；复刻时不要沿用受保护的品牌素材。

### 风景与旅行

- 记录近景、中景和远景的大气透视层次。
- 记录日出、正午、黄金时段和蓝调时刻等自然光变化。
- 记录风、水、鸟鸣、远处人声和静默等环境声音层次。
- 说明运镜如何顺应山脊、河流、道路或地平线。

### 音乐与 MV

- 记录剪辑点与节拍的踩拍、反拍或连续快切关系。
- 记录前奏、主歌、副歌和间奏对应的视觉节奏。
- 记录色彩与情绪段落的变化。
- 记录闪白、升降或其他特效与音乐节点的同步关系。

### 美食、手工与教程

- 记录俯拍工作台中工具、材料和成品的排列。
- 记录关键步骤、材质变化和完成瞬间触发的特写。
- 精确描述揉、切、搅、倒、撒等手部动作的速度和力度。
- 记录面团膨胀、酱汁收浓、金属发光等材质变化过程。

## 使用方法

1. 上传视频或切分后的关键片段。
2. 选择快速版或专业版，并指定目标生成模型。
3. 将模板提交给支持视频理解的多模态模型。
4. 人工校正不确定观察和镜头时间码。
5. 将成品 Prompt 输入视频生成模型。
6. 按主体、动作、镜头、光影、材质和一致性评估结果，每轮只修订影响最大的差异。
