# 杨小乱（@yxl44）：20 万 Star 的 agent-desktop——不用截图、不模拟坐标，直接读系统无障碍接口

> 介绍 GitHub 上 20 万 Star 的桌面 Agent 控制项目 agent-desktop：不截图识别也不模拟鼠标坐标，直接读取系统无障碍接口识别桌面应用里的按钮、输入框与菜单，再让 AI 自己点击、输入、滚动、执行操作；支持 macOS / Windows / Linux，兼容 Claude Code、Codex 等 Agent 工作流，提供 CLI 与 MCP 接口，60 种命令覆盖窗口、键盘、鼠标、剪贴板，基于 Rust 构建。并抛出行业问题：当 AI Agent 真正拥有电脑操作权限，传统 RPA 自动化还剩多少生存空间。

Github 这个项目太无敌了，20 万星标！！！

codex、Claude Code、Grok Bot 都不用续费了！！！

目前地球上最好用的 Agent 控制电脑项目

不用截图识别，也不用傻乎乎地模拟鼠标坐标

直接读取系统无障碍接口，识别桌面应用里的按钮、输入框和菜单，再让 AI 自己点击、输入、滚动、执行操作。

更重要的是：

· 支持 macOS、Windows、Linux

· 支持 Claude Code、Codex 等 AI Agent 工作流

· 提供 CLI 和 MCP 接口

· 支持 60 种命令，覆盖窗口、键盘、鼠标、剪贴板等操作

· 基于 Rust 构建

这才是 AI 桌面自动化该有的样子。

以后 AI 不光能帮你写代码，还能直接打开软件、操作界面、完成任务。

问题来了：当 AI Agent 真正拥有电脑操作权限，传统 RPA 自动化还有多少生存空间？
