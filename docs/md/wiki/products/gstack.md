# gstack

> AI 编程全流程管控工具，核心是 Browse 引擎 + 7 阶段 Sprint 管线

## Core Concept

- **Browse 引擎**：浏览器自动化能力，支持 AI 操控浏览器进行编程和测试
- **7 阶段 Sprint 管线**：完整的开发流程管理，从需求到交付
- **QA 能力**：自动化的质量保证，可与人工测试结合

## Use Case

用户工作流：
1. Superpowers 执行 TDD
2. 人工测试结合 gstack 的 QA
3. gstack 管控全流程
