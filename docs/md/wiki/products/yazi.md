# Yazi

> 用 Rust 开发的异步文件管理器，高性能、现代 UI、键盘友好。

## Core Capabilities

- 高性能异步 I/O
- 图片预览、图标显示
- 高效键盘导航
- Lua 脚本插件扩展

## Technical Highlights

- Rust 编写，性能优异
- 基于异步 I/O，响应快速
- 支持多种预览器（bat、eza、ffmpeg 等）
- 可通过 Lua 脚本深度定制

## Use Cases

- 终端文件管理
- 需要快速浏览和预览文件
- 高度定制化的文件管理工作流
