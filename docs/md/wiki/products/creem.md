# Creem

支付服务提供商，用户可直接使用信用卡/借记卡支付。

## 费用

- 每笔交易手续费：3.9% + $0.4
- 提现到 Wise：~2.1% 手续费
- 欧盟 VAT：19-22%（需代缴）

## 优势

- 用户友好，显示为"借记卡和信用卡"
- 80%+ 用户首选
- 适合个人开发者/SaaS

## 劣势

- 欧盟地区 VAT 高昂（19-22%）
- 提现到 Wise 再到银行卡，总损失约 24.9%

- [[paypal]] — 竞争对手
- [[wise]] — 提现渠道
