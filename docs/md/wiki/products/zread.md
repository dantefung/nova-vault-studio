# Zread

> 发现和阅读优质代码仓库的平台，支持 MCP 和 CLI

## Core Features

- **仓库发现**：发现趋势仓库（Trending Repos）
- **私有仓库支持**：添加私有仓库阅读
- **Zread MCP**：支持 Model Context Protocol
- **Zread CLI**：本地仓库命令行工具
- **Library**：个人阅读库
