# go-stock（AI股票分析工具）

> AI加持的股票分析/选股工具。股票行情获取，AI热点资讯分析，AI资金/财务分析，涨跌报警推送。支持A股/港股/美股。

## Key Points

- **核心定位**：专注于市场/个股整体情绪分析，结合 AI 对市场资讯、资金流向、技术指标进行综合分析
- **支持市场**：A股 ✅ · 港股 ✅ · 美股 ✅
- **支持模型**：OpenAI / DeepSeek / Ollama（本地）/ LMStudio（本地）/ 硅基流动 / 火山方舟 / 阿里云百炼
- **技术栈**：Wails（Go + WebView）+ NaiveUI（Vue 3）+ TypeScript

## 核心功能

- **AI 分析市场资讯**：AI 总结新闻要点
- **市场/个股情绪分析**：带频率权重的情感分析，量化市场情绪
- **AI 智能选股**：根据市场行情 AI 总结 + AI 智能体选股
- **技术指标**：多周期 K 线图、SATS 自感知趋势指标、13 个 TradingView 指标集成
- **资金/财务分析**：个股资金流向、主力净流入、行业排名
- **涨跌报警推送**：钉钉通知等
- **龙虎榜 + 个股研报 + 公司公告**
- **弹幕功能**：盯盘不孤单
