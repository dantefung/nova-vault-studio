# AgentHub

把 Claude Code 直接升级成一支可调度的虚拟研发团队。

## 核心特性

- **内置 46 个角色**：产品经理、技术主管、前后端开发等，按真实公司架构分工协作
- **标准化工作流 + 质量门禁**：需求→交付每步都卡在流程里，该评审就评审，该验收就验收
- **安全拦截**：危险命令执行或测试不通过时强制中断，避免带病上线
- **可视化桌面端**：Windows / macOS / Linux 跨平台支持，任务状态、文件变更、Agent 管理一屏可查
