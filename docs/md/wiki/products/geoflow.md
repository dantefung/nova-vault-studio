# GEOFlow

> 开源 GEO（生成式引擎优化）内容工程与多站点分发系统，1.6k+ stars。

## Core Capabilities

- **GEO 内容工程**：把可信资料沉淀为可管理、可生成、可发布、可追踪、可同步到多端的内容资产
- **多模型支持**：兼容 OpenAI 风格接口，支持 chat / embedding 模型、智能切换、失败重试
- **知识库与 RAG**：上传后自动切片 + 向量化，文章生成时召回相关资料
- **素材与提示词体系**：标题库、关键词库、图片库、作者库、知识库、正文提示词集中管理
- **任务自动化**：任务创建、生成数量、草稿池、审核开关、发布节奏、队列执行
- **多站点分发**：中心后台管理多个渠道站点的内容分发、远端同步和运行状态
- **目标站点包**：每个渠道生成预配置 PHP Agent 包，内置首页/详情页/sitemap/Schema
- **数据分析**：系统总览、单站运营、多站分发、访问日志、Top文章、AI爬虫识别

## 2.0 核心变化

1. **Laravel 重构**：后台、任务、队列、分发、数据分析等模块更清晰
2. **多站点多 Agent**：一个后台管理多个渠道站点
3. **知识库能力强化**：素材库、向量化检索、AI生成和内容调用优化
4. **分发闭环**：渠道管理、密钥、测试连接、分发队列、远端编辑删除
5. **目标站点包**：PHP Agent + 首页 + 详情页 + 静态资源 + sitemap + Schema
6. **数据分析页**：统一进入后台
7. **部署安全增强**：Docker 生产部署优化、多语言覆盖

## Tech Stack
