# Legado (阅读3.0)

开源 Android 阅读器，可自定义来源阅读网络内容。

**46,891 Stars · 5,777 Forks** · Kotlin · GPL-3.0

## 核心定位

阅读3.0，一款可以自定义来源阅读网络内容的工具，为广大网络文学爱好者提供一种方便、快捷舒适的试读体验。

## 核心功能

- **自定义阅读源** — 支持多种网络小说源，可自由添加配置
- **书架管理** — 书籍收藏、阅读进度、章节跟踪
- **全功能阅读器** — 目录、书签、背景、字体、夜间模式等
- **搜索** — 书源内搜索、全文搜索
- **同步** — 阅读进度同步

## 技术栈

- **语言**: Kotlin (Android)
- **平台**: Android
