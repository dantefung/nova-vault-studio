# Obsidian

本地知识库工具，作为 AI 的数据底座。

## 在这套系统里的角色

不是漂亮的笔记软件，而是 AI 的本地数据底座。

.md 文件躺在本地磁盘上，agent 可以直接 grep、直接读、直接改。

## 四类数据

- 知识沉淀：工作 / 学习笔记、Wiki 实体
- 流水记录：每日计划 + 反馈、灵感、即刻归档、日记等
- 创作产出：文章草稿、视频脚本
- 生活资料：读过的书 / 电影 / 去过的地方、签证 / 保险 / 账单等
