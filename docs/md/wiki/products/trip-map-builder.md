# trip-map-builder

> 旅行规划 skill，结合小红书评论、酒店行程、旅行偏好搜索，最后生成带地图和路程图的 HTML 行程单。

## Core Capabilities

- **小红书评论搜索**：集成 OpenAI 搜索小红书旅行评论，获取真实旅行体验
- **酒店与行程整合**：结合酒店预订、行程安排
- **旅行偏好学习**：根据用户偏好定制推荐
- **HTML 行程单生成**：输出包含每个地点地图和路程图的可视化 HTML

## Technical Highlights

- Python + OpenAI API
- 生成自包含 HTML，可离线使用
- 地图服务集成

## Use Cases

- 出国/国内旅行规划
- 生成可视化行程单分享给同行人
- 基于真实评论的旅行决策
