# Context7

> 在开发环境中获取并集成最新、特定版本的文档和代码示例的 MCP 工具。

## Core Capabilities

- 实时获取最新版本的库文档
- 确保生成的代码引用当前 API
- 减少因信息过时导致的错误
- 直接在 IDE 中使用

## Technical Highlights

- 基于 MCP 协议
- 按版本获取文档
- 支持多种编程语言和框架

## Use Cases

- 使用最新版本库时获取准确文档
- 避免 LLM 使用过时 API
- 需要特定版本文档的场景
