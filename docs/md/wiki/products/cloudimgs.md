# 云图 (Cloudimgs)

> 自建图床解决方案，适合有 NAS 的用户，支持 Docker 部署，开源自托管。

## Core Capabilities

- **自建图床**：NAS 上自建图床，摆脱第三方图床依赖
- **Docker 部署**：一条命令即可启动
- **开源免费**

## Use Cases

- NAS 用户自建图床
- 不想使用第三方图床的开发者
- 需要自托管图片的用户
