# Meigen.ai（AI生图平台）

> 域名 1 月注册，5 月流量 576 万，唯一访客 331 万。付费搜索仅 0.02%。推客矩阵 + 产品粘性驱动自然增长，可复制性极强。

## Key Points

- **产品定位**：Prompt 版的花瓣网——瀑布流里是 AI 图 + 生成它的咒语，用户不需要创作，只需要"逛"和"存"
- **增长飞轮**：推客带来首次访问 → 产品体验留住用户 → 用户收藏反复回来
- **流量数据**：576.3 万月访问 / 331.3 万唯一访客 / 68.2% 直接流量

## 技术架构

### SSR + 前端渲染
- 服务端渲染提升 SEO 和首屏加载速度
- 前端瀑布流交互优化移动端体验

### 程序化 SEO
- 大量 AI 生成图片页面 + 对应 Prompt 内容
- 每个图片详情页都是独立 SEO 页面

### 多引擎集成
- GPT Image 2 / Midjourney / Seedance 2.0 / NanoBanana
- API 聚合，用户无需切换工具

## 变现模式

积分包（一次性买断，积分永不过期）。T3 国家为主 → 订阅制不适合。
