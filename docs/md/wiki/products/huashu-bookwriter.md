# Huashu Bookwriter

从花叔4本橙皮书+开源仓库逆向拆解的写作框架，5层精密体系。

## 5层体系

### 第一层：渐进式信任建立
每章前2-3段必须有具体时间线锚点，没体验就诚实标注，不编造

### 第二层：结构化知识路径
Part1 从零跑通 → Part2 核心能力 → Part3 多场景实战，读完一章能做一件事

### 第三层：风格DNA（最关键！）
- 单句 ≤ 25字
- 第一人称高频
- 具体数字
- 禁用词表（"进行操作" → "点击"）

风格一致性不靠天赋，靠规则

### 第四层：TDD式质量铁律
- 12项章节 QC + 10项全书 QC，不通过就重写
- Rationalization Table——专门对付 Agent 找借口跳过规则

### 第五层：Agent Protocol
写作前必须研究确认事实，不凭训练数据编造

## 核心洞察

好的写作输出系统是个精密体系：**风格一致性 + 质量把控 + 读者体验**，每条都有执行标准。
