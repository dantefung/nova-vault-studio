# baokuan-title-generator-skill

> **核心结论**：SpaceZephyr/creator-buddy 仓库下的**公众号爆款标题生成 Skill**——基于 1000+ 10万+ 文章训练，fable5 + GPT-5.6 协同（精准 + 全面）。支持**两种用法**：大纲→标题（推荐）/ 文章→换标题。**适合**：公众号写作者、内容创作者、AI Skill 开发者借鉴双模型协同方法。

> **关键洞察**：
> - **16 种标题模板**：数字反差 / 生活痛点 / 揭秘 / 对话剧本 / 悬念留白 / 极值 / 认知反转 / 隐藏机制 / 场景画面...
> - **公众号新规则**：极致词（最/彻底/震惊/首个）会被限流
> - **新火方向**：口语化、观点、接地气、情绪化
> - **双模型协同**：fable5（精准戳中人）+ GPT-5.6（覆盖广）

## 一句话定义

> 用 AI 帮你**起爆款公众号标题**的 Skill。
> 输入大纲或完整文章 → 输出 10 个候选标题 + 评分 + 风险。

## 适合谁

- **公众号写作者**：每周要起几个标题的人
- **内容创作者**：跨平台发布（公众号/小红书/即刻）需要差异化标题
- **AI Skill 开发者**：想学"双模型协同"实现方法
- **产品经理**：产品发布文案的标题优化

## 两种用法

### 用法 1：先写大纲，让大纲来生成标题（推荐）

```
输入：文章大纲
输出：候选标题列表 + 评分 + 风险
```

**好处**：
- 标题定下来后写内容有"准绳"
- 不容易跑偏
- 始终知道这篇要兑现什么

### 用法 2：给已经写好的文章换标题

```
输入：完整文章
输出：10 个候选标题 + 评分 + 风险
```

每个候选都有**评分和风险**说明，但**最后拍板还是你**。

## 关键洞察

### 「震惊体」已死

公众号自五月改推荐规则后：
- 极致词（最/彻底/震惊/首个）= 限流
- 标题党 = 限流
- 题文不符 = 限流

### 「人」是核心

> 标题里始终有一个「人」在场，是「我」在跟读者说话。

### 双模型协同（AI Skill 设计方法论）

> fable5（精准戳中人）+ GPT-5.6（覆盖广）= 锋利方法 + 完整框架

这个**双模型协同**模式值得所有 AI Skill 设计者借鉴：
- 选一个**精准型模型**负责打透方法
- 选一个**全面型模型**负责覆盖框架
- 最后**融合**两边输出
