# Lazygit

> 用 Go 编写的终端 Git 客户端，提供简洁直观的 UI 进行版本控制操作。

## Core Capabilities

- 终端 UI 操作 Git
- 文件状态查看和暂存
- 提交历史浏览
- 分支管理
- 冲突解决

## Technical Highlights

- Go 语言编写，性能优秀
- 跨平台支持（Linux/macOS/Windows）
- 简洁直观的 TUI 界面
- 键盘快捷键操作

## Use Cases

- 不想记忆复杂 Git 命令的开发者
- 需要可视化 Git 状态的场景
- 终端工作流中的版本控制
