# PayPal

支付服务提供商，支持跨境人民币结算。

## 费用

- 交易手续费：4.4% + $0.30
- 贝宝跨境人民币结算：1% + $0.35
- 提现手续费：$0（当前免费阶段）
- 欧盟地区总损失：约 5.4%

## 优势

- 提现直接到公户
- 手续费相对较低（无 VAT）
- 适合有跨境收款需求的 SaaS

## 劣势

- 用户选择率低（<20%）
- 提现需 3 次以上才免费（当前）
