# find-skills

> Skill 生态入口型能力 — "找 Skill、装 Skill、扩展 Agent 能力"

## Core Concept

将模糊需求转成关键词，搜索候选 Skills 并给出安装建议。是 Agent 能力扩展的入口工具。

## Core Features

- **需求分析**：判断用户需求领域
- **关键词搜索**：通过 `npx skills find <keyword>` 搜索候选
- **安装建议**：输出候选清单和安装建议
- **高频属性**：日常使用频繁

## Use Cases

- 团队想强化前端测试，却不确定选 Playwright、E2E 还是代码审查类 Skill
- find-skills 将模糊需求转成关键词，输出候选清单
