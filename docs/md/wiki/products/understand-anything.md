# Understand-Anything

> 将代码库、文档、知识库转成交互式 Knowledge Graph，串起上下文关系，无需来回翻文件硬拼。

## Core Capabilities

- **Knowledge Graph 生成**：将代码库、文档、知识库转为交互式图谱
- **边看边搜边追问**：可视化探索代码关系
- **快速理解陌生代码库**：不用靠来回翻文件硬拼上下文
- **多类型支持**：代码库、文档、知识库皆可
