# Flipbook Canvas

点击式探索的 AI 生成知识树（142 Stars）。

## 核心创新

传统"AI 生图"只停在单张图片。Flipbook Canvas 把每张图变成可玩的知识表面：

长按任意位置 → 模型推断点击内容 → 判断是否需要联网搜索 → 生成带标注的子图。

层层递进，无限探索。

## 核心功能

- 长按图片任意位置，系统自动识别内容
- 联网搜索相关资料
- 生成全新详细图解，层层递进
- 每张图都带百科风格文字标注和说明
- 图上文字可直接框选复制
