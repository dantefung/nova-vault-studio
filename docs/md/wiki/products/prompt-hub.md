# Prompt Hub

> 提示词中心，收录各类精选提示词模板、速查表和画图提示词。

## Key Points

- 三大类别：提示词速查、文章卡片、画图提示词
- 提示词速查：快速查找常用 Prompt 模式
- 文章卡片：抽象之梯、概念卡片模板
- 画图提示词：浮世绘风格等创意生成

## Details

### 01 提示词速查

- 提示词速查表：常用 Prompt 模式一览
- 自我介绍卡片设计师：生成个人介绍卡片

### 02 文章卡片

- 抽象之梯（Abstract Ladder）：从具体到抽象的概念提炼
- 横版/竖版概念卡片模板
- 李继刚 Claude 卡片

### 03 画图提示词

- 浮世绘风格生成
- 画图 Prompt 两则
