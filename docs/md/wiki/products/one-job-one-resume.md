# One-Job-One-Resume

一岗一件定制化简历工具，帮助应届生精准展示与目标职位的匹配度。

**10 Stars · Python**

## 核心定位

针对应届生海投缺乏针对性的问题，一岗一件定制化简历能：
- 精准展示与目标职位的匹配度
- 避免简历内容冗余
- 突出关键技能和项目经验
- 提升通过筛选几率
- 展示对职位的专注和重视

## 核心价值

**个性化 vs 海投：**
- 海投：覆盖广但缺乏针对性，容易失去焦点，降低面试机会
- 定制化：在竞争激烈的 IT 行业，个性化简历才能提高通过简历大关的胜率
