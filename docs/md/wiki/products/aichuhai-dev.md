# aichuhai.dev

> droidHZ (@hezhiyan7) 创办的"AI 出海"导航站——把一年 200+ 篇实战文章按 12 大能力模块做二次分类整理，开放话题提交入口。

## Core Concept

一个 **AI 驱动的独立站出海资源导航站**，核心结构：
- 12 大能力模块分类（需求/SEO/开发/数据分析/支付/流量/外链/ads/产品设计/工具/部署/复盘）
- 每篇文章附摘要 + 原文链接
- 话题提交入口（用户可以发起新话题，作者补充内容）

## 为什么重要

aichuhai.dev 不是一个普通导航站，它本身就是一个**实战样板**：
- **AI 内容生产**：分类整理本身就是 AI 工作
- **长尾 SEO 流量**：300+ 高质量内容页 = 自然流量
- **用户参与设计**：话题提交 = 用户驱动的内容增长
- **作者权威绑定**：作者本人 1 年稳定万刀 = 内容可信度

## Use Cases

- **新人入口**：从导航站了解出海全链路
- **老手参考**：按模块找当前瓶颈对应的实操文章
- **学习路径**：配合 [[concepts/indie-site-builder-skill-stack]] 形成完整知识地图
