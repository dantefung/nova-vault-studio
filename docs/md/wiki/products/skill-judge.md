# skill-judge

softaworks 提供的元 skill，用于评估 Agent Skill 的质量。

## 来源

https://skills.sh/softaworks/agent-toolkit/skill-judge

## 用途

推荐先装好这个元 skill 再上手编写 Agent Skill。

## 评估维度

skill-judge 把决策树列为高质量 skill 的明确标志，在 D1（知识增量）和 D8（实用性）两个维度都是加分项。

### D1 知识增量 Green Flags

- Decision trees for non-obvious choices ("when X fails, try Y because Z")

### D8 实用性检查项

- Decision trees: For multi-path scenarios, is there clear guidance on which path to take?
