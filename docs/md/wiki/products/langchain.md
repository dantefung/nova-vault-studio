# LangChain

> 以"链式编排"为核心的通用型LLM应用开发框架，7万+ GitHub星标，是当前最流行的AI应用开发框架之一。

## Core Capabilities

- **Chains**：工作流编排组件，支持将多个LLM调用串联成复杂流程
- **Agents**：智能体框架，支持ReAct、Tool Calling等多种智能体模式
- **Memory**：对话记忆管理，支持上下文持久化
- **Retrieval**：检索组件，支持向量检索、关键词检索等多种方式
- **Tools**：工具集成，支持100+工具（搜索、数据库、API等）
- **LangSmith**：企业级可观测性和调试平台

## Technical Highlights

- 核心语言：Python、JavaScript/TypeScript
- 编排灵活性高，适合复杂的多步骤工作流
- 2024年推出LangGraph，支持更复杂的图结构工作流

## Use Cases

- 构建复杂AI应用
- 需要灵活工作流的智能客服
- 多工具调用的自动化流程
