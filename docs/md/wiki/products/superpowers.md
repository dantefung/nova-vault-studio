# Superpowers

> AI 编程中的质量管控工具，核心是 HARD-GATE + TDD 铁律

## Core Concept

- **HARD-GATE**：严格的质量门禁，任何代码必须通过质量门禁才能继续
- **TDD 铁律**：测试先行，测试驱动开发，确保代码质量
- **执行能力**：在 AI 编程中执行 TDD 流程

## Use Case

在 Comet 项目中与 OpenSpec 组合使用：
- OpenSpec 管归档能力
- Superpowers 管 TDD 驱动执行
- 两者组合实现"需求 → 归档 Spec → TDD → 实现验证"全流程
