# Neo4j

> 最成熟的图数据库，用于存储和查询知识图谱，支持Cypher查询语言。

## Core Capabilities

- **图存储**：原生图存储，擅长关系查询
- **Cypher查询**：声明式图查询语言
- **可视化**：内置图可视化工具
- **生态丰富**：大量GraphRAG项目集成

## Technical Highlights

- 支持ACID事务
- 社区版免费开源
- 支持多种编程语言SDK
- 14K+ GitHub星标

## Use Cases

- 知识图谱存储
- 关系推理查询
- GraphRAG的图谱后端
