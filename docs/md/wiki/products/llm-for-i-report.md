# LLM for i-Report

专为"i人"设计的低阻力碎片化记录与智能汇报工具。

**Python · 0 Stars**

## 核心定位

通过简单的命令行记录每日的已完成（Done）和待办（Todo），并利用大语言模型（LLM）一键生成高质量的日/周/月报，有效降低职场沟通的心力消耗。

## 核心价值

- **低阻力记录**：简单的命令行操作，碎片化记录每日工作
- **智能汇报**：LLM 一键生成日/周/月报
- **降低心耗**：省去职场沟通的心力消耗

## 适合人群

- i 人（内向型）
- 不擅长汇报的工程师
- 需要定期写工作日志的职场人
