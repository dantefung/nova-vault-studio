# Milvus

> 国产开源向量数据库，专为大规模向量相似度搜索设计，支持百亿级向量规模。

## Core Capabilities

- **高并发**：支持海量数据的高并发检索
- **持久化**：支持数据持久化存储
- **混合检索**：支持向量检索 + 全文检索
- **丰富索引**：支持HNSW、IVF、PQ等多种索引类型

## Technical Highlights

- 云原生架构，支持Kubernetes部署
- 支持分布式集群
- 丰富的客户端SDK（Python、Java、Go等）
- 10K+ GitHub星标

## Use Cases

- 生产环境向量存储
- 大规模知识库检索
- 智能客服的向量引擎
