# Better-Fullstack

> 快速启动项目生成器，270+ 技术栈组合，前端/后端/数据库/Auth/支付/AI/DevOps 一键配置，开箱即用。

## Core Capabilities

- **270+ 技术栈组合**：TypeScript、Rust、Python、Go 四个生态
- **全栈覆盖**：前端、后端、数据库、Auth、支付、AI、DevOps
- **开箱即用**：选完自动生成配置好的项目骨架

## Tech Stack Examples

- 前端：React、Vue、Svelte、Next.js、Nuxt 等
- 后端：Node.js、Rust、Python、Go 等
- 数据库：PostgreSQL、MongoDB、Redis 等
- Auth：OAuth、JWT、Auth0 等
- 支付：Stripe、Paddle 等
- AI：OpenAI、Claude、LangChain 等
- DevOps：Docker、Kubernetes、CI/CD 等

## Use Cases

- 快速启动新项目，不想手动配置环境
- 尝试不同技术栈组合，快速验证想法
- 统一团队技术选型，搭建标准化项目模板
- 接外包项目，快速搭建不同类型应用骨架
