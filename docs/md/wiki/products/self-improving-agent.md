# self-improving-agent

> Agent 自我进化能力代表 — 记录错误、吸收反馈、沉淀长期经验

## Core Concept

Agent 在失败、纠正或发现知识缺口时自动记录，生成 LEARNINGS.md、ERRORS.md 等经验文档，下次任务可先读取，减少重复犯错。

## Core Features

- **自动错误记录**：失败时记录原因和修正方式
- **反馈吸收**：从纠正中学习
- **知识沉淀**：生成 LEARNINGS.md、ERRORS.md 等长期经验文档
- **复用门槛低**：基础能力强，直接启用即可

## Use Cases

- 开发调试中，因依赖版本、脚本路径或 API 参数错误失败时记录原因和修正方式
- 下次开发类似任务时，Agent 先读取经验，减少重复犯错
