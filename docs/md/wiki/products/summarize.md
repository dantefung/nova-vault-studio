# summarize

> 多源内容总结工具 — 支持网页、文件、PDF、图片、音视频、YouTube、播客

## Core Concept

内容工作流底座工具，支持多种输入格式，统一输出摘要和关键观点。

## Supported Inputs

- 网页
- 文件
- PDF
- 图片
- 音视频
- YouTube
- 播客

## Usage

```bash
# 总结网页
summarize "网址"

# 总结 YouTube 视频
summarize "YouTube链接"

# 只抽取内容（不总结）
summarize "网址" --extract
```

## Use Cases

- 市场团队快速消化报告和竞品视频
- Agent 处理 PDF、网页等，输出统一摘要和关键观点
