# cockpit-tools

> 通用 AI IDE 账号管理工具，支持多平台多账号切换、配额监控、自动唤醒与多开实例管理。

## Core Capabilities

- **十二平台支持**：Antigravity IDE、Codex、GitHub Copilot、Windsurf、Kiro、Cursor、Gemini Cli、CodeBuddy、CodeBuddy CN、Qoder、Trae、Zed
- **一键切号**：多账号快速切换，无需手动登录登出
- **多开实例**：同一平台多账号多实例并行运行
- **配额监控**：实时查看各模型剩余配额、重置时间
- **自动唤醒**：定时唤醒 AI 模型，提前触发配额重置周期
- **设备指纹**：生成、管理、绑定设备指纹，降低风控风险
- **多语言支持**：18 种语言

## Platform Support

- macOS
- Windows
- Linux
