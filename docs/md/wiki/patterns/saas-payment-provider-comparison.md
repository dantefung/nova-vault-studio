# SaaS Payment Provider Comparison

Creem vs PayPal 费用对比，以及用户选择倾向分析。

## 用户选择数据

- 80%+ 用户选择 Creem（显示为"借记卡和信用卡"）
- 不到 20% 用户选择 PayPal

## 费用对比

### Creem
- 每笔交易手续费：3.9% + $0.4
- 提现到 Wise：~2.1% 手续费
- **欧盟地区总损失：约 24.9%**（含 19-22% VAT）

### PayPal
- 交易手续费：4.4% + $0.30
- 贝宝跨境人民币结算：1% + $0.35
- 提现手续费：$0（当前免费阶段）
- **欧盟地区总损失：约 5.4%**

## 以 $89.99 订阅为例

| 方式 | 到手金额 |
|------|---------|
| Creem | $67.58 |
| PayPal | $85.1 |

## 关键洞察

1. **用户偏好**：用户更倾向于选择 Creem（信用卡/借记卡），即使费用更高
2. **VAT 影响**：欧盟 VAT 19-22% 是 Creem 最大成本
3. **定价策略**：可考虑让用户承担 VAT，但要避免超过心理价位阈值（$100）
