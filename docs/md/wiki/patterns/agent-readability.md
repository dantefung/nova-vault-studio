# Agent 可读性（Agent Readability）

> 衡量代码库对 AI Agent 的友好程度的 7 项度量指标。

## Key Points

- 7 项度量指标评估代码库对 Agent 的友好程度
- 类型系统、错误消息、命名规范都是可读性的组成部分
- 好的 Agent 可读性让 Agent 更少犯错、更快完成任务

## Details

Agent 可读性关注的是：当 AI Agent 阅读代码库时，能否快速理解代码结构、约束和意图。包括类型定义的精确性、错误消息的指导性、命名的自我说明能力等。
