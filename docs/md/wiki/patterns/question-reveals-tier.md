# Question Reveals Tier

问的每个问题，其实都在暴露你的段位。

## 提问的四个层次

1. **最低级：发泄情绪** — "太难了怎么办？""我好焦虑啊怎么破？"（得不到有效答案）
2. **好一点：描述现象** — "我的转化率很低，怎么提升？"（太模糊）
3. **更高级：结构化提问** — 包含背景信息、具体数据、已有尝试、个人判断

### 结构化提问公式

> 我业务当前的情况 + 遇到的卡点 + 我想过的解决方案：1的优点/缺点 2的优点/缺点

## 提问的四个核心原因

### 1. 体现逻辑能力

- 能不能把问题结构化，反映一个人的系统思维能力
- 招人时特别关注候选人问问题的方式
- 提问是系统思维最好的训练方式

### 2. 建立高质量关系的通行证

- 好问题比一百句客套寒暄更能建立真正的连接
- 真正的社交是深度的价值交换、思维碰撞、相互启发

### 3. 触发深度思考的化学反应

- 精巧的问题能激活对方的"专家模式"
- 释放平时不会主动分享的深层洞察和隐性知识
- 好的问题就像钥匙，能打开对方知识库中那些平时不会主动拿出来的宝贝

### 4. 整理自己思路的方式

- 最重要的提问对象不是他人，而是我们自己
- 高质量的自我提问是自我认知、自我突破、自我进化的核心机制
- 先跟自己AI对话过一轮，再去寻求外部帮助，这个过程本身就已经解决了大部分问题

## 自我提问清单

当业务遇到瓶颈时，问自己：
- 这个问题的本质是什么？是流量问题、转化问题还是产品问题？
- 我们的核心优势是什么？应该在哪里集中火力？
- 如果资源完全不受限制，我们会怎么做？现在的限制因素是什么？有没有办法绕过？
- 如果从用户的角度看，我们的产品解决了什么问题？还有哪些问题没有解决好？

## 金句

> 问对问题，比找到答案更重要。因为一个好问题本身，就已经包含了答案的方向。
