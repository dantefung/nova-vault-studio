# Codex 中文内容创作者 10 个顶级 Skills

## 内容生产线

选题 → 调研 → 写作 → 去 AI 味 → 封面 → 卡片 → 信息图 → HTML 发布

## 十个 Skills 推荐（按工作流排序）

### 1. stop-slop — 先去 AI 味，再谈写作
**GitHub**: hardikpandya/stop-slop

最缺的不是"写得更快"，而是"看起来不像 AI 写的"。AI 味一出来，读者立刻防御，信任直接掉。stop-slop 帮你删掉空洞转折、模板句、过度总结、假装深刻的废话。

### 2. dbskill — 选题诊断，值不值得写
**GitHub**: dontbesilent2025/dbskill

选题诊断、爆款拆解、Hook 优化。不是催你快写，而是先问：这个内容凭什么让人停下来？内容最大的问题不是写得不够好，而是选题本身没有传播张力。

### 3. content-research-writer — 调研和写作连起来
**GitHub**: ComposioHQ/awesome-claude-skills/content-research-writer

把内容研究和写作流程连接，适合长文、行业分析、产品解读、趋势文章。写作不是从空白页开始，而是从素材密度开始。

### 4. NotebookLM Skill — 知识库写作，减少幻觉
**GitHub**: PleasePrompto/notebooklm-skill

基于课程、访谈、会议纪要、书籍摘录、资料库来写内容，减少幻觉。适合深度文章、知识类内容，越专业化越不能只靠模型记忆写作。

### 5. khazix-skills — AI 热点追踪和研究台
**GitHub**: KKKKhazix/khazix-skills

适合深度研究、长文、AI 热点相关内容。AI 内容最怕：信息更新快、读者要求高。搭一个热点研究工作台，先整理信息再往观点输出走。

### 6. Punk-Skill — 中文封面图
**GitHub**: adrianpunk/Punk-Skill

封面不是装饰，是第一眼的点击理由。能围绕标题、情绪、平台比例、视觉风格做封面，适合 X 长文封面、公众号首图、知识类内容视觉包装。

### 7. guizang-social-card-skill — 小红书和公众号卡片
**GitHub**: op7418/guizang-social-card-skill

社交卡片、公众号封面、小红书图文拆分。同一篇内容，发 X 可以是长文，发小红书可能要拆成 6 张卡片。平台不是容器，平台会改变内容形态。

### 8. baoyu-skills — 信息图、结构图、视觉工具箱
**GitHub**: JimLiu/baoyu-skills

把框架、流程、对比、清单、方法论变成图，让内容从"可读"变成"可保存"。

### 9. ian-xiaohei-illustrations — 正文配图有人味
**GitHub**: helloianneo/ian-xiaohei-illustrations

小黑风格，有手绘感，有人味，适合知识长文、观点文章、个人经验分享的情绪缓冲和记忆点。

### 10. html-anything — Markdown 变可发布作品
**GitHub**: nexu-io/html-anything

把 Markdown 转成精美海报、卡片、网页、HTML。写完不等于完成，能被舒服地阅读才算完成。

## 推荐安装顺序（按内容生产线）

1. **选题和 Hook**：dbskill
2. **调研和写作**：content-research-writer / NotebookLM Skill
3. **去 AI 味**：stop-slop
4. **封面和卡片**：Punk-Skill / guizang-social-card-skill
5. **信息图和 HTML**：baoyu-skills / html-anything

## 三个核心判断

Skill 不是越多越好。真正适合中文内容创作者的 Codex Skill，不是让你"看起来更自动化"，而是让你少做重复劳动，多做判断、表达和选择。

AI 负责加速，创作者负责品味。Skill 负责流程，内容负责信任。

**如果只能先装 3 个**：stop-slop、dbskill、Punk-Skill——一个管信任，一个管选题，一个管第一眼。
