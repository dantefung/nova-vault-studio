# Four-Layer Filter

市场奖励通过四层筛选的人：看见 → 相信 → 动手 → 坚持。

## 核心洞察

### 想象困难比真正去做更累

大脑擅长放大未知威胁：
躺在床上想创业，脑子里冒出一万个问题：启动资金、时间、失败、家人不支持……

等想了三天三夜，人已经累得不行了，还没开始做事就先把自己吓退了。

> 想象中的困难90%都是虚假的。想象困难所消耗的心理能量，往往远超实际开始所需的真实成本。

### 信息不对称制造的幻觉门槛

局外人看到的是结果的光鲜，看不到过程的朴素：
- 看到别人月入五位数 → 觉得肯定投入了很多钱
- 看到别人做得好 → 觉得肯定有特殊资源

> 互联网创业，真没那么高的门槛。一个手机，开几个号，线上摊位就支起来了。

### 四层筛选

1. **看见** — 机会摆在眼前，但大部分人根本看不见，或者看见了也当看不见
2. **相信** — 看见了，但不相信自己能做到，不相信这事能成
3. **动手** — 相信了，但就是不动手，永远停留在想的阶段
4. **坚持** — 开始做了，但遇到一点困难就放弃，半途而废

> 能通过这四层筛选的人，真的不多。但只要通过了，就能挣到那些被筛掉的人的钱。
