# Local Data Backbone

把长期数据收回一个本地 Obsidian vault，作为 AI 的数据底座。

## 核心思想

Obsidian 在这套系统里的角色，不是漂亮的笔记软件，而是 AI 的本地数据底座。

.md 文件躺在本地磁盘上，agent 可以直接 grep、直接读、直接改；图片、PDF、HTML 归档也都在同一个文件系统里。

AI 终于不是隔着 SaaS API 看一个被裁剪过的世界，而是站在我的真实资料库上工作。

## 数据分类

四类全部塞进 Obsidian：
- **知识沉淀**：工作 / 学习笔记、Wiki 实体
- **流水记录**：每日计划 + 反馈、灵感、即刻归档、日记等
- **创作产出**：文章草稿、视频脚本
- **生活资料**：读过的书 / 电影 / 去过的地方、签证 / 保险 / 账单等

## 关键原则

数据所有权和数据形态比工具本身更重要。.md 文件在本地磁盘，agent 可以直接文件系统访问。
