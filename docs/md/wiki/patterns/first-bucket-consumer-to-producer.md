# First Bucket: Consumer to Producer

任何一个人的第一桶金，大概率是从消费者到生产者的一个转变。

## 核心公式

**消费行为 → 发现机会 → 尝试做 → 第一桶金**

- 高中家教：找老师买课 → 发现能做 → 第一个几万块
- AI写作：找人代写 → 发现能做 → 做了三年
- 水晶项目：给舍友买水晶 → 发现能做 → 开启业务

## 核心方法

### 盘点自己的消费行为

你愿意为什么东西付费？去看这个事情你能不能做，你不能做的核心原因是什么？这个原因能不能靠外力解决？

### 解决卡点的方法

- 不择手段拓宽人脉圈、资源圈、信息圈
- 找已经有资源的人，置换出自己的资源
- 找同行假装客户聊出来，总结自己的框架

### 滚雪球效应

慢慢解决问题的能力越来越强，形成自己的壁垒和优势。

## 套利模式

每个人能力边界有限，在任何一端形成优势后：

- 擅长搞流量 → 后端外包，专注前端谈单转化
- 有强势后端（交付满意度高）→ 找前端谈合作分成

> 一定不是卖一单挣一单，不断消耗时间换金钱。而是搭建团队、搭建模式，实现套利，钱源源不断向你滚过来。
