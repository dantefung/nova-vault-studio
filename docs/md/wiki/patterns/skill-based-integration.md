# Skill-Based Integration

用 Skill 把外部工具接进来，扩展 AI 的行动能力。

## 核心思想

没有 Skill，AI 最多是个会翻笔记的问答机器人。有了 Skill，AI 才能替我做事。

## 示例：接富途实盘

- 数据层：「我的判断 / 我的笔记」全部回到 Obsidian
- 例外：结构化非常强且自带专业体验的东西（如富途实盘账户）不强行迁移，但「我的判断 / 我的笔记」那一层全部回来

## 行动能力层次

AI 不仅要能读笔记，还要能：
- 调用外部 API
- 执行交易操作（模拟）
- 访问专业数据
