# Geju Skill Pattern

专治 Codex "苟帝"综合征：过度兼容、局部细节陷阱、重构恐惧、温和答案偏差。

## 核心问题

Codex 经常因为害怕破坏东西，保留旧行为、旧命名、旧路径、别名、shim 和双轨流程；经常在看清整个系统前就钻进一个字段、一个函数；经常给出礼貌、平衡、低风险但不解决问题的答案。

## 核心原则

> 大胆假设，小心求证。

不要让重构困难、兼容性恐惧、既有实现形状或局部细节过早决定方向。这些都是需要定价的约束，不是必须服从的主人。

## 触发词

- 「格局打开」
- think bigger
- 挑战保守方案
- 避免过度兼容
- 跳出局部细节

## 八种打法

geju 内置 8 种打开格局打法，让 Codex 秒变暴论输出机。
