# AI API Integration（AI API集成模式）

> 普通人做 AI 出海，最重要的能力是知道去哪里找现成的 API 能力，并把这个能力变成产品。

## Key Points

- **核心公式**：普通人做 AI 产品 3 步骤 = 了解AI能力边界 → 找对应API → 把API文档交给AI编程工具
- **API 即加速器**：每一个 API 都是普通人的一个加速器，组合 API 就能做出出海产品
- **语言类首选 Openrouter**：Gemini 2.5 Flash Lite 性价比最高
- **图片类首选 kie.ai**：价格友好，模型更新快

## 9 个常用 API 平台

### 语言类模型

| 平台 | 特点 |
|------|------|
| openrouter.ai | 语言类模型综合平台，性价比高 |
| evolink.ai | 小排老师自研模型 Z-Image 首发平台 |
| deepseek.com | Deepseek 语言模型 API |

### 图片视频模型

| 平台 | 特点 |
|------|------|
| kie.ai | 图片/音频/视频模型，4o-Image、Nanobanana、Image2、Seedance2，价格友好 |
| evolink.ai | 同时提供语言+图片+音频+视频 API |
| replicate.com | 大而全，缺点是贵，可用于找产品灵感 |
| fal.ai | 图片和视频 API，有 50 美金新客积分 |

### 其它模型

| 平台 | 特点 |
|------|------|
| photoroom.com | 图片去背景效果极佳，电商抠图神器（0.02美金/张） |
| mapbox.com | 地图 API，可缩放地球，类似谷歌地图 |

## 关键洞察

1. **API 即加速器**：每一个 API 都是普通人的一个加速器，组合某几个 API 就能轻松做出各种出海产品

2. **与 AI 对话找 API**：日常开发中，最好的办法是和 AI 对话，你想实现的功能 AI 往往能给你建议并提供对应 API

3. **逛 API 平台找灵感**：Replicate 大而全，没事逛逛可以找到产品灵感

4. **语言类首选 Openrouter**：性价比高，Gemini 2.5 Flash Lite 用得最多

5. **图片类首选 kie.ai**：价格友好，模型更新快（4o-Image、Image2、Seedance2）
