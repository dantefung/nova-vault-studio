# Three Entry Points

三个入口覆盖不同场景，分工如下：

| 设备 | 最适合什么 |
|------|-----------|
| 手机 | 秒级问答，微信里问一句 agent 回一句，红绿灯之间能完成的交互 |
| iPad | 长时段沉浸式消费，通勤路上读 30 分钟笔记、沙发上标注一篇长文 |
| 电脑 | 完整桌面级操作 |

## iPad 的独立角色

iPad 在这套拓扑里有完全独立的角色——不是"手机的大号"。

## 网易 UU 远程（桌面级兜底）

保留一个兜底方案：网易 UU 远程。不是日常工作流里的"主入口"，更像是完整桌面远控。

优点：手机、iPad、Mac 客户端都有，免内网穿透，免端口转发。
代价：有点延迟、画质有损，但对"只想跑个 agent"这种活完全够用。
