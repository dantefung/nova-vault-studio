# AI 自动内链 SEO

> 内链不是「加得越多越好」，而是一个**有对照样本的归因问题**。把每天排前三的竞品当成对照组，让 AI 学它们的动作；自己的排名异动先排除大盘更新，再查谁做对了、谁做错了。

## 原始方案的形状

国外开发者 andrei saioc 的做法（Claude + GSC 导出 + 网站 MCP）：

1. 下载 GSC 导出，或用 GSC MCP 拉取最近 3 个月数据
2. 把数据放进 Claude
3. 给网站接上 MCP（WordPress 有自定义 MCP 插件，各家博客框架都有对应 connector）
4. 让 Claude 按「排最好的 query」自动做内链
5. 改完让网站静置几天
6. 每周重复一次
7. 别忘了同时做外链与新内容

原方法里的内链规则非常具体：

- 每篇文找出它排名最好的 query（位置 1–10、有不错曝光）作为目标锚点
- 遍历所有已发布文章，凡是正文里**自然提到**另一篇的目标 query（或近义变体），就把那个短语变成指向该文的链接
- 每篇最多新增 3–5 条内链，分布在正文里（不放在标题、开头句、已有链接旁）
- 不自链；同一个目标每篇只链一次
- 锚文本必须读起来自然，**不许为了塞关键词而改写句子**
- 优先把链接给排名在 4–15 位的页面（它们获益最大）
- **改动前先出表格**（来源文 → 锚文本 → 目标 URL → 目标 query 与排名），等确认
- 改动后给出 changelog，方便回滚

## 改造后的版本：五个升级点

| 改造 | 原方案 | 改造后 |
|---|---|---|
| **对照组** | 只看自己的数据 | 每天拿排名前三的页面当样本学——记录它们改了内容、结构、内链、更新日期、外链里的哪些 |
| **阈值** | 靠猜 | 正常波动与异常的界线，**全部从每个词自己的历史数据里算出来** |
| **归因** | 给一个理由 | 只认证据，对不上就写「原因不明」，不编理由 |
| **权限** | 缺权限就卡住 | 用户点一下同意，AI 自己接上继续干 |
| **判断层** | 无 | 底层是 iLang 判断层：AI 自己判断什么时候做、什么时候问、什么时候停 |

## 完整运行节奏

```text
每天
  ├─ 盯每个关键词的前三名，记录它们改了什么
  ├─ 排名一变 → 先排除 Google 大盘更新
  │            → 再查是哪家做对了、哪家做错了
  ├─ 谁是第一就盯谁；第一一换 → 研究新第一过去 28 天做对了什么
  └─ 自动给自己的网站加内链（见下方「先清单后自动」）

平时不打扰，只有异常才推送；每周固定一份周报
```

### 关键设计一：异常检测不猜阈值

「什么算异常」不是一个全局常数，而是**每个关键词从自己的历史数据里算出来的**。这解决了 SEO 工具最常见的误报问题：用一个统一阈值去套所有词，热门词和长尾词会疯狂互相干扰。

### 关键设计二：归因只认证据

Google 排名变化的原因是不可完全观测的。因此规则的底线是：**证据对不上就写「原因不明」，不编理由**。一个诚实的「原因不明」比一个编造的归因有用得多——后者会误导后续所有优化动作。

### 关键设计三：先清单，后自动

内链改动分两段，权限逐段放开：

| 阶段 | 行为 |
|---|---|
| **第一次** | 只出改动清单，等你点头（对应原方案的「先出表格，等 OK」） |
| **之后** | 自动改 → 自动验收 → 出错自动回滚 |

「自动验收 + 出错自动回滚」是自动化改站点的前提：没有回滚能力，就不能开自动化。

### 关键设计四：先排除大盘更新

排名一变，第一件事不是归因到自己的内容，而是**排除 Google 大盘更新**（算法波动）。把大盘噪声和自己的动作混在一起，是归因失败最常见的原因。

## 与站内基建的关系

子木的《SaaS SEO Playbook》第三部分给出的是**基建视角**：

> AI Coding 时代「1 是 1，2 是 2」这类确定性问题很好解决。真正的难度是**你不知道还有你自己不知道的东西**——直接让 AI 改 SEO 基建，它不可能面面俱到；让它实现多语言，它给你复制几份代码就完事。

两篇合起来是一条完整的分工：

| 层次 | 谁做 | 产出 |
|---|---|---|
| **基建**（收录、页面结构、多语言、可访问性） | Agent + 开源 seo audit Skill | 「面面俱到」很难，靠规则化 Skill 兜底 |
| **内链与归因** | Agent + 竞品对照样本 | 靠数据驱动，靠归因纪律保证不编 |

## 边界与风险

- **内链只对排名 4–15 的页面最有效**。给已经排第一的页面加链接，收益接近零。
- **锚文本不能为了塞关键词而改写句子**。这条一旦松动，整站会退化成关键词农场。
- **权限分级不可跳过**。第一次必须人工点头，之后才能自动化。
- **自动化改动必须可回滚**，否则一次错误批量改动可能同时打伤几十个页面。
- **归因不是因果**。即便证据对得上，也可能存在你没观测到的第三方因素，所以规则要求对不上就承认「原因不明」。
- **外链与新内容不能丢**。内链只是三个渠道之一。
