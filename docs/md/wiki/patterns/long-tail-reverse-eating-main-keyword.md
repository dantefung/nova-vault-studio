# Long-tail Reverse Eating Main Keyword

做老词不一定要一上来就硬刚主词。先从竞争小的长尾表达切进去，先拿长尾排名，再反向吃主词。

## 核心思想

同一个需求，不同的用户会有不同的表达。有些表达搜索量大，有些表达搜索量小。

大厂做网页，会挑搜索量最大的表达来写页面内容文案。剩下的小表达，他们大概率不会专门上一个页面来覆盖。

这就是个人站长的机会。

## 操作步骤

1. 用长尾表达注册域名（如 `B C A`）
2. 网站首页的 Title、Description、H1，瞄准长尾表达
3. 不断上内页，不断搞外链
4. 慢慢拿到该长尾表达的排名
5. 继续搞外链，权重提升
6. 最终拿到主词的靠前排名

## 核心公式

先拿小词，后吃大词。先拿曝光，后拿点击。先验证需求，再加大投入。
