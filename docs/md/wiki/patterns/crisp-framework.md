# CRISP 框架

> 批判性思维提示词框架，引导 LLM 进行深度分析和批判性思考。

## Key Points

- 融入批判性思维的 Prompt 框架
- 引导模型从多角度分析问题
- 适合需要深度分析和评估的场景
- 与 CO-STAR 互补，一个重结构，一个重思维

## Details

CRISP 框架通过特定的提示结构，引导 LLM 不仅给出答案，还要分析答案的可靠性、考虑替代方案、评估潜在风险。
