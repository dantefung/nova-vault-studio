# Execution Speed and Trust Verification

做事的速度 + 信任一旦破裂立即切割。

## 核心观点

### 执行速度

在纠结干不干这件事上不会浪费太多时间，一旦确定做，就赶紧推进，没必要前摇太久。

从有这个想法到落地，用了一个多月：找场地大概一个月，施工差不多半个月。

### 世界奖励积极主动的人

第一桶金不是靠运气中彩票，更像是这个世界总是在奖励努力做事的人的反馈。

### 信任破裂立即切割

面试时说3.0水平，实际几乎是初学者——一旦掺了水分，默认后面所有表达都有水分。

不要心存幻想，当天就把合作关系收掉。犯错后改正的最小成本就是当下。

### 关键洞察

> 有些事你只要往前推，它就会给你结果；但有些关系一旦出现裂缝，它会拖着你，把你往后拽。

三件关键事：
1. 场地：从想法到落地，坚定不移往前推
2. 业务：第一天就赚钱
3. 人：合作初期有不好体验，立即切割，不心存幻想
