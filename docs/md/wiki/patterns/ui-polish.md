# UI Polish（UI精致打磨）

> A skill file based on articles on emilkowalski.ski. 专门补 UI 细节，让交互、动效、按钮、组件状态更精致。

## Key Points

- **核心理念**：不追求让页面"变花"，而是让交互、动效、按钮、组件状态这些地方**从能看到舒服**
- **定位**：适合把页面从**能看**打磨到**舒服**的阶段，不是设计方向指引，而是微观层面的精致化
- **基于**：Emil Kowalski 个人网站文章，面向设计师和工程师

## 应用场景

- 交互细节优化
- 动效打磨
- 按钮状态处理
- 组件状态管理
