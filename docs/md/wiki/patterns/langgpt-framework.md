# LangGPT 框架

> 变量 + 模板语法，像编程一样写 Prompt 的结构化提示词框架。

## Key Points

- 使用变量和模板语法构建提示词
- 降低 Prompt 编写的门槛，让非技术人员也能写出高质量 Prompt
- 支持模块化和复用
- 与 RAG、微调形成 LLM 应用的三层优化

## Details

LangGPT 将提示词编写从"自然语言写作"转变为"结构化编程"，通过定义变量、模板、角色等组件，让提示词更可控、更可复用。
