# Income Structure and Four Certainties

收入结构要健康；用四个确定性判断项目值不值得做。

## 核心框架

### 收入结构

- **副业是第二曲线**：一个人的收入结构如果只有工资，抗风险能力非常弱
- 假设月薪8000，工作30年，不吃不喝到手300万，"这辈子就这么多了，能干什么呢？什么都干不了"
- **副业收入是主业的五倍** → 考虑离职

### 项目选择三个东西

**流量、产品、运营** — 每天问自己，这件事在三个方向能不能给你提供锻炼

### 四个确定性（判断值不值得做）

1. **技能** — 每年有没有提高？
2. **赚钱** — 每年有没有多赚更多的钱？
3. **人脉** — 客户、私域、协作团队、供应商、社群朋友有没有变多？
4. **影响力** — 在全网、在行业里的影响力有没有增加？

> 只要判断一件事情值不值得做，就看这四个东西。

### 离职时机

> 副业收入是主业的五倍，且连续三个月保持增长，且收入增长的瓶颈是由于时间导致的 — 这时候再考虑离职。

## AI使用

> 不是遇事不决问AI，而是万事问AI。把AI当实习生用。

- 不要问AI能为你提供什么价值，要问你能为AI提供什么价值
- 你提供的不断测试，是在帮AI收集样本
- 用久了你就知道它真的太好用了，绝对比你聪明

## 贵人运

**工具人 + 结构洞**

1. **同层穿透**：每个大佬想做私域/AI/电商/直播，会在周边问有没有小伙子会搞 → 把事情办漂亮了，就穿透圈层了
2. **结构洞**：记住圈子中每个领域最强的三个人，不断迭代，两三年后你会发现人生彻底变化，活在一张信任之网中

> 但行好事，莫问前程，要去利他。

## 流量结构

- 搜索流量 = 30个推荐流量
- 全网布局，而不是只盯着一个平台
- AI代写是派单逻辑：快递/滴滴/骑手都是派单

## 知识付费防坑：望闻问切

1. **望** — 翻朋友圈两三百条，看有没有料
2. **闻** — 闻味道，看讲的东西对不对你的胃口
3. **问** — 当场问，看他耐不耐心
4. **切** — 具体问题给到他，聊透再决定付费

> 说知识付费是智商税的人主要是穷。钱是用来换加速度的。
