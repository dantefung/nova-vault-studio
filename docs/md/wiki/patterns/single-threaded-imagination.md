# Single-Threaded Imagination

单线程想象的未来，经不起推敲。

## 核心观点

### 单线程思维

- 想住别墅 → 大房子=舒服，没考虑维护成本、管理成本
- 35岁退休 → 退休=享福，没想清楚退休后靠什么获得乐趣
- "等你考上大学就好了，等你毕业就好了，等你结婚就好了，等你买房就好了" — 都是单线程的想象

### 叔本华钟摆

> 人生就像钟摆，在痛苦与无聊之间摇摆。
> 如果一个人是靠奋斗获得乐趣的，那停止奋斗，也等于失去了乐趣。

### 关键洞察

1. **别墅思维**：雇保姆不仅有开销，还有隐形的管理成本
2. **退休思维**：退休不只是离开工作岗位，太魔幻太模糊，经不起推敲
3. **多线程才是真实**：换个更全景的视角，就有完全不同的答案

### 新加坡出租车司机案例

- 70岁还在开出租车
- 赚钱是为了攒钱去旅游
- 就算重新选择一百次，还是会选择继续工作

### 结论

> 无论是当初想住别墅，还是立下35岁退休的flag，都是一种单线程的想象，真正的生活远比想象复杂，也比想象有趣。
