# CO-STAR 框架

> 结构化提示词构建方法：Context + Objective + Style + Tone + Audience + Response。

## Key Points

- 六维结构化提示词框架
- 确保 Prompt 覆盖所有关键要素
- 适合需要精确控制输出风格和受众的场景
- 是结构化 Prompt 的经典框架之一

## Details

CO-STAR 框架要求 Prompt 包含：上下文(Context)、目标(Objective)、风格(Style)、语气(Tone)、受众(Audience)、响应格式(Response)六个维度。
