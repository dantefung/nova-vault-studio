# AI Productivity Tool Not The Goal

核心不是"网站"而是"利用 AI"——AI是最先进生产力工具，每月10-20美金的高级打工仔。

## 核心框架

### AI 替换工作流

把你原来需要人力完成的工作流，尝试用 AI 替换：
- 替换一个环节 → 提效
- 替换多个环节 → 大幅提效
- 替换全部 → 全自动化

> 行业演变：人工服务 → 半自动化服务 → 全自动化服务

### 更快验证

- 门槛低、成本低，可以直接上手"实现"想法
- 快速得到"结果"，快速验证产品是否受欢迎
- 不行就换想法，也不过举手之劳

> 更高的生产力意味着更快的失败，更快的失败意味着更多的尝试，更多的尝试意味着更多的机会发现自己的优势。

## 适合普通人的路径

### 路径一：智能体验证（零代码）

1. 腾讯元宝、字节豆包创建智能体
2. 验证是否有用户使用 = 验证需求是否真实
3. 有编码能力 → 接 API → 做网站/应用

### 路径二：抄已验证的需求

> 翻扣子上有哪些智能体特别火、付费用户多 → 直接做成独立产品

对方已经帮你验证过需求和付费意愿，你只需要换个渠道做信息差。

### 路径三：内容 + 应用双向转化

- 内容 → 应用：把社交媒体上热门内容做成傻瓜工具
- 应用 → 内容：发现工具受欢迎，扩展成内容站

## 线下 + AI 场景

- 蛋糕店：儿童蛋糕送 AI 做的视频（奥特曼握手、小马宝莉拥抱）
- 婚庆：把新人从小到大照片做成视频，超时空相遇
- 音乐平台：AI 歌曲发布，版权收益 or 品牌宣传歌

## 好 Prompt vs 坏 Prompt

- 坏 Prompt："写篇文章"
- 好 Prompt："以俞军产品方法论为主题，用商业顾问视角，写3000字深度长文，逻辑清晰案例丰富，附可操作框架图，目标读者是中高级产品经理和创业者"

## 俞军产品公式

> 产品价值 =（新体验 - 旧体验）- 迁移成本

不管做产品还是搞流量：
- 写文章：传统2小时，AI 5分钟
- 内容个性化：传统难，AI 轻松
- 多语言创作：传统成本高，AI 几乎免费
