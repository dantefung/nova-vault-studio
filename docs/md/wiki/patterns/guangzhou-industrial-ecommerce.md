# Guangzhou Industrial Ecommerce（广州工业品电商）

> 广州工业品店群实战：从"出租屋琢磨一周没咨询"到"一个人管二十个店"。核心逻辑：广州周边工厂多得是，就看你会不会用。

## Key Points

- **广州的优势三角**：货源（番禺农机/花都工程材料/白云小型机械）→ 物流（环城高速+广清高速，重货到全国成本可控）→ 圈层（白云/番禺电商园同行，互相分享哪个工厂配合好）
- **核心方法论**："广州周边工厂多得是，就看你会不会用"——不是选赛道，是**选地理**——广州本身就是供应链超级节点

## 商业模式：店群 + 采集 + 代发

**操作流**：
1. **采集**：用软件一键复制工厂链接和图片
2. **优化**：主图加"工厂直发"/"厂家直供"水印，标题用工厂原版
3. **上架**：淘宝店群（20 个店）
4. **发货**：代发模式，工厂直发，不用囤货

**关键公式**：好货不愁询盘。

## 供应链路由

| 地点 | 品类 | 策略 |
|------|------|------|
| 番禺 | 农机市场（微耕机/配件） | 主图加"果园专用"，打云南客户 |
| 花都 | 工程材料厂（围挡/护栏） | 主图加"厂家直供"，打工地 |
| 白云 | 小型机械 | 当天看货，当天对接石井物流园代发 |

## 一个人管 20 个店的杠杆

店群 + 采集软件 + 代发 = 极低边际成本的放大结构。核心杠杆不是资金，是**信息路由**：知道哪个工厂配合好、哪个品类售后少、哪个品类的物流成本最优。

**工厂真实场景 = 最强信任背书**。焊接火花四溅的过程拍下来，比精修图更有转化力。
