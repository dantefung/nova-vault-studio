# 跨平台信息差中介

> 最省力的变现往往不是造东西，而是**做一个中间人**：把 A 平台已有的东西（软件、模板、资讯、教程）重新包装，送到 B 平台缺需求的人群手里。**不搬运本体，只卖信息、配置与教程。**

## 五个样本

| # | 源 | 做法 | 变现形态 |
|---|---|---|---|
| 1 | Product Hunt 每天新上的 Chrome 插件 | 插件本体免费且不倒卖，只写「国内能不能直连、要不要挂卡、怎么装」的教程 | 小红书引流进私域，卖配置年更合集，199 元/年 |
| 2 | 小红书 | 针对女性痛点做减肥食谱，文案与配图参考同类博主，视频用 AI 生成 | 9.9 元一份，一个月卖 8000 份 |
| 3 | 海外 Notion 高赞模板 | 换中文字段与皮肤，同一套结构换包装 | Gumroad 标 \$5–8，闲鱼 / 小红书卖 29.9–49 |
| 4 | GitHub 热门开源项目 | 改界面、加收费接口，或直接卖安装包 | 起号快、客户精准 |
| 5 | 英文 Newsletter | 订阅后让 AI 只提炼目录与结论，做成一张图加三句话 | 放进付费群，群费 99，按月收；视频号获客 |

## 共性公式

```text
信息差 = 源平台的免费供给 × 目标平台的付费意愿 × 中间人的再加工
```

五个样本剥掉外壳后，共性是同一句话：**不搬运软件本体，只卖信息与配置**。

这一步是模式成立的边界——一旦开始搬运本体（软件、模板、内容本身），性质就从「服务中介」变成「侵权分发」，平台下架与封号的成本会立刻盖过差价收益。

### 为什么选这五类源

| 特征 | 为什么能成立 |
|---|---|
| **本体免费或低价** | 不付授权成本，只需再加工 |
| **国内有明确准入摩擦** | 直连、支付、挂卡、安装门槛本身就是付费需求 |
| **已有海外市场验证** | 不用自己做需求验证，GitHub star、Gumroad 销量就是验证 |
| **需求天然可搜索** | 用户会主动搜「能不能用」「怎么装」「中文版」 |
| **可复用到多平台** | 同一份研究在多个平台复用，边际成本趋零 |

### 为什么中介在这个时点成立

- **AI 降低了再加工成本**：翻译、中文化、配图、视频、摘要都能批量做。
- **平台之间的信息不对称比能力不对称更大**：大多数人不是造不出工具，是不知道能不能用、怎么用。
- **获客已经社交平台化**：小红书、抖音、视频号都能承接「教程型」需求，不需要等自然搜索。

## 与「内容搬运套利」的区别

[[patterns/content-arbitrage-pattern]] 讲的是**内容**层面的套利：把海外一手内容本地化重构，全平台矩阵分发，一鱼五吃。

本模式讲的是**工具与服务**层面的套利：

| 维度 | 内容搬运套利 | 跨平台信息差中介 |
|---|---|---|
| **搬运对象** | 文章、视频、观点等**内容** | 软件、模板、配置、教程等**工具与服务** |
| **收入来源** | 平台分成、广告、私域 | 教程付费包、配置年更、模板溢价、群费 |
| **复利资产** | 内容矩阵与账号权重 | 教程/配置本身 + 私域 |
| **核心风险** | 内容同质化与限流 | 侵权边界与平台下架 |
| **是否搬运本体** | 内容本身就是商品 | **不搬本体**，只卖信息与配置 |

两者可以叠加：先用内容获客，再卖配置。

## 边界与风险

| 风险 | 说明 | 对策 |
|---|---|---|
| **侵权边界** | 搬运本体、把开源项目「伪装成自己的项目」存在授权与商标风险 | 只卖信息与配置；引用开源项目要保留原项目出处与许可证 |
| **平台规则** | 抖音、小红书对「伪装成自己的项目」类内容有治理规则 | 走「中文教程 / 配置服务」定位而非「原创产品」定位 |
| **可复制的低壁垒** | 教程类内容极易被抄 | 护城河在私域与持续更新，不在单篇教程 |
| **上游变动** | 源平台改版、插件停止维护即失效 | 配置年更本身就是应对上游变动的商业模式 |
| **合规边界** | 绕过支付/直连限制可能触碰平台条款 | 明确只做「信息与配置」，不做绕过风控的工具 |
