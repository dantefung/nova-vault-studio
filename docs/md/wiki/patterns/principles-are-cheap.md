# Principles Are Cheap

道理在哪都是最廉价的。

## 核心观点

### 赢了道理，输了感情

- 10年前做校园大使，执着完成100个app下载任务，和不少人交恶
- 这是自己第一批积累的人脉朋友，结果早早就断了联系
- 我赢了道理，输了感情

### 抓大放小

- 报销费用超出平均水平，别纠结，掰扯赢了输了感情
- 综合成本没超预算即可
- "这种事典型的属于抓大放小里的小，如果自己把精力都放在这上面，公司早没了"

### 合作中沟通舒服 > 事顺利

- 事顺利 + 沟通舒服 = 理想合作
- 事不顺利 + 沟通舒服 = 可能继续合作
- 沟通不舒服，无论事顺不顺利，下次都会觉得难受

### 小项目让利，大项目争利

- 小项目上不太重视，因为还没触及核心利益
- 通过小项目让利去积累合作中的话语权
- 在重要的项目上去争取自己的利益

### 核心结论

> 道理重要，还是赚钱重要？
> 道理重要，还是感情重要？
> 道理重要，还是合作能长久重要？
> 道理重要，还是彼此都能睡得着觉重要？
>
> 这么一比较，道理在哪都是最廉价的。

## 洞察

- 水至清则无鱼
- 合作中带有信息差的生意，几乎不可能真正占到便宜
- 被误会了也没那么严重，清楚谁占主导权即可
