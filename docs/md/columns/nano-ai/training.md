## 全部章节（交互式图解的完整文字版）



### 第一部分 · 损失



#### 损失：模型错得有多离谱



```
L = −(1/3) Σ<sub>i</sub> log p[i, y<sub>i</sub>]
```


> 形状：p (3×6) → 每行一个数 (3×1) → 一个标量



训练数据就是这句话本身：输入「猫 吃 鱼」，每个位置的**答案是它后面那个词** ：猫 → 吃，吃 → 鱼，鱼 → 。。把答案写成 one-hot，就是下面的 Y。



上一系列算到最后，得到了每个位置在 6 个词上的概率 p。交叉熵损失只看一件事：**正确答案那一格的概率有多大** 。取它的 −log，三个位置求平均，就是 loss。



现在 loss = 1.98，比 6 个词随便猜的 ln 6 = 1.792 还高：没训练过的模型比瞎猜还差。训练要做的，就是把三个红框里的概率往 1 推。



#### 第一个梯度：p − y



```
dlogits = (p − Y) ÷ 3
```


> 形状：3×6 − 3×6 → 3×6



反向传播从 loss 出发，往回问每一个中间结果：「你变一点，loss 变多少？」这个量就是梯度，记作 d加矩阵名，形状和原矩阵一模一样。



softmax 和交叉熵连在一起求导，结果出奇地简单：**梯度 = 预测概率 − 答案** ，再除以 3（因为 loss 是三个位置的平均）。答案那一格 p − 1 < 0，其他格 p − 0 > 0。



梯度下降是沿着**梯度的反方向** 走：负梯度的格子分数会被抬高，正梯度的格子会被压低。模型越自信地押错，那一格的梯度越大。



#### 输出层：矩阵乘法怎么反向



```
logits = H<sub>2</sub>E<sup>T</sup>　⇒　dH<sub>2</sub> = dlogits · E，dE = dlogits<sup>T</sup> · H<sub>2</sub>
```


> 形状：(3×6)·(6×4) → 3×4；(6×3)·(3×4) → 6×4



前向的最后一步是 logits = H2ET。这一步有两个输入，梯度就要分给两边：一份传给 H2，继续往回走；一份落在 E 上，留着更新参数。



**矩阵乘法的反向规则** （后面会反复用）：前向 Y = A · B，那么

dA = dY · BT dB = AT · dY

记法：梯度的形状必须和原矩阵一样，转置放在哪边，凑形状就能凑出来。



这里 B = ET，所以 dH2 = dlogits · E。E 这一侧算出来的是 d(ET) = H2T · dlogits，转置回来就是 dE = dlogitsT · H2。



E 同时也是第 1 步的嵌入矩阵（权重共享），所以它还会在第 14 步收到另一份梯度，两份加起来才是 E 的总梯度。



#### LayerNorm 反向：一行里的格子互相牵连



```
dx = (dy − mean(dy) − x̂ · mean(dy ⊙ x̂)) ÷ σ
```


> 形状：3×4 → 3×4，逐行



前向时 H2 = LayerNorm(R2)：每一行减去均值、除以标准差。一行里任何一格变了，均值和标准差都会变，同一行的其他格子也跟着变。所以反向时，**每一格的梯度要看整行** 。



公式里减掉的两项正好对应这两件事：减 mean(dy)，是因为把整行同时加一个数，归一化后完全不变；减 x̂ · mean(dy⊙x̂)，是因为把整行同时放大，归一化后也完全不变。这两个方向上的梯度必须是 0。



最后除以 σ：前向除了多少，反向就要除多少。x̂ 就是前向的输出 H2，σ 用前向时保存的那一行的标准差。



#### 残差分流 + FFN 反向 ①：W₂



```
R<sub>2</sub> = H<sub>1</sub> + F　⇒　dF = dR<sub>2</sub>，dH<sub>1</sub> 先记下一份 dR<sub>2</sub>
```


> 形状：dW₂: (8×3)·(3×4) → 8×4；dU⁺: (3×4)·(4×8) → 3×8



前向时 R2 = H1 \+ F。加法的反向最简单：**梯度原样复制给两边** 。所以 dF = dR2，H1 也直接收到一份 dR2。这条「捷径」就是残差连接让深层网络好训练的原因：不管中间的 FFN 怎么样，梯度总有一条路可以畅通无阻地往回走。



H1 这一份先记着，第 7 步汇合。现在沿 FFN 往回走：F = U+ · W2，套用矩阵乘法的反向规则。



#### FFN 反向 ②：ReLU 和 W₁



```
dU = dU⁺ ⊙ 1[U > 0]，dW<sub>1</sub> = H<sub>1</sub><sup>T</sup>dU，dH<sub>1</sub><sup>(FFN)</sup> = dU · W<sub>1</sub><sup>T</sup>
```


> 形状：3×8 → 3×8 → 4×8 和 3×4



ReLU 前向时把负数截成 0。反向时它像一排开关：前向时 U > 0 的格子，梯度原样通过；U ≤ 0 的格子，输出恒为 0，输入怎么变都不影响结果，梯度就是 0。



然后再过一次矩阵乘法 U = H1W1：一份落在 W1 上，一份传回 H1。这是 H1 收到的第二份梯度。



#### 两路梯度汇合，再穿过 LayerNorm



```
dH<sub>1</sub> = dR<sub>2</sub> + dH<sub>1</sub><sup>(FFN)</sup>，dR<sub>1</sub> = LayerNorm 反向(dH<sub>1</sub>)
```


> 形状：3×4 → 3×4



H1 在前向时被用了两次：一次进 FFN，一次走残差直接加到 R2。**一个量被用了几次，反向时就会收到几份梯度，全部加起来** 。这是链式法则在多条路径上的样子。



汇合之后，再穿过第一个 LayerNorm，公式和第 4 步完全一样，只是换成 R1 那一行的标准差。



#### 残差再分流 + 输出投影 W`<sub>`O`</sub>`



```
R<sub>1</sub> = X<sub>0</sub> + Attn　⇒　dAttn = dR<sub>1</sub>；dW<sub>O</sub> = [O₁|O₂]<sup>T</sup>dAttn，d[O₁|O₂] = dAttn · W<sub>O</sub><sup>T</sup>
```


> 形状：(4×3)·(3×4) → 4×4；(3×4)·(4×4) → 3×4



又是一次残差：dAttn = dR1，X0 也直接收到一份 dR1（第 13 步汇合）。



Attn = [O1 | O2] · WO，再套一次矩阵乘法规则。传回来的 d[O1|O2] 按竖线切开：左边两列交给头 1，右边两列交给头 2，两个头从这里开始各算各的。



#### 加权求和反向：dA 和 dV



```
O<sub>h</sub> = A<sub>h</sub>V<sub>h</sub>　⇒　dA<sub>h</sub> = dO<sub>h</sub>V<sub>h</sub><sup>T</sup>，dV<sub>h</sub> = A<sub>h</sub><sup>T</sup>dO<sub>h</sub>
```


> 形状：(3×2)·(2×3) → 3×3；(3×3)·(3×2) → 3×2，每个头各一次



前向时 O = A · V：用注意力权重混合 V 的行。反向还是矩阵乘法规则：dA 告诉我们**每个注意力权重该变大还是变小** ，dV 告诉我们每个词提供的内容该怎么改。



dA 的右上角也算出了数，但那些位置前向时被遮罩成 0，下一步穿过 softmax 时会被清零。



#### Softmax 反向：一行加起来等于 1 的代价



```
dS<sub>h</sub>[i,j] = A[i,j] · (dA[i,j] − Σ<sub>k</sub> dA[i,k]·A[i,k])
```


> 形状：3×3 → 3×3，逐行



softmax 让每一行加起来等于 1：一个权重变大，别的必须变小。所以反向时也要看整行：先算这一行 dA 按权重的加权平均，每一格**只有比平均高出的那部分** 才算数，再乘上自己的权重 A。



两个现象值得注意：**「猫」那一行全是 0** ，它只能看自己，权重永远是 1，分数怎么变都没有意义；右上角遮罩的位置权重是 0，梯度也是 0。



再看数值大小，dS 比上一步的 dA 小了一个数量级：权重被 A 乘了一遍，梯度在这里被明显压小了。



#### 注意力分数反向：dQ 和 dK



```
S<sub>h</sub> = Q<sub>h</sub>K<sub>h</sub><sup>T</sup> ÷ √2　⇒　dQ<sub>h</sub> = dS<sub>h</sub>K<sub>h</sub> ÷ √2，dK<sub>h</sub> = dS<sub>h</sub><sup>T</sup>Q<sub>h</sub> ÷ √2
```


> 形状：(3×3)·(3×2) → 3×2，每个头各两次



还是矩阵乘法，只是多了前向的 ÷√2，反向时也要 ÷√2。



dQ 的第一行是 0，因为「猫」的分数梯度本来就是 0。dK 每一行收集的是「所有看过我的词」传回来的梯度：「鱼」只被自己看过，「猫」被三个词都看过。



#### Q、K、V 三个权重的梯度



```
dW<sub>Q</sub> = X<sub>0</sub><sup>T</sup>dQ，dW<sub>K</sub> = X<sub>0</sub><sup>T</sup>dK，dW<sub>V</sub> = X<sub>0</sub><sup>T</sup>dV
```


> 形状：(4×3)·(3×4) → 4×4，三次



两个头的 dQ 左右拼回 4 列（dK、dV 同理），再和前向时一样，三个权重共用同一个输入 X0。



对比三个结果的大小：dWV 明显最大，dWQ、dWK 小得多。V 直接决定输出内容，Q、K 只能通过 softmax 间接影响输出，梯度要被压小一道。



#### 四路梯度汇合到 X₀



```
dX<sub>0</sub> = dR<sub>1</sub> + dQ·W<sub>Q</sub><sup>T</sup> + dK·W<sub>K</sub><sup>T</sup> + dV·W<sub>V</sub><sup>T</sup>
```


> 形状：3×4，四份相加



X0 在前向时被用了四次：乘 WQ、乘 WK、乘 WV，还有一次走残差直接加到 R1（第 8 步记下的那份）。所以它要收四份梯度。



算完你会发现，最后的 dX0 大部分来自残差那一路，注意力三路加起来只占一小部分：残差连接就是梯度的高速公路。



#### 嵌入的梯度：只有出现过的词会被更新



```
dX = dX<sub>0</sub>，dE<sub>入</sub> = onehot<sup>T</sup> · dX，dE = dE<sub>入</sub> + dE<sub>出</sub>
```


> 形状：(6×3)·(3×4) → 6×4



X0 = X + P，P 是固定的位置编码，不用学，梯度直接给 X。



X = onehot · E，矩阵乘法规则给出 dE = onehotT · dX。onehotT 每一行只有一个 1，所以这一步其实是**把 dX 的每一行放回对应词的那一行** ：「猫」「吃」「鱼」各收一行，「喝」「水」「。」没有出现在输入里，梯度是 0。



最后把第 3 步输出层那一份加上，才是 E 的总梯度。「。」虽然没出现在输入里，但它是答案，在输出层收到了梯度。



到这里，**7 个参数矩阵、152 个数，每一个的梯度都算出来了** 。



### 第二部分 · 优化器



#### 梯度下降：所有参数走一步



```
W ← W − η · dW
```


> 形状：每个参数矩阵，逐格



有了梯度，更新就是一行公式：每个参数减去「学习率 η × 自己的梯度」。7 个矩阵同时做，下面拿梯度最大的 WV 演示，η = 1。



更新完再做一次前向，看 loss 变了多少。



#### 训练循环：一遍又一遍



```
重复：前向 → 损失 → 反向 → W ← W − η · dW
```


> 形状：200 步



上面 15 步合起来叫**一个训练步** 。训练就是把它重复成千上万次，每次都用更新后的参数重新前向。



点开始，看 loss 怎么往下掉，三个正确答案的概率怎么爬到接近 1。下方的 p 矩阵是每一步实时的预测，红框是答案。



因为只有一句话，模型最终会把它背下来，loss 趋近 0。真实预训练的数据量远大于模型能背下的量，loss 会停在某个高于 0 的位置。



#### Adam：给每个参数配自己的步长



```
m ← β₁m + (1−β₁)g，v ← β₂v + (1−β₂)g²，W ← W − η · m̂ ÷ (√v̂ + ε)
```


> 形状：β₁ = 0.9，β₂ = 0.999，逐格独立



第 14 步看到了：不同参数的梯度大小可以差一个数量级。用同一个 η，大梯度的参数可能迈过头，小梯度的参数几乎不动。



Adam 给每一格都记两个量：**m** 是梯度的滑动平均（方向），**v** 是梯度平方的滑动平均（典型大小）。更新时用 m ÷ √v：梯度一直大的，除以一个大数；一直小的，除以一个小数。每个参数的步长都被拉到 η 附近。



m̂、v̂ 是偏差修正：m、v 从 0 开始，前几步会偏小，除以 (1 − βt) 补回来。第一步修正后 m̂ = g，v̂ = g²，所以每个参数正好走 η × g ÷ |g|，也就是 ±η。



#### 学习率调度：Warmup + Cosine



```
η(t) = η<sub>max</sub> · t/T<sub>w</sub>（热身期），之后 η<sub>max</sub> · ½(1 + cos(π · 进度))
```


> 形状：T = 200 步



训练刚开始时参数是随机的，梯度方向不太靠谱，步子迈太大容易把模型打到很差的区域；训练后期接近最低点，步子太大又会在谷底来回震荡。



所以几乎所有大模型都这样安排学习率：**先用几百到几千步从 0 线性升到峰值（Warmup），再按余弦曲线慢慢降到接近 0（Cosine Decay）** 。



下面用 SGD 对比：同样的峰值学习率，一条一直用常数，一条用 Warmup + Cosine。拖动热身步数、换峰值，看两条 loss 曲线的差别。
