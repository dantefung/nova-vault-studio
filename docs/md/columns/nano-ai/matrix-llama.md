## 全部章节（交互式图解的完整文字版）



#### 词嵌入：和 Transformer 一样查表



```
X = onehot · E
```


> 形状：(3×6) · (6×4) → 3×4



第一步和原始 Transformer 完全一样：one-hot 乘嵌入矩阵 E，取出每个词那一行。



不一样的是**下一步不再加位置编码** 。LLaMA 把位置信息挪到了注意力内部，用 RoPE 去旋转 Q 和 K（第 4 步）。所以 X 直接进入 Block。



这一页用的还是「猫 吃 鱼」、4 维、2 个注意力头，和 
[Transformer 那一页](/matrix/)
同样大小，方便对照每一步改了什么。



#### RMSNorm：先归一化，再进注意力



```
N<sub>1</sub> = RMSNorm(X) = X ÷ RMS(X)
```


> 形状：3×4 → 3×4，逐行



两处改动。第一是**顺序** ：原始 Transformer 先算注意力、加残差、最后才归一化（Post-LN）；LLaMA 先归一化再进注意力（Pre-Norm），残差加回的是没归一化的 X。层数一多，这样训练更稳。



第二是**算法** ：LayerNorm 要先减均值再除标准差；RMSNorm 直接除以均方根 √(Σx²/d)，不减均值。少一步，效果差不多，算得更快。这里 γ = 1，省略了缩放。



#### GQA：两个 Q 头共用一组 K、V



```
Q = N<sub>1</sub>W<sub>Q</sub>，K = N<sub>1</sub>W<sub>K</sub>，V = N<sub>1</sub>W<sub>V</sub>
```


> 形状：Q：(3×4)·(4×4) → 3×4；K、V：(3×4)·(4×2) → 3×2



Q 还是 4 列，分给 2 个头。但 WK、WV 只有 **2 列** ：K、V 只有 1 个头，两个 Q 头共用它。这就是 GQA（分组查询注意力）。



为什么这么做？生成时每个词的 K、V 都要存进 KV Cache。K、V 的头数砍掉一半，**缓存就小一半** ，长文本推理省下大量显存。Q 头数不变，模型「问问题」的能力基本保住。



真实的 LLaMA 2 70B：64 个 Q 头配 8 个 KV 头，每 8 个 Q 头共享一组。



#### RoPE：按位置旋转 Q 和 K



```
(x, y) → (x cos θ − y sin θ,  x sin θ + y cos θ)，θ = pos
```


> 形状：3×4 → 3×4，3×2 → 3×2，逐行



把每两列看成平面上的一个点 (x, y)，按词的位置转一个角度：第 pos 个词转 pos × θ 弧度。每个头 2 维，正好一对，频率 θ = 100000 = 1，所以「猫」转 0、「吃」转 1、「鱼」转 2 弧度。



只转 Q 和 K，**V 不动** ，X 本身也不加任何东西。妙处在于：两个向量都旋转后再做点积，结果只取决于它们**角度之差** ，也就是两个词相隔几个位置。下面的验证框可以看到这一点。



真实模型每个头有几十对维度，每对用不同的频率 θi = 10000−2i/d：有的转得快、看近处，有的转得慢、看远处。



#### 注意力分数：两个头对着同一个 K



```
S<sub>h</sub> = Q̃<sub>h</sub>K̃<sup>T</sup> ÷ √d<sub>h</sub>
```


> 形状：(3×2) · (2×3) → 3×3，每个头一次



算法和原始 Transformer 一样：Q 的第 i 行和 K 的第 j 行做点积，再除以 √2。



区别是两个头右边乘的是**同一个 K̃ T**。因为 Q 和 K 已经旋转过，分数里已经带上了相对位置信息，不需要别的位置编码。



#### 因果遮罩 + Softmax



```
A<sub>h</sub> = softmax(mask(S<sub>h</sub>))
```


> 形状：3×3 → 3×3，逐行



和原始 Transformer 完全一样：未来的位置设成 −∞，逐行 softmax，每行加起来等于 1。



#### 加权求和：两个头混合同一个 V



```
O<sub>h</sub> = A<sub>h</sub>V
```


> 形状：(3×3) · (3×2) → 3×2，每个头一次



每个头用自己的权重 Ah，去混合**同一个 V** 。两个头看的方式不同（权重不同），但取的是同一份内容。



KV Cache 里存的就是这里的 K̃ 和 V。GQA 省下的显存，就是少存的那几列。



#### 拼接、投影，加回残差



```
Attn = [O<sub>1</sub> | O<sub>2</sub>] · W<sub>O</sub>，R<sub>1</sub> = X + Attn
```


> 形状：(3×4) · (4×4) → 3×4



两个头拼回 4 列，乘 WO。然后加回残差。



注意加回去的是**原始的 X** ，不是归一化后的 N1。Pre-Norm 结构里有一条从头到尾不经过归一化的「主干道」，每一层只往上面加东西。



#### 第二次 RMSNorm：进 FFN 之前



```
N<sub>2</sub> = RMSNorm(R<sub>1</sub>)
```


> 形状：3×4 → 3×4，逐行



和第 2 步一样：进入前馈网络之前，先把每一行除以它的均方根。



#### SwiGLU：带门控的前馈网络



```
F = (SiLU(N<sub>2</sub>W<sub>gate</sub>) ⊙ N<sub>2</sub>W<sub>up</sub>) · W<sub>down</sub>
```


> 形状：3×4 → 两个 3×6 → 3×6 → 3×4



原始 FFN 是一个矩阵升维、ReLU、再降维。SwiGLU 升维时用**两个** 矩阵：一路是**门** （gate），过 SiLU 激活；一路是**内容** （up），不激活。两路逐格相乘，门决定内容的每一格放多少过去。



SiLU(x) = x·σ(x)，和 ReLU 很像，但负数不会被一刀切成 0，曲线是平滑的。



多了一个矩阵，参数会变多。所以 LLaMA 把中间层从 4d 缩到约 8d/3，总参数量和原来差不多。这里中间层取 6。



#### 残差、最后一次 RMSNorm、输出



```
R<sub>2</sub> = R<sub>1</sub> + F，logits = RMSNorm(R<sub>2</sub>) · W<sub>out</sub>
```


> 形状：3×4 → 3×4 → 3×6



FFN 的输出加回主干道，**一个 LLaMA Block 就算完了** 。真实模型叠几十层，下一层的输入就是 R2。



所有层算完，最后再做一次 RMSNorm，然后乘输出矩阵得到每个词的分数。和 GPT-2 不同，LLaMA 的输出矩阵 Wout 是**单独一个矩阵** ，不和嵌入矩阵 E 共享权重。
