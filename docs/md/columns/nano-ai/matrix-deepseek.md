## 全部章节（交互式图解的完整文字版）



#### 起点：KV Cache 太大了



```
N = RMSNorm(onehot · E)
```


> 形状：3×4，和 LLaMA 页的 N₁ 一样



生成文本时，每来一个新词，都要和前面**所有** 词的 K、V 做注意力。为了不重复计算，模型把每个词每一层的 K、V 存起来，这就是 KV Cache。上下文越长，它越大，常常比模型权重本身还占显存。



LLaMA 的 GQA 靠**减少 K、V 的头数** 来省缓存。DeepSeek-V2 换了思路：头数不减，而是把 K、V **压缩成一个很短的向量** 只存它，用的时候再解压。这就是 MLA（Multi-head Latent Attention，多头潜在注意力）。



还是「猫 吃 鱼」、4 维、2 个头。为了直接进入正题，这一步把嵌入和 RMSNorm 合在一起，结果和 
[LLaMA 页](/matrix/llama/)
第 2 步完全相同。



#### 压缩：每个词只留下 2 个数



```
c<sub>KV</sub> = N · W<sub>DKV</sub>
```


> 形状：(3×4) · (4×2) → 3×2



N 乘一个「下投影」矩阵 WDKV，把每个词 4 维压到 dc = 2 维，得到**潜在向量** cKV（latent）。



这是整个 MLA 的核心：**KV Cache 里存的就是这个 c KV**，而不是完整的 K、V。K 和 V 两份信息都挤在这 2 个数里。



#### 解压：从 c 还原出每个头的 K 和 V



```
K<sub>C</sub> = c<sub>KV</sub>W<sub>UK</sub>，V = c<sub>KV</sub>W<sub>UV</sub>
```


> 形状：(3×2) · (2×4) → 3×4，两次



用两个「上投影」矩阵，从同一个 cKV 分别解压出 K 和 V。解压后是完整的 4 列，**两个头各有自己的 K、V** ，不像 GQA 那样共用。



所以 MLA 存得少，但每个头看到的 K、V 依然不同。代价是多了一次矩阵乘法，第 9 步会看到这一步在推理时其实可以省掉。



这里的 K 叫 KC（content，内容部分），它不带位置信息。位置在第 5 步单独加。



#### Query：内容部分



```
Q<sub>C</sub> = N · W<sub>UQ</sub>
```


> 形状：(3×4) · (4×4) → 3×4



Q 和平常一样，每个头 2 维，叫 QC，和 KC 配对。



DeepSeek-V2 其实也把 Q 先压缩再解压（cQ）。Q 不进缓存，这样做省的是训练时的激活显存，原理和 K、V 一样，这里省略。



#### 解耦 RoPE：位置信息单独走一条路



```
q<sub>R</sub> = RoPE(N W<sub>QR</sub>)，k<sub>R</sub> = RoPE(N W<sub>KR</sub>)
```


> 形状：Q：3×4（每头 2 维）；K：3×2（所有头共享）



为什么不直接对 KC 做 RoPE？因为 RoPE 的旋转角随位置变化。如果夹在 cKV 和 WUK 之间，第 9 步那个「把 WUK 提前乘进 Q」的技巧就失效了，推理时又得把 K 全部解压出来。



DeepSeek 的办法是**拆成两部分** ：内容部分（KC）不带位置；另开一小段专门带位置的 qR、kR，用 RoPE 旋转。kR 只有一份，**所有头共享** ，它也要进缓存，但只有 dR = 2 个数。



#### 拼起来算分数：内容 + 位置



```
S<sub>h</sub> = [Q<sub>C,h</sub> | q<sub>R,h</sub>] · [K<sub>C,h</sub> | k<sub>R</sub>]<sup>T</sup> ÷ √(d<sub>h</sub> + d<sub>R</sub>)
```


> 形状：(3×4) · (4×3) → 3×3，每个头一次



每个头把内容部分和位置部分**左右拼成 4 维** ：q = [QC 的这个头 | qR 的这个头]，k = [KC 的这个头 | 共享的 kR]。竖线左边是内容，右边是位置。



点积展开就是两项之和：**内容相似度 + 位置相关度** 。现在每个头是 4 维，所以除以 √4 = 2。



#### 因果遮罩 + Softmax



```
A<sub>h</sub> = softmax(mask(S<sub>h</sub>))
```


> 形状：3×3 → 3×3，逐行



和前两页完全一样：未来的位置设成 −∞，逐行 softmax。



#### 加权求和、拼接、输出投影



```
O<sub>h</sub> = A<sub>h</sub>V<sub>h</sub>，Attn = [O<sub>1</sub> | O<sub>2</sub>] · W<sub>O</sub>
```


> 形状：(3×3)·(3×2) → 3×2，再 (3×4)·(4×4) → 3×4



每个头用自己的权重混合**自己的 V** （第 3 步解压出来的那一半），再拼接、乘 WO。V 不需要位置信息，所以没有 RoPE 部分。



到这里 MLA 的一次注意力就算完了，输出形状 3×4，后面接残差和 FFN，和 LLaMA 一样。



#### 推理时的吸收技巧：K 根本不用解压



```
Q<sub>C,h</sub>K<sub>C,h</sub><sup>T</sup> = Q<sub>C,h</sub>(c W<sub>UK,h</sub>)<sup>T</sup> = (Q<sub>C,h</sub>W<sub>UK,h</sub><sup>T</sup>) · c<sup>T</sup>
```


> 形状：(3×2)·(2×2) → 3×2，再 (3×2)·(2×3) → 3×3



第 3 步每次都要从缓存里的 c 解压出 K，看起来很费。但矩阵乘法可以换个结合顺序：先把 WUK 乘到 Q 那边，得到 q̂，再直接和 cKV 做点积。**结果完全一样** 。



WUK 是固定权重，可以提前和 Q 的权重合并成一个矩阵。所以推理时 KC 从来不用真的算出来，注意力直接在压缩后的空间里做。这也是第 5 步要把 RoPE 拆出去的原因：旋转矩阵随位置变化，夹在中间就没法提前合并了。
