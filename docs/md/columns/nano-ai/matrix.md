## 全部章节（交互式图解的完整文字版）



#### 词嵌入：把词变成向量



```
X = onehot · E
```


> 形状：(3×6) · (6×4) → 3×4



模型先把「猫 吃 鱼」变成词表里的编号，再写成 one-hot 行：只有自己那一格是 1，其余都是 0。



one-hot 乘以嵌入矩阵 E，结果正好是 E 里对应的那一行。所以矩阵乘法在这里就是**查表** ：「猫」是 0 号词，就取出 E 的第 1 行。



这里词表只有 6 个词、每个词 4 维。真实模型的词表有几万到十几万个词，维度是几千。



#### 位置编码：给每一行加上位置



```
X<sub>0</sub> = X + P
```


> 形状：3×4 + 3×4 → 3×4



注意力本身不知道词的先后顺序：「猫吃鱼」和「鱼吃猫」如果不加位置信息，每个词算出来的结果完全一样，只是换了行。



所以给第 pos 行加上一个只跟位置有关的向量。这里用原始 Transformer 的正弦位置编码：P[pos, 2i] = sin(pos / 100002i/d)，P[pos, 2i+1] = cos(pos / 100002i/d)，保留两位小数。逐格相加，形状不变。



LLaMA 等模型改用 RoPE：不在这里加，而是在第 4 步对 Q、K 做旋转。



#### Q、K、V：同一个输入乘三个矩阵



```
Q = X<sub>0</sub>W<sub>Q</sub>，K = X<sub>0</sub>W<sub>K</sub>，V = X<sub>0</sub>W<sub>V</sub>
```


> 形状：(3×4) · (4×4) → 3×4，三次



同一个 X0 分别乘三个权重矩阵：**Q** （Query，我在找什么）、**K** （Key，我身上有什么）、**V** （Value，被选中后我提供什么）。



后面要分成 2 个注意力头，每个头 2 维：Q、K、V 的前两列归头 1，后两列归头 2，图里用竖线隔开。



#### 注意力分数：谁在看谁



```
S<sub>h</sub> = Q<sub>h</sub>K<sub>h</sub><sup>T</sup> ÷ √d<sub>h</sub>
```


> 形状：(3×2) · (2×3) → 3×3，每个头一次



每个头单独算。Qh 的第 i 行和 Kh 的第 j 行做点积，数越大，表示第 i 个词越「关注」第 j 个词。



结果是 3×3：**行是「谁在看」，列是「被看的是谁」** 。再除以 √dh = √2，防止维度一大点积就变得很大，让后面的 softmax 过于尖锐。



#### 因果遮罩 + Softmax：变成权重



```
A<sub>h</sub> = softmax(mask(S<sub>h</sub>))
```


> 形状：3×3 → 3×3，逐行



生成文本时，一个词只能看见自己和前面的词，不能偷看后面的。所以把右上角（未来的位置）设成 −∞，softmax 之后它就是 0。



Softmax 逐行进行：每个数取 e 的指数，再除以这一行的总和，于是**每一行加起来等于 1** ，可以当作「注意力分配比例」。「猫」前面没有词，只能 100% 看自己。



#### 加权求和：按权重混合 V



```
O<sub>h</sub> = A<sub>h</sub>V<sub>h</sub>
```


> 形状：(3×3) · (3×2) → 3×2，每个头一次



用上一步的权重把 V 的行混合起来：输出第 i 行 = Σj A[i][j] × V 的第 j 行。



算完以后，「鱼」这一行已经按比例混进了「猫」和「吃」的信息。这就是注意力在词与词之间**搬运信息** 的方式。



#### 多头拼接 + 输出投影



```
Attn = [O<sub>1</sub> | O<sub>2</sub>] · W<sub>O</sub>
```


> 形状：(3×4) · (4×4) → 3×4



把两个头的结果左右拼回 4 列（竖线左边是头 1，右边是头 2），再乘 WO，让两个头各自找到的信息互相混合。



到这里多头注意力就算完了，形状回到 3×4，和输入 X0 一样。



#### 残差连接 + LayerNorm



```
R<sub>1</sub> = X<sub>0</sub> + Attn，H<sub>1</sub> = LayerNorm(R<sub>1</sub>)
```


> 形状：3×4 → 3×4



**残差** ：把注意力的输出加回原来的输入。原信息不会被冲掉，训练时梯度也能直接传回去。



**LayerNorm** 逐行做：减去这一行的均值 μ，再除以标准差 √(σ² + ε)，让每个词的向量回到差不多的尺度。这里 γ = 1、β = 0，省略了缩放和平移。



这是原始 Transformer 的 Post-LN 顺序。GPT-2 之后多用 Pre-LN（先归一化再进注意力），矩阵运算一样，只是顺序不同。



#### 前馈网络 FFN：每个词单独加工



```
F = ReLU(H<sub>1</sub>W<sub>1</sub>) · W<sub>2</sub>
```


> 形状：3×4 → 3×8 → 3×8 → 3×4



注意力负责在词与词之间搬运信息，FFN 则**对每个词单独加工** ：每一行只和自己有关，行与行互不影响。



先把 4 维升到 8 维，经过 ReLU 把负数变成 0，再降回 4 维。升维加非线性，让模型能表达更复杂的变换。



真实模型的中间层通常是 4 倍宽。原始 Transformer 用 ReLU，GPT-2 换成 GELU，LLaMA 用 SwiGLU。



#### 第二次残差 + LayerNorm



```
R<sub>2</sub> = H<sub>1</sub> + F，H<sub>2</sub> = LayerNorm(R<sub>2</sub>)
```


> 形状：3×4 → 3×4



和第 8 步一样：先把 FFN 的输出加回去，再逐行归一化。



到这里，**一个 Transformer Block 就算完了** 。真实模型会把这样的 Block 叠几十层，每层权重不同，下一层的输入就是这里的 H2。我们只算一层。



#### 输出：预测下一个词



```
logits = H<sub>2</sub>E<sup>T</sup>，p = softmax(logits)
```


> 形状：(3×4) · (4×6) → 3×6



拿最后的向量和词表里每个词的嵌入做点积，得到每个词的分数 logits，再逐行 softmax 成概率。这里直接复用了第 1 步的 E（转置），叫**权重共享** ，GPT-2 就是这么做的。



每一行都在预测「自己后面那个词」。生成时只看最后一行：「鱼」后面接什么。选出概率最高的词，接到句子末尾，再把整句重新送进第 1 步，就是一次次生成的过程。
