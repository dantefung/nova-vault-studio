# AI Native 学习法：用费曼 + AI 高效掌握新知识

> AI 时代如何利用 AI 高效学习是一个值得探究的问题。

## 费曼学习法 + AI

自己的做法是费曼学习法，学习过程中反复问 AI。

## 高阶技巧

### ASD-STE100 简化技术英语

ASD-STE100 是最初为航天航空维护文档开发的语言风格。LLM 很擅长这种语言风格，用这种格式生成的文本更易读。

### 文字转图像/可交互内容

把抽象的文字转换成：
- 人类更易读的图像
- 可交互的卡片
- 演示内容
