# 年轻时投资自己才是回报率最高的事

> 别急着玩合约、杠杆、炒币。就算你赢了，接下来往往只会更痛苦，直到你真正经历过"这钱终究会亏完"的阶段，再去碰也不迟。

## 投资自己的6个方向

### 1. 多出去看看世界

去不同的国家，感受不同的人文与文化，看看有没有地理逃离的可能。同时拿起手机，把这些都记录下来。

### 2. 多做没做过的事

没蹦过极、没跳过伞、没游过泳、没住过五星级酒店、没上过游艇……人生是体验的合集。只有真正体验过，才知道那是什么感觉，才知道自己到底想不想要。

### 3. 找到你持续想做的事

翻看过去自己人生中，那些真正让你开心、想要抵达的瞬间，然后慢慢朝那个方向走。不用着急，人生很长。

### 4. 别想着走捷径

想走捷径本身就是一种市场需求，最终你大概率会被捷径打败。这个世界上除了父母，几乎没有人会无条件帮你。一旦涉及金钱，关系往往就会发生变化。

### 5. 多读书，多获取信息

世界上 99% 的问题，前人已经解决过了。你只需站在他们的肩膀上，找到解法，再做出自己的方案——甚至直接用现成的也行。比如想从网站下载视频，去 GitHub 搜一搜，往往就有现成插件。只有看到过巨人，才知道巨人有多高。

### 6. 一定要做一个自媒体账号

抖音、小红书、推特都行。在这里记录你的日常、思考和感受，账号是可以复利的资产，能让更多人看见你正在做的事。

**这些，才是真正重要的东西。**

> 愿你看过世界的一切繁华之后，仍然有面对世界的勇气。
