# Dan Koe Human 3.0 测试：你处于哪个段位？

> 来自"超级个体教父" @thedankoe，人在生活这场游戏里，其实只有三种活法。

## 三种活法

### 1.0 顺从者（NPC）

生活完全由外部剧本设定。注意力被算法切碎，白天出卖时间换生存，晚上靠刷短视频麻痹无聊。以为自己 在生活，其实只是被算法运行的电池。

### 2.0 苦行僧（个体玩家）

开始拼命自律搞钱，但掉进了最隐蔽的"虚假努力"——靠浓咖啡透支身体硬顶、用收藏干货的快感掩盖不敢发布作品的怯懦。收入涨了，却沦为 7×24 小时不敢停工的黄金牢笼。

### 3.0 觉醒者（高维玩家）

心智、身体、精神、事业四大象限高度协同。自律不再是咬牙坚持的苦役，而是顺其自然的生活审美；把自己攻克人生痛点的过程做成复利资产，工作即是玩耍。
