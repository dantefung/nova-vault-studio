# podcast-deep-dive：将长内容转为深度解读文档

> 将播客、视频等长内容转为带金句和标注的深度解读文档。

## 核心能力

输入为一个 **YouTube / 播客链接或节目名称**，输出为带**金句**和**标注**的飞书文档。

## 定位

不是简单转录，而是深度解读：
- 提取核心观点和金句
- 标注关键洞察
- 结构化整理成文档
- 输出到飞书文档（可修改适配其他 AI Agent）

## 适用场景

- 深度学习一手播客内容
- 整理嘉宾观点形成笔记
- 将视频/播客转化为可搜索的文档
- 提炼嘉宾方法论和洞察
