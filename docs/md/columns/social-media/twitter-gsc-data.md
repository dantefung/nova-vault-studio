# 推特主页绑定 GSC 后，三天数据出来了

上次把推特主页绑定到 GSC 后，现在有一些数据出来了。

7 月 28 日到 30 日，共三天的数据，有 1246 个曝光，32 个点击。

说明几个事情：

1. 推文是可被谷歌索引的，尽管其实推文页面是前端渲染的，这是谷歌给大站的特权，谷歌需要推特这种时刻有新信息发布出来的网站提供新鲜内容，所以愿意去渲染获取内容；

2. 借助推特高权重域名发推文来拿某些关键词排名是可行的，会被抓取，会有曝光，会有点击。也就是说，最后也会有转化。
