# X 高级玩法：划分区域刷推，效率提高 200%

> 把推特划分为娱乐区、学习区、关注区等，大幅度提高信息密度，学习娱乐两不误。

## 核心思路

把推特按需求划分为多个区域，看优质信息累了，直接从娱乐区放松。

## 使用工具

- **X 自带列表功能**：划分区域
- **X Pro**：管理列表
- **dessix.io**：分类记录的笔记工具

## 操作步骤

1. 创建多个列表：娱乐区、学习区、关注区等
2. 将对应账号加入各列表
3. 用 X Pro 管理这些列表
4. 用 dessix.io 做分类笔记记录

## 效果

刷推效率提高 200%，学习娱乐两不误。
