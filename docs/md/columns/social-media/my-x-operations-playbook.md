# 我的版本（X 运营）

> 相信时不带身体，执行时不带脑子，选择时对着市场，分润时对着信仰。

## 四条核心原则

**相信时不带身体**

以后我的定位，就是在中文 X 上，把「用 AI 把手头的问题解决掉」这件事写清楚。

**执行时不带脑子**

14 天内别开新插件、别开新产品、把有的东西写好。

**选择时对着市场**

听歌文和心法篇效果明显，日常和碎碎念没有任何水花。

**分润时对着信仰**

时间是目前最宝贵的，2 小时高质量回复，和每周那一篇高质量文章，务必投入超所值。
