# 写作流水线 7 个 Skill：从选题到排版全流程

> 分享常用的 7 个 skill，从选题到排版，拼出一条自己的写作流水线。

## 1｜选题：dbskill

[@dontbesilent](https://github.com/dontbesilent20)

动笔前先拿它过一遍，问它「这个选题谁会看、凭什么点开」。答不上来的选题，直接放回选题库。

GitHub: [dontbesilent/dbskill](https://github.com/dontbesilent20)

## 2｜写稿：khazix-skills

[@Khazix0918](https://github.com/KKKKhazix)

不代写，主要学它的长文推进：开头怎么抓人，每隔几段怎么把人拉回来。

GitHub: [KKKKhazix/khazix-skills](https://github.com/KKKKhazix/khazix-skills)

## 3｜自查：dbs-ai-check

[@dontbesilent](https://github.com/dontbesilent20)

dbskill 里自带的。写完先让它出一份 AI 痕迹报告，默认只标问题不改原文，哪句要改自己定。

GitHub: [dontbesilent20/dbs-ai-check](https://github.com/dontbesilent20)

## 4｜润色：Humanizer-zh

[@op7418](https://github.com/op7418)

报告里确认要改的句子，再交给它处理。整篇丢进去，它容易把正常的过渡也一起删掉。

GitHub: [op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh)

## 5｜配图：baoyu-skills

[@dotey](https://github.com/jimliu)

封面、信息图、文中插图都靠它，一个仓库装完基本够用。

GitHub: [jimliu/baoyu-skills](https://github.com/jimliu/baoyu-skills)

## 6｜排版：gzh-design

[@jiamu_future](https://github.com/isjiamu)、[@li_mo60607](https://github.com/li_mo60607)

Markdown 直接转成能粘进公众号后台的 HTML，章节编号、代码块都排好了。

GitHub: [isjiamu/gzh-design](https://github.com/isjiamu/gzh-design)

## 7｜二次分发：guizang-ppt-skill

[@op7418](https://github.com/op7418)

把文章的核心观点做成一份网页 PPT，杂志风和瑞士风二选一，拿去做分享很省事。

GitHub: [op7418/guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill)
