# 游戏站快速上手

## 核心理念

> 游戏站最快的是做一个页面，然后把现成的网站嵌进来。游戏中 iframe 比较快。

## 5步实操路线

### 第一步：找词

用关键词找词方法找到一个游戏相关词：
- 有搜索量
- 竞争不算太大
- 与游戏相关

参考：[[哥飞SEO找关键词方法论]]

### 第二步：注册域名

- 使用包含游戏名称的域名
- 优先 `.com`
- 注意版权风险（参考 [[02-copyright]]）

### 第三步：获取 iframe src

1. 在 itch.io 等平台找到对应游戏
2. 找到游戏的嵌入代码
3. 复制 iframe src 地址

**案例**：群友华从问「嵌入码去哪找」到「可以了，谢谢」只花了不到半小时。

### 第四步：生成落地页

让 Cursor 生成一个落地页，包含：
- 游戏 iframe 居中展示
- 标题
- 描述
- Adsense 广告位

### 第五步：部署

部署到 Cloudflare Pages：
- 免费
- 快速
- 全球 CDN

## 学习资源

> new.web.cafe 搜索「游戏」，把几十篇文章看完就差不多了。

## 完整流程图

```
找词 → 注册域名 → 获取iframe → 生成落地页 → 部署CF Pages
```
