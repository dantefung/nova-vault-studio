# 游戏站深度补充（阶段三）

## 一、游戏资源获取：Flash 到 DOS，万物皆可复活

| 路径 | 方法 | 备注 |
|------|------|------|
| Flash 游戏 | Ruffle 开源脚本复活 | 4399 上的 Flash 游戏都能搬，.swf 后缀 |
| DOS 游戏 | DOS 模拟器在浏览器跑 | GTA1、沙丘、红色警戒等经典可玩，**注意版权** |
| 游戏分发网络 | iframe 嵌入 + 分成 | GameDistribution 等 |

**版权警告**：任天堂等大厂游戏有商标保护，域名商、服务器商、广告联盟都可能在版权投诉后封你。

> "比获取游戏资源更重要的就是搞流量，我就是来赚钱的，搞流量不可耻。"

## 二、Blank 转型之路与收入真相

### Blank 背景

从北京大厂离职回到老家，靠出海做网站实现 WLB。10 月比赛第一名，单站 991K PV、约 $4955 收入。

### 收入真相

哥飞自己的游戏站：9 月底做，10 月广告收入 **$1.2 万**。还不是群里收入最高的。

### 广告平台对比

| 平台 | 特点 |
|------|------|
| Monetag | 支持俄罗斯流量，但自动广告严重影响体验 |
| Adsterra | 无自动广告，会识别 VPN 不展示广告 |
| Adsense | 门槛最高但单价最高 |

**当前策略**：Adsense 自动广告 + Adsterra Native Banner 混合投放

### Google Ads 投放窗口

新词初期每次点击只要几分钱，如果能打正就继续放大。但后来投的人越来越多，单价被推上去就没继续了。新词初期的 Google Ads 投放窗口存在，只是很短。

## 三、信奉：TikTok 跨平台找词 + 长内容单页

信奉 10 月比赛第二名，219K UV、302K PV——做的是**内容站**，不是游戏站。

### 找词：从 TikTok 来

国庆刷 TikTok 发现同一款游戏视频反复出现，评论区都在问"在哪里可以玩"，立刻查谷歌趋势——新词，谷歌首页只有 TikTok 视频和 YouTube 视频，没有专门网站。当天注册域名。

### 页面结构：不套 iframe，做长内容单页

大 H1/H2 → 大量游戏截图（高清、改过的图片，不抄袭别人）→ 详细介绍文字（自己写）→ 嵌入 YouTube 视频 → 列出用户分享的原视频

这个结构让他同时从 TikTok 搜索拿到额外流量——把 TikTok 账号名改成关键词名，用户直接在 TikTok 里搜索就能找到他。

### Gitbase 模板

哥飞开源模板 github.com/qiayue/gitbase，对爬虫极度友好，新站提 GSC 后 3 小时左右就被收录。不懂 Next.js 也完全可用。

## 四、Xi5h1r：一小时建站流

自研浏览器插件 TrendsBar，测试时偶然发现当天才出现的新词，谷歌第一页几乎零竞争，当晚用 Next.js 模板 + Claude 生成落地页上线，第二天排到前三。

### 踩过的坑

| 坑 | 教训 |
|---|------|
| 域名没覆盖强关联词 | 导致拿不全流量 |
| 404 页面放广告 | 被 Adsense 拒了三次 |
| 初期外链分散到子页面 | 应该只指向主域 |

两个站热度消退前合计产生约 **$80 广告收入 + $25 打赏**。

## 核心要点

1. **游戏资源**：Flash 用 Ruffle 复活、DOS 游戏用模拟器、万物皆可 iframe
2. **收入天花板**：新站首月收入远超想象，哥飞自己站 $1.2 万/月
3. **找词新思路**：从 TikTok 刷到流量词，TikTok 账号名改成关键词名拿双平台流量
4. **模板选择**：Gitbase 对爬虫极度友好，3 小时收录
