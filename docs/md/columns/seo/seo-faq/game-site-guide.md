# 游戏站完整操作指南

## 一、什么是游戏站

特指网页小游戏站（H5），与以前 Flash 小游戏一脉相承，现用 HTML5/JavaScript 开发。

**特征**：规则简单、免注册即开即玩、单机为主、单局几分钟到十几分钟、纯休闲打发时间

**常见类型**：益智解谜、休闲跑酷、消除、简单射击、小型策略

## 二、为什么游戏站是最佳入门方向

| 优势 | 说明 |
|------|------|
| 竞争格局好 | 被站长盯上，但没被创业公司盯上，不像 AI 工具那么卷 |
| 用户停留时间长 | 打开就玩，谷歌把这当重要排名信号，更容易拿排名且稳得住 |
| 生命周期不短 | 不是一波流，suikagame.com 2024年10月注册，当月423万访问，第13个月仍月访问七八十万 |
| 变现门槛低 | Adsense 广告，国内银行卡直接收款，不需要 Stripe |

## 三、收入参考

| 案例 | 数据 |
|------|------|
| 哥飞真实数据 | 月访问七八十万游戏站，Plausible 实际月 UV 160万、PV 550万，单月 Adsense 收入 3万美金 |
| wordly.org | 月访问 300万，估算仅 Adsense 年收入 100-200 万人民币 |
| 哥飞另一站 | 稳定日入 300+ 美元（做的衍生词而非主词） |

## 四、找词找游戏：三种方法

### 方法一：监控竞品 Sitemap（核心大招）

抓取几百个做得好、流量大的游戏站 Sitemap，相当于几百双眼睛帮你监测新游戏。针对每个新页面提取关键词，去谷歌趋势判断是否是新词，如果是就注册域名上站。

### 方法二：Semrush 看高权重平台子域名

搜索 `*.vercel.app`、`*.github.io`、`*.netlify.app`、`*.pages.dev`、`*.js.org` 等域名下所有有流量的子域名，直接发现别人刚做的游戏站。

参考页面：rentry.org/github-io-pages

### 方法三：谷歌趋势 + 新游戏首发平台蹲点

在 itch.io 的"last 7 days"区、Scratch 的 Explore/Projects/Games 区、cocrea.world 等平台关注最新发布的游戏，一旦发现势头就立刻行动。

## 五、三种建站方式

| 方式 | 适用阶段 | 说明 |
|------|---------|------|
| iframe 嵌入别人游戏 | **新手首选** | 最快上手，从 itch.io 等平台拿嵌入地址，Cursor 生成落地页，群友华从不到半小时完成 |
| 基于开源游戏修改 | 进阶 | Wordle、2048、合成大西瓜等源码开源，直接拿来放自己网站 |
| 自己开发 | 不推荐新手 | 花几周开发出来可能没几个用户 |

## 六、页面布局关键要素

对照 wordly.org 抄作业：

- **首屏**：打开网页第一屏就能直接玩游戏，游戏区域正中，iframe 加好 allowfullscreen 等属性
- **广告位**：游戏下方放 Adsense 广告，哥飞推荐**自动广告**比手动设置收入更高
- **SEO 文字区域**：游戏下面必须放文字介绍给搜索引擎，让谷歌知道页面内容。"三大原则"之一是"分门别类罗列"
- **多语言**：覆盖越多语言流量越大，要找当地人的实际说法，不要 AI 简单翻译
- **外链获取**：做用户愿意分享的功能页面，如"自定义 Wordle 制作器"

## 七、两种建站策略

| 策略 | 模式 | 适用场景 |
|------|------|---------|
| 单游戏单域名 | 一个游戏一个独立域名 | 蹭爆款游戏词精确流量，成本低，词凉了不续费 |
| 聚合站 | 多个游戏在一个域名下 | 长期价值更大，更稳定 |

**哥飞建议**：两个都做，自己卷自己。

## 八、变现：Adsense 是首选

广告是游戏站核心变现方式——游戏区域内的广告收益归游戏平台/开发者，你赚的是自己页面上游戏区域之外的广告收益。

**Adsense 优势**：正规、几乎不扣量、打款及时、国内银行卡就能收款

**审核期间替代**：MoneTag、Adsterra（注意广告比较野，需后台手动关掉）

## 九、部署：Cloudflare Pages

iframe 的静态页面直接部署到 Cloudflare Pages。群友经验：Astro 配合 SSG 很适合游戏站，多语言也能原生支持。

## 十、常见坑

| 坑 | 解决方案 |
|---|---------|
| 跨域限制 | 换一个允许嵌入的源 |
| poki 拿不到 iframe | poki 是开发者直接上传的，不让别人 frame，别死磕 |
| 商标风险 | 游戏名作域名前先查是否被注册商标，大厂游戏别碰 |
| 被谷歌降权 | 程序化 SEO 站点近期容易被"抹平"，保持一定内容质量 |

## 进阶：找词段位升级

### 第一阶段：Semrush 找低 KD 词（踩坑版）

Semrush 找 KD 不到 30 的游戏词，但游戏词竞争极卷——5 个月够几十个网站抢位，外链都大得吓人。**教训**：游戏词出现超过 30 天，且有竞品域名做了超过 20 天，直接放弃。

### 第二阶段：监控 Sitemap 做站（外链碾压版）

自己写监控程序抓取竞品站 Sitemap，两个月做了约 20 个站。解法：**疯狂发外链**，每天 4-6 小时，坚持两个月，外链域名攒到 200-300 才能排上首页甚至第一。

### 第三阶段：谷歌 Trends 第一时间发现新词（最佳路线）

发现游戏词当天飙升、域名还没被注册、谷歌首页只有几个相关内容时，果断注册 com 域名，30 分钟内上站。克勤群友一个多小时完成从调研到部署全流程。

## 自动化找词方案

**游戏新词监控自动化**：脚本监控游戏站 Sitemap → 抓取新游戏名 → 自动调用 Google Trends API → 判断是新词且有爆发潜力就立即行动

**词根循环挖掘**：从已有词根库出发 → API 获取相关查询 → 分析趋势增长词 → 识别关键词意图 → 新词变词根持续扩展

工具：Google Multi Keyword Trends 一次分析最多 100 个关键词

## 外链策略

外链核心在于**域名本身的权重**，不是单纯数量。越是难以批量获取的链接越有价值。

新站冷启动技巧：用自己老站做第一批外链——做站越多，外链资产越厚。

## 游戏资源获取进阶

| 渠道 | 说明 |
|------|------|
| 游戏 CMS 平台 | 如 CloudArcade，可一键从 GameDistribution、GamePix 等拉取数千款游戏 |
| gamemonetize.com | 提供 iframe 嵌入，游戏内展示自己广告获利，双方共赢 |
| 套竞品原生代码 | 小游戏 JS 文件可直接下载 .html 和 .js 放到自己服务器，无跨域限制 |

## 重要警告：新站别碰程序化 SEO

没有权重的域名批量生成海量页面，怎么死的都不知道。建议新站先坚持手更半年，确保手工页面有流量后再考虑上量。
