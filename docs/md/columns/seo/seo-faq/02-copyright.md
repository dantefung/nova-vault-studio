# 游戏站版权 / 商标避坑

## 核心原则

> 游戏名称作为域名，需要看这个游戏是否申请了商标版权。如果申请了商标版权，尽量别用。如果没有申请过，就没事。

## 版权判断

| 类型 | 能否用 | 说明 |
|------|--------|------|
| **大厂游戏**（任天堂等） | ❌ 不能碰 | 有完整商标保护 |
| **独立小游戏** | ✅ 可以用 | 大多无商标保护 |
| **开源游戏** | ✅ 可以用 | 版权友好 |

## 风险等级

- **高风险**：使用知名IP名称（如 Pokemon、Mario、Zelda）
- **中风险**：使用知名独立游戏名称（需自行查证）
- **低风险**：使用开源/无名游戏名称

## 实操建议

1. 搜索「游戏名 + 商标」查看是否有注册
2. 使用商标查询工具（如 USPTO、TIPO）
3. 不确定时咨询律师或选择其他词
