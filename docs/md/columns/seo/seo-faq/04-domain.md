# 游戏站域名策略

## 两种路线

### 单游戏单域名

**模式**：一个游戏 = 一个域名

**示例**：`gamename.com`

| 优点 | 缺点 |
|------|------|
| 成本低（每年一个域名钱） | 无协同效应 |
| 词凉了不续费就行 | 各自独立运营 |
| 精准匹配搜索意图 | 大量工作重复 |

**适用场景**：蹭爆款游戏词的精确流量

### 聚合站

**模式**：多个游戏在一个域名下

**示例**：`gamesite.com`

| 优点 | 缺点 |
|------|------|
| 长期更有价值 | 起步需要更多维护 |
| 域名权重积累 | 需要持续内容更新 |
| 多个游戏共享流量 | 初期投入大 |

**适用场景**：长期运营，建立品牌

## 哥飞的建议

> 两个都做，自己卷自己。

## 实际选择建议

| 情况 | 推荐方案 |
|------|---------|
| 练手/试错 | 单游戏单域名 |
| 长期运营 | 聚合站 |
| 有资源投入 | 双线并行 |
| 想快速验证 | 先单游戏后聚合 |

## 域名注册建议

- 使用 `.com` 或目标国家域名
- 包含游戏名称关键词
- 注意版权（参考 [[02-copyright]]）
