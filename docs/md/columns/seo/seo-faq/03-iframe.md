# iframe 外链问题

## 问题

> 你们套别人的 iframe，那就是给别人做外链了。

群友田七指出：如果直接在页面嵌入别人的 iframe，外链就指向了别人的域名，而不是你自己的站。

## 影响

- **SEO 权重流失** — 外链不归己
- **流量不归己** — 用户跳转到别人平台
- **依赖他人** — 对方站挂了你的站也受影响

## 解决方案

### 方案一：自托管游戏文件

- 下载游戏原始文件
- 上传到自己的服务器/云存储
- 修改 iframe src 指向自己的域名

### 方案二：Scratch 导出

- Scratch 游戏可以导出为 HTML 文件
- 自托管 HTML 文件，外链完全归己
- 无版权风险（Scratch 本身开源）

## 对比

| 方案 | 外链归己 | 工作量 | 风险 |
|------|---------|--------|------|
| 直接嵌入别人 iframe | ❌ | 低 | 低 |
| 自托管游戏文件 | ✅ | 中 | 中（注意版权） |
| Scratch 导出 HTML | ✅ | 中 | 低 |

## 核心观点

> 如果想让外链归自己，进阶做法是自己托管游戏文件。
