# 我用800条提示词，把AI出海建站这件事做成了流水线

出海赚美刀，量化吃波动。这一年我在后台和群里，见过太多想做出海的程序员。

技术都不差，React、Next.js、部署一条龙，闭着眼睛都能撸出一个站来。但一年过去，真正收到美刀的，少得可怜。

## 死法特别集中，主要两种

**死法一，死在改 UI 上。** 首页改了 18 版，配色换了 7 轮，字体调了 3 天，网站永远差一点就能上线。差着差着，三个月过去了……域名都过期了，网站还锁在本地环境里。

**死法二，死在转化上。** 站是上线了，点进去一看，首页写的全是功能列表，"My Product is a powerful AI-powered platform that helps you..."，用户一秒就关页面。代码写得再漂亮，用户不关心，用户只关心三件事：**你能帮我干嘛，凭什么信你，怎么付钱。**

说真的，AI 时代，问题从来不在技术。程序员做站，技术是长板，短板是打仗的思路。

## 出海建站拆到最后就三件事

让人来，让人信，让人付钱。

落地页、电商独立站、导航目录站、博客内容站、SaaS 工具站、个人品牌站、订阅会员站、工具引流站、AI 应用展示站、出海官网——各种赛道看着眼花，其实都是在用不同姿势解决这三件事。

- **落地页**是最短路径，一页纸收第一单
- **博客**是资产，一篇文章写一次，被搜索和 AI 问答引用几年
- **SaaS** 是产品生意，把一个高频痛点做成可订阅的功能

## 选赛道只看三条

你手里有什么，你能等多久，你愿意重复做什么。

- 急着见钱的去打落地页和电商
- 有耐心的去攒博客和导航站
- 有产品有交付能力的去啃 SaaS

## 打法四步

1. **调研定位**——看竞品怎么讲、用户怎么搜、评论区在骂什么，确定这一页只解决一个问题
2. **设计搭建**——先结构后视觉，首屏说清你是谁、给谁、解决什么，移动端优先
3. **文案转化**——标题说结果，副标题说怎么做到，CTA 说下一步，少形容词，多数字
4. **上线变现**——埋点、表单、支付至少跑通一条，先看首屏跳出、CTA 点击、下单完成这三个数

## 先上线，再完美

第一版不需要 20 个版块。你纠结的很多细节，用户根本没看。

这事一点不新鲜，街边摆摊的大叔都懂：摊位位置是让人来，招牌是让人信，收款码是让人付钱。程序员代码写久了，容易把生意想复杂。

## 提示词就是弹药

前面这些是地图，地图免费送你。但真要动手，你缺的是弹药。

把 800 条 AI 建站实战提示词按十大赛道和作战顺序整理成一套提示词合集，每条长这样（编号 01-013，SaaS Landing Page for Developer Tool，来自第 1 章落地页赛道）：

色板精确到 hex，字号、字重、行高、字距全是参数，第一句就写明拒绝 SaaS 套话。这条丢进 Deepseek Harness、Lovable 或者 Claude Code，出来的不是 demo，是能直接拿去收钱的页面。

你收藏夹里那些「帮我写一个漂亮的落地页」，跟这个一比，就是土枪和机枪的区别。

一个像样的落地页，外包市场报价几千块起步，风格还不由你说了算。这 800 条够你把十条赛道的站全搭起来，一条赛道配几十条弹药反复迭代。
