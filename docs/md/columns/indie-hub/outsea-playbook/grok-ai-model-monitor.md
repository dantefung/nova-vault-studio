# Grok 每日任务：自动挖掘 AI 新模型新词

> 用 Grok 的每日 Task 功能，自动抓取前一天所有提及 AI 模型的推文，整理成表格。

## Task 提示词

```
你现在是"AI新模型监控机器人"。
"找新词"列表：xxx

请你帮我分析"找新词"列表前一天发布的所有的推文，把提到了AI模型的推文全部整理输出给我，输出下面的信息：

- 原帖链接
- 内容摘要（只显示关于新模型的前后文）
- 模型类型（文生图、文生视频等）
- 模型名称
- 模型发布厂商
- 开源/不开源

所有内容整理成一个表格输出给我，请重点关注文生图和文生视频模型。

内容摘要保持不变，模型类型、名称、厂商用英文，其他内容均用中文输出。
```

## 输出表格字段

| 字段 | 说明 |
|------|------|
| 原帖链接 | 推文 URL |
| 内容摘要 | 关于新模型的前后文（中文） |
| 模型类型 | 文生图 / 文生视频等（英文） |
| 模型名称 | 英文 |
| 发布厂商 | 英文 |
| 开源/不开源 | 开源 / 不开源 |

## 核心思路

在"找新词"列表（AI 相关 Twitter 账号）前一天推文中，自动识别所有 AI 模型发布信息，重点关注**文生图**和**文生视频**模型，快速发现新词机会。
