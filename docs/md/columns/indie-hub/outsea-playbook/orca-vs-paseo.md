# Orca vs Paseo / Herdr vs Paseo 统一回答

> 哥飞直播回答高频问题

## 核心结论

**Orca 和 Paseo 功能重叠度很高**，但定位不同：

- **Orca**：面向程序员的软件，提供全套源代码管理的开发环境
- **Paseo**：通用的 Agent 调度软件，新手更友好

**如果你是一个程序员，且 Agent 主要用途是编程 → 建议 Orca**
**如果你不是程序员 → 强烈推荐 Paseo**

---

## Herdr vs tmux

herdr 和 tmux 都是维持 Terminal 会话状态的工具，herdr 多了些 fancy 功能。

哥飞本人用的是 **iTerm2 的 -CC tmux**，不比 herdr 弱，没有切换需求。

---

## 总结

- 程序员：用 **Orca** 足够了，其他软件不需要
- 非程序员：用 **Paseo** 足够了
