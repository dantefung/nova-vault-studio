# 做外贸未来才可能翻身

外贸是我目前唯一看好的大行业。

十四五、十五五规划均专门提及外贸，十五五战略目标进一步升级为「加快建设贸易强国」——十四五「打基础」，十五五「上台阶」。

## 为什么国内卷不动了

- 产能过剩，内卷到几近绝望
- 失业、房贷锁定未来消费能力
- 全民消费力断崖式下降

国内狼多肉少，想在国内赚钱，不管哪个行业都是炼狱级的。

## 为什么老外有钱

中国家庭财富近六到八成是房产，而美国、日本仅 18%-25%。老外房贷占比较少，可支配消费资金比中国人多得多，并且老外爱消费，国外市场更有活力。

## 为什么现在做外贸是天时地利

- **一带一路**扩大了外贸朋友圈
- YouTube 上大量外国博主来中国旅游，「travel China」成外网最热门话题之一
- 老外对中国认知正在重塑，「中国制造」逐渐获得认可
- **广西平陆运河**开通，东南亚市场将兴起

## 结论

以前做外贸不好说，但现在做外贸是天时地利人和。

不要听失败者发牢骚。外贸肯定是大方向，必定诞生大批草根富豪。而且没有 35 岁年龄限制，值得后半辈子深耕。

如果现在还没方向，先找个工资低要求低的外贸公司做个业务员。赚不赚钱其次，先摸清行业框架和整套流程，路自然就知道了。
