# 我把公众号发文做成了一条命令

![image](./images/001.png)

每天发一篇，最累的从来不是写。

是写完之后那一堆事：配图、排版、传素材、登后台、点来点去。

所以我把它做成了一条命令。

## 1、这条命令做了什么

它把整个链路串了起来：

用 AI 生成一张封面图

把 Markdown 转成微信认的内联样式 HTML

封面传成永久素材，同一张图再插到正文最前面

自动补上文末的往期文章和公众号名片

调 API 进草稿箱，拿到 media_id

跑完之后，草稿箱里已经躺着一篇排好版的文章。

## 2、为什么不让它自动发表

微信有个freepublish接口，能直接正式发表。我没用。

原因很简单：它经常出现「搜一搜能搜到、但公众号主页和列表行为异常」的情况。技术上返回成功，运营上是个坑。

所以流水线只负责到草稿箱。最后那一下「发表」，留给人点。

## 3、我的操作？

日更保持这个节奏：机器做脏活，人做判断。

原创声明、赞赏、合集这些开关，微信 API 压根不给字段，只能在后台点。流水线干脆把它们列成清单，顺便按正文内容把合集名选好。

## 4、明日观察重点：

（1）这条流水线能不能扛住连续日更

（2）封面模型的稳定性

（3）文末往期文章的点击率变化
