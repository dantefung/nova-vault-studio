# SEO 黑科技：Video Keywords 和 Google 全家桶索引

## 1. Video Keywords

在 YouTube 拍视频介绍产品（How-to 教程、产品对比、工具评测），Google 对有意图的关键词经常直接出视频卡，小频道的视频有时能压过权威博客。

**核心要点：**
- 选**种子词**用产品**真实使用场景**，不要用硬广
- 这类词叫 **Video Keywords**

## 2. Google 全家桶快速索引（未验证）

把自己产品的文章挂到 Google 全家桶，据说可以很快被 Google 索引：

- Google Docs（公开文档）
- Chrome Web Store
- Google Drive
- NotebookLM

> 注意：此条未实践，真实性待验证。
