# 如何找关键词

## 一、找词渠道：9个入口穷尽关键词

| 渠道 | 方法 | 备注 |
|------|------|------|
| 谷歌下拉搜索 | 输入词根追加字母/单词 | 覆盖 photo/image/picture/pic/img 等同义词 |
| 谷歌相关搜索 | People also search for | 搜索结果底部推荐 |
| Similarweb | 关键词生成器/竞品网址查流量词 | 着陆页分析 |
| Semrush | Keyword Magic Tool | 按搜索量/KD/CPC筛选 |
| Ahrefs | Keyword Generator | 选国家拓展 |
| 谷歌趋势 | 搜索量上升/热门查询 | 最多25个，可链式拓展 |
| 平台下拉 | YouTube/TikTok等 | 各平台搜索框推荐 |
| 谷歌 Ads 规划工具 | **核心武器** | 基于语义，搜索量最权威 |
| 竞品反查 | Similarweb/Semrush/Ahrefs | 挖掘竞品流量词 |

**工具**：searchsuggest.tips、searchsug-extractor.com、keywordtool.io 可批量提取。

## 二、评估筛选：7步判断流程

1. **看搜索量** — 谷歌趋势/Ads规划工具/Similarweb 交叉验证
2. **看搜索结果** — 前10是首页还是内页。权重：域名>子域名>子目录>内页
3. **看整站/页面流量** — Similarweb 或 AITDK 插件查竞品
4. **看外链** — Ahrefs 查 KD 和竞品外链数。ROI = 流量 ÷ 外链数
5. **看 CTR** — Google Organic SERP CTR Curve 工具
6. **计算 KDROI** — 公式：KDROI = Volume × CPC / KD
7. **避开陷阱** — 季节词、谷歌直达、搜索量大但 KD 奇低

**核心逻辑**：搜索量小+竞争大→放弃；有搜索量+竞争大→蛋糕够大分一小块也有价值。

## 三、跨平台对齐

**原则**：以谷歌 Ads 规划工具为准（Semrush/Similarweb 数据也源于谷歌）

方法：
1. 所有渠道收集的关键词去重，一行一个填入 Ads 规划工具
2. 清空地理位置，选全球，拿谷歌真实搜索量
3. 同义词归组后用谷歌趋势+双引号对比各说法搜索量

## 四、AI 辅助：从关键词到网站

把 Ads 规划工具结果下载 CSV（选「方案历史指标」格式），删掉无关词，转 Markdown 丢给 Claude：

1. 让 Claude 做初步需求分析
2. 让 Claude 规划 SEO 友好的网站结构，列出所有页面 URL

完整链路：找关键词 → 理解需求 → 网站规划
