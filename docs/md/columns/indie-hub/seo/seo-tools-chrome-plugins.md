# SEO 工具链：流量分析 + 竞品监控 + Chrome 插件合集

> 来自 droidHZ（赫兹）的实用工具分享，覆盖竞品分析、广告监控、技术栈发现等场景。

## SiteData：全能网站数据分析插件

### 基础功能

Chrome 插件：[SiteData](https://chromewebstore.google.com/detail/site-data-seo-toolkit/siteroids-data-seo-checker/)，直接搜索结果页查看：

- 流量情况
- 网页基本情况
- 域名信息
- 导流搜索词

### Ads 投流反查

通过 Google Ads 投流反查，找到这个网站所有投流的人，同时也能看到这些投流的人投了哪些网站。

### Adsense 反查

查询某人所有接入 Adsense 的网站。

### 新功能：KGR 竞争度

安装插件后，搜索结果页直接显示 KGR（Keyword Golden Ratio），帮助评估网站竞争度：
- 月搜索量
- allintitle
- KGR 值
- Google Trends（直接在结果页展示，不用多次切换）

### Ads Title 查询

投流时标题很重要，决定用户是否会点击。使用 SiteData 查询完整广告标题信息：

1. 打开 [sitedata.dev/?via=droid](https://sitedata.dev/?via=droid)
2. 选择 Google Ads Analysis
3. 切换到 ads title
4. 输入关键字，点击搜索

### Ads 和 Adsense 监控

- **Ads 监控**：第一时间发现别人投的广告，快速找到性价比高的关键词
- **Adsense 监控**：可以发现一些新上线的网站

使用方法：头像 → Dashboard → Monitors → Add Monitor，可选监控 adsense（输入 publisher ID）或 ads（输入广告主名字），选择时间频率即可。

## Wappalyzer：技术栈分析插件

Chrome 插件：[Wappalyzer](https://chromewebstore.google.com/detail/wappalyzer-technology-pro/efaidnbmnnnibpcajpcglclefindmkaj)

进入网站加载一会，分析出这个网站使用了哪些技术栈，点击插件就能看到结果。平时查看竞品网站或者有趣的网站都可以看看，可以发现一些有趣的东西。

---

## Google Trends Everywhere：关键词趋势插件

Chrome 插件：[Google Trends Everywhere](https://chromewebstore.google.com/detail/google-trends-navigator/inflcalehpinjidhkeagkflfcaaochk)

基于搜索词，快速看到其他网站的 top 关键词。使用这个快速实现"词找词"。可以直接看到 DR，免费版本也可以看到一些页面数据。

---

## Ahrefs SEO Toolbar +AITDK

**Ahrefs SEO Toolbar**：Chrome 插件，会直接展示当前网站的 DR，点开可直接看到网站更多 SEO 相关的信息（部分功能需开会员）。

搭配 **AITDK**，这两个插件已经足够对网站进行初步分析。

## 工具组合

| 工具 | 用途 |
|------|------|
| SiteData | 流量分析、Ads/Adsense 反查、KGR、趋势 |

| Google Trends Everywhere | 词找词、关键词趋势 |
