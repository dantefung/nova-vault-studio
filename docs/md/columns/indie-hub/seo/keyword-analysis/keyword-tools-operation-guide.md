# 网站分析与关键词挖掘：工具操作流程与数据交叉验证

基于社区里的实操框架，这是对关键词工具使用和数据可信度判断的完整补充。与[上一轮指标清单](./keyword-metrics-overview.md)构成完整闭环：**指标清单告诉你"看什么"，本文告诉你"怎么拿到这些指标、拿到的数据能不能信"**。

---

## 一、关键词收集的 9 条渠道

### 1. 谷歌下拉搜索
免费，不断加前缀字母就能一层层挖出更细分的长尾词。缺点是没有搜索量数据，只能先收集。

### 2. 谷歌相关搜索（People also search for）
搜索结果底部的相关词区域，同样是免费拓展来源。

### 3. 谷歌趋势相关查询
"搜索量上升"和"热门"两个 tab 都要看，每次最多显示 25 个相关词，可以拿一个词继续滚雪球。

### 4. Similarweb 关键词生成器 & 着陆页分析
输入一个词得到相关关键词列表；也可以输入竞品网址，在「关键词研究 → 着陆页」里看到这个页面拿了哪些关键词的流量。

### 5. Semrush Keyword Magic Tool
输入一个词根得到相关关键词列表；也可以查某个具体网址的关键词。缺点：每次只能看一个国家，还需要分别切换 PC 端和移动端。

### 6. Ahrefs Keyword Generator
免费版不需要登录就能用，适合快速拓词。

### 7. Google Ads 关键词规划工具
最核心的一步，下面单独展开。

### 8. YouTube 搜索框下拉
直接从 YouTube 搜索框的下拉推荐里抓词。

### 9. TikTok 等平台搜索框
任何带搜索框的平台都能提供下拉推荐词——只要有搜索框，一般都会有下拉搜索关键词推荐。

> 收集完后，用表格工具去重，得到唯一关键词列表，再统一送入 Google Ads 关键词规划工具获取搜索量。

## 二、Google Ads 关键词规划工具：全流程与关键坑

### 两个核心功能

1. **发现新关键词**：输入一个种子词（如 `ai photo`），选择英语、删除已选位置（选择所有位置），点击获取结果。它基于语义，会给你很多你没想过的表达方式。
2. **获取搜索量和预测数据**：把收集到的唯一关键词列表一行一个填入，移除超长等不合要求的关键词后，得到每个词的月搜索量，以及预估单次点击出价区间（CPC）。

### 三个关键注意事项

**1. 默认地址要去掉**：工具会默认勾选一个地理位置，必须删除掉，才能拿到不受地区限制的全量搜索数据。

**2. 同义词会被归并**：Ads 关键词规划工具会把同义词归类到一起并给出相同的搜索量。此时必须借助谷歌趋势来进一步区分哪个更大。

**3. 谷歌趋势加双引号的技巧**：把两个候选词放进谷歌趋势对比，加上双引号后能看到更真实的差异。

### API 自动化：MCC 账号

如果想程序化获取搜索量，需要注册 Google Ads 经理账号（MCC），然后获取 Ads API Token。

## 三、搜索量数据到底信谁？终极答案

**终极答案：两家都不信，信谷歌的。**

逻辑链条：Semrush 和 Similarweb 的搜索量数据本身就是从 Google Ads 关键词规划工具拿来的，所以直接去谷歌那里查到的数据才是最准确的源头。谷歌趋势虽然没有绝对搜索量数值（只有相对热度），但通过找一个已知搜索量的词作为参照物进行对比，就能反推出未知词的搜索量。

## 四、交叉验证：不只是搜索量，而是整个竞品分析

**只看一个工具的数据就下结论是新手第一个也是最危险的错误。**

一个典型的翻车场景：在 SimilarWeb 上看到一个站月访 40 万，觉得好厉害，赶快反推它的词，结果花了半天时间抄了一堆词，做出来的站一个流量都没有。为什么？因为那 40 万月访可能根本不是 SEO 带来的——它可能是付费广告、社交流量、直接访问，甚至是工具误判。

**Jade 给出的核心方法论**：用 SimilarWeb 看竞品的搜索流量关键词列表时，要同时结合 Ahrefs 或 Semrush 复查同一个站的词，看两边的关键词列表是否重合。如果两边给出的词差异很大，说明至少有一边的数据有问题，不能盲目参考。

## 五、从竞品反推关键词的完整逆向操作路径

1. 在谷歌搜索目标关键词，打开排在前面的一两个竞品网页
2. 把竞品的网址复制到 SimilarWeb 的"关键词研究 → 着陆页"功能，看到这个页面从哪些关键词获取了流量
3. 也可以把网址输入 Semrush，查看关键词列表
4. 把从竞品那反推出来的关键词收集起来，再次回到整套流程中——去 Ads 关键词规划工具验证搜索量，去谷歌趋势看趋势，去谷歌看前 10 名竞争情况

### 容易被忽略的技巧

收集关键词时，尽量把同一种需求的每一种表达方式都覆盖到。比如图片，不只是 `photo`，还有 `image`、`picture`、`pic`、`img` 等不同的说法——每个说法背后都对应着独立的关键词和搜索需求。
