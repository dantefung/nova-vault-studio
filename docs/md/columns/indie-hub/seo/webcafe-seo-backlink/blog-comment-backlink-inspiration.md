# 基于博客评论外链想到的挖掘需求新思路


朋友们，关于挖掘需求，哥飞又有了一个新思路。

之前哥飞教了大家如何根据竞品网站的外链，找到可以发博客评论外链的网站 [https://new.web.cafe/experience/ao30ki8tzk](https://new.web.cafe/experience/ao30ki8tzk) 。

刚在想，所有会去发外链的网站，其实都是有利可图的，不然他就不会去搞外链。

如果我们把评论列表里的网站都抓取过来，再把域名注册时间、网站最近三个月流量抓取过来，也许就能够找出一些别人在偷偷赚钱，或者准备偷偷赚钱的产品。

通过分析他们的产品和关键词，也许就对我们有启发。

    你的思路非常有创意！通过挖掘那些发布外链的网站背后的商业逻辑，确实可能发现一些潜在的市场机会。我理解你的核心想法是:
