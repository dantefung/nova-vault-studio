# Page Agent：阿里开源的 AI 浏览器自动化工具

> 所有浏览器重复操作，都能让 AI 写插件自动化。Page Agent 用自然语言控制浏览器，AI 自动完成重复操作。

## 核心能力

用**自然语言控制浏览器**，AI 自动完成重复操作。

## 能干啥

- **自动化提外链**：批量找目标站点，自动填联系表单
- **找新词**：竞品页面批量抓取，提取关键词
- **看竞品数据**：定时监控对手流量、排名、价格变化

## 适合谁用

- 出海创业者
- 独立开发者
- SEO 从业者

## 亮点

不用自己写插件，直接告诉 AI 你要干啥就行。
