# 【系列实操】新手如何上自己的第一个Google Ads广告（二）- 学习期 —— 冉云

大家好，我是冉云。
【系列实操】新手如何上自己的第一个 Google Ads 广告（一）
接着上一篇的内容，我们继续来聊聊新手必踩的一个大坑——“学习期”。
每个新上的广告都会经历一个“学习期”的过程。表面上看，系统提示可能 5-7 天学习期就会结束，但很多人实操时会发现：怎么一个月过去了，我的广告居然还在学习期？
感觉学习期绝对是刚开始投广告的时候，新手最容易踩坑、也最容易焦虑的地方。所以这第二篇连载，我们就来详细说说面对学习期，该做什么，以及千万不该做什么。
一、 到底什么是“学习期”？
简单来说，这是一个谷歌系统在“认识并学习”你新广告的过程。
有一个很多人不知道的细节：在学习期内，甚至当你出价比竞争对手低的时候，系统也会给你的广告进行一个“加权”。谷歌为了测试你的广告效果，会主动帮你拿到一部分流量来进行学习和跑量。
二、 学习期“不该”做什么？（避坑重点）
由于学习期的特殊机制，我们在广告上线的初期，绝对不能频繁地改动广告设置。
任何核心改动都会导致学习过程中断，Google 会认为你每一次的修改都是在上一个“新广告”，然后直接重置，重新开始学习。这也是为什么很多人的广告过了很久都还是“学习期”阶段——因为你手太勤快了，频繁修改导致了频繁重置。
比如下面这些操作，如果不是发生了特别严重的错误，都最好是保持不动：
添加或删减关键词
修改单次点击价格（CPC）上限
改动广告的标题和描述
一句话总结：多观察，少操作。
所以在广告投放的初期，流量小、数据不稳定是非常正常的。看广告千万不要根据某一天的涨跌来判断怎么调，至少也得持续跑 4-7 天，才能看出数据曲线的形态，判断流量的真实趋势。
比如下面这个广告，在刚开始投放时，只要你不做任何干预和调整，它在学习期内一样能稳稳地走出自己的增长曲线。有时候做搜索广告，慢就是快。
三、 学习期期间，我们主要能调整什么？
既然不能乱动设置，那这几天我们就干看着吗？也不是。
学习期我们唯一能做、也最应该做的日常优化，就是去“搜索字词”报告里添加否定关键词。
去看看用户到底搜了什么词点进来的。一旦看到那些明显意图不对、转化率极低的词，凡是认为会影响转化和白嫖预算的，统统否定掉。
比如咱们最常见的：free（免费）、模版、教程这类词。看到就赶紧加否，别让他们浪费你的钱。
四、 什么时候才必须去修改广告？（什么是严重错误）
前面提到，除非有“严重的错误”才去更改设置。那什么叫严重错误呢？一般是以下三种情况，一旦发生必须马上处理，不用管是不是在学习期：
忘记设定预算上限： 比如一天消耗了超出你心理预期很多的钱，那必须赶紧去改预算。
广告 0 展示： 跑了一两天一点展现都没有。这通常有两个原因：一是 CPC 单价限制得太死了，需要稍微提升单价上限后再观察；二是词本身的搜索量实在太小了，那就必须去换词。
素材被拒登： 图片或者标题不符合规定被拒了，不用等，直接及时修改。
以上就是关于“学习期”的实操经验，管住手是度过这个阶段的关键。
