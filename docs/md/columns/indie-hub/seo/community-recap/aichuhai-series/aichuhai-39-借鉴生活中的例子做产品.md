# 网站出海每日分享：借鉴生活中的例子做产品

早上好，朋友们！今天分享一个做产品的思路：从现实生活里找设计灵感。用户用你的产品，是带着所有生活经验来的。设计越贴近他已有的认知，就越顺手，越不需要被教育。

![image](./images/001.png)

举几个生活里的例子：超市限购——"每人限购2件"，你可能只需要1件，但看到提示大概率会拿2件。稀缺感驱动行为。用在定价页上，就是"当前价格仅剩3个名额"，用户会被推着走。

快递实时追踪——快递在路上时你会反复打开 App 查进度，因为进度可见。AI 生成类产品如果只显示一个转圈的"处理中"，用户很容易关掉不回来。换成进度条、分步骤状态，用户会等，因为感觉"快了快了"。

餐厅菜单——菜单不标"￥"只写数字，减少花钱的感知。还会放一两道贵菜做锚点，让旁边的中等价位或者套餐看起来特别划算。定价页照搬即可：去掉货币符号，设计一个高价企业版，让用户觉得中间那档是捡到了便宜。

试吃——超市给一小块试吃，吃完大概率会买。产品里的免费额度是同一个逻辑。但很多产品免费功能太弱，用户没尝到味道就走了。试吃的关键是要给最好吃的那口，免费要开放到让用户真正感受到产品价值的部分，体会到啊哈时刻。

多留意一下身边让你 沉迷、消费的时候，背后大概率有值得借鉴的逻辑，可以直接用到我们自己的产品上。
