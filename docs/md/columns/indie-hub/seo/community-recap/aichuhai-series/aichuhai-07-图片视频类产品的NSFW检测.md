首先NSFW 检测对于生成类产品还是很有必要的，因为各个支付渠道如果检测到你网站能生成这样的内容，是会封你的支付，并且可能会罚款，之前哥飞社群就有人晒出来stripe 被罚来5万美金。

另外检测是在调用api 之前，避免用户生成NFSW内容了，我被api 平台扣款了，用户还看不到结果的情况。

## api 平台默认的检测

我的NSFW 的检测最开始是默认kie有个nsfw_checker 的参数，这个参数确实能拦截一部分内容，但是也会有漏网之鱼。

## creem 检测

你申请creem 支付时，会要求你调用他们的api 进行检测，但是只是文本的检测，图片如果本身有问题也是不能拦截的，而且最开始我还以为这个检测是免费的，后面扣款才发现是收费的，是会用了过了一段时间会把账单发到 /balances/activity 里面，价格算下来是 ：1000次 0.3美元，还是比较低。

## wavespeed 检测

这个是支持图片和文字检测的，价格是1000次 1美元。基本能够把绝大多数情况都拦截，但是也发现有人会用小语种越狱的，这种暂时还没有检测出来。另外还有一个坑是，api 支持文字和图片2个参数，但是如果同时传2个参数，应该是只检测了一个值，另外一个参数没有检测，导致失效。所以有图片和文字时要分开调用2次。

文档：wavespeed.ai/models/wavespeed-ai/content-moderator/image

目前我这个可能还不是最好的方案，其他朋友有更好的方式也欢迎推荐下。
