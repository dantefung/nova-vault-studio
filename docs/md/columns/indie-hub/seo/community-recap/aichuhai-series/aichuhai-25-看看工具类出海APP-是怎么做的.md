# 网站出海每日分享：看看工具类出海APP 是怎么做的

早上好，朋友们！想要尝试把网站产品做一个APP版本很久了，有网站用户咨询过我这个问题，也能拿到高质量的应用商店外链，还能有一个新的流量渠道。但是我一直停留在想的阶段，今天我们先来看看别人是怎么做这类的产品，我们以视频工具站为例，在他们的网站上找到对应的app。

首先还是看看我们出海的老大哥——pollo 的app。pollo 整体上来看非常的专业，花了很多心思和时间去做的，可以见下图

![image](./images/001.png)

首页：有很多各种各样场景的工具，预设好的模板，不同工具也有不同的实现。探索tab： 就是我们日常的一些提示词模板创作：功能和网页端的输入框一样，这个输入框里面还是很多逻辑的。智能体：看上去也是挺牛的我的：一些基础信息的编辑，生成、点赞的内容都在这里登录方式是支持苹果、Google、Facebook

再看一个实现上简单一点的app，更适合个人去做的

![image](./images/002.png)

首页是常见图片、视频、音乐、还有一些模型的生成器 加上一些视频特效具体的生成器输入框也和网页的很类似我的就是，生成、上传、收藏的一些东西。登录是google 和 苹果

看完这2个app，感觉也没有那么难，个人也可以去尝试下，个人猜测比较难的就是审核、登录、支付这几块吧，有做过app的朋友也欢迎补充讨论下呀。
