# 网站出海分享：开发产品前做一些价值判断

早上好，朋友们！最近similarweb找到一个词，hd photo converter，常规的一些竞争指标看起来还行，也很适合做成订阅产品。![image](./images/001.png)

然后我就去Google Trends 做一个验证，整体趋势是上涨，看起来不错，但是仔细看看国家，发现全是印度，如果去做了可能转化率会比较低，避免吭哧吭哧投入，没啥收益，所以还是要做一个价值判断，但是我还是会去把这个词作为内页，去观测一下数据，万一效果不错呐。![image](./images/002.png)

除了前面说的国家判断，其实还有很多维度可以去进行判断价值：

常见的就是cpc，这个是广告点击的单价，值越高说明你这个词也越值钱。

还可以去看看有没有人投广告，广告主的数量或者是广告持续的时间，时间越长说明在持续的挣钱。

去看前几名是套餐的价格，免费次数是多少，套餐定价多高，这里面的利润有多少。

使用场景的痛点是否足够痛，或者是使用频率是不是很高。

确定做产品之前还是要多评估下，毕竟这也是要实打实投入资源和时间的，能提早避坑就提早避坑，多看看竞争度、价值、实现难度之类的。大家有什么评估标准，也欢迎一起讨论。
