# 网站出海每日分享：stripe第一次遇到争议，应该怎么处理

早上好，朋友们！我Stipe 收款2000多单，昨天第一次遇到争议，还是一个下了很多单的正常用户，积分也用完了，我图省事就直接同意了（错误示范，而且即使同意也会扣15美元的争议费用的）。后面好几个朋友给了我一些建议，根据大家都建议和stripe 的官方政策，今天来分享一下stripe遇到争议应该怎么办。![image](./images/001.png)

官方的处理建议：如何预防争议最佳实践：docs.stripe.com/disputes/prevention/best-practices如何处理争议最佳实践：docs.stripe.com/disputes/best-practices

预防：开启雷达、3ds验证（之前也有分享过）提供服务协议、退款政策，购买前协议确认使用清晰的账单描述主动退还可疑项（这个我是发现用户什么都没有用，直接付款，可能会退款）订单确认邮件自动发送付款收据

处理：按照用户的时间线整理证据，不支持链接![image](./images/002.png)

一些朋友的实操建议：首先是联系用户，沟通争议，让用户取消争议，然后退款给用户，而且邮件的截图也是应对争议的一个重要证据。

即使不不处理，也不要主动点同意，stripe 会自动提交最基本的争议材料给发卡行，也有一定概率胜诉（但是自动提交争议证据这个功能要手动打开的，有手续费）

不要给用户开薅羊毛的口子，用户可能会反复过来薅羊毛。
