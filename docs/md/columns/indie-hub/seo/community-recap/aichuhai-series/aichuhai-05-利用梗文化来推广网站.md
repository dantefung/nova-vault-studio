# 网站出海分享：利用梗文化来推广网站

早上好，朋友们！昨天推特上刷到一个“滑动变祖器”的网站，玩了最近很火的梁组的梗，一天时间帖子都是百万流量，发现这类梗文化的产品传播流量非常大，感觉是可以在我们的产品中加入一些梗元素去吸引用户传播的。![image](./images/001.png)比如最近很火sbti测试，本身就融入了当下不少的梗，很抽象，吸引用户传播，所以很多群友做相关的蹭词站，流量也是非常大。还有一些测试类的产品，比如mbti、看手相 这类产品也会去蹭这样的梗。

还有前段时间，因为claude 大面积封号，有人又玩封号的梗，其实是一些各种环境的监测，这波流量其实就挺适合 vps、家宽、指纹浏览器、中转站来蹭这个梗的流量，去推广自己的产品。![image](./images/002.png)

玩梗推广的例子还有挺多：比如杜蕾斯的各种广告、疯狂星期四、多邻国哭泣的猫头鹰，“你是否在雪山救过一只狐狸”视频模板衍生推广自家产品......

那我们的产品要怎么玩梗推广 ？首先还是要关注热点事件，借着热点事件自动的流量，然后结合我们的产品去搞抽象，热点与抽象的结合更容易引爆裂变。

要做好分享裂变相关的能力，可以是一个个性化的抽象网页让人分享，可以是类似“雪山救狐狸”的视频特效结合我们的产品，也可以是“东北雨姐的codex皮肤”等，总之就是抽象、反差、带动情绪、钩子。

产品自身也可以考虑加上一些，有趣搞怪个性化的设计，模板，视频等，让用户忍不住去分享。维护好社媒账号，可以定期做一些带梗的推广内容。
