# 网站出海每日分享：挖掘优质的过期域名

早上好，朋友们！不知道大家有没有人忘记过续费域名，或者自己投入挺多的，就是不想做的域名。之前我听有大佬忘记域名续费了，被别人偷家了。最近还知道有人通过购买优质的过期域名，减少了不少外链投入还出单了。所以要是能够挖掘到优质的过期域名，其实可以省一些外链成本，甚至别人之前还给你的域名推广过。

那怎么发现优质的过期域名呐。搜索expireddomains，我发现com 和 net 域名的站流量都不小，com 180万流量，net 有65万流量，这2个网站就是挖掘过期域名的，你可以筛选不同的域名后缀、长度、过期时间、价格、是否适合SEO。然后去是不是有没有值得做（或者投资）的域名。

![image](./images/001.png)

除了用一些三方的服务，你还可以用爬虫搭建适合自己的域名过期监控，比如去抓取各个导航站的域名，然后用户一些免费的域名查询服务，获取到对应的过期时间。同时还可以加上一些其他信息帮助判断要不要入手，比如搜索词流量，ahrefs刚免费开发的DR查询接口。

![image](./images/002.png)

当然，这种用过的域名，一定不要忘记查询它的黑历史，可以用 virustotal.com 去查询有没有不良记录。
