# 2026-07-05 日收万刀神话再现，黑客松作品惊艳全场

今日概览
今天社群氛围热烈，两大事件点燃讨论。上午，leilei磊磊坦诚分享其AI视频站日收入突破1万4千美金的故事，从两年前一条2亿播放的TikTok视频起家，到如今两人团队冲击1000万美金ARR，让大家看到社媒冷启动结合SEO长尾流量的爆炸潜力。下午，哥飞主办的“上站黑客松”颁奖揭晓，特等奖作品imagetoascii.app以极富艺术感的ASCII图像转换设计惊艳众人，再次证明同词不同命，创意与执行决定上限。

leilei磊磊在社群分享了自己主力AI视频站近期的突破——昨天单日收入达到1万4千美金，而这一结果的起点要追溯到两年前。当时他用可灵制作了一个视频发到TikTok，意外获得全球2亿播放，涨粉数十万，顺势搭建了AI视频网站。初始社媒流量让网站“上线即转化”，但他强调SEO转化率更高、更稳定。目前核心收入仍来自去年布局的SEO长尾流量，最近上新的三个站还在广告学习期。全是两个人做出来的——他自己写后端、前端外包，后又找来技术合伙人。面对群友“月入万刀”到“日入万刀”的惊叹，他直言AI视频赛道正爆炸式增长，自己因为重度影迷持续热爱这个方向。对于想对标的群友，他半开玩笑地说“提前跟我打个招呼就行”，随后在合伙人要求下撤回了产品链接。哥飞忠告不必执着于看别人网址，天选之人只是因为自己就是那个天。leilei磊磊最后勉励大家多动手更新，目标冲击1000万美金ARR。

广告位微调让Adsense收益翻倍，PC端对联广告是关键
木寸长发现广告位的设计极大影响收益。他在一个流量很小的站点做测试：不再使用全屏100%宽度布局，而是在左右两侧留白，让Google能自动加载对联广告。仅这一改动，在相似展示次数下，日收入从0.67美元提升到1.26美元，直接翻倍。测例中，PC端广告收益甚至高于移动端。他谨慎地表示还需多观察几天确认效果，再搬到大流量站。同时他也在考虑在iframe内嵌广告，但害怕触发谷歌限流或封号——此前曾在登陆页误放Adsense导致被限流一个月。哥飞补充提醒，404页面同样不能放置Adsense，多位群友提示iframe内广告有风险。
