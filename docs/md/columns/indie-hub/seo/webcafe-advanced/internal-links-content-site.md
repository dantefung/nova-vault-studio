# 再聊内链和内页内容型工具站

> 来源：[web.cafe 进阶教程](https://new.web.cafe/topic/v2NENgATdt5a62SzVQUYY6)
> 作者：哥飞

大家听过哥飞无数次在群里说，有些关键词，别人靠内页，就能够拿到排名，如果我们做一个网站专门做这个关键词，举全站之力去优化这个关键词，那么假以时日，我们的网站也能够拿到排名，甚至超过那些内页，拿下第一名都是有可能的。方法是什么呢？什么是举全站之力呢？这跟内页和内链又有什么关系呢？这就是今天要跟大家讲清楚的问题。大家先看下半年前，哥飞发在公众号的文章：【哥飞解读】2024年谷歌算法排名因素变化。当时解读了2024年谷歌排名算法。其中有几条，我摘出来：1、持续发布吸引人的内容：权重21%；2、细分领域专长：权重14%；3、新鲜度：权重6%；4、可信赖性：权重5%；5、内部链接：权重2%。这五条，加起来权重是48%。哥飞为什么把这五条摘选出来？因为都是跟内页和内链相关的。只有持续发布吸引人的内容，搜索引擎才会认为你的网站是活跃的，有新鲜内容的。细分领域专长意味着你的网站要聚焦在一个垂直领域，而不是什么都做。新鲜度很重要，旧内容如果没有更新，排名会下降。可信赖性需要通过品牌建设、外链建设来提升。内部链接则帮助搜索引擎理解你的网站结构，权重传递。什么是内页？简单说，就是网站的子页面。比如首页是根页面，那么 /blog/xxx 就是内页。内页相比首页，权重通常较低。但如果一个内页获得了大量外链，它的权重也会提升。如何做好内链？1. 锚文本要多样化，不要都用同一个关键词。2. 内链要自然，不要刻意堆砌。3. 相关页面之间互相链接。4. 首页链接到重要内页。5. 文章之间互相链接。内容型工具站的关键：1. 内容要原创、有价值。2. 内容要持续更新。3. 内容要聚焦垂直领域。4. 内容结构要清晰。5. 要做好站内搜索优化。
