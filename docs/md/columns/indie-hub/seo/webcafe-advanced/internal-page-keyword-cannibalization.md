# 防止内页关键词蚕食

建内页过程中要注意防止关键词蚕食。

## 核心原则

防止内页和首页之间、内页与内页之间，关键词互相蚕食。

每个搜索意图全站只允许**一个页面**去承接。

## 关键词蚕食的判断方法

A B C 三个页面，如果 Google 判定这三个页面是「同一个 SERP 意图」，那么 Google 只会在这三个页面里挑一个排，其余的互相压制。

**一个关键词一个页面的前提是这些关键词落在不同的 SERP。**

## 如何判断关键词是否会蚕食？

直接看 Google 的搜索结果：

1. 你搜 A 词，看到 10 个 URL
2. 你搜 B 词，又看到 10 个 URL
3. 如果这两组 URL **大面积重合**，说明 Google 认为「搜 A 的人和搜 B 的人想要的是同一个东西」，所以 Google 给了他们同一批答案。既然是同一个问题，那就应该由**同一个页面**去回答
4. 如果两组 URL **几乎不重合**，说明 Google 认为这是两个不同的问题，需要两个不同的页面

## 参考标准（非硬性）

| 重合 URL 数 | 判断 | 行动 |
|-------------|------|------|
| ≥ 5 | 同一个 SERP | 必须合并成一个页面 |
| 3–4 | 灰色地带 | 通常合并，或做成主页面下的一个 section |
| 0–2 | 不同 SERP | 可以各建一个页面 |

## 另一种方法：使用 SEMrush

在关键词概览里，每个词都有「SERP 分析」模块，把几个关键词的 URL 列表拉出来对比即可。
