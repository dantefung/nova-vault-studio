# 获取外链的三种方法

## 1. 同类型网站筛选法

用 Semrush 查看竞品的反向链接，导出数据后用 Codex 做两轮筛选：
- 第一轮：去掉过期失效的链接
- 第二轮：保留带有 submit、form、blog 等明显提交入口的链接
- 最后人工验证

## 2. 循环积累法

换不同域名重复上面的流程，一天能筛出不少有效外链，靠日常积累慢慢做。

## 3. 花钱购买法

- 预算充足可以直接买高权重外链
- 或者付费写客座文章（Guest Post）
- 单条可能几百美金，但效果快且省事

## 博主建议

网站还没形成闭环前，先自己动手堆几百上千个外链，总会产生作用。
