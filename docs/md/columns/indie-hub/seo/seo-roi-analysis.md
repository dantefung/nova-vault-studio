# SEO ROI Analysis

判断关键词需求是否值得投入的多种方法。

## 判断方法

- 看 CPC
- 看搜索量
- 看搜索意图
- 看有没有人投广告
- 看排名靠前的网站是免费用还是收费
- 看收费网站价格套餐里的核心卖点
- 看排名靠前网站舍不舍得花钱买外链
- 在 Similarweb 看 Stripe 收银台域名的入站和出站流量
- 在 Similarweb 看其他支付收款平台域名的入站和出站流量
- 让 AI 搜索竞品公布的营收数据

## 核心思路

不需要每个关键词都用上所有方法，基本用上几个方法去查一下，就可以有大概判断。

## 重要提醒

如果看到某个关键词搜索结果里，竞品都没收费，并不意味着你不能收费。用户并不会货比三家，而是找到哪家就用哪家。只要价格合理，他们能够接受，就愿意付费。
