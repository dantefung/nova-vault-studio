# 产品营销推广

## 外链建设

首先要让 Cursor 输出你的产品基本信息，名字链接介绍文案长文案短文案，营销图片文案等等；

另外要再新建一个 Excel 来整理外链；

然后还需要让 Cursor 生成一些营销文案，比如这个项目需要做 Dribbble 的文案，你也可以做 Twitter 的文案；

最后每天提交推广产品外链。

**Tips**：可以找竞品抄作业，直接看竞品从哪个外链过来的流量最多，一个一个去提交，合作推广一样。

## 合作推广（重要）

### 思路

1. 去 Google 搜索你的关键词
2. 把排在前几页的网站全部点进去看是什么类型的网站
3. 找到能够推广你产品的排在前面的网站
4. 联系他们，看看是否可以合作推广

### 评估是否可以合作推广的标准

- 网站是否相关（是否是我们产品相关关键词搜索结果过来的）
- 网站是否有人气
- 网站是否愿意合作
- 网站是否愿意付费
- 网站是否愿意提供资源

如果可以合作推广，那么就联系他们，看看是否可以合作推广。

建立一个 Excel 来整理合作推广的网站，然后每天邮件联系维护这些合作关系。

### 合作推广的方式

**客座文章**：一些资讯站，可以找一些相关文章，然后联系站长，看看是否可以付费添加你的外链（比如 best weather apps icon 这种文章能不能把我的产品加进去，收多少钱）

**付费广告位**：按照上面的评估标准找到一些站长的联系方式，然后联系他们，看看是否可以付费在他的网站上推广你的产品（比如在他们的网站上添加你的产品链接，收多少钱）

**联盟营销**：自己开发 affiliate 后台，然后联系站长，看看是否可以合作推广。给合作方提供 UTM 链接，然后合作方推广你的产品，你给合作方提供佣金。

## 社交媒体营销

- 让 Cursor 生成一些营销文案，比如这个项目需要做 Dribbble 的文案，你也可以做 Twitter 的文案
- 自己去 Dribbble 发内容，然后去 Twitter 发内容，也可以找一些大 V 合作推广
- Reddit 评论，找到相关 Reddit，然后评论，留下你的产品链接。（注意可能删帖，需要自己长期实验）
