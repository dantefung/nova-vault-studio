# AI Product SEO Launch（AI产品SEO冷启动）

> 域名 1 月注册，5 月流量 576 万。付费搜索仅 0.02%。推客矩阵 + 产品粘性驱动自然增长，可复制性极强。

## Key Points

- **核心模式**：Prompt 版花瓣网 = AI 图 + 生成咒语，瀑布流展示，用户"逛"和"存"
- **增长飞轮**：推客带来首次访问 → 产品体验留住用户 → 用户收藏反复回来
- **变现模式**：积分包（一次性买断，积分永不过期），T3 国家为主
- **技术架构**：SSR + 程序化 SEO + 多引擎 API 聚合

## 产品定位

**Prompt 版的花瓣网**：瀑布流里是 AI 图 + 生成它的咒语，用户不需要创作，只需要"逛"和"存"。

核心需求：大量用户想要"同款效果"，但自己写不出那条 Prompt。

用户行为三件套：
1. **刷图** → 一键复制 Prompt 拿去自己跑
2. **生图** → 内置四个引擎（GPT Image 2 / Midjourney / Seedance 2.0 / NanoBanana）
3. **发图** → 作品被社区精选能赚积分，积分又能拿来生图

## 技术架构

### SSR + 前端渲染
- 服务端渲染提升 SEO 和首屏加载速度
- 前端瀑布流交互优化移动端体验

### 程序化 SEO
- 大量 AI 生成图片页面 + 对应 Prompt 内容
- 每个图片详情页都是独立 SEO 页面

### 多引擎集成
- GPT Image 2 / Midjourney / Seedance 2.0 / NanoBanana
- API 聚合，用户无需切换工具

### 积分系统
- 一次性买断积分包
- 社区贡献（发图）可赚积分
- 积分永不过期提升付费转化

## 关键洞察

1. **T3 市场策略**：印度等 T3 国家有大量"有手机但舍不得花钱"的互联网人口，积分制完美匹配

2. **移动端优先**：62% 移动端流量，优化手机端比桌面端更重要

3. **品牌即护城河**：68% 直接流量意味着用户已建立品牌认知，不需要搜索就能回来

4. **Prompt 经济**：用户愿意为"同款效果"付费，但不愿意/不会写 Prompt，这是核心痛点

5. **社区飞轮**：用户贡献内容 → 社区丰富 → 更多用户来访 → 更多贡献，形成正向循环
