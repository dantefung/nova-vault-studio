# 【哥飞SEO教程】新词老词都可以做，老词可以用长尾表达反向吃主词

大家好，我是哥飞。今天跟大家聊一个最近社群里分享过的话题：新词老词到底应该怎么做。先看一个真实案例。这个站，三个月前 1 月 16 日最高峰单日 26K 曝光，2.1K 点击，之后就一路下跌。后来站长持续发外链，慢慢涨回来了。到了 4 月 13 日，已经回到 43K 曝光，2.1K 点击。GSC 曝光点击恢复图而且这次曝光增加了。虽然点击率更低，但在我看来，其实是潜力更大了。因为它拿到了更多关键词的曝光，后面随着权重提升、排名提升、点击率提升，能够拿到的点击会更多。GSC 关键词曝光扩大图不过这里还有一个背景。从下半年上站到现在，半年多时间，这个站总共买了 $16K+ 的外链，算下来超过 11 万人民币。这些投入贵不贵？对于没赚过钱的新朋友来说，肯定贵。但从 ROI 角度看，其实是值得的。换个角度，即使这个站每个月只有 $2.5K 收入，半年也能回本。实际上，显然不止 $2.5K/月，所以实际回本周期会更短。从投资开店的角度来说，如果一家线下店投入 11 万，半年能回本，那绝对是很好的生意。但是，这对社群里的新朋友就很不友好了。刚开始学，还没学会，也没从网站赚到过钱，不敢花钱买外链，那怎么办呢？现在做站的三条路说实话，经过社群里这么多朋友两年多时间不断筛词、不断上站、不断搞外链，目前的现状的确是很多低垂的果实已经被采摘了。一两年前，有些关键词，并不需要那么多外链就能够拿到排名。现在需要更多外链了。所以现在就三条路：做新词，可以很少外链拿到排名；做老词，卷外链；做老词，卷体验，送积分甚至完全免费，把外链成本转换成 API 成本。当然，也可以 2 和 3 结合起来做。新词老词三条路先说新词。这是社群里很多新老朋友都验证过的路，只要上站速度够快，初期可以不用外链就拿到排名。当然，后面随着竞争加剧，你的先发优势会越来越弱，所以外链还是得买。但好在，你通过先发优势，已经拿到流量了，变现了，确认了是可以赚钱的，那么再花钱投入进去买外链，就不心疼了。新词到底出现多长时间算新？我觉得，半年一年内，其实都还可以卷。因为很多一开始拿到排名的站，会疏于防范，他们的外链其实都不强。我们花一些钱不断买外链，是可以拿到排名的。所以，如果你提前准备好了代码，提前做好了支付接入相关准备工作，在新词出来的第一时间开始动手，快速上站，的确可以抢到先发优势。但是，这并不意味着后面的人就没有机会了。我看了很多新词，搜索结果前 10 里，并不严格是按照域名注册时间排序的。也就是说，后发也可以先至。所以，不要因为自己没有第一时间上车而懊悔，只要你开始动手去做了，就有机会。老词不是不能做再说老词。老词其实也分蓝海词和红海词。可以通过 intitle 查看网页供应量来简单判断。网页越多，说明可能竞争越激烈。但这也不是绝对的。还要看参与竞争的网页权重高不高，以及参与竞争的是网站首页还是内页。如果一个老词，竞争不激烈，那么大概率就不是特别赚钱的领域。但是否特别赚钱，其实是公司团队化作战时考虑的指标。我们作为个人站长，即使不是特别赚钱的领域，其实也可以做。我们的目标不是吃下整个赛道，也不是做到行业第一。很多时候，每个月赚到几千刀、上万刀，就已经足够养活自己一家人。公司团队一般不会考虑这种需求，因为 ROI 太低。但我们个人可以做。我们之前说过，每一个关键词的搜索结果，就是一个排行榜。你的网站，其实是在这个排行榜里竞争。你不需要跟全世界所有网站竞争，只需要去研究排行榜里前几十个网站就够了。看到域名首页，是好信号还是坏信号？有一个秘诀，我一般不看 KD。我更喜欢看搜索结果里网站首页多不多。如果一个关键词的前两页搜索结果里，除了大站内页，还能看到一些独立站首页，那么这就是一个明确的信号。那这是好信号，还是坏信号？社群里当时也有很多朋友讨论。我的答案是：是不是好信号，还需要继续多看几个数据来判断。先看关键词搜索量大不大。如果搜索量很小，或者变现能力很差，那即使我们能做上去，也没多大意思，可以略过这个关键词，看下个关键词。如果关键词搜索量还是不错的，并且目前拿到排名的网站外链域名只有几百个，那么在我看来，就是一个好信号。这证明，新站是有机会能够拿到排名的，谷歌愿意给新站机会。我们去上一个站，做好体验，搞多外链，也同样有机会。关键词机会判断表有时候也会看到这样的情况：关键词的搜索量并不是特别大，搜索结果前 10 里，有独立站首页出现。但是这些网站的月访问量很低，才十几 K 或者几十 K，然后外链域名数量又很多，如超过 1K。这种我就认为，没必要去竞争了。别人有了 1K 外链，也还没拿到前 5 的排名，我们再投入进去就没多大意义，算 ROI 算不过来。简单总结：如果别人花了很大的力气，结果也没拿到多少访问量，而且潜力不大，那我们就略过这种词，多看看别的词。如果别人通过一定的努力可以拿到排名，而且市场潜力很大，这时候就不需要看 KD 了。管他 KD70 还是 80，都可以干他。这里我还想起 2023 年底看到的一个需求。当时判断力还没有现在这么强，看到首页出现了好几个域名首页，就觉得这事不好做，就没去做。但后续我一直观察这个词，发现排名其实是在变化的。有新的站冒出来，有老的站掉队，有的站排名在上升。虽然第一名一直都很稳，但是谁说我们就一定要做第一名呢？在一个已经被证明了只要有流量就有付费的需求下，我们不需要做第一。做老二老三，甚至老五老六，都可以。重中之重：长尾表达反向吃主词接下来是今天的重中之重。同一个需求，不同的用户会有不同的表达。有些表达搜索量大，有些表达搜索量小。这就意味着，有些表达，其实竞争并不会那么激烈。我们完全可以先去做这个竞争小的表达，拿下排名，得到流量，之后慢慢养着，就能够慢慢吃到越来越多的别的表达的关键词搜索流量。举例来说，某个需求，搜索量最大的表达是 A B C。但其实还会有人搜索 A B、B A、B C、B C A 等等各种词。那些大厂做网页，会挑搜索量最大的 A B C 来写页面内容文案。还剩下一些别的表达，他们可能会在页面的 H2 或者 H3 里覆盖，但是大概率不会专门上一个页面来覆盖，更不可能单独做一个网站来覆盖。如果此时，没有别的网页去做别的表达，那么不管用户搜索 A B C、A B、B A、B C、B C A 中的哪个词，搜索结果里出来的都是标题里含有 A B C 的页面。因为谷歌其实是有语义理解能力的，知道用户要找的是什么。即使标题不是完全匹配，也会在搜索结果中返回。当我们发现，谷歌会自动匹配别的关键词网页返回时，就说明其实别的表达，并没有网页专门去做，或者也许有网页做了，但是竞争力不强。这就是我们个人站长的机会。我们可以去瞄准某个表达来上站。举例，我们可以用 B C A 来注册域名，然后举全站之力来优化 B C A 这个词。网站首页的 Title、Description、H1，就瞄准 B C A 这个说法去做。不断上内页，不断搞外链，慢慢会发现，我们能够拿到一些关键词的排名了，有曝光，有点击。再继续搞外链，会发现排名继续上升，会拿到更多关键词的曝光。最终你会发现，有一天，你能够拿到 A B C 的靠前排名。长尾反吃主词示意图所以，做老词不一定要一上来就硬刚主词。先从竞争小的表达切进去。先拿小词，后吃大词。先拿曝光，后拿点击。先验证需求，再加大投入。怎么判断需求值不值得投入？好，那么接下来的问题是：怎么看一个关键词背后的需求，是否能够赚到钱，是否值得我们花钱投入买外链，是否值得花半年一年去做？方法很多。看 CPC；看搜索量；看搜索意图；看有没有人投广告；看排名靠前的网站是免费用还是收费；看收费网站价格套餐里的核心卖点；看排名靠前网站舍不舍得花钱买外链；在 Similarweb 看 Stripe 收银台域名的入站和出站流量；在 Similarweb 看其他支付收款平台域名的入站和出站流量；让 AI 有新的站冒出来，有老的站掉队，有的站排名在上升。



虽然第一名一直都很稳，但是谁说我们就一定要做第一名呢？



在一个已经被证明了只要有流量就有付费的需求下，我们不需要做第一。



做老二老三，甚至老五老六，都可以。



## 重中之重：长尾表达反向吃主词



接下来是今天的重中之重。



同一个需求，不同的用户会有不同的表达。



有些表达搜索量大，有些表达搜索量小。



这就意味着，有些表达，其实竞争并不会那么激烈。



我们完全可以先去做这个竞争小的表达，拿下排名，得到流量，之后慢慢养着，就能够慢慢吃到越来越多的别的表达的关键词搜索流量。



举例来说，某个需求，搜索量最大的表达是 A B C。



但其实还会有人搜索 A B、B A、B C、B C A 等等各种词。



那些大厂做网页，会挑搜索量最大的 A B C 来写页面内容文案。



还剩下一些别的表达，他们可能会在页面的 H2 或者 H3 里覆盖，但是大概率不会专门上一个页面来覆盖，更不可能单独做一个网站来覆盖。



如果此时，没有别的网页去做别的表达，那么不管用户搜索 A B C、A B、B A、B C、B C A 中的哪个词，搜索结果里出来的都是标题里含有 A B C 的页面。



因为谷歌其实是有语义理解能力的，知道用户要找的是什么。



即使标题不是完全匹配，也会在搜索结果中返回。



当我们发现，谷歌会自动匹配别的关键词网页返回时，就说明其实别的表达，并没有网页专门去做，或者也许有网页做了，但是竞争力不强。



这就是我们个人站长的机会。



我们可以去瞄准某个表达来上站。



举例，我们可以用 B C A 来注册域名，然后举全站之力来优化 B C A 这个词。



网站首页的 Title、Description、H1，就瞄准 B C A 这个说法去做。



不断上内页，不断搞外链，慢慢会发现，我们能够拿到一些关键词的排名了，有曝光，有点击。



再继续搞外链，会发现排名继续上升，会拿到更多关键词的曝光。



最终你会发现，有一天，你能够拿到 A B C 的靠前排名。



所以，做老词不一定要一上来就硬刚主词。



先从竞争小的表达切进去。



先拿小词，后吃大词。



先拿曝光，后拿点击。



先验证需求，再加大投入。
