# SEO New vs Old Keyword Strategy

现在做站的三条路：新词、老词卷外链、老词卷体验。

## 三条路

1. **做新词**：上站速度快，初期可以不用外链就拿到排名
2. **做老词，卷外链**：通过大量外链竞争
3. **做老词，卷体验**：送积分甚至完全免费，把外链成本转换成 API 成本

## 新词策略

- 只要上站速度够快，初期可以不用外链就拿到排名
- 新词出现半年一年内都还可以卷
- 先发优势会越来越弱，后续还是得买外链
- 通过先发优势拿到流量、变现后，再花钱买外链就不心疼

## 老词策略

- 通过 `intitle` 查看网页供应量判断竞争程度
- 看搜索结果里网站首页多不多判断机会
- 不要一上来就硬刚主词
- 先看搜索量、变现能力、对手外链和对手流量
