# SEO Homepage Signal Judgment

通过搜索结果里独立站首页的数量判断关键词机会。

## 判断方法

不看 KD，更喜欢看搜索结果里网站首页多不多。

如果一个关键词的前两页搜索结果里，除了大站内页，还能看到一些独立站首页，这是一个信号。

## 判断流程

1. **先看搜索量大不大**：搜索量很小或变现能力差就略过
2. **再看外链域名数量**：如果只有几百个外链就能拿到排名，这是好信号
3. **如果外链超过 1K 还没进前 5**：没必要竞争，算 ROI 算不过来

## 核心结论

- 如果别人花了很大力气，结果也没拿到多少访问量，且潜力不大 → 略过
- 如果别人通过一定努力可以拿到排名，且市场潜力很大 → 不需要看 KD，管他 KD70 还是 80，都可以干
