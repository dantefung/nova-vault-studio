# 不再望而生畏：金融衍生品的本质与核心逻辑简明介绍

“衍生品”这三个字听起来既高深又危险。

1. 小故事



假设你是一家果汁厂的老板，需要大量橘子。



夏天橘子便宜，冬天贵。你担心冬天橘子涨价导致成本失控，于是和果农老张签了一份合约：“三个月后，我以每斤3元的价格买你1万斤橘子。”



这份合约就是最原始的金融衍生品：远期合约。



在这个故事里面：



现货（标的资产）： 实实在在的1万斤橘子。



衍生品： 你和老张之间签的这份“三个月后，我以每斤3元的价格买你1万斤橘子。”的约定。



衍生品本身没有价值，它的价值是“衍生”出来的。



如果橘子三个月后它涨到了5元/斤，你赚2元/斤，这份约定就值20000元，因为你可以用3元/斤买到市价5元/斤的1万斤橘子。



当然如果价格下跌，你就亏钱。



这就解释了衍生品的核心特征：价值衍生、依附标的、交易未来、以小控大。它不创造新的资产，只转移价格风险、锁定未来收益。



金融衍生品，本质就是一份金融合约，其价值取决于一种或多种基础资产，如股票、债券、汇率、利率、大宗商品（黄金、石油）等的价格变动。



2. 衍生品的四大门派



虽然衍生品的数学模型千变万化，但在商业银行实务中，它们基本逃不出这四种基础形态。



我给它们起了四个形象的绰号：



⚪️ 远期（Forward）：私人定制的“君子协定”场景： 就像刚才说的买橘子。你和交易对手（比如企业客户）私下约定，未来某个时间，按某个价格买卖某种资产。特点： 灵活，想怎么定就怎么定（金额、日期、价格均可定制）。痛点： 因为是私下签的，如果对方跑路（信用风险），你就惨了。而且签完之后，你想转手卖给别人很难，流动性不强。业务关联： 银行给企业做的远期结售汇（锁定未来的汇率），就是典型的远期。⚪️ 期货（Futures）：标准化的“交易所门票”场景： 把刚才的“橘子约定”标准化。比如规定好：每份合约就是10000斤橘子，只能在每月15号交割，价格公开透明，大家都在交易所里喊价买卖。特点： 标准化、流动性好（随时可以转手卖掉）、有交易所作为中间人担保（不用担心对方跑路）。痛点： 不够灵活，只能按照交易所规定的标准来。业务关联： 银行自营资金去交易国债期货、利率期货，或者帮客户在境外做大宗商品套保。⚪️ 期权（Option）：付了“定金”的“反悔权”场景： 你相中了一套房子，跟房东说：“我给你1万块，你把这房子给我留一个月。一个月后，如果房价涨了，我按现在的价买；如果跌了，我就不要这1万块定金了，我不买了。”特点： 买方有权利，没义务（可以反悔）；卖方收了权利金，必须履行义务。痛点： 买方虽然风险有限（最多亏定金），但胜率低；卖方虽然稳赚权利金，但一旦市场大波动，可能亏到倾家荡产。业务关联： 这是银行最爱的工具之一。比如给企业做的“期权组合”，或者银行自营做的波动率交易。按执行时间分类：美式期权，可以在合约到期日之前的任何时间里执行；欧式期权，只能在到期日执行。按买入卖出分类：看涨期权（call option），赋予期权的所有者在约定的时期里以商定价格购买某种金融工具的权利；看跌期权(put option)，在约定的时期里以上定的价格卖出某种金融工具的权利。⚪️ 互换（Swap）：你家的米换我家的面场景： 你家有米，我家有面。咱们俩约定，以后每个月我都给你一袋米，你给我一袋面。在金融里，最典型的是“利率互换”：你有一笔浮动利率贷款（利息随市场变），你担心利率上涨，我有一笔固定利率贷款，我担心利率下跌。咱们约定，以后你付给我固定利息，我付给你浮动利息。这样，你就把浮动利率换成了固定利率，优化了负债结构，锁定了成本。特点： 交换的是现金流，通常是长期的。业务关联： 利率互换（IRS）是银行间市场成交量最大的衍生品，没有之一。几乎所有涉及利率风险的资产负债管理都会用到它。类型：货币互换，一种货币的一系列款项与另一种货币的一系列款项的交换；利率互换，一系列利率款项同另一系列利率款项的互换交易，所有的款项用相同的货币来计量。



⚪️ 远期（Forward）：私人定制的“君子协定”



场景： 就像刚才说的买橘子。你和交易对手（比如企业客户）私下约定，未来某个时间，按某个价格买卖某种资产。



特点： 灵活，想怎么定就怎么定（金额、日期、价格均可定制）。



痛点： 因为是私下签的，如果对方跑路（信用风险），你就惨了。而且签完之后，你想转手卖给别人很难，流动性不强。



业务关联： 银行给企业做的远期结售汇（锁定未来的汇率），就是典型的远期。



⚪️ 期货（Futures）：标准化的“交易所门票”



场景： 把刚才的“橘子约定”标准化。比如规定好：每份合约就是10000斤橘子，只能在每月15号交割，价格公开透明，大家都在交易所里喊价买卖。



特点： 标准化、流动性好（随时可以转手卖掉）、有交易所作为中间人担保（不用担心对方跑路）。



痛点： 不够灵活，只能按照交易所规定的标准来。



业务关联： 银行自营资金去交易国债期货、利率期货，或者帮客户在境外做大宗商品套保。



⚪️ 期权（Option）：付了“定金”的“反悔权”



场景： 你相中了一套房子，跟房东说：“我给你1万块，你把这房子给我留一个月。一个月后，如果房价涨了，我按现在的价买；如果跌了，我就不要这1万块定金了，我不买了。”



特点： 买方有权利，没义务（可以反悔）；卖方收了权利金，必须履行义务。



痛点： 买方虽然风险有限（最多亏定金），但胜率低；卖方虽然稳赚权利金，但一旦市场大波动，可能亏到倾家荡产。



业务关联： 这是银行最爱的工具之一。比如给企业做的“期权组合”，或者银行自营做的波动率交易。



按执行时间分类：美式期权，可以在合约到期日之前的任何时间里执行；欧式期权，只能在到期日执行。



按买入卖出分类：看涨期权（call option），赋予期权的所有者在约定的时期里以商定价格购买某种金融工具的权利；看跌期权(put option)，在约定的时期里以上定的价格卖出某种金融工具的权利。



⚪️ 互换（Swap）：你家的米换我家的面



场景： 你家有米，我家有面。咱们俩约定，以后每个月我都给你一袋米，你给我一袋面。在金融里，最典型的是“利率互换”：你有一笔浮动利率贷款（利息随市场变），你担心利率上涨，我有一笔固定利率贷款，我担心利率下跌。咱们约定，以后你付给我固定利息，我付给你浮动利息。这样，你就把浮动利率换成了固定利率，优化了负债结构，锁定了成本。



特点： 交换的是现金流，通常是长期的。



业务关联： 利率互换（IRS）是银行间市场成交量最大的衍生品，没有之一。几乎所有涉及利率风险的资产负债管理都会用到它。



类型：货币互换，一种货币的一系列款项与另一种货币的一系列款项的交换；利率互换，一系列利率款项同另一系列利率款项的互换交易，所有的款项用相同的货币来计量。

## 信用衍生品



如果说前四类衍生品主要管理的是市场价格风险（利率、汇率、股价波动），那么信用衍生品管理的则是交易对手不还钱的信用风险。



2008年金融危机中，CDS和CDO一度成为“罪魁祸首”的代名词，但事实上，信用衍生品本身是中性的，关键在于如何使用。



例如，你借钱给朋友，担心他不还。这时你找到保险公司，每年付一笔保费，约定“如果朋友违约，保险公司赔你损失”。这份保险合同，就是信用衍生品的雏形。它让你在不卖出债权的情况下，把“不还钱的风险”单独打包卖出去了。



所以信用衍生品的本质：用一笔费用，买一个“如果对方违约，有人替我扛损失”的安排。



信用衍生品诞生的意义在于，它让信用风险第一次变成了可以独立定价、独立交易的资产类别。银行不再只能被动持有贷款直到到期，而是可以主动管理自己的信用敞口。



1. 国际市场上的几类



⚪️ 信用违约互换（CDS）：最核心的品种



CDS（Credit Default Swap）是信用衍生品中交易最广泛、最基础的品种。信用保护的买方定期向卖方支付一笔费用（类似保费），一旦参考实体发生约定的信用事件（如破产、债务违约、债务重组），卖方需向买方赔付损失。



例如你持有某房企债券，怕它违约。你每年付 200bp 给交易对手，如果这家房企发生信用事件，对方赔你本金损失。



⚪️ 总收益互换（TRS）：把“收益权”换出去



TRS（Total Return Swap）的买方将参考资产（如一只债券）的全部经济收益（利息+价格涨跌）转移给卖方，卖方则向买方支付一笔基于浮动利率的回报。本质上，TRS让买方在不真正持有资产的情况下，获得或转移该资产的全部经济敞口。



⚪️ 信用联结票据（CLN）：可以流通的“信用保险单”



CLN(Credit-Linked Note)是一种嵌入了CDS的结构化债券。投资者获得高票息（低风险资产收益+信用保护保费），但若参考实体违约，可能损失本金。



投资人买一张票据，票面收益更高；但如果参考实体违约，本金会被扣减或用于赔付。



> 相当于：你买理财，收益高一点，但“挂钩某家公司会不会炸”。

⚪️ 信用价差期权（CSO）：对“信用利差”下注



以信用价差为标的的期权，赋予买方在约定时间以约定利差买入或卖出信用风险的权利。本质上是对信用利差的走向进行期权交易。



⚪️ 合成担保债务凭证（Synthetic CDO）：组合化的信用风险



将多个CDS或CLN打包成一个资产池，按风险高低分层（优先级、中间级、劣后级），不同层级承担不同的信用风险。这正是2008年金融危机中放大风险的核心工具之一。

## 银行业金融机构



## 衍生品交易业务管理



另外，监管机构的发文《银行业金融机构衍生产品交易业务管理暂行办法》中，对金融衍生品也有明确的定义和分类。



另外，监管机构的发文《银行业金融机构衍生产品交易业务管理暂行办法》中，对金融衍生品也有明确的定义和分类。



1. 定义



办法中定义，称衍生产品是一种金融合约，其价值取决于一种或多种基础资产或指数，合约的基本种类包括远期、期货、掉期（互换）和期权。衍生产品还包括具有远期、期货、掉期（互换）和期权中一种或多种特征的混合金融工具。



2. 分类



办法中说，银行业金融机构衍生产品交易业务按照交易目的分为两类：



（一）套期保值类衍生产品交易。即银行业金融机构主动发起，为规避自有资产、负债的信用风险、市场风险或流动性风险而进行的衍生产品交易。此类交易需符合套期会计规定，并划入银行账户管理。



（二）非套期保值类衍生产品交易。即除套期保值类以外的衍生产品交易。包括由客户发起，银行业金融机构为满足客户需求提供的代客交易和银行业金融机构为对冲前述交易相关风险而进行的交易；银行业金融机构为承担做市义务持续提供市场买、卖双边价格，并按其报价与其他市场参与者进行的做市交易；以及银行业金融机构主动发起，运用自有资金，根据对市场走势的判断，以获利为目的进行的自营交易。此类交易划入交易账户管理。
