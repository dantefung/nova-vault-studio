# 肉身到美国：银行开户与信用建立完整攻略

> 云居民最难搞的就是美国地址。换个思路：办美签、旅游时直奔美国，肉身到了什么都好办。

## 行程方案

1. 去新泽西州租间房
2. 用中国驾照考美国驾照（考科目一即可）
3. NJ 驾照到手 = 全美通用的顶级法定 Photo ID，卡面印有真实物理地址

## 银行开户与信用卡

### 1. Bank of America（美国银行 / BOA）

- 开立账户：Advantage Banking
- 同时线下申请信用卡 Customized Cash Rewards
- 立刻启动美国个人信用记录（FICO）

### 2. American Express（美国运通）

- 申请卡片：Blue Cash Everyday (BCE) 或 Amex Gold
- 用真实地址与 ITIN 直接在官网提交申请
- 审核宽松，出卡极快（通常 3~5 天平信寄达租住房）

### 3. Chase（摩根大通）

- 开立账户：Total Checking + Savings
- 养半年信用后申请 Chase Freedom 或 Sapphire 等经典卡片

### 4. Citi（花旗银行）

- 开立账户：Access Checking 或 Plus Checking
- Global Transfer 全球秒转功能极强，适合作为跨国资金流转的中转与备用枢纽

### 5. Wells Fargo（富国银行）

- 开立账户：Everyday Checking
- 作为全美大型四大行之一，增加一个独立的本土资金出入渠道

### 6. TD Bank（道明银行）

- 开立账户：Beyond Checking 或 Complete Checking
- 美东（尤其新泽西与纽约区域）网点密集、营业时间长（周末通常营业）

## 离美前需要完成的事项

### 1. 地址长期托管

离美前，将所有银行的邮寄地址切换为长期维护的转运地址，但居住地址不变，确保后续申请其他卡或更新卡片能平稳转运回国。

### 2. 开通 Paperless 与双重验证（2FA）

所有银行账户当场开通无纸化账单，并绑定能够长期全球漫游接收短信的美国本地实体电话卡（如 Ultra Mobile PayGo 或 T-Mobile 原生卡）。
