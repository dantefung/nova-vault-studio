# 利用 AI 给自己做个网站给养老吧，「躺」着把钱挣

> zlbigger 上次 AI 产品沉思录没能融到钱，这次**裸晒项目**——一个 `linggan.io` 全球多语言 AI 自动运营站点，14 张截图完整手把手教程。这是目前**最具体的"AI 躺赚"实操拆解**。

> 📖 **完整带图版**：[wiki sources 版](/md/wiki/sources/ai-website-lay-flat-income-zlbigger) 含 14 张关键截图
> 📘 **方法论提炼**：[concept-ai-lay-flat-income](/md/wiki/concepts/ai-lay-flat-income)

## 一句话核心

> **一个普通 CMS 系统 + AI 驱动 + 全球多语言 + 自动化**，让 AI 24 小时持续打工。

**本质**：**N 个 AI 打工人各司其职（写主题 / 出图 / 标题 / 标签 / description / 正文），定时任务调度，组合成完整内容页上线。**

## 4 步准备工作

| 步骤 | 操作 |
|------|------|
| 1 | 域名 + 空间（去国外平台买，便宜，不做国内可以免备案）|
| 2 | 成功开通 Google AdSense |
| 3 | 常用 AI 大模型的 API |
| 4 | 基础 SEO 知识 |

## 6 个 AI 打工人（核心流水线）

| # | 打工人 | 输入 | 输出 |
|---|--------|------|------|
| 1 | **写主题** | prompt | 完整主题描述（角色 + 服饰）|
| 2 | **画图提示词** | 主题 | 简化成英文 prompt JSON |
| 3 | **标题党** | 主题 | 5 语种标题 JSON（es/zh/jp/kr/en）|
| 4 | **分词高手** | 主题 | 5 语种标签 keywords JSON |
| 5 | **description 高手** | 主题 | 5 语种 meta description |
| 6 | **文本创作大师** | 主题 | 5 语种正文 JSON（HTML `<p>` 分段）|

**输出格式强制 JSON 多语种**，例：

```json
{"es": "...", "zh": "...", "jp": "...", "kr": "...", "en": "..."}
```

## 完整流水线

```
定时任务（每 5 分钟提交一个主题）
        ↓
[AI 打工人 1] 写主题（角色 + 穿搭）
        ↓
[AI 打工人 2] 简化成英文画图 prompt → 调图 API
        ↓
[AI 打工人 3] 5 语种标题
        ↓
[AI 打工人 4] 5 语种标签（keywords）
        ↓
[AI 打工人 5] 5 语种 description
        ↓
[AI 打工人 6] 5 语种正文
        ↓
组合 → 上线
```

## 5 个 URL SEO 设计铁律

| 页面 | 规则 |
|------|------|
| **首页** | 每个语种一个子路径：`/en /jp /kr /zh /es` |
| **首页 301** | 默认首页对应的子路径 → 301 重定向到 `/`，避免重复内容惩罚 |
| **内容页** | `/<lang>/page/<角色>-<风格>` —— friendly URL |
| **内容页 URL 部分** | 统一英文，不翻译成多语种 |
| **标签页** | `/<lang>/tag/<本地化标签>` —— 标签要翻译 |

## 两种运行模式

### 手动模式

后台输入主题或批量导入上百个主题，AI 打工人按顺序执行，组合成完整页面上线。

### 全自动模式（真·躺赚）

写一个**定时任务**，让 [写主题] 打工人自己写主题，然后再交给其他打工人按顺序完成。

**建议频率**：每 5 分钟提交一个主题 → 每天 288 个内容页。

## 成本拆解（看作者怎么"白嫖"）

| 项 | 成本 |
|---|------|
| 域名 | ¥100/年 |
| 空间 | 白菜价（搬瓦工 etc.）|
| Cloudflare | 白嫖基础功能 |
| 文本生成 API | 用低级模型 ≈ 免费 |
| **图片生成 API** | 成本不低（但"要动脑子想办法"）|

## 关键金句

> **「成为一个拥有十万用户的套壳产品显然比拥有自有模型却没有用户更有价值。」**

> 本质不在于「一定做 AI 应用」，**在于「AI 能帮你干很多事情」**。

> 写成详细架构 + 启动流程：[concept-ai-lay-flat-income](/md/wiki/concepts/ai-lay-flat-income)

## 启动路径

1. **选一个有流量的主题**（动漫角色穿搭、宠物 × 服装、古风 × 美食 etc.）
2. **搭 CMS**（WordPress / Strapi / 自研都行，关键是结构化字段）
3. **招 6 个 AI 打工人**（写主题 / 出图 / 标题 / 标签 / desc / 正文）
4. **定时任务调度 → 上线 → 流量**

剩下的交给定时任务，**3-6 个月就能看到流量起来**。
