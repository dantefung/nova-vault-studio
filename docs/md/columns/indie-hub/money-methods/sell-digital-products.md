# 同样一份资料，国内卖19，国外卖9刀？ 这个副业太适合普通人了

最近一直在看数字产品这块。

越来越觉得，现在普通人搞副业，真可以试试电子资料。

比如：

PDF

AI Prompt

模板

工作流

表格

教程

资料整理

这些本来就是文件。

做出来后国内国外都能卖。

而且，同样一份东西。

国内卖 19.9。

换成英文版本放国外。

可能就是 9 美元。

尤其 AI、效率工具、模板这些。

国外很多人对数字产品付费会自然一点。

所以现在挺多人在搞：

一份内容。

国内卖一次。

国外再卖一次。

—

如果能做网站的，可以自己搭建个网站来卖，

再在社交平台引流。

不会自己搭网站的，

国内有个专门卖数字资料的网站， 好多人在使用，

叫链动小铺：https://pay.ldxp.cn/ 。

它可以让人在上面开店，通过它开通个人支付宝和微信收款，

手续费跟其他家比也还可以。

原本小红书上卖虚拟资料的有各种限制，通过这种方法一样也可以卖。

然后我顺手看了一圈国外卖数字产品的平台。

Payhip、Gumroad、Sellfy、Stan Store、Beacons。

看完以后最大的感觉就是：

这些平台其实完全不是一种东西。

—

### Gumroad 算是国外比较多人知道的平台。

很多卖：

Prompt

模板

PDF

AI 教程

的人都在用。

它有个地方挺方便。

就是上东西很快。

传个文件。

定个价格。

基本就能卖。

而且它确实有一点平台流量。

有些国外用户会直接在上面搜东西。

所以刚开始没流量的时候，用它会轻松一点。

不过后面我发现它手续费也不低。

现在 Gumroad 直链销售大概是：

10% + 0.5 美元。

Stripe 或 PayPal 还会再收支付手续费。

刚开始卖的时候可能感觉不明显。

后面订单多了以后，会越来越肉疼。

—

### 我比较喜欢用 Payhip, 看中的是它的免费版。

它有点像：

手续费更低一点的 Gumroad。

免费版现在是：

5% 平台费。

29 美元/月的套餐是 2%。

99 美元/月是 0%。

支付手续费还是 Stripe / PayPal 另外算。

整体会比 Gumroad 低不少。

但它平台流量很弱。

基本还是得靠自己导流。

不过它特别适合接独立站。

现在很多网站其实都不是自己开发商城。

而是：

网站负责内容和 SEO。

Payhip 负责：

收款

自动发货

下载

邮件

税务

这样会轻很多。

尤其个人做副业的时候。

不用一开始就折腾支付系统。

—

### Sellfy 给我的感觉有点像轻量版 Shopify。

页面会比：

Gumroad

Payhip

更像商城。

它现在是月费制。

22美元/月起。

平台费是 0%。

比较适合后面想认真做品牌的人。

比如：

Prompt 商店

模板品牌

数字资源站

这种。

不过它也基本没平台流量。

所以更适合已经有一点流量的人。

—

### Stan Store 和 Beacons 就明显是另一种路子。

更偏：

TikTok / Instagram creator。

很多海外博主会：

主页挂链接

卖课程

卖咨询

卖模板

移动端体验会不错。

但它不太适合做 SEO。

如果主要靠：

TikTok

Instagram

Shorts

那它们挺合适。

但如果是想做：

博客

工具站

内容站

我自己还是更偏 Payhip。

—

Prompt

支付直接走 Payhip。
