# 边走边看，边干边学，判断标准，在实践里找

前两天加入了哥飞社群，干 web 出海。全职梭哈干。

泡在哥飞出海的资料里，大概过了一遍，直接上站。

实践过程中，我发现自己对于需求判断、这个词是不是能做，我还是模糊的。

正好最近也在发推，搞 X 自媒体，我就直接发了自己的想法，得到了推友的回复：

> 有没有效的判定标准是能不能帮你更靠近目标，做一个贝叶斯主义者，每次行动后用结果调整你的策略，不断提高实现目标的可能性。

是的，有没有效的判断标准，我突然就明白了，需要在实践中调整。不断提高对出海建站的认知，感知得靠不断地熟悉。

当思维很清晰，学习和做事逻辑很熟练，就知道自己处在什么阶段了，拖延不存在了，知道自己该干啥，也知道给自己安排事。

搞钱和搞流量，总得有一个在干吧。

不知道怎么提升的时候，我就写公众号，发推吧。
