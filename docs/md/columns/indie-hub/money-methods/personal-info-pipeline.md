# 构建独特信息流

## 社媒信息的本质问题

现在社媒上本质都是大众群发的各种内容，热点就是大公司的，还有八卦绯闻。整体上没什么价值，而且很多都是利益相关——别人打广告费，获取我们的注意力来变现。

## 解决方案：构建主动推送的信息渠道

从龙虾出来之后，我就在构建一些信息源渠道。**构建信息渠道本质就是让优质信息主动推送给你，那么它就不会过时**。

把一些非常好的历史过往内容，定时发送，推到自己手机上看就好了。

当然也有很多各种聚合的信息平台，但那些本质上都依赖于别人未发送的、不确定的质量内容——比如别人可能发过广告，而且还要去其他平台上看。

## 龙虾的信息推送方案

- **网站相关内容** → 放飞书
- **信息相关内容** → 放 Telegram

**首推是记忆承载的所有历史精华文章**，每天定时三五篇推送。也可以通过邮件渠道。

## 核心原则

1. **手机上看信息最方便**
2. **信息要主动找我**，而且都是确定性的高质量内容，或符合我品味的
3. **而不是不确定性的**——等别人写出来的，有可能是广告或各种频道的信息，纠缠在一起，等待你的点击，骗取眼球的

## 书籍的独特价值

书籍也优于被动接收的社交信息。自己打开主动去翻，跟被动接收信息去看，还是两种感受的。因为很多信息来了，还是有一个强迫症，想把那些都消掉——红点、信息数字，全部都看一下。但书看不看都在那里，要一页页翻。

## 干货类的现状

干货类的现在主要都靠 Agent 来去梳理执行了，更多的还是认知相关的。整体上各种不会过期的优质信息还是很多的，比如很多企业家的发言理解。但是有一些可能要结合当时的形势会过期。

**所以还是要自己去主动筛选**，想看哪些信息，然后定时每天三五篇推送就好了。
