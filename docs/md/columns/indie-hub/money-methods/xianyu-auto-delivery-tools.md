# 闲鱼虚拟商品自动发货：两个现成工具一站搞定

> 做闲鱼虚拟商品，想要自动发货但自己不会搭建？分享两个别人已经搭好的网站，登录闲鱼账号、设置商品发货内容，就能自动发货。

## 背景

闲鱼虚拟商品（资料、模板、教程等）的痛点在于：每笔订单都要手动发货，量大之后非常耗时。自己搭建自动发货系统需要一定的技术能力，对于只想专注卖货的人来说成本太高。

解决方案：直接使用别人已经搭好的平台。

## 推荐工具

### 工具一：易店

- **地址**：`https://ed.weeeg.com`
- **类型**：商业化平台
- **特点**：开箱即用，功能完整，适合不想折腾的人

### 工具二：智年博客开源版（在线版）

- **地址**：`https://xy.zhinianboke.com`
- **类型**：开源项目的在线托管版
- **特点**：基于开源方案，有社区支持，数据相对透明

## 使用步骤

1. **登录闲鱼账号**：在平台中绑定自己的闲鱼账号
2. **设置商品发货内容**：为每个虚拟商品配置对应的发货内容（网盘链接、文件等）
3. **开启自动发货**：平台会自动在买家付款后发送发货内容

设置非常简单，不需要任何技术背景。

## 安全提示

> **重要**：使用别人搭建好的平台，安全性需要自己判断。
>
> - 需要授权登录闲鱼账号，涉及账号安全
> - 虚拟商品的发货内容（如网盘链接）会存储在第三方平台上
> - 建议：评估平台的口碑、运营时间、用户评价后再决定是否使用
> - 敏感资料可以考虑自建方案（如开源的 xianyu-auto-reply）
