# 互联网行业地图

同一个产品能力，放在不同行业里值钱程度差好几倍。行业决定了你的天花板，也决定了你要跟谁抢。

读完你能回答

*   为什么有些行业里做得再好也长不大
*   各个行业盯的核心指标为什么不一样
*   AI 这一轮真正撬动的是哪几块，哪几块没动

2000 年到现在，从 PC 到移动，主要行业的市场划分基本定型了。这不意味着没机会，而是机会的位置变了：存量行业里，新玩家要靠效率或者细分人群切入；增量位置在出海、企业服务和 AI 应用这三块。

## 各行看的指标不同

选行业等于选了一套判断标准。同一个功能上线，电商看的和内容看的完全不是一个数。

| 行业 | 核心指标 | 这个指标背后的意思 |
| --- | --- | --- |
| 电商 | GMV、转化率、复购 | 每一步流失都是钱，链路优化是主战场 |
| 内容 | 时长、完播、供给量 | 内容断供比功能不好用更致命 |
| 社交 | DAU/MAU、关系链密度 | 人在这里因为别人也在，产品好坏是次要的 |
| 企业服务 | 续费率、客单价、回本周期 | 能不能续费，比新签多少更能说明问题 |
| 工具 | 付费转化、留存 | 用完即走，要么高频，要么沉淀数据 |

换行业的人最容易栽在这里：把上一份工作的指标习惯带过来，盯着一个在新行业里说明不了任何问题的数。

## AI 打开的口子

这一轮真正被撬动的，是那些「以前要靠人手工做、量又大」的环节。看一个方向有没有机会，就看它里面有没有这种环节。

撬动了

内容生产 客服与售后 代码与设计 翻译与本地化 数据整理 营销素材

共同点：结果有标准答案的空间很大，做错了成本可以承受，量大到雇人不划算。

基本没动

线下履约 供应链 金融合规 医疗诊断 建立信任 谈判与关系

共同点：出错要担责，链条里有实物或者监管，或者根本问题就不在效率上。

你想做的东西如果整个落在右边，AI 帮不上什么忙；如果左边的环节占了工作量的大头，那就是这一轮的机会所在。

换行业的人最容易栽的地方在另一处：**把上一份工作的指标习惯带过来**，盯着一个在新行业里说明不了任何问题的数。电商看链路转化，内容看供给量，社交看关系链密度——同一个功能上线，各行看的完全不是一个数。

## 怎么选

三条能过滤掉大部分不靠谱的方向。

*   **先看阶段，再看规模。** 存量行业规模再大，新玩家能拿到的也是边角。宁可选一个小但还在长的方向。 
*   **选你有信息优势的那个。** 你待过的行业、身边人的真实困扰，这些是你和别人的差距所在。产品方法论人人能学，行业里的门道学不来。 
*   **算一遍你要抢谁的饭碗。** 如果答案是巨头的核心业务，换一个。如果答案是「原来没人做，因为人工成本太高不划算」，那就对了。
