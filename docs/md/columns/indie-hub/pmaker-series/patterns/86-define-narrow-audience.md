# 目标用户收窄

## 目标用户收窄

用户描述得越宽，能做的判断越少。窄到能想出一个具体的人，产品才有形状。

你会遇到的现象

*   做功能时总在纠结「有的人可能要，有的人可能不要」
*   产品什么人都能用，但什么人都不会特意选它
*   写文案时写不出具体的话，只能写「更高效」这类词

宽泛的用户描述之所以让人安心，是因为它把市场规模写得很大。但那个数字是幻觉——你并不能同时满足其中任何两拨人的具体需求，因为他们的处境不一样。

**窄的真正好处是能做减法。**知道用户一定用手机、一定在户外、一定戴着手套，你就能果断放弃很多设计上的可能性，剩下的方案自然就少了。

## 往哪个方向收

收窄不是随便切一刀，是沿着「会改变产品做法」的那些维度切。

| 沿这个维度收 | 它会改变什么 |
| --- | --- |
| 使用场合 | 在工位上还是在路上，决定了屏幕大小、单手操作、能不能被打断 |
| 熟练程度 | 老手要快捷键和批量，新手要引导和默认值。两者的界面几乎相反 |
| 数据量级 | 管十条和管一万条，是两个产品。搜索、筛选、分页全都不一样 |
| 一个人还是一群人 | 协作一旦进来，权限、通知、冲突处理全都要有，复杂度翻几倍 |
| 付钱的是不是本人 | 自己掏钱看性价比，公司报销看合规和发票 |

按年龄、性别、城市这类人口属性去切，通常切不出有用的差别。切完之后如果产品做法没变，说明这一刀切错了地方。

窄的真正好处不是「更聚焦」这种口号，是**能做减法**：知道用户一定用手机、一定在户外、一定戴着手套，你就能果断放弃一大批设计上的可能性，剩下的方案自然就少了。

## 怕市场太小怎么办

宽的做法

面向所有自由职业者

潜在市场：很大

实际转化：每个人都觉得「差不多但不完全适合我」

大市场 × 极低转化 = 没有用户

窄的做法

面向用微信对接的设计师

潜在市场：小很多

实际转化：「这就是给我做的」

小市场 × 高转化 + 口碑 = 有用户

先在一小撮人里做到不可替代，再往外扩。反过来做几乎没有成功的：一个谁都能用的产品，很难后期变成某群人的首选。

判断收得够不够窄，有个土办法：你能不能列出五个符合描述的真人，并且知道去哪儿找到他们。列不出来，就再收一层。
