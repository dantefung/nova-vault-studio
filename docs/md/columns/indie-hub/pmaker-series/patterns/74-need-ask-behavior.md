# 问行为不问意愿

## 问行为不问意愿

人预测不了自己将来会做什么，但记得住自己上周做过什么。所以只问过去，不问将来。

你会遇到的现象

*   访谈时对方一直点头，做出来他不用
*   问卷结果很好看，转化率对不上
*   问完一圈，笔记里全是形容词，没有一件具体的事

不是用户在敷衍。人在回答假设性问题时，脑子里模拟的是一个理想版本的自己——那个人有充足的时间、没有惰性、愿意学新东西。真实的那个人下周会照旧用他熟悉的老办法。

还有一层：被问的人会想让你好过。你花时间来问他，他不好意思说这个东西没用。**问意愿，等于邀请对方说客气话。**

## 怎么换问法

规则很简单：把所有「会不会、想不想、需不需要」，换成「上次、当时、怎么做的」。

| 别问 | 改成 |
| --- | --- |
| 这个功能你会用吗 | 上次遇到这个情况是什么时候，你当时怎么处理的 |
| 你愿意为它付费吗 | 你现在在类似的事情上花钱了吗，花了多少 |
| 你觉得这个设计怎么样 | 你现在试着完成这件事，我不说话，你边做边讲 |
| 你多久用一次 | 最近一次是什么时候？上一次呢？ |
| 你希望增加什么功能 | 最近哪一次让你觉得特别麻烦，麻烦在哪一步 |

倒数第二条尤其有用。问「多久用一次」得到的是估算，问「最近两次分别是什么时候」得到的是频率的真实样本。

## 哪些信号最硬

按可信度排一遍，你就知道该往哪个方向追问。

访谈的目标是尽量往上面两格挖。听到「我现在是自己弄一张表」这种话，比听到十句「很重要」都值钱。
