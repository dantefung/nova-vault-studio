# 指标体系怎么搭

## 指标体系怎么搭

指标体系是一棵树：顶上一个代表方向，往下拆到能被单次改动影响的那一层。

你会遇到的现象

*   看板上二十个数，不知道该盯哪个
*   做了个功能，说不清它该让哪个数变好
*   两个人说的「日活」不是一回事，对不上账

## 先定一级

一级指标要跟产品目标一致，而且随生命周期变。同一个产品在不同阶段，顶上那个数是不一样的。

| 阶段 | 业务重点 | 一级指标 |
| --- | --- | --- |
| 引入期 | 打磨核心功能，获取第一批用户 | 总用户数、次周留存 |
| 成长期 | 激活并留住已有用户 | 活跃度、留存率 |
| 成熟期 | 商业变现 | 付费转化、客单价、GMV |
| 衰退期 | 提效降本，找新增长点 | 获客成本、利润、新方向的验证数据 |

常见的一级指标分六类：收益型、获取型、活跃型、留存型、传播型、复合型。选的时候问一句：这个数改善了，是不是意味着产品真的变好了。

还有一条筛选标准：**指标必须是可改进的。**你无法通过任何策略调整去影响的数，盯着它没有意义。

「日活」之所以常常对不上账，是因为一个完整的指标由三部分组成：**时间周期 ＋ 修饰词 ＋ 原子指标**。缺了时间周期没法对比，缺了修饰词就不知道算的是哪种行为——打开算活跃，还是点了内容才算。

## 往下拆

| 拆法 | 怎么用 |
| --- | --- |
| 按 AARRR 拆 | 获取、激活、留存、收益、推荐，每段设二三级指标。适合看整条链路 |
| 按用户流程拆 | 照着用户实际走的步骤逐段设指标。适合定位卡在哪一步 |
| 按 OGSM 拆 | 目标、绩效、策略、度量。强调区分过程指标和结果指标 |
| 按 OKR 拆 | 目标加关键结果，再把每个关键结果拆成具体指标 |

过程指标和结果指标要分清楚。结果指标（订单数、收入）滞后且很难直接干预，过程指标（搜索转化率、优惠券领取率）才是你能动手优化的地方。

## 一个指标要定义清楚

指标的歧义是团队里最常见的对账问题。一个完整的指标由三部分组成。

近 7 日＋浏览＋文章数量

时间周期

修饰词

原子指标

缺了时间周期就没法对比，缺了修饰词就不知道算的是哪种行为。「日活」之所以常常对不上账，就是因为没定义清楚：打开算活跃，还是点了内容才算。

指标确定之后，写成一份指标字典：名称、口径（怎么算）、限制维度。团队里所有人查同一份，才不会各说各的。

## 一个人做产品的简版

*   **一级只要一个。**探索期就是次周留存，别的都先不看。
*   **二级三到五个。**对应主流程的关键几步，用来定位问题出在哪一段。
*   **三级按需加。**发现某一段有问题时，再往下拆那一段，不必一开始全铺开。
*   **每个都写清口径。**哪怕只有你自己看，三个月后也会忘。
