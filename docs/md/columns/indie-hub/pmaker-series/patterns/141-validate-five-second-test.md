# 五秒测试

[首页](https://pmaker.space/index.html)/[验证与迭代](https://pmaker.space/index.html#yanzheng)/五秒测试
五秒测试测的不是好不好看，是「第一眼能不能建立起心智」——三五个陌生人的答案，比一群自己人的长篇点评更能暴露问题。

## 五秒测试

首屏的信息传达，五秒就定生死。找个没接触过产品的人，让他看五秒，然后问三句话：**这是什么？我能得到什么？我该做什么？**答不上来，就是首屏没讲清。

你会遇到的现象

*   用户第一眼不知道这是干什么的，要靠小字慢慢猜
*   首屏堆满了功能入口，没有一句在说「这是什么」
*   自己看久了觉得哪都懂，换个陌生人就懵

## 五秒在测什么

五秒测试测的不是好不好看，是**信息传达**：用户在这五秒里，有没有建立起「这是什么产品、关我什么事」的心智。

*   **只测首屏。**五秒只够看完第一屏。第一屏没讲清的，后面的屏再精彩，用户未必看得到。
*   **测的是「留不留下」的那个瞬间。**它验证的是用户愿不愿意继续往下走，不是用户会不会付费、会不会注册。
*   **答不出来的原因通常是信息太多。**首屏试图同时讲十件事，等于一件都没讲。堆功能不等于传达价值。参见[一屏一件事](https://pmaker.space/patterns/one-screen-one-job.html)。

## 怎么做

流程简单，难在选对人、问对问题：

五秒测试

对象 没接触过产品的人 同事、用户都不行

时长 只看五秒 看久了就不是第一印象

提问 这是什么 / 我能得到什么 / 我该做什么 三问定生死

样本 三到五个人 够暴露问题，别等「量」

回答里出现「大概」「可能是」这样的词，和「不知道」一样，都说明没讲清。

*   **找没接触过的人。**同事、已注册用户都不行——他们已经「知道这是什么」了，测不出信息传达。样本脏了，结论就脏了。
*   **严格五秒。**看一眼就收走。看久了就变成「仔细阅读测试」，测的是阅读能力，不是第一印象。
*   **问的是开放问题。**别给选项，别提示。他说出「这是个做笔记的软件」，说明讲清了；他说「呃，一个网站」，说明没有。
*   **三五个人的答案就够判断方向。**五秒测试是暴露问题的定性检查，不是给结论的定量依据——别拿它当统计调查。定量的事交给[真实数据](https://pmaker.space/patterns/real-data.html)。

严格五秒，看一眼就收走。**看久了就变成「仔细阅读测试」**，测的是阅读能力，不是第一印象。也别拿它当定量依据——它是暴露问题的定性检查，三五个人的答案就够判断方向。

## 答不上来怎么办

三个问题答不上来，对应的修法不一样：

*   **答不出「这是什么」→ 首屏缺一句能概括产品的表达。**加一句白话说清产品的一句话定位，而不是摆更多功能入口。参见[一句话产品](https://pmaker.space/patterns/one-sentence.html)。
*   **答得出「是什么」、答不出「我能得到什么」→ 价值被功能列表盖住了。**把「对我有什么用」从「有什么功能」里挑出来，放到看得见的位置。
*   **前两个都对、答不出「我该做什么」→ 缺一个明确的下一步。**首屏要有且只有一个主入口，别让用户自己找。参见[首次体验设计](https://pmaker.space/patterns/first-run.html)。
*   **修完再测一遍。**五秒测试的好处就是便宜：改一版，再找三个人，十分钟出结果。循环到三问都能答上为止。
