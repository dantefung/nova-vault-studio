# 1688跨境电商一件代发怎么发货

> Dropshipping 在国内称"一件代发"，是"无货源模式"的一种。很多卖家用1688作为货源平台做跨境电商起步或测品。

## 1688一件代发全流程（使用店小秘ERP）

### 第一步：授权与绑定

注册店小秘ERP → 将1688账号授权给ERP → 登陆1688点击【立即续订】→ 完成授权，开启跨境铺货。

### 第二步：出单前——跨境铺货

通过链接采集或插件采集，将1688商品批量认领到速卖通、Temu等跨境店铺：
- 商品标题、图片、描述、价格、规格一键同步
- 可用ERP的图文翻译、批量改价、图片白底/换背景等功能做二次优化

### 第三步：出单后——1688采购代发

商品出单后：
1. 从1688购买同款产品
2. 留下客户地址及面单
3. 让供应商直接发货给客户
4. 将供应商发货单号填入订单
5. 后续出库、配送、签收状态同步监控

## 1688一件代发常见问答

**Q：如何避免陷入价格内卷？**
争取更低供货价，同时对采集的商品信息做二次优化（图、标题、描述）。

**Q：任何1688店铺都支持一件代发吗？**
不。采集前先确认供应商是否支持一件代发及代贴面单，商品详情页一般会注明。

**Q：售后问题如何解决？**
合作前沟通售后政策（无理由退换、仅退款、质量问题退货退款等）。

**Q：筛选供应商有何建议？**
- 优先选带"诚信"标志的供应商
- 观察资质和资历信息
- 从评论区侧面了解服务质量
