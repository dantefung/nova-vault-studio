## 核心概念速查

- **Dropshipping / 一件代发**：商家不囤货，有订单后供应商直发客户
- **MOQ**：最小起订量
- **POD**：按需打印/定制
- **SKU**：库存量单位
- **ERP**：企业资源管理系统（如店小秘）
