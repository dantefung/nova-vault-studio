# 创业反直觉：大众认知相反的五件事

> 赚钱的节奏、C端产品、情绪、工作的累、人脉——这五件事的大众认知都是反的。

## 1. 赚钱的节奏

赚钱像登山，勤奋重要，但走一走需要登高望一下前方的路，不要一直埋头不看路。方向错的勤奋，越勤奋错的越多。

**破除执念的方法**：多去大自然，感受自己的渺小，用"常识"去思考，而不是比拼"智商"。

> 反直觉：不要追逐风口，不要焦虑。常识比智商有时候管用很多。不做自己不擅长的事情，就大大降低了创业失败的概率。

## 2. C 端产品的未来

人与人之间的差距不在于短期几周或几个月要比你强，这种短期的强弱靠勤奋就可以获得。人与人之间的差距在于能否把一件事情坚持 5 到 10 年。

**坚持的根本**不是让你去吃苦，而是让你"独处"，获得独特的品味。

> 反直觉：放轻松，做自己，不要着急。你的品味，那个独特的你，才是 C 端产品最后做好的关键。

## 3. 让情绪传过去

喜欢你和讨厌你的本质不是情绪，情绪只是表现。情绪深挖 5 层原因的本质是**利益**。

- 喜欢你 = 你让用户的利益扩大了
- 讨厌你 = 你让陌生人的利益受损了，或者他们通过诋毁你获得流量和利益

> 反直觉：根本没有对错，根本没有情绪，有的只是利益。用理性对抗情绪，想对策怎么做取舍让自己的利益增加，而不是和对方争对错，掉入人性的陷阱。

## 4. 工作的累

真正让你身心疲惫的不是工作，体力活还是脑力活好好睡一觉肯定可以解决。真正让你累的是"**人际关系**"。

> 反直觉：你的能力越大，你就越不容受环境的影响。能力或资源不足，破碎的人际关系才让你身心俱疲。

## 5. 世界上不存在人脉

成年人只有利益和独处。如果你能力不足，大佬的微信也没用。很多人做任何事情都是为了满足"中国教育那种无处不在的竞争和危机感"。

> 反直觉：好好赚钱，好好读书，好好增强自己。当你自己足够强大的时候，资源会因为利益自己来找你，到处投机的参加各种局是创业最浪费时间的事情。
