## 一句话核心

> 5 大类工具，国内皆可用，**都有免费额度，且额度用完换下一个继续免费用**。

**核心心法**：不用纠结选哪个，先用起来；不用纠结订阅，月度免费额度足够"一次性需求"使用。

## 5 大类工具总览（国内优先）

| 类别 | 国内推荐 |
|------|---------|
| **文本** | **Kimi**（出题/文档解读）+ 豆包/文心一言/通义千问/元宝/智谱清言 |
| **图像** | **Liblib**（中文 SD 生态）+ WHEE（免费额度）+ 豆包文生图 |
| **图像修改** | **百度 AI 图片助手**（去水印/抠图/变清晰/提取线稿）|
| **视频** | **快影**（每天免费）+ 即梦 + 海螺 AI |
| **音乐** | **网易天音**（带曲谱编辑）+ QQ 音乐 AI 做歌 + 海绵音乐 |
| **语音** | **通义听悟**（会议/播客转写）+ ttsmaker |

## 核心心法：额度轮换

**作者原话**：

> 这个额度用完了，可以换一个地方继续免费用。

**实操思路**：
- 注册 N 个工具账号
- 每个用满免费额度
- 个人月度需求全覆盖
- 不订阅任何付费

## 信息差变现 3 个高阶玩法

### 1. 工具目录（最浅）

工具目录 → 公众号/小红书 → 返佣 + 流量。

### 2. 教程课程

工具教程 → 视频课程 → 付费用户。

### 3. 垂直工具集成

自建工具 → 集成上游免费 API → 一站式服务 → 用户订阅。
