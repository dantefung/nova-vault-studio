# 出海选品工具导航

> 发现 Web 需求的工具集合，按使用顺序排列：找方向 → 验证流量 → 验证付费

---

## 工具概览

| 工具 | 网址 | 用途 | 适用阶段 |
|------|------|------|----------|
| [Columbus Tools](https://columbus.tools/ai-rank) | columbus.tools/ai-rank | AI 产品榜单、流量增长、收入、外链、关键词 | 找方向 |
| [Traffic.cv](https://traffic.cv) | traffic.cv | 新网站、增长榜、月访问量、流量来源、收入信号 | 验证流量 |

| [Toolify](https://toolify.ai) | toolify.ai | 大型 AI 工具目录，分类/新品/榜单 | 找方向（灵感库） |

---

## 使用顺序

**第一步：找方向** — Toolify、Columbus

- [Toolify](https://toolify.ai) — 大型 AI 工具目录，按分类、新品、榜单寻找产品。做灵感库用，观察赛道拥挤度。
- [Columbus Tools](https://columbus.tools/ai-rank) — 看 AI 产品榜单、流量增长、收入、外链和关键词，寻找近期增长较快的小网站。

**第二步：验证流量和获客方式** — Traffic.cv、SiteData

- [Traffic.cv](https://traffic.cv) — 查看新网站、增长榜、月访问量、流量来源和收入信号。很适合判断一个方向到底有没有流量。*注意：数据属于模型估算，并非网站后台数据。*
- [SiteData](https://sitedata.dev) — 竞品研究专用。查关键词、流量渠道、Google Ads、AdSense 关联站点和 WHOIS 信息，适合顺藤摸瓜研究一个赛道的产品矩阵和获客方式。

**第三步：验证付费意愿** — TrustMRR

- [TrustMRR](https://trustmrr.com) — 查看 SaaS、App 和数字产品的收入、增长与出售价格。部分收入通过 Stripe、RevenueCat 等支付平台验证，适合判断用户是否真的愿意付费。*留意数据是否仍在持续更新。*

## 快速参考

```

验证流量：Traffic.cv → SiteData（看流量和竞品）
验证付费：TrustMRR（看收入和增长）
```
