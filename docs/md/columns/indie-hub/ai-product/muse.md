# Muse：帮每个人造自己想要的世界

> 我们压根不知道人们会想要什么。这个世界从来都是少数疯子折腾出来的，他们也说不清怎么回事，反正就是能把脑子里的念头变成真的。

## 核心理念

**说不出口，就实现不了。**

大多数人对自己想要什么，说不出口。不是不想要——一直都在想，拼了命地想。但念头还没出声，就在琐碎里磨没了。世界是座迷宫，到处是表格、审批、排期、障碍。

## 产品愿景

要是每个人身边都有个替你操心的助手：
- 你说不清的，帮你理清
- 你嘟囔一句，助手秒懂，帮你把后半句补上
- 帮你列计划、发邮件、打电话、找钱、盯进度
- 能清的障碍全清，能解的问题全解，一路干到底

到最后，留给你的只剩人才能干的事：**去想，去渴盼。**

## 目标

> 八十亿人，只要把想要的写下来，就能动手去干。

让每个人心里那团火，全着了。
