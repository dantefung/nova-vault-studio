# 为什么我们要把 Agent 引擎从自研换成 AgentScope

> AgentScope 迁移系列第 01 篇。团队从自研 Agent 引擎迁移到 AgentScope 的决策过程、踩坑记录与核心结论。

---

## 文章要点

- 自研 Agent 引擎的痛点：重复造轮子、缺乏生态、维护成本高
- 为什么选择 AgentScope：阿里开源、Java 原生、生态完整、Spring AI 兼容
- 迁移后的收益：开发效率提升、功能快速补齐、社区支持
- 需要权衡的问题：框架锁定、学习成本、定制化限制
