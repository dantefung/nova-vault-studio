# 任意 AI 模型可用的手绘风视频 Skill

做了一个手绘风格的动效 skill，用 DeepSeek 最新模型就能制作。

## 为什么手绘风

之前做过好几个动效 skill：

- **地图动效 map-motion**——旅行视频里的地图动画，从地球俯冲到某地、路线一笔描出来、飞线、行政区高亮，一共 14 种镜头
- **产品宣传片**——给产品做宣传片，logo 和截图自己去官网扒，内置 8 种动效风格
- **讲解视频**——把一篇文章做成 3 分钟的口播讲解，配音用自己克隆的声音

但做得越多，心里越别扭。这是上周做的一支宣传片：米白底、衬线大标题、卡片一张张滑进来，最后一面图片墙斜着铺满屏幕。

单拎出来挺精致，看多了就会发现：它就是一个会动的网页，还是 AI 做的那种网页。

**大家的片子都长这样。** 字一行行淡入，卡片从下面浮上来，镜头推一下拉一下，一页一页翻，像在放 PPT。模型最熟悉这一套，你不管它，它就往这个方向做。

画面很满，看完什么也记不住。缺的是一点灵魂。

那什么样的画面会更有特点？我想到的是自己文章里的配图。我的文章经常配手绘风格的图，框画不正，箭头有点抖，反而让人愿意多看两眼。讲东西讲得最好的场景，也是一个人站在白板前，边讲边写，讲到哪画到哪。

所以把最喜欢的手绘风格做成了视频。从写稿、配音到每一笔画面，都是一个 skill 做的，只说了几句话。

## 01 十种画风

这个 skill 配了 10 种风格。挑几个最喜欢的：

- **黑板**：墨绿底加木框，字和线带粉笔颗粒，那支笔也换成了一截粉笔
- **水彩**：米色水彩纸，墨线勾边，框和圈画完会自动晕开一层淡彩
- **水墨**：宣纸纤维，墨线边缘洇开，朱砂红做强调，笔是一支竹杆毛笔
- **霓虹**：近黑的底，线和字都在发光
- **漫画**：粗黑线，每场一圈分格框，重点字放进黄底黑框，便利贴变成对白气泡
- **蓝图**：深蓝底加网格，白色细线几乎不抖，像工程图，笔是一支黄色铅笔
- **笔记本**：横线纸、红色页边线，蓝色圆珠笔写字，红笔圈重点
- **牛皮纸**：粗蜡笔在牛皮纸上画，线和字都带蜡的颗粒

10 种风格对应不同场景：

| 风格 | 笔 | 适用场景 |
|------|-----|---------|
| 白板 | 马克笔 | 产品介绍、功能讲解 |
| 黑板 | 粉笔 | 讲原理、课程 |
| 水彩 | 水彩笔 | 故事、旅行、品牌片 |
| 蓝图 | 铅笔 | 架构、流程、技术方案 |
| 笔记本 | 圆珠笔 | 学习笔记、复盘、教程 |
| 牛皮纸 | 蜡笔 | 亲子、生活方式、手作 |
| 漫画 | 马克笔 | 讲故事的产品片 |
| 软木板 | 马克笔 | 案例拆解、线索梳理 |
| 水墨 | 毛笔 | 国风、历史、诗词 |
| 霓虹 | 霓虹笔 | 科技发布、游戏预告 |

## 02 实现原理

画面是一个网页，给它一个时间，它就把每个元素摆到这一刻该在的位置。

**无头 Chrome 每隔 1/30 秒截一张，ffmpeg 拼成视频。** 2 分 44 秒的片子，是 4900 多张截图。

手绘的感觉来自这几处：

- **手写字**：Excalidraw 的中文手写字体「小赖」，一个字一个字露出来
- **抖动的线**：rough.js 给端点加一点随机偏移，再描两三遍，加粗成马克笔的样子
- **跟着走的笔**：每一帧算出笔尖此刻停在哪个字、哪段线上，把笔挪过去
- **无限画布**：每场是画布上的一块白板，镜头按平滑缩放的路径飞过去，离得远就先拉远再推近

## 03 怎么用

skill 已经开源：`SpaceZephyr/space-handdrawn-motion-video`

装好以后，给 Agent 说一句：

```text
用黑板风格，把这篇文章做成一条 3 分钟的讲解视频，配音用我的声音，镜头用无限画布。
```

测试过在国内模型和海外模型效果都不错。

**可以用在多种场景：**

- **科普讲解**：把一篇文章做成 3 分钟视频，每个概念画一张图
- **产品宣传**：官网抓截图贴在白板上，一个功能一个功能讲
- **发布会预告**：30 秒短片，动感配乐，转场卡点
- **口播的 B-roll**：口播讲到流程、对比、架构时，切一段手绘图解
- **课程培训**：每节课开头一张知识地图，边讲边画
- **出海内容**：英文配音，中英双语字幕

比例支持 16:9、3:4、9:16 和 1:1，横版发 B 站，竖版发视频号和抖音。

它会自己读文章、写每一场的旁白、配音、校对读音、按关键词排画面，先截每一场的结尾帧自查，没问题再逐帧渲染，最后混音、做封面。
