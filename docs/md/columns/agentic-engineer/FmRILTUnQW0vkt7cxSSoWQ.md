# Agent 已经会干活了，下一步是让它自己变强

现在行业里讲 Agent，最常听到的词是 Human in the loop——人在回路里，Agent 做一步，人看一步，人审批、人纠正、人兜底。这个模式没错，但它有个硬伤：人不可能 24 小时盯着。



一个没人盯着的 Agent，自己改了自己的行为，你怎么知道它改好了还是改坏了？出了问题谁负责？我更认同的路径是：受控的自进化。



什么叫受控？就是 Agent 在真实业务里跑，跑完之后系统自动收集它的工作轨迹和人工反馈，然后做三件事：把事实存成 Memory，把可复用的方法整理成 Skill，再经过评测和审批，决定要不要更新到 Agent 的能力里。



关键在于：有边界、可回滚。经验不是自动生效的，得过评测；能力更新不是立刻全量的，得审批；表现退化了，能一键回滚。



对于 Agent 来说，经验积累，就是持续提升学习能力，这项能力大致沿着这样一条路线发展：任务内适应 → 长程连续运行 → 跨会话记忆 → 经验技能化 → 评测驱动的自进化 → 多 Agent 集体进化



不是一夜之间变聪明，是一步一步、可控地变聪明。当这套机制扩展到多个 Agent、设备和用户时，一个数字分身学会的方法，还可以经过汇集、去重和验证，转化为团队乃至组织的共同能力。



以上说的这些，都是我在学习《自进化 Agent 工程实战》专栏时提炼出来的，讲师是 Tyler，国内头部大模型团队的算法负责人，自己带数字员工平台团队。



他这个课程主线是围绕一个长期在线的 On-call Agent 展开，案例都是来自一线实战。为什么选这个？因为每个工程师都懂值班是什么感觉——半夜告警、查日志、定位问题、改配置、写复盘。



这个场景里天然包含了：长任务、权限边界、高风险操作、人工审批、事故复盘、经验沉淀。所有 Harness 要解决的问题，这个场景里全有。

## 这门课怎样展开？



这门课不只是讲几个 Agent 技术名词，而是沿着一个 Agent 的能力成长，拆成五个篇章，带你一步步走完从“会行动”到“会进化”的过程。



### 01 初识 Harness：让 Agent 学会行动



从 Codex 入手，拆解 Agent Loop、运行时控制和上下文引擎。



你会看懂 Agent 如何决定下一步、调用工具、处理结果，以及模型每一轮究竟能看到什么，从而找到工程师真正能够干预 Agent 的关键位置。



### 02 长程运行：让 Agent 持续工作



当任务从几轮变成几十轮、几百轮，如何管理上下文？如何利用过去的经验？如何让规则持续生效，又不把所有信息塞进上下文？



这一部分将围绕 AGENTS.md、上下文压缩、会话分支、Skill、渐进披露，以及隔离与审批机制展开，让 Agent 从“完成一次任务”走向“长期值守”。



### 03 经验回流：让 Agent 从工作中学习



任务结束之后，经验如何留下来？



课程将转向 Hermes，讲解后台复盘、Memory、历史会话检索、外部知识接入和 Skill 演化，让一次有效的排障经验，逐渐变成可以复用的事实和方法。



### 04 验证改进：让 Agent 进化得更可靠



会学习还不够，还要知道自己有没有变得更好。



通过 Skill Curation、业务 Eval、A/B 测试、安全恢复和离线优化，让新的方法经过评测、审批和版本管理；效果退化时，也能够及时回滚。



由此建立可观测、可验证、可回滚的受控 RSI 闭环。



### 05 群体进化：让经验成为团队能力



最后借助 SkillClaw，让不同 Agent 的经验能够汇集、验证和共享，并按照岗位、项目和权限边界进入下一次任务。



最终，你将完成一个完整的自进化 On-call Agent：持续工作、积累经验、引入新能力，并在效果退化时回滚。



贯穿课程的能力进度是：连续行动 → 长程值守 → 积累经验 → 验证改进 → 共享能力。每一步都对应具体的工程问题，带你结合真实挑战，掌握自进化 Agent 设计与落地方案。



## 写在最后
