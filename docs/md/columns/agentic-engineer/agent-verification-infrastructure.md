# 为什么你用 AI Agent 越用越累？因为你把自己活成了系统最大的瓶颈

> SpaceX 工程师 Lauren Tan 的分享：连单个 Agent 的输出你都无法信任，就别妄想调动上百个 Agent 协同作战。

## 核心观点

如果你没有把"验证机制（Verification）"沉淀成工具与技能，那你就是那个肉眼找 Bug 的人工瓶颈。

从"每行代码都要人肉盯盘"到"单月自动化合并 1,000 个 PR"，核心演进路径：

```
人肉盯防 → 规则验证 → 技能封装（Skills）→ 评测体系（Evals）→ 自动合并（Auto-merge）
```

## 关键结论

对 Agent 的信任从来不是一种主观感觉，而是**必须亲手搭建的代码基础设施**。
