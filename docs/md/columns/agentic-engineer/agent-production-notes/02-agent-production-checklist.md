# 你的 Agent 离生产级还有多远？一份开箱即用的体检清单

> 生产实战笔记系列第 02 篇。5 大病灶对照代码自查，三期改造方案落地。

---

## 五大病灶

| # | 病灶 | 典型表现 |
|---|------|---------|
| 1 | **上下文失控** | 长对话丢失早期信息，Agent 答非所问 |
| 2 | **工具裸奔** | 工具调用无预算、无防护、可被恶意触发循环 |
| 3 | **RAG 检索「过敏」** | 关键词命中即召回，无关内容污染上下文 |
| 4 | **单点阻塞** | 一个专家挂了整个 Supervisor 卡死，无超时降级 |
| 5 | **黑盒推理** | 没有 Trace ID，出问题只能翻 log 文件人肉排查 |

## 三期改造

- **P0（第一批）**：不改会出事故，立即动手
- **P1（第二批）**：影响体验和成本，快速见效
- **P2（第三批）**：锦上添花，持续优化
