# Someone behind the software

> Karri Saarinen，Linear 创始人。关于好产品为什么需要有灵魂的创作者。

## 核心观点

好的产品承载着制作者的经验、他们关心的事、以及他们认为事情应该如何运作的思考。你可能不认识那些人，但你能感受到产品中的视角。

## 软件工厂的迷思

业界常把软件说成是从工厂出来的——收集需求、建立功能、衡量效果。按照流程走就能得到好结果。现在我们谈论用 agents 自动化整个流程。

但两个团队可能面对类似的客户、使用同样的技术，却做出截然不同的东西。差异来自于他们如何理解自己看到的事物，以及他们构建它的风格。创始人的背景或公司 DNA 深刻塑造了这一切。

## 直觉高于流程和数据

在 Linear，我们一直重视直觉而非流程或数据。人们有时认为这意味着基于个人偏好做决定，不需要太多思考或证据。我们所说的直觉是：你的直觉通过经验和理解发展而来。你做某件事、和客户交谈、犯错，然后学习该注意什么。直觉是你对某事物的观点，强迫你运用判断，而不是躲在冰冷的数据背后。

发布之前，我们和不同公司、不同角色的人交谈，了解他们如何工作。我们对自己的挫折有清晰的认知，但这些对话帮助我们理解了自己经验之外真正重要的事。我们的视角在那些对话之后变得更好了。

## 产品的灵魂

产品通过制造者关注的事、他们决定不做什么、以及技术实现后他们继续打磨什么来发展出它的性格。我有时把这叫做产品的灵魂。你能感受到有人在乎这一切如何组合在一起。

一个功能可能自身运行完美，却让产品变得更糟。认识到这一点需要关于产品应该是什么样的信念。需要有人做决定，然后足够贴近客户去看他们是否正确。

## 越来越像怪物

近来很多产品开始让我觉得杂乱，包括一些非常成功的公司的产品。似乎更多思考放在技术能做什么、能添加什么，而不是它应该采取什么形态。产品变化主要是附加的，而不是改进核心问题。

原因是：添加新能力比重新思考现有能力容易得多。每个产品都变成能力的集合，却没有真正统一的视角。

我好奇这是否来自工作组织方式。个人与 agents 一起工作，独立产生变化，每个都在运营一个小型软件工厂。每个变化自身可能合理，但合在一起开始像 Frankenstein 的怪物，而不是精心雕琢的雕塑。

没有共同的视角、灵魂或思想，产品变成了所有这些输出的平均值。曾经赋予它性格的选择正在被日复一日地稀释。更多东西能工作，但越来越难感受到背后有某个人或某种东西。

## 愿望

制作软件越来越容易了。我希望这给了人们更多空间去发展自己的视角并进一步遵循它。深入理解一个问题，然后不断塑造答案，直到各个部分融为一体。

> 我想感受到软件背后的创造者，而不是工厂。
