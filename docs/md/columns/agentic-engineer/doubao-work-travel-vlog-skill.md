# 用豆包工作做了个 skill，自动剪辑旅行 vlog

> 作者把一个地图动效 skill 放到豆包工作里调优后，可以输出 3D 地图动效，根据照片自动推断拍摄机位，还能直接拿一连串照片自动剪辑旅行 vlog。从云南自驾实战案例出发，拆解全链路：安装 skill → 给照片 → 多模态生成 Q 版 IP → 推断机位 → 渲染 mp4/gif → 接入剪映二次精剪。

## 核心效果

成片示例（云南自驾）：从地球俯冲定位到虎跳峡，Q 版小人沿真实路线一颠一颠走，每到一站停下来"拍张照"，照片一张张弹出，片尾照片墙收尾。全程一张网图都没要、一张照片都没修，纯链接输入，输出 1 分钟左右的 mp4 + gif。

## 使用流程

### 1. 安装 skill

让豆包工作执行：

```
安装这个 skill：SpaceZephyr/travel-vlog
```

Map-motion skill 包含五个子命令：

- `plan` — 机位规划
- `avatar` — 形象生成
- `check` — 成片质检
- `make` — 渲染成片
- `status` — 状态查看

### 2. 给照片

最简单的方式是直接丢社媒链接（即刻、小红书都行），skill 会自动抓取链接里的图片一张不落。

照片里没有 GPS 也没关系——模型会根据画面内容推断机位，再匹配地图上的真实地点。作者这次的照片从社媒链接下载、定位信息被转码剥光，skill 照样把虎跳峡、梅里雪山、雨崩三个机位在地图上标得清清楚楚，连站点间的驾驶里程都算好了。

想要更精确的路线，也可以对话中补充更详细的旅行路线。

### 3. 等成品

模型自动完成：

- 根据照片里的人物形象设计 Q 版动漫 IP（走路、拍照双姿势）
- 挑选每张照片的拍摄位置并在地图标注
- 制作视频、配乐
- 交付 mp4 视频 + gif 动图

> 这里必须夸夸豆包工作自带的多模态生成能力：上传一张旅行自拍，就能量身输出走路姿势、拍照姿势两套 Q 版贴纸，并自动抠成透明背景，直接做成视频里的小人素材，省去单独贴图素材制作环节。

### 4. 二次精剪（可选）

如果对成片不满意，或手里已有大量视频素材需要自己剪，可以再装一个剪辑 skill：

```
luoluoluo22/jianying-editor-skill
```

让豆包工作调用剪映 skill 把生成的动效视频作为片段，产出剪映工程文件，再在轨道里手动调整字幕、音效、补充自己拍的内容。作者痛点是"大量素材懒得剪"，靠这套组合做旅行 vlog 的粗剪版。

## 取舍

- **优势**：纯链接输入即可成片，多模态能力叠加 skill 编排，免去剪映手工操作
- **限制**：豆包工作的多模态生成与 skill 子命令属于平台内部能力，换到 Claude Code / Codex 需要重新封装 plan/avatar/make/check/status 这一整套

## 适用场景

- 一次性整理旅行照片出视频留念
- 自媒体创作者批量把社媒帖子转视频素材
- 作为剪映粗剪的预生成片段
