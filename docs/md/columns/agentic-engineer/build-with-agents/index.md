# 与智能体一起构建

> 记录"与 AI Agent 一起写代码、设计系统、推进项目"的第一人称实践——不是教 AI 怎么干活，而是和 AI 一起干活时的工程纪律。

## 这个专栏要解决什么

大模型不是"按下回车就有答案"的工具。当 AI Agent 开始能自主浏览代码库、编辑多文件、运行测试、提 PR，团队的工作方式就从"我写代码 + AI 帮忙搜文档"变成了"我和 AI 一起把事情做完"。

这个过渡带出三个真实问题：

1. **怎么分工**：哪些环节让 Agent 自主跑，哪些环节必须我亲自确认？
2. **怎么判断对错**：Agent 跑出结果后，我怎么快速判断它对不对、漏没漏、改歪没改歪？
3. **怎么演进方法**：每次合作完成一个任务，我都应该带回一条"下次更好的做法"——这是 Skill 的真正来源，不是 prompt 工程文档。

本专栏的每一篇文章都是一次"与智能体一起构建"的具体实践。可能是重构一段遗留代码、可能是给生产系统打补丁、可能是把一个新功能从想法推到上线。读完之后，你应该能拿走三样东西：可复用的工作流、可避开的坑、可借鉴的判断框架。
