# pi-crew：完整多 Agent 工作流

> 支持 Team、Workflow、并行执行、Worktree、Review、Research，还会判断一个任务到底值不值得上多 Agent。

## 定位

**偏完整的多 Agent 工作流**插件。

## 核心能力

- **Team 模式**：多 Agent 团队协作
- **Workflow 模式**：预定义工作流程
- **并行执行**：任务可并行处理
- **Worktree**：任务树管理
- **Review**：审查环节
- **Research**：研究环节
- **智能判断**：会判断一个任务**值不值得上多 Agent**，避免过度设计

## 适用场景

需要完整工作流程的复杂任务，如：
- 端到端产品开发
- 深度研究项目
- 完整的代码生成 + 审查流程
