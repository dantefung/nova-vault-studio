# pi-cost：专门查钱花哪了

> 可以从 Project 一路看到 Session、Message，Token 和费用都能拆开看。以前只知道"今天又烧钱了"，现在至少知道钱到底烧在哪。

## 定位

Pi 费用拆解工具。

## 核心能力

- **Project 级别**：看整个项目的费用汇总
- **Session 级别**：每个 Session 的 Token 消耗和费用
- **Message 级别**：细化到每条消息的消耗
- **费用归因**：明确知道钱烧在哪个模型、哪个 Provider

## 适用场景

- 想优化 Token 使用成本
- 不清楚为什么某个项目费用突然变高
- 需要给团队/客户汇报 Agent 使用成本

## 核心价值

从"今天又烧钱了"进化到"知道钱烧在哪"。
