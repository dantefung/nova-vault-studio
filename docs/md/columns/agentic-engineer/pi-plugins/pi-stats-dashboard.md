# pi-stats-dashboard：给历史 Session 做数据分析

> 模型、Provider、Tool、Cache、Token、错误都能统计。Pi 用久以后，几百个 Session 本身其实就是一份很有价值的 Agent 行为数据。

## 定位

历史 Session 数据分析仪表盘。

## 核心能力

- **模型统计**：各模型使用频率和消耗
- **Provider 统计**：不同 Provider 的成本分布
- **Tool 使用统计**：哪些 Tool 被用得最多
- **Cache 命中率**：Cache 效率分析
- **Token 趋势**：历史 Token 消耗趋势
- **错误分析**：Session 失败原因统计

## 核心价值

**几百个 Session = 一份很有价值的 Agent 行为数据**。

## 适用场景

- 深度复盘 Agent 使用习惯
- 优化 Agent 工作流
- 团队使用情况汇报
