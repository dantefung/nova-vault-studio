# pi-usage-widget：直接在 Pi 里看实时消耗

> Context、Cache、Token、Cost 都能盯，还会提醒 Large Context、长 Session 这些异常。

## 定位

实时消耗盯屏工具。

## 核心能力

- **Context 实时监控**：当前 Context 大小一览
- **Cache 状态**：Cache 利用率实时显示
- **Token 消耗**：当前 Session 的 Token 消耗
- **Cost 估算**：实时费用估算
- **异常提醒**：Large Context、长 Session 等异常自动提醒

## 适用场景

- 不想开额外工具，在 Pi 内直接看消耗
- 需要实时监控长任务的资源消耗
- 想及时发现 Context 膨胀问题
