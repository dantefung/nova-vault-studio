# pi-health：插件装多以后给 Pi 做体检

> 配置、依赖、Extension 状态出问题的时候，比自己一个个猜舒服很多。

## 定位

Pi 健康体检工具。

## 核心能力

- **配置检测**：Pi 各项配置是否正常
- **依赖检测**：插件依赖是否完整
- **Extension 状态**：各 Extension 是否正常运行
- **一键体检**：比逐个猜测更高效

## 适用场景

- 插件装多了以后 Pi 行为异常
- 不知道哪个插件导致了问题
- 需要系统性地排查而不是靠猜

## 注意

适合插件已经装得比较多的用户，初级用户暂时不需要。
