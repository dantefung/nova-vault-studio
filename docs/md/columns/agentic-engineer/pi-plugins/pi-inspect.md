# pi-inspect：把 Pi 当前加载的东西全部摊开

> System Prompt、Tools、Skills、Commands 都能直接看。特别适合插件装多以后排查，到底是谁把 Context 撑大了。

## 定位

Pi 加载项全览工具。

## 核心能力

- **System Prompt 可视化**：当前加载的 System Prompt 一览无余
- **Tools 清单**：列出所有已加载的 Tools
- **Skills 清单**：查看已注册的 Skills
- **Commands 清单**：所有可用 Commands
- **Context 诊断**：快速定位是谁把 Context 撑大了

## 适用场景

- 插件装多了以后不知道哪个在捣乱
- 想深入理解 Pi 的加载机制
- 调试 Token 异常消耗
