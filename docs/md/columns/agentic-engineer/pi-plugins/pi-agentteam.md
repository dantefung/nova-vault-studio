# pi-agentteam：Leader + Teammates 经典模式

> 比较经典的团队模式，Leader 负责调度，下面可以分 Researcher、Planner、Implementer，结构简单直接。

## 定位

经典的 **Leader + Teammates** 团队模式。

## 核心能力

- **Leader 调度**：一个 Leader Agent 负责任务分配和协调
- **专业角色分工**：下设 Researcher、Planner、Implementer 等专业角色
- **结构简单直接**：易于理解和上手

## 适用场景

结构清晰的多步骤任务，如：
- 研究任务：Researcher 搜集 → Planner 整理 → Implementer 执行
- 开发任务：Planner 分析需求 → Implementer 编码 → Reviewer 审查
- 内容创作：Researcher 调研 → Writer 写作 → Editor 编辑
