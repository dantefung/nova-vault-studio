# pi-agent-teams：常驻队友 + 共享任务板

> 不是临时拉一个 Sub-agent 干完就走，而是多个 Teammate 常驻，还能共享任务、互相发消息。

## 定位

多 Agent 协作，不是临时拉一个 Sub-agent 干完就走，而是**多个 Teammate 常驻**。

## 核心能力

- **常驻 Teammate**：不是用完即弃，而是持续存在于团队中
- **共享任务板**：任务在团队成员间共享和分发
- **互发消息**：Teammate 之间可以互相通信协调
- **持久化协作**：更像一个真正的 Team，而非单次工具调用

## 适用场景

需要多个专业角色长期协作的项目，如：
- 多角色代码审查团队
- 产品开发中的设计 + 开发 + 测试协作
- 研究团队中的信息搜集 + 分析 + 写作分工
