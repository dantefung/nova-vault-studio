# 如何更聪明地与AI协作：把事情做到极致的思路

> 来自 Claude 团队 Felix 的个人博客，一篇帮助你理解如何更好地与 AI 协作、如何更聪明地使用 AI 的文章。

## 核心问题

在这个能力每隔几周就突飞猛进的世界里，我们需要一些技巧，让我们能够做到以前从未想过或认为不可能的事情。

## 把事情做到极致的思路

1. **坚持使用业内顶尖专家使用的工具**
2. **选择看似不切实际的目标，然后告诉模型这些目标非常合理**
3. **挑战认知，创造新知识，使用外部评判者**

## 配套提示词

```
我想要的是一个更深入的版本，而不是一个更大的版本。在重写题目之前：
（1）请说明该领域的顶尖专家会做哪些我没有要求的事情；
（2）请列出他们会从哪些最原始的素材入手，而不是我已经整理好的素材；
（3）请列出他们会使用的具体方法和工具；
（4）除了你我之外，还有什么可以证明结果是正确的。

然后，请修改我的题目，使其完全符合上述要求。
```
