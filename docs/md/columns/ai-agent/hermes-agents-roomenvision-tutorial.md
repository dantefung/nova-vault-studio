# Hermes Agents 实战：从代码到上线、支付全链路一天跑通

> 和聊天 AI 最大的区别：它会自己去查官方文档、自己跑命令、自己验证结果，把判断留给我。
>
> —— 范范

我的 AI 房间改造工具 RoomEnvision 上线了：https://roomenvision.pages.dev/

上传房间照片，选风格，几秒生成改造效果图。从代码到上线、支付全链路跑通、提交商店审核——一天。

这篇文章想讲讲背后干活的 Hermes，以及它和我以前用的聊天 AI 到底有什么不一样。

## 一、三个概念：Profile、Skill、Agent

Hermes 是 Nous Research 出的开源 AI Agent 框架，和 Claude Code、Codex 是同类：能调用工具自己干活的 AI。它和我以前用的聊天 AI 最大的区别，是三个设计。

### Profile（档案）

官方文档的定义：每个 Profile 是一个独立的 Hermes 实例，有自己的配置、API 密钥、记忆、会话和技能，互不干扰。可以开一个写代码的、一个研究资料的、一个日常聊天的，各自的状态完全不混。

但这里我想说点真实的：Profile 管的是「状态」，不是「工作目录」。我原本想用桌面版的 Project 工作区来规范管理日常项目，用下来发现不方便——桌面端区分不好，最后只能靠硬盘目录自己分好，每次对话把项目目录复制一遍给 AI。这是我觉得它还不顺手的地方。

### Skill（技能）

官方定义：按需加载的知识文档。Agent 平时只带着技能清单（几百个技能只占很小一段上下文），遇到相关任务才加载完整内容——不浪费对话空间。

更关键的是：技能可以自己长出来。今天它把「从代码到上线」的完整流程、Creem 支付对接手册都沉淀成了技能，下次建站直接调用，不用重新翻文档。我发现它写的 skill 挺清晰的，不会有冗余堆砌的情况。

### Agent（代理）

官方的机制叫 agent loop（代理循环）：模型决定下一步做什么——调用工具、执行、看结果、再决定，循环往复，直到任务完成。

翻译成大白话：它不是回答完就结束，而是一轮轮自己干活：读文档、跑命令、调 API、验证结果，全程自动；遇到危险操作（比如改生产配置、删东西）会停下来等你确认。

## 二、实战一：它自己去查官方数据、找解决方案

对国内个人开发者来说，收海外用户的钱是老大难：PayPal 手续费高、Stripe 要海外公司主体。我最后选了 Creem（个人可注册、MoR 模式税务发票全包、支付宝直提人民币）。

但选完只是开始，接支付绕不开平台审核。Hermes 没有让我去啃文档，它自己读了 Creem 官方审核文档原文，把 7 项合规 checklist 整理得明明白白：

| # | 合规要求 | 说明 |
|---|---------|------|
| 1 | 政策页面必须存在 | 隐私政策/服务条款，无需登录可访问 |
| 2 | AI 产品需 AUP | 可接受使用政策，明确禁 NSFW/有害内容 |
| 3 | 客服邮箱一致 | 必须和商户资料完全一致（审核被拒最常见原因） |
| 4 | 内容审核 API | 必须接内容审核 API，正式环境要开 production 模式 |
| 5 | 自助取消订阅 | 用户要能自助取消订阅 |

它还顺手试出了文档里没明说的坑：测试环境的审核 API 很宽松，违规词也会放行——所以真实拦截效果必须到正式环境验证。

这些它半小时理清，我照着确认就行。

## 三、实战二：体力活，比如 8 个产品，它全包了

我的站是 4 个套餐（Basic/Pro/Scale/Team）× 月付/年付 = 8 个产品。Creem 的测试环境和正式环境完全隔离——这是支付平台的规范做法（Stripe 也一样）：沙盒里随便造，永远不会误扣真钱；但切正式环境意味着 8 个产品全部要重建（ID 完全不同）、webhook 重新配置、密钥独立，两边互不干扰。

这套迁移动作 Hermes 全自动走完了：

1. 读测试环境的产品配置
2. 复制字段到正式环境重建 8 个产品
3. 配置 webhook
4. 更新 26 个环境变量
5. 重新部署
6. 逐项验证（违规词必须真拦截、checkout 指向正式域名、错误签名 401 / 正确签名 200）

加上部署本身：数据库建表、生产迁移、图片存储、限流、6 个中英文政策页面……全程没让我碰终端。

## 四、我只做了三件事

拍板技术选型、在浏览器点授权按钮、用测试卡手动付了一笔钱验证流程。

技术选型也很朴素：

- **Next.js 静态导出 + Cloudflare Pages**（几乎零成本、全球边缘网络）
- **D1 数据库 + R2 图片存储 + KV 限流**（全家桶不用自己运维）
- **Replicate 跑 FLUX 模型**（单张成本约 $0.08）
- **Google One Tap 登录**

## 五、沉淀

今天踩的所有坑——改环境变量后必须手动重新部署、webhook 验签失败怎么排查——全部存进了它的技能库。下次我再建一个站，从代码到能收钱，预计半天到一天。

## 现状

| 阶段 | 状态 |
|------|------|
| 部署上线 | 静态页 + 数据库 + 图片存储 + 登录全通 |
| 沙盒支付全链路 | 测试卡支付 → 回调 → 订阅建档 → 积分到账 |
| 内容审核合规 | 政策页面中英文齐全 |
| 商店审核 | 已提交，48 小时内出结果，通过后正式收款 |

「从写代码到提交审核，一天。这在五年前是不可想象的。」

AI Agent 有没有用，不看它多聪明，看它能不能把体力活接走、把判断留给你。Hermes 对我来说就是这样：它干执行，我做判断。
