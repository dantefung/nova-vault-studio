# 为什么借钱的人多半不会再还

1



1



1



1



关于借钱这事‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍



‍‍‍



对于借钱这事，咱都不好意思开这个口。



但反过来管咱借钱的，张口就来。



人性的好赖大部分人并不真懂，借钱这种事就能扒个底朝天。



在很久很久以前，那年代的人欠人钱都睡不着觉。



用现在的话说，既感觉是负资产又感觉有羞耻感。



用我们东北话说，那时欠一屁股饥荒让人笑话。



但那已经成为历史，现在人没几个有契约精神。



很多事尤其朋友熟人之间，私约本就是很OK的。



你看现在事前口头说的，后面对自己不利多半不认了。



于是就各种合同条款，事事都要公约。



但借钱这事，写欠条都白搭。



因为只要借钱，人的心里就发生了变化。



如果他饭都吃不起了，他拿什么还。



如果他拆东墙补西墙呢，借完钱暴雷了他怎么还。



如果他手里没钱，挣了点钱一想到钱又要拿出去内心就不想还。



还不起不想还，最终都是一个结果拖着。‍‍‍
