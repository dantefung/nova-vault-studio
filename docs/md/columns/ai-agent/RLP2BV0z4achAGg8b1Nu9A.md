# AI 重塑研发范式，从技能驱动到意图驱动

AI 正在全面重塑互联网研发的底层逻辑，研发范式正从技能驱动转向意图驱动。传统岗位护城河土崩瓦解——当 90% 的常规编码可由 AI 完成，「会写代码」不再是稀缺能力；「纯人工堆砌代码」被彻底遗弃，人机协同正在孕育新的研发生产关系。
