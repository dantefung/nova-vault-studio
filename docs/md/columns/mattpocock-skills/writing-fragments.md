# writing-fragments 技能：挖掘异质写作片段

## 定位

writing-fragments 是一个**质询会话**，从你那里挖掘**片段**（fragments）——异质的写作块——并将其附加到单个文档中作为未来文章的原始材料。属于 **in-progress** 技能。

## 片段类型

挖掘的片段包括但不限于：

- **声明**（Statements）— 你坚信的观点
- **小插曲**（Anecdotes）— 你经历过的真实故事
- **尖锐的句子**（Sharp Lines）— 让人记住的金句
- **半成型的想法**（Half-formed Ideas）— 直觉但尚未体系化

## 挖掘策略

writing-fragments 通过追问挖掘：

1. 「你最近看到的一个反直觉的现象是什么？」
2. 「你不同意的主流观点是什么？为什么？」
3. 「你经历过的一个失败案例是什么？」
4. 「如果你只能传递一个信息给读者，你会说什么？」

## 输出

一个积累中的 `fragments.md` 文件，每次 session 追加新的片段。

## 与 writing-shape 的关系

- **writing-fragments** — 收集原料（输入）
- **writing-shape** — 塑造原料（加工）
