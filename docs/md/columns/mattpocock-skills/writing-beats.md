# writing-beats 技能：选择你自己的冒险文章塑造法

## 定位

将文章塑造成**节拍的旅程**，选择你自己的冒险风格。属于 **in-progress** 技能。

## 核心机制

1. **选择一个起始节拍** — 文章的起点（Hook / Problem / Thesis）
2. **只写那个节拍** — 不需要预先规划全篇
3. **转向下一个节拍** — 自然过渡到下一段
4. **重复直到自然结束** — 文章到达应该结束的地方

## 常见节拍序列

**叙事型**：
Hook → Background → Conflict → Resolution → Reflection

**说理型**：
Thesis → Evidence → Analysis → Counterargument → Synthesis

**教程型**：
Goal → Prerequisite → Step 1 → Step 2 → Gotcha → Next Steps

## 与 writing-shape 的区别

| 维度 | writing-beats | writing-shape |
|------|---------------|---------------|
| 起点 | 节拍（beat） | 原始材料（raw material） |
| 过程 | 按节拍顺序写 | 逐段塑造 |
| 结构 | 非线性，可选路径 | 线性，逐段精化 |
