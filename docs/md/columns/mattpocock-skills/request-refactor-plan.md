# request-refactor-plan 技能：重构计划生成（已弃用）

> ⚠️ 此技能已弃用，不再维护。

## 原定位

通过**用户采访**创建详细的**重构计划**和微小提交，然后将其作为 GitHub issue 提交。

## 弃用原因

- 用户采访的成本高于直接看代码
- 重构计划的质量依赖于采访者对代码的理解深度
- 实际场景中，直接用 **to-issues** 或 **improve-codebase-architecture** 更高效

## 替代方案

- **to-issues** — 直接从 PRD 或 plan 分解 issue，不需要采访
- **improve-codebase-architecture** — 直接在代码库中发现深化机会
