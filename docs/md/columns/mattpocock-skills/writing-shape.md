# writing-shape 技能：逐段塑造文章

## 定位

获取**原始材料的 markdown 文件**，逐段将其塑造成文章，在每一步论证格式选择。属于 **in-progress** 技能。

## 塑造流程

1. **选择一段** — 从 fragments 或 raw material 中选一段
2. **提出格式选项** — 这段适合什么格式？（叙事 / 说理 / 对话 / 列表）
3. **争论格式选择** — 追问为什么要用这个格式而不是另一个
4. **执行塑造** — 按选定格式重写该段
5. **重复** — 直到全文塑造完毕

## 格式类型

| 格式 | 适用场景 |
|------|----------|
| 叙事 | 有时间线、有因果的故事 |
| 说理 | 需要逻辑链条的观点阐述 |
| 对话 | 展示冲突、揭示认知差距 |
| 列表 | 步骤、要素、对比 |
| 引用 | 权威背书、案例举证 |

## 与 writing-beats 的区别

writing-beats 从**节拍**出发，writing-shape 从**原料**出发。前者更像即兴创作，后者更像编辑打磨。
