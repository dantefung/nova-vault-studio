# ubiquitous-language 技能：DDD 通用语言词汇表（已弃用）

> ⚠️ 此技能已弃用，不再维护。

## 原定位

从当前对话中提取 **DDD 风格**的**通用语言词汇表**（Ubiquitous Language Glossary）。

## 弃用原因

- DDD 的 ubiquitous language 需要在**团队协作**中建立，不是对话中提取
- 从对话提取的词汇表缺乏**团队共识**，准确度存疑
- 更好的替代：在 **setup-matt-pocock-skills** 建立的 CONTEXT.md 中手动维护

## 替代方案

- **setup-matt-pocock-skills** → `CONTEXT.md` 中手动维护领域词汇
- **grill-with-docs** → 质疑并更新领域术语定义
- 团队 workshop 中共同建立，而不是 agent 提取
