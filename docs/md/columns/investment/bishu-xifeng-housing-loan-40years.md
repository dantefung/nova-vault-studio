# 房贷40年，问题是我的前途有没有40年？

那天我写，没背景的孩子，怎么才能给自己谋个前途。

有读者留言问我有没有注意到，现在房贷最高已经可以贷40年了。

也就是说，假设一个人35岁攒够首付，他可以贷款到75岁。

那么如果他63岁就退休了，也就是说，退休之后，他依然要还款12年。

于是问题来了，房贷可以有40年，可你那天讲的前途本身，可不可以有40年呢？

.......

这个问题非常有趣。

有趣就有趣在算法，我听得懂你的表达。

你的表达很像我小时候，80年代那种24级工资制下的思维方式。

从50年代到80年代，当时有一代人都习惯了，习惯于工资是窄福波动的。

所以90年代第一次下岗的时候，对很多人的冲击是相当大的。

这个冲击，更大意义上是观念上的，倒未必是生活上。

那时候买断工龄，一次性给你几万块，在当时是很大一笔钱。

这笔钱在那时可以全款买房，也可以买辆车去开出租，基本上一年半就能回本。

搁今天，就相当于裁员大礼包不再是N+2，甚至都不是N+7，而是直接送你套房。

或者，送给你一门几乎必成的生意，每年赚套房那种。

但我们讲这个，是以后视者的目光去看的，对当时那代人来说，太艰难了。

这个艰难体现在思想上，认知上。

大家的认知，跨不过去那道坎。

也许遍地是黄金，可认知过不了关，你就没法捡，于是许多人在那时候都是借酒消愁。

直到买断工龄的钱花光了，实在过不下去了，不得不被推向市场。

慢慢地才适应了商品经济，也有相当一部分人，终身都未能再站起来。

年轻的读者可能不知道，去问你们的父母，或者爷爷奶奶，都知道。

一个人，如果几十年如一日的生活在24级工资制的环境下，他慢慢的就会养成一种习惯。

就是把收入看成是平均的。

而有些人，尽管出生在商品经济时期，但在思想深处，也会深受父母那代人的影响。

好比有些人，赚的少，他一年赚10万块，他就会预计自己明年，后年，也就这样了，他会鼓不起勇气，觉得自己做啥都不如人。

反之有些人，比如前些年的码农，他一年赚150万，于是他预计自己今后只高不低，他就按照年收入150万去贷款买房子，去送孩子进国际学校。

但实际上，在商品经济下，一个人一生的收入，是宽幅震荡的。

你的峰值，200万一年，你的谷值，20万一年，在相差十倍的区间里宽幅震荡，都是很正常的。

换言之，这个削峰填谷的工作，本来就是需要个人来完成。

那么我们想想看，如果一个人的认知没到位，他会怎么去理解房贷这件事？

他会觉得这是自己人生一个巨大的干扰项。

好比一个码农，他25~40岁这十五年的收入在20万到80万之间震荡。

可是41岁那年，收入断崖下降，他可能一下子变成了零散接活的状态，每年的收入在10~30万之间波动。

于是他就会产生一个问题。

你40年的房贷，是25岁还到65岁，每年的还款额度是差不多的。

可是他40岁到65岁之间每年的收入，是远低于他25岁到40岁之间的收入的。

假设他40岁之前还的刚刚好，那他40岁之后，就会还款困难，就会觉得是巨大的压力。

假设他保守一点，他40岁之前少还点，他又很可能因为还的少，手里的活钱多，养成大手大脚的习惯。

结果到了40岁之后，他的收入不断的下降，也没多少储蓄，后面还是还不起。

这种情况是很常见的。

因为多年以来，很多人都把买房当成了某种强制储蓄。

你不买房，那工资发下来也不知道花哪儿去了，你买房，好歹最后留了套房。

但上面这套机制存在的前提，是你的年收入在很小的区间内，窄幅波动，而且持续。

否则，你的收入宽幅震荡，你咋贷40年？

你算不灵清的，你没法把自己的收入曲线，和还房贷这件事，匹配起来。

所以，这种长达四十年期的房贷，这种类型的金融工具，它真正适合的对象，是那种具备很强的财务纪律，和财务管理能力的人。

所谓的财务纪律，就是说，这种人根本不需要通过房贷的方式给自己强制储蓄，他的钱本就不会乱花。

而所谓的财务管理能力，是说对他而言，所谓的房贷，实际上是一种低息融资。

我们来想一个很简单的问题，假设有一个人，一个年轻人，他就是我前面讲的，具备财务纪律和财务管理能力的人。

现在他要结婚生娃买房定居了，手头的钱呢，可以选择付600万的首付，还款20年，也可以少付一些，付300万的首付，还款40年。

那么他选择了后者，他的理由是什么呢？

是他这么做，相当于用3%的贷款利息，拿回了300万现金的个人支配权。

然后他去做了一些他擅长的事情，我随便举个例子，比如他拿去捡乌龙指了。

那他就很舒服，好比我用张三的钱去给自己每年赚30个点，但我却只需要向张三支付3个点，我白得27个点。

你有没有发现很有趣？我加了两个定语，这个40年房贷的金融工具，就从一个对普通人而言的鸡肋，变成了法宝。

所以，回到那天，这个读者的问题。

重点在于你怎么理解前途？

或者说，你理解的前途，到底是绑定在外部世界的，还是绑定在你自己身上的？

很显然，这个提问的人，他想象中的前途，是完全依赖于外部世界的。

外部世界觉得你有前途你就有前途，外部世界一旦不要你了，你就变成了流浪汪。

你等于把自己想象成一个宠物，主人喜欢我，我就是宝贝波斯猫，主人不喜欢我了，那我完蛋了，我就是街头流浪猫。

那你实际上就等于从来没有过前途，理解我的意思么？你自己什么都不能控制，你何曾有过前途？所以我那天讲的前途，它一定是加在每个人自己身上的定语。只有能伴你始终的，才是你身上的东西，才是别人剥夺不走的，它才配叫个前途。
