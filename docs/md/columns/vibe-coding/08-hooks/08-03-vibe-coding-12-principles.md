## 四阶段学习路径

### 1. 准备 (Prepare)

- **单一真源** (Single Source of Truth)
- **提示词先行** (Prompt First)
- **上下文洁净** (Context Hygiene)

为高效的 AI 协作奠定坚实基础。

### 2. 执行 (Execute)

- **人在回路** (Human-in-the-Loop)
- **分块工作** (Chunked Work)
- **并行流程** (Parallel Flow)

实施系统化的开发过程。

### 3. 协作 (Collaborate)

- **认知负荷预算** (Cognitive Load Budget)
- **心流保护** (Flow Protection)
- **可复现会话** (Reproducible Sessions)

优化团队协作模式。

### 4. 迭代 (Iterate)

- **休息与反思** (Rest & Reflection)
- **技能对等** (Skill Parity)
- **好奇心文化** (Culture of Curiosity)

鼓励持续改进与学习。
