# 开源一个拯救你旅行废片的 Skill

做了一个把旅行照片做成杂志风格海报的 Skill：**Yingzao · 营造**。

GitHub：https://github.com/op7418/guizang-yingzao-skill

安装：`npx skills add https://github.com/op7418/guizang-yingzao-skill --skill yingzao`

## 它好在哪里

**风格多样，不撞款**

营造有一套完整的 Design Token 系统，内置几十个经过验证的 Recipe（风格配方），每个 Recipe 对应一套字体谱系、材质层级、配色逻辑和排版骨架。生成海报时它会先分析照片——是正立面还是仰视？是大场景还是构件特写？是暖光还是冷调？然后从 Recipe 库里匹配兼容的方向。

善化寺藻井用古纸底、木刻字形；关帝庙木构用半靛蓝半石灰分区底色；大理上关做成了青花瓷蓝白色调；边靖楼则是朱红大字、竖排信息栏——完全不同的气质。组合起来有上千种变化，但每一种视觉上都说得通。

**自动检索文化背景**

给一张善化寺山门的照片，它会识别匾额「威德护世」，检索出明嘉靖七年（1528）所书，把这些信息排进海报。给一张应县木塔的照片，它标注「1056 · 辽 · 清宁二年」「五层六檐 纯木楼阁」。这些信息经过事实分级，不会编造「千年古刹，历经沧桑」之类的废话。

**多图融合，不是拼贴**

把多张照片融合成一张海报，不是往网格里一塞。灯笼、室内陈设、甜品特写、茶碗纹理这些来自不同照片的元素，会被提取后放进同一个视觉空间——共同的古纸底色、一致的光线方向、有明确的前后层次关系，看起来像一个场景，不像四张图硬拼。

**不只是古建**

食物、饮品、手工器物、文化店铺、暖光室内这些「亲密尺度」的场景也能处理。只要照片有一个真实的主体和在地感，它就能找到合适的方向。

**甚至有视频**

生成图片后，可以要求生成一张九宫格分镜和配套提示词，发给 Seedance 2.0 或 MiniMax H3 就能做海报分享视频。

## 怎么做到好看的

**整体思考，重建视觉世界**

很多海报工具是照片当背景，上面叠半透明遮罩再放标题。营造的做法不同，同时向图像模型输入四样东西：

1. **校正后的原图**：负责建筑的真实身份，屋坡、飞檐、匾额、轮廓这些「身份锚点」必须保留
2. **主导参考图**：负责完整的视觉机制——主体怎么处理、背景怎么参与、图文怎么互动
3. **排版垫图**：负责文字的位置、大小、层级、遮挡关系
4. **提示词**：告诉模型如何提取这几个图片中的样式，同时补充哪些样式

图像模型把这四样融合成统一画面。主体的语义抠取、背景的重建、材质的分区处理、文字和建筑轮廓的遮挡关系，都在同一次生成里完成。

**字体不是「选个宋体」**

每张海报的标题字形都是单独设计的：碑刻、雕版、人文宋、几何黑体、隶意还是实验字，然后逐字定义宽窄比例、笔画对比、起收笔特征、重心高低、字腔大小、表面媒介。

**丰富但不混乱**

每张海报只选一个主构图、一个主体容器、一个主材质、最多一个辅助材质、一套有角色差的字体、一个配色来源、一个主要空间冲突、零或一个语义装饰。

配色优先从照片里提取——建筑的漆色、砖石、天空、植物、灯光。不会无中生有加一个和照片毫无关系的强调色。

装饰也是克制的——只有来自照片可见内容、同时承担两项以上视觉任务、并且锚定到真实主体或标题的装饰才会被加入。不会因为是古建就撒满祥云纹。

限制越明确，出品越稳定。给模型一个被验证过的框架，它的任务从「设计」降级成「在框架内发挥」，成品率就上来了。

## AI 的角色

程序负责它真正擅长的事：测量、字体覆盖检查、碰撞检测、对齐、几何校正、输入纪律；图像模型负责它真正擅长的事：语义理解、空间重构、材质渲染、光线处理、图文关系。

生成之前把方向想清楚，生成之后把判断权交还给用户。不自动评分、不自动重生成、不消耗额外额度。成图直接交给你，你觉得哪里不对，告诉它，它再定向修改。
