# Pastory — 剪切板历史

> 电脑上什么都有历史记录，只有剪贴板除外。Pastory 给剪贴板开了个长期记忆的外挂。

**macOS App** · 已通过 Apple 公证

## 核心问题

每天复制文本、截图很多次，其中不少是一小时前刚做过的操作。剪贴板只记得最后一次，「下一次复制」时瞬间消失。

## 功能特性

- **历史记录**：复制过的文字、链接、图片、截图、录屏，都收拢在同一处
- **常用内容 Pin 起来**：就算设了定时清理，也不会被删
- **重要内容起标题**：一眼就能认出，单击立即复制，双击直接贴进外部输入框
- **本地优先**：所有东西都在你自己的电脑上，没有账号
- **隐私安全**：除每天一次检查更新外不联网，隐私 100% 在你手里

## 高阶用法

Agent 可定期读 Pastory 数据库，帮你结构化提炼成可随时 review 的 md 文件。
