Human System Optimization

像调优软件那样调优人体系统

整理自 Andrew Huberman（斯坦福神经科学教授）podcast 的高质量同行评审研究结论——从机体工作原理出发，而非经验偏方。

系统
调优
极简基础四件事 · 做到这四点已达不错健康状态
  • 1保持睡眠时长与质量
  • 2不要吸烟
  • 3尽可能每天做点运动
  • 4减少糖分摄入
I睡眠
生物钟由光照与体温驱动
  • 户外光照 2–10 分钟
  • 夜间避光 23–04 点
  • 时长 6–8 小时
  • 早冷水澡 / 晚锻炼调周期
II饮食
何时进食与吃什么同等重要
  • 8 小时进食窗口
  • 睡前 2–3 小时不吃
  • 一天两次发酵食品
  • 地中海优于生酮
III心态与动力
多巴胺看相对变化量
  • 储备有限，快乐通用
  • 随机化叠加因素
  • 把过程本身当奖励
  • 冷水浴 2.5 倍 / 3 小时
IV学习与专注
学习 = 神经元重连接
  • 需专注 + 犯错信号
  • 重连接发生在睡眠
  • 倒立瑜伽触发可塑性
  • 17 分钟冥想改善注意
V大脑健康
有氧运动对大脑帮助最大
  • 有氧每周 150–180 分钟
  • EPA 每天 1.5–3 克
  • 胆碱来自蛋黄
  • 蓝莓每天 60–120 克
VI长寿
衰老 = 基因信息损失
  • 表观基因组占 80%
  • 低血糖激活 sirtuin
  • 植物蛋白与健康脂肪
  • NMN 证据仍有争议
VII个人实践
原作者 zijie0 执行情况
  • 8 小时进食窗口
  • 每周 3 次运动 PAI 200
  • 专注模式近似番茄钟
  • 间歇 Yoga Nidra
◎数据监控
用指标代替感觉
  • HbA1c 血糖
  • CRP 炎症
  • LDL 胆固醇
  • 补充剂先取公认者
