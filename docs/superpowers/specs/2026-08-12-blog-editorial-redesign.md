# 博客克制出版视觉升级设计规格

## 目标

将 `/md/blog/` 从模板化卡片墙改为个人作者博客：观点与文章是主角，页面依靠排版、留白、细线和少量精选插画建立识别度。

## 范围

- 改造博客首页、分类页、系列页、归档页、博客公共页头和页脚。
- 保留最新、分类、系列切换，搜索、主题切换、移动端导航、现有路由和索引数据。
- 不修改文章正文阅读页、博客索引生成脚本和内容 frontmatter。

## 信息结构

### 首页

1. 编辑式导语：`BLOG / NOTES ON BUILDING`、一句明确主张和简短说明。
2. 5 篇精选：优先使用索引里的 `featured` 文章；不足 5 篇时按时间以最新文章补齐。
3. 全部文章：排除精选后的最新文章，以单列文字目录呈现。
4. 分类与系列：沿用现有标签切换，不新增路由或筛选状态。

### 分类与系列

- 页头展示类型、名称和文章数。
- 内容统一使用文字行，不显示封面、标签胶囊或卡片容器。

### 归档

- 月份是左侧时间锚点，文章是右侧紧凑目录。
- 不为每个月创建独立卡片网格。

## 视觉系统

- 表面：纸张感的低饱和背景，不使用渐变装饰。
- 层级：衬线/楷体标题、清晰字号差、细分隔线和宽留白。
- 交互：颜色和下划线反馈，不使用上移动画、悬浮阴影。
- 形状：不使用大圆角卡片、胶囊标签或伪封面首字。
- 元信息：纯文字和中点分隔，不使用 Emoji。
- 插画：仅 5 篇精选使用低饱和编辑插画；插画只是识别锚点，不进入其余文章目录。

## 组件边界

- `BlogLayout.vue`：路由分发、公共页头和页脚。
- `BlogIndexLayout.vue`：首页导语、精选集合、三种索引模式。
- `ArticleCard.vue`：唯一文章条目组件，通过 `feature`、`default`、`compact`、`row` 变体适配场景；根元素不再包裹可点击元信息，消除嵌套链接。
- `ArticleMeta.vue`：无图标元信息；链接只在卡片根元素之外的使用场景启用。
- `SeriesLayout.vue`、`CategoryArchiveLayout.vue`、`ArchiveLayout.vue`：只负责各自页面结构，不复制文章视觉。
- `easton-blog.css`：博客跨组件布局、主题和响应式规则。

## 响应式

- `> 900px`：精选采用主条目加四条次级条目的非对称布局；归档月份和文章并列。
- `641px - 900px`：精选改为两列，普通文章保持单列。
- `<= 640px`：全部单列，页头导航由现有移动端组件接管，导语字号收敛，元信息允许换行。

## 兼容性与验收

- 保持所有现有 URL 和导航行为。
- light、dark、sepia 三种主题均有可读对比度。
- 页面不得产生嵌套 `<a>`。
- 运行 `npm run build`，并在桌面和移动端检查首页、分类、系列、归档。
