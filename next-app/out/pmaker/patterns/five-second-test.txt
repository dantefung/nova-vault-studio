<h1>五秒测试</h1>
<p>首屏的信息传达，五秒就定生死。找个没接触过产品的人，让他看五秒，然后问三句话：**这是什么？我能得到什么？我该做什么？**答不上来，就是首屏没讲清。</p>
<p>你会遇到的现象</p>
<ul>
<li>
<p>用户第一眼不知道这是干什么的，要靠小字慢慢猜</p>
</li>
<li>
<p>首屏堆满了功能入口，没有一句在说「这是什么」</p>
</li>
<li>
<p>自己看久了觉得哪都懂，换个陌生人就懵</p>
</li>
</ul>
<h2>五秒在测什么</h2>
<p>五秒测试测的不是好不好看，是<strong>信息传达</strong>：用户在这五秒里，有没有建立起「这是什么产品、关我什么事」的心智。</p>
<ul>
<li>
<p>**只测首屏。**五秒只够看完第一屏。第一屏没讲清的，后面的屏再精彩，用户未必看得到。</p>
</li>
<li>
<p>**测的是「留不留下」的那个瞬间。**它验证的是用户愿不愿意继续往下走，不是用户会不会付费、会不会注册。</p>
</li>
<li>
<p>**答不出来的原因通常是信息太多。**首屏试图同时讲十件事，等于一件都没讲。堆功能不等于传达价值。参见一屏一件事。</p>
</li>
</ul>
<h2>怎么做</h2>
<p>流程简单，难在选对人、问对问题：</p>
<p>五秒测试</p>
<p>对象没接触过产品的人同事、用户都不行
时长只看五秒看久了就不是第一印象
提问这是什么 / 我能得到什么 / 我该做什么三问定生死
样本三到五个人够暴露问题，别等「量」</p>
<p>回答里出现「大概」「可能是」这样的词，和「不知道」一样，都说明没讲清。</p>
<ul>
<li>
<p>**找没接触过的人。**同事、已注册用户都不行——他们已经「知道这是什么」了，测不出信息传达。样本脏了，结论就脏了。</p>
</li>
<li>
<p>**严格五秒。**看一眼就收走。看久了就变成「仔细阅读测试」，测的是阅读能力，不是第一印象。</p>
</li>
<li>
<p>**问的是开放问题。**别给选项，别提示。他说出「这是个做笔记的软件」，说明讲清了；他说「呃，一个网站」，说明没有。</p>
</li>
<li>
<p>**三五个人的答案就够判断方向。**五秒测试是暴露问题的定性检查，不是给结论的定量依据——别拿它当统计调查。定量的事交给真实数据。</p>
</li>
</ul>
<p>三问依次通过，卡在哪一问，修法就不同</p>
<p>这是什么？</p>
<p>我能得到什么？</p>
<p>我该做什么？</p>
<p>缺一句概括产品的话
加一句白话的定位，
而不是摆更多功能入口</p>
<p>价值被功能列表盖住了
把「对我有什么用」挑出来，
放到看得见的位置</p>
<p>缺一个明确的下一步
首屏要有且只有一个
主入口，别让他自己找</p>
<p>回答里出现「大概」「可能是」，和「不知道」一样，都说明没讲清。</p>
<p>找没接触过的人——同事、已注册用户都不行，他们已经「知道这是什么」了，样本脏了结论就脏了。
改一版，再找三个人，十分钟出结果。循环到三问都能答上为止。</p>
<p>严格五秒，看一眼就收走。<strong>看久了就变成「仔细阅读测试」</strong>，测的是阅读能力，不是第一印象。也别拿它当定量依据——它是暴露问题的定性检查，三五个人的答案就够判断方向。</p>
<h2>答不上来怎么办</h2>
<p>三个问题答不上来，对应的修法不一样：</p>
<ul>
<li>
<p>**答不出「这是什么」→ 首屏缺一句能概括产品的表达。**加一句白话说清产品的一句话定位，而不是摆更多功能入口。参见一句话产品。</p>
</li>
<li>
<p>**答得出「是什么」、答不出「我能得到什么」→ 价值被功能列表盖住了。**把「对我有什么用」从「有什么功能」里挑出来，放到看得见的位置。</p>
</li>
<li>
<p>**前两个都对、答不出「我该做什么」→ 缺一个明确的下一步。**首屏要有且只有一个主入口，别让用户自己找。参见首次体验设计。</p>
</li>
<li>
<p>**修完再测一遍。**五秒测试的好处就是便宜：改一版，再找三个人，十分钟出结果。循环到三问都能答上为止。</p>
</li>
</ul>
<h2>接着看</h2>
<p>视觉层级从哪来
五秒里用户先看到什么，由层级决定。层级错了，什么都白搭。</p>
<p>一屏一件事
首屏同时讲十件事，等于一件都没讲——这就是五秒答不上来的根源。</p>
