这一行的黑话密度很高，但真正高频的没多少。把这几十个认全，大部分会议就不会掉线了。

需求与用户

词意思 PMF产品与市场匹配。有没有一群人真的需要你做的这个东西 MVP最小可行产品。能完整验证一次想法的最小范围 用户画像把目标用户写成一个具体的人，方便团队对齐 用户旅程用户完成一件事的完整路径，含情绪起伏和卡点 痛点 / 痒点痛点是不解决不行，痒点是解决了更爽。两者的付费意愿差很多 需求池攒着还没做的需求，带优先级和状态 PRD产品需求文档。给设计和开发看的那份说明 BRD / MRD商业需求文档 / 市场需求文档，比 PRD 更早，给决策层看 竞品分析拆同类产品，看它的结构和取舍，不是抄功能列表

数据与增长

词意思 DAU / MAU日活 / 月活。两者的比值反映使用频率 留存率今天来的人，第 N 天还有多少回来。次留、7 留、30 留 转化率某一步走到下一步的比例。链路上每一步都有 漏斗把链路每一步的人数画出来，看在哪一步掉得最狠 埋点在代码里记录用户做了什么，是所有数据分析的前提 北极星指标选一个最能代表产品在变好的数，其余都是参考 AB 测试把用户随机分两组，一组看新版一组看老版，比效果 灰度新功能先放给一小部分人，没问题再全量 GMV成交总额。注意它不是收入，抽佣之后才是 LTV / CAC一个用户带来的总收入 / 获得一个用户花的钱。前者要大于后者

设计与交互

词意思 信息架构内容怎么分组、导航怎么长，用户靠它知道自己在哪 线框图 / 原型线框是黑白结构，原型是能点的假界面 设计系统一套定死的颜色、间距、字号和组件，保证各页长得一样 空状态没有数据时页面显示什么。新用户看到的多半是它 骨架屏加载时先占住内容的位置，避免数据回来页面跳动 吸顶 / 悬浮滚动时固定在顶部或浮在内容上的元素 走查上线前照着清单逐条过一遍界面和流程

技术

词意思 前端 / 后端用户浏览器里跑的 / 你服务器上跑的 API 接口前后端之间约定好的对话方式，谁传什么、返回什么 字段一条数据里的一项，比如订单的金额、状态 同步 / 异步同步是等它做完再往下，异步是先往下走结果晚点回来 缓存把算过的结果先存着，下次直接拿。快，但可能是旧的 并发很多人同时操作。抢购、改同一条数据都属于这个问题 幂等同一个操作重复执行结果不变。付款按两次不能扣两次钱 回滚发现新版本有问题，退回到上一个版本 软删除只标记为已删除，数据还在，可以恢复
