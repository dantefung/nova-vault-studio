<h1>北极星拆解</h1>
<p>一个北极星只能告诉你「整体好不好」，不能告诉你「该干什么」。把它<strong>拆成几条可以分别下手的路径</strong>，拆到每一步都有人能负责、有数可看，北极星才从口号变成日常工作。</p>
<p>你会遇到的现象</p>
<ul>
<li>
<p>北极星定了，但没人知道这个月该做什么来推它</p>
</li>
<li>
<p>所有人都「对北极星负责」，等于没人负责</p>
</li>
<li>
<p>只有总指标，没有中间指标，涨了跌了都说不清是哪一环的功劳</p>
</li>
</ul>
<h2>一个指标为什么不够</h2>
<p>北极星适合当「裁判」，不适合当「任务」——它回答的是「这季度做得好不好」，不回答「这周干什么」。</p>
<ul>
<li>
<p><strong>总指标是结果，不是动作。</strong>「周活跃用户数」不会告诉你下一步做什么。一个只能事后看结果的指标，当不了事前的手册。</p>
</li>
<li>
<p>**结果只能复盘，中间指标才能抓手。**涨了，是新增多了还是流失少了？只有拆开才能回答。拆开之后，每一环都有事可做。</p>
</li>
<li>
<p>**不拆，责任就没人认领。**一个指标对所有人负责，等于对所有人不负责。拆成路径，每一条才有具体的责任人。</p>
</li>
</ul>
<h2>怎么拆</h2>
<p>顺着用户的路径拆——来、用、留、回，每一步落一个可以单独下手的指标：</p>
<p>环节这一步的指标能被什么动作影响谁在看
来新增激活数加一个入口、调一个渠道增长
用核心任务完成率改引导、减步骤产品
留次周留存改唤醒、建使用习惯用户运营
回回来后的活跃个性化内容、推荐算法</p>
<p>拆到这一层，「这个月做什么」就有了答案：每一条路径都有一个指标、一组动作、一个责任人。</p>
<ul>
<li>
<p>**把达成北极星的用户路径画出来。**从来到用、留到回，画成一条可走的路。路径不画出来，拆解就是拍脑袋。</p>
</li>
<li>
<p>**每一步落一个能单独看的指标。**来的看渠道，用的看完成率，留的看次月留存，回的看唤醒。别让几条路径共用同一个数。</p>
</li>
<li>
<p><strong>每条路径都要能被一个具体动作影响。</strong>「加一个入口」「改一个引导」「调一个提醒」——改得了才算路径，只能看着它涨跌的不算。</p>
</li>
<li>
<p>**每条路径都要能独立埋点看数。**没埋点，路径就只是个说法。埋点跟着功能一起上线，参见先埋点后上线。</p>
</li>
</ul>

<p>拆到这一层，「这个月做什么」才有答案：每条路径一个指标、一组动作、一个责任人。
一个指标对所有人负责，等于对所有人不负责。</p>
<p>三个判断过一遍就知道拆得对不对：**每条路径能被单独影响、有数据可看、有人负责。**没埋点、算不出来的路径不算路径；没人负责的路径只会出现在周报上。</p>
<h2>拆得对不对</h2>
<p>拆完用三个判断过一遍：</p>
<ul>
<li>
<p>**每条路径都能被单独影响。**团队做一件事，能只影响这一条而不动别的——这样才谈得上针对性下手。</p>
</li>
<li>
<p>**每条路径都有数据可看。**没埋点、算不出来的路径不算路径。数据来源要跟路径一起确认。</p>
</li>
<li>
<p>**每条路径都有人负责。**有人负责的路径会前进，没人负责的路径只会出现在周报上。参见指标体系怎么搭。</p>
</li>
</ul>
<p>拆完之后别忘了上游：路径拆得再细，北极星本身选错也白搭。选北极星的四个条件，参见一个北极星。</p>
